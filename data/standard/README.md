# data/standard — 標準パッケージ(環境ミキサーで世界に足す。D-457・T-0373)

エンジンは中身を持たない(D-454)。現実の元素・物質・反応・地球の環境は、ここにある Luau のパッケージで、
エディタの環境ミキサー(14 §2)か `--mix <名前,...>` で世界に足す。ここは世界の既定の読み込み(data/packages)とは別の棚で、
足さなければ読まれない(ブランクの世界は空のまま。D-455)。

| パッケージ | 中身 | 依存 |
|---|---|---|
| real_elements | 現実の元素(C・H・N・O・Ar の原子量) | なし |
| real_matter | 現実の物質(空気の気体・水蒸気・CO・炭・セルロース。値は現実のまま) | real_elements |
| real_reactions | 現実に則した反応(セルロースの熱分解と燃焼・炭の燃焼・Boudouard) | real_matter |
| earth_environment | 地球の環境(重力・気体の音速の基準・基準の大気の成分と温度と地面の圧力) | real_matter |
| earth_air | 世界のセルを地球の基準の大気(15 ℃・1 気圧の乾いた空気)で満たす | real_matter |

中身は ⑤ の場面(草原の延焼・氷が溶けて流れる・木の橋が燃える)に要る分だけ(D-471 ②)。足りない物は場面のチケットで足す。
世界ごとに変えられる物理の値は今は重力と音速の基準だけで、どちらも地球の環境(D-480)。普遍の定数(気体定数 R など)は器(エンジン)にある。
