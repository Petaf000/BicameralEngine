## 目的
T-0871・T-0944 の 2 次元(縦の面・奥行 1 セル)の格子の梁 + 段の斜めの棒を 3 次元にする。節 = セルの中心が変位 3 + 回り 3 を持ち、面ごとに梁(伸び・ずれ 2・ねじれ・曲げ 2)。

## 完了条件
- [ ] 3 次元の格子の梁(奥行の向きの面・回り 3・ねじれ)。T-0871・T-0944 の 2 次元の場面で同じ答え(奥行 1 セル。丸めの内)
- [ ] 3 次元の段の斜めの棒: 辺で接する斜めの隣(面の段)だけか、角で接する斜め(3 軸の段)にも置くかを、斜めに傾いた壁・3 次元のアーチ(奥行 > 1)で連続体(六面体の Q6 / H11 を細かく刻んだ基準)と比べて決める(±5 %・0.5 m と 0.25 m)
- [ ] 帳簿(力 3 成分と回り 3 成分の釣り合い)が毎刻み厳密・決定的
- [ ] 欄に触るなら LoadNestField / FieldPageValues(疎な頁 T-0921)
- [ ] C-0 の部品は変えない(成分を持つ節 T-0919 が入るまで結合は遅らせる)
