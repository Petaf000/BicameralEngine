## 目的(1〜2 行)
今は最初の保存点(刻み 120 = 起動から約 2 秒)より前に置いた筆の運びを元に戻せない(パネルに理由が出る)。刻み 0 の保存点を作り、
エディタを開いた直後の運びもいつでも戻せるようにする(保存点 1 つ分の VRAM 約 33 MiB。仮の世界 + 積み木の時の値)。

## やったこと(ADR-0101 追記 1・ADR-0036 追記 1・14「実装(T-0411)」)
- **数え方**: 保存点を使う起動(`--editor` の既定・`--save-points n ≥ 1`)は、n 個の回す保存点とは別に刻み 0 の保存点を 1 つ作る
  (番号 0 = TICK_ZERO_SAVE_SLOT。`--editor` の既定で 7 個・VRAM は 1 つ分増える)。刻み 0 は回して上書きしない・巻き戻しでも捨てない。
  捨てるのは反応表の差し替えだけ。回す保存点は 1 + (刻み / 間隔 − 1) mod n の番号へ(いちばん古いものから上書き)。
- **写し方**: 保存点を使うなら最初のリストは初期化だけ(単位・コマンドなし)。次のリストの先頭で S(0) を写す(frame_loop の SubmitSim・SaveSlotFor)。
- **元に戻す**: PlanBrushUndo は変えない(運び以前でいちばん新しい保存点)。刻み 0〜119 の運びは刻み 0 へ戻して流し直す。
- 試験: gpu_probe_rewind に刻み 0 の場面を足した・window_place_tick0_record/play(保存点の間隔 1000000 = 刻み 0 の保存点だけで --auto-place の
  元に戻すを通す。仮の世界)・window_blank_rewind(ブランクの世界の再生で刻み 0 へ戻す)。window_replay_rewind は刻み 0 へ戻すようになった。

## 判断待ち(仮で進めた。ユーザー未確認)
- **回す保存点より古い運び(`--editor` の既定で約 12 秒より前)を元に戻す時**、刻み 0 の保存点から流し直してよいか。
  - 案 A(仮で採った): 戻す。最後の運びは古さによらず元に戻せる(「古すぎて戻せない」は反応表を差し替えた後だけ)。作り手から見ると、
    長く動かした後に古い運びを戻すと、起動からの全部の刻みを流し直すので待つ(世界が早送りで追いつくのが見える。速さは GPU の予算しだい。未計測)。
  - 案 B: 刻み 0 の保存点は「最初の回す保存点〔刻み 120〕より前の運び」だけに使う(D-474 ② の文字通り)。起動直後の運びはいつでも戻せるが、
    刻み 120 以後の運びは今まで通り約 12 秒まで。流し直しが長くなるのは起動直後の運びを後で戻した時だけ。
  - 案 C: 刻み 0 の保存点もほかと同じく回して上書きする(VRAM は増えない)。起動直後の運びも、ほかの運びと同じく約 12 秒の間だけ戻せる。
  - おすすめ A(どの運びも同じ規則で戻せ、作り手が「古すぎる」で止まらない)。B・C への切り替えは PlanBrushUndo の引数か SaveSlotFor の 1 か所。
