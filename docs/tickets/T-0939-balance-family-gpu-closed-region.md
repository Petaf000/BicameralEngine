## 目的(1〜2 行)
T-0915 の部品の GPU 版(GpuEquilibrium)は、同じレベルの節(気体の箱)と閉じない解きだけ。CPU の部品(SolveEquilibrium)の閉じた領域と、
木のセル(違うレベルの節・粗い側 ÷ 8^差の面)を GPU でも同じに解く。

## 完了条件(チェックできる形で)
- [ ] 閉じた領域の GPU 版: 種(右辺が seedTolerance を超えて変わった・対角が変わった・法則の種・前の残差が residualSeed を超えた)→ 長さの内の節の印(Chebyshev。EqAxisGap)
      → 未知数の詰め(キーで並べてからプレフィックス和。R5)→ 外への面を外の前の答えを値にした固定した面に(EqSourceTerm)
- [ ] 段の形を GPU で作る(GpuImplicitLevels の形を部品の系に当てる。閉じた領域は刻みごとに未知数が変わるので、CPU の段の形を写す形では写しの費用が得を消す〔未確認。測る〕)
- [ ] 違うレベルの節(粗い側の行の係数 ÷ 8^差・縮約の行き先が混ざる段。equilibrium_core.hlsli の EQ_GPU_ROW_MAX を超える長い行)
- [ ] equilibrium_test の閉じた領域(12³・重みの形)を GPU で: 長さが世界を覆う時は閉じない解とビット一致・小さい長さで外の節がビット一致・種と未知数の数が CPU と同じ
- [ ] 気体の泡(16³・3 m)で閉じても保存 0・CPU とビット一致・2 回の実行でハッシュ一致

## メモ・参考
- T-0916(熱の陰解法を部品の上へ)が木のセルを使う。GPU の木の熱の陰解法(GpuMultiresImplicit)を部品へ移すのはこのチケットの後。
- 作業場の詰め(T-0918)と一緒にすると、GPU の段の作りの上限の決め方を 1 回で決められる。
