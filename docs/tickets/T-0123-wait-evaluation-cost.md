## 決めたこと(Claude。実装の細部。ADR-0018 追記〔T-0123〕)
- GPU の StepBlockWait は、`印 < wakeTick かつ busyTick ≠ 印` のブロックを一様でも頁でも評価しない(今までは一様なブロックだけ)。
  最後に評価してからセルも tc も変わっていないので、評価しても何も変わらず起こす刻みも同じ値になる(ADR-0018)。CPU の StepNest・StepActive は
  今までどおり全部を評価する(全部を計算する側 = 確かめる側。GPU との毎刻みの一致がこの省略を確かめる)。
- log2 と割り算を要る時だけにする形(整数部だけで使い切るなら log2 なし・候補ができた後と整数部のある規則は割り算の代わりに掛け算で比べる)は、
  CPU の答えは同じ(g++ で前の式と 300 万通り突き合わせて食い違い 0)だったが、GPU の仮の世界(gpu_conduct_bench)が 8〜12% 遅くなった
  (ウェーブの中で道が分かれ、両方の道を走るうえに式が大きくなったためと推定)ので採らない。式は今のまま(RxDesiredExtentWait・RxWaitTicks)。
