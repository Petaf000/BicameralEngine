# T-1207 違う大きさの面の移り目が梁の中立軸に沿う所の偽の曲げ(T-1191 から)

- Status: Done(2026-10-29・wt4・CPU + GPU のビット一致: 根は仮説 1〔回りの勾配〕→ ADR-0501(Proposed・仮で既定)。上の段だけ 6.95 / 10.08 % → 1.32 / 4.87 %)
- 種類: 研究
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: 試作の列 3(R-B2〜R-B3。世界の木の支え T-1178 の前)
- 設計: docs/design/22-support-law.md §3.2・§3.5 / 決定: ADR-0470・ADR-0485・ADR-0491

## 目的(1〜2 行)
片持ち梁 8 × 1 m の上の段だけを 0.25 m にした場面(移り目 = 上の面が梁の中立軸に沿う)で、違う大きさの上の面に偽の曲げが出る
(根の柱の移り目 10.08 %・根から 1 m 6.95 %。全部 0.25 m では 0)。根を突き止めて T-1191 の線(5 % 以内)に入れる。

## 分かっていること(T-1191・T-1206 から)
- 全部 0.25 m の答えでは、中立軸の上の面の縁の力は 0(伸び 0・回りの差 0)。混ざると 根の柱 低 −8.4 / 高 +29.2 MN・根から 1 m(細かい座標 (4, 1))低 −20.1 / 高 +15.8 MN。
- ③・②・③' でも同じ大きさ(7〜16 %)= ④ の対のずれ(線形の場)の直しの外。

## 仮説(2026-10-29・始める前)
1. **回りの勾配(曲率)を粗いセルが持てない**: 曲げの梁では回り ω が x に沿って変わる(∂ω/∂x = 曲率 κ)。粗いセル C の上に並ぶ細かいセル L・R の回りは
   C の回りから ±κ s/2 ずれ、違う大きさの面の曲げの項 ½ (b/3)(2φ_F − φ_C)² が L・R に逆向きの偽の回りを出す(全部細かい塊では上下に並ぶセルの回りは同じなので 0)。
   見積もり: 偽の縁の力 6 × (b/3) × κ s²/2 = b κ s²・根の上の縁の力 ≈ 0.75 b κ(s = 0.25)の 8 %。観た 7〜10 % と合う。
2. **縦の変位の放物線**: 曲率で L・R の面の点の縦の変位が C の剛体の面から κ s²/8 ずれ(弦と中心の差)、L・R に同じ向きの偽の伸びが出る(根の柱の平均 +10 MN)。
- 直し(④ と同じ芯 = 対の中の形の違いは C に掛けない): 対の曲げの差 (φ_R − φ_L) の分を負の項で引く(ずれの −½ K (d_U − d_L)² と同じ形)・
  伸びは対の回りの差から弦の差を引いて読む(2Δn'_k ∓ (φ_R − φ_L)/2)。

## 研究の打ち切り条件
- 浮動小数点の捨てる模型(作業場だけ・リポジトリに入れない)で C++ の 6.95 % / 10.08 % を 3 桁で再現できなければ、まず模型を直す(2 回でだめなら C++ で直接試す)。
- 仮説 1・2 の直しを 2 つの形(① 曲げの差を引くだけ ② ① + 伸びの弦の直し)で試し、上の段だけの場面の違う大きさの面と固定した面の近くが **5 % に入らなければ**、
  その形を記録して退く道へ: **細かさの規則の側で移り目を中立軸(横のずれ・曲率の大きい所)から離す**(細かくする領域を梁の厚さの全部に広げる = 支えの節 = 木の節で
  T-1178 に渡す)。作り手から見た違い(梁の厚さの途中で細かさを変えない)をチケットに書いて司令塔へ。
- ほかの支えの場面(ctest `^support_` 9 本)の値が変わるなら、変わった値と新旧の比べを書く。混ざる面の無い場面はビット一致を保つ(混ざる面の式だけを変える)。

## 判断待ち(仮で進めたもの)
- **違う大きさの面の曲げも対の平均でつなぐ(ADR-0501・Proposed・仮で既定)**。【エンジン】作り手から見た違い: 書く値は無い。梁の厚さの途中(特に中立軸)で細かさが変わる所の
  縁の力の偽の曲げが 7〜10 % → 1〜5 % になり、移り目で割れの判定が早まる・遅れる量が減る。代わりに隣の細かい面の誤差が 0.1〜0.6 点上がる場面がある(全部 5 % の中)。
  取り消しは `SupportOptions::mixedBeam = MixedBeam::FacePairShear`(前の値にビット一致)。
- 上の段だけの場面の縁の力の確かめを 5 % に入れた(固定した面の近く 4.87 % で余裕が小さい)。

## 分けたもの・司令塔へ
- 分けたもの無し。残りの 4.87 %(根の柱。固定した面のすぐ横で縦の変位が強く曲がる所の縦の伸び)と、中立軸を挟んだ回りの放物線を粗いセルの片側の差で読む 2 次の誤差は、
  粗いセルの側の精度(研究)か移り目を固定した面から離す細かさの規則(T-1178)の側。
- 土台の共通部分に足したものは無い(支えの法則の混ざる面の中だけ)。対の面のブロック(L と U の面)に負の項が 1 つ増えた(ずれの負の項と同じ所。面のブロックだけでは正でないのは前と同じ)。
- 3 次元(T-0944)の対は 2 × 2 の 4 つ。曲げ(回り 3 成分)の差も同じ芯で延ばす(T-0944 に 1 行)。
