## 目的
表面のセルの粒(支えられた詰まり切らないセル。層の厚さ = 詰まり × 辺)を、陰の圧力の系に「速さの決まった相」(右辺だけ・係数なし)として入れ、
粒が圧力に押される重い相にならず、層の上を空気が流れ、粒の体積はいつも圧力の釣り合いの中で動く形にする。

## 口の確かめ(C-0 / C-1)
- 圧力の系の口(`PressureSolver`: C_i x_i + Σ K (x_i − x_j) = b_i)はそのまま。層の流れは右辺 b(予測の流れ)にだけ入る。21 §2.3 の「物を速さの決まった相に」と同じ形で、
  **C-0 / C-1 の部品に足す口は無かった**(層の厚さは今の状態 = 詰まりから読む。欄は増えない)。だから equilibrium・gas_projection・support_law・GPU 版は流していない。

## 分かったこと
- 表面のセルの粒と空気の強いつなぎ(セル平均の Kozeny–Carman)は、砂を平らにする一方で、表面のセルの空気の揺れを抑える役もしていた。
  つなぎを弱めると(層として数える・孔でもない障害物にする・速さを決める)、空気が暴れる。暴れの元(陰の圧力の解き残り・層のセルの体積の受け渡しの食い違い・
  弱い差の戻りの過減衰が層のセルで足りない、のどれか)は未確認。
- 層の形をどう決めても、空気ありの止まる角度は書いた値に届かなかった(最良 13〜15°)。
