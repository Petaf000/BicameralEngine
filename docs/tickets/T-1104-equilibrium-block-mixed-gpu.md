# T-1104 違うレベルの節が混ざる系を GPU 版でも(T-0969 の続き)

- Status: Done
- 種類: 工学
- PC: 必須
- 見積もり: チャット 1 回分
- マイルストーン: 試作の列 1(C-0)
- 設計: ADR-0462 / 決定: ADR-0422・ADR-0455

## 目的(1〜2 行)
gpu_equilibrium_block に 16 色(色の一覧の置き場を 16 に)と、残した節の単位の延ばし方(9 個目の延ばし方・縮約の置き場)を足し、CPU とビット一致にする。

## 完了条件
- [x] equilibrium_block_test の混ざる箱(k = 1・3)を gpu_equilibrium_block でも毎刻み CPU とビット一致(逆順も)
- [x] 同じレベルの系の今のハッシュが変わらない

## 作業ログ
- 2026-10-26(wt2): 係数のバッファの延ばし方・縮約の置き場を 9 つに(`EQB_PROLONG_SLOTS`。8 つ目の後ろ = 粗くしない節の単位の行列)、段の色の一覧を 16 まで(`EQB_MAX_COLORS`)。
  シェーダーの式は変えていない(残した節は子 1 つの親として今の Galerkin・縮約・延ばし方で通る)。混ざる系を断る所を外した。
- 試験(gpu_equilibrium_block_test・RTX 3070 Ti): 違うレベルの箱 k = 1・3 × {V 2 回・V 4 回 + 共役勾配・V 2 回 + 刻みをまたぐ共役勾配(D-649)} × {順のまま・節と面を逆}を 12 刻み、
  支えの違う大きさのセルの場面 5 本(張り出しの根・片持ち梁の根の半分・上の段・両端固定の真ん中・洞窟の天井。支えの既定 = 刻みをまたぐ向きと残差も GPU)を 30 刻み、
  全部毎刻み CPU とビット一致(GPU の逆順も)。同じレベルの 18 本のハッシュは前と同じ。場面は tests/equilibrium_block_scenes.h・support_scenes.h の Marked に共有。
- **見つけた不具合(直した)**: 支えの法則の混ざる場面(T-1120)が細かいセルをレベル 0・粗いセルをレベル 1 にしていた(EquilibriumNode は「細かいほど大きい」)。
  段の作りが粗いセルを先にまとめて細かいセルの座標と重なり、粗い段で同じ色の節が隣り合った(CPU の 1 本の回しでは解けるが GPU の並びと答えが分かれた。
  BuildEquilibriumBlockGrid の FX_ASSERT は debug だけなので release の作業ツリーでは出なかった)。細かいセルをレベル 1 に直した = 混ざる場面の刻みごとの値が変わる
  (support_law・support_mixed・support_fracture・support_fracture_window は合格。ADR-0470 の精度の表は直す前の値)。試験は比べる前に「同じ色の隣が無い」を確かめる。
