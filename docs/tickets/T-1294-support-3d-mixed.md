## 目的(1〜2 行)
3 次元の格子の梁(sim/support_law_3d)に違う大きさのセル(印のセルを一辺 ÷ 2 の 2 × 2 × 2 に分ける)を入れる。粗いセルの面に並ぶ細かいセルは 4 つなので、対は面ごとに 4 組。

## 完了条件(チェックできる形で)
- [ ] 違う大きさの面(面の点のばね・ADR-0485 の対のずれ・ADR-0501 の対の曲げの差〔回り 3 成分の差〕)を対 4 組で(ROADMAP の T-0960 の行「3 次元の対は曲げの差も同じ芯で」)
- [ ] 段の角の斜めの棒(ADR-0504 の ① の硬さ)を 3 次元の段に
- [ ] 形 A(NeighborStrain。ADR-0509)の項を対 4 組それぞれに(T-1279 §2 の読み方。C の面の中の 2 つの向きの隣から読む繊維の歪み・ねじれ ω_n r_q を含む)。
      選べる形(2 次元と同じ SupportOptions::mixedPairMaterial。**既定は None のまま**・Q182 の答えで support_law.h の 1 行を変えれば 3 次元も付いてくる)
- [ ] 一様な歪み 6・回り 3・一様な曲げ・ねじれで違う大きさの面の項が 0(つぎはぎの検査。None と形 A の両方)
- [ ] 奥行 1 セルの 2 次元の混ざる場面(support_mixed_test)の奥行を 2 セルにした場面が 2 次元と同じ答え(丸めの内)
- [ ] CPU と GPU のビット一致(None と形 A の両方)・帳簿・決定性
- [ ] 3 次元の根の角・洞窟の天井・自重の塊での縁の力とつぎはぎの検査(T-1279 §2 の未確認)

## メモ・参考
- 共通部品の面の約束(隣のレベルの差 1・混ざる段は 16 色)の中に入る見込み(T-1279 §2)。足りなければ印を付けて司令塔へ(土台の共通部分は足さない)。
