## 目的(1〜2 行)
参照の温度の形(2 側)の負の側は、参照より冷たい物が無い刻みにも固定の費用(1 側 約 167 µs。持ち越しの密な表を掃く CarryIn・Hash が 95 µs)を払っていた。
空の刻みはその側の段(Sources・CarryIn・歩き・袋を空にする・ハッシュ)を GPU が自分で飛ばす。CPU に読み戻して決めない。結果は流した時とビット単位で同じ。

## 完了条件

- [x] 飛ばしても刻みごとの世界のハッシュが飛ばさない時と全部同じ(ずっと空・時々要る・ずっと要るの 3 場面)・CPU リファレンスとのビット一致の試験が通る
- [x] 飛ばした刻みの持ち越しの表の偶奇で古い値が残らない(下の「正しさ」)
- [x] gpu_radiation_cost の 7 場面の前後の µs(下の表・docs/perf.md)

## 飛ばす形
1. **放つセルの印**: RadiationGrid(セル → 両側の作業の写し)が、負の側の RcSources と同じ式(RcCellEmissionRelative。温度 0 は放たない)で
   負の側に放つセルがあれば、負の側の作業の頭の終わりの語(RC_GPU_WORK_EMITTERS = 248 バイト目。RcGpuParams の 256 バイトの余り)へ印(波に 1 回)。
   面の向こうの飽和(RcMaskAcross)は見ない(多めに流すだけで、結果は変わらない)。
2. **流すかの印**: 負の側の刻みの初めに RcPlanTick(1 スレッド)が
   「放つセルの印が 0・入る持ち越しの表の 0 でない鍵の数(RC_GPU_CARRY_COUNT + 入る表)が 0・前に流した刻みの帳簿の 放った・持ち越しを放った・そのまま送った が 0」
   なら流さない(頭の RC_GPU_RUN = 0。飛ばした数 RC_GPU_SKIPPED を足す)、でなければ 1。印は作業の印を 0 に戻す。
3. **起動の予告**: RC_GPU_RUN を予告のバッファ(GpuCascadeLight::m_predicate。uint64 1 語)へ写し、`SetPredication(EQUAL_ZERO)` の間に負の側の
   RecordTick(11 起動)を記録する。ハッシュの単位の負の側の RadiationHash も同じ予告で囲む(同じ刻みの印)。
   予告のバッファは COMMON に置き、使う間だけ写し先 / 予告にして COMMON に戻す(リストの境で COMMON に戻るバッファの約束と同じなので、状態を追わない)。
4. ProbeSimOptions::radiationSkipIdle(既定 true)。切るのは比べる試験だけ。ProbeFrameReadback::radiationSkippedTicks(作ってからの飛ばした刻み)。

## 正しさ(飛ばしても結果が同じ。偶奇の扱い)
- 飛ばす条件の時に流した刻みの結果は「放った・吸ったの欄が 0・出る持ち越しの表が 0・帳簿が 0」:
  前に流した刻みが何も放たず受けなかったなら、その刻みの Sources が全部のセルの欄を 0 にし、歩く光線が無いので吸ったも 0・表へ足す物も無い。
  入る表は鍵の数が 0 なので空。今の置き場はもうその値なので、流しても変わらない。
- 持ち越しの表の偶奇: 刻み t は表 t & 1 を読み 1 − (t & 1) へ書く。飛ばす間は両方の表が 0 のまま
  (入る表は空・出る表は前に流した刻みの CarryIn が読んで 0 に戻した)。鍵の数の語は飛ばす間に前の値が残ることがあるが、
  鍵の数は「表の 0 でない鍵の数」より多くにしかずれない(0 から増えた鍵だけを数え、0 に戻すのは CarryIn だけ)ので、多めに流すだけ。
  数が 0 なら表は必ず空。
- 頭の語(帳簿・光線の本数・放つ面の数)は前に流した刻みの値(どれも 0)が残る。読み戻し(ReadRadiationHeader)と Read の値は流した時と同じ。
- 当てる段(RadiationApply)は負の側の放った・吸ったの欄(0)を読むので、正 − 負は流した時と同じ。
- 印は刻みの初めの写しの段で毎刻み作り直す(保存点・写しの後も、その刻みの状態の頭から決まる)。

## 分けたもの・残り
- 空の段の LevelWalk(袋 0 の段の起動 4 回 15 µs/側)を間接の起動にするのは入れていない(T-1161 の分けたものの注記。正の側にも効く。小さいので後回し)。
- 正の側も同じ形で飛ばせる(参照より暖かい物が無い刻み)が、今の既定の世界では正の側が空の刻みはほぼ無いので入れていない。
- Grid の +23 µs(288.15 K)を減らすなら、負の側の放つセルの一覧を T-1228(変わったブロックの印)で直す形に乗せる。
