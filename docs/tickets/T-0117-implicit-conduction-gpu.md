# T-0117 細かいレベルの熱の陰解法(方式②)を GPU に

- Status: Todo
- 種類: 工学(形は T-0110・ADR-0019 で決まっている)
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: M2 の並走(D-432)
- 設計: docs/design/17-multiresolution.md §4・§6「結果(T-0110)」 / 決定: D-428・D-432 / ADR-0017・ADR-0019・ADR-0011(予算)

## 目的(1〜2 行)
T-0110 の CPU 試作(engine/src/sim/implicit_conduction.*)を GPU に載せ、毎刻み CPU とビット一致させる。費用を測って、方式①との組み合わせと V サイクルの上限を決める。

## 完了条件(チェックできる形で)
- [ ] 赤黒の掃き出し・縮約・直しの足し込み・面の流れ・安全網を HLSL(shaders/common に式、CPU と共通)に。V サイクルの段ごとに Dispatch(か Work Graphs)
- [ ] 「止めるか」の判定(|残差| × D/C ≤ 1 mK の全部のセルの論理積)を GPU で: 間接の起動か Work Graphs で、要らない回は空で抜ける
- [ ] HW・WARP で物差しと熱い点の場面が毎刻み CPU とビット一致(回数も一致)・2 回の実行で一致
- [ ] 計測(docs/perf.md): V サイクル 1 回・空の Dispatch・安全網 1 回の GPU 時間。予算(ADR-0011)と比べて、①との組み合わせ(T-0110 の a / b)と上限の回数を決め ADR-0019 に追記
- [ ] 予算を超える場合は、T-0110 の「判断待ちの見込み」を遊びへの影響の形でユーザーに聞く

## メモ・参考
- 費用の目安(CPU の数え方): なめらかな場で 1 刻みに 1 セルを 5〜43 回(Δk 0〜6)・直列 12〜357 段。熱い点(差 6)で V 12〜13 回。
