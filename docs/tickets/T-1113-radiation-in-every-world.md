## 目的(1〜2 行)
同じ宇宙に一つの法則(D-465)。今は熱の放射の段が仮の世界の CPU で「入れた時だけ」動き(EnableRadiation。T-0585)、仮の世界の既定・GPU(T-0586 は止めた)・多重解像度の世界には無い。
現実の伝導率(T-1066)では放射の無い世界で火が広がらないので、放射の段を全部の世界で既定にする。T-0586(GPU の放射)と wt6 の T-0973 をこのチケットにまとめる。

## 完了条件
- [ ] 放射の段が仮の世界の既定で動く(書いた物質だけが吸う・出す。ブランクの世界では何もしない)
- [ ] 多重解像度の世界(実験の箱・世界の刻み)で動く。光の RC(cascade_light。D-646)と同じ置き場・組を使うかを先に決める
- [ ] GPU 版と CPU リファレンスのビット一致
- [ ] T-1066 で止めた試験を戻す: reaction_package_scene・lab_box(火)・gpu_probe_fire(tests/CMakeLists.txt の DISABLED)
- [ ] 費用(RTX 3070 Ti。D-634)

## メモ
- 放射の吸い込みは標準の物質に書いた(T-1066。セルロース 1100 万・炭 4000 万 mm²/mol = 長い帯の光と同じ値)。【エンジン】放射の段が書いていない時に長い帯の光の値を読む形にすれば値を 2 か所に書かない(ベイクの警告は既にその形の文を持つ)。
- 草原の延焼(仮の世界の CPU・放射あり): 手前 14 s・2 m の川を 18 s で越える(T-1066)。
