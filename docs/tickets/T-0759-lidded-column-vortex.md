# T-0759 固体の蓋の下に閉じ込められた水の柱に、定常の渦が残る(液体・不具合の疑い)

- Status: Todo

- PC: 必須
- 見積もり: チャット 1 回分
- マイルストーン: ③' 運ぶ計算の共通の土台(T-0757 から分けた)
- 設計: docs/design/07-transport.md §3.1 / 決定: ADR-0266・ADR-0327

## 目的(1〜2 行)
水の中に沈んだ石(固体のセル)の真下の柱で、面の運動量が一定のまま回り続ける(静かな水が眠らない)。根っこを突き止めて liquid_flow.hlsli で直す。

## 完了条件(チェックできる形で)
- [ ] 再現: 16 × 6 × 16・水 3 層(6900 mol)・水面のセル(真ん中の y = 3)を石にして押しのけた水を上へ。石の真下の柱(y = 1〜2)で
      下向きの縦の面の運動量 9.5 × 10^8 が 60 秒一定・速さの上限に毎刻み当たる・横に外へ(y = 1)・内へ(y = 2)回る(T-0757 の写しで確かめた。
      T-0757 の直しの前からある)
- [ ] 根っこを直し、渦が摩擦で静まる。保存はビット単位・CPU と GPU(HW・WARP)の一致・probe_liquid・rest_return が通る

## メモ・参考
- 見立て(未確認): 固体のセルは「支えている上の液体」を 0 にする(LqColumnPressure)ので、蓋の下の柱は上の水の重さを受けず、溢れの倍率(16)で
  縮んだ水の圧力で隣の柱と釣り合う。縮み(密度)と圧力の向きが揃わない所では、回る道の圧力の仕事(面の質量で割った圧力の差の和)が 0 にならない
  (バロクリニックの渦)。摩擦で失う分を毎刻み圧力が補い、運動のエネルギーは一定(熱も一定 = 帳簿では仕事が見えない)。
- 直しの候補: ① 蓋の下へ上の水の圧力を伝える(固体を越えて「支え」を渡す。閉じた洞窟は今は溢れで圧力を伝える)② 縦の面も
  位置のエネルギーの勾配の形に揃える(ADR-0327 の横の面と同じ考え)③ 溢れの倍率を上げる(縮みを小さく。根っこではない)。
- T-0757 の写し(probe_liquid の Step を 1 物質に縮め liquid_flow.hlsli を呼ぶ C++。`MODE=stone Y=6 ./pond 16 16 3600 3`)が速く回せる(数秒)。
