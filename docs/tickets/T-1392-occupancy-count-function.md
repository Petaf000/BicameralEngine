## 目的(1〜2 行)
shaders/common/occupancy.hlsli に数える関数(姿勢・物の箱の形・行き先の並び → (箱, 点の数) の並び。重みは呼ぶ側が掛ける)を置く。+側 3 面の面の点は T-1393 へ回した。
点のレベル = max(物, 行き先)+ 2・8 隅が同じ箱なら塊で足す・それ以外は割る。CPU の試験で確かめる(GPU は後)。

## 完了条件(チェックできる形で)
- [x] 塊で足す数え = 全部の点を 1 つずつ数えた数とビット一致(斜め・境をまたぐ物・行き先 3 種〔世界の木の違うレベル・地面の格子・ほかの物の箱〕)
- [x] Σ 点 = 物のボクセルの数 × 点の数(行き先の細かさに依らない)・向きの揃った物で 0 か全部だけ
- [x] 物の順を入れ替えてもビット一致
- [x] 浮動小数点なし(float_check)・release 警告 0(archmap --check は未実行。関数を図に足していない)
