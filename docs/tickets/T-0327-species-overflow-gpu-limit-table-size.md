## 目的
- T-0272 で上限 RX_GPU_WIDE_SPECIES を 64 にした(HW の compute キューの止まりの直し)。まだ固定の大きさの配列(RxGpuWideCell)なので、表の物質が 64 を超えると
  超える生成物は待たせて MR_COUNTER_LIMIT_PRODUCTS に数える(CPU の上限の無い世界と食い違う。D-448 の仮のふるまい)。
- 大きいセルの道(T-0326 の段)の上限を表の物質の数まで上げる: セルの形を作業場(UAV)に置く・核(reaction.hlsli)をセルの形の道具で読むように替える、など。測ってから選ぶ。
- 見出しの塊の表を面の最初の塊に置けば、見出しの大きさが上限に依らない(今は上限 64 で 192 語 = 768 B/頁)。
