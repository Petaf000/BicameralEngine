# T-0505 前の刻みから選ぶ記録の形で、1 グループの安い回が大きい系で GPU を止める

- Status: Done
- 種類: 工学(不具合)
- PC: 必須
- 見積もり: チャット 0.5〜1 回分
- マイルストーン: D-471 ④ の周り(T-0494 から分けた)
- 設計: docs/design/19 §4・ADR-0019(陰解法)/ 決定: D-465(重くても結果を変えない)・D-468(負荷で遅れるのは不具合)・ADR-0224

## 目的(1〜2 行)
陰解法の記録の形 ShapeFrom(T-0154・T-0179)で、余裕の後の「安い回」を段 0 から 1 グループ(ImTail)で回すため、大きい系で
1 刻みが数百 ms〜2 秒を超え DXGI_ERROR_DEVICE_HUNG になる(T-0494: 64³ で 460 ms・128³ ×10⁶ で TDR)。値を変えずに 1 グループの仕事に上限を付ける。

## 完了条件(チェックできる形で)
- [x] 安い回の 1 グループに入る段の節の数に上限(CHEAP_TAIL_MAX_NODES = 4096)。それを超える先頭の段は段ごとの Dispatch(GpuImplicitRecordShape::cheapLevels)
- [x] 記録の形で値が変わらない: gpu_implicit_box_bench が 3 つの形の最後のセルをビット一致で比べる・gpu_multires_implicit_tree_test に
      「2 回目から安い回・段ごとの段 1 と 2」の形(CheapSplit)を足し、CPU と毎刻みビット一致
- [x] gpu_implicit_box_bench の 16³〜128³ の前後を docs/perf.md に(128³ ×10⁶ の「前の刻みから」が GPU を止めない)
- [x] 既存の陰解法の試験(gpu_multires_implicit*・gpu_multires_conduction・gpu_lab_box)が通る

## 直し方(決めたこと。ADR-0224)
- **根っこ**: 「1 グループで回す仕事の大きさを、記録の形が抑えていない」。ImTail は 1 グループで段の間の同期をとって V サイクルを回すので、
  仕事は節の数に比例し、GPU の並びを使えない(64³ で節あたり約 33 ns/V)。
- **一つの芯**: 安い回の ImTail は「節が上限以下の段」だけを受け持ち、上の大きい段は普段の V サイクルと同じ段ごとの Dispatch
  (同じ間接の引数)で回す。ImTail の始まりは min(下りが止まる段, cheapLevels)(シェーダーの定数 g_wholeTail → g_cheapTail)。
  cheapLevels = 0 が前の形(段 0 から全部 1 グループ)。ShapeFrom が前の刻みの段ごとの節の数(GpuImplicitCost::levelNodes。計画の見出しから読む)で選ぶ。
  順は RecordVCycle と同じなので値は同じ(CPU とビット一致のまま)。
- **上限 4096 の理由**: 安い回を上限 64 回全部 1 グループで回しても 1 刻み約 10 ms(4096 × 33 ns × 64)で止まる。
  代わりに 32³(3.3 万節)の箱は段 0 が段ごとになり、止めた後の回のバリアが増えて 0.5〜0.7 ms/刻み重くなった(下の表)。
  上限を 32768 にすると 32³ は前と同じになるが、最悪は約 70 ms/刻み。仮で 4096(遅れの最悪を小さくする方。D-468)。
- **回数の上限**: 加えない(V の上限 options.cycles のまま)。安い回の 1 グループの仕事は節で抑えたので、回数で切る必要がない。
  回数で切ると値が変わる(D-465)。

## 残り・分けたもの
- **系が 1 刻みで急に大きくなった刻み**(前の刻みが小さく、今の刻みが大きい): 形は前の刻みの数で選ぶので、その刻みだけ大きい段が
  1 グループに入りうる(値は同じ・遅い。最悪は TDR)。同じことは段の数を切る dispatchLevels(前の刻みの下りが止まった段まで積む)と、
  多重格子の段を作る LvTail の回の数(GpuImplicitLevels::RoundsFrom)にもある。伝導の段(GpuMultiresImplicit)は系を GPU で作るので
  CPU は記録の時に大きさを知らない。直すなら「GPU が大きさを見て段ごとの Dispatch か 1 グループかを選ぶ」形(Work Graphs か、
  両方を積んで間接の引数で片方を 0 にする。バリアは両方残る)→ 司令塔に。今は D-468 で予算を超える大きさ(最速の伝わりで数万節超)は
  ゲームの側の予算の違反として警告される前提で、エンジンは止まらないことだけを守る(この刻みは遅いが値は同じ)。
- **T-0504(×10⁶ の V が上限 64 まで回る)**: この直しでは変わらない(V の回数・温度の幅は 3 つの形で同じ)。64³ ×10⁶ の V 58・43 の刻みは
  前の形で 474・355 ms → 直した形で 72・54 ms(既定の形 81・56 ms と同じ桁)。V を減らすのは T-0504。
