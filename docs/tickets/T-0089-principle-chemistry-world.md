## 目的
仮の世界(64³)のセルを「成分 + エネルギー」にし、伝導を温度の差で行い、反応を Work Graphs の段として走らせる。
窓でクリックして着火すると、木箱が燃えて炭と煙と熱になり、熱が伝わって燃え広がる(M1 の完了の姿の化学の部分)。

## 完了条件(2026-10-01 に詰めた)
- [x] セル = 成分(T-0014 の RxCell)+ エネルギー、2 世代。場面は 64³(32 m 角)を空気(N2・O2、300 K)で満たし、中央に木箱
      (壁の厚さ 1 セル・中は空気。木のセルはセルロース + 孔の中の空気)
- [x] 伝導は温度の差で熱を受け渡す: 面の流れ = min(両側のコンダクタンス) × ΔT × Δt、大きさは min(両側の熱容量) × ΔT の 1/8 まで
      (両側が同じ大きさで逆向きを計算するので、エネルギーは構造的に保存)
- [x] 伝導率は物質の値(W/(m·K))。**試験の表の値は「リアルっぽいが、反応が遅すぎない」ように大きくする**(ユーザー 2026-10-01)。
      現実の値だと木の中を 0.5 m 伝わるのに数日かかる。現実の火は放射と対流で広がる(M3)ので、M3 で見直す
- [x] **遅すぎる反応は 0**(ユーザー 2026-10-01): 1 刻みの進みの期待値が 2^-16 µmol 未満の規則は、どこでも進まない法則にする。
      これで「何も変わらず、どの規則も進めない」ブロックは正確に眠れ、全部のセルを計算する CPU リファレンスとビット一致を保てる
- [x] 伝導と反応を 1 つの Work Graphs のノード(1 ブロック = 1 グループ)で: 熱を受け渡してから、その場で反応。
      WARP はこのグラフを作れない(ADR-0013。ユーザー判断で WARP のテストを外した)
      次の刻みに起きるのは、値が変わったブロック(と 6 面の隣)と、まだ進める規則があるブロック
- [x] クリック = そのセルを 2700 K 温める熱の湧き出し(明示的な出入りとして刻みごとに数える。D-206)。木箱が燃え広がる。
      (900 K では燃えた 1 セルの熱が隣を点ける前に薄まって消えた。1 回のクリックで壁の 9 割が 49 秒で炭になる)
      デバッグ表示で温度・O2・CO2・炭をキーで切り替えて色分け
- [x] CPU リファレンスとビット一致(短い刻み数)・2 回の実行でハッシュ一致・
      燃焼の場面を 10 分(36,000 刻み)走らせて、元素ごとの数とエネルギーの合計が(湧き出しを除いて)一致(GPU で刻みごとに合計)
- [x] 費用を docs/perf.md に(伝導 + 反応の段の ms/刻み、燃えている時と静かな時)

## メモ・参考
- 気体の流れ(煙が昇る・酸素が入ってくる)は M3。閉じたセルでは O2 を使い切ると燃焼が止まる(熱分解は続く)。
- 1 つのセルの成分が 8 を超えたらどうするか(T-0017 / R-MULTI-4)。
