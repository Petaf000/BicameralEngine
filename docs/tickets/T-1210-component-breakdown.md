## 目的(1〜2 行)
砂と灰が混ざったセルで、積もった層と舞う粒の物質の割合を別々に持つ(舞いやすい粉だけが舞う。#37・#38)。物質は 1 つのまま・作り手の書く値は増えない。

## 完了条件(ADR-0481 の 5 の形)
- [ ] セルの頁に並ぶ「成分の内訳の頁」(粒のある頁だけ・疎)。物質で結ぶ(成分の並びの位置ではない)
- [ ] セルを書く全部の道(CPU の StorePageCell・反応・運ぶ・相変化・溢れの領域・GPU のセルを書くカーネル)で `層 = min(前の層, 新しい量)`・増えた分は残りへ
- [ ] 細かくする(成分ごとに T-1177 の配り)・粗くする(成分ごとの和 ÷ 8 の切り捨て)・眠る(残りのある頁は畳まない)
- [ ] 0 ≤ 層 ≤ 量 の検査・ハッシュと保存点に入る・保存の列は物質ごとの量のまま
- [ ] 層の無い世界はビット単位で今と同じ(multires_sparse の要約の束・GPU とのビット一致)
- [ ] 費用を測る(粒のある頁の 1 セルのバイト・書く道の時間。perf.md)

## 1 段目の形(T-1210 で入れたもの)
- 置き場: `MultiresCellPage::layers`(`[セル × 頁の幅]` の µmol。並びは species・amounts と同じ位置)。層を一度も書いていない頁は空(何も持たない)。
  眠る判定の前(NarrowPageCells)で全部 0 なら返す。読む値は `LoadNestCellLayers`(`MrCellLayers`。RxCell の species と同じ位置)。
- 規則(ADR-0481 の 5 の 2): 成分の量だけを書く道(`StorePageCell`。反応・運ぶ・相変化・伝導・GPU から読んだ列・液体の 1 段などの CPU の道は全部ここを通る)は、
  書く前の成分と**物質で結んで** `層 = min(前の層, 新しい量)`。前に無かった物質・無くなった物質の層は 0。層を書くのは `StoreNestCellWithLayers` だけ(層を動かす法則用。まだ使う法則は無い)。
- 層の無い世界: 層の並びを持たないので書く道は前と同じ(枝 1 つ)。要約は 0 でない層だけを足すので、層の無い世界の要約はビット単位で今と同じ。
- 1 段目の限り(T-1220 で直す): 一様の枠の層は 0・細かくする / 粗くすると層は 0(全部が残り。量は保存)・層のある頁は畳まない(FoldExact・FoldNear)・
  溢れを使う世界では層を書けない(FX_ASSERT)・GPU は層を知らない(GPU から読んだ列は付け替えで 層 ≤ 量 だけ保つ。T-1221)。

## 費用(1 段目。CPU。docs/perf.md 用。測った値は作業ログ)
- 層のある頁: 1 セル 8 × 頁の幅 B 増える(幅 2 で 33 → 49 B。ADR-0481 の 5 の見込みと同じ)。層の無い頁は 0 B。保存点(写し)も同じだけ増える。

## 土台に足りないもの(司令塔へ。仮で進めた)
1. **一様の枠の層の持ち方**: ADR-0481 の 5 の 1 は「一様の値の枠は層 = 0 か全部が層の 2 つだけ」。ところが一様の砂の床にも隙間の空気(層を持たない成分)が混ざると
   「全部が層」で表せない。おすすめ(仮・T-1220): 一様の枠は成分ごとの層(`MrCellLayers` 1 つ。層のある枠だけ・疎)を持つ(2 つの値はその特別な場合)。作り手から見た違いは無い(畳めるかだけ)。
2. **眠る判定の「残り」**: ADR-0481 の 3 は「残りのある頁は畳まない」。成分の層では、気体の成分(層にならない)の残りまで数えると空気のある頁が眠れない。
   「残り」を数えるのは粒の物質(相の印 RX_SPECIES_GRAIN)だけにするのがおすすめ(仮・T-1220)。1 段目は「層のある頁は畳まない」で、どちらにも寄せていない。
3. **GPU の付け替えの粒度**: CPU は 1 回書くごとに付け替える。GPU は 50 か所ほどが g_cells を直接書く(エネルギーだけの書き込みが多い)。
   おすすめ(仮・T-1221): 成分の量を変える段の後に「層を合わせる」段を 1 つ置く(層の頁に物質も持たせ、層 = min(層, 今の量))。CPU の 1 段の中で 1 セルを 2 回書く道(減って増える)があると
   GPU と結果が分かれるので、T-1221 でその道を数え、あれば CPU も段の境で合わせる形に寄せる。
