## 目的(1〜2 行)
ゲームが登録した遊びの指標(「密室の火が何分で消えるか」など)を、表を変えるたびに写しの早送り(sim::WorldCopy)で測り、前の版との差を
エディタのパネルとコマンドラインで出す。決定性があるので毎回同じに測れる。

- [x] 測る所: sim::PlayMetricMeasurer(GPU。元の世界 S(0) + 写し)・sim::MeasurePlayMetricReference(CPU)・同じ判定(PlayMetricObserver)

## 判断待ち(仮で進めた。ユーザー未確認。詳しくは ADR-0206「判断待ち」)
作り手(エンジンを使う人)から見た違い:
- A. **指標の書き方**: 仮 = パッケージの分類 play_metrics(Luau。反応表と同じ書き方・型検査・Mod で足せる。指標だけ直しても表の版が変わり、
  記録に表の差し替えが残る〔世界は変わらない〕)。代案 = エディタの設定に保存(版は変わらないが書き方が別・Mod で足せない)。おすすめ: 仮のまま。
- B. **いつ測るか**: 仮 = 表を変えたら自動(パネルのチェック「表を変えたら測る」既定 入)+ ボタン「今の表で測る」。代案 = ボタンだけ
  (重い指標を何個も登録しても普段の操作を邪魔しないが、測り忘れる)。チェックを切れば代案になる。おすすめ: 仮のまま。
- C. **前の版をどこに残すか**: 仮 = エディタはその起動の中で前に測った版(メモリだけ。起動の初めの測りが基準)・コマンドラインは指定のファイル
  (--metrics-baseline。--metrics-save で書き直す。ゲームのリポジトリに入れれば版の歴史と一緒に残る)。代案 = パッケージのフォルダの横に自動で
  置く(起動をまたいで差が見える。ファイルが勝手に増える)/ 版ごとに全部残す(どの版とも比べられる。置き場が育つ)。おすすめ: 仮で始め、
  要ればエディタにもファイルの設定を足す。
- D.(エンジンの作りの細部。Claude が決めた)場面 = 表の世界の組み立ての初めの世界(今の世界ではない。前の版と同じ場面で比べるため)。
  判定はつつきを全部当てた後の測る刻みだけ。測る世界の物理の場面は本物と同じ形(--no-physics なら無し)。測り終えたら写しを捨てる。

## メモ・参考
- WorldCopy の API は変えていない(wt2 T-0413「wt3 との分担」: WorldCopyResult に欄を足すのは wt2。こちらは使っていない)。
- 測る VRAM は世界 2 つ分(元の世界 + 写し。サンプルで 77 MiB × 2)。エディタでは「写しの早送り」の写しと別(測り終えたら返す)。
- サンプルの指標の道のり(2026-10-14・RTX 3070 Ti・--no-physics・試験の表): 箱の壁の火で O2 は約 3600 刻み(1 分)で減らなくなる /
  1000 K 以上のセルは 4200 刻みで最大 787、16800 刻み(4.7 分)で 0 / 600 K 以上は 36000 刻み(10 分)でも 1040 セル残る(冷めにくい)。
  なので「火が消えた」の目安は 1000 K にした。36000 刻みの早送りは約 30 秒(物理あり 120 秒)。
