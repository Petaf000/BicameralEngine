# T-0324 魔法のパッチの範囲を細かくする要求(T-0287 から分けた)

- Status: Todo(T-0287 の後)
- 種類: 工学
- PC: 必須
- 設計: docs/design/02-reaction-system.md §5・§5.1 / ADR-0095。関係: T-0024・T-0287

## やること
パッチの範囲がセルより小さい時(遠くの粗いセルで小さい魔法)、範囲を細かくする要求を出して細かいセルにだけ効かせる。今は粗いセルが範囲に少しでも重なれば丸ごと効く。

## 注意
- QUESTIONS Q37 のおすすめ(ユーザー未確認)。遊びへの影響: 細かくすると魔法の効く範囲が見た目どおりになるが、遠くの魔法ほど細かくする費用がかかる。
- 公開リポジトリなので、魔法・魔素の設定や値はゲームの中身として書かない(D-006)。シミュのコードに浮動小数点を書かない。
- ルートの SRV / UAV に GetDimensions を使わない(大きさは定数で渡す。T-0024)。
