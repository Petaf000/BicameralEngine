## 調べたこと(2026-10-17。probe_gas_test の 2「燃える木箱 2 秒・陽解法」と 8 の露の場面。CPU・release)
- 元(T-0646 の換算。下の測り直しと同じ): 燃える木箱 9 セル・最も負 −628 kJ、露 10 /s の木箱 2・−158 MJ、露 100 /s の木箱 3・−11 MJ、湯気の塊 0。
- **案 A(チケットの見立て)**: 出ていく割合の合計 ≤ H ÷ (H + W)(H = 力積の後の熱〔MovedEnergy の sourceHeat と同じ式〕、
  W = n R T₀)、H ≤ 0 なら出さない → 燃える木箱 **14**・−11.9 MJ、露 10・100 /s の木箱 **18・18**(−11.8 MJ)。湯気の塊は 0。どの場面も数が増えた。
- **案 B**: 案 A で H ≤ 0 の時だけ T-0646 の換算に戻す → 燃える木箱 5 セル・最も負 **−81 MJ**(熱の重心 11387・CO2 の重心 10571。露の場面は測っていない)。
  どちらの案でも 0 にならず、最も負の値は元と同じく数 MJ〜百 MJ の桁(元でも露の木箱で −158 MJ)。
- 負になったセル(案 B に診断を足して記録): 木箱の真上の柱(x31〜32・y0〜7・z27〜34)、物質 1〜5.6 mol、熱 −2.5〜−81 MJ、
  運動量が大きい(上の軸で −1.2e14 など)。空気 5 mol を 1000 K にする熱(約 100 kJ)の 25〜800 倍で、「少し出しすぎ」ではない
  (元の換算でも露の木箱で −158 MJ。出ていく量の上限の問題ではない)。
- 読み: この刻み方では、力積が足す運動のエネルギーはセル自身の熱から払い、同じ小刻みで流れ込む塊の押し出す仕事で返ってくる
  (なめらかな流れでは釣り合う)。力積の後の熱で出ていく量を抑えると、返ってくる前の値で出口を塞ぐことになり、運動量がセルに
  溜まって次の力積でさらに運動のエネルギーが増える(暴走)。**負の熱の元は出ていく量ではなく、力積が熱より大きな運動のエネルギーを
  足すこと**(実効の音速の頭打ちが軽い・熱い気体で足りない〔T-0658〕か、木箱の近くの空きの小さいセルの圧力〔÷ 空き。T-0593〕が
  力積に効いている、が候補。未確認)→ T-0676。
- なので出ていく割合の上限は T-0646 の換算(C + n R)÷ C のまま(小刻みの初めの物質で決まる)。木も同じ換算にした。
