## 目的(1〜2 行)
中身(反応表・魔素の値)を触って決めるために、実験室の箱の値(セルの中身・温度・反応の速さ)を時間のグラフで見て、
同じ保存点から条件を 1 つ変えた 2 つの実験を並べて比べられるようにする。

## 完了条件(チェックできる形で)
- [x] 計器(sim/lab_gauge): 1 刻みに 1 つ、見るセルの温度と物質量・箱全体の物質量と最高温度。反応の速さは物質量の刻みごとの差(µmol/刻み)。整数だけ
- [x] LabSession が刻むたびに読み戻した GPU の箱から計器の値を取る(世界に何も返さない。ADR-0035 の「見るだけ」)。上限 20000 刻み
- [x] 保存点 = 実験の記録を刻み t で切ったもの(CutLabRecording)。A = 元の実験の続き・B = A に条件を 1 つ足す(MakeLabComparisonPlan)
- [x] RunLabComparison: 同じ箱で A → B を初めの箱から流し直す(保存点までのハッシュを元の実験と突き合わせ・GPU と CPU を毎刻み比べる)
- [x] パネル「計器と比べる」(editor/gauge_panel): 見るセル・量(温度・最高温度・物質量・速さ。セル / 箱)・物質を選んで直近の刻みのグラフ、
      保存点の刻み・流す刻みの数・B に足す条件(「実験室」で組んでいる置く / 温度だけ)→ 並べて流す → 2 本を重ねて描く(保存点に縦の線・指すと値)・元の実験に戻す
- [x] editor_overlay.cpp の変更は数行(作る・Build)
- [x] lab_box: 置いた量・最高温度・速さの和 = 量の差・保存点で切る・A は元の実験と同じ・B は保存点の刻みから違う・表を替えた記録は CPU の計器で流さない
- [x] window_lab_compare(`--editor --auto-lab-compare`): グラフの値(GPU)が CPU リファレンスだけで流した値と全刻み一致・保存点 20 から A は元の実験と同じ・
      B(隣に冷たい木を足す)は刻み 20 から違い、B の値も CPU と一致

## メモ・参考
- 箱は 1 つだけで A と B を順に流す(GpuMultires の作成が debug で数十秒〜数分かかるので 2 つ目の箱を作らない)。「並べる」は同じ刻みの値を重ねて描くこと。
- 保存点は ProbeSim の保存点(ADR-0036。VRAM の写し)ではなく記録の切り口(箱は 512 セルで、刻み t まで流し直すのは軽い。ADR-0037 の記録と再生の道をそのまま使う)。
- 比べた後の箱は B の状態。比べる前の実験は「元の実験に戻す」で流し直せる。
- 流している間はフレームが止まる(刻みごとに GPU を待つ。数百刻みなら数秒。debug ではもっと)。
