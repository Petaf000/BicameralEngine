分かったこと:
- **夜**: 歩の終わりの差は 0.3〜1.0 K → 11〜13 mK(T-1269)だが、**写しの刻み(16384 刻みごと)の差は 5〜6 mK → 11 mK に増える**(どちらも予算 0.1 K の内)。
  今の既定は写しの刻みにたまたま終わる歩だけが良く見えていた。(c) は歩の終わりがどこでも同じ桁(11 mK = 解けきらなさの床。T-1269 の Gap0 と同じ)。
  解きは 0.46〜0.73 倍・出来事 51(木によらない)・打ち切り 0(長い単位どうしの打ち切りの連なりが無くなった)。
- **火事**: 温度・前線・燃えた量は今と同じ値(差の最大も同じ)。解き × 1.0001〜1.0011。
- **試験の期待**: どの試験も要約の固定値を持たない(1 刻みずつ・一気に・2 回・セーブの比べだけ)ので、既定を (c) にしても**書き直す期待は無い**。
  変わるのは記録の値だけ: forward の 1 通り目の要約・night の差と解き・choose-dump の要約と「隣の差で縮んだ」・gpu_time_step_choose が読むファイル(表が 1 本増える)。
  直す所は `TimeTreeSetup::border` の既定 1 行と、試験の `border=` の既定(none → c0)・perf.md の値。
