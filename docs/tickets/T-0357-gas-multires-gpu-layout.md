## 目的
T-0209 は面の一覧(`ListGasTreeFaces`)とセルごとの面の並びを、木を作った時に CPU が一度だけ作って写す(木は作った後に変えない前提)。
本物の世界(05 のセル・細かくする・粗くする)では木が変わるので、面の一覧と並びを GPU で作り直す(Model は GPU。D-107)。d ≥ 2 の面(T-0321 で決める読み方)も GPU に。

- [ ] d ≥ 2 の面(T-0321 の後)を GPU でも CPU とビット一致
