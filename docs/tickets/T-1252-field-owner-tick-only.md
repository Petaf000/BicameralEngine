## 目的(1〜2 行)
登録の 1 行に配り手(SF_SCALE_OWNER + 配り手の番号)と寿命(SF_FLAG_TICK_ONLY)を足し、散らばった書き手が欄へ書く共通の「集めて書く段」と、粗くする時のセルの配りの口を CPU で作る。
段 1 は CPU・段 2 は GPU。使い手(Ec = T-1230・放射の持ち越し = T-1227・源の項 = T-1228)はまだ載せない(配り手の表は空 + 試験用の配り手 1 つ)。
