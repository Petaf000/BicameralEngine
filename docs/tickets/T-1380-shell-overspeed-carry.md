## 目的(1〜2 行)
層の流れで射影の答えが速さの上限(1 小刻みに 1 ボクセル = 1.875 m/s)を超えた時、運ぶ量は上限で止まり、越えた慣性は運動量のまま次の小刻みへ持ち越す(今。ADR-0534)。
この持ち越しが (1) 上限の値で答えを変えるか(D-428)(2) 保存を破るか (3) 費用 を測り、直す価値があれば形を比べる。

## 判定
1. **D-428(上限の値で答えが変わるか)**: 上限 0.5〜2・持ち越しの形 A / B・① の中心の止め 0.5〜1 を変えて、閉じた 1 セル 8.88〜9.28(0〜−4.3 %)・世界の流れ 7.99〜8.27(0〜−3.4 %)。
   上限を越える面は 1 回の燃えで 100 前後(面 × 小刻みの 0.0001 %)しかない。A と B は越えた面 84〜104 か所だけの違いで −0.9 / −1.8 % 動くので、この場面の「どんな小さな違いでも出る揺れ」は 2 % 前後。
   上限の向きにも揃わない(B: 0.5 → 1 → 2 で 9.09 → 9.20 → 9.14)。→ **上限の値と持ち越しの形への依りは揺れの幅と同じ桁で、直す価値は無い**(今のまま。既定は変えない)。
   A と B の違いが小さい理由: 射影は膨らみ(発散)の分を毎小刻み解き直すので、上限で止めて捨てた運動量のうち発散の分は次の小刻みに圧力が戻す。違いが残るのは渦の分だけ。
2. **保存**: 26 本すべて 0(運ぶ量は風上から引いて風下へ足すので、どの上限・形でも元素とエネルギーは保たれる。運動量は帳簿に無い)。
3. **費用**: 変わらない。
4. **ただし打ち切り条件の「小刻み 2 倍で 2 % 以内」を満たさない**: 答えは流れの小刻みの数 N に大きく依る(4 → 8 で +18〜35 %・16 で火が消えるか 3 倍)。止めの速さを N = 4 と同じ m/s に揃えても同じ
   (= 上限のせいではない)。射影の答えの一番速い面が N にほぼ比例する(3.4 → 4.6〜8.0 → 15.4 m/s)。反応を 1 小刻みに 1 回に分けても N = 4 → 8 で +19〜28 %。
   **根の見込み(未確認)**: 1 刻みぶんの膨らみ(物の熱の小刻みの熱の受け渡し・反応の熱)が刻みの初めにまとめて出て、射影がそれを 1 小刻みで出し切る → 膨らむ速さ = 膨らみ ÷ 1 小刻み ∝ N。
   N は細かさの選び(1 小刻みに 1 ボクセル = 1.875 m/s になるよう箱の細かさで決めている。D-428 の「手抜きで結果を変えない」に触れる)。T-1186 の 3.9 mm の箱(N = 8)の「走り」(30〜41 mm/s・出る上限で縮めた 100 万以上)も、小刻み 4 倍の 28.8 mm/s・23 万と同じ形で、同じ根の見込み(未確認)。
   → 退く道(打ち切り条件に書いたもの)へ: **T-1381 に分けた**(膨らみを刻みの中で小刻みに分けて出す形など。土台の運動量の式に当たるので司令塔へ)。
