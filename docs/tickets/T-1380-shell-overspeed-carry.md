## 目的(1〜2 行)
層の流れで射影の答えが速さの上限(1 小刻みに 1 ボクセル = 1.875 m/s)を超えた時、運ぶ量は上限で止まり、越えた慣性は運動量のまま次の小刻みへ持ち越す(今。ADR-0534)。
この持ち越しが (1) 上限の値で答えを変えるか(D-428)(2) 保存を破るか (3) 費用 を測り、直す価値があれば形を比べる。

## 完了条件(チェックできる形で)
- [ ] 上限を変えた時(0.5・1〔今〕・2 ボクセル / 小刻み)と、小刻みを 2 倍にした時の燃え広がりの速さ・一番熱い温度・保存・費用(CPU)
- [ ] 持ち越しの形の比べ: A = 今(越えた慣性を運動量に持ち越す)/ B = 射影の後に運動量を上限で止める(越えた分は運ばれずに残った膨らみとして次の小刻みの圧力が押す)
- [ ] 判定(今のままで閉じる / 直す価値あり)と、直すなら案ごとの作り手から見た違い・おすすめ。既定は変えない(調べの口は既定 0 = 今と同じ答え・同じハッシュ)
- [ ] 口を足したなら: release 警告 0・object_shell(--quick)・float_check 系・archmap --check

## 研究の打ち切り条件(先に書く)
- 物差し: `object_shell_test --case`(CPU だけ)の紙・箱 7.8 mm・骨格 24 列・層 4 段・閉じた 1 セル(と世界の流れ)の燃え広がり。T-1380 で足す調べの口
  (上限の値・持ち越しの形・小刻みの倍数・上限を越えた面 × 小刻みの数)で並べる。比べの差の物差しは、T-1355 の丸めの違いで出た差(1.0 %)。
- **今のままで閉じる**: 保存 0 のまま、上限 0.5 → 2 と小刻み 2 倍で燃え広がりの速さの差が 2 % 以内 → 上限は結果を変えない(持ち越しは答えを変えない止め)。ADR-0534 の残りを閉じる。
- **直す価値あり**: 差が 2 % を超える → 上限に依っている(D-428 に触れる)。B と「小刻みを状態で増やす」(C)のどれが上限への依りを 2 % 以内にするかを見て、案ごとに作り手から見た違いとおすすめを書く。
- **打ち切り(退く道)**: B でも小刻み 2 倍でも依りが 2 % を切らない → 根は上限の扱いではなく「反応が 1 刻みに 1 度で、燃えたボクセルの膨らみが最初の小刻みに出る」(T-1143 の 6・T-1186)。
  退く道 = 膨らみを流れの小刻みに分けて出す形(反応を流れの小刻みに分ける〔T-1186〕・D-663 の運動量の式)を司令塔へ(土台に当たる)。2 時間で終わらなければ分かった所までと次の一手を書いて返す。

## メモ・参考
- 上限は 3 つ: 速さの上限(OH_FLOW_SPEED_LIMIT_Q16 = 1 小刻みに 1 ボクセル。運ぶ ④ と運動量を運ぶ ① だけ)・出る上限(1 小刻みにボクセルの中身の半分)・射影の右辺の桁あふれの止め(256 ボクセル。ADR-0534)。
- T-1143 の 6: 燃えたボクセルの膨らみ(約 8 倍)が 1 刻みの最初の小刻みに出るので、燃え広がりの最中も一番速い面は上限(1,875 mm/s)に当たる。
