# T-1076 物の熱の一般の形(空のボクセルを持たない並び・物の箱の中を粗く・9 つ以上の気体・違うレベルの物の混在)(T-1064 から分けた)

- Status: Todo
- 種類: 工学
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: 列 4(T-1078 の後)
- 設計: docs/design/20 §12.4・§11.1 N1 / 決定: ADR-0434・ADR-0451(仮)

## 目的(1〜2 行)
T-1064 の最小の形(箱の並び・表の気体 8 つまで・全部の物がレベル 6)を、要る形に広げる。費用の芯は薪の中(燃えていない中の木も毎刻み回る)なので、
物の箱の中を粗い箱にする(中と外で細かさを変える。N1)のが一番効く見込み(見積もり 1/4〜1/8。T-1065)。

## 完了条件
- [ ] 丸い断面・穴のある物を、空のボクセルを持たない並び(形の語 + 詰めた並び)で
- [ ] 物の箱の中を粗く(外の燃える層だけ 7.8 mm)。中と外の面は違うレベルの面の端数(ADR-0017)と同じ形で
- [ ] 表の気体が 9 つ以上の時(OH_MAX_GASES を超える)の形
- [ ] 違う細かさの物(小刻みの数が違う)を同じ Dispatch で(今は小刻みの番号で飛ばすだけ。段の数が一番多い物に合う)
