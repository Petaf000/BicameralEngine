# T-0273 GPU の溢れの世界で成分の多いセルを刻むと HW が DEVICE_HUNG になる(T-0248 で見つけた)

- Status: Todo(T-0272 より先)
- 種類: 研究(原因が読めない)
- PC: 必須(HW)
- 見積もり: チャット 1 回分
- 設計: 02 §3・ADR-0052(追記 3)。関係: T-0236・T-0248・T-0272

## 見つけたこと(T-0248、RTX 3070 Ti / 32.0.15.9597、release、ほかのランナーの負荷あり)
- 1 セルの上限 RX_GPU_WIDE_SPECIES = 32 で、`gpu_multires_test --queue compute --measure-wide` の「32 種のセル・溢れの世界」
  (根 64、試験の表 m01〜m32、150 刻みを 1 本のリストで)が 3 回中 2 回 DEVICE_HUNG(1 回は 535 / 265 ns/セル で通った)。
  空気だけの場面は毎回通る。WARP では測っていない。
- 64 では gpu_multires(HW)の「溢れを使う世界の刻み(伝導 あり)」(上限の場面 RunLimitsStepWide。1 刻みずつのリスト)が 2 回続けて DEVICE_HUNG
  (WARP は全部通った)。32 では gpu_multires・gpu_multires_warp とも通った(1 セル 32 種の場面は 10 刻み)。
- 試験で CPU と比べているのは 10 刻みまで。計測は 150 刻み(m01〜m32 が揃った後の刻みは CPU と比べていない)。

## やること
1. 32 種のセルの場面を CPU と比べながら 150 刻み(1 刻みずつのリスト)で HW・WARP に流す。食い違う・止まる刻みと段を絞る
   (段ごとに ExecuteAndWait、debug プリセットの DRED・GPU の FX_ASSERT)。
2. データで決まる回数のループ(LoadGpuWideCell の溢れの範囲・待ちの丸め)に壊れた値が入っていないか。1 本のリストに刻みを並べた時のバリアの抜け。
3. 打ち切り条件: 1・2 で原因が見つからなければ、上限の無い形のセルを伝導の段・全部を刻む段から無くす T-0272 の 1 を先にやり、直るかを見る。
