- 見積もり: チャット 1 回分
- マイルストーン: 試作の列・土台の変更要求の束(docs/plan/ROADMAP.md の T-1159 の行から分けた)

## 目的(1〜2 行)
積もった層の量のように「保存量の欄の内訳」を持つ欄を、登録の 1 行の印で書けるようにする(物質は 1 つのまま。作り手の書く値は増えない)。

## 完了条件
- [ ] 登録の印「内訳」と親の保存量の欄の番号(SfFieldDesc に欄を 1 つ)。0 ≤ 内訳 ≤ 親 の検査(SfDescValid と状態の検査)
- [ ] 保存の列は親だけ・ハッシュと保存点に入る
- [ ] 細かくする時は層は置かれ方の凝縮相(2-1)・舞う粒は空きに同じ濃さで・粗くする時は和
- [ ] 眠る判定: 層は止まっていれば眠れる・舞う粒は濃さ 0 まで起きている
- [ ] 形は wt3 T-1136 の 2 本目(層は落ちても層のまま)の結果に合わせる(2-6 の置き場を足すかも同じ時に)

## メモ・参考
- ADR-0469 の 2-2 の案 (b)(2 つ目の物質として登録)はとらない(作り手の反応が片方にしか当たらない書き間違いが起きうる)。
