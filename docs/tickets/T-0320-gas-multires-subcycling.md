## 目的
gas_tree(T-0208)は全部のレベルが同じ小刻みで、細かいレベルが 1 つ増えるごとに全体の小刻みが 2 倍になる。レベル k を 1 刻みに substeps × 2^σ(k) 回に分ける
(σ = k − 基準。ν はどのレベルも 0.47 のまま)。違うレベルの面は細かい側が細かい小刻みごとに計算し、粗い側は粗い小刻みの終わりに合計を受ける(Berger–Colella の refluxing。
粗い側の値は粗い小刻みの初めのまま)。

## 完了条件
- [x] σ = 0(全部同じ小刻み)なら T-0208 の gas_tree と毎刻みビット一致(T-0208 の実装で測った状態のハッシュの鎖 0x968f764677303a49 と一致。閉じた 2 レベルの箱 12 刻み)
- [x] 閉じた 2 レベルの箱で全保存量が毎刻み「初め + 帳簿」とビット一致(レベル 0 は 24・レベル 1 は 48 の小刻み。30 刻み。端数を持つ粗いセル 64)・同じ入力なら同じ状態
- [x] 圧力の波がレベルの境を通る時の反射: 分けない形 1.05% → 分けた形 2.26%(通った波の誤差 3.25% → 3.89%)。時間補間が無い分で約 2 倍(同じ桁)。減らす方法は T-0338
- [x] 静止大気が動かない(分けた形で 20 刻み、ビット単位で同じ)

## メモ
- 係数: レベル k の小刻みの Δt が 2^-σ 倍 → 流れ・拡散・力積の × 2^k が × 2^(k−σ)、重さの力積が × 2^-σ。乱数の小刻みの通し番号はレベルごとに。
- 粗い風上から細かい面が何度も引く時の負の中身: 粗い小刻み 1 回の間の細かい面の割合の合計で抑える(熱の C/8 ÷ 引く回数と同じ考え。ADR-0017 追記)。
- 粗い側の端数の受け方は T-0208 のまま(粗い小刻みの終わりに足す変化の表を持つ)。

## 引き継ぎメモ
- 使い方: `MakeGasTree(config, regions, 割合, 温度, 地面の圧力, GasTreeOptions{.subcycleBaseLevel = 0, .maxSubcycleGap = 1})`。
  レベル k の小刻みは `config.substeps << levels[k].subcycleExponent` 回。安定の条件(全部のレベルで ν × 2^(k − σ) ≤ 0.6)は MakeGasTree が assert。
  既定(maxSubcycleGap = 0)は分けない = T-0208 と同じ値。ゲームの値(基準・Δσmax)は 05 に載せる時(T-0210)に決める(基準 0・Δσmax = いちばん細かいレベルなら
  どのレベルも ν = 0.47 で、小刻みの数はレベル 0 のまま 24)。
- 規則(ADR-0117 追記): 違う小刻みの面は細かい側が計算・粗い側は力積も塊も粗い小刻みの終わりに受ける(next に足す)。粗い側の値は粗い小刻みの初めのまま。
  粗い風上の割合は × 2^g で数え、使える分 = 1 − 粗い小刻みの初めの同じ小刻みの面の分(committedOutflow)。移す物質量は粗い小刻みの間に出した分(taken)を引いた中身で抑える。
- GPU(T-0209)へ: 小刻みは「いちばん細かい小刻みの列」で、各 micro ではそこで始まるレベルの面とセルだけを動かす(空の段は抜ける)。セルごとに forced・next・
  committedOutflow・taken(成分ごと)を粗い小刻みの間持つ必要がある。粗い側への足し込みは next への 128bit の足し算(T-0208 と同じ)。乱数の小刻みの通し番号はレベルごと。
- 粗い風上から割合を抑える道(committedOutflow で縮める・taken で縮める)は、今の試験の場面では通っていない(普通の流れでは割合の合計は 1 よりずっと小さい)。
  式は σ = 0 の時に T-0208 と同じ形になることだけ確かめた。極端な圧力差の場面を足すなら T-0321 か T-0209 で。

  2% ほど跳ね返る(耳や計器で分かる大きさではない見込み。未確認)。必要になったら T-0338 で減らす。
