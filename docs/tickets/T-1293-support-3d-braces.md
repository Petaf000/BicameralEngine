# T-1293 3 次元の段の斜めの棒(辺の斜めだけか角の斜めにも)とねじれの硬さを連続体と比べて決める

- Status: Todo

- マイルストーン: 試作の列 3(R-B1。T-0960 から分けた)

## 目的(1〜2 行)
3 次元の格子の梁(T-0960 の 1 本目。sim/support_law_3d)の段の斜めの棒を、辺で接する斜め(3 つの座標の面の段。今の既定)だけにするか、角で接する斜め(3 軸の段)にも置くかを決める。
あわせて、ねじれの硬さ(J = 9/64 dx⁴。1 セルの太さの棒で連続体と同じになる仮)を太い棒で確かめる。

## 完了条件(チェックできる形で)
- [ ] 基準: 斜めに傾いた壁(2 軸に傾けた板)・3 次元のアーチ(奥行 > 1・斜めに回した向きも)・ねじった 1 × 1・2 × 2・4 × 4 の断面の棒を、六面体の要素(Q6 / H11 など)を細かく刻んで解いた値(浮動小数点の捨てる試作。値だけ試験に書く)
- [ ] 辺の斜めだけ / 角の斜めにも、の 2 本でたわみ ±5 %(0.5 m と 0.25 m)を比べて決め、ADR-0514 に書く
- [ ] ねじれの角が連続体の ±5 %(太い棒)。外れたら J の分数を選び直す
- [ ] 帳簿・決定性・剛体の動きと一様な歪みの検査(support_3d_test)を壊さない

## 研究の打ち切り条件(研究のときだけ)
2 本(辺だけ / 角にも)のどちらも ±5 % に入らなければ、棒の係数を面の向きごとに測り直す道(ka/12 は 2 次元の合わせ込みの値)。それもだめなら司令塔へ。

## メモ・参考
- 2 次元の段の棒は ADR-0415(ka/12・内径 4 m のアーチで +14 % → 0.959 / 0.984)。3 次元の辺の斜めの棒は同じ係数を 3 つの座標の面に置いた(T-0960)。
