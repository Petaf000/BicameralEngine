# T-1293 3 次元の段の斜めの棒(辺の斜めだけか角の斜めにも)とねじれの硬さを連続体と比べて決める

- Status: Done(2026-11-05・wt3。辺の段の棒に面の外の曲げを足し・角の段の棒を 3 歩の階段に置き・ねじれ 7/4 b。全部の場面で ±5 %。CPU と GPU のビット一致)

- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: 試作の列 3(R-B1。T-0960 から分けた)

## 目的(1〜2 行)
3 次元の格子の梁(T-0960 の 1 本目。sim/support_law_3d)の段の斜めの棒を、辺で接する斜め(3 つの座標の面の段。今の既定)だけにするか、角で接する斜め(3 軸の段)にも置くかを決める。
あわせて、ねじれの硬さ(J = 9/64 dx⁴。1 セルの太さの棒で連続体と同じになる仮)を太い棒で確かめる。

## 完了条件(チェックできる形で)
- [x] 基準: 斜めに傾いた壁(2 軸に傾けた板)・3 次元のアーチ(奥行 > 1・斜めに回した向きも)・ねじった 1 × 1・2 × 2・4 × 4 の断面の棒を、六面体の要素(Q6 / H11 など)を細かく刻んで解いた値(浮動小数点の捨てる試作。値だけ試験に書く)
- [x] 辺の斜めだけ / 角の斜めにも、の 2 本でたわみ ±5 %(0.5 m と 0.25 m)を比べて決め、ADR-0514 に書く
- [x] ねじれの角が連続体の ±5 %(太い棒)。外れたら J の分数を選び直す
- [x] 帳簿・決定性・剛体の動きと一様な歪みの検査(support_3d_test)を壊さない

## 研究の打ち切り条件(研究のときだけ)
2 本(辺だけ / 角にも)のどちらも ±5 % に入らなければ、棒の係数を面の向きごとに測り直す道(ka/12 は 2 次元の合わせ込みの値)。それもだめなら司令塔へ。

## メモ・参考
- 2 次元の段の棒は ADR-0415(ka/12・内径 4 m のアーチで +14 % → 0.959 / 0.984)。3 次元の辺の斜めの棒は同じ係数を 3 つの座標の面に置いた(T-0960)。

## 結果(2026-11-05・wt3)
### 決めた形(ADR-0514 に追記。T-1294 の前提)
- **辺の斜めの棒**(段の面 (a, b) の中・間の 2 セルの片方だけ): 今までの軸の伸び ½ q (s Δu_a + Δu_b)² に、**面の外の曲げ ½ q (w · Δφ)²**(w = e_a − s e_b = 段の面の中で棒に直交する軸)を
  **同じ係数 q = ka/24** で足す。奥行 1 セルの 2 次元の場面では面の外の回りしか触らないので 2 次元の答えは同じ。
- **角の斜めの棒**: c → c + (s_x, 1, s_z) が、間の 6 セルのうち **2 つだけを通る 3 歩の階段**でつながる所(2 次元の「間の 2 セルの片方だけ」の 3 次元の読み)に、
  軸の伸び ½ q_c (s · Δu)²(q_c = ka/36 = 軸の硬さ ka/12 = 辺の棒と同じ)。残りの硬さは道の 3 つの面の小さい方。間に 3 つ以上あれば置かない。
- **ねじれ 7/4 b**(J = 7/48 dx⁴。前は 27/16 b = 9/64 dx⁴)。
- 作り手から見た違い: 無い(書く値は無い・3 次元の支えはまだ世界に入っていない)。斜めに伸びた物・回した物の硬さが向きによらず揃う。ユーザーへの問いにしない。

### 基準(浮動小数点の捨てる試作。リポジトリには入れない・値だけ試験に)
- 同じ階段の形(ボクセル)を H11(Wilson の非適合モードの六面体。ν = 0)で各セル m³ に刻み、u(m) = u∞ + C m^-p に 3 点で合わせて外挿
  (0.5 m は m = 3・4・6、0.25 m は 梁が m = 2・3・4・アーチは m = 2・3 と 0.5 m の同じ形の p)。段の入り隅で p ≒ 1.0〜1.4(h² で外挿すると足りない)。
- 格子の形は同じ式の浮動小数点の直接解(C++ の整数の 300 刻みと 4 桁で一致を確かめた)。
- 場面(「斜めに傾いた壁」は、段の継ぎ目の効きが強く出る斜めの片持ち梁で代えた。自重で立つ壁は押し縮めだけで段の効きが小さい): 斜めの片持ち梁(長さ 6 m・断面 1 × 1 m・根の t < 0 の 2 セルを壁にして接する面を固定)の向き x・(1,1,0)・(1,0,1)・(1,1,1)、
  回したアーチ(内径 4 m・外径 5 m の半円・幅 1 m・上の軸の回りに 0° と 45°)。見る所は梁の先の平均・アーチの頂の平均の上の変位。
