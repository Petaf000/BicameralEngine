# T-0612 液体・固体・気体が 1 セルの体積を分け合う

- 見積もり: チャット 1 回分(T-0593 と合わせて)
- マイルストーン: ROADMAP の T-0027(T-0609 から分けた)
- 設計: docs/design/07-transport.md §2.8・§3.1 / 決定: ADR-0268(Proposed)・ADR-0266

## 目的(1〜2 行)
「固体を少しでも含めば液体の壁」をやめ、固体が占める体積(密度から)を除いた空きに液体が入り、孔を通り、液体が入ると空気が押し出される形にする。

## 完了条件(チェックできる形で)
- [x] 凝縮相の体積(密度から)→ 液体の空き = セル − 固体・気体の空き = セル − 固体 − 液体(sim/cell_volume。T-0593 と同じ芯)
- [x] 壁の決まり(固体を少しでも含めば壁)を外す: 空きが 0 のセルだけが壁。砂 1 µmol は水を止めない
- [x] 固体の隙間(孔)を液体が通る・染みる(砂の床に 10 秒で 99.98%)
- [x] 液体が入ると空気が押し出される(下のセルの空気 5.08 → 2.55 mol)
- [ ] 閉じた洞窟の空気の圧力を液体の圧力に足す → T-0618
- [x] 保存(水の量・運動量 − 帳簿)が毎刻みビット単位。T-0609 の試験(probe_liquid)が通る(石に密度とセルを満たす量を書いた)
