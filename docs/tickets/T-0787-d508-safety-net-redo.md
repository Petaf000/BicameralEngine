## 目的
強い爆発の 1 小刻みの中で熱が 0 以下になる件(T-0691)を、陽解法の世界の安全網で式の形から無くす。爆風の先端は約 650 m/s で頭打ちになりうる・
頭打ちの回数は開発の計器で警告(D-508)。ふつうの火・煙・風・衝撃波の値は変えない。

## T-0722 で分かったこと
- 面の力積を「|P + ΔP| ≤ |P| + Σ|J| ≤ √(2 m K_上限)」で縮める形(セルごとの倍率 = 当てる段の TxSideScale、面は両側の min)は、
  向かい合う面の力積が打ち消し合う分まで数えるので効きすぎる: gas_reference の衝撃波の管の試験の速さが外れ、5 倍・1500 K でも 132 面縮む。
- 40 倍・2600 K の爆発では縮めても温度 0 のセルが残った = 熱が 0 以下になる根は力積だけでなく、運ぶ側(押し出す仕事込みの出ていく量・
  割合の切り捨て・移す塊のエネルギーの丸め)にもある。
- 案: 当てる段の上限の「エネルギーの列」(設計 20 §2.4 ②: 出る側の倍率を量・エネルギー〔押し出す仕事込み〕の列ごとの最小)に、
  力積で増える運動のエネルギーを同じ列として載せる(正味の力積で数え、Jacobi の倍率で両側を同じに縮める)。まず熱 0 になる刻みと面を測る。

  - **小刻みの終わりに負のまま**のセルは、**運ぶ側**(力の後は正で、出ていく塊を引いただけで負)が 1059(87% は力の後の温度が小刻みの初めより低い =

  セルは、出ていく面の割合と成分を同じ倍率で縮める。熱が 0 以下のセルは出さない):
  - 40 倍: **小刻みの終わりに熱が負のセルは 0**(運ぶ側 0・その他 0)。5 倍: 縮めた面 0(値は変わらない)。

## 次の案(続きのチャットで)
1. **熱の列を余裕だけで既定にする**(熱が負にならないことを式の形で保証。5 倍は変わらない)+ 温度 0 に着くのを受け入れる(熱は負でない・
   次の刻みに入ってくる塊が戻す)。要る確かめ: gas_reference の衝撃波の管・probe_gas・multires_gas・GPU の気体の段との一致(GPU に同じ式を入れる)。
2. 温度 0 に着く根(1 小刻みの押し出す仕事の冷え過ぎ)を直すなら、押し出す仕事を「出ていく側の平均の温度」(小刻みの初めと終わりの間)で数える形を試す
   (割合が大きい時だけ違う)。打ち切り: 2 本で 40 倍の温度 0 が消えて 5 倍が変わらない形が無ければ案 1 で閉じる。
3. 爆風の先端の頭打ち(約 650 m/s)は、力積の側が一時だけと分かったので要らない見込み。頭打ちの回数の代わりに「熱の列で縮めた面の数」を計器へ
   (GasBox::energyLimitedFaces。刻みの報告と開発の計器の警告は案 1 と一緒に)。

## 2 チャット目(2026-10-19・D-524 の順)
### 案 2 を 2 本(押し出す仕事を「出ていく側の平均の温度」で数える)
終わりの温度 = 出ていく側だけ引いた後の風上の温度。出ていく面の全部で同じ倍率 x(数える温度 ÷ 初めの温度)とし、閉じた形で解いた
(A = 力の後の熱 − 熱の分け前の和・W = 初めの温度の押し出す仕事の和。終わり ÷ 初め = 1 − (W ÷ A) x):
- 2a 平均(台形): x = 2A ÷ (2A + W)  / 2b 終わりの温度: x = A ÷ (A + W)(残る熱 = A² ÷ (A + W) ≥ 0)
| 形 | 5 倍 1500 K(縮めた面・最も冷たい・最速) | 40 倍 2600 K(縮めた面・最も冷たい・最速) |
|---|---|---|
| 前(熱の列なし) | 0・283.5 K・4.58 m/s | 0・0 mK・2.48 m/s |
| 熱の列・余裕だけ(案 1) | 0・283.5 K・4.58 m/s | 7021・0 mK・2.14 m/s |
| 2a 平均・熱の列なし | 0・**282.3 K・5.47 m/s** | 0・229.7 K・3.63 m/s(終わりに熱が負のセル 12 = 力で負のセルが持ち出す) |
| 2a 平均・熱の列(余裕だけ) | 30・282.3 K | 436・231.0 K |
| 2b 終わり・熱の列なし | 0・**281.4 K・5.46 m/s** | 0・231.4 K・3.59 m/s(同上 12) |
| 2b 終わり・熱の列(余裕だけ) | 30・281.4 K | 556・227.5 K |
(熱の列 + 案 2 の 5 倍の 30 面は、熱の列が初めの温度の押し出す仕事で数えている食い違い。案 2 を入れるなら列も同じ x で数える)
→ どちらも 40 倍の 0 K は消えるが、5 倍の値が変わる(最も冷たい −1.2 / −2.1 K・最速 +19%)。**打ち切り条件に当たったので案 1 で閉じた**。

## 引き継ぎ(次のチャット)
- 今のブランチは熱の列を**既定で切った**(GasBox::limitMovedHeat = false。値は 0ea6fa3 とビット単位で同じ。試験の強い爆発だけが入れる)。

  持ち出せる熱が 0 になり、出ていく面が全部 0 に縮む(未確認。まず CPU の probe_gas の燃える木箱で、縮めたセルの物質量・熱・出ていく割合を測る)。
