# T-0997 R3 の 3 本目: 書いた崩れる角度を「山が止まる角度」にする(勢いで行き過ぎる分を崩れ始めの差に)

- 見積もり: チャット 1 回分

## 目的(1〜2 行)
T-0996 の 2 本目は書いた φ で崩れ始め、勢いで行き過ぎて φ より約 6° 低く止まった。D-620(書いた `repose_angle_deg` は山が止まる角度・崩れ始めは数度急)に合わせ、
砂山が書いた値 ±4° で止まる形にする。崩れ始める角度がどれだけ急になるかも記録する。

## 完了条件(21 §5.2 の R3)
- [x] 砂山が書いた φ ±4° で止まる(φ 25°・34°・40°)→ 差 6° で 26°・33°・39°
- [x] 0.5 m と 0.25 m で同じ(±1 セル)→ 同じ角度(26/26・33/33・39/39)
- [x] 60 秒でほぼ止まる(動く粒の質量 1 % 未満)→ 全部「ほぼ止まる」
- [x] 崩れ始める角度を記録 → 31°・38°・44°(書いた値 + 4〜6°)
- [x] 保存 0・決定的(`^case_b` 5 本が通る。case_b_r3 は保存・決定性・負の質量で落ちる)
- [~] 掘った後に崩れ直す角度(記録)→ 30 秒後 27° / 28°(差 0 では 22°)。まだ止まり切る前の値
- [ ] 勢いで走る → 差 6 で 0.5 m 4.50 m・0.25 m 4.25 m(差 0 は 4.50 / 5.25 m)。角度だけの 4.22 m + 0.5 m に届かない(摩擦を上げた分だけ短い)
- [x] release 警告 0

## 研究の打ち切り条件(着手時に書いた)
- 1 本(2 時間)。降伏の上限の角度を「書いた値 + 差」にし、差 0 で行き過ぎを φ 25°・34°・40° で測り、その値で差を置いて砂山・斜面を測り直す。
- 止まる角度が書いた値 ±4° に入らない・0.5 m と 0.25 m で 3° 以上違う、のどちらかなら記録して返す(案 A へは戻さない。D-556)。

- 勢いで走る長さは差を上げた分だけ短くなった(柱の崩れでは上限の摩擦が全部の面で効く)。実験の 7.3 m との差は差 0 でもあった(0.5 m 4.5 m)。
  「止まる角度を書いた値に」と「勢いで遠くへ走る」を 1 つの差で両立できていない。根の見込み(未確認): 走る間の摩擦(動の上限)まで書いた値 + 6° になっている。
  次の 1 手の候補(研究・記録だけ): 動いている面の上限を「書いた値」・止まった面の上限を「書いた値 + 差」に分け、止まりかけ(速さが小さい面)だけ止まった面の上限を使う。
- 計器(`SlopeAngleDegrees`)の角度がこの場面で 90° と出た(壁際に残った粒の列を拾う見込み。値は斜面の芯で見た。未確認)。
- ctest は通った本数だけで出力を残さないので、場面 1・4〜8 の値は差 6 では取っていない(差に効かない場面 4・6・7 は T-0998 の値のまま)。

## 仮・判断待ち
- 仮: 差は 1 つの法則の定数 6°(角度によらない)。作り手が書く値は増えない。
- 仮: 動いている面と止まった面で上限を分けない(ADR-0430 の代案。分けても止まる角度を書いた値にするには動の上限も上げることになる)。
- ゲームの中身へ: 無し。

## 分けたもの
- T-1004(研究・R3 の続き。記録だけ・判定の後でよい): 勢いで走る長さを戻す(動いている面と止まりかけの面で上限を分ける)。合格: 止まる角度 書いた値 ±4° のまま、柱の崩れが角度だけ + 0.5 m 以上。
- 差が角度でわずかに違う〔5.5〜7°〕のは記録だけ。15°・50° など外側は R3 の判定の後に要れば測る。
