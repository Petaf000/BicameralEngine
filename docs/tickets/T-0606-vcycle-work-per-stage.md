# T-0606 V サイクルの段の中の仕事を減らす(計画を系ごとに 1 回・同じ色の隣が無い段の赤黒・子ごとの縮約)

- Status: Done(①〜③と止める判定の半分を入れた。値は同じ。64³ の 4 ms は段 0 の帯域と V の回数が残り → T-0625)
- 種類: 工学(値は同じで費用だけ変わる。見込みは未測)
- PC: 必須(GPU)
- 見積もり: チャット 1〜2 回分
- マイルストーン: ROADMAP ③(T-0587 から分けた)
- 設計: ADR-0264・docs/perf.md の T-0587 の行 / 決定: D-468・D-302

## 目的(1〜2 行)
T-0587 の段ごとの計測で、V 1 回の重さは同期ではなく段の中の仕事と分かった。64³ の重い段を値を変えずに軽くし、圧力の投影の 64³ の爆発の刻み(約 9 ms)を 4 ms に近づける。

## 完了条件(チェックできる形で)
- [x] ① 段の計画(ImPlanLevels。64³ で 376 µs/解き)を系の形が変わらない間は作り直さない(外側の反復の解き直し・熱の毎刻みで形が同じ時)。
      GpuImplicit に「計画を使い回す」記録の形を足し、呼ぶ側が系を写し直した時だけ作る
- [x] ② 同じ色の隣が無い段(一様な箱の段 0)は、赤黒の 1 色でその色の節だけを書く(今は 1 色ごとに全部の節を A ↔ B に写す)。
      計画が段ごとに「同じ色の隣が無い」を印にし、B を読む所が無いことを確かめてから(ImSolveConverged・縮約・直しは A だけを読むか)
- [x] ③ 縮約(R1 64³ 183 µs)を子ごとのスレッドで計算して親ごとに足す(整数の和は順によらない)
- [x] gpu_gas_projection_test・gpu_implicit_box_bench・陰解法の GPU の試験が CPU とビット一致。`--stages` で前後を docs/perf.md に
- [x] release のビルドが警告 0・archmap --check

## メモ・参考
- T-0587 の計測(64³ の V 約 1050 µs): S0 × 8 = 538・R1 183・判定 101・S1 × 8 = 73・T3 55・P0 24。V の外 ImPlanLevels 376 µs/解き。

## 結果(2026-10-15。表は docs/perf.md の T-0606 の行。前は同じ日の T-0587 の段ごとの計測)
- **入れたもの(値は同じ。CPU とビット一致)**:
  ① 計画の段ごとの表(ImPlanLevels・新しい ImPlanColors)は系を写した後の最初の解き・刻みだけで作る(GpuImplicit が RecordUpload・RecordCopySystem・
  RecordCopyLevels で「作り直す」印を立てる。呼ぶ側は何もしなくてよい。引数を作る ImPlanArgs は記録の形で変わるので毎回)。
  ② 計画が段ごとに「同じ色の隣があるか」を印にし(ImPlanColors。IM_PLAN_SAME_COLOR)、無い段の ImSmooth はその色の節だけを値 A に直接書く。
  ③ ImRestrict は 1 つの親を 8 スレッドで(子を分けて Relax し、groupshared で親ごとに足す)。子の隣が多い親は前の形。
  ④(足した)V の後の止める判定(ImConverged・ImSolveConverged)は、段 0 に同じ色の隣が無ければ色 1 の節を飛ばす
  (V の段 0 の最後は色 1 の掃き出しで、その節の残差はちょうど 0。熱は 0 が許容差を超えず、圧力の閾値は切り上げで 1 以上)。
- **段ごと(64³、µs)**: R1 183 → 115・判定 101 → 66(V の前の 1 回は 105 のまま)・ImPlanLevels 376/解き → 0(系ごとに 1 回)。
  S0 の 1 色 67 → 68(変わらない)。32³: R1 22.5 → 14.3・判定 12 → 10・V 237 → 224。16³: R1 13 → 4(V の残りは ImTail 58)。
- **② が効かなかった理由**: 色が交互に並ぶ節の配列(節 40 B・隣 16 B × 6)では、その色の節だけを書いても読むキャッシュの行はほぼ同じ
  (写す節の 8 B の読み書きが消えるだけ)。S0 は帯域で決まっていて、軽くするには段 0 の並べ方を変える必要がある → T-0625 の案 A。
- **64³ の爆発の刻み(解く部分、2 刻み目、2 回取って小さい方)**: 最速 4.2 ms・340 m/s 9.6 ms(前の約 9 ms は T-0531 の 3 刻みの平均で直接は比べられない。
  段ごとの差からの見積もりで 1 刻み約 1.2〜1.9 ms 軽い〔計画 0.38 ms × 解き 3〜4 + (R1 68 + 判定 35 µs)× V 7〜8〕)。
  4 ms に入れるには V 1 回を約 0.5 ms にするか V の回数を半分にする必要がある → T-0625(研究)。
