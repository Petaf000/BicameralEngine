# T-1365 熱の放射の段の不透明な面の受け渡しを τ で連続にする形を決める(ADR-0535 の (b)。研究)

- Status: In progress(2026-11-12 wt4 の作業役が 2 時間で区切った。費用 (5) が残り。研究。既定は変えない = 既定 0 の口〔CascadeParams::faceCoupling〕で CPU リファレンスだけ試す。ADR-0535 はユーザーの答え待ち・仮 (a))
- 種類: 研究。**打ち切り条件(2026-11-12 着手の前に書いた。司令塔の指示で CPU だけに絞った)**: 面の係数 g の形 2 つ
  〔① Rosseland の上限付き g = min(1, 4 ÷ 3τ)・② 二流束 g = 1 ÷ (1 + 3τ/4)。τ = 面の両側の小さい方〕を CPU リファレンスで試し、
  両方が次のどれかに当たれば (b) をやめて (a)(または (c))に退く案を司令塔へ出す:
  (1) 保存が破れる(帳簿の 放った = 吸った + 返した + 外へ がビット単位で合わない)、
  (2) 詰まった物(木・石・既定の灰色の固体)の面で放射が伝導の数 % 以上を運ぶ = 伝導と二重に数える、
  (3) 同じ温度の閉じた箱で正味の流れが既定(形 0)より大きくなる(坂を上る)、
  (4) 厚い一様な物の中の拡散が Rosseland の解析解(4σΔ²(T⁴) ÷ 3τ)から τ ≥ 8 で ±30 % を超えてずれる、
  (5) RC の段の CPU の費用が既定の 1.5 倍を超える。
  2 時間で決まらなければ、測った所までと次の形の案をここに書いて返す。GPU 化はこの仕事に含めない(形が決まってから)
- PC: 必須
- マイルストーン: 列 4(T-1156 から分けた)
- 決定: ADR-0535(Proposed)・D-428

## 目的
RcMaskAcross の「向こうが τ ≥ 32 なら 0・未満なら全部」の崖を、光学の厚さで連続な受け渡しにする。詰まった固体の中は 0 に近づき(伝導の仕事のまま)、
まばらな燃える物は a の値で燃え広がりの速さが連続に変わる。CPU・GPU のビット一致・保存(D-206)を保つ。

## 足場
- 測りの道具: radiation_scene_measure の lc=・ls=(草の光の a)・watch=1(付けたセルと隣の熱の内訳)。試験 radiation_scene_spread。
- 飽和の値は RdOpticalDepthQ32 で 32 に丸める。連続にするには丸める前の Σ a·n(FxU128)から係数を作る所が要る。

## 結果(2026-11-12 wt4・release・CPU リファレンス・main 9818006a の上。既定は不変)

## 作り手(エンジンを使う人)から見た違い(形 1・2 にしたら)
- 光の a は「どれだけまばらか」を連続に表す値になる(崖が無い)。a を少し変えても燃え広がりが急に現れ・消えることはない。
- **今の a のままでは草は燃え広がらない**(表の値でも τ 28.8 でも)。放射だけで隣の草を燃やすには τ がおよそ 2〜8 より小さい a が要る(τ 8 で 1 セルだけ。未確認の幅)。
  実の草原(葉の太さ 0.4 mm・詰まり 0.1〜1 %)は τ 1〜12 / 0.5 m ほど(文献の消散の係数からの計算。未確認)なので、桁は合う。燃え広がりは炎(T-1366)が主になる見込み。
- 既定の灰色の固体(土・石・木)は今と同じ(面どうしは伝導の仕事)。透ける物と固体の面は両側で釣り合う(T-1367 が消える)。
- 熱い「まばらな厚い物」(τ 32〜9 万: 草の山・藁・煙の濃い所)が中の面からも放つので、その場面の段は重くなる(直に当てて減らした。下)。
