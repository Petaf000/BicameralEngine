- Status: Todo(2026-10-26: T-1141 の測りで見立てを書いた。確かめは T-1152 と一緒に)

- マイルストーン: 試作の列 6(docs/plan/ROADMAP.md の R-T2。T-1111 から分けた)

## 目的
T-1111 の 8,192 セルの出来事が回によって 0.06〜0.52 ms と揺れた原因を確かめ、費用の式の値(D-662 の起動時の測り)の取り方を決める。

## 見立て(2026-10-26・T-1141)
- **GPU の時計(電力の段)**の見込みが強い。`gpu_time_step_span_test --stage-variants` で同じ大きさ・同じ形の系を順に測ると、プロセスの始まりから約 2.7〜3 秒で
  どの変種も 4〜6 倍遅くなった(8,192 セルの段 0: 0.0215 → 0.128 ms。**読むだけの変種も 0.0041 → 0.0164 ms** = 割り算でも系の形でもない)。
  512 セルの系の組でも同じ時刻に跳ねた。測りは系ごとに別の実行(小さい仕事の間に GPU が休む)なので、時計が下がりやすい。
- 本物の早送りは出来事を続けて積むので、高い時計のままの見込み(未確認)。

## 打ち切り条件
- 出来事を 1 本のリストに続けて積んで測り、揺れが 1.3 倍の内に入れば「時計」と決めて、費用の式は続けて積む形で測る(T-1152)。入らなければ系の形(枠をまたぐ面・項の数)を並べ替えて比べる。
