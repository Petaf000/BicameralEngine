## 目的(1〜2 行)
T-0519 で数えた物理の散逸(PxBody::dissipatedEnergy)を、世界のセルの熱へ実際に返す。帳簿「物理で失った量 = セルに増えた熱 + 借りの残り」を毎刻みビット単位で合わせる。

- [x] CPU の物理(PhysicsWorld::HeatEntries・HeatLedger)と CPU リファレンスの世界(ProbeReference::Advance の heat)

## 作り
- 入口(小刻みごと・接触点ごと): 最後の本反復の後・速度の更新の前に、w = Σ 行 |λ| × |行の向きの相対の速さ|(2^-16 W)と点の位置(A と B の点の真ん中)。
  当たった瞬間(近づく速さ × 法線の力)・滑る間(滑る速さ × 摩擦の力)が大きく、静止は 0 に近い。重みが 0 の点は CPU は積まない(GPU は決まった枠に 0 で置く。和は同じ)。
- 刻みの終わり: 返す元 = Σ dissipatedEnergy − 1024000 × 返した mJ。正なら mJ に切り捨て、重みの割合で切り捨てて分ける(重みの和を 31 桁に収めるよう右へずらす)。
  負なら返さない(借り)。残り(端数・借り)は帳簿に。1 刻み 2^31 mJ まで(超えた分は次の刻み)。
- 世界: 物理の刻み t の入口を刻み t + 1 の初め(コマンドの後)に ProbeCellOfPhysicsPoint のセルへ足し、ブロックを起こす(つついたセルと同じ)。
- 返す元は世界で 1 つ(仮。ADR-0242): 島を作らない(GPU で回数の決まらない連結成分が要るため)。

## 結果(2026-10-15・release・CPU)
- 落とした物(試験の世界に 500 kg の立方体を x = 20 m・底 5 m から。120 刻み): セルへ返した熱 24534.208 J(m g h = 24516.6 J。積み木の柱が
  初めに沈む分を含む)・落ちた所のまわり(9 × 5 × 9 セル)に 24184 J(98.6%)・残り −11.04 J・最も大きい借り −56.3 J・熱を返した刻み 33。2 回の実行で同じ。
- 崩した積み木(柱を上の方で 5000 N·s 押す。180 刻み): 返した熱 68979 J・残り −5.0 J・最も大きい借り −106.5 J。
- 借りは T-0519 の 1 小刻みの最大(0.064 J)より大きい: 積み木の柱が静止のまま解き方の誤差でエネルギーを出し入れし、それが溜まる(返すのは正の分だけなので)。
  帳簿は合っている。熱の量への影響は 0.2% 以下。
- 物の状態のハッシュ・GPU の世界はまだ変えていない(このブランチでは世界のハッシュは変わらない。変わるのは T-0561: 物が接して動いた刻みの次の刻みから、
  接触点のセルのエネルギーが増えるため)。GPU の物理は刻みの終わりに 3 パス・小刻みごとに 1 パス増えた(時間は未計測)。

## 判断待ち(仮で進めたもの。ユーザー未確認)
1. **返す元を世界で 1 つにする**(ADR-0242 の 2。作り手から見た違い): 熱の場所は接触点の仕事の重みで決まるので変わらない。違いは量だけで、
   ある所の解き方の誤差(試験で最大 107 J)が別の所の熱から差し引かれることがある。島ごとにするには GPU で島(連結成分)を作る必要があり、
   回数を固定すると島が途中で切れる。おすすめ(仮)は世界で 1 つ。島ごとに替えても入口・帳簿の式は同じ。
2. **両側の分とも接触点のセルへ**(物に温度ができるまで): T-0519 のおすすめ案 B のまま。物に温度ができたら半分を物へ。
