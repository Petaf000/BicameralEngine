## 目的(1〜2 行)
D-424 の下限(1 刻み 2^-16 µmol 未満は 0)を外しても、眠らせたブロックを「次に 1 単位進む刻み」に起こせば全部を計算した場合とビット一致する、
という方式(待ちの丸め)を CPU リファレンスで確かめる。何年分の遅い反応が正しい平均の速さで起きることも確かめる。

## 方式(ADR-0018)
- 進行度 = 整数部 + [刻み t ≥ tc + n]。tc = セルのブロックが最後に変わった刻み(刻みの初めに読む)、n = 幾何分布の待ち
  (P(n = k) = (1 − f)^(k−1) f、f = 1 刻みの進みの端数〔64bit〕)。n の乱数は (世界のシード, tc, セル, 規則の鍵) だけで決まる。
- 幾何分布は記憶が無いので、ブロックが変わるたびに引き直しても速さは偏らない。毎刻み変わるセルでは今の丸めと同じ分布。
- 変わらなかったセルは「次に評価の要る刻み」= min(tc + n) を返す。ブロックはその最小に起こせばよい(全部を計算しても、その手前では何も変わらない)。
- 取り合いの丸め(D-431)は今のまま刻みの乱数(取り合うのは進む規則があるセル = 起きているセルだけ)。
- 今の世界(多重解像度・仮の世界)はまだ今の丸め(RxStepCell)のまま。新しい関数は reaction.hlsli の RxStepCellWait(C++ は StepReactionCellWait)。

## 完了条件(チェックできる形で)
- [x] 待ちの分布: f = 0.9〜2^-58 で待ちの平均 = 1 ÷ f・P(待ち = 1) = f が ±5σ。f について単調、級数と log2 の境目で 1 刻みまでしか違わない
- [x] 引き直し: ブロックが別の理由で変わる・f が周期的に変わる(変わる時に引き直す)場面で、起きた回数が Σ f の ±5σ。引き直さない場合の偏りを測る
- [x] 眠らせる: ブロック(8 セル)× 16 を、起こす刻みだけ評価する場合と全部を毎刻み評価する場合が、毎刻みビット一致(2^32 刻みをまたぐ・外から熱を入れる)
- [x] 何年分: 遅い熱分解を起こす刻みだけで 10 年(約 1.9e10 刻み。64bit の刻み)進め、Σ f × 刻み の ±5σ
- [x] 今の場面を待ちの丸めで: 閉じた木箱 36,000 刻みの保存則・490 K の遅い熱分解 ±5σ・規則の並びで結果が同じ・酸素不足の火の取り合いの基準(reaction_contention)
- [x] 今のテストは全部そのまま通る(世界はまだ今の丸め)

## 研究の打ち切り条件(代案に移る条件)
- 偏りが ±5σ を外れ、原因が「古い乱数・新しい f」(速さが変わったのに引き直さない)なら、速さが変わった刻みで必ず引き直す
  (設計上、速さはブロックが変わった時しか変わらない。魔法のパッチ・表の差し替えは「変わった」とみなす)。
- それでも外れれば、Anderson の修正次反応法(MNRM。規則ごとの内部時刻を状態に持つ。Anderson 2007)へ。
- 眠っている所の費用(T-0115 で GPU を測る)が静かな場面の固定費(docs/perf.md の 0.08〜0.12 ms)を明らかに超えれば、
  見出しを全部なめる方式から階層タイマーホイール(Varghese & Lauck 1987)か木の上の最小値(InterlockedMin)へ(T-0116)。
- 出典: Gillespie 1977 https://doi.org/10.1021/j100540a008 / Gibson & Bruck 2000 https://doi.org/10.1021/jp993732q /
  Anderson 2007 https://arxiv.org/abs/0708.0370 / Varghese & Lauck 1987 https://www.cs.columbia.edu/~nahum/w6998/papers/sosp87-timing-wheels.pdf

## 判断待ち(今は止めない。早送りを作るチケットで要る)
- 問い: 何年分を早送りする間、プレイヤーの近く(観察の枠 = 細部まで毎刻み動かしている所。D-403)をどう扱うか。世界の結果はどの案でも同じ(観察は世界に返さない)。
  - A 早送りの間は観察の枠を止め、世界(起きている所と起こす刻み)だけ進める。戻ったら粗い状態から細部を作り直す。
    遊び: 何年でも数秒〜数分で飛ばせ、石の風化・結晶の成長を「結果」として見られる。早送り中に炎の揺らぎのような細部は見えない(粗い表示かタイムラプス)。
  - B 観察の枠も毎刻み刻む。遊び: 早送り中も細部が見え続けるが、速さは 1 刻みの費用で頭打ち(数十倍程度)で、何年分は事実上できない。
  - C 倍率で切り替える(低い倍率は B、高い倍率は A)。遊び: 数分〜数時間の観察は細部つき、何年分は結果だけ。
  - おすすめ: C(D-429 の「何年もかかる変化も早送りで見られる」と、近くの実験を細部つきで早回しする遊びの両方が残る)。

## メモ・参考
- 費用: 端数のある規則ごとに log2 を 2 回(FxLog2U64 = 64bit の掛け算の上位 32 回ずつ)。毎刻み変わるセルでも評価のたびに計算する(T-0115 で GPU を測る。
  重ければ、待ちを見出しかセルに持って変わった時だけ引く・整数部のある規則は経過 1 の判定だけ、など)。
- 待ちが約 2^61 刻み(約 12 億年)を超える引きは「起きない」(割り算を 64bit に収めるため)。
