# T-1016 物の箱の熱の口をエンジンへ(対の面の伝導・気体の混ざり・放射・光・対の端数)と、箱の細かさの収束(T-0991 から分けた)

- Status: Todo(物のボクセル T-0821 の後。土台の共通部分に掛かるので司令塔が配る)
- 種類: 工学 + 研究(箱の細かさの収束)
- PC: 必須
- 見積もり: チャット 2 回分
- マイルストーン: 列 4(物の箱の最小の形 S45 の後)
- 設計: docs/design/20 §12.4 / 決定: ADR-0434(仮)・ADR-0360

## 目的(1〜2 行)
T-0991 の試作(tests/object_heat_test.cpp の試験の中の仮の口)を、物のボクセルと当てる段の共有 .hlsli に移し、CPU と GPU で同じ関数にする。
箱 3.9 mm で燃え続けなかった理由を調べ、箱の細かさの選び方(N1)を決める。

## 完了条件
- [ ] 対の面の口(膜の長さ = 細かい側の半分): 伝導・気体の混ざり(運ぶ気体のエネルギー込み)・放射(物の表面の広さ)・光(物の表面が遮る)。共有 .hlsli・当てる段で
- [ ] 対の端数(物ごと・量ごと。真実・ハッシュとセーブ)・保存の検査を「セル + 物 + 対の端数 − 帳簿」に
- [ ] 膜の温度の形(ADR-0434 問い 1 の答え次第)
- [ ] 箱の細かさの収束: 箱 15.6 / 7.8 / 3.9 / 1.95 mm で燃え始めと燃え続けた時間を並べる。3.9 mm で消える理由(物の中の伝導の面の値・熱分解の水蒸気の濃さ・光の配り方のどれか)を確かめる。
      打ち切り: 2 本で 7.8 mm と 3.9 mm が ±20 % に揃わなければ、箱の細かさを「当たる熱の流れの升(2 mm)」に合わせる案と、細かさごとの差を受け入れる案を並べて司令塔へ
- [ ] T-0991 の試験(object_heat)を共有の口で通す・0.5 m と 0.25 m で同じ・CPU と GPU でビット一致
- [ ] release 警告 0・archmap --check

## 申し送り(T-0991)
- 試験の表の伝導率の倍率(units.luau)は物の箱では外す(倍率のままだと膜の伝導が 5000 倍)。倍率を表に残すかは M3 の見直しと一緒に。
- 物のボクセルの中の気体の体積(紙の体積を引く)と占める体積(T-0820)の分け方は未定。
