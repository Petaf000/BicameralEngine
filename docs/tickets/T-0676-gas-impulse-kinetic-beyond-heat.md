# T-0676 燃える木箱の熱が負のセル: 力積が熱より大きな運動のエネルギーを足す根っこ

- Status: Done(根っこ = 頭打ちの積の 64bit の溢れ。小刻みの中の一時の負の熱は T-0691 へ分けた)
- 種類: 研究(→ 工学)
- PC: 必須
- 見積もり: チャット 1 回分
- マイルストーン: ROADMAP の T-0210(気体)。T-0647 から分けた
- 設計: docs/design/07-transport.md §2 / 決定: ADR-0286・ADR-0292

## 目的(1〜2 行)
T-0646・T-0647 の後も、仮の世界の燃える木箱(probe_gas_test の 2)で熱が負のセルが 9 残る(最も負 −628 kJ。8 の露 10 /s の木箱は 2 セル・−158 MJ)。出ていく割合の上限では
直らないことを T-0647 で確かめた(抑えると悪くなる)。力積が熱より大きな運動のエネルギーを足す根っこを特定して一つの芯で直し、
probe_gas_test の「熱が負のセル」を EXPECT(0)に上げる。

## 完了条件(チェックできる形で)
- [x] 負になる最初の刻みで、そのセルと隣の 空き(openQ16)・圧力 p̃・力積・速さ・質量・熱を記録する(probe_gas の CPU に一時の診断)
- [x] 根っこを特定(候補は下)して直す。CPU と GPU のビット一致・毎刻みの保存
- [x] probe_gas_test の 2・8 の「熱が負のセル」を EXPECT(0)に(6 の地球の空気の木箱も)

## 調べる順と打ち切り条件
1. 空きの小さいセル(木箱の中・縁。圧力 = n R T ÷ (V × 空き)、下限 1/256)の圧力が力積に効いていないか(T-0593)
2. 実効の音速の頭打ち(温度で比べる。ADR-0292)が軽い・熱い気体で足りず、1 小刻みの力積が不安定になっていないか(T-0658 と同じ根っこなら T-0658 で)
3. 力積の後の運動のエネルギーが「熱 + 流れ込む押し出す仕事」を超える量(T-0647 の案 A・B の記録: 木箱の真上の柱 x31〜32・y0〜7・z27〜34、
   1〜5.6 mol に −2.5〜−81 MJ)
- 打ち切り: 3 つを調べて根っこが特定できなければ、「運動のエネルギーは熱 + 押し出す仕事を超えない」速さの上限(両側に同じ力積で運動量を保つ)を
  案としてユーザーに出す(作り手から見た違い: 強い爆発の先端の速さが頭打ちになる)。

## 調べたこと(2026-10-17。probe_gas_test の fire・dew。CPU・release。Substep の終わりに一時の診断を入れて、小刻みの初め・力積の後・移した後の熱を比べた)
- **根っこ**: 頭打ち p̃ ← p̃ × T_頭 ÷ T を `FxDivS64(FxMulShiftS64(p̃, T_頭, 0), T)` で作っていた。`FxMulShiftS64(…, 0)` は 128bit の積の下 64bit だけを返すので、
  p̃ × T_頭(既定 T_頭 ≈ 372 K = 372000 mK)が 2^63 を超える **p̃ ≳ 25 MPa** で符号が反転する。燃える木箱の燃えているセルは 1 刻み目で
  気体 4.55 kg・2598 K・本物の圧力 44 MPa になり、p̃ が −0.94 MPa(本当は +6.16 MPa)= 周りを吸い込む負の圧力になっていた。
  隣のセル(空気 146 g)は木箱の側へ引かれ(1 小刻みで約 550 m/s)、力積の運動のエネルギー 22 kJ を熱 32 kJ から払い、さらに 71% が木箱へ流れて
  押し出す仕事(小刻みの初めの温度で数える)を持ち出し、残りの熱が負(−6.4 kJ → 刻みの終わりに −15 MJ まで)。前任の見立て
  「力積が熱より大きな運動のエネルギーを足す」の元がこれ。候補の 1(空きの小さいセル)・2(頭打ちの比べ方 = T-0658)ではなかった。
- **直し**(一つの芯): `fixed.hlsli` に `FxMulDivS64(a, numerator, denominator)`(積を 128bit のまま割る。商が 64bit に収まれば溢れない)を足し、
  頭打ちの 3 か所(CPU の箱 `ScalePressure`・木 `DeriveGasTreeCell`・GPU `gas_cell.hlsli` の導く値。GPU の木も同じ関数)をそれで書いた。
  溢れない所の値はビット単位で前と同じ(0 方向の切り捨て)。gas_reference_test に「40 倍の空気・2600 K(35 MPa)の p̃ が正で式と合う」を足した。
- 測り直し(このブランチ = t-0647 + main。直す前 → 直した後):
  - 燃える木箱 2 秒: 熱が負のセル **12(最も負 −15.2 MJ)→ 0**・CO2 の 5% 以上がある最も高い層 2(EXPECT が落ちていた)→ 23・熱の重心 11973 → 10459・CO2 の重心 10807 → 8948
  - 露 10・100 /s の木箱・湯気の塊(240 刻み): どれも熱が負のセル 0・保存 yes・運動量 yes
- **残り(T-0691 へ)**: 溢れを直しても、強い爆発の 1 小刻みの中では熱が一時的に負になる(刻みの終わりには 0。診断で見た)。
  木箱のセル(44 MPa、頭打ちの p̃ 6.2 MPa)が隣の空気 146 g を 1 小刻みで約 3600 m/s に押す(運動のエネルギー 約 940 kJ ≫ 熱 32 kJ。
  クーラン数で約 5 = 陽解法の安定の条件の外)。熱は「頭打ちが温度だけを抑え、密度 30 倍のぶんの圧力は抑えない」ので守られない。
  式の形で 0 未満にならないことを保証するのは、作り手から見た結果を変えるので案を出して T-0691 で決める。
- 運転メモ: probe_gas_test の fire は 35 秒・dew は約 3 分(release)。
