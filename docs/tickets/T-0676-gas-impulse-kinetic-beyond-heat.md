# T-0676 燃える木箱の熱が負のセル: 力積が熱より大きな運動のエネルギーを足す根っこ

- Status: Todo
- 種類: 研究(→ 工学)
- PC: 必須
- 見積もり: チャット 1 回分
- マイルストーン: ROADMAP の T-0210(気体)。T-0647 から分けた
- 設計: docs/design/07-transport.md §2 / 決定: ADR-0286・ADR-0292

## 目的(1〜2 行)
T-0646・T-0647 の後も、仮の世界の燃える木箱(probe_gas_test の 2)で熱が負のセルが 9 残る(最も負 −628 kJ。8 の露 10 /s の木箱は 2 セル・−158 MJ)。出ていく割合の上限では
直らないことを T-0647 で確かめた(抑えると悪くなる)。力積が熱より大きな運動のエネルギーを足す根っこを特定して一つの芯で直し、
probe_gas_test の「熱が負のセル」を EXPECT(0)に上げる。

## 完了条件(チェックできる形で)
- [ ] 負になる最初の刻みで、そのセルと隣の 空き(openQ16)・圧力 p̃・力積・速さ・質量・熱を記録する(probe_gas の CPU に一時の診断)
- [ ] 根っこを特定(候補は下)して直す。CPU と GPU のビット一致・毎刻みの保存
- [ ] probe_gas_test の 2・8 の「熱が負のセル」を EXPECT(0)に

## 調べる順と打ち切り条件
1. 空きの小さいセル(木箱の中・縁。圧力 = n R T ÷ (V × 空き)、下限 1/256)の圧力が力積に効いていないか(T-0593)
2. 実効の音速の頭打ち(温度で比べる。ADR-0292)が軽い・熱い気体で足りず、1 小刻みの力積が不安定になっていないか(T-0658 と同じ根っこなら T-0658 で)
3. 力積の後の運動のエネルギーが「熱 + 流れ込む押し出す仕事」を超える量(T-0647 の案 A・B の記録: 木箱の真上の柱 x31〜32・y0〜7・z27〜34、
   1〜5.6 mol に −2.5〜−81 MJ)
- 打ち切り: 3 つを調べて根っこが特定できなければ、「運動のエネルギーは熱 + 押し出す仕事を超えない」速さの上限(両側に同じ力積で運動量を保つ)を
  案としてユーザーに出す(作り手から見た違い: 強い爆発の先端の速さが頭打ちになる)。
