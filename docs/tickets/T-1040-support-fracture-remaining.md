## 目的(1〜2 行)
22 §6 の R-B2 の合格のうち、T-0872・T-1042 で測っていない残り 3 つを、決まった割れの判定の形で測る。

## 完了条件
- [ ] 45° 傾けた梁が真っすぐな梁と同じ強さ(±10 %)。区間(ℓ)は割れの面に沿って並べるので、斜めの割れの面での区間の作り方も確かめる
- [ ] 石のアーチが同じ石の真っすぐな梁より強い(アーチは押しで運ぶ)
- [ ] 割れた後の瓦礫が粒の崩れる角度で止まる(瓦礫の φ の既定 = 粒の崩れる角度。強さ 2 つから出る φ は 65° で急すぎる。T-0872 の記録)。物の物理へ渡す R-O1 の後かもしれない

## 研究の打ち切り条件
判定の形を変えずに 45° の梁が ±10 % に入らなければ、区間を割れの面の向きに沿って取る形を 1 本試し、それでも駄目なら記録して司令塔へ。
