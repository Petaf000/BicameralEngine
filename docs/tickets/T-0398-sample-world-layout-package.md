## メモ・参考
- 洗い出しの一覧は T-0371 のチケット。合わせた表の版(TableVersion)は全部の分類を含むので、反応表と同じ読み込みに新しい分類を足すと
  表の版が変わる。世界の組み立ては別の読み込み(または版に入れない分類)にするかをここで決める。
