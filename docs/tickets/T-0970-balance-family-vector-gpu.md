## 目的
T-0919 の SolveEquilibriumBlocks(CPU)を GPU の Compute に載せ、CPU とビット一致させる。支えの GPU 版(T-0946)の下地。

## 完了条件
- [x] 式を shaders/common/ の hlsli に移し CPU と共有(節ごとの LDLᵀ・ブロックの残差・延ばし方と縮約。決まった数の回し + FX_UNROLL。書き換えた構造体の配列を動的な添字で読まない〔T-0397〕)
- [x] 8 色を色ごとの Dispatch で。Galerkin の粗い段(Pᵀ K P の 128bit の和)は CPU で作るか GPU で作るかを決める(GPU で作る。仮。ADR-0422)

## 仮(ユーザー未確認)
- 粗い段の係数(Galerkin)と節の LDLᵀ は GPU が作る(形だけ CPU から写す)。CPU で作って写す形より、係数が変わる刻みで写しが少ない(ADR-0422 の代案)。
- 段 0 の係数・右辺の項は今は CPU の系を写す(支えは今 CPU の試作。法則が GPU で段 0 を組む形は T-0981)。
- k はシェーダーの定数(1・2・3・6 を用意)。4・5 は要るまで作らない。
