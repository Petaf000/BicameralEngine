## 目的(1〜2 行)
T-0717 の液体は外から入った運動量と段の外の位置のエネルギーを世界の欄(`liquid.ledger_momentum`・`liquid.ledger_energy`)に仮置きしている。
これを世界の帳簿の 1 型(列 = 量 × 理由)へ移し、`ComputeConservedTotals`(Σ 登録した保存量 − 帳簿 = 一定の 1 関数)が液体の世界でも釣り合うようにする。

## 完了条件(チェックできる形で)
- [x] 運動量の 3 列(`liquid.momentum` の保存量の列)に、壁・重さ・摩擦・行き場なし・速さの上限・段の外で減った分を理由ごとに(正 → 出・負 → 入。WlEnergyEntry と同じ)
- [x] 位置と運動のエネルギーの扱いを決める: 欄の列(`liquid.potential_energy`・`liquid.kinetic_energy`)に「熱になった分」を出入りとして書くか、
      エネルギーの列(0)に合わせるか(作り手から見た違い: 保存の検査で「エネルギー」が 1 つの数で見えるか、内訳が欄ごとに見えるか)。おすすめは前者(欄の列の出入り = セルの熱の入り)
- [x] 世界の欄 `liquid.ledger_*` を消す。`MultiresLiquid::Ledger` は帳簿の列から読む
- [x] multires_liquid_test: 仮の世界の帳簿(ProbeLiquidLedger)と列の和が毎刻み同じ・`ComputeConservedTotals` が毎刻み一定
- [x] release のビルド 警告 0・archmap --check

## メモ・参考
- T-0717 の今の約束: 欄は保存量の印(SF_FLAG_CONSERVED)が付いているので列はもうある(T-0762 が登録から作る)が、液体はまだ書いていない
  = `ComputeConservedTotals` の欄の和は液体が動くと変わる(この間は液体の世界でこの検査を使わない)。
- 理由の列が足りなければ(行き場なし・速さの上限は今の WL_REASON_* に無いかも)、足すのは T-0714(面の帳簿)とそろえる。

## 作業ログ(チャットごとに 3〜5 行、新しいものを下に)

  位置のエネルギーの列: 段の外で現れた分 = 段の外の質量の変化の入・熱になった分 = 重さの仕事の出(同じ量をエネルギーの列の入)。運動のエネルギーの列(軸ごと): 熱になった分 =
  物理の熱の出(同じ量をエネルギーの列の入)。理由を 3 つ足した(摩擦・行き場なし・段の外の質量の変化。WL_REASON_COUNT 8 → 11 = 帳簿は 1.375 倍)。
