## 目的
T-0871 の格子の梁(①')を 3 次元(節 = 変位 3 + 回り 3・面ごとに梁)にし、アーチ・洞窟の天井を整数で測る。0.5 m と 2 m(と 0.25 m)で同じか。表面の引きの応力を面の力から出す口(R-B2 が読む)。

## 完了条件
- [ ] 3 次元の格子の梁(奥行の向きの面と回り 3)。T-0871 の 2 次元の場面で同じ答え(奥行 1 セル)
- [ ] アーチ・洞窟の天井・片持ち梁を 0.25 / 0.5 / 2 m で、細かく刻んだ連続体の基準と ±5 %(アーチが 0.25 m で入らなければ ② + 非適合モード H11 を 2 本目に)
- [ ] 帳簿(力と回りの釣り合い)が毎刻み厳密・決定的
- [ ] 表面の引きの応力(N/A ± 6M/A·Δx)を面の力から出す関数と、梁の式との比べ
- [ ] 欄に触るなら LoadNestField / FieldPageValues(疎な頁 T-0921)
