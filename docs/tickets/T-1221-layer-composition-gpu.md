## 目的(1〜2 行)
GPU の世界(gpu_multires)でも物質ごとの層の量を持ち、CPU リファレンス(T-1210・T-1220)とビット単位で同じにする。

## 完了条件(チェックできる形で)
- [ ] 層の頁のバッファ(層のある頁だけ。疎。欄の頁と同じ作り)を上げる・読む。頁を配ったら層の頁を空に
- [ ] 成分の量を書く GPU のカーネル(反応の段・運ぶ・相変化・細かくする / 粗くする・畳む)で付け替え。
      おすすめ(T-1210 の「土台に足りないもの 3」): 成分の量を変える段の後に「層を合わせる」段を 1 つ(層の頁に物質も持ち、層 = min(層, 今の量))。
      CPU の 1 段の中で 1 セルを 2 回書く道があるかを先に数える(あれば CPU も段の境で合わせる形に寄せる)
- [ ] 刻みの段を足したら RecordWideRetry。シミュの HLSL の約束(浮動小数点なし・64bit の引き算と比べを並べない・動的な添字で構造体の配列を読まない)
- [ ] 試験: gpu_multires_* に層のある場面(CPU とビット一致)・層の無い場面はビット単位で今と同じ・WARP も
- [ ] 書く道の時間と層の頁のバイト(docs/perf.md。日付と GPU)

## メモ・参考
- GPU が g_cells を直接書く所は約 50 か所(shaders/sim の multires_graph・multires_tree・multires_wait_step・multires_wide_step・multires_conduct・implicit_conduct・
  object_heat*・lab_box・reaction_cells。2026-10-26 の grep)。エネルギーだけを書く所は付け替え不要。
- T-1220 の洗い出し(T-1220 のチケットの「2 回以上書く道」): CPU は反応・気体の段・液体の段でそれぞれ 1 セル 1 回書き、段ごとに付け替える。
  GPU の「層を合わせる段」は刻みの最後に 1 回ではなく、この段の境ごとに置くとビット一致する(反応で減って気体で増える物質で分かれるため)。
- T-1220 の CPU の限り(ここで直す): GPU から読んだ溢れの領域は層を消す(gpu_multires.cpp)・溢れを使う世界の一様の値の層は読み戻しで結び直さない・
  層の頁・一様の枠の層(MultiresCellStore::uniformLayers)・溢れの層(MultiresOverflowArea::layers)を GPU へ上げる形。ADR-0489。

## 入れた形(1 段目。2026-10-29 wt3)
- 置き場(shaders/common/multires_layers.hlsli。HLSL と C++ で同じ並び): `GpuMultiresOptions::layerPages` 頁ぶん。層の頁ごとに見出し 2 語(セルの頁・持ち主の枠)+
  [512 セル × 8 組 × 3 語(物質・層の下位・上位)](1 頁 48 KiB)。層は成分の並びの位置ではなく**物質で結ぶ**(層の頁に物質も持つ。T-1210 の「土台に足りないもの 3」のおすすめ)。
  layerPages = 0(既定)は今と同じ(パイプラインもバッファも作らない)。
- 層を合わせる段(shaders/sim/multires_layers.hlsl の ReconcileLayers。1 スレッド = セル 1 つ): 層 = min(前の層, 今のセルのその物質の量)(無ければ 0)。
  持ち主の枠がもうその頁を持っていなければ層は 0(頁を返した・別の枠に配った)。64bit の比べは 32bit の 2 つで(引き算なし)・組は決まった数の回し。
  ルート署名は 64/64 語なので、層の置き場は外のバッファの口 u4 に結ぶ(覗き窓と同じ口。段の間だけ結び替えて戻す)。
- 置く所: RecordStep(全部を刻む・伝導つき)と RecordStepActive の最後に 1 回。理由: T-1220 の洗い出しのとおり CPU は刻みの段の中で 1 セルを 1 回書く
  (伝導はエネルギーだけ・反応は 1 回)。GPU の刻みも「全部を刻む段」と「頁に広げて刻む段」は別のセルを書くので、段の後に 1 回でビット一致する。
  GPU の世界(gpu_multires)には気体・液体の段が無い(CPU の multires_gas・multires_liquid の段は GPU に未実装)ので、その段の後の合わせは段が GPU に来た時に置く。
- 写す・読み戻す(engine/src/sim/gpu_multires_layers.cpp): RecordUpload が層のある頁を頁の番号の順に層の頁へ詰める。Read は CPU の頁の層を全部消してから GPU の層を写す
  (GPU の層が真実。CPU の前の層に頼らない)。
- 限り(T-1240 へ): 要求の処理(細かくする・粗くする・畳む・頁に広げる)は層を配らない。一様の枠の層・溢れを使う世界の層は写さない(RecordUpload が false とログ)。
  層の頁は GPU で新しく取れない(写す時に詰めるだけ)。
- ADR-0489 の 3(仮 (a))の答えで変わる所は CPU の付け替えと同じで、GPU の段は「層 = min(前の層, 量)」だけを持つので、(b) になっても段は変わらない
  (変わるのは「層の並びが無い」を表す印の持ち方。値で切り替える所は無い)。
