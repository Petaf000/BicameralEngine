## 目的(1〜2 行)
T-0104 の CPU リファレンス(multires_activity.cpp の FoldQuietPages の許容差つき)を GPU の TreeFoldCheck → TreeFold に載せ、毎刻み CPU とビット一致させる。

## 完了条件(チェックできる形で)
- [ ] 許容差をルート定数か定数バッファで渡す(ルート署名は残り 2 語。足りなければ既存の定数に詰める)
- [ ] TreeFoldCheck: ちょうど静かになったブロックの集計(MrFoldStats。1 グループ = 1 ブロック。ウェーブで最小・最大・和を縮約するか 1 スレッドで 512 セル)
- [ ] TreeFold(1 グループ・枠の順): 平均の値を書き、余りと端数の枠の端数を帳簿へ(繰り上げつき。CPU の AddLedgerBits と同じ順)・端数の枠を空きへ
- [ ] 鎖の場面(--residue と同じく畳まれるまで)と CheckNearFoldUnit 相当で HW・WARP が CPU と毎刻みビット一致。許容差なしなら今までと同じ

## メモ・参考
- 帳簿の足し算は他の段では atomic(桁あふれを繰り上げない)。畳む段は 1 グループで順に足すので繰り上げられる。
