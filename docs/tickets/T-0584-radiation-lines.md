## 目的(1〜2 行)
セルの間の見通し(途中のセルが遮る)を決定的な光線で求め、T-0583 の対の交換に渡す。対の交換の保存と坂を下ることを保ったまま、
**受け手が複数の送り手から受ける時も、1 つのセルの分け前の合計が 1 を超えない(行き過ぎない)**ことを、形で保証する。CPU・レベル 0 の一様な格子。

## 完了条件(チェックできる形で)
- [x] 平行な板(黒)の見え方の割合が解析解の ±10%(60 刻みの平均)
- [x] 壁の陰(完全に遮る壁の向こう)の受け手との対はちょうど 0
- [x] 保存がビット単位(エネルギーの変化の合計 0)・対の並びによらない(逆順でも同じ)
- [x] 受け手の分け前: どのセルも、その刻みの対の分け前の合計 ≤ 65536(乱数の世界・多数の刻みで全部のセルを数える)
- [x] 受け手の温度が送り手を超えない(熱い板と熱容量の小さい膜)
- [x] release のビルド(警告 0)・archmap --check

## 研究の打ち切り条件(先に書く。T-0028 の (a)〜(d)。D-411)
- (a) **揺れ**: 同じ初めの世界で向きの回し方(種)を変えた時、向こう岸の着火の時刻が ±10% 以上ばらつく(T-0585 で測る)→ 本数を 2 倍
  (32 → 64 → 128)→ 見つけた対を M 刻み覚える → それでも ±10% なら、レベル 0 の 16 m の中は対の一覧をベイクする方式へ移る。
- (b) **重さ**: CPU リファレンスが 64³ の場面で 1 刻み 50 ms を超えたら、場面の試験は 32³ に縮める。GPU の推定が 1 ms/刻みを超える →
  送る側を 2×2×2 でまとめる → 4 刻みに 1 回 → 遠くは多重解像度の粗い側だけ(T-0586 で測る)。
- (c) **受け手の分け前**: 決まった向きの組で、受け手 1 つに届く対の分け前の合計 ≤ 1 を示す形がこのチケットの 2 時間で見つからなければ、
  2 回に分ける上限(受け手ごとに入る係数の合計を数え、超えた分を比で縮める。順番によらない)に移る(1 段増える)。
- (d) **全体**: T-0584〜T-0585 の 4 時間で、草原の場面で「川の幅(か火の強さ)で越える・越えないが変わる」がどの値でも作れなければ、
  放射は止めて報告する。次は気体(T-0210・T-0186)。

## 決めた形(仮。ADR-0262)
- **平行な線の束**: 刻みごとに 1 組 32 本の向き(半球を等しい立体角に分けた Fibonacci の点。16 組をベイク: `shaders/common/radiation_directions.hlsli`・
  道具 `tools/radiation_directions/generate.py`)。向きごとに、一番大きい軸の面の上の間隔 2 セル(+ 2^-16)の格子から線を出す。組と格子のずれは R6 のハッシュ。
- **分け前の保証**: 板の中で線が掃く幅 1 + |D_b/D_a| ≤ 2 < 間隔なので、1 つの向きでどのセルも線 1 本。線の上の片側の Σ α_b τ_ab ≤ 1。
  対の分け前 = α_a α_b τ_ab ÷ 64 → どのセルも合計 ≤ 1。事前調査の「熱いセルから光線」(送り手ごとに線がずれ、受け手に同じ向きから何本も届く)を、
  線を世界の側に置く形に変えたのが芯。2 回に分ける上限は要らない。
- 整数の DDA(板ごとに、2 つの境を越える割合を掛け算で比べる)・途中の透過 Q16・1/16 未満か 16 m で閉じる。対は線が 1 回だけ見つける。
- コード: `engine/src/sim/radiation_lines.{h,cpp}`(CPU。GPU の T-0586 では線 1 本 = 1 スレッドで、線を歩く部分を hlsli に移す)。

## 測った値(試験 radiation_lines・2026-10-15・release)
- 平行な板 16×16 セル(黒)の見え方の割合(60 刻みの平均): 隙間 2 セル 0.7923(解析解 0.7900・+0.3%)/ 4 セル 0.6345(0.6320・+0.4%)/ 8 セル 0.4180(0.4153・+0.7%)
- 壁の陰: 送り手と受け手の対 0(壁へは届く)。分け前の合計の最大 53,132 / 65,536(24³ の乱数の世界 6 つ × 8 刻み・対 1,663 万個)
- 熱い板(1500 K)の前の小さい膜(2 mJ/K)は最高 1121 K で、板を超えない。600 刻みで保存がビット単位
