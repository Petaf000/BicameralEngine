# T-1077 物の熱を世界の刻みに入れる(多重解像度のセルの口・起きている物の一覧で眠らせる・物のボクセル T-0821 の置き場)(T-1064 から分けた)

- PC: 必須
- 見積もり: チャット 2 回分

- 設計: docs/design/20 §12.2・§12.4 / 決定: ADR-0434・ADR-0451(仮)・ADR-0360

## 目的(1〜2 行)
T-1064 の段は囲むセルを平らな並びで持つ。世界のセル(MultiresCellStore の口)を読み書きし、世界の刻みの中の位置(当てる段の後・反応の前)に入れる。
眠っている物(冷えた木・紙の山)を回さない(起きている物の一覧で Dispatch。費用 0)。

## 完了条件
- [ ] 囲むセルを MultiresCellStore の口で読む・当てる(物ごとの範囲は囲むセルの順)
- [ ] 起きている物の一覧(眠る = 1 刻みで受け渡しが全部 0 かつ反応が待ちで起きない。起こす = 囲むセルが変わった・光が当たった)。眠っている物 10,000 個で費用 0 を測る
- [ ] 帳簿(理由「物との受け渡し」)と、対の端数をハッシュとセーブへ
