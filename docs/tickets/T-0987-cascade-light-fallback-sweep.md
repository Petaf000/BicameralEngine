## 目的
T-0584 の平行な線の束(sim/radiation_lines)を基に、23 §2 の帯と物質の光の値・面から放つ量(RcFaceEmission)・照り返しの持ち越しを載せ、

## 完了条件
- [ ] 向きの組を刻みごとに R6 のハッシュで回す(16 組に決めない)・16 m の上限を外す(D-572)
- [ ] 保存(ビット単位)・決定的(順によらない・2 回で同じ)・壁の陰(ちょうど 0)・解析解(平行な黒い板 ±10 %)

- [ ] 坂を下る: 同じ温度の閉じた箱で正味の出入りが 0(対の流れは温度の差に比例するので構造で 0 のはず)
- [ ] 光線(線)の本数と CPU の費用の記録(GPU と 1 ms の判定は T-0959)
- [ ] 照り返し: 対の形で 1 刻み遅れて返す形を載せられるか(載せられなければ形の案をチケットに)

## メモ
- 坂を下るの芯: 対ごとに 1 つの整数(RadiationPairFlow)。距離ごとの段では「放った量を配る」形だったので、向きの偏りが正味の流れになった(T-0958・T-0972)。
- 試験の中の仮の口で測る(吸った・放った量をセルのエネルギーへ当てる段・帳簿の理由・刻みの順は土台の仕事)。
