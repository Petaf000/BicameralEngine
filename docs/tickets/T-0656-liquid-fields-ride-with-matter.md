# T-0656 液体の区画で、反応・相変化が液体の質量を変える所のエネルギーと運動量(T-0648 の前半も)

- Status: Done(ADR-0286 は Proposed のまま。液体の版を追記)
- 種類: 工学(不具合)
- PC: 必須
- 見積もり: チャット 1 回分
- マイルストーン: ROADMAP の T-0027(水)・T-0611(相変化)・⑤ の場面
- 設計: docs/design/07-transport.md §3(面の運動量は液体に付く)/ 決定: ADR-0286(気体の T-0646 と同じ決まり)・ADR-0276・ADR-0266・D-465

## 目的(1〜2 行)
T-0623(釣り合いの規則)の枝の probe_phase で、霧・蒸発・凍る・溶けるで液体の質量が毎刻み変わると保存が崩れた。液体の側の根っこを
T-0646(気体)と同じ一つの決まり「区画の欄は物質に付き、段の外で物質の量が変わったら欄を合わせ直す」で直し、CPU と GPU で確かめる。

## 完了条件(チェックできる形で)
- [x] 根っこ: 区画の外の段で液体が減っても面の運動量がそのまま残り、速さと運動のエネルギーが増えて、その分を熱から取っていた(熱が負になり得る)
- [x] CPU(probe_liquid.cpp の FollowMassChange): 前の刻みの終わりの質量(m_mass)を持ち、面の両側の質量の和が減ったら速さを保つ(減った液体の運動量は帳簿へ)・増えたら運動量を保つ
- [x] GPU(probe_liquid_tick.hlsl の LiquidForces の初め。massOffset を持ち越す)が CPU と毎刻みビット一致(液体の状態・質量・帳簿のハッシュも)
- [x] probe_liquid_test の 7(流れている水を半分にする・2 倍に戻す): 毎刻みエネルギーと運動量がビット単位で一定・半分で運動量の半分が帳簿へ・運動のエネルギーは増えない
- [x] gpu_probe_liquid(HW・WARP)に「ダムの水が押し寄せながら湯気になる」(試験の蒸発の規則 毎秒 5%)
- [x] probe_liquid・probe_phase(release)・release のビルド(警告 0)・archmap --check

## 調べたこと(2026-10-17)
- 液体のエネルギーの合計(セル + 位置 + 運動 − 帳簿)は、前から作りでビット単位に保存していた(運動のエネルギーを今の質量から計算し直した差を熱にする)。
  崩れて見えたのは probe_phase の合計が液体の位置・運動・帳簿を数えていなかったため(T-0646 で直った)。
- ただし中身が違っていた: 液体が減っても面の運動量が残るので、速さ = 運動量 ÷ 質量が上がり、運動のエネルギー p²/2m が増えた分をセルの熱から取っていた
  (質量が 0 に近い面ほど大きい。速さの上限で頭打ち)。試験 7 で水を半分にすると、直す前は運動のエネルギーが 2 倍になるはずのところ、
  直した後は 10,193,449 → 5,141,944 mJ(≒ 半分)・運動量 70.5e9 → 35.1e9(帳簿へ −35.2e9)・熱 +5.17 MJ。2 倍に戻すと帳簿へ 0・運動のエネルギー 3.22 → 1.30 MJ。
- T-0623 の枝の氷の場面(240 刻みで +44.7 kJ)は、T-0646 の probe_phase の合計の直し(液体の欄を数える)と同じ根に見える(未確認: probe_phase_test が
  両方の枝で大きく変わっているので、この枝では重ねて走らせなかった)。T-0623 を main(T-0646・T-0656 の後)へ載せ直す時に、毎刻みの保存の試験で確かめる。
  液体を重ねた湯気の場面の +1.8e16 mJ(回り込み)も同じ時に見る。
- 物質の無いセルに熱を入れる所: 液体の面の運動のエネルギーの差は両側のセルへ半分ずつ入る。両側とも物質が無い(真空・空気の無い世界)と
  物質の無いセルにエネルギーが残り得る(普段は空気があるので起きない。probe_phase の物質の無いセルの検査は通る)。気にするなら T-0674。

## 判断待ち(仮で進めたもの)
1. **ADR-0286 の液体の版**(Proposed のまま追記)。作り手から見た違い: 流れている水が蒸発・凍る・反応で減っても、残りの水の速さは変わらない
   (前は減るほど速くなった)。増えた水(溶けた氷・露)は静止して現れ、まわりの流れを少し遅くする。おすすめ: このまま(数値の正しさで、作り手が選ぶものではない)。
2. **凝縮した露の運動量を液体へ渡すか(T-0648 の後半)は T-0673 に分けた**。作り手から見た違い: 渡すと、風に流された湯気が凝縮した露・雨が
   風の向きの勢いを持って液体になる(今は静止して現れ、勢いは帳簿へ)。気体の区画(セルの中心に運動量)と液体の区画(面に運動量)をつなぐので、
   運動量をセルの両側の面へ分け、気体の帳簿へ出ていた運動のエネルギーを液体の運動のエネルギーへ回す形になる。おすすめ: 雨・霧の場面(⑤)で
   要ると分かってから(今の場面では湯気の速さが小さく、見える違いは無い見込み。未測定)。
