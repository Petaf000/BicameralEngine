# T-1102 世界の中の光(RC): 閉じた箱の正味の出入りを構造で 0 にする(研究)

- Status: Doing(2 本目: CPU と GPU に入れ、ビット一致と 6 場面で構造で 0 を確かめた。**既定はまだ 0**〔空との交換の口が要る。下〕。ADR-0461)
- 種類: 研究
- PC: 必須
- マイルストーン: 列 4(R-R1)
- 設計: docs/design/23-radiation.md §3.3(坂を下る)/ 決定: ADR-0424 の 2・**ADR-0461(Proposed)**
- 試験: tests/cascade_light_swing_test.cpp の RecordBox(T-1100 と同じ実行)

## 目的
RC の閉じた箱で同じ温度でも正味の出入りが 15〜21 % 残る(T-0958・T-0972)。ADR-0424 の 2(対ごとに 1 つの整数の流れで構造で 0)を RC に入れられるか。

## 1 本目: 釣り合いとの差だけを運ぶ(CascadeParams::referenceMk。CPU だけ・既定 0)
熱で放つ量を「参照の温度 T_ref の黒体との差」σ(T⁴ − T_ref⁴)にする(負は 0 にした。下の残り)。同じ温度の閉じた箱では何も運ばないので**正味は構造で 0**。
| 場面(18³ の石の殻 1000 K + 塊・60 刻み) | 今の形: 壁のセルの正味の最大 / 熱を失った壁のセルの最大 | 差だけを運ぶ(T_ref = 1000 K) |
|---|---|---|
| 塊 1000 K(同じ温度) | 0.090 / 0.090 mK/刻み | **0.0000 / 0.0000**(ちょうど 0) |
| 塊 1100 K | 0.087 / **0.083**(冷たい壁が熱を失う) | 0.073 / **0.0000** |
| 塊 1010 K | 0.087 / **0.087** | 0.0064 / **0.0000** |
- 塊が失った量は両方で同じ(3,020 J/刻み・264〜270 J/刻み)。今の形は壁が得た和が 554 J(1100 K)・−2,150 J(1010 K)で、同じ温度の壁どうしの偏りが温度差の信号より大きい。
  差だけを運ぶ形は 2,968 J・260 J(残りは殻の一番外の層と外へ)。保存はどれもビット単位。

## 残り(入れる前に要るもの)
1. **参照の温度の決め方**: 箱の中の 1 つの値なら構造で 0。広い世界では場所で温度が違うので、ブロック(例 16³)ごとの参照の温度にし、
   ブロックどうしの「参照どうしの交換」σ(T_refA⁴ − T_refB⁴) を対称な対の流れ(ADR-0252)で運ぶ(粗い格子・構造で坂を下る)。
2. **参照より冷たいセル**: σ(T⁴ − T_ref⁴) が負(冷たい物は参照の光を吸う)。RC の量を符号付きにする(int64 の足し算は順によらない。袋の溜めは |量| で選ぶ)。共通の核 cascade_light.hlsli と GPU 版の変更。
3. **空・世界の外へ**: 参照の分も世界の外(空)へは逃げる。外へ抜ける割合を RC の「外へ出た」から参照の分に当てる形が要る(未確認)。
4. 照り返し: 差の光の照り返しは線形なので同じ形でよい(持ち越し D-619 も差だけになる)。

## 2 本目(2026-10-24 司令塔の判断で進めた): 正の側と負の側を CPU と GPU の両方へ
- 共通の核 cascade_light.hlsli に RcFaceEmissionRelative(参照の温度と負の側の印を 1 語に。64bit の差は符号付きで〔T-0185〕)。RcGpuParams の空き語を referenceWord に(大きさは同じ)。
- 正の側(自分 − 参照)と負の側(参照 − 自分)を、袋・持ち越しを別にした 2 つの組で運ぶ(StepCascadeLightRelative。GPU は同じ刻みを 2 回)。量は両方とも符号なしのまま(核の袋・溜め・持ち越しは変えていない)。
- **ビット一致**: gpu_cascade_light に「参照の温度との差・正の側 / 負の側」(32³ の石の地面 + 熱い床・参照 600 K・3 刻み)を足し、全部の場面で GPU と CPU がビット一致(31 刻み分)。
- **6 場面**(cascade_light_swing。release・ランナー・通過 1,236 秒・2026-10-24 01:42〜02:03。ほかの作業ツリーとの重なりは見ていない。参照の温度のセル〔殻の一番外の層を除く〕の正味。60 刻み):
| 場面 | 今の形: 正味の最大(失った / 得た) | 差だけを運ぶ: 正味の最大(失った / 得た) | 構造で守る形 |
|---|---|---|---|
| 閉じた箱 1000 K | 0.090(0.090 / 0.076)mK/刻み | **0.0000(0 / 0)** | どのセルもちょうど 0 |
| + 熱い塊 1100 K | 0.087(0.083 / 0.087) | 0.073(**0** / 0.073) | 参照の温度のセルは熱を失わない |
| + 熱い塊 1010 K | 0.087(0.087 / 0.076) | 0.0064(**0** / 0.0064) | 同じ |
| + 冷たい塊 900 K | 0.096(0.096 / 0.075) | 0.054(0.054 / **0**) | 参照の温度のセルは熱を得ない |
| 空へ開いた板 1000 K(空も参照の温度) | 0.695(0.695 / 0)= 世界の外を 0 K として冷える | **0.0000(0 / 0)** | どのセルもちょうど 0 |
| 空へ開いた板 + 熱い石 1100 K | 0.695(0.695 / 0.004) | 0.036(**0** / 0.036) | 失わない |
- 保存はどれもビット単位(側ごと)。
- 費用: 負の側は参照より冷たい物が全部放つ(参照 600 K・地面 293 K で 42 万本/刻み。正の側 7.7 万本)。参照は起きている所のいちばん多い温度(環境の温度)にし、負の側は冷たい少数だけにする。

## 既定に入れる前に残っているもの
1. **空との交換**(→ **T-1145 で口を作った**〔ADR-0474 案。CPU・GPU の掃きのビット一致・開けた地面と壁の解析〕。残りは RC の刻みの順へつなぐ所〔土台〕): 参照の分(εσT_ref⁴)の世界の外への出入りは RC が運ばなくなる。今の形は世界の外を 0 K として運んでいた(上の表で板が 0.695 mK/刻み 冷える)。
   参照の分の空との交換 εσ(T_ref⁴ − T_空⁴) × 空の見える割合 を、青空の上の境目(23 §3.2・天候の層)の口で入れる形が要る。空の見える割合は日の影の柱(R-R0)と同じ掃きで出せる見込み(未確認)。
2. **参照の温度の決め方**: 起きている所に 1 つ(環境の温度)。焚き火の熱い炉の中のような「参照から離れた同じ温度の所」は、今の形と同じ偏り(放つ量 × 15〜21 %)が差の量にだけ残る(差が小さいほど小さい)。
   ブロックごとの参照 + 参照どうしの対の流れ(ADR-0424 の 2)は、ブロックの間の見える割合の作り方が要る(T-1062 の対のつながりの問題と同じ)。今は入れない。
3. 2 つの組なので、負の側に放つ物がある刻みは光線が足される(上の費用)。

## 次の手
