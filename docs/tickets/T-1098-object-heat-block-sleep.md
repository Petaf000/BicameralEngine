# T-1098 物の中の眠っている所をブロックごとに眠らせる(T-1076 から先に分けた。最初 T-1097 で書いたが、T-1097 は D-645 の研究に回したので付け替えた)

## 目的(1〜2 行)
薪の中(燃えていない木)・冷えた紙の山を、結果を変えずに回さない。薪 100 本・焚き火の 1 刻みの費用がどれだけ減るかを測る。

## 完了条件
- [x] 眠らせた世界と全部回す世界が毎刻み同じ(CPU。gpu_object_heat の比べ・object_heat の 7 の試作と同じ)
- [x] GPU と CPU がビット一致(ボクセル・セル・対の端数・待ち・ブロックの状態)
- [x] 冷えた紙は後半 600 刻みで回したブロック 0(object_heat の 8)
- [x] 薪 100 本・焚き火・1000 個の費用を 全部回す / 眠らせる で(docs/perf.md)

## 作業ログ
- 2026-10-24 wt5: ブロック(64 ボクセル以下。薪 4×4×4・紙 8×1×8・小枝 2×2×16)ごとに、受け渡しは「静か + 自分・隣のブロックの自分に向いた面・囲むセル・光が変わっていない」で、
  反応は changedTick と待ちの丸めの起こす刻みで眠らせた(ADR-0459)。物ごとの和(③)も、物の全部のブロックが眠っていればボクセルを読まない。
  反応の changedTick を「毎刻み t − 1」から「本当に変わった刻み」にした(試作も同じに直した。試作の要約 6d140941c39f6027・燃え続けた時間は変わらない)。
  確かめ: 眠らせた世界と全部回す世界が毎刻み同じ(CPU)・GPU と CPU がビット一致(ボクセル・セル・対の端数・待ち・ブロックの状態)・冷えた紙は後半 600 刻みで回したブロック 0。
- **費用(RTX 3070 Ti・1 刻み 中央 ms。全部回す → 眠らせる。300 刻み暖機の後)**:
  | 場面 | 全部回す | 眠らせる | 起きているブロック |
  |---|---|---|---|
  | 燃えている薪 100 本 | 5.38 | 5.42 | 11700 / 11700 |
  | 焚き火(薪 10・小枝 30・紙 10) | 0.83 | 0.83 | 1460 / 1460 |
  | 薪の山 100 本(燃えているのは 10 本) | 2.72 | 0.73(−73 %) | 1170 / 11700 |
  | 紙の山 1000 枚(燃えているのは 100 枚) | 5.23 | 1.41(−73 %) | 2000 / 20000 |
  (物ごとの和を眠った物で飛ばす前の値)。**飛ばした後: 薪の山 0.68 ms(−75 %)・紙の山 1.30 ms(−75 %)**。燃えている薪 100 本 5.40・焚き火 0.82 ms は変わらない。
  - **燃えている物はほぼ減らない**: 8 cm の薪は 4×4×4 のブロックが全部外に面するか、外に面するブロックの隣で、燃えている間は囲むセルが毎刻み変わり、
    熱の前線で中のボクセルのエネルギーも毎刻み少しずつ変わる(温度が mK で変わらなくてもエネルギーは変わる)。眠るのは冷えた物・燃えていない部分だけ。
  - 燃えている物を減らすのは、中を粗くする(T-1076)か、外の燃える層の費用(反応 55 %・流れ 35 %)そのものを下げる方。
  - 眠っている物の残りの費用: ブロック 1 つ 1 語読む + 物ごとの和。起きている物の一覧で Dispatch しない形は T-1077。
- 紙 1000 枚の揺れ(前回 最小 9.7・中央 18 ms): この回は 10.1 / 11.4 ms・7.8 / 9.9 ms で、前回ほど揺れない。ほかの作業ツリーのビルド・試験との重なりか時計の揺れと見る(未確認。突き止めていない)。
