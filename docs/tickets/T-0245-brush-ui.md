## 目的(1〜2 行)
`--editor` の筆で、ドラッグで塗り、球・直方体・円柱を置き、材料を表の全物質から組めるようにする。置く操作はどれもコマンドとして
記録され、再生で同じ結果・GPU と CPU が一致する。

      GPU(probe_tick.hlsl の ApplyPlace)と CPU(ProbeReference)が同じ形を囲む箱を回し、同じ ProbePlaceCovers で選ぶ

## 引き継ぎメモ(HANDOFF に載せる内容)
- 動いているもの: `bicameral --editor` の「筆(世界に置く)」で、形(球・直方体・円柱〔軸 x / y 縦 / z〕)・材料(表の全物質から 3 つまで・
  mol・g・kPa。ひな形から読み込める)・温度・置き換えか足すかを選び、「筆を持つ」で左ボタンを押す / ドラッグすると置く・塗る。
  ドラッグは 1 フレーム 8 個・待っているコマンド 64 個まで(残りは次のフレームに続きから)。足すは重ならない間隔(2 × 半幅 + 1)。
- 注意:
  - 置くコマンドの形は語 [0]・[1] の上の 8 ビット(ADR-0089)。もう空きビットは無い(語 [1] の 28〜31 ビットだけ。形の番号の上位)。
    これ以上の形は種類の番号を替える。
  - 材料の量の %(T-0222)は無くした(行の量で決める)。--auto-place は、フレーム 18・19・22 にパネルの形と材料を書き換える(人が触っていない前提)。
  - 実験室の材料の行は editor/material_rows に移した(lab_panel の MaterialRow・AmountUnit も)。
  - 適用の重さは測っていない(T-0280)。止めている間にドラッグすると 1 刻みに約 64 個溜まる。

## 分けたもの(司令塔が ROADMAP に足すか決める)
- **T-0278 筆の元に戻す**: 保存点への巻き戻し + 取り消した筆の運びを除いた再生(14 §1・ADR-0089 §4)。筆の運び(押してから離すまでの
  コマンドの番号の範囲)を CPU の文書として持ち、元に戻す = その運びの最初の刻みより前の保存点へ戻し、記録からその運びを除いて今の刻みまで流し直す。
  記録中(--record)の扱い(記録から除く・取り消しの印を残す)を決める。今は巻き戻しで戻る(記録中・トレース中は巻き戻せない)。
- **T-0279 カーソルの下に筆の形を描く**: 描画側(render/probe_view か ImGui の前面の描画リスト)で、断面のカーソルのセルに今の形の囲みを描く。
  シミュに入れない。DebugViewController にカーソルのセル(押していない時も)を足す。
- **T-0280 面に沿って塗る・適用の重さを測る**: 地面の表面のセルだけに塗る形(当たったセルの法線の向きの厚さ)と、1 刻みにたくさんの大きな筆を当てた時の
  適用の単位の時間(1 スレッド)を測り、分けるか決める(ADR-0067・ADR-0089 の「しにくい」)。
