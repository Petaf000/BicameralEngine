## 目的(1〜2 行)
T-0592 の GPU の気体の段(区画 12 × 24 × 12 = 3456 セル・小刻み 24)の費用を段ごとに切り分けて下げ、Work Graph と Compute を比べる(D-302)。
投影(GPU の解く部分は T-0531)を区画にも使えるようにする(今は陽解法だけ)。

## 完了条件(チェックできる形で)
- [ ] 段ごとの時間(probe_gas_tick の 7 段・gas_step の 9 段 × 24)。gas_step の 1 段は T-0374 の 16³ で 0.6〜1.5 µs/段の見込み → 216 段で 1〜2 ms のはず
- [ ] 費用を下げる(例: 段をまとめる・音だけの小刻み・活性の所だけ。結果は CPU とビット一致のまま)
- [ ] WG と Compute を測って perf.md へ(反復の数が決まっているので結果は同じ。D-302)
- [ ] 投影: ProbeGasPressure::Projection を GPU で(gas_projection の当てる・作るの GPU 版と T-0531 の解く部分)。CPU と毎刻み一致

## 研究の打ち切り条件
段ごとの時間を測って原因の仮説を 2 つ試し、区画 3456 セルで 2 ms/刻みを切れなければ、測った値と仮説をここに書いて次の手(活性の所だけ回す・17)へ移す。
