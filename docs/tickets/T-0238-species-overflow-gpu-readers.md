# T-0238 GPU の溢れの残りの読み手: 覗き窓・実験室・陰解法の段(T-0211 から分けた)

- Status: Todo(T-0237 の後。T-0199 の CPU と合わせる)
- 種類: 工学
- 設計: 02 §3・17(R-MULTI-4)・ADR-0052・ADR-0054。関係: T-0176・T-0199・T-0211・T-0132(陰解法)

## 今(T-0211 の後)
- 覗き窓(multires_peek.hlsl)・実験室は溢れを読まない(8 種を超えるセルの 9 種目以降が見えない)。
- 陰解法の段(gpu_multires_implicit・implicit_conduct.hlsl・系を作る段)はセルの熱容量を溢れなしで読む。溢れを使う世界で陰解法を入れると
  RecordStep の FX_ASSERT で止める(T-0211)。

## やること
1. 覗き窓・実験室が溢れを読む(CPU の T-0199 と同じ見せ方。成分の一覧の長さ)。
2. 陰解法の系を作る段が、溢れを持つセルの熱容量・伝導率を溢れまで読む(伝導の段の BlockCellThermal と同じ)。
   ルート署名は 64 / 64 語で一杯なので、g_overflowBase は MR_WIDE_CELLS の変種だけが宣言する形を守る。
3. 試験: 溢れを使う世界で陰解法あり(gpu_multires_implicit の場面)が CPU と HW・WARP で毎刻みビット一致。

## 完了条件
- 覗き窓が溢れのあるセルの全部の成分を返す(CPU と一致)
- 陰解法ありの溢れの世界が CPU と HW・WARP で毎刻みビット一致
