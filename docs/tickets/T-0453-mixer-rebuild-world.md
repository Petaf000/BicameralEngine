## 目的(1〜2 行)
今は環境ミキサー(T-0452)で足すと表の法則(元素・物質・反応)だけが刻みの境界で替わり、環境の値(重力)と初めのセル(earth_air の空気)は
起動した時のまま。エディタに「世界を作り直す」(今の表の組み立て・環境で刻み 0 から作り直す)を足し、足したものが全部効くようにする。

## wt3 との分担(2026-10-13 第 3 巡。wt3 = T-0444 環境の値のホットリロード)
境目: **「表の差し替えに乗って刻みの境目で当たるもの」は wt3、「刻み 0 からしか作れないもの(初めのセル・物)と、ミキサーの作り手から見た振る舞い」は wt2**。
- **wt3(T-0444)が作る**: 差し替えた表の環境の値(分類 environment: 重力・音速の基準・基準の大気)を、差し替えの刻みの境目で世界に当てる道。
  どこから来た差し替え(ファイルのホットリロード・ミキサー・再生の印)でも同じ道。GPU の物理の重力(GpuPhysics の PxParameters)・
  CPU リファレンス(PhysicsWorld)・--check-physics・再生でビット一致。記録は今の表の印のコマンド(版に環境が入っている)のままで足りるはず。
  触る所: sim/gpu_physics・sim/physics_world・sim/probe_sim の差し替えの処理・frame_loop.cpp の TakeTableSwaps 〜 物理の確かめの所。
- **wt2(T-0453)が作る**: ミキサーで足した**初めのセル(world_cells。earth_air の空気)・物(world_bodies)**を効かせる道 =
  エディタの「世界を作り直す」(今の表で刻み 0 から作り直す)。ミキサーのパネルに「今すぐ効くもの(法則・環境の値)/作り直すと効くもの(初めのセル・物)」の表示と
  ボタン。作り直しの記録の扱い。触る所: editor/mixer_panel・frame_loop.cpp の RunFrameLoop・CreateParts・ApplyMixRequest の辺り(TakeTableSwaps と物理の確かめは触らない)。
- 重力はミキサーから足しても wt3 の道で今の世界に効く(wt2 は重力を別に差し替えない)。ブランクの世界は物が無い(物理を作らない)ので、
  重力を足しても見た目は変わらない。物を持つパッケージを足したら作り直しで物理ごと作る。
- frame_loop.cpp は両方が触る。衝突しやすいのは FrameLoop のメンバーの並びだけの見込み(wt2 は末尾に足す)。

## 判断待ち(仮で進めたもの。ユーザー未確認。詳しくは ADR-0192)
- **ミキサーで初めのセル(空気で満たす など)・物を足した時、今の世界にどう効かせるか**: 案 A(仮)= 足すと法則と環境の値だけ当たり、
  初めのセル・物は「世界を作り直す」ボタンで効く(今の世界の状態は消える)/ 案 B = 足した刻みにセルを置き換える(世界は続く・帳簿に改造の出入り)/
  案 C = 今のセルに足し合わせる(既に空気がある所は 2 気圧になる)/ 案 D = 足すと自動で作り直す。案 B・C は A の横に後から足せる。
- **作り直した時の記録**: R1(仮)= 記録は作り直した所から(再生ファイルの形は変わらない)/ R2 = 作り直しを記録のコマンドにする(形の版が上がる)。
