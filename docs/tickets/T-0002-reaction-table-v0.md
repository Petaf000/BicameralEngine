## 前提(2026-10-12〜13 の指針)
- ゲームの世界は遊びのために作った独自の法則を持つ一つの宇宙(D-463)。**現実 + 嘘の二層に分けない**。法則は一つの表だけで、
  調整は法則そのものを書き換える。現実の化学(標準パッケージ「現実」)は出発点の一つで、そこから書き換え・足していく。
- ゲームが決めるのは「何があるか・何が何になるか(反応の網)・値」だけで、法則の形は作らない(D-464)。
  元素もゲームが決める(ブランクの世界には何も無い。D-455)。
- 魔法は反応則の書き換えではなく、体に蓄えたエネルギーで魔素を**押す**ことと、魔素の反応を**解く**(触媒)こと(D-466・D-481)。
  魔法の遊び方は「一旦の決定」(試すのをタダにする・大きいことは試せないから研究が生まれる)。中身は非公開側の控え。
- 法則は状態だけで決まる(D-465)。最初の発見を確実に起こす仕掛けは、法則ではなく配置・地形・NPC で仕込む。
- 優先順位は 面白さ > 美しさ(D-462)。良い法則の基準は「知ると何が作れ、どんな作戦が立てられるようになるか」。

## 目的
このゲームの面白さのほぼ全部が決まる作業。「実装する反応のリスト」ではなく、
「プレイヤーが即興と実験で見抜ける法則の体系」を、層状に設計する(表の規則 → 隠れた変数 → まとめる法則 → 細かく覗くと見える仕組み。02 §8)。

## 完了条件
- [ ] 元素・物質の種類(⑤ の場面に要る分から)と、それぞれの状態量(温度・湿り気など)
- [ ] 規則性: 系統ごとにどう振る舞うか(「この系統はこう」)。類で書く補助(D-485)で書ける形にする
- [ ] 例外: 「なぜかこれだけ違う」を意図して置く場所
- [ ] 合成可能性: 単純な規則の組み合わせで、設計者が想定していない結果が出る例を 3 つ(作戦専用の法則は 0 が目標。D-464 の例)
- [ ] 中間生成物(灰・炭・蒸気・煤・溶けた金属など)と、それが次の反応の材料になる経路
- [ ] 遊びの速さに合わせた値(例: 密室の火が遊べる時間で消える)と、その帳尻(熱・元素)が法則の中で合っていること。
      遊びの指標として自動テストに登録する(T-0432・D-482)
- [ ] 魔素の坂: 魔素が何を引きずり、押す・解くで何ができるか(⑦ の魔素の段で。D-466・D-481)
- [ ] 最初の 3 つの発見を、配置・地形・NPC でほぼ確実に起きるように仕込む方法
- [ ] 観測手段(温度計・組成分析・記録)= プレイヤーの道具の一覧。計器も物として法則に従う(D-470)
- [ ] 最悪ケースの見積もり: 同時に活性になるセル数の上限(→ 予算。負荷で遅れてはいけない。D-468)
- [ ] ⑤ の場面をエディタ(Luau と道具)で作り、面倒だった所を記録する(D-486)
