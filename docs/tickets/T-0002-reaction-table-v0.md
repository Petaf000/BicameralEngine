# T-0002 反応表 v0(プレイヤーが発見していく自然法則の体系)

- Status: Todo
- 種類: 設計
- PC: 不要(紙とペン・スマホのチャットで進められる)
- 道: 中身の道 C1(ROADMAP)。期限は M5(非公開リポジトリに載せ始める時)。元素は現実の元素すべて + 魔素(D-418)。**中身はユーザーが決める**。仕組みは docs/design/02-reaction-system.md
- 見積もり: チャット 2〜3 回分

## 目的
このゲームの面白さのほぼ全部が決まる作業。「実装する反応のリスト」ではなく
「プレイヤーが仮説と実験で発見できる法則の体系」を設計する。
これが決まると、ノードの属性数・近傍検索の範囲・VRAM 予算・Work Graphs のバッキングメモリ上限が決まる。

## 完了条件
- [ ] 基本の属性/元素の種類(目安: まず 8〜12)と、それぞれの状態量(温度・湿り気など)
- [ ] 規則性: 系統ごとにどう振る舞うか(周期表のような「この系統はこう」)
- [ ] 例外: 「なぜかこれだけ違う」を意図して置く場所
- [ ] 合成可能性: 単純な規則の組み合わせで、設計者が想定していない結果が出る例を 3 つ
- [ ] 中間生成物(灰・炭・蒸気・煤・溶けた金属など)と、それが次の反応の材料になる経路
- [ ] 魔法 = 反応則への介入(触媒・阻害・転換・増幅)を何段階で解禁するか
- [ ] 最初の 3 つの発見を、ほぼ確実に起きるように仕込む方法
- [ ] 観測手段(温度計・組成分析・記録)= プレイヤーの道具の一覧
- [ ] 最悪ケースの見積もり: 同時に活性になるノード数の上限(→ Work Graphs のメモリ上限)
- [ ] docs/design/02-reaction-system.md に反映

## メモ・参考
- 出発点として BotW の属性(燃える・導電・濡れ など、実質 10 種程度)を置き、そこに中間生成物と魔法の介入を足す。
- 参照: Outer Wilds(知識だけが進行を進める)、Opus Magnum、Noita。
