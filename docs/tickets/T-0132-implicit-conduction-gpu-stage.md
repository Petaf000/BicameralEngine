## 目的(1〜2 行)
MultiresStepOptions::implicitConduction を GPU の刻み(GpuMultires::RecordStep・RecordStepActive)でも効くようにする。D-434 案 a
(方式① は分けない + 方式② を基準より細かい Δk 1〜8)・D-436(V の上限 64 まで解き切る)の形のまま、CPU の StepNest・StepActive と毎刻みビット一致。
