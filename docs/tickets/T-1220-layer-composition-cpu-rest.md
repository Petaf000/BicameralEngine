## 目的(1〜2 行)
T-1210 の 1 段目(頁のセルだけ)で層が 0 に戻る道を無くす: 一様の枠・細かくする・粗くする・溢れの成分でも、物質ごとの層の量を保つ。

## 完了条件(チェックできる形で)
- [x] 一様の枠の層(T-1210 の「土台に足りないもの 1」のおすすめ: 成分ごとの層を層のある枠だけ持つ)。頁に広げる時に写し、畳む時は層まで一様な時だけ
- [x] 細かくする: 成分ごとに T-1177 の配り(層 = 内訳の印 = 凝縮相・残り = 親の印 = 空きに同じ濃さ)。子の層の和 = 親の層 × 8・子の量の和 = 親 × 8(ビット単位)
- [x] 粗くする: 成分ごとに層の和 ÷ 8 の切り捨て(単調なので 0 ≤ 層 ≤ 量 のまま)。切り捨ての余りは層から残りへ移る(量の保存は今のまま)
- [x] 溢れを使う世界(T-0187): 溢れの成分の層(溢れの領域に層の並び)。インライン ↔ 溢れの間で物質が動いても物質で結ぶ
- [x] 眠る判定: 残りのある頁は畳まない(残りを数えるのは粒の物質だけ。T-1210 の「土台に足りないもの 2」)。止まれる側だけなら畳める
- [x] 試験: multires_layers に足す(往復で層の和が保たれる・溢れの世界・眠る)・今の multires 系・placement_refine が通る(層の無い世界はビット単位で同じ)

## 入れた形(2026-10-27 wt3。ADR-0489)
- 一様の枠: `MultiresCellStore::uniformLayers`([枠] 0 でない層の物質と量の組。読む時に一様の値〔溢れまで〕と物質で結んで min)。
  書くのは畳む(`FoldLayeredPage`。層まで一様な時だけ。ほぼ同じ頁の平均の畳みは層のある頁でしない)・細かくする(一様な子 = 親の層)だけ。
  頁に広げる(`FillPageFromUniform`。刻みの広げ・粗くする時の親の広げ)で頁へ写して消す。粗くする時、一様な親のまま残るのは層も同じ時だけ(`CoarsenKeepsUniformLayers`)。
  枠を返す・根を置く時に消す。GPU から読んだ列(`StoreDenseCellImage`)は一様の値と結び直す(溢れを使う世界は T-1221)。
- 頁へ写す口 `CopyCellToPage`(細かくする時の子の頁・影の頁・広げる時)。層のある所から・層の並びを持つ頁へは層まで書く(書く先の古い層を残さない)。層の無い所は前と同じ書き方。
- 細かくする(置かれ方): 層を持つ成分と、層を使う世界の粒は「層 = 沈む側」「残り = 物質の置かれ方」の 2 つの物質に分けて `PlaceRefineCell` に渡し、子の層 = 層の分(multires_refine_cells.cpp)。
  欄の重み(refinePlacement)も同じ分け方。層の無い成分は前と同じ 1 つの物質。
- 粗くする: `CoarsenLayers`(成分ごとに層の和 ÷ 8 の切り捨て・粗いセルの量で抑える)。子に層がある時だけ求める(層の無い世界は前と同じ道)。
- 溢れ: `MultiresOverflowArea::layers`(セルの溢れだけ。層のある領域だけ)。`StoreWidePageCell` は層のある頁なら書く前のセル(インライン + 溢れ)と物質で結ぶ。
  GPU から読んだ溢れの領域は層を消す(T-1221)。
- 層を使う世界: `EnableCellLayers(nest, table)`(粒の印 RX_SPECIES_GRAIN を持たせる)。舞う粒(粒の 量 > 層)のある頁は畳まない(FoldExact・FoldNear)。
  使わない世界は眠る判定・置かれ方とも今のまま。
- 要約: 一様の枠の層(`HashUniformLayers`。HashWholeNest は枠の番号 + 2^63 の番地・HashRealLeaves はセルごと)・溢れの成分の層(`HashCellLayers` が溢れまで)。0 でない層だけ。
  保存点は置き場ごと写す(セルの置き場・溢れの領域)。検査 `CountLayerMisfits` は一様の枠(一様な枠だけが持つ・物質がある・層 ≤ 量)と溢れも見る。

## セルの大きさ(2026-10-27。CPU)
- 頁: 1 段目のまま(層のある頁だけ 1 セル + 8 B × 頁の幅。幅 2 で 33 → 49 B)。
- 溢れ: 層のある領域だけ、溢れの成分 1 つに + 8 B(12 → 20 B)。
- 一様の枠: 層のある枠だけ 0 でない層の成分 1 つに 12 B(物質 4 B + 量 8 B)。ただし置き場の頭(vector 2 つ)が**全部の枠に 48 B**(層の無い世界も)。
  気になるなら枠ごとの番号(4 B)+ 組の表に替えられる(分けたもの 3)。

## CPU の 1 刻みの中で同じセルを 2 回以上書く道(GPU と結果が分かれる所。T-1221 用の洗い出し)
CPU は書くたびに `層 = min(前の層, 新しい量)` で付け替える。1 刻みの中で同じ物質が「減って → 増える」と、CPU は減った所の min が残り、
段の最後に 1 回だけ合わせる GPU は最後の量との min になって分かれる。今の CPU の 1 刻み(試験の場面の順)で 1 セルを書く所:
| 段 | 書く所 | 量が変わるか | 2 回目になりうるか |
|---|---|---|---|
| 刻み(StepActive)の伝導 | multires_nest.cpp StepPagedBlock の ApplyEnergyDelta → StoreCellAt | エネルギーだけ(層に効かない) | 次の反応と同じセル(量は伝導で変わらないので分かれない) |
| 刻みの反応 | StepPagedBlock の MrStepCellWait → StoreCellAt / StoreWidePageCell | 減る(反応物)・増える(生成物) | 1 セル 1 回(連鎖の中は書かず、結果だけ 1 回) |
| 伝導の小刻み | multires_conduction.cpp(ApplyEnergyDelta → StoreCellAt) | エネルギーだけ | 分かれない |
| 気体の段 | multires_gas.cpp(StoreNestCell。読んだ列から 1 回) | 減る・増える(運ばれる) | **反応で減った物質が同じ刻みに気体で運ばれて増えると分かれる** |
| 液体の段 | multires_liquid.cpp(StoreNestCell。1 回) | 減る・増える | **同上(反応・気体の後)** |
| 細かくする / 粗くする・畳む・広げる | multires_tree.cpp・multires_activity.cpp | 配るだけ(層は明示で書く) | 層を明示で書くので付け替えに依らない |
| 影の引き戻し | multires_nest.cpp PullBack*Level(StoreCellAt / StoreWidePageCell) | 影だけ(真実は親) | 影の値は観察用(分かれても真実は変わらない) |
- おすすめ(T-1221): GPU の「層を合わせる段」は 1 刻みの最後に 1 回ではなく、**CPU が書く段の境と同じ所(反応の後・気体の段の後・液体の段の後)に 1 つずつ**置く。
  そうすれば各段の中では 1 セル 1 回の書き込みなので CPU とビット一致する。GPU のカーネルが 1 段の中で同じセルを 2 回以上書く所(反応の待ち・溢れ)は T-1221 で数える。
- 法則として見ても「減ってから増えた分は残り(舞う側)へ」は ADR-0481 の 5 の 2 の規則どおり(段の境ごとに付け替えるのが規則の字義に近い)。

## 判断待ち(仮で進めた)
- 【エンジン】ADR-0489 の 3: 層を使う世界で、層を書かずに置いた粒を「舞う粒」と読むか(入れた形 (a))、「全部が層」と読むか((b))。
  作り手から見た違い: (a) は砂の床を層として置く必要があり、置き忘れた砂は細かくすると空中に同じ濃さで広がって頁が眠らない(重くなる)。
  (b) は何も書かなくても積もるが、「層の並びが無い」と「層 0」を分ける印が要り、付け替えの規則が 2 つになる。おすすめ (a)。
- 【エンジン】ADR-0489 の 1・2 の司令塔の仮の決め(一様の枠は成分ごとの層・眠る判定の残りは粒だけ)はそのまま入れた。作り手から見た違いは
  「隙間の空気が混ざった一様の砂の床が畳める(軽い)」「空気のある頁も砂が全部層なら眠れる」。

## 分けたもの(司令塔へ。番号は未取得)
1. 層つきの根の置き口(`PlaceRootBlock` は層 0 で置く)と、環境のパッケージから層を置く道。ADR-0489 の 3 が (a) のままなら、層を使う世界の初めの場面に要る。
2. ほぼ同じ頁を平均で畳む道(許容差つき)の層: 今は層のある頁を平均で畳まない。層の平均(成分ごとの和 ÷ 数の切り捨て)を入れるかは、畳まずに重くなる場面が出てから。
3. 一様の枠の層の置き場の頭(全部の枠に 48 B)を枠ごとの番号 + 組の表に縮める(層の無い世界でも 48 B × 枠かかる)。
4. 影(観察の枠)の引き戻しで層を親に合わせる(今は付け替え〔min〕だけ)。観察の見え方に層を出す時。
