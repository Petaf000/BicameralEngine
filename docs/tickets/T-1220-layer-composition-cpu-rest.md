## 目的(1〜2 行)
T-1210 の 1 段目(頁のセルだけ)で層が 0 に戻る道を無くす: 一様の枠・細かくする・粗くする・溢れの成分でも、物質ごとの層の量を保つ。

## 完了条件(チェックできる形で)
- [ ] 一様の枠の層(T-1210 の「土台に足りないもの 1」のおすすめ: 成分ごとの層を層のある枠だけ持つ)。頁に広げる時に写し、畳む時は層まで一様な時だけ
- [ ] 細かくする: 成分ごとに T-1177 の配り(層 = 内訳の印 = 凝縮相・残り = 親の印 = 空きに同じ濃さ)。子の層の和 = 親の層 × 8・子の量の和 = 親 × 8(ビット単位)
- [ ] 粗くする: 成分ごとに層の和 ÷ 8 の切り捨て(単調なので 0 ≤ 層 ≤ 量 のまま)。切り捨ての余りは層から残りへ移る(量の保存は今のまま)
- [ ] 溢れを使う世界(T-0187): 溢れの成分の層(溢れの領域に層の並び)。インライン ↔ 溢れの間で物質が動いても物質で結ぶ
- [ ] 眠る判定: 残りのある頁は畳まない(残りを数えるのは粒の物質だけ。T-1210 の「土台に足りないもの 2」)。止まれる側だけなら畳める
- [ ] 試験: multires_layers に足す(往復で層の和が保たれる・溢れの世界・眠る)・今の multires 系・placement_refine が通る(層の無い世界はビット単位で同じ)
