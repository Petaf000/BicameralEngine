## 一つの芯にできるか(先に検討した。結論: できる)
- T-0493 の交差(ADR-0220)は「坂 X の流れが量 Y も動かす。L_XY = q √(L_XX L_YY)、|q| ≤ 1 なら半正定」。押す構造はこれと**同じ 2 × 2 の形**で、
  X を「構造の蓄えが自分の坂を下る流れ」、Y を「押される物の流れ」にしたもの(Kedem–Caplan の能動輸送の形そのもの)。違いは係数の出どころだけ:
  引きずりは物質の係数(伝導率・拡散)、押す構造は構造が持つ係数(速さ P・1 単位を押す費用 w: L_XX = P・L_YY = P ÷ w²)。
- エネルギーの単位にそろえた坂(f_X = 蓄え 1 単位が下る時の自由エネルギー、f_Y = Y を 1 単位動かす時の自由エネルギーの下がり。y = f_Y ÷ w)で
  **J_X = P (f_X + q y)、J_Y = (P ÷ w)(q f_X + y)**。生成 T σ = P (f_X² + 2 q f_X y + y²) ≥ 0 ⇔ |q| ≤ 1。効率の上限は q だけ(η_max = q² ÷ (1 + √(1 − q²))²)。
- X は坂をエンジンが知っている流れなら何でもよい: 仕事の蓄え(f = 1)・熱の流れ(f = 1 − T_低 ÷ T_高 → 熱機関。Carnot を形が守る)・物質(Δμ)・反応(−ΔG)。
  Y も同じ: 気体・成分・熱(冷やす機械)・物理の仕事(体。T-0537)。魔法の「押す」(⑦)もこの形を使う。
- **q = 1 = 比の機械**: 1 単位押すたびに w を使い、坂が費用に追いつく(y = −f_X)と止まって蓄えも使わない。押し返されると逆に回る(発電機)。
  案 c(きっちり結合の比の規則 + 止まる条件)はこの形の q = 1 で、別に作る必要はない。**法則を破れる数は q だけ**(w・P はどんな正の値でもよい)。

## 表の書き方(作り手から見た違い。おすすめは仮・ユーザー未確認)
例(仮): `machines = { { name = "pump", store = "energy", push = { what = "gas", from = "port:in", to = "port:out" }, coupling = 0.9, cost = 3000, speed = 3000 } }`
(cost = 1 mol 押すのに使う蓄え J/mol、speed = 負荷のない時に蓄えを使う速さ W)

**問い 1 どこに書くか**
| 案 | 作り手から見た違い |
|---|---|
| **A 独立の表 `machines`(おすすめ・仮)** | 置いた所だけで効く「物」として、法則の表(反応・`drags`)と分かれて見える。構造の種類ごとに 1 行。検査は `drags` と同じ(q の範囲) |
| B `drags` の行に `through = 構造` を足す | 表は 1 つで済む。物質の法則(どこでも効く)と置いた機械(そこだけで効く)が混ざり、費用 w・速さ P・口の欄が `drags` の行の多くで空になる |
| C 物の型(物理の物・生き物の体)の欄 | 体の筋肉のように物に付いた機械は書きやすい。セルで作る機械(壁に埋めたポンプ)は書く所が無い |

**問い 2 数を何で書くか**
| 案 | 作り手から見た違い |
|---|---|
| **a q・w・P(おすすめ・仮)** | q は `drags` と同じ 1 つの数。パネルに「最大の効率 η_max(q)」と「止まる坂」(例: 気体なら何倍の圧力まで押せるか)を出す |
| b 最大の効率 η(0〜1)・w・P | 機械を作る人には分かりやすい(「効率 25% の筋肉」)。q = 2√η ÷ (1 + η) に換算。`drags` の q とは別の数に見える。η > 1 は警告して 1 に押さえる |
| c 止まる坂(例: 最大の圧力の比)・q・P | 止まる所を直接決められる。ただし気体の坂は温度で変わる(R T ln)ので、書いた値は決めた温度での値になる(w = 止まる坂 ÷ q に換算) |

**問い 3 坂に負けた時**: **結合の形(止まる・押し返されると逆に回る。おすすめ・仮)** / 一方向の規則(反応と同じく向きは作り手、坂を上る時は警告して動かす。
機械を限界まで使うたびに警告が出る。止まる所・逆回りを作り手が別に書く)。
**問い 4 範囲の外(|q| > 1。効率 > 1 になりうる)**: 警告して ±1 に押さえる(おすすめ・仮。D-487 ②)/ 読み込みを止める。
**問い 5 q = 1 を許すか**: 許す(おすすめ・仮。止まった所で蓄えを使わない・押し返されない理想の機械)/ 1 未満に押さえる。

## 模型の結果(2026-10-15・tests/push_model_test.cpp・ctest push_model・release)
構造: 1 µmol を押すのに 3 mJ(w = 3 kJ/mol)・負荷なしで 50 J/刻み。2 つの部屋に 1 mol ずつ・熱の溜め 1000 J/K・300 K。4000 刻み。
| 場面 | 結果 |
|---|---|
| ポンプ q = 1 | 圧力の比 3.3079 で止まる(止まる坂の計算 3.3080)。効率の最大 0.991(上限 1)。蓄え 1.62 kJ を使い気体が 0.74 kJ の自由エネルギーを得た |
| ポンプ q = 0.9 | 比 2.607(計算 2.605)。効率の最大 0.39282(上限 0.39286)。止まった後も空回りで蓄えを使う(39 kJ) |
| ポンプ q = 0.5 | 比 1.494(計算 1.493)。効率の最大 0.07178(上限 0.07180) |
| 書きすぎ q = 1.2(押さえずに) | 止まった所で J_X < 0 になり、**熱から蓄えを作り続ける**(+86 kJ・熱の溜め −85 K・エントロピー −3.4 × 10^5 mJ/K)。保存は守るので帳簿では見つからない。ベイクは警告して 1 に押さえる(押さえた後は蓄えが増えない) |
| 蓄えが尽きる(0.3 kJ) | q = 1: 押した差 199,990 µmol をそのまま保つ。q = 0.9: 176,816 µmol 押した後、滑りの分だけ押し返されて 378 µmol まで戻る |
| 発電機 q = 1(比 9 から) | 押し返されて逆に回り、蓄えを 789 J 作った(気体が失った自由エネルギー 1074 J の 73%)。比 3.34 で止まる |
| 熱機関(600 K → 300 K。Carnot 0.5) | q = 1: 熱からの効率の最大 0.486(÷ Carnot 0.987)。q = 0.8: 0.123(÷ Carnot 0.2499。上限 0.25) |
- 全部の刻みで、エネルギー(蓄え + 熱)と物質量がビット単位で一定・1 刻みの厳密なエントロピーの変化 + 丸めの幅 ≥ 0(発電機の最小 −6.7 × 10^-3 mJ/K は丸めの幅の中)。
  2 回の実行でハッシュ一致。打ち切り条件にはどれも当たらなかった(行き過ぎの歯止め 1/64 は直さずに足りた)。
- 気づいたこと: (1) q = 1 でも 0 から止まるまで押し上げる全体の効率は 46%(効率は「今の坂 ÷ 費用」なので、坂の低い所で押した分は損になる)。
  (2) 1 刻みの厳密な変化は線形の生成より 2 次の項だけ小さい(エントロピーの関数が凹)。歯止めは「1 刻みの流れ × 坂の傾き ≪ 生成」を守る形で、模型の値では余裕が約 50 倍。
  エンジンに入れる時は、伝導の 1/8 と同じく係数から歯止めを決める(未確認)。
