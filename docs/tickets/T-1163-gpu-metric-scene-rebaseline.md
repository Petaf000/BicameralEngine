- PC: 必須

## 目的(1〜2 行)
main(90ff780e)でも GPU の試験 gpu_play_metric・gpu_world_copy が落ちていた。GPU と CPU の一致は両方とも通っており、落ちたのは
「場面が変わること」を前提にした判定だけ。現実の伝導率(T-1066)で、殻 1 セルの木箱に火をつけた場面が燃え広がらなくなったため。

## 完了条件(チェックできる形で)
- [x] 出どころの確かめ: 作業ツリーを main に切り替えて release で 2 本を流し、main でも同じ判定で落ちることを確かめた(t-1113 の枝の変更と無関係)
- [x] gpu_world_copy: 使い直した写しの止める条件を「木の量が閾値以下」から「最高温度が閾値以下」に替えた(閾値は CPU の道のりの 4 番目の読み戻し)。
  木の量・最高温度とも CPU と 10 刻みごとに一致を見る
- [x] gpu_play_metric: 「表を変えると指標が変わる」の判定を、木の燃焼の速さ × 10 と sealed_fire_out から、固体の伝導率 × 10 と
  試験の指標 fire_peak(同じ場面の 1 秒後の最高温度。CPU リファレンスともビット一致を見る)に替えた
- [x] release で 2 本が通る(RTX 3070 Ti)

## メモ・参考
- 原因(測り): 火をつけた 3 セルは 1 刻み目に熱分解で炭 + 水蒸気になり(気体の区画の無い仮の世界では O2 は孔の分だけ)、
  放射の無い GPU の世界では約 7669 K のまま冷めない。そのため
  - gpu_world_copy: 刻み 40 からの木の量が 11387000000 で変わらず、閾値 = 初めの量 → 写しが刻み 40 で止まり、刻み 50 のつつきの差が出なかった
  - gpu_play_metric: sealed_fire_out(1000 K 以上のセルが 0 になるまで)が、元の表でも速さを変えた表でも上限 36000 刻み(量 1)で同じ
- 判定の目的(写しの条件で止めた刻みが CPU と同じ・表の版の差が報告に出る)は変えていない。量を場面に効くものに替えただけ。
- 残り(司令塔へ): パッケージ combustion_test の sealed_fire_out は今の法則では「密室の火」を測っていない(火が広がらず、上限まで 1 セルが熱いまま)。
  場面を直すのは燃え広がりの研究(T-1156。燃える気体 D-660・気体の区画)と一緒に。放射が GPU に入ると(T-1154)火をつけたセルは冷め、sealed_fire_out は 86 秒で止まる(2026-10-26 t-1113-radiation-all で測った)。
