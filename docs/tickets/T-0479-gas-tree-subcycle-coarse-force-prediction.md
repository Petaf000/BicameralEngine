# T-0479 気体の木の分けた小刻みで、一様な加圧が偽の流れを出す(粗い側の力の見込み)

- Status: Done
- 種類: 工学(不具合)
- PC: 必須
- 見積もり: チャット 1 回分(T-0470 の中で見つけて直した)
- マイルストーン: D-471 ② 中身の器(T-0470 から分けた)
- 設計: docs/design/07-transport.md §2.5 / 決定: ADR-0117(レベルごとの小刻み T-0320)・ADR-0201(この直し)

## 目的(1〜2 行)
レベルごとの小刻み(T-0320・T-0356)の木で、箱全体の圧力が基準から一様にずれると(閉じた部屋の火・基準と違う大気・環境の差し替え)
偽の流れが出る不具合を、仕組みの根で直す(D-428: シミュの手抜きで結果を変えない)。

## 見つけた形(T-0470 の差し替えの試験から)
- 分けた形(レベル 0 は 24・レベル 1 は 48)の 2 レベルの閉じた箱で、基準の大気を 90 kPa・263 K に替える(セルは 101 kPa のまま)と、
  最大の速さが 30 刻みで約 21 m/s になり 90 刻みでも下がらない。分けない形(小刻み 48)は同じ差し替えで約 1 m/s(熱い泡の浮力と同じ程度)。
- 差し替えなしでも再現: 静止大気の全部のセルを同じ温度のまま物質量 +1/9(一様な加圧)にすると、重さなしで分けた形は 10 刻みで 10.6 m/s・
  60 刻みで 11.8 m/s、分けない形は 0(少しも動かない)。重さありでも分けた形 11.8 m/s・分けない形 0.03 m/s。
  今までの試験の静止大気は p = p_基準 ちょうどなので見えなかった。

## 根(原因)
- 力を先に当て、その運動量で流れを出す(前進・後退の順)。分けた形では、粗いセルが細かい面(細かい小刻みの面)から受ける圧力の力積は
  粗い小刻みの終わりに next へまとめて入る(refluxing)。そのため粗い小刻みの間の流れを出す forced の運動量は、粗い面の側の圧力だけを受け、
  細かい範囲の側の圧力を受けていない。圧力が基準と一様にずれていると(p̃ = α(p − p_基準) が一様に 0 でない)、境の粗いセルは片側だけから
  押され、偽の運動量で毎小刻み質量を流す(合計の運動量は next で釣り合うので保存は崩れない = 保存の試験では見えない)。
- Berger–Colella の refluxing は、粗い側も境の面の流束を自分で計算して使い、終わりに細かい側の合計との差を受け直す形。T-0320 は粗い側の
  見積もりを使っていなかった。

## 直し方(ADR-0201)
- 粗い側(小刻みの差 g > 0)の面の力(圧力の力積・重さ)は、粗い小刻みの初めにその面の初めの値 × 2^g を見込みとして forced に足し、
  同じ分を next から引く。next の合計は見込みの有無で変わらない(保存はそのまま。帳簿は本当の力の回だけ)。
  CPU は gas_tree.cpp の ApplySideForce、GPU は gas_tree_step.hlsl の AddFaceForces(同じ倍率 2^g・1 − 2^g)。
- 分けない形(g = 0 だけ)は何も変わらない(T-0208 のハッシュと一致のまま)。
