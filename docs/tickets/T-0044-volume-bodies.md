## 事前調査(2026-10-09、調べ役。読むだけ。未確認の数値は「推定」「未確認」)

### 今の実装の要点
- 物は直方体だけ(PxBody: halfExtent・質量・局所の主慣性の対角 3 つ・位置 2^-20 m・Q1.30 の四元数)。接触は箱どうしの解析解(分離軸 + 面の切り抜き。組 1 つに 8 点・点ごとの法線・特徴の番号で λ を引き継ぐ。T-0091)。
- 整数の AVBD(ADR-0014)。6×6 は対称スケーリング + Q62 の Cholesky、1 ウェーブ 27 レーン(T-0095)。広域と接触は Work Graph、色ごとの解は Compute。固定の上限(枠 16・組 24・色 16)。
- 島の方式は「解き方」として遅いので消した(T-0094/T-0099)。島の印(最小の番号を伝える)は CPU とビット一致していた。眠りは無い。ジャイロの項も無い。地面は箱。物と格子は y を裏返した別の座標(T-0098)。
- 場の側は ADR-0018 の wakeTick/busyTick(atomic の最小で起こす)と T-0100 の活性(種 + 面の隣を Work Graph の再帰で起こす)。

### 結論(推奨)
1. 体積は**場と同じブロックのプール(8³)に、キー =(物の ID, レベル, 座標)で持つ**(物の中の反応・伝導・待ちをそのまま使える)。物ごとのレベルは 0.5 m × 2^-k(k=3 で 6.25 cm、k=4 で 3.1 cm)。
2. 質量の性質は**整数のモーメントの和** S0=Σm・S1=Σm·x・S2=Σm·xxᵀ を 128bit で(ブロックごとの部分和 → 物の和。順番に依存しない)。燃えて変わったブロックだけ差分。重心 c=S1/S0、I_cm=S2−S0·ccᵀ。
3. 慣性は**局所の対称 3×3 をそのまま**(整数の固有値分解を作らない。AVBD は M/h²・I/h² を 6×6 に入れるので逆行列も要らない)。非対角で 6×6 の値の幅が足りるかは測る(未確認)。ジャイロの項は別の小研究。
4. 物の局所の原点はボクセルの格子に固定(特徴の番号 = ボクセルの座標で引き継ぎが安定)。重心のずれは c_local。重心が動いたら position += R·Δc、v と ω はそのまま。出ていった質量の運動量は場へ(R2。T-0047 までは帳簿)。y の裏返しはやめ、場の整数の座標に揃える。
5. 接触(T-0045 の前提): A の表面の点で B の**固体の割合の場を三線形で引き、0.5 の等値面を表面**に(法線は整数の中心差分)。地形の木も同じ式 → T-0049 の Surface Nets と見た目・当たりが揃う。点は決定的に減らす(一番深い → 接平面で一番遠い → 三角形の面積最大 → 四角形最大。同値は座標のキー。atomic の max)。直方体の解析解は形の種類として残し「ボクセルの箱 = 解析の箱」の基準に。
6. 眠りは**法則として定義**(CPU も GPU も同じ判定。「全部計算したのとビット一致」は一般には成り立たない。ADR-0018 との違いを ADR に書く)。物の見出しに wakeTick/busyTick、起こすのは atomic の最小。物理の眠りと物の中の化学の眠りは別(眠っている丸太も燃え続ける)。
   - 眠る判定: 物ごとの静かさの数(3 点の 1 刻みの動き < しきい値。Jolt と同じ)。**島は眠る判定の時だけ**、静かな物に限って最小の印を伝えて求める(T-0094 の部品を再利用)。成分の中で静かさの最小 ≥ N 刻み、かつ静かでない動く物と触れていなければ眠る。
   - 起こす: その刻みの中で閉包(Work Graph の再帰。WakeFaceNode と同じ形)。触れた・押された・反動(D-420)・形が変わった・重心が閾値以上ずれた・場の支えや水位が変わった。眠っている物の組と λ は残して温かく始める(Box2D と同じ)。
7. 場との受け渡し(T-0047 の前提): 外に出ている面のボクセルの中心 → 世界の点 → それを含む一番細かい本物のブロックのセル(索引で上へ。T-0100 と同じ)。流れは刻みの初めの値から両側に整数で加算(世代同期・R2)。押しのけた体積はセルへ atomic で足す(浮力・気体の空き)。動いている物は AABB のブロックをつつき、眠っている物は AABB にかかる場の変化で起きる。

### 方式の比較
| 項目 | 推奨 | 代案 | 採らない理由 |
|---|---|---|---|
| 体積の置き場 | 場と同じプール + 物の ID | 物ごとの密な箱 / 場に焼き込む | 多重解像度・切る(T-0046)を失う / 回すと形が崩れる |
| 慣性 | 対称 3×3 | 主軸に分解 | 整数の固有値分解が要る |
| 接触 | 点 対 割合の場 | 点 対 狭帯域の整数 SDF / 凸分解 | SDF を作り直す費用 / 壊れるたびの分解は決定的にしにくい |
| 眠りの島 | 判定の時だけ印を伝える | Box2D の持ち続ける union-find | 決定性のため直列の併合が要り GPU に向かない |
| 起こし | 同じ刻みで閉包 | 1 刻みに 1 歩 | 20 段の塔なら約 0.33 s 宙に浮く |

### 試す順番と、次の代案へ移る条件(D-411)
1. 工学: ADR(体積の持ち方・座標の統一・眠りを法則にする)→ 2. 工学: モーメントの和・3×3 の慣性・形と質量の更新(ボクセルの箱の慣性 = 解析の箱がビット一致・CPU と GPU 一致)→ 3. 研究: 眠り(山の種 1〜48 で残りの動きが消えるか〔BACKLOG の 2 割〕・正しい遅い動きを止めないか・眠ったり起きたりを繰り返さないか)→ 4. 研究・T-0045: ボクセルの接触で場面 A/C の基準(食い込み 2 cm・1 cm/s)。
- 移る条件: 接触の基準を満たさず原因が法線や角のノイズ → 狭帯域の SDF → それでも駄目なら「粗い形は箱や凸で、壊れた所だけボクセル」。眠りの印の伝え方が刻みの約 1 割を超える(しきい値未確認)→ 局所の規則(自分と触れている相手全部が静か)+ 同じ刻みの閉包。表面の点が予算超え → ブロックの占有ビットで間引き・粗いレベルの点で当て近い所だけ細かく。

### リスクと未確認
- 非対角の慣性・多数の点で 6×6 の値の幅が ADR-0014 の範囲に収まるか(要測定)。ジャイロの項が無いので細長い物の回転が正しくない可能性。
- 割合の場の法線は角を約半ボクセル丸める。角ばった物(D-405)の積み重ねへの影響は未確認。
- 眠りを入れると「眠らない場合」とはビット一致しない(法則としては決定的)。D-208 のため判定にプレイヤーとの距離を入れない。
- T-0098 の「組を局所の変数に持つと結果が揺れる」問題が残る。閉包や島の印をノードの局所に大きく持たない。
- 事例の数値(Teardown のボクセル 10 cm など)は未確認。AVBD の目立った続報(2026)は見つからなかった。

### 事例の要点
- Box2D v3: 島を持ち続け直列の union-find で併合・分けるのは遅らせ 1 刻み 1 つ・眠りは島ごと・起こすのは即座。FMA を切り三角関数を自作して機種をまたいで一致。
- Jolt: 島ごとに眠る・CROSS_PLATFORM_DETERMINISTIC は「試みる」。Rapier/Avian: enhanced-determinism。Teardown: 決定的ではない(2026 のマルチでは破壊だけ固定小数点のコマンドの列)。PhysX 5: SDF の当たりは接触が多くなる・GPU のバッファは固定で溢れたら捨てる。Box3D(Catto、2026 アルファ): スレッド数と機種をまたいだ決定性・記録と再生。
