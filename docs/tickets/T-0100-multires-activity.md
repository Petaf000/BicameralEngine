## 目的(1〜2 行)
多重解像度の木(T-0018)の上で、刻むブロックを「活性」のものだけにする。仮の世界(T-0005・T-0089)の活性の規則を木に広げ、
レベルの違う隣(親の覆われていないセル・細かい子の面)も起こす。全部を刻む CPU リファレンスとビット一致すること。
静かなブロックを粗くする要求は T-0101、一様なブロックは T-0102(2026-10-04 ユーザー決定で分けた)。

## 完了条件(チェックできる形で)
- [x] 活性の規則: 刻み t で刻むブロック = 種(刻み t − 1 に進める反応の規則があった・刻み t に木の変更でつつかれた)とその面の隣
- [x] 面の隣はレベルをまたぐ: 刻むセルどうしが面で接するブロック(粗い親の覆われていないセル・同じレベル・細かい子孫の面)。
      CPU のテストで、索引を引く方法と総当たり(覆われていない八分の一の箱どうしの面の接触)が毎刻み同じ集合になる
- [x] GPU は Work Graph(種 → 面の隣を起こす〔細かい側は再帰〕→ ブロックを刻む)。刻んだブロックの印と数が CPU と一致
- [x] 活性のブロックだけ刻んだ結果が、全部を刻む CPU(StepNest)と毎刻みビット一致(セル・端数)
- [x] 状態の全部と次の刻みの種の集合が CPU と GPU(HW・WARP)で毎刻み一致・2 回の実行で一致
- [x] T-0017 / T-0018 / T-0096 の場面がそのまま通る
- [x] build(debug / release)・tidy 警告なし・archmap OK・活性だけ刻む時と全部刻む時の GPU 時間を perf.md に

## メモ・参考
- 段をまたぐ輸送(T-0019)はまだ無いので、反応だけなら隣を起こさなくても結果は変わらない。隣を起こすのは T-0019 の前提を作るため。
  正しさは「総当たりの隣と一致」と「全部を刻む CPU と一致」の 2 つで確かめる。
- 観察の枠(影・写し)は活性に入れない(毎刻み全部刻む。D-403)。
