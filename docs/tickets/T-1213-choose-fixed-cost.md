## 内訳(2026-10-26・RTX 3070 Ti・release・compute キュー・`--no-gbv`・前の形 = ADR-0487)
| まとまり | 0.5 m の木(4,096 単位) | 広い木(65,536 単位) |
|---|---|---|
| 初め(1 Dispatch) | 0.0016 ms | 0.0024 ms |
| 置く(1) | 0.0016 | 0.0023 |
| 軸ごとの最小 × 3 | 0.0056 | 0.0094 |
| 集める(1) | 0.0015 | 0.0024 |
| 掃く・初めの 4 回 | 0.0086 | 0.0148 |
| 述語の写し(遷移 4 + 写し) | 0.0042 | 0.0043 |
| **掃く・残りの 124 回(述語で飛ばす)** | **0.0856(77 %)** | **0.0886(70 %)** |

| 和 | 0.110 | 0.126 |
- 述語は Dispatch を飛ばすが、Dispatch ごとの UAV の壁は飛ばない。飛ばした 1 回 ≈ 0.7 µs(壁)。走る Dispatch は 1 つ 1.5〜2 µs(セルの数にほぼよらない)。
