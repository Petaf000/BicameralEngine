## 目的(1〜2 行)
多重解像度で細かくする時の配り方を、SAME(子は親と同じ数)から「置かれ方で配る」1 つの規則にする。関数は state_field.hlsli(CPU と GPU の 1 つの源)に置き、
どの欄がどの置かれ方に乗るかは登録の印で決める(作業役が欄ごとに考えない)。

## 完了条件(チェックできる形で)
- [ ] state_field.hlsli に置かれ方の関数(縦に沈めて詰める・横の傾き minmod・列の重み・重みで配る)と登録の印(凝縮相に乗る・空きに乗る・無印 = SAME)
- [ ] wt3 の `SettleColumn`・`SettlePictureCell`(T-1106)と同じ答え(試験の中に写した参照の実装と、詰まり・傾き・物質を変えた場合でビット一致)
- [ ] 物質ごとの和はビット単位で保つ(全部の場合で)。一様な置かれ方では SAME とビット単位で同じ
- [ ] 欄の細かくする(nest_fields::Refine)に置かれ方を渡す口。渡さなければ今とビット単位で同じ(今の世界の試験がそのまま通る)
- [ ] release のビルド警告 0・archmap --check
