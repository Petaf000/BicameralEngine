## 目的(1〜2 行)
液体の区画の摩擦(今は区画の設定 `frictionShift`。全部の液体で同じ 1/128)を、物質の粘り(層流。溶けた岩・蜂蜜が遅い)と世界の環境の乱れの摩擦(川底。水の流れ方)から決める。

## 完了条件(チェックできる形で)
- [ ] 物質に任意の欄 `viscosity_pa_s`(読み込み・ベイク。液体だけ)。面の減り方 = 粘り ÷ 密度 ÷ 厚さ²(整数。面の両側のセルの液体の成分の比で混ぜる)
- [ ] 世界の環境の値に乱れの摩擦(Manning 型。速さの 2 乗。既定は無し = ブランクの世界は摩擦 0 で動く〔D-455〕か、断るかを決める)
- [ ] 粘りの大きい液体のダムが遅く広がる・水は T-0610 の測定と同じくらい駆け上がる・保存と決定性(T-0610 の試験のまま)
- [ ] release のビルド(警告 0)・ctest probe_liquid・reaction_package_test・archmap --check

## メモ・参考
- 水の本当の粘り 1 mPa·s では 0.5 m のセルの減り方は約 4e-5 /秒(ほぼ 0)。水の減り方は乱れの摩擦で決まる(Manning n = 0.02・深さ 0.5 m・3 m/s で約 0.09 m/s²)。
- 並走の注意: reaction_table.h の SpeciesDefinition・reaction_package.cpp の FIELDS(T-0609 が phase・density を足した所)に欄を足す。
