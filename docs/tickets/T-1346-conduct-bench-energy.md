- 種類: 工学(切り分け)
- PC: 必須
- 見積もり: チャット 0.5 回分
- マイルストーン: 列 4(元: T-1083 の「気づいたこと」)
- 設計: docs/design/07-transport.md / 決定: D-206(保存則)・T-1113(既定の熱の放射の段 RC。持ち越しと外へ出た分はセルの外)

## 目的(1〜2 行)
gpu_conduct_bench(ctest に無い測りの道具)の木箱の壁 1 点が main でも「エネルギーの保存 NG」と出る。本物の保存の破れか、道具の数え方の誤りかを切り分ける。

## 完了条件
- [x] 破れか道具の誤りかを決める根拠(CPU リファレンスとの刻みごとの突き合わせ・放射を含む保存の式)
- [x] 道具の誤りなら道具を直す / 破れなら最小の場面とどの段で失うかをこのチケットに

## 見立て(コードを読んだ所)
- 道具は刻みごとに「GPU のハッシュの表のセルのエネルギーの和 = 前の和 + つつきの分」で保存を見ていた。
- T-1113 から仮の世界には既定で熱の放射の段(RC)が入る。放射の持ち越し・世界の外へ出た分はセルの外にあり、GPU のハッシュの表には無い
  (CPU は ProbeReference::CascadeRadiationUnits で持つ)。gpu_probe_sim_test は「セル × 2^16 + CascadeRadiationUnits」で保存を見ている。
- 空気のつつきは放射の吸い込みが 0 の物質なので放射が動かず OK、燃える木箱は放射が動くのでセルだけの和が外れる → 道具の数え方の誤りの見込み。
- 同じ数え方が gpu_probe_fire_test(DISABLED。T-1066)の AccumulateFrame にもある(止めを外す時に同じ直しが要る)。

## 直し(道具だけ。シミュのコードは変えない)
- tests/gpu_conduct_bench.cpp: GPU を走らせた後、同じ刻みの数だけ CPU リファレンスを走らせ、刻みごとの要約(ハッシュ・エネルギーの和・つつき・ブロックの数)が一致し、
  CPU で放射を含む保存が成り立つことを合格の条件にした。セルだけの和の保存は参考の行(外れたら放射がセルの外に持つ分の mJ と一緒に出す)。
- CPU の RC の段は重い(64³ で 1 刻み約 0.85 s。T-1347 の測り)ので、突き合わせは既定で各場面の初めの 160 刻み(--check-ticks n。0 = 全部)。
  セルだけの和が最初に外れた刻みも出す。
- 変わり目の当たり: GPU の仮の世界に RC が載ったのは T-1154 の b02c1368(2026-10-26)。この後から木箱の壁で NG になった見込み(T-1083 で気づいた時は既に main)。
- 同じ数え方が gpu_probe_fire_test(DISABLED)にある。止めを外す時(T-1156)に同じ直し(CPU と突き合わせるか、セルだけの和は見ない)が要る。

## 結果(2026-11-12 wt4・release・RTX 3070 Ti・main 75656697 の上)
`run -Preset release -Exe gpu_conduct_bench`(突き合わせは各場面の初めの 160 刻み): **gpu_conduct_bench(hardware): OK**
| 場面 | GPU の刻み | CPU と一致(ハッシュ・エネルギー・つつき・ブロック) | 放射を含む保存(CPU) | セルだけの和 | 放射の置き場の溢れ |
|---|---|---|---|---|---|
| 空気 1 点 | 2000 | OK | OK | OK(放射がセルの外に持つ分 0) | 0 |
| 空気 8 点 | 608 | OK | OK | OK(0) | 0 |
| 空気 64 点 | 304 | OK | OK | OK(0) | 0 |
| 木箱の壁 1 点 | 3600 | OK | OK | **刻み 1 から外れる**(160 刻みの終わりで放射の段がセルの外に持つ分 6873049807 mJ) | 0 |
- **本物の保存の破れではなく、道具の数え方の誤り**: GPU は CPU リファレンスと毎刻みビット一致し、CPU では「セル × 2^16 + 放射がセルの外に持つ分」がつつきの分だけ変わる。
  セルだけの和が外れるのは燃える木(放射の帯を持つ)が刻み 1 から RC の段で放ち、その分がセルの外(持ち越し・外へ)にあるため。空気は放たないので外れない。
- 外に持つ分の大きさ(6.9 × 10^9 mJ)は参照の温度 300 K との差の正負の持ち越しの mod 2^64 の和で、意味の読みは未確認(保存の式はこの値で閉じる)。
- CPU の突き合わせは速かった(160 刻み × 4 場面で数秒ずつ)。全部の刻みを見たい時は --check-ticks 0。
- 時間(参考・ほかの作業ツリーと並走): 空気 64 点 伝導と反応 147.5 µs/刻み。
