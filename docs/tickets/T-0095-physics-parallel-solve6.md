## 目的(1〜2 行)
色ごとの解で、1 グループ 64 スレッドのうち 1 スレッドだけが 6×6(PxSolveSymmetric6)を解き、残りが待っている。これが 1 刻みの 56%(山で約 2.0 ms、1 回 約 42 µs)。
同じ演算を数スレッドに分けて待ち時間を縮める。演算の中身と順番(各要素の式)は変えないので、CPU とビット一致のまま。

## 完了条件(チェックできる形で)
- [x] 尺度合わせ・Cholesky(列 j の下の行 i > j を並列に)・前進と後退の代入を、グループの数スレッドで分けて解く(共有メモリと同期)。要素ごとの式は CPU(physics_math.hlsli)と同じ
- [x] 3 場面の全部の刻みで CPU とビット一致・2 回の実行で一致(gpu_physics_*)
- [x] `gpu_physics_test --profile` で色ごとの解の時間を T-0093 と比べる(山 SolveColor 15.8 µs/回・1 刻み 3.54 ms。T-0094 の後の数字とも比べる)
- [x] 足りなければ、平方根と割り算を減らす研究(LDLᵀ・対角の逆数。値が変わる)に進むかをユーザーと決める(打ち切り条件を書く)

## メモ・参考
- T-0093 の診断: 6×6 を 2 回解かせると +11.2 µs/回。平方根 6 回 ≈ 3 割・128÷64 の 27 回 ≈ 3 割・残りは 64bit の Q の積と局所の配列(推定)。
- 6×6 の局所の配列は添字で引かれてメモリに置かれる(DXIL の alloca 8 個)。共有メモリに置くと、それも減るかもしれない(未確認)。
- 並列にできるのは 5〜6 本まで(6×6 は小さい)。T-0094 の島の方式の中で使う形にする。
