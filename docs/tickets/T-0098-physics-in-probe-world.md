## 目的
窓の中で、熱の伝導・燃焼と同じ GPU の世界の刻みの中で角ばった箱が崩れる。CPU は入力と Present だけ。
CPU リファレンスとビット一致・2 回の実行で一致・再生でハッシュ列が一致。

## 完了条件
- [ ] 物理の 1 刻み(sim/gpu_physics。広域と接触は Work Graph・色ごとの解は Compute)を仮の世界の刻みの単位に入れる(ProbeSim の単位の表・UnitsPerTick)
- [ ] 箱の状態を世界の状態のハッシュに入れる(刻みの最後のハッシュの単位)。再生ファイルでハッシュ列が一致(window_replay_*)
- [ ] 箱の位置と向きを抽出へ写し、デバッグ表示に回転した箱として描く(格子の中の座標。立体と断面の両方)
- [ ] 場面: 積み木の規模(箱 11 個。08 §6 の場面 A の小さい版)が崩れる。崩すきっかけ(最初から崩れる積み方か、クリックで押すコマンドか)はこのチケットで決める
- [ ] CPU リファレンス(sim::PhysicsWorld)と毎刻みビット一致、2 回の実行で一致(GPU のテスト)
- [ ] 窓の GPU 時間(シミュ ms/投入)を docs/perf.md に。map.yaml

## メモ・参考
- 積み木は 1 刻み約 2.6 ms(T-0092)。60 刻み/秒で GPU の約 16%。山(56 個)は 3.75 ms/刻みと重いので M1 では使わない(速くするのは T-0094・T-0095)。
- 物理の GPU は区間の数を読み戻さずに固定の数だけ投げる。統計の overflow が 0 でなければ結果は信用できない(HANDOFF の注意)。
- やらないこと: 箱と世界のセルのやり取り(燃える・熱で変わる・セルを押しのける)。M6 で。
