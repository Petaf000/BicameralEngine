## 目的(1〜2 行)
仮の世界(64³ の熱)を面 1 枚ではなく**立体のまま**見られるようにし、カメラで回り込んで、見ている所をクリックでつつけるようにする。
以降の原理の確認(化学・物理・多重解像度)で「何が起きているか」を目で確かめる道具にする。

## 完了条件(チェックできる形で)
- [x] 抽出を 64³ の全体 + ブロックごとの活性の印にする(描画は抽出だけを読む。CPU は世界を読まない)。抽出は CPU リファレンスとビット一致(全体のハッシュ)
- [x] 描画: 格子のボリューム表示(レイマーチ)を 3 通り — 吸収と発光(ボリューム)・最大値の投影・断面。量の色分け(対数/線形の切り替え・凡例の帯)
- [x] 重ね書き: 格子の枠・断面の枠・活性なブロック(次の刻みで計算する所)
- [x] カメラ: 回り込み(右ドラッグ)・平行移動(中ドラッグ)・寄る(ホイール)・透視/平行投影・リセット。カメラは View の状態で、世界には入らない
- [x] クリック: カメラの光線と断面の交点のセルをつつく(断面の軸と位置はキーで動かす)。つつきは今までどおり整数のコマンド(再生で再現できる)
- [x] `--screenshot <path>`(最後のフレームを BMP に)・`--view <volume|mip|slice>`・`--camera <yaw>,<pitch>,<距離>` で、自動で絵を撮って確かめられる(10 のテストの入口)
- [x] カメラの光線と拾うセルの単体テスト(GPU なし)。描画の GPU 時間を docs/perf.md に
- [x] (シミュ)既存の gpu_probe_sim のビット一致・再生のテストがそのまま通る

## メモ・参考
- 操作: 左クリック = つつく / 右ドラッグ = 回る / 中ドラッグ = 平行移動 / ホイール = 寄る / 1・2・3 = 表示 / X・Y・Z = 断面の軸 /
  Q・E(Shift で 8)= 断面を動かす / B = 活性なブロック / L = 対数・線形 / O = 透視・平行 / R = カメラを戻す
- 座標: 世界 = セルの番号(0〜64)。既定のカメラは +z を向き、画面の右 = +x・下 = +y(今までの z = 32 の面の見え方と同じ)。
- 時間の操作(止める・1 刻み)・値の読み取り(カーソルの下のセルの数値)・文字の表示はこのチケットに入れない(14 §2 の別のパネル・12 §5)。
