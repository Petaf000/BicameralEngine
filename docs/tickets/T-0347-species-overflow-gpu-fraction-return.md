# T-0347 GPU で畳む時に端数の溢れを帳簿へ返す・端数の枠の塊を返す(T-0329 から分けた)

- Status: Todo(T-0329 の後。畳むは T-0312 と合わせてもよい)
- 種類: 工学
- 設計: 02 §3・17(R-MULTI-4)・ADR-0052(追記 7・9)。関係: T-0311・T-0312・T-0329

## 今(T-0329 の後)
- 畳む時に端数を帳簿へ返す(multires_tree.hlsl の ReturnFractionCell。TreeFoldCheck の中)はインラインだけ: 溢れのある端数の枠を畳むと
  溢れの成分を帳簿へ返さない(保存が崩れる)。TreeFoldCheck は既定の世界の 1 組だけで、溢れの変種が無い(g_overflowBase を読めない)。
- 端数の枠が持つ塊は返さない: 枠を空きに返しても付けたまま(T-0311)、粗くした後の新しい面の余り(上限で取った分。T-0329)も付けたまま
  (刻みの段の WideAllocate は頁しか見ない)。端数の溢れが多い世界では置き場が細る。

## やること
1. TreeFoldCheck(と TreeFold)の溢れの変種(MR_WIDE_CELLS。T-0312 の「畳む」と同じ変種にする)で、ReturnFractionCell が端数の枠の今の面の
   溢れの成分も帳簿へ返す(CPU の ReturnFractionsToLedger。溢れまで)。返した枠の今の面を空にする。
2. 端数の枠の塊を返す: 木の管理の段(要求の処理の後に 1 グループの段を足すか、TreeRelease の溢れの変種)で、要求の順の累積和で
   (a) 空きに返す端数の枠の両面の塊、(b) 粗くした親の端数の枠の今の面の余り(MrWideChunksFor(溢れの数) を超える分)を空きのスタックに積む。
   刻みの段を足したら RecordWideRetry の約束を確かめる。
3. 試験: 溢れのある端数の枠を畳む場面(multires_wide_test に CPU の場面があれば GPU でも)と、粗くして細かくし直すのを繰り返しても
   置き場の空きの数が戻る場面。CPU と HW・WARP が毎刻みビット一致。

## 完了条件
- 溢れのある端数の枠を畳んでも保存がビット一致・置き場の塊が枠に残り続けない
