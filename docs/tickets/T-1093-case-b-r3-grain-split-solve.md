# T-1093 R3 の続き(代案 (b)): 粒どうしの押し合いを空気の圧力と分けて解く — 最初の見立て

- Status: Proposed(**見立てだけ。着手はユーザーの判断の後**)

- マイルストーン: ③'(案 B の判定)

## 中身(案)
粒の流れは粒の体積と摩擦だけで決め(陽)、空気の陰の圧力は粒を孔(Darcy)と「速さの決まった相」として見る(T-1092 と同じ口・右辺だけ)。
粒と空気の引きずりは、空気の圧力を解いた後に面ごとの 2 相の小さな陰の連立で受け渡す。

## 最初の見立て
- **D-556(B-a: 引きずりは圧力と一緒に解く)の決め直しに当たる。** 分けて解くと、強い引きずり(詰まった砂の中の空気・水。K Δt ÷ m が 1 刻みで 10^3〜10^6)で、
  染みる速さが刻みの長さで変わる(21 §2.3 で採らなかった理由そのもの)。R2 の Darcy・砂の芯・砂の堤の行(刻み 1/60 と 1/120 で ±5 %)が崩れる見込み。
- 引きずりを圧力の後に陰で受け渡すと、粒の体積の流れが圧力の釣り合いの外で変わる(T-1043 の (b) と同じ食い違い)。
  食い違いを次の刻みの圧力の右辺に持ち越す(体積の誤差の持ち越し。21 §2.10 の端数と同じ形)なら決定的に閉じる見込み(未確認)。
- 濃い砂の塊が空気と一緒に落ちる(T-1003 の直し)・砂時計の空気の逆流は残る見込み(受け渡しは陰のまま)。
- T-1092 で見た「表面のセルのつなぎを弱めると空気が暴れる」は (b) でも起きうる。先に暴れの元を測る(T-1105)。

## 問い【エンジン】(司令塔からユーザーへ)
- 粒と空気(と水)の引きずりを、圧力と一緒に解く形(D-556)のまま砂の止まる角度を探し続けるか、粒だけ分けて解く形(b)を試すか。
  作り手から見た違い: (b) にすると、砂の中を染みる水・空気の速さが刻みの長さで少し変わりうる(R2 の線 ±5 % で測る)。砂山・斜面の止まる角度が空気のある所でも書いた値に近づく見込み(未確認)。

## 分けたもの
- T-1105(測り・R3): 表面のセルのつなぎを弱めた時に空気が暴れる元を測る(陰の圧力の解き残り・層のセルの体積の食い違い・戻りの減衰)。(a)(b) どちらにも要る。
