## 目的(1〜2 行)
CPU → GPU のコマンドキュー(適用する刻みを付けて、同じ刻みの中は番号順)と、GPU → CPU のイベント(キーで並べてからリングへ)を本物の形にし、
「初期状態 + コマンドの列 + 刻みごとのハッシュ」の再生ファイルで世界が再現できることを確かめる。

## 完了条件(チェックできる形で)
- [ ] コマンドキュー: 刻みをまたいで待つコマンドを GPU 側に持ち、刻みの単位が「その刻みの分」だけを適用する(フレームの切れ目と関係なく)
- [ ] イベント: 刻みの終わりにキー(刻み・種類・場所)で並べてからリングへ。溢れたら落とした数を数える
- [ ] 再生ファイルの骨組み(形式の版・初期状態・コマンドの列・刻みごとのハッシュ)を書く・読む
- [ ] 記録した窓の操作を再生して、同じハッシュ列になるテスト(06「テスト」の 2 つ目・15 §2)

## メモ・参考
- 刻みごとのハッシュは T-0012 で入る。
