## 目的(1〜2 行)
T-0631 の直し(ADR-0292。頭打ちの温度を拡散の数で)の後も、仮の世界の燃える木箱の下半分に市松が残る(谷か山 3044・250 K 未満 589)。
頭打ちを温度でなく拡散の数そのもの(c_e² ∝ γ p/ρ = γ RT/M)で比べる形にし、T-0646 の直しと合わせて市松が消えるか確かめる。

## 完了条件(チェックできる形で)
- [ ] T-0646(出ていく割合の上限)が main に入った上で、probe_gas_test の 9(市松の物差し)を測り直す(残りが熱が負の穴だけなら、ここは頭打ちだけ)
- [ ] 頭打ちを T × M_基準 ÷ M(できれば γ も)で比べる: CPU gas_reference の ScalePressure・gas_tree の DeriveGasTreeCell・GPU gas_cell.hlsli(と木の GPU)
- [ ] gas_reference_test の等圧の熱い塊に、もっと軽い気体(H2 など)・単原子の気体を足して真空のセルができない
- [ ] probe_gas_test の 9 の谷か山を EXPECT に(なめらかな柱の山の数の目安を決めて)
- [ ] CPU と GPU のビット一致(gpu_gas・gpu_gas_tree・gpu_probe_gas)・保存・release の警告 0・archmap --check
