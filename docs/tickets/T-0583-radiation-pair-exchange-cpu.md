## 作り手から見た違い(何を書くと何が起きるか)
- 物質に `radiation_absorption_mm2_per_mol = a` を書くと、その物質を含むセルが放射を出し・吸う。セルの吸収率(= 放射率)は
  α = 1 − e^−τ、τ = Σ a × 物質量 ÷ セルの面(0.25 m²)。**薄く少ない物は半透明、多い塊は黒い**(同じ欄で、煙・草・砂・ガラスが書ける)。
  例: a = 500,000(0.5 m²/mol)の物 1.2 mol のセル → α = 0.91。砂 2000 mol なら a = 100 でも α = 1。
- 書かない物質は放射しない・吸わない(既定 0)。今ある標準パッケージ・試験の表は書いていないので、世界の結果は変わらない(ブランクの世界は放射なし)。
- 2 つのセルの交換 = σ × 面 × Δt × α_i × α_j × 見え方の割合 F × (T_i⁴ − T_j⁴)。σ は器の定数(パッケージでは変えない。ADR-0252 の判断待ち 2)。
- 物質の欄は今は CPU のリファレンスだけが読む(世界の刻みにはまだ入らない。T-0585)。

## 決めた形(仮。ADR-0252)
- 放射の対の係数は伝導の面の係数と同じ単位にした: h = σAΔt·w·(T_i + T_j)(T_i² + T_j²)、流れ = h × ΔT >> 32。伝導の面の流れと同じ形で、
  i と j について対称な式なので、入れ替えると符号だけ反転する(保存)。h ≥ 0 なので坂を下る(D-466)。
- 行き過ぎの上限: 対の係数 ≤ min(両側の熱容量) × 1/4 × 対の分け前。1 つのセルの分け前の合計 ≤ 1 にすれば、伝導(6 面で 6/8)と合わせて
  新しい温度は凸結合で、温度の順序が入れ替わらない。**分け前をどう配れば受け手の側でも合計 ≤ 1 になるかは T-0584 の研究**(光線の組の決め方)。
- 温度は約 134,000 K(2^27 mK)で飽和(各セルの温度だけの関数なので保存と対称は崩れない)。精度: 流れの mJ への切り捨てを除いて相対 1e-4 以内(試験)。

## 判断待ち(仮で進めた。ユーザー未確認)→ ADR-0252
1. 物質の放射の性質の書き方: 仮 = 「1 mol が遮る面積」(案 B)。代案 A = 物質ごとの放射率 0〜1(セルは混ぜ方の規則が要る・煙の濃さが書けない)。
2. σ を器の定数にするか、世界の値(環境のパッケージ)にするか: 仮 = 器の定数(R と同じ扱い)。
3. 放射率 > 1(黒体より強く光る物)を許すか: 仮 = 許さない(α ≤ 1。灰色体)。
