# T-1261 違う大きさの面の対の負の項を、粗いセルの材料の硬さとの直列にする(T-1260 の根の直し)

## 目的(1〜2 行)
T-1260 の根(④ の対のずれの負の項が、根の角で強く変わる伸びまで粗いセルに掛けない = 粗いセルの材料の硬さまで外す)を一つの芯で直す。
「粗いセル C が表せない分だけ外す」を「C の材料の硬さを残して外す」に: 対の相対のずれの硬さを、外す前の硬さ K と C の材料の硬さ K_C の直列 K K_C ÷ (K + K_C) にする
(負の項の係数 = K − 直列 = K² ÷ (K + K_C))。

## 完了条件(チェックできる形で)
- [ ] 根の線の両側だけの 2 場面(support_mixed)のたわみ ±5 % に入り、試験の線を 6 % → 5 % に戻せる
- [ ] ほかの support_mixed の場面(上の段だけ・張り出し・洞窟ほか)の値が悪くならない(5 % の線の中・縁の力の差が大きく増えない)
- [ ] 自重の塊(support_cost_test `--coarse`)の移り目の縁の力の差が ④ の 2.19 % / 1.35 % から大きく悪くならない
- [ ] 違う大きさのセルが無い場面はビット一致・帳簿厳密・決定的(support_law・support_mixed)
- [ ] 当たれば ADR-0501 の残り 4.87 %(上の段だけの根の柱)が同じ芯で下がるか確かめる(未確認)

## 研究の打ち切り条件
- 形は 2 つまで・各 30 分(ビルド・測りを除く考える時間)。どちらも CPU の支えの法則(support_mixed_test `--study`・ctest の support_mixed・support_cost `--coarse`)で確かめる。
  - 形 A: K_C = C の断面全部(2s × 奥行き)÷ 対の中心の間 s = 12 b(b = 対の並ぶ向きの硬さの単位。同じ大きさの面は 6 b)
  - 形 B: K_C = 面の側の C の半分(s × 奥行き)÷ s = 6 b(細かい面の伸びの硬さと同じ)
- どちらも根の線の両側の 2 場面が ±5 % に入らない(負の項を 0 にしても 1.030 なので、届く下限は 1.03 前後)か、ほかの場面(特に上の段だけ・自重の塊)を 5 % の外へ出すなら打ち切る。
- 場面ごとの係数・場所による補正は入れない(形は C の材料の硬さだけで決める)。
- 退く道(打ち切った時): T-1260 の退く道のまま(既定 refineRing = 1 で作られる形は 1.023・周りなしの比べ用の 2 場面だけ線 6 %)。
  作り手から見た違い: 書く値は無い。周りを分けない設定にした時だけ根の角が約 5 % 柔らかい。

## メモ・参考
- 一様な歪みのつぎはぎの検査では、C の歪みは C の外の面(中心の変位の差)が既に持つので、残した硬さはその分を 2 度数える(一様な ε で対の相対のずれに偽の力)。
  直列にしたのはその分を小さくするため。どれだけ効くかは自重の塊と ctest の場面で見る。
- T-1260 の捨てる試し: 負の項を 0 にすると 1.030(③ の 1.009 との間)。上の向きの面だけ 0 で 1.031。
