# T-0761 観察の枠(影・写し)の欄: 影を細かくする/引き戻す・写しを置くで登録した欄を付いて行かせる

- 種類: 工学
- PC: 必須(CPU の試験だけ)
- 見積もり: チャット 1 回分

- 設計: docs/design/20 §2.1 / 決定: ADR-0329・ADR-0361・D-403

## 目的(1〜2 行)
RefineShadowChain・PullBackShadowChain・PlaceMirrorBlock で、状態の登録(ADR-0329)の欄(気体の運動量・液体の面の運動量など)を付いて行かせる。
影の欄の引き戻しの規則を決めて ADR に残す。

## 完了条件(チェックできる形で)
- [x] 欄(運ぶ計算と同じ形の欄 + 試験の欄)を持つ世界で、影を細かくする/引き戻す・写しを置くの前後で本物の葉の要約と保存量(帳簿込み)がビット単位で同じ
- [x] 覗く世界と覗かない世界の本物の葉の要約・保存量が毎刻み同じ(見るだけなら世界は変わらない。D-403)
- [x] 既存の影・写しの試験はビット一致のまま(欄の無い世界は何も変わらない)
- [x] release のビルド(警告 0)・archmap --check

## メモ・参考
- 規則: ADR-0361。共有の関数は shaders/common/state_field.hlsli の SfPullBackChild(段 6 の GPU もこれを呼ぶ)。
- CPU: engine/src/sim/multires_fields.cpp の nest_fields::RefineShadow・PullBackShadow。写しは nest_fields::PlaceRoot で 0 から。
- 試験: tests/multires_state_test.cpp の 5(TestShadowFields・TestMirrorFields・TestPullBackRule)。

### 判断待ち(仮で進めたもの。ユーザー未確認)
- 影の欄の引き戻しの配り方(ADR-0361 の 2): 全部 0 以上の組は比で配る・負の値がある組は等しく足す。
  作り手から見た違い: 影の中の細部(覗いて見る細かい流れ)が残る・負にならない量は負にならない。代わりに「子を全部親の値に戻す」なら影の細部が毎刻み消える。
- 写しの欄は 0 から・写す元の欄は呼ぶ側が書く(仮の世界が欄を持つのは設計 20 §3 の後)。
