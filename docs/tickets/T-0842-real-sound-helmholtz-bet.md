# T-0842 本物の音速の陰解法(Helmholtz)を 1 刻み 1 回・V 2 回・外側 0 で固定する賭けを CPU で安く確かめる

- Status: Done(研究の答えを出した。採るかは司令塔 → ユーザー)
- 種類: 研究(CPU だけ。GPU は使わない)
- PC: 必須(ランナーで release のビルドと実行)
- 見積もり: チャット 1 回分(2 時間)
- 関係: ADR-0346(最速 × 外側の反復の発散と打ち切り)・D-515・D-519・T-0722・T-0788・docs/design/07 §2.6・§2.8

## 目的
気体の費用は音の小刻み 24 回に集中している(気体 285 ns/セル・液体 4.5 ns)。設計の壁打ちの「賭け 1」:
縮みの分を「本物の音速の状態式(C = V/c²)の陰解法を 1 刻みに 1 回・V サイクル 2 回・外側の反復 0 回で固定」で解けば、小刻み 24 回が要らない。
仮説: ADR-0346 の発散の根は最速(C → 0)にある。本物の音速 340 m/s なら、1 刻みに 1 面を通る量 ÷ 中身は
≈ (a/α)·Δp·dt²/(ρΔx²)(a = 面の開き ≤ α = セルの空き)で α によらないので、小さいセルは開いたセルより悪くならない。

## 完了条件
- [x] 既存の場面(細孔の板 16³・空き 1/256・1/16・1/4 × 差 1.02・1.2 倍 / 孔の壁 / 静止大気 / 泡 / 扉 / 熱い柱〔爆発の後〕)を
      音速 340・外側 0(と 1)・V 固定 2・excludeCutFlows で 300 刻み回す(`gas_projection_test --t0842`)
- [x] 版 2: 運ぶ側の局所の小刻み(出ていく量 ÷ 中身 > 0.9 のブロックだけ n = ceil(比) 回・上限 8)+ 切った面の運動量を実際に運んだ量に合わせて縮める
      (差は熱と帳簿の壁の力積へ)
- [x] 合格: 300 刻みで |x| ≤ 初めの差 × 10・最大の速さ ≤ 2√(2Δp/ρ)・保存がビット一致・2 回の実行でハッシュ一致・泡の重心が陽解法と ±10 %
- [x] CPU の 1 セル 1 刻みの時間を陽解法と並べて記録(参考。docs/perf.md)
- [x] 既定の値は変えない(足す口は既定で切ってある)

## 研究の打ち切り条件
版 1(音速 340・外側 0/1・V 固定 2)と版 2(+ 局所の小刻み・切った面の運動量)の 2 版で、
板の 1.02 倍・1.2 倍が 300 刻みで有界(|x| ≤ 初めの差 × 10・速さ ≤ 2√(2Δp/ρ))にならなければ、仮説は外れ。結果をそのまま書いて終える。

## 結論
1. **仮説は当たった(測った範囲)**: 同じ板・同じ外側の反復の形で、最速(C → 0)は 4〜18 刻みで int64 の手前まで発散し、本物の音速(C = V/c²)は
   空き 1/256 でも max|x| ≤ 1.01 dp で有界。空きの小さい板が開いた板より悪くならない(1/256: 0.85、1/4: 0.42。どちらも dp を超えない)。
   外側の反復 0 回(解き直さない)でも、V 2 回固定でも、有界・保存・決定性は崩れない。
2. **版 2 は有界には要らない**(版 1 で全部通った)。効くのは「渡る速さと釣り合いの量」: 1.2 倍の板で、釣り合った後の渡った量が
   陽解法との差 v1 −11 %(1/4)・−4.7 %(1/16)→ v2 −4.7 %・−1.2 %。1.02 倍では v1 と v2 はほぼ同じ。
3. **費用(CPU の模型・参考)**: 1 セル 1 刻み 外側 0 で 2.5〜5.3 µs、外側 1 で 3.1〜8.2 µs。陽解法(小刻み 24)は 9〜65 µs → 約 1/4〜1/12。
   v2 の上乗せは +3〜16 %(孔の壁 +16 %・1.2 倍の 1/256 の板 +11 %)。CPU の模型は毎刻み式・多重格子を作り直すので、GPU の比はこれと別に測る(未確認)。
4. **見えた違い(合格の条件の外。採る前に確かめる)**:
   - 後退 Euler の音(1 刻みに約 11 セル)なので圧力の波・揺り戻しは消える(扉: 陽解法は 30 刻みで 22.7 → 300 刻みで 20.1 と揺れる、投影は 19.0 → 19.5 で単調)。
   - 釣り合いの量が陽解法とずれる(上の 2。最大 −11 %)。根は未確認(見立て: 断熱の気体で、どこで運動のエネルギーが熱になるかが違い、
     板の上下の温度 → 重さの釣り合いの量が違う)。D-428(手抜きで結果を変えない)に当たるかは、温度の分かれを測って決める。
   - 熱い柱の最大の速さが陽解法より +25 %(2.61 / 2.08 m/s)。
5. 打ち切り条件(2 版で板が有界にならなければ外れ)には当たらない。次の手(司令塔・ユーザーが決める): GPU の気体の段を「音速 340・V 2 固定・外側 0」の
   投影で置き換える見積もり(GPU の費用を測る)と、上の 4 の釣り合いの量のずれの根を調べる研究(打ち切り付き)。
