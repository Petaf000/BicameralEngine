# T-0276 成分の二段: 一様なブロックの評価が 9 種目の生成物を待たせる(溢れを使う世界。CPU と GPU を一緒に直す。T-0199 で見つけた)

## 見つけたこと
溢れを使う世界(CPU の EnableWideCells・GPU の wideCells)でも、一様なブロック(値 1 つ)を待ちの丸めで評価する所(CPU の StepBlocks の初めの
MrUniformWaitOf・GPU の multires_wait_step.hlsli / multires_conduct.hlsli)はインラインの形(RxCell)で評価する。8 種そろった一様の値で
進む規則が「9 種目を作る規則」だけだと、評価では待たされて「変わらない」になり、頁に広げない(= その規則が進まない)。
頁に広げた後のセルは上限の無い形で刻むので、ほかの規則・熱の流れ・介入で広がれば進む。CPU と GPU は同じふるまいで一致している
(T-0199 で CPU だけ上限の無い形で評価すると gpu_multires の「大きい溢れ」が刻み 0 で食い違ったので、CPU は溢れの無い一様の値をインラインで評価するまま。
一様の値に溢れがある時〔T-0199 で畳めるようになった。GPU にはまだ無い〕だけ上限の無い形で評価する)。

## プレイヤーと遊びへの影響
- 8 種がちょうど混ざった一様な広い領域(例: 何も起きていない大きな混合物)で、9 種目を作るゆっくりした反応だけが起こるはずの時、その反応が止まって見える
  (熱が流れ込む・触る・魔法で乱すと急に進み出す)。「長くかかる反応も起きる」(D-428)に反する。めったに無い場面だが、研究の再現性に関わる。

## やること(案。仮)
1. 溢れを使う世界では、一様の値の評価で「9 種目の生成物を待たせた」(RX_LIMIT_PRODUCTS の印)なら「変わる」として頁に広げる(CPU と GPU の両方。
   GPU は印を見るだけなので軽い)。広げた頁のセルは上限の無い形で刻むので、待たずに進む。
2. 試験: 8 種の一様な根で 9 種目だけを作る規則がある場面を、溢れの世界で CPU と GPU(HW・WARP)が毎刻みビット一致し、9 種目ができる。

## 完了条件
- 溢れを使う世界で、一様なブロックでも 9 種目の生成物を待たせない(CPU と GPU が一致)
