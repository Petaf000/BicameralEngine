## 目的(1〜2 行)
陰解法で解くブロック(基準より細かい本物のブロック)の開いた世界の端の面を、GPU の陰解法(gpu_multires_implicit・implicit_build.hlsl)でも
CPU と同じに流し、帳簿の「世界の端」へ。CPU は wt5 の T-0790 が直し、形を共有の .hlsli に置く(今は CPU も GPU も wall と同じ)。

## なぜ分けたか
- 陰の伝導を当てる段へ移す T-0715 と、陰のブロックの開いた端を直す T-0790(どちらも wt5)が同じ所(multires_implicit_conduction.cpp・系の面・
  TxApplyFaceFlow)を触る。GPU はその共有の形に合わせる(司令塔の指示 2026-10-18)。外の柱は表の語 t2(T-0773・ADR-0343)から読める。
