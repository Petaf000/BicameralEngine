## 目的(1〜2 行)
影の引き戻し(PullBack*Level)は今、層を付け替え(層 = min)だけで扱う。影は観察用なので真実は変わらないが、観察の見え方に層を出す時は
影の層を親の層に合わせる(細かくする時の配りと同じ規則)。

## 完了条件(チェックできる形で)
- [ ] 影を作る時・引き戻す時に、影の層を親の層から置かれ方で配る(子の層の和 = 親の層 × 8)
- [ ] CPU と GPU(Work Graph の PullBackNode)でビット一致。GPU の層の頁は T-1221・T-1240 の形
- [ ] 影の無い世界・層の無い世界はビット単位で今と同じ
