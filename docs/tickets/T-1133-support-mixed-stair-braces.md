# T-1133 違う大きさのセルが絡む段の斜めの棒(T-1067 の残り)

## 目的(1〜2 行)
段の斜めの棒(ADR-0415)は今、同じ大きさのセルどうし(粗いセルどうし・細かいセルどうし = T-1067 の AddFineBraces)だけに置く。
段の角に粗いセルと細かいセルが絡む所(斜めの 2 つのセルの大きさが違う・間のセルが分けたセル)にも棒を置き、細かくする道の境が段の角に来ても答えが変わらないようにする。

## 完了条件
- [ ] 段の角だけを分けた場面(壁と梁の角の片側だけ 0.25 m など)で、全部 0.25 m の根の面の縁の力と ±5 %(`support_fracture_test --root-compare` の形)
- [ ] 帳簿厳密・決定的・同じ大きさの場面はビット一致

## 研究の打ち切り条件
棒の端を ① 粗いセルの中心 ② 粗いセルの角に近い細かい場所(剛体の動き)の 2 通り試して ±5 % に入らなければ、司令塔へ(退く道: 段の角の周りは両方とも分ける = 細かくする規則の側で避ける)。

## メモ・参考
- 2026-10-26 の見つけ(T-1067): 段の棒が無いと片持ち梁の根の応力が 16 % 高く出た(壁と梁の角の棒が根の線の力の一部を運ぶ)。
