## 目的(1〜2 行)
区画のある世界をエディタの窓で 置く → Undo → プレイ → やめる、写しの早送りで遊びの指標を測る、ができることを窓の試験で確かめる。

## 完了条件(チェックできる形で)
- [ ] window の試験: 区画のある世界(T-0671 の書き方)で、置く → Undo → プレイ → やめるのハッシュが区画の欄まで元に戻る(T-0497 の試験の区画版)
- [ ] 写しの早送りの遊びの指標(T-0432・play_metric)を区画のある世界で測れる(同じ問いを 2 回で同じ値)
- [ ] 区画のある世界の表のホットリロード: 速さだけの表は効き、断る表は窓に理由が出る(CheckRegionTableSwap。frame_loop が差し替える前に聞く)
