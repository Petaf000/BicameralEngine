# T-0102 一様なブロック: 見出しの枠とセルの頁を分け、一様なら頁なしで値 1 つ

- Status: Done(2026-10-05)
- 種類: 工学
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: M2(docs/plan/ROADMAP.md)
- 設計: docs/design/05-world-data.md §3・17 §5「一様なブロック」 / 決定: ADR-0015・ADR-0016・D-208

## 目的(1〜2 行)
岩の中・空の空気のような一様なブロックに 512 セルの頁(57 KB)を持たせない。見出しの枠とセルの頁を別のプールにし、
一様なブロックは値 1 つで表す。刻んで反応が進む時だけ頁に広げる。畳むのは T-0103(2026-10-05 ユーザー決定で分けた)。

## 決めたこと(2026-10-05 ユーザー決定)
- 一様 = 覆われていないセルが全部同じ値・覆われたセルは空・端数のブロックなし(1 点だけ細かくした大きな空気の親も一様のまま)。
- 刻んで反応が進むのに頁の空きが無ければ、そのブロックはその刻みは刻まず、種に残して次の刻みへ回し、数える(決定的。テストは 0 を確かめる)。
  世界の時間を遅らせる本来の扱いはメモリの管理のチケットで(05 §8)。

## 完了条件(チェックできる形で)
- [x] 見出しに頁の番号(padding を page に。MR_NO_PAGE = 一様)。頁の空きのスタックは枠の番号と同じく決定的(要求の順・枠の順)
- [x] 根: 512 セルが全部同じなら一様で置く。細かくする: 一様な親の子は一様(頁なし)。粗くする: 一様な親へ一様で同じ値の子なら一様のまま、違えば親を頁に広げる
- [x] 刻む: 一様なブロックは値 1 つで「進める規則」を調べ、無ければ刻まない(D-424 で変わらない)。あれば印を付け、刻んだ後に枠の順で頁を配って広げて刻む
- [x] 観察の枠(影・写し)はいつも頁を持つ(頁の番号は固定)
- [x] 世界の要約(HashRealLeaves)と保存量は表現によらない(論理のセルで計算)。CPU と GPU(HW・WARP)で状態の全部が配列のまま毎刻み一致
- [x] T-0017 / T-0018 / T-0096 / T-0100 / T-0101 の場面がそのまま通る。一様な根の場面で頁の数が減ることを確かめる
- [x] build(debug / release)・tidy 警告なし・archmap OK・頁を配る段の GPU 時間を perf.md に

## メモ・参考
- 「進める規則があるか」(RxCellStep::possible)は乱数によらない(reaction.hlsli の RxScaleExtent・RxDesiredExtent)ので、値 1 つで決まる。
- ルート署名は 63 / 64 語。新しいバッファは足さない: 一様の値はセルのバッファの先頭(枠 × 1 セル)、頁の空きのスタックは世界の枠の空きのスタックの後ろ。
