## 目的
20 km の世界の VRAM を決めるのは細かい所の半径 r と移り目(0.5 m → 遠くの葉の輪。セルの 6〜7 割)。これを部品の閉じる長さ(closeLengthMm)と同じく
物理の長さ(mm)で世界のデータから渡す口にする。

## 完了条件
- [x] 世界のデータ(ブランクの世界の既定あり)に「細かい所の半径 mm」「遠くの葉の大きさ mm」「移り目の粗くし方(距離が 2 倍ごとに 1 段など)」の値。既定は T-0900 の仮の幅(r = 128〜256 m・遠くの葉 16〜32 m)の内
- [x] 粗さを選ぶ所(多重解像度の木の粗さの規則 §11.1)がその値を読む。値を変えると木の葉の数が変わり、同じ値なら同じ木(決定的)の試験
- [x] docs/perf.md に既定の値での 20 km の見込みのセル数(T-0900 の表の行と比べる)

## メモ

## 引き継ぎメモ(次の作業役へ。調べたことだけ・コードは未着手)
- 今のコードに「細かい所の半径・移り目」の規則は無い(木は細かくする要求 RefineShadowChain・静かな葉を粗くする SubmitQuietCoarsenRequests だけ。multires_nest.h)。
  「既定は今の値」は、T-0900 の仮の幅の内から置く(案: 半径 128 m・遠くの葉 32 m・距離が 2 倍ごとに 1 段 = T-0900 の表の L = 2 の行 0.10 億セル)。
- 置き場の案(T-0955 の balance_cycles と同じ道): `sim::WorldPhysics` に `MultiresGrading { fineRadiusMm; farLeafMm; levelsPerDoubling; }`、
  検査は `CheckWorldPhysics`、環境の鍵(仮)`fine_region = { radius_mm, far_leaf_mm, levels_per_doubling }` を script/environment_package.cpp の
  `ReadWorldEnvironment` で読む(`ReadBalanceCycles` と同じ形)。規則は純粋な関数 `GradedCoarseness(grading, 距離 mm, いちばん細かいセルの mm)`
  (距離 ≤ 半径は 0 段・その外は ceil(log2(距離 ÷ 半径)) × 段数・遠くの葉で頭打ち。整数だけ)。
- 試験の案: 20 km 四方の地表の 4 分木を規則で作って葉を数える(値を変えると葉の数が変わる・同じ値なら同じ葉の並びのハッシュ)。perf.md に既定の値の見込みのセル数を T-0900 の表の行と並べる。
- 【エンジン】**半径は何からの距離か**: 20 §11.1(D-544)は「粗さは局所の状態だけで選ぶ。予算・視点・距離では選ばない」。そこで仮に
  「局所の状態で細かくした所(活性・前線・割れの先端 = 種)からの距離」とする(視点からではない)。作り手から見た違い: 視点の近くでも何も起きていなければ粗いまま(観察の影 D-403 で見るだけ細かくする)/
  視点からにすると、見ている所の周りはいつも 0.5 m で、遠くで起きたことは粗く解かれる(D-544 と食い違う)。答えで規則の入力(種の集め方)が変わる。
- 2026-10-22(wt2 の作業役・続き): 司令塔の連絡で同じブランチで着手(距離は種から = 仮のとおり)。`WorldPhysics::fineRegion`・環境の鍵 `fine_region`・

## 結果(2026-10-22、release、wt2 のランナー)
- 規則: 半径の内 0 段・外は 2 倍ごとに段の数ずつ・遠くの葉で頭打ち(0.5 m から 32 m = 6 段)・0.25 m でも細かい所の広さと遠くの葉 32 m は同じ。
- 20 km 四方の地表の木: 同じ値で同じ木(葉の並びのハッシュ一致)。半径を広げる・遠くの葉を細かくすると葉が増え、移り目を急にすると減る。
- 見込み(perf.md): 既定 = 地表の葉 159 万・セル 0.053 億(L = 2)/ 半径 256 m = 0.17 億 / 半径 256 m・遠くの葉 16 m = 0.18 億 / 2 倍ごとに 2 段 = 0.024 億。
  T-0900 の表より約 2 分の 1(縦を「面積あたり × 5/3 × L」で数えた違い。木の実物でなく見込み)。
- 通した試験: multires_grading・environment_package(ほかの CPU の 4 本は T-0953 の時に通した。この変更は WorldPhysics に欄を足しただけで、それらの道は読まない)。

## 判断待ち(仮で進めたもの)
- 【エンジン】**半径は何からの距離か**(仮: 局所の状態で細かくした所〔種〕から。D-544)。作り手から見た違い: (a 仮)視点の近くでも何も起きていなければ粗いまま
  (見るだけ細かくするのは観察の影 D-403)・遠くで起きた燃焼も種の周りは 0.5 m で解かれる / (b) 視点から: 見ている所の周りはいつも 0.5 m、遠くで起きたことは粗く解かれる
  (D-544「距離・視点で選ばない」と食い違うので、選ぶなら D-544 を直す)。答えで規則の入力(種の集め方)が変わる。おすすめ (a)。
- 既定の値(半径 128 m・遠くの葉 32 m・1 段)と欄の名前 `fine_region` は仮(値は VRAM の線 D-209 で決まる → ゲームの中身へ)。
