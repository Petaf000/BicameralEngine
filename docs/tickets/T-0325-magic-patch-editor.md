# T-0325 エディタの実験室パネルに魔法のパッチの操作(T-0287 から分けた)

- Status: Todo(T-0287 の後)
- 種類: 工学
- PC: 必須
- 設計: docs/design/02-reaction-system.md §5・§5.1 / ADR-0095。関係: T-0024・T-0287

## やること
実験室パネルに「パッチ」の操作: 規則を名前で選ぶ・範囲(箱の座標。大きい箱でも)・期間・効き方(2^shift / 止める)。効いているパッチの一覧(残りの刻み)。LabSession::ApplyPatch を呼ぶ。

## 注意
- 値は試験用の仮のもの(D-006)。
- 公開リポジトリなので、魔法・魔素の設定や値はゲームの中身として書かない(D-006)。シミュのコードに浮動小数点を書かない。
- ルートの SRV / UAV に GetDimensions を使わない(大きさは定数で渡す。T-0024)。
