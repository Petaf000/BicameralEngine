## やること
`--editor` で、規則を名前で選び・効き方(倍率 2^shift・止める・触媒 ΔEa)と強さ・範囲・期間を選んで、実験室と仮の世界にパッチを置く。
置いたパッチの一覧(残りの刻み・断られた数)と、範囲を断面に描く(描画側)。置く操作はコマンドとして記録・再生される。
人がいなくても確かめられる自動の確認(`--auto-patch`。止めた反応が進まない)。

## 注意
- 値は試験用の仮のもの(D-006)。公開リポジトリなので、魔法・魔素の設定や値はゲームの中身として書かない。
- シミュのコードに浮動小数点を書かない。ルートの SRV / UAV に GetDimensions を使わない(このチケットはシミュのコードを変えていない)。

## 引き継ぎメモ
- 実験室の「断られた」は、置いた時に CPU リファレンスの列の写しへ同じ関数で足して決める(GPU の実験室は断った数を返さない)。
  同じ刻みにパネル以外がパッチを置くことは今は無いので一致する。箱を「初めに戻す」と前の判定は残る(一覧は表示だけ。「(戻した)」と出る)。
- 仮の世界のイベントは「投げた順」に結ぶ(イベントにコマンドの番号が無い)。パネル以外がパッチを投げる道(再生など)では結ばない。
- 範囲の選び方は直方体だけ(パッチの範囲が直方体なので。球・円柱は筆にだけある)。
