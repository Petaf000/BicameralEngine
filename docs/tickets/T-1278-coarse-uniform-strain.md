## 目的(1〜2 行)
違う大きさの面の対の負の項(ADR-0485 のずれ・ADR-0501 の曲げ)は「粗いセル C が剛体で表せない対の中の形」を全部外す。T-1261 は C の材料の硬さを
直列で残したが、一様な歪みまで止めてつぎはぎの検査を壊した。**C が表せる一様な歪み(と一様な曲げ)は外したまま、そこからのずれ(2 次の分)にだけ C の材料の硬さを残す**。

## 見立て(机の上・始める前)
- 対(L・U。粗いセル C の面に並ぶ 2 つの細かいセル。並ぶ向き p)の相対の動き R = d_U − d_L(ずれの負の項が外す量)は、L と U の面の点の p の向きの相対の動き × 側。
  C が一様な歪み ε_p を持つなら、C の面の点の相対の動きは s ε_p(s = 細かいセル)。外すべきなのはこの分だけで、R − 側 × s ε_p は C の材料が担う(T-1261 は ε_p = 0 と置いたので一様な歪みを 2 度数えた)。
- **C の一様な歪みは、新しい自由度を足さずに C の粗い隣(p の向き。両側)の中心の差で読む**: C の面の高さの繊維(fiber = t_p ∓ φ。面が C の中心から側 × s の所)の差 ÷ 2。
  繊維で読むので一様な歪み 3 つ・回り・一様な曲げ(つぎはぎの検査の全部)で R − 側 × m = 0(外したまま = 今と同じ)。固定した面の側は壁(0)までの半分の長さで読む(m = ± 繊維_C)。
- 足す項(対ごと・読める側ごと): ½ (K_q ÷ 側の数) (R − 側 × m_側)²。K_q = 外した硬さ K と C の材料の硬さ K_C の直列(K_C = 6 b_p。T-1261 の形 B と同じ硬さ)。
  2 つの側を 1 つの項にすると C の両隣(同じ色)が直接つながり C-0 の色の約束を壊すので、側ごとに分ける(線の歪み〔2 次〕には ¼ K_q (m_左 − m_右)² の小さい偽の硬さが残る。測る)。
  項の節は L・U・C・隣 N の 4 つ(N と L・U は斜めの隣でレベルの差 1 = 今の系の面の約束の中)。
- 曲げ(ADR-0501 の負の項 −½ K_曲げ (p_L − p_U)²。p_L − p_U = s(θ_L − θ_U) = −s² κ_p)も同じ芯: C の曲率を隣の回りの差で読み(−s² κ = −(φ_N − φ_C)/2 ÷ 側)、
  ½ (K_qb ÷ 側の数) (p_L − p_U − 目標)²。K_qb = K_曲げ と b_p/2(細かい面の曲げの硬さを p の単位で)の直列。
- **どの試験で何が変わるはずか**:
  - 違う大きさのセルが無い場面・既定(None): ビット一致(変えない)。
  - 根の線の両側の 2 場面(ctest・study): 根の角で x の伸びが壁の列の中で強く変わる = C の上の隣(壁の左の列)の歪みと対の歪みが違う → T-1261 の 1.03 に近づく(1.056 → 1.03〜1.045 の見込み・未確認)。
  - 洞窟の天井(T-1261 で 3.42 → 10 %): 自重の縦の縮みは一様に近い・線の勾配は両側の読みで消える → 3.42 % のまま(±0.5 点)の見込み。
  - 片持ち梁の上の段だけ(ADR-0501 の 4.87 %): 曲げの形(B)だけが効く見込み。根の柱の C(0,0) は左が固定した面で、壁から読む曲率が対の回りの差を引き止める → 下がるか不明(未確認・測る)。
  - 自重の塊(support_cost `--coarse`): 縁の力の差 2.19 % / 1.35 % から大きく悪くならない。

### 分かったこと
- **形 A(ずれだけ)は当たり(T-1260 の側)**: 粗いセル C の一様な歪みを C の隣の中心の差(繊維)で読み、そこからのずれにだけ C の材料の硬さを残すと、
  T-1261 で壊れたつぎはぎの検査は壊れず(洞窟の天井 3.42 → 1.23 % とむしろ良くなる)、根の線の両側の 2 場面は 1.056 / 1.052 → 1.045 / 1.041(±5 % の中)。
  細かい面の縁の力も広く半分ほどに(片持ち梁 1.6〜3.3 → 0.7〜1.6 %・両端固定 4.47 → 2.20 %・自重の塊 4.72 → 2.03 %)= ADR-0485 の「C が表せない分を全部外す」は外しすぎで、
  C の隣が表す一様な歪みを目標にすれば残してよい、という見立てが当たった。
- ただし根の角は 1.045 で、T-1261 の 1.031(つぎはぎを壊した形)・負の項 0 の 1.030 までは届かない。残り約 1.5 点は、C の隣から読む歪みが根の角の集中を平らに読む分(線の歪みの偽の硬さ)と見ている(未確認)。
- **形 B(曲げも同じ形)は外れ**: 上の段だけの根の柱が 4.87 → 5.25 %。ADR-0501 の 4.87 % は対の曲げの負の項でも動かない(A で 4.83 %)= T-1261 の結論の通り別の根
  (固定した面のすぐ横の 2 次の離散化)。形 B は段の角の固定した面の近くを下げる(12.7 → 8.6 %)が、試験の場面を 5 % の外へ出すので打ち切り。
- 悪くなった所(記録): 上の角の梁の側だけの細かい面 3.39 → 4.30 %(記録だけの場面・5 % の中)。自重の塊の倍率 4 の掘った後の差 0.17〜0.77 → 0.46〜1.07 %(2 % の線の中)。

## 判断待ち(【エンジン】)
- 【エンジン】違う大きさのセルの間の面で、粗いセルの「隣から読む一様な歪み」を目標にして材料の硬さを残す形(形 A)を既定にするか。
  - 作り手から見た違い: 書く値は無い。細かくする所の境で、細かい面の縁の力(割れの判定が読む)の偽の差が今の 1.6〜5.8 % → 0.7〜2.5 % に減り、
    周りを分けない設定(refineRing = 0)の根の角の柔らかさが 5.6 % → 4.5 %(試験の線を 6 % → 5 % に戻せる)。釣り合いの答え(たわみ)はほかの場面で同じ(4 桁)。
  - 代わり: 対ごとに面が最大 12 増える(C の隣と対の細かいセルの間の斜めの面。系の節の数・解く回数は同じ)。3 次元(T-0944)・GPU 版も同じ形で延ばす必要がある(未確認)。
  - おすすめ: 既定にする(取り消しやすい: 選択 1 つ)。Claude はユーザーの決定まで既定を変えない。
- 司令塔へ: 比べ用の選択の値(Section・HalfSection・NeighborStrainBend)は記録用。要らなければ消してよい。
