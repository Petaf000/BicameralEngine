# T-0687 区画のある世界の表のホットリロードを窓で確かめる(通る表と断る表)

- PC: 必須

- マイルストーン: ⑤ の T-0414(T-0672 から分けた)

## 目的(1〜2 行)
区画のある世界(⑤ の場面)で、速さだけを直した表は当たり、区画の欄の作りが変わる表(水の密度・物質を足す・重力)は理由付きで断られて古い表のまま、を窓の試験にする。

## 完了条件(チェックできる形で)
- [ ] --packages の写しの場面で、速さを直す → 当たる(差し替えの印が記録に残る)→ 水の密度を変える → 「今の世界に当てられない表」で古い表のまま、を自動で
      (--auto-reload の手順を場面の写しに使えるようにするか、場面用の書き換えを auto_reload に足す)
- [ ] 記録を再生して同じハッシュ列

## メモ・参考
- 道は T-0672 で付けた: ReactionTableHotReload::SetWorldCheck(frame_loop のコンストラクタ)→ ProbeSim::CheckRegionTableSwap。
- 区画のある世界で環境ミキサーが標準パッケージを足す(物質が増える)と断られるので、「世界を作り直す」でも足した表にならない(T-0670 の作り直しまで)。
