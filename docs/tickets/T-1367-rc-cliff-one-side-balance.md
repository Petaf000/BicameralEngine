# T-1367 熱の放射の段の崖(RcMaskAcross)が、片側だけ通さない面で同じ温度の釣り合いを崩す

- Status: Todo(2026-11-12 wt4 の作業役が T-1365 の測りで見つけた。ADR-0535 の答えで直し方が決まる)
- 種類: 工学(直し方は ADR-0535 の答え次第)
- PC: 必須
- マイルストーン: 列 4(T-1365 から分けた)
- 決定: ADR-0535(Proposed)・D-466(坂を下る)・T-0877

## 目的(1〜2 行)
RcMaskAcross は「向こうが τ ≥ 32 ならその面から放たない」。両側とも τ ≥ 32 なら両方とも放たず釣り合うが、**片側だけ τ ≥ 32 の面では
通さない側だけが放つ**(透ける側は向こうが通さないので放たず、通さない側は向こうが透けるので放つ)。同じ温度でも通さない側から透ける側へ熱が流れる(坂を上る)。

## 測った数(2026-11-12 wt4・release・CPU リファレンス・tests/cascade_face_test の「釣り合い」)
- 12³ の閉じた箱(外の 1 層が石の殻・中は τ 2 の物・全部 1000 K・8 刻みの平均・n0 4・2 段・組 1):
  形 0(今の崖)= 中の物の正味の和 **+5.09 MW**(放った 86.9 MW の 5.9 %)・セルの正味の最大 27.0 kW(殻に触れる隅)。
  中が τ 40 だけ(両側とも飽和)の箱は 0.0 W(釣り合う)。T-1365 の形 1・2(両側で同じ係数)は −1.51 MW・−0.91 MW(向きの粗さの残り。符号が逆)。
- 既定の世界で起きる所: 透ける物(τ < 32 の草・薄い煙・水の浅い層など)が、通さない物(既定の灰色の固体: 土・石・木)に触れている面。
  参照の温度の形(ADR-0461)では参照と同じ温度の所は放たないので眠った世界では出ない。熱い地面の上の薄い草・熱い石に触れた煙で出る。

## 完了条件
- [ ] 同じ温度の閉じた箱(透ける物 + 通さない殻)で、正味の和が向きの粗さの残り(cascade_light_test の坂を下る)の大きさ以下
- [ ] 直し方: ADR-0535 が (b) なら T-1365 の形(係数を面の両側の小さい方の τ で決める)で消える。(a) のままなら、
  RcMaskAcross を「自分と向こうの両方が通さないなら」放たない(両側で同じ条件 = τ の小さい方が 32 以上)にする案
  (触れている固体どうしは伝導の仕事のまま。透ける物と通さない物の面は両方が全部放つ。どちらか一方の条件にすると、
  透ける物の向こうの物から通さない物へは届くのに逆は届かず、やはり崩れる)。
  どちらも CPU と GPU(cascade_light.hlsl・probe_radiation.hlsl)の両方とハッシュの見直しが要る
