# T-1383 木箱の燃え広がりの基準を、木箱を物(物の箱 + 空気の層)として置いた場面で取り直す(T-1366 から分けた)

- Status: Todo(司令塔が順を決める)
- 種類: 研究(打ち切りは着手する時に書く)
- PC: 必須
- マイルストーン: 列 4
- 決定: D-660・D-667・ADR-0469・T-1158(物の箱が囲む空気の層)

## 目的
T-1366 の測り: セルの木箱(0.5 m のセルの 1 割が木)は、炎が無ければ燃え広がらず(T-1156)、炎(熱分解の燃える気体)があれば 1 秒で爆発する(木と空気が 1 つの温度で
熱の厚みが無く、燃える気体の出る速さに上限が無い)。燃え広がりの基準「60 秒で 9 割」を、木の板を物(物の箱 + 空気の層。T-1143・T-1144 の形)として置いた木箱で取り直す。
セルの gpu_probe_fire(DISABLED)をどうするか(消す・爆発の見張りにする)もここで決める。

## 申し送り
- GPU の区画には陽解法の熱の列が無い(T-0813)。爆発のある場面では CPU の列を切って比べる(gpu_probe_fire_test・gpu_probe_gas_test と同じ)。
