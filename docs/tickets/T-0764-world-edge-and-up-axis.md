## 目的(1〜2 行)
多重解像度の 1 段の気体(T-0720)は世界の端の種類を自分の設定(MultiresGasOptions の top / bottom / sides)で持っている。T-0721 の世界の端(WeWorld)から読むように替える。

## 判断(仮。ユーザー未確認)

- おすすめ: z(多重解像度の世界の側はすでに 3 つが z。仮の世界は退かせる方針〔D-513〕)。
