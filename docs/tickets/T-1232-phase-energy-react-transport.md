## 目的
世界の反応の段から PlReactCell(2 回の反応。T-1211 で核に入れた)と PlRemixCondensedEnergy を呼び、気体と液体の区画が混ざったセルから部分の h を持ち出す。世界で CPU と GPU のビット一致を取り、混ざったセルの頁の数と GPU の時間を測る。

## 完了条件
- [ ] 反応の段(世界のセルの反応。RxStepCellWait を呼ぶ所)を PlReactCell に。混ざらないセルはビット単位で今と同じ(PL_RULES_ALL)
- [ ] 運ぶ: 気体の区画は気体の部分の温度の h・液体の区画は層の温度の h を持ち出す(Ec の側も合わせて動かす)→ 量が変わったセルは PlRemixCondensedEnergy
- [ ] 世界の盤面(仮の世界と世界の木)で CPU と GPU のビット一致・2 回の実行でハッシュ一致
- [ ] 測り: 混ざったセルの頁の数・GPU の時間(docs/perf.md に日付と GPU と)
- [ ] (速さ)規則の振り分けの印をベイクに(PlRuleHasCondensed を表の印に替える。reaction.hlsli の RxRule に触るので、その時の持ち主と合わせる)
