## やること(T-0022 の事前調査の「試す順番」3)
1. ブロックの頁ごとに溢れ領域(成分の (ID, µmol) の並び)を持つ。1 グループ(1 ブロック)の中でセル番号順のプレフィックス和で配る(決定的)。
2. 頁の溢れ領域が足りなければ「大きい頁が要る」印 → 刻みの中で配り直して、そのブロックを同じ刻みでやり直す
   (「印 → TreeExpand → ExpandStepNode」と同じ型)。今の StepPagedWait は g_cells をその場で書き換えるので、やり直す元の値を残す方法を先に決める
   (頁を 2 世代にする・溢れる時だけ元の頁を写す、など。VRAM と ns/セルで比べる)。
3. 粗くする時の和集合も溢れ領域へ(MR_STATUS_SPECIES_FULL を使わなくなる)。
4. HW の Work Graph はノードに反応の核を足さない(1 ノード 2 か所まで。T-0124)。飽和する足し算の形を書かない。
