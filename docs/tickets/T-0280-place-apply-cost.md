# T-0280 置くコマンドの適用の重さを測り、軽くする(面に沿って塗るは T-0332 に分けた)

- Status: Review(作業役・wt6・ブランチ t-0280。司令塔のマージ待ち)
- 種類: 工学
- PC: 必須
- 見積もり: 作業役 1 体・2 時間以内(面に沿って塗るは T-0332)
- マイルストーン: M2(docs/plan/ROADMAP.md)
- 設計: docs/design/14-editor-tools.md §2「実装(T-0280)」/ 決定: ADR-0125(新)・ADR-0067 §5・ADR-0089 / 元: T-0245 の「分けたもの」

## 目的(1〜2 行)
筆のドラッグで 1 刻みに置くコマンドが多い時(1 フレーム 8 個・止めている間に溜まると 64 個)の、GPU の適用の単位の時間を測る。
重ければ軽くする。

## 完了条件(チェックできる形で)
- [x] 計測の道具 tests/gpu_place_bench(ctest には登録しない。`job.py run -Preset release -Exe gpu_place_bench`): 球 r8・直方体 8³ ×
      置き換え・足す × 1 刻みに 1・8・64 個の、適用の単位と伝導の単位の GPU 時間(8 刻みの中央値と最大)。当たった数も確かめる
- [x] 結果を docs/perf.md に(前と後)
- [x] 重かった(1 スレッドで 3〜4.5 µs/セル。64 個の直方体の足すで 1.3 s/刻み = TDR の 2 s に近い)ので軽くした(ADR-0125):
      適用の単位を 1 スレッド → 1 グループ 256 スレッドにし、コマンドは今まで通り番号の順に 1 つずつ、置くコマンドのセルだけをグループで分ける
      (コマンドの間にグループの同期)。約 80 倍速い(64 個の直方体の足すで 15 ms)。CPU リファレンスは変えない(GPU と CPU の一致の試験がそのまま確かめる)
- [x] テスト: gpu_probe_place(HW・WARP)ほか置く・つつく・押すを流す試験と window_place_record/play(作業ログ)
- [ ] 面に沿って塗る → T-0332 に分けた

## 引き継ぎメモ(HANDOFF に載せる内容)
- 置くコマンドの適用は 1 グループ 256 スレッド(probe_tick.hlsl の PROBE_APPLY_GROUP_SIZE。ADR-0125)。コマンドの順・イベント・トレースの根・
  ブロックの印はスレッド 0 で今まで通り。置くコマンドのセルだけを分ける。1024 にしても速くならなかった(1 つの SM で頭打ち)。
- 計測: docs/perf.md の 2026-10-11 T-0280 の行。もっと軽くする道は ADR-0125「さらに軽くするなら」。
- 面に沿って塗るは T-0332(設計の下書きは下の「分けたもの」)。

## 判断待ち
- なし(並べ方は実装の細部。世界の結果は変わらない〔GPU と CPU のビット一致〕)

## 分けたもの(司令塔が ROADMAP に足すか決める)
- **T-0332 面に沿って塗る・置く**(T-0280 の (1)): カーソルの光線が最初に当たる「物」のセル(空気でないセル)の手前の空いたセルを中心に置く・
  そのままドラッグで面に沿って塗る(断面の平面だけでなく)。下書き:
  - **物かどうかの読み戻し(View。シミュに入れない)**: 今の抽出には見る物質 3 つの量しか無く、「空気でない」が CPU で分からない。
    抽出の後ろのフック(ProbeFrameInput::afterExtract。覗き窓と同じ道)で、セルの物質量の合計がしきい値(仮: 空気のセルの 4 倍 ≈ 20 mol。
    木〔セルロース 1 割〕は約 115 mol・空気は約 5 mol。表に相の情報が無いので物質量の濃さで見分ける。気体の材料〔窒素・二酸化炭素〕は面にならない)
    を超えるかを 64³ ビット(32 KiB)にして読み戻す。筆が「面に沿って」の時だけ。数フレーム遅れてよい。
  - **光線**: DebugViewController が押した・ドラッグした画素の光線も返す(PointerDrag に光線の列)。CPU で格子の DDA を回し、最初に物のセルに入る
    直前のセルを中心にする(物が無ければ断面に当たったセル)。editor/surface_pick(CPU だけ・ctest)。
  - **パネル**: 筆のパネルに「当て方: 断面 / 面に沿って」(brush_panel に閉じる)。カーソルの下の表示(T-0279)も同じ中心に。
  - **自動の確認**: `--auto-place` に、木箱(初めの世界)へ決まった光線で面に沿って置く・ドラッグする手順を足し、置いたコマンドの中心が
    木箱の壁の外側に接するセルであることと、記録 → 再生で同じハッシュ列を確かめる(window_place_record/play)。
  - プレイヤーと遊びへの影響: エディタで地面や壁の表面に燃料・苔・魔素を「塗る」ことができ、断面を動かさずに 3D の物の上に置ける。
    しきい値は「何を物とみなすか」を決める(仮の値。相〔固体・液体〕を表に持たせる時に置き換える)。
