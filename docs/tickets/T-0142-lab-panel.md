## 目的
反応表を書く人が、小さな箱の世界に物質と温度を置いて反応を試し、GPU の結果が CPU リファレンスとビットで同じかを刻みごとに確かめる道具。
置く操作はコマンドとして記録・再生できる。食い違ったら最初に違った刻みとセルを出す。今の試験の表(燃焼・熱分解)の範囲。

## 完了条件
- [x] 箱: 多重解像度の本物の根 1 つ(8³ セル・0.5 m 角・300 K の空気・いつも頁を持つ)。刻みは反応 + 熱の伝導(sim/lab_box・ADR-0037)
- [x] 置く操作はコマンド(LAB_COMMAND_TYPE_FILL = 物質 3 つまで + 温度で置き換え・TEMPERATURE = 温度を決める)。当てる関数は
      shaders/common/lab_box.hlsli で GPU(shaders/sim/lab_box.hlsl)と CPU(ApplyLabCommands)が共通。当てられないコマンドは両方とも飛ばす
- [x] GPU(sim/gpu_lab_box)と CPU を 1 刻みずつ並べて比べ、最初に違った刻みとセル(セルが同じなら違う欄)を出す(sim/lab_session・FindLabMismatch)
- [x] 記録(コマンドの列 + 刻みごとのハッシュ)の保存・読み込み・再生。再生が記録と違えば最初の刻みを出す
- [x] エディタのパネル「実験室」(editor/lab_panel): 箱を作る・セルと材料と温度を選んで置く・温度だけ・1/10/60 刻み・流し続ける・最初に戻す・
      断面の温度(押すとセルを選ぶ)・選んだセルの温度と成分を CPU と GPU で並べる・食い違いの表示・記録の保存と再生
- [x] テスト: lab_box(CPU。コマンドのセル = MakeReactionCell・当てられないコマンド・木が燃える・コマンドの無い刻みは元素とエネルギーが同じ・
      決定性・記録の読み書き・最初に違ったセル)/ gpu_lab_box(200 刻み毎刻みビット一致・燃えた・記録から再生して同じ)/ window_lab(--editor --auto-lab)
- [x] ADR-0037・14 §2・map.yaml

## 作業ログ(チャットごとに 3〜5 行、新しいものを下に)
- 2026-10-09(作業役・wt4): 箱は仮の世界ではなく多重解像度の根 1 つにした(ADR-0037。8³ で伝導があり、刻みは本物の木の刻みそのもの)。
  コマンドは GpuMultires の外のパイプライン(覗き窓と同じ RecordExternalDispatch・u4)で当てる。根は PlaceRootBlock が一様にしないよう 1 セルだけ変えて置き、すぐ戻す。
- gpu_lab_box は 1 回目で通過(128 秒。ほとんどがパイプラインの作成)。lab_box は 4 秒。

## 引き継ぎメモ(HANDOFF に載せる内容)
- 動いているもの: `bicameral --editor` のパネル「実験室」。「箱を作る」で GPU の箱を作る(debug では作成に数十秒〜数分。並走中は長い)。
  `--auto-lab`(--editor と一緒に)は、木を置いて火を付けて 60 刻み → 記録 → 再生を流して、通らなければ終了コード 1。
- 注意:
  - 箱は自分の compute キューで 1 刻みずつ待つ(512 セルなので軽い)。仮の世界の刻みとは関係しない(別の世界)。
  - 記録のファイルは既定で作業フォルダの `lab_recording.blab`(パネルで変えられる)。形は SerializeLabRecording(`BLAB`・版 1)。
  - 箱の材料(空気・木・木炭・二酸化炭素・窒素)は試験の表の物質の名前で引く。表に無い物質の材料はパネルに出ない。

## 判断待ち
1. **「置く」は中身を置き換えるか、足すか**(仮で「置き換え」にした。ユーザー未確認。後から「足す」コマンドを足せる)
   - A(今): セルの中身を選んだ材料に置き換える。プレイヤーと遊びへの影響: 無し(エディタの道具。ゲームの中の魔法・物の置き方とは別)。
     反応表を書く人には「このセルを木にする」が 1 回で済み、実験の初めの形を作りやすい。
   - B: 今の中身に足す(空気のセルに木を足すと、空気 + 木)。影響: 混ぜる実験(酸素を足す・炭を足す)が直接できるが、セルの量が増え続ける。
   - おすすめ: A のまま。混ぜる実験が要るようになったら B を別の種類のコマンドとして足す(費用: 小)。
2. **箱の温度を決めるコマンドは保存則の外(エディタの明示的な湧き出し)**: つつき(仮の世界)と同じ扱いにした(D-206 の「明示的な湧き出し」)。
   ゲームの中で熱を足す・引く魔法(反応則への介入)とは別の話で、ここでは決めない。
3. **箱の大きさと境界**(仮: 8³ × 0.5 m = 4 m 角、外とは熱も物も通さない): 実装の細部として Claude が決めた。広げるのは T-0173。
- (T-0023 の判断待ち 1「時間の操作を記録に残すか」: 実験室の記録は刻みごとのコマンドを持つので、実験の手順の見返しはこれで足りる。B は要らないまま)
