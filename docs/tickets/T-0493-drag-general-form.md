## 一般の形(案。ADR-0220 Proposed)
引きずりを GENERIC の 2 つの部分に分ける(19 §2.1 の P3)。
1. **運ぶ**(可逆): 流れる物(気体・水・物)は自分の中の量(熱・成分・運動量)を同じ割合で運ぶ。係数は 1 で作り手は書かない(1 以外は中身を作る・消すか、
   仕事なしの選り分けになる)。作り手が決めるのは何がどの流れる物の中にあるか(相)。今の気体(07 §2)の形。模型 2 はこれ。
2. **交差**(散逸。Onsager): 坂 X の流れが量 Y も動かす。作り手は**結合の強さ q(−1〜1)**を書き、エンジンが L_xy = q √(L_xx L_yy) と逆向きの引きずり(相反)を作る。
   |q| ≤ 1 なら半正定 = どの状態でも坂を上らない。|q| > 1 はベイクが警告して ±1 に押さえる。模型 1 はこれ。
   - 整数: K = (|q| 切り捨て)×(√ 切り捨て)なので丸めた後も半正定。GPU ではセルのキャッシュに √L を置き、面は両側の小さい方(√min = min √ なので半正定のまま)。
   - |q| = 1 は結合しきった理想の機械: 1 つの組み合わせが坂を下らずに残り、閉じた系でも一様にならない(模型: 棒の差 50 K が残る)。エントロピーは減らない。
   - 坂を上らせる構造(T-0495)の効率の上限は q だけで決まる(Kedem–Caplan: η_max = q² ÷ (1 + √(1 − q²))²)。同じ数で書ける見込み(未確認)。

## 表の書き方(作り手から見た違い。おすすめは仮・ユーザー未確認)
**問い 1 どこに書くか(Luau の分類)**
| 案 | 書き方の例 | 作り手から見た違い |
|---|---|---|
| **A 独立の表 `drags`(おすすめ・仮)** | `drags = { { flow = "heat", drags = "species:salt", coupling = 0.3, within = "phase:liquid" } }` | 法則の表(反応表と並ぶ)。全部の引きずりが一か所で一覧でき、D-482 ② のノード表示にそのまま出る。物質を消すと行がベイクで警告(反応と同じ扱い)。どの物質・相の中で効くかを `within` で書く |
| B 物質の欄 | `material.salt = { ..., drag = { heat = 0.3 } }` | 物質ごとに見える。その物質の中の流れだけ。違う物質の境の面ではどちらの値かの決まり(小さい方など)が要り、作り手から見えにくい |
| C 流れの側 | `flows.heat = { drags = { salt = 0.3 } }` | 流れの種類は少ないので短いが、どの物質・相の中でかを書く所が無い |

**問い 2 値を何で書くか**
| 案 | 作り手から見た違い |
|---|---|
| **a 結合の強さ q(−1〜1)(おすすめ・仮)** | どんな値でも(押さえた後は)坂を上らない保証が式の形で、温度・濃さによらない。ベイクの検査は範囲だけ。T-0495 の効率と同じ 1 つの数。現実の係数(Soret 係数など)は直接写せない(パネルで換算を出す) |
| b 物理の係数(Soret 係数 1/K など) | 現実の値を写せる。坂を上らない上限が温度・濃さで変わるので、ベイクは「この範囲で上限を超える」の警告まで、実行時は面ごとに押さえる(押さえた回数を計器に)。書いた値と効く値が場所で違う |

**問い 3 範囲の外(|q| > 1)**: 警告して ±1 に押さえて動かす(おすすめ・仮。D-487 ② と同じ)/ 読み込みを止める。
**問い 4 |q| = 1 を許すか**: 許す(理想の機械を作れる。閉じた系で 1 つの組が一様にならない)/ 1 未満に押さえる。おすすめは許す(仮)。

## 模型の結果(2026-10-15・tests/drag_model_test.cpp・ctest drag_model・release)
**模型 1 交差の引きずり**(1 次元の棒 8 セル・熱容量 1000 mJ/K・G = 100 mJ/K・D = 1/10・左半分 +100 K・成分は一様 1 mol・6000 刻み):
| q | 熱の流れが引きずった成分の最大のずれ | 1 刻みの生成の最小(mJ/K) | 終わりの差 |
|---|---|---|---|
| 0 | 0(動かない) | 0 | 62 mK / 0 µmol |
| +0.5 | 12,406 µmol(1.2%) | 0 | 62 mK / 62 µmol |
| −0.9 | 24,182 µmol(2.4%。逆向き) | 0 | 482 mK / 482 µmol |
| +1.0 | 27,961 µmol(2.8%) | −1.1 × 10^-4(丸めの幅の中) | 50.1 K / 49,864 µmol(結合しきった組が残る) |
- 全部の刻みで「生成 + 丸めの幅 ≥ 0」・エネルギーと成分の合計がビット単位で一定。
- **書きすぎ**: q = 1.5 を押さえずに流すと、±1 K の揺れ(温度と濃さを逆向き)が **26 刻みで 57 K の差に育ち、エントロピーが 105.7 mJ/K 減った**(仕事なしで温度差ができる = 第二種の永久機関)。
  ベイクが押さえた q = 1 では 400 刻みで差 956 mK(育たない)・エントロピー +2.7 × 10^-4。
**模型 2 運ぶ引きずり**(気体の箱 8 × 8 × 16〔4 m × 4 m × 8 m〕・閉じた壁・標準の重力と音速・木 2 × 2 × 1 セルを z = 1 に 800 K で・2 秒 = 120 刻み):
| | 熱の重心(1 K 以上熱い所)| 5 K 以上熱い最も高い層 | 燃えた木 |
|---|---|---|---|
| 伝導だけ(気体を流さない) | z 1.000 → 1.109(+0.11 セル) | z 4 | 80,256 µmol |
| 煙が流れる | z 1.000 → 4.059(**+3.06 セル = 1.5 m**) | z 7 | 45,000 µmol |
- 元素(C・H・O・N)・エネルギー(気体の全エネルギー + 木 − 帳簿)・運動量(− 帳簿)が**毎刻みビット単位で一致**。2 回の実行でハッシュ一致。
- 結合の形: 反応は木のセルの O2 を同じ場所の気体から取り、生成物を気体へ、燃えた木の化学のエネルギー(物質量 × H0)を気体のエネルギーへ足す。
  気体の熱(= 全エネルギー − 化学 − 運動)が反応熱の分だけ上がる。伝導は気体のエネルギーへ足し引きするだけ。どちらも「引いた値をそのまま足す」なので保存はビット単位で、
  gas_reference に手を入れずに済んだ(T-0186 の形の下書きになる)。
- 気づいたこと: (1) 煙が流れると燃えた量が少ない(45,000 対 80,256 µmol): 冷たい空気が入れ替わって木が冷える(燃え方は O2 より熱の行き先で決まった)。
  (2) 加熱で音の波が出て、箱の全体が mK だけ温まる(熱の重心を基準より熱い分の全部で取ると最初の刻みから z 3.8 になった → 1 K 以上だけで数えた)。

## T-0186・T-0210 への申し送り
- 気体の成分は 4 つまで(GAS_MAX_SPECIES)。反応表(combustion_test・標準パッケージ)の気体の物質をそのまま載せられない。成分の上限か、載せる物質の選び方が要る。
- 反応表の気体の比熱は定圧(T-0234 の申し送りのまま)。模型は c_v を直接書いた。
- 反応と伝導の熱は気体の全エネルギーへの足し引きで保存が保てる(模型 2)。物質量を変えると運動エネルギー(P² ÷ m)が変わり熱が少し動くが、保存は崩れない。
- 交差の引きずりを世界に入れるには、気体の中の成分の拡散(濃さの坂の流れ)が先に要る(今は数値のにじみだけ。19 §2.2)。
