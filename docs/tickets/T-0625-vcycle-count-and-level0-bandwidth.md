# T-0625 64³ の強い爆発の刻みを 4 ms に: 段 0 の帯域と V の回数を減らす研究

- Status: Todo
- 種類: 研究(段 0 の並べ方・V の回数の減り方が読めない)
- PC: 必須(GPU)
- 見積もり: チャット 1〜2 回分(2 時間で区切る)
- マイルストーン: ROADMAP ③(T-0606 から分けた)
- 設計: ADR-0264・ADR-0254・docs/perf.md の T-0587・T-0606 の行 / 決定: D-468・D-428

## 目的(1〜2 行)
T-0606 の後、64³ の V 1 回の解きは約 1.03 ms(V の前の判定を含む)で、その半分が段 0 の掃き出し(1 色 約 68 µs × 8。全部の節の読みの帯域)。
強い爆発の刻み(解き 3〜4 回・V 7〜8 回)を予算 4 ms(仮)に入れるには、V 1 回を約 0.5 ms にするか、V の回数を半分にする必要がある。

## 完了条件(チェックできる形で)
- [ ] 下の案 A を作って測る(値は同じ。CPU とビット一致)。64³ の S0 1 色の前後
- [ ] 案 B・C は CPU の模型(gas_projection)で V/刻み・外側が上限で止めた刻みを測り、作り手に見せる形(結果が許容差の中でどう変わるか)でまとめる
- [ ] 64³ の爆発の刻みが 4 ms に届くかの見積もりと、届かなければ残りの手

## 研究の打ち切り条件(始める前に書く)
- 時間: 2 時間で区切る。
- 案 A: 試作で S0 の 1 色が 2 割以上軽くならなければ(帯域ではなく読みの往復が支配)、並べ替えはやめて書く。
- 案 B・C: CPU の模型で V/刻みが 2 割以上減らない、または外側が上限で止めた刻みが増えるなら、その案は採らない。

## 案(T-0606 で分かったことから)
- **A(工学寄り・値は同じ)段 0 の読みを減らす**: 今の段 0 は節(40 B)+ 隣(16 B × 6)を節ごとに読む配列の並び(AoS)で、色が交互に並ぶので
  「その色の節だけ書く」(T-0606 の ②)では読む量がほとんど減らなかった(S0 1 色 67 → 68 µs)。
  (a) 一様な箱の段は隣を番地の計算で求め、重みを面ごとの配列(+x・+y・+z の 3 本)に持つ形(節の読み 約 150 B → 約 50 B の見込み・未測)。
  (b) 節の表を「隣の範囲」「色」「重み」の別々の配列(SoA)にする(どの段にも効く。見込み 2〜3 割・未測)。
- **B(結果が許容差の中で変わる)V の回数**: 段 0 の前後の掃き出しを 2 + 2 → 1 + 1(1 回の V は約 4 割軽い・V の数は増える)/
  多重格子を前処理にした共役勾配(整数の内積は足す順を決めれば決定的。V の数は 3〜5 割減る見込み・未測)。
- **C(結果が許容差の中で変わる)解きの回数**: 外側の反復に運ばれる熱を入れて解き直しを減らす(T-0530 の引き継ぎ・ADR-0254 の見直す条件)。
