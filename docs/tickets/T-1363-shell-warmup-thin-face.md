## 目的(1〜2 行)
暖機の刻み 3〜8 だけ紙の両隣のボクセルの面の気体が囲むセルの 1/10^5 まで落ちる理由を突き止め、式どおりか作り方の誤りかを決める。

## 研究の打ち切り条件(先に書く)
- 物差し: CPU だけの流れ(`gpu_object_shell_flow_test --grow --grow-cpu N --grow-shape 列 高さ 層`)で、小刻みごとに層で一番薄いボクセルの
  質量の比・温度・膨らみたい体積・6 つの面の速さ(上限で止める前)を書き出す(`--grow-trace 書き出し先`。T-1363 で足した調べの口)。
- 候補を順に見る: (a) 出る上限(1 小刻みに半分)の重なり / (b) 速さの上限(1 小刻みに 1 ボクセル)と圧力の射影の食い違い / (c) 膨らみたい体積の
  初めの値(暖機の 1,500 K の層)/ (d) 運動量を運ぶ式(① の質量と運ぶ気体の食い違い)。
- **誤りの判定**: 膨らみたい体積が負(吸い込みたい)なのに質量が減り続ける・射影の後の速さが射影の式を満たさない、のどれかが出たら作り方の誤り。
- **打ち切り**: (a)〜(d) のどれでも薄くなる仕組みを説明できない、または直しても 29,952 ボクセルの暖機の濃淡が 10^3 を切らない → 式どおりとして T-1364 へ。
  2 時間で終わらなければ、分かった所までと次の一手をここに書いて返す。
