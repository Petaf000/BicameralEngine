## 目的(1〜2 行)

## 判断待ち(仮で進めたもの。作り手から見た違いで)
1. **パッケージに切り替えを置かない**(仮): `heat_capacity_mj_per_mol_k` は気体なら定圧の c_p、の 1 つの意味。
   作り手から見た違い: 定積の値しか無い時は R(8.314 J/(mol·K))を足して書く。案 = 表ごとの宣言(例 `gas_heat_capacity = "constant_volume"`)を足すと、
   混ぜたパッケージで同じ欄が違う意味になる。おすすめ: 仮のまま(取り消しは欄を 1 つ足すだけ)。
2. **燃える木箱の「同じく動く」幅(Q63)を外れた** → 基準を取り直すかは本体とユーザー(下の表。今は記録だけ)。

### 燃える木箱(slope_check_test --burn 18000。CPU。2026-10-17。T-0491 の幅・Q63 の案 a)
同じ実行ファイルで `--written-heat-capacity`(前の比熱)を流すと基準と全部同じ数(4030.5 K・787 / 3829・16,657・3,123・炭 67,972 mol・CO 582 mol)。
| 計器 | 基準(前の比熱) | 定圧で書いた既定(T-0597) | 幅 | 判定 |
|---|---|---|---|---|
| 火が消える刻み | 16,657 | **18,000 刻みでまだ 1000 K 以上が残る**(> 18,000) | ±10 %(15,000〜18,322) | 外れの見込み(18,000 で打ち切った。測り直すなら 20,000 以上) |
| セルロースが 1 % 以下になる刻み | 3,123 | **2,211**(−29 %) | ±10 % | **外れ** |
| 1000 K 以上のセルの最大 / その刻み | 787 / 3,829 | **1,277**(+62 %)/ **4,305**(+12 %) | ±10 % / ±10 % | **外れ / 外れ** |
| 最後の炭 | 67,972 mol | 67,972 mol | ±5 % | 中 |
| 最後の CO | 582 mol | 582 mol | ±25 % | 中 |
| 最高温度 | 4,030.5 K | **4,967.3 K**(+23 %) | ±5 % | **外れ** |
- 理由: 空気・煙(気体)の比熱が約 3 割小さくなり(N2 29.1 → 20.8)、同じ反応熱で炎のセルが熱くなる → 熱分解が速く(セルロースが早く尽きる)、
  熱いセルが多く、熱い所が長く残る。燃え残りの炭と CO は量の釣り合いで決まるので変わらない。
- 坂の計器: 坂を上ったのは boudouard の 184 回だけ(2,068〜2,138 K。前は 179 回・1,645〜1,738 K)。伝導で坂を上った面 0。
- **基準を取り直すかは本体と相談(今は記録だけ)**。取り直すなら、上の「定圧」の列を新しい基準にし、火が消える刻みは 20,000 刻み以上で測る。

## 並走との重なり
- **wt3(T-0623 釣り合いの規則)**: tests/probe_phase_test.cpp を触る(水の規則の書き直し・湯気と氷の場面)。このブランチは同じファイルの
  MakeTable(引数 writtenHeatCapacity を足した)・潜熱の lambda(定圧の比熱で数える)・main(--written-heat-capacity)を変えた → マージで衝突しうる。
  意味: wt3 の湯気・氷の場面の数(釣り合いの温度・湯気の量)は、このブランチの後は気体の比熱が定積になって動く(湯気の場面の水たまりは 20 秒で
  前の比熱 2,433 mol → 定圧で書いた既定 2,484 mol。差は小さい)。real_reactions・real_matter の値は wt3 と重ならない(wt3 は real_matter を触っていない)。
- 坂の検査(sim/reaction_slope)の G(T) の比熱を SpeciesPressureHeatCapacity にした。wt3 が釣り合いの規則を坂の検査に足す時は、同じ関数で定圧の比熱を読む。
