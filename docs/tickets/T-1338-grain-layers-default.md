## 目的(1〜2 行)
層を使う世界(environment.cell_layers = true)で、層を書かずに置いた粒を「全部が層」と読む。舞う粒は崩れ・吹き上げの出来事からだけ生まれる。

## 完了条件(チェックできる形で)
- [ ] 読み方の切り替え(world_layout.h の UNWRITTEN_GRAIN_LAYERS を Settled〔層 = 量〕に)
- [ ] ハッシュ・期待の取り直しはこのブランチの中だけ
- [ ] ベイクの警告(unsettledGrainNotes → BakedReactionTable::warnings)が要らなくなるかを確かめてこのチケットに(要らなければ外すか、残す理由を書く)
- [ ] 「層の並びが無い ≠ 層 0」の印(刻みの付け替え・層なしの置き方)が要るかを ADR-0489 の記録どおり確かめる
- [ ] 層を使わない世界(既定)はビット単位で今と同じ・CPU と GPU のビット一致・release ビルド警告 0・archmap --check

## メモ・参考
- 作り手から見た違い(D-687): 層を書かずに置いた砂もそのまま積もった層になる(置き忘れて舞う・眠らないことが無い)。舞わせる時だけ層から残りへ移す法則を書く。
