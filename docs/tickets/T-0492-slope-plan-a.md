## 作り(このチャット)
- ΔG°(T) = Σ ν (h0 + Cp T − T S° − Cp T ln(T / 298.15))(mJ/mol。h0・Cp はベイクした物質の値 = エンジンのエネルギーと同じ比熱一定の近似)。
  ln は fixed.hlsli の FxLnU64(Q32)。触媒は正味の係数が 0 なので両辺で消える(エントロピーが無くてよい)。
  値の上限(|h0| < 2^36 J/mol・S° < 2^36 mJ/(mol·K)・正味の係数 < 2^8)を超える規則は「未評価(値が大きすぎる)」。
- 速さの表が 0 の温度は見ない(進まない規則は坂を上らない)。
- **成分しだい**(注意だけ。警告の文には出さない): 坂を下るが |ΔG°| < RT ln 10^6(生成物と反応物の比が 10^6 倍で向きが変わる)温度。
  T-0491 の申し送り(釣り合いの近くの一方向の規則が生成物が溜まると釣り合いを越える)をベイクで言えるのはここまで。量は T-0518 の計器で出す。
- 警告の文: 坂を上る規則ごとに 1 行(温度の範囲・釣り合いの温度・直し方の例)+ 調べられない規則をまとめて 1 行(エントロピーの無い物質の名前)。
- 試験の表(combustion_test + 標準パッケージ)の結果: 坂を上る = boudouard・mana_test_catalyzed_boudouard(11〜948 K。釣り合い 949 K)。
  ほかの 5 本は下る。「成分しだい」は boudouard の組が 949〜2279 K(T-0491 で実際に釣り合いを越えた 1645〜1738 K を含む)・carbon_combustion が 3478〜4095 K。**標準パッケージ real_reactions の boudouard も警告が出る**(一方向の規則。中身を直すかはユーザー。下の「判断待ち」2)。

## 判断待ち(仮で進めたもの。ユーザー未確認)
1. **エントロピーの無い物質を含む規則の扱い**(作り手から見た違い):
   - 案 1 黙って通す: パネルの「坂」の欄が「未評価」になるだけ。エントロピーを書かない作り手には何も出ない。坂を上る書き間違いに気づけない。
   - **案 2 まとめて 1 行の警告(仮に採った)**: 「坂を調べられない規則 N 本: …(標準エントロピーの無い物質: …)」がログとパネルに 1 行出る。
     規則が多くても 1 行。エントロピーを書けば消える。読み込みは断らない。
   - 案 3 規則ごとに警告: 未評価の規則ごとに 1 行。書き足す所が一目で分かるが、エントロピーを書かない表では警告が規則の数だけ並ぶ。
   - 案 4 エントロピーを必須にする: 書き忘れはベイクの誤り(表が当たらない)。坂の検査は必ず効くが、今の任意の欄(T-0491)と既存のパッケージを全部直す要がある。
   - 案 5 無ければ 0 とみなす: 必ず判定は出るが、0 は物理的に誤りなので誤った「上る」「下る」が出る。
   - おすすめは案 2(取り消しやすい。案 1・3 へは文の出し方を変えるだけ)。
2. **標準パッケージ real_reactions の boudouard**(ゲームの中身の現実のサンプル。D-487 ① で向きは作り手が書く): 一方向なので 949 K 以下で坂を上る警告が出たまま。
   直すなら逆向きの規則(2CO → C + CO2)を足すか、速さを低い温度で小さくする。燃える木箱の燃え方(T-0491 の幅)が変わりうる。今は直していない。
3. 「成分しだい」のしきい値 10^6(RT ln 10^6 ≈ 13.8 RT)は仮。パネルの注意だけなので、警告の数には効かない。
