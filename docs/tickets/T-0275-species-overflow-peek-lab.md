# T-0275 成分の二段: 覗き窓・実験室が溢れを読む(T-0199 から分けた)

- Status: Todo
- 種類: 工学
- 設計: 02 §3・17(R-MULTI-4)。関係: T-0199(溢れを使う多重解像度の世界〔CPU〕の残り)・T-0237・T-0212(GPU の要求の処理・覗き窓の溢れ)・T-0248

## 目的
T-0199 で CPU の溢れを使う世界(EnableWideCells)は影の引き戻し・畳む・端数を帳簿へ返す・静かな葉の許容差まで溢れを読む。
覗き窓(probe_peek。ProbePeek の m_nest は GPU に上げる世界)と実験室(lab_box。LabBoxCell・FindLabMismatch は CPU と GPU の世界を比べる)は、
まだインラインの形(LoadNestCell = 8 種まで)で読む。どちらも GPU の世界(GpuMultires)を写す・比べる作りなので、GPU 側の溢れ
(要求の処理・覗き窓の段。T-0237・T-0212)が入ってから、溢れの成分まで読む・比べるようにする。

## やること
1. 覗き窓: 覗いたセル(probe_peek.cpp の LoadNestCell)を LoadWideNestCell で読み、9 種目からの成分も表示の物質に入れる。GPU の覗き窓の段が溢れを読むこと(T-0212)。
2. 実験室: LabBoxCell・FindLabMismatch を上限の無い形で比べる(GPU の世界の溢れを読み戻す口が要る)。
3. 試験: 9 種以上のセルを覗く・実験室で 9 種目の生成物ができる場面で、CPU と GPU がビット一致。

## 完了条件
- 覗き窓と実験室が 9 種以上のセルの成分を落とさずに見せ、CPU と GPU の比べ方が溢れの成分まで比べる

## 見積もり
1 チャット(2 時間)。GPU の溢れ(T-0237・T-0212)の後。
