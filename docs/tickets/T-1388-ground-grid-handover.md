## 目的(1〜2 行)
地面の格子の頁(物の箱のレベルの 4³ ボクセル・番号は世界の木の座標)を試験の中に作り、§12.6.4 の判定と渡し直し(点の数えで整数に配る・余りは地面の座標で決める・同じ刻みに m 個動き出す時は 1/m)を CPU で書く。

## 完了条件(チェックできる形で)
- [ ] 止まる・動き出す・頁を返すで、Σ 葉 + Σ 格子 + Σ 物 + Σ 対の端数 − 帳簿 が毎刻みビット単位で一定
- [ ] 向きの揃った物の往復(止まる → 動き出す)で層の中身がビット単位で元に戻る
- [ ] 重なる 2 つの物が止まる・同じ刻みに 2 つ動き出す で、物の登録の順を入れ替えてもビット一致
- [ ] 浮動小数点なし・release 警告 0・archmap --check

## メモ・参考
