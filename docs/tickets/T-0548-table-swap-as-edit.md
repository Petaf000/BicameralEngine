## 目的(1〜2 行)
UE と同じ形(D-491)に揃える: 編集の状態で表を差し替えたら時間を進めずにすぐ当たり、Undo/Redo で戻せ、保存点を捨てない。
プレイ中に差し替えても、やめるとプレイ前の世界に戻る(表はファイルの今の中身)。

## 完了条件(チェックできる形で)
- [x] 編集の状態の差し替え(ファイル・反応表のパネル・環境ミキサー。どれも同じホットリロードの道)は刻み E の適用の単位で当たる(刻みの番号は E のまま)
- [x] 表を差し替えても保存点を捨てない。差し替えより前の保存点へも戻れる(戻すと表も戻り、差し替えの印を足し直して当て直す)
- [x] 元に戻す・やり直す(置く・消す)が差し替えをまたいで効く
- [x] プレイ中に差し替えてやめると、プレイ前の世界 + ファイルの今の中身の表に戻る(Q64 ④。仮)

## 判断待ち(仮で進めた。ユーザー未確認)
1. **プレイ中に表を差し替えてからやめた時の表**(作り手から見た違い。Q64 ④):
   - 案 A(仮・おすすめ): **やめるとプレイ前の世界に戻り、表はファイルの今の中身のまま**(ファイルが正本)。プレイ中にパネルで値を詰めて、
     やめてもう一度プレイすると、その値でプレイ前の世界から試せる。表とファイルが食い違うことが無い。
   - 案 B: やめると表もプレイ前に戻す(UE の PIE の中の変更が残らないのと同じ)。プレイ中に詰めた値は捨てる。ファイルは書き換わったまま
     なので、エンジンがファイルを書き戻すか、表とファイルが食い違う(次に保存すると当たる)。
   - おすすめは A(パネルは書いた時にファイルへ書き戻すので、B だと書き戻しを取り消す仕組みが要り、表の正本が 2 つになる)。
2. **表の差し替えを Ctrl+Z / Ctrl+Y(世界の元に戻す)の 1 歩にするか**:
   - 仮: しない。Ctrl+Z は世界の編集(置く・消す・つつく・押す)だけ。表を戻すのは反応表のパネルの「元に戻す」(ファイルを書き戻す → 差し替え)
     か、ファイル・ミキサーで。差し替えの後も置く・消すの元に戻すは効く(保存点を捨てないので)。
   - 代案: パネルの値の変更とミキサーも Ctrl+Z の列に入れる(UE の Transaction と同じ。パネルの元に戻すとミキサーの外すを呼ぶ。外のエディタで
     保存したファイルは入れない)。チャット 1 回分ほど。おすすめ: 仮のまま始め、パネルで値を詰める作業で不便なら代案(T-0567 に控えた)。
