## 目的(1〜2 行)
置き場 ①(気体・液体・粒の面の運動量を別に)で、面の 3 × 3 の引きずりの連立を消去して陰の圧力の式に入れ、
しずく・水面の風・詰まった砂を染みる水が 21 §5.2 の R2 の合格に入るかを測る。

## 完了条件(21 §5.2 の R2 の残り)
- [ ] しずく(2 mm)の空気中の終端の速さ ±20 %(気体 ↔ 液体の引きずり。しずくの大きさ `drop_size_um`)
- [ ] 水面で風が水を引きずりすぎない(10 m/s の風で水面の速さが風の 5 % 以下。水面のセルでの弱め方。21 §2.4)
- [ ] 詰まった砂の堤を染みる水(Kozeny–Carman で導いた通しやすさの Darcy ±10 %。場面 sand_levee)
- [ ] 置き場 ① で R1 の主の行(静かな池・連通管・閉じた空気・ダム)が ④ と同じ範囲(① で水面の気体が液体の柱の坂で暴れないか。T-0868 の仮)
- [ ] 保存 0・決定的・刻み 1/60 と 1/120 で ±5 %

T-0869 の 2 本目に当たる。ここで終端の速さ・刻みによらない・1 mg で暴れない、のどれかが落ちたら R2 は 2 本で不成立。

## メモ・参考
- T-0869 の 1 本目(置き場 ④)の作り: `PrepareCoupledFace`・`EliminateGrain`・`CoupledSystemTerms`・`SolveCoupledFace`。2 × 2 を消去した形を 3 × 3 に広げる(気体と液体の間にも K)。
