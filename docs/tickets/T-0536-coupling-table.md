## 作り手から見た違い(書き方の問い。Q66・Q70 の本体。おすすめは仮・ユーザー未確認)
書き方(仮。ADR-0238):
```lua
drags = {
    salt_thermal = { flow = "heat", drags = "species:salt", coupling = "0.3", within = "water" },  -- within は省ける(どこでも)
}
machines = {
    pump = { store = "work", push = "gas", coupling = "0.9", cost_j_per_mol = 3000, speed_w = 3000 },
}
```
| 問い | 案 | 作り手から見た違い |
|---|---|---|
| ① どこに書くか | **A 2 つの分類 drags・machines(仮)** / A' 1 つの分類 `couplings` に `kind = "drag" / "machine"` / B drags の行に構造の欄 / C 物の型の欄 | A: 物質の法則(どこでも効く)と置いた機械(そこだけで効く)が分かれて見える。A': 一覧が 1 つで「同じ形」が見た目にも出るが、引きずりの行に費用・速さの欄が、機械の行に within が空で並ぶ。B・C は T-0493・T-0495 の表。**どれにしてもエンジンの中は同じ 1 つの型・ベイク・検査**で、変わるのは読み手の入口(script/coupling_package)と data/types だけ |
| ② 数を何で書くか | **a q・w・P(仮)** / b 最大の効率 η と w・P / c 止まる坂と q・P | a: drags と machines が同じ 1 つの数 q。b: 機械には分かりやすいが drags の q と別の数に見える(換算 q = 2√η ÷ (1 + η))。c: 気体の坂は温度で変わるので書いた値は決めた温度での値になる。パネルは今 a で書いた値から η_max と止まる坂(300 K の圧力の比)を出す |
| ③ q を書く形 | **10 進の文字列 "0.9"(仮。A と同じ)** / 百万分率の整数 `coupling_ppm = 900000` | 文字列: 読みやすい。小数を数で書く(0.9)と形の誤り(Luau の数は倍精度。R7)。ppm: 「整数・単位は欄の名前」の約束どおりだが −1〜1 が読みにくい |
| ④ 範囲の外 | **警告して ±1 に押さえる(仮。D-487 ②)** / 読み込みを止める | 押さえる: 表は当たり、パネルに「1.2 → 1(押さえた)」と出る。止める: 書き間違いに気づきやすいがホットリロードで古い表のまま |
| ⑤ |q| = 1 | **許す(仮)** | 理想の機械(止まった所で蓄えを使わない)・結合しきった引きずり |

## 構造の置き場所の案(T-0555 で決める。作り手から見た違い)
押す構造は「2 つの口(Y を取る所・押し出す所)と蓄えの置き場」を持つ。表 `machines` は**種類**(q・w・P)だけを書き、置いた物(インスタンス)は世界のデータ。
| 案 | 作り手から見た違い |
|---|---|
| **i 口の組の一覧(おすすめ・仮)**: 構造 1 つ = { 種類・口 A のセル・口 B のセル・蓄え・持ち主〔無し / 物の ID〕} の一覧。物に付いたもの(体の筋肉・荷車のポンプ)は持ち主の物が動くたびに口のセルを付け替える | セルで作る機械(壁に埋めたポンプ)も物に付いた機械も同じ 1 つの書き方。口は 2 つのセル(隣でなくてよい = 管)。数は構造の数だけで、セルの数に比例しない |
| ii セルに付く(セルの材料の欄に「この面は押す」) | 壁・管の形をブラシで描ける。物に付いた機械は書けない。多重解像度でセルを粗くすると構造が消える(17 の頁を畳むと衝突) |
| iii 物に付く(物の型の欄) | 体・道具は書きやすい。地形に作った機械は「動かない物」を置くことになる |
- 蓄えの置き場: i は構造ごとの数(J)。体は体の塊の成分(D-469。魔素・ATP に当たるもの)を X にしたいので、蓄え X = `species:<物質>` の時は口 A のセル(か持ち主の体)の成分から取る形が要る(T-0537 と一緒に)。
- 世界の刻みでは、構造ごとに口の 2 つのセルの坂(f_X・f_Y)を読み、流れの組を ADR-0228 の規則(蓄えが足りない時の解き直し・行き過ぎの歯止め・丸めの向き)で当てる。
  同じセルに複数の構造の口があると取り合いになる(反応の取り合い〔T-0016〕と同じ扱いが要る。未設計)。
