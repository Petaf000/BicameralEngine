# T-0323 世界のコマンドの段に魔法のパッチ(T-0287 から分けた)

- Status: Todo(T-0287 の後)
- 種類: 工学
- PC: 必須
- 設計: docs/design/02-reaction-system.md §5・§5.1 / ADR-0095。関係: T-0024・T-0287

## やること
多重解像度の世界(GpuMultires / StepNest)と仮の世界(ProbeSim)で、パッチを置くコマンド(PROBE の型)・記録と再生・境(始まり・終わり)で範囲に重なる全部のレベルのブロックをつつく段を刻みに(活性の種にも)・世界の保存点(VRAM の写し。T-0143)にパッチの列を含める・列が一杯で断った数を数える。

## 注意
- 仮の世界の反応の評価は Work Graph。反応の核を 1 ノードに 3〜4 か所展開すると HW で DEVICE_HUNG になるので、MpPatchedTable の包みは今の展開の数を増やさない形で入れる。ルート署名は多重解像度で 64 / 64 語(T-0024 と同じく外のバッファの枠を刻みの間だけ結ぶ)。
- 公開リポジトリなので、魔法・魔素の設定や値はゲームの中身として書かない(D-006)。シミュのコードに浮動小数点を書かない。
- ルートの SRV / UAV に GetDimensions を使わない(大きさは定数で渡す。T-0024)。
