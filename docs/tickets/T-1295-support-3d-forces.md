## 目的(1〜2 行)
3 次元の格子の梁(sim/support_law_3d)に、割れの法則(sim/support_fracture)が読む面の力と、掘った後の温めた始まりの運び(CarryFrom)を足す。

## 完了条件(チェックできる形で)
- [ ] 面の力(伸び・ずれ 2・ねじれ・曲げ 2・縁の力 = N ± 6M/dx の 2 つの向き + 角)とたわみのエネルギー(2 次元の SupportFaceForces を 3 次元に)
- [ ] 割れの法則の 3 次元への口(面の残りの硬さ 3 軸は 1 本目で読める)
- [ ] CarryFrom(掘った後の温めた始まり・共役勾配の向きを捨てる)
- [ ] 2 次元の法則を 3 次元の奥行 1 セルで置き換えるかを決める(置き換えれば 2 次元の試験の全部が 3 次元の道を通る。費用は節 × 6 成分。【エンジン】なら問いに)
