## 目的(1〜2 行)
気体の熱いセルの実効の音速の頭打ちを、地面の温度(293 K)からではなく安定の上限(ν = 0.6)に届く温度(約 473 K)から掛ける。
普通の爆発・衝撃波(後ろ 470 K まで)を本物の音速で解き、炎の中(470 K 超)だけ約 432 m/s で頭打ちにする(T-0234 の判断待ち 1)。

## 完了条件(チェックできる形で)

- [x] 多重解像度の木は ν がいちばん大きいレベルで求める(小刻みを分けない 2 レベルでも 473 K)
- [x] gas_reference: 既定の頭打ちのまま衝撃波が理論どおり・1500 K のセル・熱い爆発(1500 K・5 倍の物質量)で真空のセルができず保存がビット単位
- [x] gpu_gas(HW・WARP): 1500 K のセル(hot_cell)・熱い爆発(blast_hot)・爆発(blast)で毎刻み CPU とビット一致
- [x] release のビルドが警告 0・archmap --check

## メモ・参考
- 頭打ちの温度 T_頭 = T_基準 ×(上限 ÷ c̃)²(切り捨て)。上限は 1 レベルの箱で `GasSoundSpeedLimitMmPerS(substeps)`(= 小刻み × 18 m/s。ν = 0.6)、
  木では `>> max(k − σ)`。T_頭 より熱いセルは α × T_頭 ÷ T(実効の音速が上限で止まる)。シェーダーは係数を受け取るだけで変えていない。
- 設定の意味: 0 = 安定の上限から(既定)・UINT32_MAX = 頭打ちなし(試験だけ)・地面の層の基準の温度を入れると T-0234 までの形(案 A)。
- 気体の成分による音速の違い(軽い気体は c_iso² が大きい)は、α を地面の空気から作るので頭打ちと関係なく前からある(水素の多いセルは上限を超えうる。T-0186 で気体と反応を結ぶ時に見る)。
