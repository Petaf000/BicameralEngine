## 目的(1〜2 行)
T-1331 の --grow で見つけた 2 つの振る舞いの原因を切り分ける。① 1 万ボクセルを超える箱で圧力の赤黒が上限 1024 回で止まり、収まらないまま進む刻みがある。
② 12 万ボクセル(紙 96 × 48・層 8 段)の箱で GPU の実行が失敗する。直すのは結果を変えない範囲(② の上限・置き場)だけ。

## 完了条件(チェックできる形で)
- [ ] ② の原因を順に切り分ける(GBV/WARP・置き場の大きさ・ルート定数の幅・Dispatch の上限・1 つの Dispatch の時間〔TDR〕)
- [ ] ① 上限に当たった時に何を返すか(今の振る舞い)と、0 から収まるまで・多重格子の既定で、箱の大きさごとに当たるかを表に
- [ ] 直しがあれば CPU とビット一致(gpu_object_shell_flow HW/WARP)→ 印。① の直しが収まりの規則を変えるなら案と測りを書いて司令塔へ(T-1321 のチケットに 1 行)

## メモ・参考
- 測り方(試験の中だけ・捨てる測り): `gpu_object_shell_flow_test --queue compute --grow [--grow-shape 列 高さ 層] [--grow-sweeps N] [--grow-ticks 暖機 測る] [--grow-groupshared]`。
  ログの「測った N 回の解きのうち上限で止まった M」は暖機の後の刻みだけ(「上限で止まった」は暖機から)。
