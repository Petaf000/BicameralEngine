# T-1347 T-1084 の場面で「放射なし」の火が 40 s で消えなかったのが 8 s で消える件を切り分ける(挙動の変化)

- Status: Done(2026-11-12 wt4。意図した変化 = T-1113 の既定の RC。仮 = ユーザー未確認)
- 種類: 工学(切り分け)
- PC: 必須
- 見積もり: チャット 0.5 回分
- マイルストーン: 列 4(元: T-1084 の表の「放射なし」の行)
- 設計: docs/design/07-transport.md / 決定: D-647(標準の物質に赤外の吸い込みを現実の桁で)・T-1113(既定の熱の放射の段 RC)

## 目的(1〜2 行)
radiation_scene_measure(草原の延焼 64³・CPU)で、T-1066 の 2 回目(2026-10-24)は放射なしで付けたセルが 5002 K・40 s で消えなかったのに、
T-1084(2026-11-12 main)の rad=0 は 8 s で消える・一番熱い 1942 K。どのコミットで変わったか、意図した変化か不具合かを決める。

## 見立て(コードを読んだ所。二分の前にログと道具から絞る)
- radiation_scene_measure の rad=0 は「対の形の放射の段(EnableRadiation)を入れない」だけ。T-1113 から ProbeReference は既定で熱の放射の段 RC を流す
  (対の形を入れると RC は流さない)。だから T-1084 の rad=0 は「放射なし」ではなく「既定の RC の段 + 表の放射の吸い込み(D-647)」。
- T-1066 の 2 回目は、表の放射の吸い込みが 0(D-647 の前)で、RC の段も無い(T-1113 の前)= 本当に放射なし。
- 2 つの違い(D-647 の表の値・T-1113 の既定の段)のどちらか / 両方で、付けたセルが RC で熱を放って冷める見込み。
- 確かめ: 道具に cascade=0(RC も外す)を足し、rad=0 / rad=0,cascade=0 / 吸い込み 0 の組で流す(ビルドの二分より安い)。

## 結果(2026-11-12 wt4・release・main 75656697 の上・CPU リファレンス・4 つをスレッドで並べて)
`radiation_scene_measure sec=40,rad=0 | +cascade=0 | +cascade=0,ac=0,ak=0,as=0,aw=0 | rad=0,ac=0,ak=0,as=0,aw=0`
| 設定 | 火が消えた | 一番熱い | ms/刻み |
|---|---|---|---|
| rad=0(T-1084 の「放射なし」の行 = 既定の RC の段が流れる) | **8 s** | 1941581 mK | 844.6 |
| rad=0,cascade=0(本当に放射なし) | 40 s で消えない | **5002322 mK** | 66.3 |
| rad=0,cascade=0 + 吸い込み 0 | 40 s で消えない | 5002322 mK | 66.4 |
| rad=0 + 吸い込み 0(RC は流れる) | 8 s | 1941581 mK | 845.4 |
- **変わったのは T-1113 の daaf77e3(2026-10-26。仮の世界の CPU リファレンスに既定の熱の放射の段 RC。main へは df371e8d)**。cascade=0 で RC を外すと T-1066 の 2 回目
  (5002 K・40 s で消えない)が mK まで同じに戻る。D-647 の吸い込みの値(speciesRadiationAbsorption = 対の形の値)は効かない(RC は表の speciesLight の帯を読む)。
- **意図した変化(不具合ではない)**: 付けた 1 セルが 5000 K のまま居座るのは、熱を逃がす道が伝導だけだった時の形。RC が入って熱く光るセルが周り・空へ放つので
  冷めて 8 s で消える(D-206 の保存は RC の持ち越し・外へ出た分を含めて成り立つ。T-1113 の試験)。T-1084 の表の「放射なし」は名前の誤りで、正しくは「既定の RC の段(対の形なし)」。
- 気になる所(司令塔へ・直すのは別): **既定の RC の段では、この場面の草は燃え広がらない**(付けたセルだけ・8 s で消える)。燃え広がる 14 s・18 s は対の形(ADR-0262。退く道・比べる参照)の値。
  T-1113 が「燃え広がりを T-1156(燃える気体)に分けた」のと同じ根(既知)。RC の CPU リファレンスは 845 ms/刻み(64³。対の形 134 ms・放射なし 66 ms)で、CPU の測りの道具では重い。
- 二分のビルドはしなかった(切り替えの口 1 つで変わり目のコミットが決まったため)。
