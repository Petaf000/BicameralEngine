## まとめ方(GroupTimeTreeEvent)
- 同じ刻みに解く列どうしは面を持たない(列の外は値 0 を固定した面)ので、節を並べただけの系は塊の対角。部品の掃き出しは赤黒(座標の偶奇)で節ごとに閉じる。
- ただし部品の段の作り方は系全体で決まる(粗い段を足すかは「どれかの節の重み < 1/2」・縮約は座標の親・最も細かいレベルから縮める)。
  そこで **V の回数・段の数・節のレベルが同じで、粗い段が 3 つまで(縮約がブロック = 8 セル角の中で閉じる)の列だけ** を 1 組にまとめ、ほかは列ごとの組に残す。
- 組の系の値は列ごとに解いた値とビット一致する(作りの上でも・試験でも)。だから CPU の試作(列ごと)を変えずに、GPU だけまとめて解ける。

## 結果(2026-10-26・RTX 3070 Ti・release・compute キュー・`--no-gbv`)

### ビット一致
- CPU(`time_step_tree_test event-merge shape=fine`・火事 18 分 = 65,536 刻み・既定の設定): 出来事 53,246・列 104,155。2 つ以上の列をまとめた組 26,615 の**全部で
  まとめた系の値 = 列ごとに解いた値(食い違い 0)**。試作の結果(要約・保存・負 0)は変わらない(試作は列ごとのまま解いている)。
- **どの出来事も組は 1 つ**(列の数 1/2/3/4 以上 = 26,631/13,308/6,655/6,652)。段の数は e ≤ 7 が 1・e 8〜9 が 2・e 10〜12 が 3・e 13 が 4 だが、
  同じ出来事に段の数の違う列が並ぶ場面は出なかった(粗い段 4 つの e 13 の列も単独の出来事)。
- GPU(`gpu_time_step_span_test --spans <event-merge が書いた系>`): 火事 18 分の 128 出来事に 1 つ(416 出来事・列 831・77 万セル)で、
  組を GPU で解いた値 = 列ごとの CPU の値(ビット一致)。ctest は着火から約 4,000 刻みの 64 に 1 つ(`time_step_event_merge` → `gpu_time_step_event`)。

### 1 出来事の GPU の時間(416 出来事の平均。段 0 + 段の重み + その e の V の回数・記録の形は前の解きから・各系を別の実行で暖機 2 回の後 6 回の最小)
| 形 | 1 出来事 | 火事 18 分(× 53,246) |
|---|---|---|
| 列ごとの系(今の口) | 0.683 ms | 36.4 秒 |
| **出来事ごとに 1 本(組)** | **0.320 ms** | **17.0 秒**(列ごとの 0.47 倍) |
- 起動の数(Dispatch の組)が列の数 1.96 → 1 になり、待ちはほぼ半分。
- **ただしこの測りは GPU の時計が下がった状態**(下の T-1140 の見立て)。費用の式(TimeTreeSolveCost・高い時計の測り)は同じ出来事で列ごと 6.37 秒・組 7.51 秒と出て、
  組の方を遅く見積もった(1,024 セルを超えると「大きい出来事の下限 0.26 ms」に入る形)。実測では組の方が 2 倍速いので、**下限の値は時計の揺れの分で、
  式の「小さい / 大きい」の分け方は実際の出来事に合わない**。費用の式の値は D-662(起動時に測る)で決め直す(T-1152)。

### 段 0 の 128bit の割り算(`--stage-variants`。段 0 の段だけ。e = 0 の系は段 1 つ)
| 系 | 本物 | 右辺の項を割らない | 読むだけ | 割り算の分 |
|---|---|---|---|---|
| 512 セル(高い時計) | 0.0133 ms | 0.0082 ms | 0.0020 ms | 85 %(右辺の項 38 %・段 0 の重み 47 %) |
| 8,192 セル(高い時計) | 0.0215 ms | 0.0143 ms | 0.0041 ms | 81 % |
| 8,192 セル(下がった時計) | 0.128〜0.139 ms | 0.099〜0.110 ms | 0.016〜0.018 ms | 87 % |
- 前の作業役の見込み「段 0 の費用の大半は 128bit の割り算」は**当たり**(8 割強)。ただし段 0 は 512 セルの出来事 0.040 ms の 3 分の 1 なので、出来事の 3 割弱。
  部品の共通の関数(EqGpuFinishNode・EqSourceTerm)なので変えていない(土台に足りないもの へ)。

### V の回数を作る時に決める形

  **未測**(静かな夜の出来事で測る = T-1152 の測りと一緒に)。
