## 目的
T-0853 の部品はスカラー(節ごとに値 1 つ)。支えの法則(R-B1・wt4)は変位 3 成分を持つ。
成分ごとに独立なら今の部品を 3 回呼べばよい。成分の間の結合(ポアソン比など)が要るなら、節が成分を持ち、面の係数が 3 × 3 になる口を足す(部品の芯 = 多重格子の段・決まった回数・面の形・閉じた領域は同じ)。
