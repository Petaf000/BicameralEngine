## 目的
T-0853 の部品はスカラー(節ごとに値 1 つ)。支えの法則(R-B1・wt4)は変位 3 成分を持つ。
成分ごとに独立なら今の部品を 3 回呼べばよい。成分の間の結合(ポアソン比など)が要るなら、節が成分を持ち、面の係数が 3 × 3 になる口を足す(部品の芯 = 多重格子の段・決まった回数・面の形・閉じた領域は同じ)。

- [ ] 要るなら: 成分を持つ節の型と CPU リファレンス・スカラーの場合(成分 1)が今の部品とビット一致・保存・決定性
- [ ] 段の斜めの棒(T-0944・ADR-0415)を、同じレベルの斜めの 2 節を結ぶ面(x ⇄ 上の非対角あり)として持て、粗くする時に子の面の和で扱えること。棒の硬さ ka/12 は合わせ込みの値なので、この口を入れた後に測り直す
- [ ] 1 セルの厚さの張り出し・片持ち梁・アーチで、釣り合いに着くまでの刻みと割れの判定が遅れないか(すぐ折れるはずの棚が遅れて折れないか)を測り、前(R-B1: 張り出し 400〜640 刻み)と並べる。ユーザーはこの結果を見て、今の速さでよいかを決める(2026-10-21)
