## 目的
「水 → 湯気」「氷 → 水」のような相変化を、新しい仕組みを足さずに反応表の規則と物質の相で書けるかを確かめ、書けない所に何が要るかを作り手から見た違いで決める。
標準パッケージに水の 3 相の見本(現実の値・出典)を足し、仮の世界の CPU リファレンスで確かめる。

## 結論: 書ける(足したのは「全部次数 0 の規則」だけ)
氷・水・湯気を別の物質にし、相変化を向きごとの規則の対で書く(D-487 ① 案 A: 向きは作り手が書く)。

| 作り手が書きたいもの | 書き方(見本の値) | 書けたか・作り手から見た違い |
|---|---|---|
| 潜熱 | 書かない。物質の生成エンタルピーと比熱の差から出る | 書けた。融解 6.010 kJ/mol(273.15 K)・蒸発 44.004(298.15 K)・40.87(373.15 K。本当は 40.65)。エネルギーは構造的に保存 |
| 蒸発の速さと沸点 | 蒸発 = 水(次数 0)→ 湯気。凝縮 = 湯気(次数 1)+ 水(触媒)→ 水。釣り合いの湯気の濃さ = A_蒸発 e^(−Ea/RT) ÷ k_凝縮 を飽和水蒸気の濃さに合わせる | 書けた。釣り合いは 298 K で 0.1585 mol/セル(飽和 0.1585)・323 K 0.553(0.571)・373 K 4.073(4.066)。沸点は「湯気の分圧が周りの圧力に届く温度」として出る(書く値ではない) |
| 逆向き(凝縮) | 上の対の片方 | 書けた。ただし**水のあるセルでだけ**(水を触媒にした。判断待ち 2) |
| 融点で止まる | 融解 = 氷(次数 1)→ 水 を急な Arrhenius(Ea 600 kJ/mol)・凝固 = 水(次数 0)+ 氷(次数 1)→ 氷 を一定(1 /s)。273.15 K で等しい | ほぼ書けた。正味 = 氷 ×(k_融解 − k_凝固)で向きが温度だけで決まり、熱が足りなければ張り付く。**ちょうどではない**: 鋭さは Ea(1 K 上で 2.3 倍)・速さの表は 1 K ごとなので切り替わりは 273/274 K の境(0.85 K 高い) |
| 凍り始める(過冷却の水が凍り出す) | — | **書けない**: 冷えるほど速い規則(Ea < 0)が要る。今は種の氷があるセルでだけ凍る(T-0624) |
| 霧・雲(水の無い所の過飽和) | — | **書いていない**: 凝縮を水の触媒にしたので、水も氷も無い空気の湯気は凝縮しない(T-0624) |

足したもの: ベイクが「次数 1 の反応物は 1〜2 個」を「0〜2 個」に緩めた。全部次数 0 の規則は「ある限りセルの体積あたり一定の速さ」(A は mol/(m³·s))で、
凝縮相の活量 1(量によらない蒸発)を書く形。評価のコード(reaction.hlsli)は前から 0 個を扱えた(積が 1)。GPU の表の形は同じ。

## 書き方で分かったこと(作り手の注意。ADR-0272 の注)
1. **触媒の形の規則は、同じ刻みのうちに自分の触媒を作り直す**: 凝固を次数 0(一定の速さ)で書くと、熱いセルでも融解が氷を使い切る同じ刻みに凝固が
   氷を作り、氷が 2.08 mol/セル残り続けた → 固体を含むセルは液体を通さない(T-0609)ので、溶けた水が台から流れなかった。凝固を氷について次数 1 にして直した
   (残りは毎刻み 2/61 に減って 0 になる)。蒸発と凝縮も同じ形で、湯気のある熱いセルには水が「湯気 ÷ 60」ほど残る(流れは止めない)。
2. **釣り合った対は眠らない**: 水と湯気が釣り合ったセルは、蒸発と凝縮が毎刻み行き来して値が変わる。静かな池(8 × 8 セルの 1 層・空気の下)で
   10 秒目も 1 刻みあたり 39 ブロックを計算した(眠れば 0)。海・湖のある世界の費用(D-468)。氷と水が共にあるセルも同じ → T-0623。
3. **坂の検査が対の片方ずつに警告する**: 標準の状態で、蒸発は 373 K より下・凝縮は上・融解は 273 K より下・凝固は上で坂を上る(4 本の警告)。
   正味は坂を下る(対の釣り合いが熱力学の釣り合いと合う)ので、検査を「逆向きの対」として見る形が要る → T-0623。
4. 次数 0 と 2 の規則の速さは 0.5 m のセルの体積で焼いてある(02 §3.1)。多重解像度の粗いセルで体積の換算が要るかは未確認(T-0623 の中で確かめる)。

## T-0601 の仮の扱い(気体のぶんがセルの器 2^31 を超える)
- 蒸発を次数 0 にしたので、湯気は**飽和の濃さ × セルの体積で止まる**(水の量によらない)。1 セルいっぱいの水(6917 mol)でも、湯気になるのは
  釣り合いの量まで(373 K で 4.1 mol・500 K で 108 mol)。残りは流れで湯気が運ばれた分だけ蒸発する。
- 見本の値で釣り合いが 2147 mol に届くのは約 **726 K より熱い水**(溶岩に水を掛けるなど)だけ。そこは未解決のまま → **T-0622**(器を取り合いの資源に)。
- 気体の式の assert に当たるかは、726 K より熱い水のセルを作らないので試していない。

## 判断待ち(仮で進めた。ユーザー未確認)
1. **相変化を「向きごとの規則の対」で書く**(ADR-0272。仮・おすすめ)。作り手から見た違い: 蒸発・凝縮・融解・凝固を 4 本の規則として書き、速さの値で沸点・融点・
   蒸発の速さが決まる。潜熱は書かない。代案: 規則に「釣り合い」(K(T) か融点)を書く形(T-0623 の案 B)= 1 本で両向き・釣り合えば眠る・融点がちょうど。
   新しい書き方が 1 つ増える。
2. **凝縮・凝固は相手の相があるセルでだけ**(水・氷を触媒。仮)。作り手から見た違い: 霧・雲・自然に凍り始めることが書けない。
   代案: 種なしの規則も足す(水の無い空気でも湯気が凝縮 → 全部の湿った空気のセルが眠らない・燃焼の煙の湯気が水になる = サンプルの世界の振る舞いが変わる)。
3. **融点の鋭さ(融解の Ea 600 kJ/mol)と凝固の速さ(1 /s)・凝縮の速さ(1 /s)**: 見本の値で、現実の値ではない。作り手から見た違い: 大きくすると
   融点のまわりがちょうどに近づき、熱の出入りに速く付いていく。速さの表が 1 K ごとなので、それより細かい融点は表を補間しないと出ない。
4. **場面 grass_fire_river の川を相変化つきの水にした**(仮)。作り手から見た違い: 火に近い川の水が蒸発して熱を吸う(前は液体のまま熱くなった)。
   湯気は GPU の世界では流れない(気体の区画が GPU に載るまで。T-0592)。戻すなら場面の species.luau に相変化の無い水を書き戻す。

## 分けたもの(番号は司令塔の配り T-0622〜T-0624・ADR-0272〜0273)
- **T-0622**(工学・設計あり)気体のぶんの器(2^31)を反応の取り合いの資源にする(吸熱の上限と同じ形: 気体を増やす規則は器の残りまでに縮める)。
  GPU の表に物質の相の 1 bit が要る(RxSpecies)。T-0601 の残り(726 K より熱い水・燃焼の生成物)。置くコマンドの気体のぶんの確かめも。
- **T-0623**(設計 + 工学)逆向きの対: ベイクが「規則 B は規則 A の逆」を見つけ、①坂の検査を対の正味で見る(片方ずつ警告しない)②釣り合ったら眠る
  (正味だけ進める・対の正味が 0 なら変えない)。案 B: 規則に釣り合いを書く形。多重解像度の体積の換算(次数 0・2)もここで確かめる。研究を含む
  (打ち切り: 対の正味で決定性と保存を保てない時は、坂の検査の対だけ入れて眠りは見送る)。
- **T-0624**(設計)冷えるほど速い規則(Ea < 0。核ができる・過冷却から凍り出す・霧)と、種なしの凝縮・凝固を書くか。判断待ち 2 と一緒に。
- 名前だけ: ⑤ の場面 grass_fire_river の指標を測り直す(川が湯気になって熱を吸う。GPU の世界)・速さの表の 1 K の補間・霜(湯気 → 氷)。

## 重なり(並走へ)
- **湯気が気体の区画で大きく凝縮・蒸発すると、エネルギーの保存が崩れる刻みがある**(元素は保存): 湯気の場面で、気体の区画だけでは 960 刻み目に +54.2 kJ、
  液体の区画も重ねると 569 刻み目に +52.9 kJ。氷の場面(湯気 200 mol まで)は 20 秒保存した。見立て(未確認): 反応(凝縮・蒸発)がセルの気体の質量を
  変えても、気体の区画が持つ運動量・運動エネルギーのぶん(セルの外の欄)は変わらないので、次の気体の段の運動エネルギーとずれる
  (燃焼でも気体の質量は変わるが、湯気の凝縮ほど大きく速くない)。相変化の規則が初めて大きく踏んだ所。→ 気体の区画の持ち主(wt3 T-0592)・wt2 T-0612・wt6 T-0610。
  この試験の湯気の場面は、元素を毎秒確かめ、エネルギーは崩れた刻みを表示するだけにした(`Run(..., energyHolds = false)`・`ReportSteamWithLiquid`)。
- 物質の欄: phase・density_kg_per_m3 を data/types/bicameral.d.luau の Species に足した(T-0609 は読む所だけで型に無かった)。
- probe_liquid_test は自分で `liquid_water` を足す(名前が違うので real_matter の `water` とぶつからない)。
