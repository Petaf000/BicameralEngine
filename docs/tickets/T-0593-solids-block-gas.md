## 目的(1〜2 行)
今は木箱・岩・壁のセルも気体を素通しする(気体の体積 = セル)。凝縮相の体積を差し引き、面の開き(通れる割合)で流れを絞る。

## 完了条件(チェックできる形で)
- [ ] 物質の型に体積の欄(モル体積か密度。どちらで書くかはユーザーに聞く。作り手から見た違い: 密度は調べやすい・モル体積は混ぜた時の足し算がそのまま)
- [ ] 気体の体積 = セル − 凝縮相の体積(圧力・基準との差)。満ちたセルは気体を通さない
- [ ] 孔のある物(砂・土・木)の通しやすさ(T-0414 の地面の孔の空気)
- [ ] 書かなければ今どおり(既定 0 = 体積なし)
- [ ] CPU リファレンスとビット一致・保存則の検査
