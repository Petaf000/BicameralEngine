# T-0593 固体が気体を塞ぐ(凝縮相の体積と面の開き)

- Status: Done(2026-10-15 wt2。T-0612 と一つの芯で。残りは T-0616〜T-0618 と下の「判断待ち」)
- 種類: 工学 + 設計
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: ROADMAP の T-0210(T-0590 から分けた)
- 設計: docs/design/07-transport.md §2.7・§2.8 / 決定: ADR-0256・ADR-0268(Proposed)

## 目的(1〜2 行)
今は木箱・岩・壁のセルも気体を素通しする(気体の体積 = セル)。凝縮相の体積を差し引き、面の開き(通れる割合)で流れを絞る。

## 完了条件(チェックできる形で)
- [x] 物質の型に体積の欄: T-0609 の密度(density_kg_per_m3)をそのまま使う(ベイクがモル体積を作る。判断待ち 2)
- [x] 気体の体積 = セル − 固体 − 液体(圧力・基準との差)。満ちたセルは気体を通さない(0 µmol)
- [~] 孔のある物(砂・土・木)の通しやすさ: 空き(体積の割合)で通す。孔の形(透水の係数)は T-0616
- [x] 書かなければ今どおり(既定 0 = 体積なし。密度を書いた固体の無い世界はビット単位で同じ。probe_gas・gas_reference・gas_projection・gas_tree が通る)
- [x] 保存則の検査(毎刻み 元素・エネルギー・運動量が帳簿込みでビット単位)・決定性(2 回でハッシュ一致)。GPU は無い(T-0617)

## 一つの芯(T-0612 と一緒。ADR-0268)
セルの体積 = 固体 + 液体 + 残り(気体)。`sim/cell_volume` が密度から数え、気体の段(probe_gas → gas_reference の GasBox::openQ16)と
液体の段(probe_liquid)が同じ「空き」を読む。面の開き = 両側の空きの小さい方。空きは毎刻みセルから作る(状態の欄は増えない)ので、
燃えて固体が減る・溶けて液体になると次の刻みから通る。液体が入れば気体の空きが減り、空気は押し出される。

### 作り手から見た違い(何を書くと何が通る / 止まるか)
| 書くもの | 気体 | 液体 |
|---|---|---|
| 固体に密度を書き、セルを満たす量(岩・壁・満ちた砂) | 通さない(0 µmol) | 通さない(0 µmol) |
| 固体に密度を書き、体積の半分(砂・土) | 通る(渡り始めが遅い。33 ms で 61%) | 孔に入り通る(2 秒で 92%)。上の水は染み込む |
| 固体に密度を書き、少し(砂 1 µmol) | 砂なしと同じ(99.997%) | 砂なしと同じ |
| 固体に密度を書かない(どれだけ多くても) | 素通し(今まで通り) | **素通し(T-0609 までは壁だった。判断待ち 1)** |
| 液体 | 液体が占めたぶん空気が押し出される | — |

## 判断待ち(仮で進めたもの。作り手から見た違いで)
1. **密度を書かない固体**: 仮 = 場所を取らない(気体も液体も通す)。
   - 作り手から見た違い: 岩・壁の物質に密度を書き忘れると、水が岩を素通りする(T-0609 までは「固体が少しでもあれば水の壁」だった)。
     気体は今までと同じ。案 B「密度の無い固体はセルを満たす」にすると、密度の無い木箱が煙も止め、木の孔の空気(燃える酸素)が閉じ込められる。
   - おすすめ: 仮のまま + ベイクが「凝縮相に密度が無い」を警告に出す(T-0616 で。今は出していない)。
2. **書く欄**: 仮 = 密度(kg/m³)だけ(モル体積は書かない。ベイクが作る)。作り手から見た違い: 密度は調べやすい。混ぜた物の体積は足し算(混ぜて縮む・膨らむは無い)。
3. **孔の通しやすさ**: 仮 = 空き(体積の割合)だけで、開いた管と同じ速さで通す(半分の砂でも水が 2 秒で 92% 渡る。本物の砂よりずっと速い)。
   作り手から見た違い: 今は「砂を厚くしても少し遅くなるだけ」。T-0616 で物質に透水の欄を足すか、空きの 3 乗(Kozeny–Carman)で決めるか。
4. **気体が閉じ込められた液体**: 液体は空気の圧力を感じない(T-0618)ので、水が気体のセルを満たし切ると、気体の空きが 0 になって閉じ込められる
   (圧力は空き 1/256 で頭打ち)。今の試験の速さでは空気が先に抜けて起きていない。

## 並走との重なり
- probe_liquid.cpp の Step(圧力の列・面の運動量の更新)を書き換えた。wt6 の T-0610(運動量の移流)も同じ関数を触る: 私の変更は
  ReadState(空き・equivalent)と圧力の列(room・equivalent)と面の更新の `push / weight / faceOpen` の分岐だけ。マージでは T-0610 の移流を
  面の更新の後に足す形で合わせる。
- probe_gas.cpp の Step に `box.openQ16 = CollectGasOpen(...)` の 1 か所。wt3 の T-0592(GPU に気体)は GPU の箱に openQ16 を渡さないので、
  密度を書いた固体のある世界では CPU と GPU が食い違う → T-0617 まで、GPU の試験の表に固体の密度を書かない(今の試験の表には無い)。
- wt4 の T-0611(相変化)は液体と気体の間を物質が移る: 移ると次の刻みの空きがそのまま変わる(このチケットの形で足りる)。
- tests/probe_liquid_test.cpp の石の量と密度(2 行)を変えた(wt6 も触る)。
