# T-1079 世界の中の光: 面どうしの対のつながりを整数で作り、GPU 版と費用を測る(R-R1)

- Status: Todo(T-1080 の結果の後。D-636 で入れ替えを考える時)
- 種類: 工学 + 測り
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: 列 4(R-R1)
- 設計: docs/design/23-radiation.md §3.3・§3.4 / 決定: ADR-0452(Proposed)
- 親: T-1062(試作 tools/light_exchange)

## 目的
試作の double の所(つながりの係数・空の割合・組の中の 1 次の重み)を整数にし、CPU リファレンスと GPU(Compute)をビット一致させ、RTX 3070 Ti で 1 刻みの費用を測る。

## 完了条件
- [ ] 近い対は遮る物の無い G をベイクした表(ずれ × 2 つの向き)から、遠い対は整数の式で。空の割合は決まった向きの光線で整数に
- [ ] 1 次の重み(勾配・モーメント)を固定小数で。組から面へ分け直す時の和がちょうど親の量(整数)
- [ ] CPU と GPU のビット一致・2 回でハッシュ一致・保存(T-1062 の場面)
- [ ] 費用: 48³・64³ の石の地面・段のある地形・閉じた部屋(RTX 3070 Ti。D-634)。閉じた部屋の近い対を記憶に持たずステンシルで回す形も
- [ ] 値は docs/perf.md に日付と GPU とともに

## メモ
- T-1062 の見込み(未確認): 64³ の地形 約 0.5 ms・64³ の閉じた部屋 約 4.6 ms(1,372 万本。近い対が 1,061 万本)。
