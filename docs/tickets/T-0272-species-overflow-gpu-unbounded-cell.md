# T-0272 GPU の溢れの 1 セルの上限を無くす(速い形 + 大きいセルの道。T-0248 から分けた)

- Status: Done(2026-10-11。範囲を「伝導の段から上限の無い形のセルを無くす・上限 32 → 64」に絞った。全部を刻む段の大きいセルの道は T-0326、上限を表の物質の数までは T-0327)
- 種類: 工学
- PC: 必須
- 見積もり: チャット 1〜2 回分
- 設計: 02 §3・17(R-MULTI-4)・ADR-0052(追記 3)。関係: T-0176・T-0211・T-0236・T-0248・D-428・D-448

## 今(T-0248 の後)
- GPU の溢れの世界の 1 セルの上限は RX_GPU_WIDE_SPECIES = 32 種(インライン 8 + 溢れ 24)。物質が 32 以下の表なら CPU の上限の無い世界
  (EnableWideCells)と食い違わない。超える生成物は待たせて MR_COUNTER_LIMIT_PRODUCTS に数える(D-448 の「上限を無くすまでの仮のふるまい」)。
- 上限の無い形のセル RxGpuWideCell は固定の大きさの配列で、伝導の段の溢れの変種(512 スレッド・1 スレッド 1 セル)と全部を刻む段の全部が
  その大きさのスクラッチを持つ。64 にすると空気だけの伝導ありの刻みが 9 → 20 ns/セルになり、HW(RTX 3070 Ti)の gpu_multires の
  「溢れを使う世界の刻み(伝導 あり)」(上限の場面・RunLimitsStepWide)で DEVICE_HUNG が 2 回続けて出た(WARP は通る)。原因は未確認。
- 反応の核(reaction.hlsli)はセルの配列を直接読む(.species[i]・.amounts[i] が約 55 か所)・値で写すので、メモリに置くセルの形に替えるのは大きい。

## やること
1. 速い形(今の 32 種まで)で刻み、超えるセルだけ大きいセルの道で刻み直す: ①で「入らない」印 → 刻みの段の後に少ないスレッドの段
   (WideRetryBlock と同じ型。1 グループ = 1 枠、大きいセルを持つのは印のセルだけ)。伝導の段の熱(BlockCellThermal)は溢れから直接足し合わせる
   関数にして、伝導の段から上限の無い形のセルを無くす(熱容量・化学エネルギー・伝導率は和なので並びに依らずビット一致)。
2. 大きいセルの道の上限を表の物質の数まで上げる(セルの形をメモリ〔作業場の UAV〕に置く・核をセルの形の道具で読むように替える、など。
   測ってから選ぶ)。見出しの塊の表は面の最初の塊に置けば、見出しの大きさが上限に依らない(今は 32 種で 96 語 = 384 B/頁)。
3. HW の DEVICE_HUNG: 32 種の計測の場面のものは 1 本のリストの時間切れ(T-0273)。64 種のものは「同じ compute キューで 32 種のセルを刻んだ後の
   伝導の溢れの変種」で起き、上限 48 は通り 56 から止まる(T-0290・ADR-0052 追記 5。1 スレッドのスクラッチの大きさが疑わしい。1 で伝導の段から
   上限の無い形のセルを無くすのが直し方の本命)。

## 引き継ぎメモ
- 上限 RX_GPU_WIDE_SPECIES = 64(shaders/common/multires_wide.hlsli。戻すなら 1 行)。上限の無い形のセルを持つのは 64 スレッドの段
  (StepPagedWaitWide・StepExpandedWait の溢れの変種・WideRetryBlock・WideDeferredBlock)だけ。伝導の段の溢れの変種は持たない。
- 刻みの段の順(溢れの世界・伝導あり): … → ConductApply → WideDeferred(新)→ WideAllocate → WideRetry。--diagnose-wide の段のタイムスタンプは 1 つ増えた
  (足す / 回したセルを刻む / 配る / 刻み直す)。
- 見出しの要求の語にビット 11(MR_WIDE_REQUEST_DEFERRED)を足した。WideDeferredBlock が消してから PlanWideSide が書き直す。
- 32 種のセルが並ぶ極端な場面は 64 で 2.5〜3 倍遅い(全部を刻む段・WideDeferred のセルの形が倍)。T-0326 の大きいセルの道で戻す。
