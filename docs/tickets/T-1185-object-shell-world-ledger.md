## 目的(1〜2 行)
T-1144 の世界の流れの場面(tests/object_shell_nest.h)で、物の側の保存は 0 なのに世界の Σ − 帳簿 が崩れた(物なしの同じ世界は 0)。どの列が・どの段で崩れるかを測り、直す。

## 完了条件
- [x] 崩れる所を特定する(列・段)
- [x] 直して、世界の流れの場面で 世界の Σ − 帳簿 が毎刻み 0(紙・層 2 段・0.5 m)
- [x] ctest の object_shell(--quick)が通る

## 分かったこと(2026-10-26 wt5)
- **原因は試験の場面の書き戻しの二度載せ**: `AfterObject`(object_shell_nest.h)は物の熱の前の囲むセル `before` との差を帳簿「物との受け渡し」に載せて書く。
  走りの終わりに層を返して保存を確かめる 2 回目の呼び出しが、同じ `before`(最後の刻みの物の熱の前の値)と比べたので、**最後の刻みの差を帳簿に二度載せていた**。
  刻みの途中の検査(60 刻みごと)は全部 0 で、崩れは終わりの 1 回だけだった(T-1144 の紙の出力に「世界の保存が崩れた刻み」の行が無いのと合う)。
- T-1144 で見込んだ「物がセルの気体の質量を変えた時の運ぶ欄(運動量・運動のエネルギー・前の質量)が帳簿に載っていない」は**誤り**:
  気体の段の「欄が物質に付く」(sim/multires_gas。前の質量と比べて運動量・運動のエネルギーを合わせ直し、差を帳簿の理由「欄が物質に付く」「物理の熱」へ)が
  物との受け渡しで変わった質量も受けている。毎刻みの検査で途中の崩れは 0。
- 直し: 書いた後に `before` を書いた値へ揃える(同じ刻みにもう一度呼んでも差は 0)。検査を毎刻みにし、崩れたら初めの刻みと崩れた欄(エネルギー・元素・登録した欄)を書く口を足した(`PrintBrokenColumns`)。

## 結果
| 場面 | 速さ | 物 + 帳簿 | 世界の Σ − 帳簿 |
|---|---|---|---|
| 紙・層 2 段・7.8 mm・24 列・世界の流れ・0.5 m(T-1144) | 16.1 mm/s | 0 | 崩れた |
| 同じ(直した後・毎刻み検査) | 16.08 mm/s | 0 | **0** |
- 草の溢れ(成分の枠 8・物の熱の気体の上限 8 を世界の大気〔argon 入り〕で超える)は別の件のまま(T-1144 の「土台に足りないもの」)。

## 司令塔へ
- 土台は足していない・変えていない(試験の中だけ)。T-1144 の「土台に足りないもの」の 2 つ目(物との受け渡しと運ぶ欄の帳簿)は**要らない**ので消してよい。
  ただし D-663(面の運動量の式)で物が運動量を持つ形にする時は、物へ運ぶ運動量の帳簿の理由が要る(今は物の層の流れの運動量は箱の中だけで、セルとは受け渡さない)。
