## wt3 との分担(WorldCopy の変更)
- **sim::WorldCopy の API は変えない(足すだけ)**。`WorldCopyResult` に欄を 1 つ足す:
  `std::vector<uint64_t> tickGpuTimestampTicks` — `hashes[i]` と同じ並びで、S(hashes[i].tick) を作った刻みの GPU の時間(タイムスタンプの刻み。
  その刻みの単位の和)。活性のブロック数は今まで通り `hashes[i].scheduledBlocks`。今ある欄(gpuTimestampTicks・ticksRun など)はそのまま。
- 単位の時間を刻みにまとめる部品は `sim::TickCostAccumulator`(engine/src/sim/tick_cost.h。新しいファイル)。WorldCopy の中と本物のフレームのループで使う。
- 判定(予算・スロー)は frame/weight_check(新しいファイル)。wt3(T-0432)は使わなくてよい。world_copy_runner・copy_panel は wt2 が触る。
- wt3 が WorldCopy に欄やメソッドを足すのは自由(衝突したら司令塔が両方残す)。
