## 目的
T-0954 は世界のデータの値(`WorldPhysics::fineRegion`)と規則(`sim::GradedCoarseness`)と見込みの数えだけを作った。多重解像度の木は今この規則を読まない
(細かくする要求と、静かな葉を粗くする SubmitQuietCoarsenRequests だけ)。種(局所の状態で細かくした所)からの距離で、木の葉の粗さを規則に合わせる。

## 完了条件
- [ ] 種の集め方(活性・前線・割れの先端。状態だけで決まる)と、種からの距離(Chebyshev・mm)を木の上で出す
- [ ] 静かな葉を粗くする時に、規則の粗さより細かい葉だけを粗くする・規則より粗い所を細かくする(2:1 の釣り合いと合わせる)
- [ ] 同じ値なら同じ木(決定的)・値を変えると葉の数が変わる・CPU と GPU でビット一致
- [ ] 実際の木の葉の数を docs/perf.md の見込み(T-0954)と比べる
