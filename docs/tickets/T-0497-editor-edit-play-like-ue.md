## 目的(1〜2 行)
今のエディタは起動すると世界が動き続け、Space で止める(前の方針の実験の窓の名残り)。UE と同じく、起動は止まった編集の状態 →
プレイで動かす → 動かしたままも編集できる → プレイをやめると編集の状態(プレイ前の世界)に戻る形にする。

## 完了条件(チェックできる形で)

## やったこと
- editor/time_control: `EditorMode`(Edit / Play)・`StartInEdit`・依頼に play / stopPlay。Space は編集の状態ならプレイ、プレイ中は一時停止 / 再開。
  1 刻みはプレイの一時停止中だけ。tests/time_control_test に編集の状態とプレイの場面。
- frame/frame_loop: 編集の状態で待っているコマンドを当てる刻みだけ進める(ApplyEditCommands)・プレイを押した後の最初の刻みの境界 P を
  プレイを始めた保存点へ写す(SubmitSim・SaveSlotFor。保存点の最後の番号)・やめる(StopPlay: 番号がプレイを押した後のコマンドと運びを捨て、
  P の保存点へ戻す。残っていなければ P 以前の保存点から P まで流し直す)・やり直し(RedoBrushStroke)・戻ってよい範囲(UndoFloor)。
- editor/brush_undo: `UndoFloorTick`・`PLAY_UNDO_WINDOW_TICKS = 720`・`PlanBrushUndo` に floorTick・`TakeStrokeCommands`(やり直し用)。
- editor/brush_panel: やり直しの列(元に戻した運びのコマンドを元の刻みのまま持つ)・やり直すボタン(Ctrl+Y)・プレイ中の運びを忘れる。
- frame/sim_scheduler: `Rewind` が前の流し直しの行き先を忘れる(残すと、やめて戻った後に古い行き先まで流し直していた)。
- frame/auto_play: `--auto-play` の手順と判定(下の試験)。

## T-0411 の刻み 0 の保存点の扱い(見直し)
- 刻み 0 の保存点は**編集の状態の元に戻す・やり直し**の土台(編集の状態で進むのは置いた分の刻みだけなので、刻み 0 から流し直しても短い)。
- プレイ中の元に戻すは `UndoFloorTick(プレイ中, P, 今)` = max(P, 今 − 720) より後の運び・保存点だけ。P が 0(プレイをすぐ押した)なら、
  最初の 12 秒は刻み 0 の保存点がプレイを始めた保存点を兼ねる。T-0411 の判断待ち(古い運びを刻み 0 から戻す案 A)は、
  D-491 で「プレイ中は最近約 12 秒」に置き換わった(編集の状態は何回でも = 案 A の形のまま)。

## 試験
- `window_play_record`(`--world sample --editor --auto-play --record`): 起動から 30 フレーム刻み 0 の前で止まっている → 木の球 A・木炭 B を置く →
  B を戻す(止まった境界 E の状態 S(E) が変わる)→ A を戻す(さらに変わる)→ A をやり直す(B だけ戻した状態と同じ)→ B をやり直す(元と同じ)→
  プレイ(P = E)→ 60 刻み後に木の球 C → P + 100 でやめる → 刻み P の境界に戻り 20 フレーム動かない → もう一度プレイ →
  刻み P〜P + 50 のハッシュが 1 回目と同じ・P + 60〜P + 100 のどこかが違う(C が消えた)。
- `window_play_play`: その記録(最後の流れ)を別の起動で再生して同じハッシュ列。

## 判断待ち(仮で進めた。ユーザー未確認)
1. **編集の状態で置いた時、世界の時間が進むか**(作り手から見た違い)
   - 案 A(仮で採った): 置いたものを当てる刻みだけ進める(置く 1 回 = 1 刻み = 1/60 秒、世界が進む。燃えている所は 1 刻みぶん燃える・
     積み木は 1 刻みぶん落ちる)。今の刻みの仕組みのまま(適用は刻みの最初の単位)。編集の状態の刻みは置いた回数ぶんだけ。
   - 案 B: 時間を進めずに当てる(適用の単位だけを走らせて、伝導・反応・物理を走らせない)。編集の状態の世界が本当に止まる。
     刻みの途中の状態を見せる・保存点を刻みの途中に置く仕組みが要る(GPU のループの変更。チャット 1 回分ほど)。
   - おすすめ: 今は A。編集の状態で燃えるものを扱う・積み木を組む時に 1/60 秒ずつ進むのが気になるなら B(T-0509 として分けた)。
2. **キーの割り当て**: F5 / Space = プレイ・Esc = やめる・プレイ中の Space = 一時停止 / 再開・N = 一時停止中に 1 刻み・Ctrl+Y = やり直す(仮)。
   UE は Alt+P でプレイ・Esc でやめる。Visual Studio は F5 / Shift+F5。どちらに寄せるか。
3. **プレイ中の Undo の幅**: 720 刻み(12 秒)で固定(仮)。保存点の数・間隔(`--save-points`・`--save-interval`)とは別に決めた
   (保存点が足りない時は「保存点が無い」で戻せない)。
4. **プレイ中に反応表を差し替えた(ホットリロード)後にやめる**: 保存点は全部捨てられるので、プレイ前の世界に戻れない(今の世界のまま
   編集の状態へ。ログに警告)。表の差し替えを「編集」として扱い、プレイ前の世界 + 新しい表で作り直す形にするか(D-491 ③ の「世界を作り直す」と同じ道)。
5. **編集の状態でのホットリロード**: 表の差し替えは刻みの境界で当たるので、編集の状態ではプレイを押すまで当たらない(未確認。試していない)。
