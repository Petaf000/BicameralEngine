## 引き継ぎメモ
- 2026-10-13 の形(位置の表): HW の compute キューの `--no-gbv --repeat-wide many,many-conduct,limits,limits-conduct 1` が通った。計測は 32 グループで
  981 / 498 ns/セル(perf.md)。64 グループとの組み合わせと debug の ctest(gpu_multires_wide_*)は投げた所で返した(wt4 の runner/logs の
  20261013-072925-run〔64 グループの計測〕・20261013-082750-test〔ctest〕を見る)。ctest が通れば完了条件は全部済み → Done にしてよい。
- 位置の表の正しさの理由: 1 セルに同じ物質の成分は 1 つだけなので、表が指す位置の成分が同じ物質ならそれが前から探した位置。表は作業場の
  レーンごとに 1 つで、前のセル・別の書くセルの位置が残っていても「同じ物質か」で弾いて前から探す(無い物質を引く時は今まで通り前から探す)。
  成分の物質を書くのは RX_SET_ENTRY(= RxWithEntry)だけなので、核の書き方を変える時はそこを通すこと(RxWritableCell は位置を変えずに写す)。
- 作業場の VRAM: レーン = (3 + 2 + 3 × 8 + 1)c + 64 語(前は 29c + 64)。
- 前の巡目のメモ(① → ③ の写し・VRAM が増えた・伝導なしはグループを増やしても変わらなかった)は 2026-10-12 の作業ログのとおり。
  1 セルの仕事は成分の数に比例する形になったので、残りは同時に動くスレッドの数(T-0458)。
