## 作業ログ(チャットごとに 3〜5 行、新しいものを下に)
- 2026-10-03: Nsight Graphics の GPU Trace をコマンドライン(ngfx)でランナーから動かせた(性能カウンタはユーザーが NVIDIA コントロールパネルで許可)。
  物理の山は **SM 0.9%・DRAM 1.3% で、演算でも帯域でもなく待ち時間で詰まる**(1 スレッドの 6×6 の連鎖・Dispatch 877 回/刻み)。結果は 04 §6・08 §6「結果(T-0093)」・perf.md。
- 6×6 を 2 回解かせる診断(結果は捨てる・ハッシュ不変、コミットしない)で、6×6 は 1 刻み約 2.0 ms(56%)、平方根と 128÷64 がそれぞれ約 3 割。山の色は 4〜5 で 11〜12 色が空。
- SASS は静的には読めない(GetCachedBlob は圧縮)ので、実行命令数のカウンタで動的な数を取った: gpu_fixed_bench に `--only` `--iterations` `--groups` と演算 solve6 を足し、
  `tools/fixed_bench/sass_count.py` で記録と表を作る。04 §6 の SASS の列を埋めた。
- BACKLOG の「空の色を飛ばす」「6×6 を並列に / 命令を減らす」に材料を書いた。どれを採るかはユーザーの判断待ち。書き方(04 §6)は変えていない(処理量ではなく待ち時間が効いているため)。
