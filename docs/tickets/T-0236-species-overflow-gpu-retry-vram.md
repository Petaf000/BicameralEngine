# T-0236 GPU の溢れが足りない時に同じ刻みでやり直す・使う分だけの VRAM(T-0211 から分けた)

- Status: Todo(T-0211 の後)
- 種類: 工学 + 測定
- 設計: 02 §3・17(R-MULTI-4)・ADR-0052。関係: T-0176・T-0211・T-0187・D-401・D-428

## 今(T-0211 の後)
- 溢れは頁ごとに先に取った 2 面(1 面 MR_WIDE_PAGE_ENTRIES = 1024 成分・1 頁 約 28 KiB。空気だけの頁も同じだけ取る)。
- 頁の溢れが 1024 成分を超えるブロック・1 セル RX_GPU_WIDE_SPECIES = 24 種を超えるセルは、溢れるセルを書かずに待たせて MR_COUNTER_LIMIT_PRODUCTS に数える
  (全部を刻む Compute の StepPagedWaitWide と伝導の段の RestepConductWideCells。どちらも ②の PlanWideSide が「入らない」を返す所。CPU の上限なしの世界と食い違う)。

## やること
1. 入らない時: 印(「大きい溢れが要る」)→ 刻みの中で配り直し(TreeExpand と同じ型: 枠の順に配る段)→ そのブロックの溢れるセルだけ同じ刻みでやり直す。
   ③ は入るかを決めてから書くので、入らないブロックの溢れるセルは書かれていない(伝導の段では変化だけ足した値、反応の前)= やり直す元の値が残っている。
   やり直しは ③ の RestepWideCell を新しい溢れの塊に向けて呼ぶだけで足りるはず(印の付いたセルは groupshared の gs_wideMarks。やり直しの段では数え直す)。
2. 使う分だけの VRAM: 溢れの塊(例: 128 成分)を空きのスタックから枠の順に配る(端数の枠と同じ型)。頁の見出しに塊の表。空気だけの頁は溢れを持たない
   (今の 1 頁 28 KiB を先に取るのをやめる)。頁を返す時・畳む時に塊も返す。
3. 1 セル 24 種の上限: RxGpuWideCell の配列の大きさ。超える場面(試験の表で 25 種)を作って、待たせずに済む形(2 回に分けて刻む・上限を上げる)を測って選ぶ。
4. 計測: 溢れを使う世界の空気だけの刻みの ns/セル と VRAM(docs/perf.md。本体・他の作業ツリーのランナーが全部 idle の時に)。

## 完了条件
- 頁の溢れが足りない場面(試験: 1 ブロックに 9 種目の生成物を 1024 成分より多く作る)で待たせず、同じ刻みで終わり、CPU と HW・WARP が毎刻みビット一致
- 空気だけの頁の溢れの VRAM が 0(見出しを除く)
