## 目的
セルの中で燃える反応を、整数で・決定的に・保存則を守って評価する核を作る。手書きの小さな試験用の表(公開側に置く試験データ。D-006)で、
ベイク(整数)→ 1 セルの評価(HLSL と C++ で共通のソース)→ CPU と GPU のビット一致、まで。

## 形(このチケットで決めて 02 §3 に書く)
- **量**: 物質量 uint64、1 = 1 µmol(ADR-0012)。エネルギー int64、1 = 1 mJ(熱 + 化学。04 のまま)。
- **温度**: 化学のエネルギー = Σ 量 × H0(H0 = 0 K を基準にした物質ごとの値、J/mol = µJ/µmol。ベイクで生成エンタルピーと比熱から作る)。
  熱 = エネルギー − 化学、温度 = 熱 ÷ Σ 量 × 比熱。**反応は成分を変えるだけでエネルギーの合計を変えない**ので、エネルギーは構造的に保存される。
- **速度**: Arrhenius をベイクで温度(1 K 刻み)ごとの表にする(整数の ln・exp。R7)。値は「仮数 32bit × 2^指数」。
  反応物の次数は 0 か 1(次数 1 の反応物は 1〜2 個)。進行度 = 表の値 × 次数 1 の反応物の量の積。
- **端数**: 進行度の端数は、カウンタ型の乱数(R6: 世界のシード・刻み・セル・規則の鍵)で確率的に丸める(遅い反応が 0 に切り捨てられて止まらないように)。
- **候補の規則**: 規則は「反応物のうち物質 ID が最小のもの」の索引にだけ入れる(重複なく引ける)。反応物が全部そろった規則だけ評価。
- **取り合い**: 物質ごとに要求の合計とある量を比べ、足りなければ各規則を min(ある量 ÷ 要求) で縮める(128bit の掛け割りで切り捨て)。
  吸熱の規則は「熱」も資源として同じく縮める(熱が負にならない)。並び順に依存しない。
- **成分の持ち方**(この段階): インラインに 8 個(物質 ID で並べる。0 になったものは消す)。溢れは T-0017 / R-MULTI-4。
- イベント(音・光)の出力はしない(T-0089 以降)。GPU の形はこのチケットでは Compute(1 スレッド = 1 セル)で、Work Graphs へは T-0089 で載せる。

## 研究の打ち切り条件
「打ち切り」ではなく、うまくいかない時に試す順(D-411):
1. 端数の確率的な丸めで遅い反応の速さが合わない → 規則ごとの端数をセルに持ち越す(状態が増える)
2. 1 刻みで反応物を使い切る速い反応が振動・破綻する → R-REACT-1(06 の細分)へ回す(このチケットでは記録だけ)

## メモ・参考
- 試験の表の値は文献値を丸めた(生成エンタルピーは NIST の 298.15 K の値、比熱は一定と置く)。セルロースの熱分解は
  この値だと発熱になる(実際は生成物が複雑でほぼ中立)。ゲームの中身ではないので直さない(T-0002 で決める)。
