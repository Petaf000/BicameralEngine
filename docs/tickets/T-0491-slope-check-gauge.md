## 目的(1〜2 行)
坂の原理の P2「散逸の流れは坂を下る向きにだけ進む(エントロピーの生成 ≥ 0)」を確かめる物差しを作る。
仮の世界の CPU リファレンスの燃える木箱で、毎刻み面の熱の流れと反応ごとのエントロピーの生成を数え、坂を上る規則の一覧を出す。

## 作り
- 静的な一覧: 規則ごとに、正味の係数(触媒は両辺で消える)と物質の H(T) = h0 + Cp T(エンジンと同じ)・S(T) = S° + Cp ln(T / 298.15) から ΔG°(T) を出し、
  速さの表が 0 でない温度のうち ΔG° > 0 の範囲を「標準で坂を上る」とする(T-0492 のベイクの警告の元)。
- 毎刻み: 伝導は S(t) の熱のキャッシュから HcFaceFlow(伝導の段が使う値そのもの)で全部の面を数え、σ = Q (1/T冷 − 1/T熱)。
  反応は、成分が変わったセルだけ刻みの核(RxStepCellWait → 取り合い → 入りきらない規則を待たせる)と同じ手順をなぞって規則ごとの進行度 ξ を取り出し、
  σ = ξ · A / T(A = −ΔG。気体は分圧 n R T / V を活量に、固体〔セルロース・炭〕は 1)。なぞった結果は S(t + 1) とビット一致を確かめる。
- 場面: 遊びの指標 sealed_fire_out と同じ(木箱の壁 (28, 32, 32) を刻み 0 につつく)。ctest は 600 刻み(約 20 秒)、`slope_check_test --burn [刻み]` で長く測る(既定 18000)。
- セルロースのエントロピー 170 J/(mol·K) は推定(**未確認**)。±100 J/(mol·K) 動かしても静的な判定が変わらないことを試験が確かめる。

## 結果(2026-10-15・試験の表・18000 刻み = 5 分・CPU 30 分)
- **伝導**: 流れのある面 1.08 × 10^10(延べ)・坂を上った面 **0**・非対称 0・面の σ の最小 0(負は一度もない)・Σσ 3.71 × 10^6 J/K。
- **反応**: なぞったセル 49,561(延べ)・食い違い 0・エネルギーの合計は毎刻み保存。
- **坂を上る規則の一覧**:
  | 規則 | 標準(ΔG°)で坂を上る温度 | 木箱で起きたこと |
  |---|---|---|
  | boudouard(C + CO2 → 2CO) | 11〜948 K(釣り合い 949 K。文献の約 980 K との差は比熱一定の近似) | 650 回。949 K より冷たい 122 回は CO が少ないので活量込みでは下る。**1645〜1738 K の 179 回は活量込みで坂を上った**(CO が多く CO2 が少ないセルで、一方向の規則が釣り合いを越えて進んだ。ξ 2.7 × 10^-4 mol と小さい)。最後の CO2 は 0 mol |
  | mana_test_catalyzed_boudouard | 8〜948 K(同じ物質なので同じ坂。触媒が低い温度で進ませる) | 木箱には魔素が無いので起きない |
  | cellulose_pyrolysis・cellulose_combustion・carbon_combustion・carbon_partial_combustion・mana_test_catalyzed_cellulose_combustion | なし(ΔG° は −275〜−3435 kJ/mol) | 坂を上った回 0 |
- **分かったこと(T-0492 へ)**: ΔG° だけのベイクの警告は boudouard の組を捕まえるが、「釣り合いの近くの一方向の規則が、生成物が溜まると釣り合いを越えて進む」(上の 179 回)は
  成分で決まるのでベイクでは捕まえられない → 開発ビルドの計器(刻みごとの数え上げ)が要る。ベイクで出せるのは「速さが 0 でない温度で |ΔG°| が小さい(例: 13.8 RT = 10^6 倍の Q で逆転)規則 = 成分しだいで坂を上りうる」の注意まで。

- 案と影響(作り手から見た違い): (a) 上の幅(おすすめ。燃え方の形〔燃え尽きる・炎が残る時間・残る炭〕が同じなら通す)/
  (b) 全部 ±5 %(反応や伝導の小さな直しでも落ちうる。直すたびに基準を取り直す手間)/ (c) 火が消える刻みだけ(sealed_fire_out 1 本で足りるが、燃え方の中身が変わっても気づかない)。
- 気体とつなぐ(T-0493・T-0186・T-0210)と煙が熱を運ぶので、燃え方はこの幅を大きく外れる見込み。その時は基準を取り直すか(ユーザーが決める)を聞く。
- 幅の検査を ctest にするか(18000 刻みは CPU で 30 分。GPU の写しの早送り〔遊びの指標〕なら速い)は T-0492 以降で決める。
