## 目的(1〜2 行)
仮の世界の気体の区画で燃える木箱を流すと、断面の温度と CO2 が隣り合うセルで交互に熱い・冷たい(800 K 超と低いセルが交互)になる。
CPU(probe_gas)と GPU はビット一致なので式の性質。原因を最小の場面で突き止め、根っこを一つの芯で直す(見せ方でぼかさない)。

## 調べたこと(2026-10-17・release・CPU。probe_gas_test の 9・gas_reference_test の TestHotBlockNoCheckerboard)
- **再現**(main・燃える木箱 2 秒・陽解法): 区画 3456 セルのほぼ全部が**パリティ(x + y + z の偶奇)どおりの完全な 3 次元の市松**になる。
  谷か山(x・z の 3 つ組で真ん中が両隣より 100 K 以上熱い・冷たい)0(1 刻み)→ 255(2)→ 3384(5)→ 5755(120)・250 K 未満 1682 / 800 K 超 1751。
  断面は「*0*0*0…」(1000 K 超と 0 K が交互)。**投影では出ない**(120 刻みで谷か山 4。区画がほぼ全部 800 K 超で一様)。
  → 陽解法の圧力の拡散(Δp̃ ÷ 4c̃。陽的な拡散)の奇偶のモード。投影は陰的なので出ない。MUSCL(成分だけ)・格子の配置(中心の流れ)は
  市松の圧力に力も流れも返さない(面の平均で消える)ので、育てるのは拡散だけ・抑えるのは出ていく割合の上限だけ。
- **線形の解析**: 市松のモードの 1 小刻みの増え方 g = 1 − 3 × (c_e² ÷ c̃)× Δt ÷ Δx(3 次元・6 面)。c_e² = dp̃/dρ。
  地面の空気は c_e = c̃ で ν 0.47 → g = −0.42(安定。境は ν 2/3 = T-0226 の「小刻み 16 で発散・18 で安定」と合う)。
  熱いセルは p̃ を T_頭 ÷ T 倍するので c_e² = c̃² × T_頭 ÷ T_基準 × (M_基準 ÷ M)(p/ρ = RT/M)。
  **T-0269 の頭打ち T_頭 = T_基準 ×(上限 ÷ c̃)²(約 473 K)は音の速さの数(c_e Δt ÷ Δx ≤ 0.6)だけを見ていて、拡散の数(c_e² ÷ c̃ × Δt ÷ Δx)は
  空気で 0.76 > 2/3**。さらに頭打ちは温度で比べるので、軽い気体(湯気 M 18)は同じ温度で c_e² が 1.6 倍になる。
- 直し 1(頭打ちを拡散の数で: T_頭 = T_基準 × 上限 ÷ c̃ ≈ 372 K。`GasSoundCapTemperature`): 燃える木箱の谷か山 5755 → 3044・250 K 未満 1682 → 589。
  区画の上半分はなめらかになり、下半分(燃えた気体)は市松が残る。
- **最小の場面**(gas_reference_test の TestHotBlockNoCheckerboard。12³ の閉じた箱の真ん中 6³ を等圧の熱い気体に替えて 1 秒):
  T-0269 の頭打ちでは**湯気(M 18)の塊が 600 K・1000 K とも真空のセル(0 mg)まで抜けた**。空気・CO2 は出ない。新しい頭打ちでは湯気も
  最も軽いセル 45717・27431 mg(試験の EXPECT に)。→ 拡散の数は p/ρ = RT/M に比例し、軽い気体ほど不安定(空気の線形の解析の境 2/3 より、
  実際の境は少し上〔空気 1.61 倍は安定・湯気 2.5 倍は発散・1.97 倍は安定〕。押し出す仕事の応答が断熱と等温の間のためと見ている。未確認)。
- 原因の切り分けのまとめ: **陽解法の圧力の拡散(陰的な投影では出ない)**。格子の配置(中心の流れ・面の力積)は市松に応じない(育ても抑えもしない)。
  MUSCL は成分だけで市松の向きを持たない。反応の熱の出方(熱分解で一瞬に膨らむ)は、熱く軽い気体を作る・出ていく割合の上限に当てる(T-0646 の熱が負の穴)ことで
  強く出すきっかけ。
- **直した芯**(ADR-0292 Proposed): `GasSoundCapTemperature` を T_基準 × 上限 ÷ c̃ に(係数は CPU から GPU へ渡るのでシェーダーは同じ・CPU と GPU の一致はそのまま)。
- **残り → T-0658**: 頭打ちを温度でなく p/ρ(と γ)で比べる(CPU・木・GPU の 3 か所)。燃える木箱の下半分の市松は、T-0646(熱が負の穴)と
  どちらが残すかを T-0646 のマージ後に測り直す(t-0646 を重ねて測ろうとしたが、H: の空きが 0 で git が書けず中止)。

## 既存の試験で動いた数(release・CPU)
- gas_reference: 通る。sound cap 473258 → 372471 mK(実効の音速 383 m/s・拡散の数 0.6000)。strong pressure 1500 K の 2 秒後の最大の速さ 1.35 → 2.04 m/s・
  x5 1500 K 1.24 → 1.65 m/s(最も軽いセル 133091 → 122726 mg。熱いセルの音が遅いぶん圧力が抜けるのが遅い)。5 倍の衝撃波の幅 2.53 → 2.51 セル。ほかは同じ。
- gas_tree: 頭打ちの温度の範囲の EXPECT 2 つを直した(約 473 → 372 K・1 レベル 小刻み 48 は 1893 → 745 K)。ハッシュの試験は変わらない。
- gas_projection: 通る。
- probe_gas: 通る。燃える木箱 2 秒の熱の重心 11636 → 11781・CO2 の重心 10120 → 4595・CO2 1 mol 以上の最も高い層 22 → 3。
  6 種の空気の燃える木箱の CO2 の重心 4631 → 9070(どちらも市松の抜けたセルの運び方が変わった見込み。未確認)。
- 回していない: GPU(gpu_gas・gpu_gas_tree・gpu_probe_gas)。頭打ちは CPU の係数で GPU に渡るので一致は変わらない見込み。H: の空きが 0 のため
  最後のビルド(試験の範囲の直しとコメント)を通せていない → 司令塔が空きを作った後に release のビルドと gas_tree・gas_reference・GPU の 4 本。
