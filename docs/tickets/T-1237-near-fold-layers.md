## 目的(1〜2 行)
今は層のある頁を許容差つきの平均で畳まない(層まで完全に一様な時だけ畳む。ADR-0489 の 1)。層の平均(成分ごとの和 ÷ 数の切り捨て)を入れ、
ほぼ同じ砂の床も一様の枠に戻せるようにする。

## 完了条件(チェックできる形で)
- [ ] 平均で畳む時の層: 成分ごとに層の和 ÷ 数の切り捨て(0 ≤ 層 ≤ 平均の量。切り捨ての余りは層から残りへ。量の保存は今のまま)
- [ ] CPU(FoldNear)と GPU(TreeFold の許容差つき)でビット一致(GPU の一様の枠の層は T-1240 の後)
- [ ] 層の無い世界はビット単位で今と同じ(multires_quiet・gpu_multires_quiet)
- [ ] 着手の条件: 層のある頁が畳めずに重くなる場面が測れてから(D-468)

## メモ・参考
- 畳む: engine/src/sim/multires_activity.cpp の FoldNear・FoldLayeredPage。GPU は shaders/sim/multires_tree.hlsl の TreeFold。
