## 作業ログ
- 2026-09-30: 窓(platform/window)・待てるスワップチェイン(3 枚・先行 2〜3)・キュー + フェンス(gpu/queue)・待たない読み戻し(gpu/readback_ring。DebugRing も枠ごとにした)を作り、
  compute の仮の刻み(sim/probe_sim: クリック → 64 バイトのコマンド → つつき → 拡散 → 抽出 → イベント)と direct の描画(render/probe_view)をフェンスだけで並べた(frame/frame_loop)。
  リストは作るときに 1 度だけ記録(描画はバックバッファごと、シミュは枠 × 刻みの数ごと)。刻みの数は TickPacer がタイムスタンプから決め、重いと世界が遅くなる。
- 測った(docs/perf.md): CPU 0.26〜1.6 ms/フレーム(大半は Present)。空の ExecuteIndirect は 1 回約 30 µs → 刻みの数ごとのリストに替えた。
  抽出は 3 組にして描画がシミュを待たない形に(06 §4)。重いシミュ(1 刻み 25 ms 以上)では描画がシミュのバッチの速さまで落ちる(R-LOOP-2 の途中経過。BACKLOG)。
- アダプタ: 同じ PCI の ID の RTX 3070 Ti が別 LUID で 2 つ、片方は画面なし → 窓の画面を持つアダプタを優先(DeviceOptions::presentMonitor)。
- テスト 22/22(gpu_probe_sim: 分け方 8/1/ばらばらで CPU とビット一致 + イベント、tick_pacer)。ReSTIR の流用の項目はユーザー決定で削除(D-423)。
