# T-0326 GPU の溢れの世界の全部を刻む段に「大きいセルの道」を足す(溢れるセルだけ少ないスレッドの段で刻む。T-0272 から分けた)

## 目的
- T-0272 で伝導の段(512 スレッド)から上限の無い形のセル(RxGpuWideCell)を無くした(反応は WideDeferredPass へ回す)。残りの全部を刻む段
  (StepPagedWaitWide・StepExpandedWait の溢れの変種。64 スレッド・1 スレッド 8 セル)と刻み直し(WideRetry)はまだ 1 スレッドが上限の無い形のセルを
  何個も持ち、32 種のセルの頁が並ぶ場面で 1 刻み 17〜176 ms(T-0273)。
- 溢れるセルだけを WideDeferredPass と同じ型の段(印 → 1 グループ = 1 枠、または 1 セル 1 ウェーブ)に回し、全部を刻む段から上限の無い形のセルを無くす
  (ADR-0052 追記 4 の (1)。① の結果を作業場に置いて ③ は写すだけにする (2) も測って選ぶ)。

## 完了条件

## 引き継ぎメモ
- 形の選び方は ADR-0052 追記 9。速い形で上限に当たらなければ大きい形とビット単位で同じ(違うのは RxHasRoomForSpecies だけ)。
  RX_GPU_MID_SPECIES(multires_wide_step.hlsli)を変えると速い形と大きい形の境が変わる(結果は変わらない)。
- 全部を刻む段が回したブロックは要求の語の MR_WIDE_REQUEST_DEFERRED で分かる(伝導の段と同じ)。--diagnose-wide の段のタイムスタンプは伝導なしで 2 つ増えた
  (起こす / 刻む / 回したセル / 配る / 刻み直す / 木 / 広げて刻む / 回したセル / 配る / 刻み直す)。
- 1 セル 33〜64 種のセルが一面に並ぶ場面は WideDeferred(64 スレッド・1 スレッド 8 セル)が大きい形で刻むので T-0272 の重さのまま(未計測。計測の場面も無い)。
  軽くするなら追記 4 の (2)(作業場)か 1 ブロックを複数グループで(T-0327 で上限を上げる時に一緒に測る)。
