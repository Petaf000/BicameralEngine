## 目的(1〜2 行)
物の姿勢(PxBody の position・rotation)と物の箱の形から、格子のボクセルごとに 4³ 点の整数の数えで「骨格の外の点の数 θ_v・+ 側 3 面の 4×4 点の開き θ_f・上位 4 物・対の面(物のボクセル, 格子のボクセル, 点の数)」を作る関数を shaders/common の 1 つの源に置く。

## 完了条件(チェックできる形で)
- [ ] 向きの揃った物(回り 0・位置が格子に揃う)で点の数が 0 か 64 だけ
- [ ] 斜めの物で Σ 点 = 物のボクセルの数 × 64(細かい側で数える。違うレベルの物も)
- [ ] 物の順を入れ替えても結果がビット一致・5 物以上の重なりは溢れの計器
- [ ] 浮動小数点なし(float_check)・release 警告 0・archmap --check
