## 目的(1〜2 行)
T-0102 の頁を持つブロックが、静かになって一様(覆われていないセルが全部同じ・覆われたセルは空・端数なし)なら、値 1 つに戻して頁を返す。
頁を返す順は枠の順(決定的)。2026-10-05 ユーザー決定で T-0102 から分けた。

## 完了条件(チェックできる形で)
- [ ] 一様かどうかを決定的に調べる(セルが変わった時・木の変更の時など、調べる時を決めて設計に書く)
- [ ] 静かで一様な頁を枠の順に返す。CPU と GPU(HW・WARP)が毎刻み一致・保存量一致
- [ ] 燃え尽きた後に頁の数が最初に戻る場面
