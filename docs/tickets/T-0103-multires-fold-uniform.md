# T-0103 静かで一様になった頁を畳む

- Status: Done
- 種類: 工学
- PC: 必須
- 見積もり: チャット 1 回分
- マイルストーン: M2(docs/plan/ROADMAP.md)

## 目的(1〜2 行)
T-0102 の頁を持つブロックが、静かになって一様(覆われていないセルが全部同じ・覆われたセルは空・端数なし)なら、値 1 つに戻して頁を返す。
頁を返す順は枠の順(決定的)。2026-10-05 ユーザー決定で T-0102 から分けた。

## 完了条件(チェックできる形で)
- [x] 一様かどうかを決定的に調べる(ちょうど静かになった刻みに 1 回。頁に広げたのも忙しいとする。17 §5「頁を畳む」)
- [x] 静かで一様な頁を枠の順に返す。CPU と GPU(HW・WARP)が毎刻み一致・保存量一致
- [x] 燃え尽きた後に頁の数が最初に戻る場面(900 K の木箱 2 つ。刻み 20 に両方畳まれて頁 0)

## 作業ログ(チャットごとに 3〜5 行、新しいものを下に)
- 2026-10-05: ちょうど静かになった刻み(MrWantsFoldCheck)に頁のブロックが一様か調べ、一様なら値 1 つに戻して頁を枠の順に返す(CPU FoldQuietPages、
  GPU TreeFoldCheck → TreeFold。結果は取り合いの印を借りて置く)。頁に広げたのも忙しいとした。数える欄 22 MR_COUNTER_FOLDED。
  600 K の木箱は O2 が 1 単位残るセルが分かれて一様に戻らない(BACKLOG)ので、場面の木箱を 900 K にした(数刻みで燃え尽きて全部同じになる)。
  頁が 1 つの場面は「1 つ目が畳まれて頁が返った刻みに 2 つ目が広がって燃える」に変わった。子に覆われた頁を畳む場面も足した。CPU と GPU(HW・WARP)が毎刻み一致。
