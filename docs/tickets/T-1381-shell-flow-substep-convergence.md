## 目的(1〜2 行)
紙の燃え広がりが流れの小刻みの数 N(細かさの選び)で大きく変わる(N = 4 → 8 で +18〜35 %・16 で火が消える / 3 倍。T-1380)根を突き止め、N によらない形を決める。

## 完了条件(チェックできる形で)
- [ ] 根の切り分け: 1 刻みの膨らみのどれ(物の熱の小刻みの熱の受け渡し / 反応の熱 / 流れが運んだ熱い気体)が刻みの初めにまとめて出て、射影が 1 小刻みで出し切っているか(小刻みごとの膨らみの和と一番速い面を N = 4 / 8 / 16 で)
- [ ] 案の比べ(下)と、N = 4 / 8 / 16 で燃え広がりの差が 2 % 以内(または揺れの幅)になる案。案ごとの作り手から見た違い・費用・おすすめ
- [ ] 層の流れの式(object_heat.hlsli・D-663 の運動量の式)の共通部分に当たるので、直す形は司令塔・設計役が決める(作業役は CPU の調べの口・既定 0 で比べるだけ)

## 研究の打ち切り条件(先に書く)
- 物差し: T-1380 の口(`object_shell_test --case ... <上限> <持ち越し> <小刻み 2^k> <① の止め>`)で、紙・閉じた 1 セル と 世界の流れの燃え広がりを N = 4 / 8 / 16 で。
- 案(順に): C' 膨らみを刻みの中で分ける(N 小刻みの k 番目は残りの膨らみの 1 / (N − k) を出す = 刻みの終わりで出し切る。膨らむ速さ = 膨らみ ÷ 1 刻み)/
  D 熱と反応の源を流れの小刻みごとに出す(物理に近い・熱の段の費用 × N)/ E 両方。
- 打ち切り: C'・D のどれでも N = 4 / 8 / 16 の差が 2 % を切らない → 根は膨らみの出し方ではない(例: ① の運動量を運ぶ式・出る上限〔1 小刻みに半分〕の N への依り)→ それを次に。2 時間で分かった所までと次の一手を書いて返す。

## メモ・参考
- T-1380 の数: 既定 N = 4 で 9.28 / 8.27 mm/s(閉じた 1 セル / 世界の流れ)・N = 8 で 10.94 / 10.81(止めの速さを m/s で揃えて 11.06 / 11.14)・N = 16 で 0.00(火が消えた)/ 揃えて 28.78。
  射影の答えの一番速い面が N にほぼ比例(3.4 → 4.6〜8.0 → 15.4 m/s)。反応を 1 小刻みに 1 回に分けても N = 4 → 8 で 6.34 → 7.55 / 5.29 → 6.77。
- 今の N は「1 小刻みに 1 ボクセル = 1.875 m/s」になるよう箱の細かさで決めている(箱 7.8 mm で 4・3.9 mm で 8)。T-1143・T-1186 の細かさ・層の数の比べは、この N への依りを含む。
