# T-0017 原理: 多重解像度(1 点を入れ子に細かくして戻す・見るだけなら変わらない)

- Status: Done
- 種類: 研究(原理の確認。R-MULTI の基準 1〜2)。量の換算と端数の持ち方が確かめどころ、木と GPU の起動は工学
- PC: 必須
- 見積もり: チャット 1〜2 回分
- マイルストーン: M1 (docs/plan/ROADMAP.md)
- 設計: docs/design/17-multiresolution.md §1・§3・§5・§6 / 04 §2 / 決定: D-401〜D-403・D-206・ADR-0012・ADR-0015

## 目的
同じセルの形(RxCell)のまま、1 点の周りを 0.5m から 1mm(k = 0〜9)まで入れ子に細かくして反応を進め、粗く戻しても
保存量(元素の数・エネルギー)がビット単位で一致することを、CPU と GPU(ビット一致)で確かめる。観察のための影の細分があっても世界が変わらないことも。

## 形(このチケットで決めた。ADR-0015)
- **木**: 比 2 のブロック。ブロックはどのレベルも 8³ セル。子ブロック(k+1)は親ブロックの 1/8(4³ セル = 八分の一の範囲)を覆う。
  親のセル 1 つ = 子のセル 2³。覆われた親のセルは空(中身は子にある)。
- **単位**: レベル k の物質量の単位 = 8^-k µmol、エネルギー = 8^-k mJ(体積と同じ比)。同じ濃度・温度なら、どのレベルのセルも同じ数になる
  (反応の核 RxStepCell はレベルを知らずにそのまま使える。温度・比熱の式も変わらない)。
- **細かくする**: 子のセルは親と同じ数(量・エネルギー・端数)。余りは出ない。
- **粗くする**: 子 8 つの (整数部 · 2^64 + 端数) の合計を 3bit 右へ。整数部が親の量、下の 64bit が親の端数。
  端数の下から落ちる 3bit は、21 段より深くから続けて粗くした時だけ 0 でなくなる(落ちた分は統計に数える。帳簿は T-0018)。
- **端数**: 64bit、反応は使わない(整数部だけで計算。端数はレベル 0 で 1 µmol 未満の動かない量)。**疎に持つ**: 端数が 0 でないブロックだけ
  端数のブロック(セルごとに エネルギー + 物質 ID と端数 × 8)を持つ。細かく/粗くする時しか変わらないので 1 世代。
- **乱数の鍵(セルの ID)**: (レベル, 世界の座標) のハッシュ。どのレベルでも重ならない。
- **影(観察)**: 影のブロックは親を覆わない(親は観察していない時と同じ計算をする)。毎刻み、反応の後に上から順に、
  影の子 2³ の合計を親 × 8 に引き戻す(物質は比で配り、余りは子の番号順に 1 ずつ。エネルギーは差を等分)。世界のハッシュは本物の葉のセルだけ。
- 起動: 細かくする・粗くする・引き戻すは Work Graph の再帰のノード(1 レベル = 1 グループ、次のレベルを自分に投げる)。反応の刻みは Compute(1 スレッド = 1 セル)。
  この段階ではブロックの置き場所は固定(本物の鎖・影の鎖の枠)。疎な木・ブロックプール・割り当ては T-0018。

## 研究の打ち切り条件
打ち切りではなく、うまくいかない時に試す順(D-411・17 §6):
1. 影の引き戻しで熱が負になる → エネルギーも比で配る / 影の中を「親の値 + ゆらぎ」にする
2. 粗くした時の成分の和集合がインラインの 8 を超える → 溢れの数を数えて記録し、R-MULTI-4(成分の連鎖)へ
3. WARP の Work Graph の JIT が落ちる → ADR-0013 のとおり記録し、Compute で同じ手順を確かめる

## メモ・参考
- 段をまたぐ輸送(熱の伝導)は入れない(T-0019)。この段階のセルは隣と独立で、反応だけで中身が変わる(確率的な丸めの乱数がセルごとに違うので、子が親からずれていく)。
