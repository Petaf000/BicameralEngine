## 目的
RC の試験(tests/cascade_light_test.cpp の MeasureRing)の割り方(立方体の中心の距離)には、軸の向きの受け手で +6.83 % の床がある(T-1062)。
受け手ごとの正しい値(焚き火の面から受け手の面への遮る物の無い G の細かい積分)からのずれも出し、RC の瞬間と 60・250・500 刻みの平均を測り直す(Q147 の材料を公平にする)。

## 完了条件
- [x] MeasureRing に正しい値からのずれ(最大・二乗平均)を足す(焚き火の 6 面 × 受け手の 6 面の 8 × 8 点の積分。FaceExchange)
- [x] RC の形を測り直してチケットに記録(23 §10 へ写すのは本体)

## 結果(release・Windows のランナー・cascade_light 通過 551 秒。2026-10-24 20:02〜20:11。ほかの作業ツリーとの重なりは見ていない。CPU の ms は目安)
| 形 | 前の割り方: 瞬間 / 60 / 250 / 500 刻み | 正しい値から: 瞬間 / 60 / 250 / 500 刻み |
|---|---|---|
| 今の形 n0 = 4・5 段 | 122.0 / 15.0 / 10.8 / 9.2 % | **121.8 / 19.8 / 10.2 / 11.4 %** |
| 放つ面の組 7(熱も・504 刻み) | 18.1(瞬間の平均)/ 65.1 / 24.4 / 15.1 % | 18.0 / 67.8 / 26.5 / 14.6 % |
| 袋 8 本(30 刻み) | 107.1 / — | 106.0 / 30 刻みの平均 25.6 % |
| n0 = 8(30 刻み) | 101.7 / — | 100.4 / 30 刻みの平均 17.3 % |
| 段なし n0 = 128(4 刻み) | 32.7 / — | 28.1 / 4 刻みの平均 12.4 % |
| (比べ)対のつながり(T-1062・乱数なし) | 6.83 %(どの刻みも) | **0.29 %(どの刻みも)** |
- 読み: 前の割り方の床(+6.83 %)は RC の数を良く見せていなかった(500 刻みで 9.2 → 11.4 %)。**RC は数秒の平均でも ±10 % にぎりぎり入らない**(250 刻みで 10.2 %)。
- 二乗平均が -nan になる行がある(組 7: 受け手が 0 の刻みで割る。前からの出し方の傷。合否には使っていない)。
