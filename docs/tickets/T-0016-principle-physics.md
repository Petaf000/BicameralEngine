- Status: Done(2026-10-01。岩の山の未達の 2 基準は T-0091 へ。ADR-0014 は Proposed のまま、T-0090 で GPU の費用を測ってから判断)

- PC: 必須
- マイルストーン: M1 (docs/plan/ROADMAP.md)
- 設計: docs/design/08-bodies-physics.md §6 / 04 §2(単位)・§6(整数の演算の費用)/ ADR-0002

## 目的(1〜2 行)
整数(64bit の固定小数点)の AVBD で、角ばった箱が積み重なり、崩れても発散・貫通・振動しないことを CPU で確かめる(R-PHYS-1)。
GPU 化(Work Graphs / Compute・CPU とのビット一致・Nsight)は T-0090 に分けた(2026-10-01 ユーザー決定)。

## 範囲(2026-10-01 ユーザー決定)
- CPU だけ。整数版はシェーダーと共有できる形(fixed.hlsli の約束: shaders/common/physics_*.hlsli)で書き、T-0090 でそのまま GPU に載せる。
- 箱 = 直方体の解析的な接触(分離軸 + 面のクリップで多点接触)。ボクセル / SDF の接触は R-PHYS 本番(T-0043)。
- 確認は数値の基準(テストで判定)+ 軌跡の書き出しを Linux 側で画像にする。窓の描画は作らない。

## 進め方
1. **浮動小数点の試作**(tools/physics_lab、double。ツールなので浮動小数点可): AVBD(剛体・接触 + 摩擦・彩色した Gauss-Seidel)と直方体の接触。
   アルゴリズムとパラメータ(反復回数・α・β・γ・硬さの範囲)を、値の幅を気にせずにここで決める。
2. **整数版**(shaders/common/physics_*.hlsli + engine/src/sim/physics。浮動小数点禁止): 04 §2 に単位の行を足してから。
   6×6 の連立方程式は「2 の冪の対称スケーリング(対角を [1/4, 1) に)+ Cholesky(Q62)」で解く案から(SPD で対角 < 1 なら L の要素は |L| ≤ 1 に収まる)。
3. 同じ場面を整数版で通し、試作との差・値の幅(各量の最大ビット数)を記録する。
4. 結論を ADR に(R-PHYS-1 で確定 / R-PHYS-2 へ)。08 §6 を更新。

## 場面と基準(h = 1/60 s。数値は試作で見直してよい。変えたらここに書く)
- **A 積み木**: 1 m の立方体 10 段(各 500 kg)を地面に積み、60 s(3600 刻み)。
  最上段の水平のずれ < 1 cm・傾き < 0.5°・最大の食い込み < 5 mm・1 s 以降の全部の箱の速さ < 1 cm/s。
- **質量比**: 地面に 1 kg の箱、その上に 100 kg の箱(1:100)、10 s。食い込み < 5 mm・崩れない・1 s 以降の速さ < 1 cm/s。
- **C 小(岩の山の小さい版)**: 大きさ 0.25〜1 m・質量比 1:100 を含む箱 50 個を落として山にし、5 s 後に支えの箱を 1 つ消して崩す。30 s。
  全期間で速さ < 20 m/s・食い込み < 2 cm・力学的エネルギーが初めより増えない(数値の許容は試作で決める)・最後の 5 s で全部の速さ < 1 cm/s。
- 共通: 整数版を 2 回走らせて刻みごとのハッシュが一致。

## 研究の打ち切り条件(D-411: 時間の打ち切りは置かない。次の方法へ移る条件)
- R-PHYS-1 → R-PHYS-2: 試作が満たす場面を整数版が満たせず、原因が値の幅か精度と分かり、
  (a) 2 の冪のスケーリング (b) 単位の取り直し (c) 128bit の中間値 のどれでも直らないとき。どの量で溢れた/足りなかったかを記録する。
- 試作(double)でも満たせない場面は、整数の問題ではないので R-PHYS-1 の判定から外し、アルゴリズムの問題として扱う(ユーザーと相談)。

## メモ・参考
- AVBD: Giles, Diaz, Yuksel "Augmented Vertex Block Descent"(SIGGRAPH 2025)。論文の性能・安定性の数値は未確認(条件を確かめてから使う)。
- 1 刻みの中は「刻みの初めで線形化した接触」(接触点・法線・ヤコビアンは刻みの初めに 1 回。C = C0·(1−α) + J·Δx)で解く案。
  回転は刻みの初めからの回転ベクトルの和で持ち、刻みの終わりに四元数へ積む。
