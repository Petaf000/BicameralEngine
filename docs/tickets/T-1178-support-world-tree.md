## 目的(1〜2 行)
割れかけの所を細かくする道(T-1067。今は支えの場面の印 SupportScene::fine 2 × 2)を、世界の多重解像度の木の細かくする要求として出し、支えは木の上で解く。
2 段以上の下りは木の 2:1 がそのまま作る。割れかけの所の細かさが熱・粒と揃う。

## 完了条件(wt2 T-1134「世界の木へ寄せる時の形」の 1〜5)
- [ ] 細かくする要求 = 状態で細かくするの種(面の強さの比 ≥ refineIndex の面の両側のセル + 周り refineRing。レベルは ℓ_min / 2)
- [ ] 戻してよいかを家族ごとに断る印(比 ≥ coarsenIndex から coarsenRing の中は戻さない・coarsenTicks・中の面が割れていない・外の面の 2 つの子の進みが同じ)。熱・粒の粗くする判定と同じ所に
- [ ] 支えの節 = 木の節(EquilibriumNode のレベル = 木のレベル)。違うレベルの梁は ADR-0470 ②(2:1)
- [ ] 子の中身: 変位・回りは剛体の延ばし方(CarriedValue)・割れの進みは親の面の値を子の面 2 つへ・残りの硬さは面ごと(疎)。支えの物は据わる固体なので置かれ方では SAME(T-1159 で確かめた)
- [ ] Window の数え方は長さと面積のまま(ADR-0470)
- [ ] A〜D・厚い梁の場面で今の下りる道と ±2 %(T-1134 の表)
