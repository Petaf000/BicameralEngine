# T-0377 物質を足す・消す反応表の差し替えで、転換のパッチの物質 ID を付け替える(T-0359 から分けた)

## 目的(1〜2 行)
物質の ID は名前のバイト順なので、物質を足す・消す表の差し替えで ID がずれる。魔法の転換(T-0359)の「替える先の物質 ID」を
新しい表の ID へ名前で付け替え、替える先が消えた転換は黙って捨てずに効かなくする(数える)。**値はすべて試験用の仮のもの(D-006)。**

      替える先が消えた(と、今の表の範囲の外の)転換は替える先 0 = 効かない(MpConvertedCoefficient が 0・MpEffectValid が断る)

## メモ・参考
- 試験の表: `MakeConversionRemapBeforeTestTable`(転換の試験の表 + CO2 と同じ元素の仮の物質 carbon_dioxide_late_test)→
  `MakeConversionRemapAfterTestTable`(転換の試験の表 + 名前の順で一番前の仮の物質 a_marker_test。late は無い)。
  異性体の ID が 1 つ後ろへずれ、前の表の異性体の ID は後の表では CO2 を指す(付け替えないと「CO2 → CO2」になり異性体ができなくなる)。
- 仮の世界の GPU は、効かなくなった数をハッシュの表に出していない(付け替えの段は刻みの適用の単位〔BeginTick が欄を 0 にする〕の前)。
  効かなくなったことは列そのもの(替える先 0)に残り、状態の要約(MpListHash)で CPU と突き合わせる。数は CPU リファレンスの報告。

## テストの結果
- 2026-10-12(debug・main c6bca01 の上): CPU 5 本(reaction_hot_reload・reaction_replay_table・reaction_species_remap・multires・lab_box)通過。
  gpu_probe_patch 通過(付け替えの場面: 異性体 978846 → 978852 µmol・消える物質 978846 µmol・効かなくなった転換 1・2 つの分け方で S(32) 一致)。
  gpu_lab_box は付け替え・列・数・毎刻みの一致は通り、「後も効き続ける」だけ落ちた(上の作業ログ)。置き直す形にして流し直すと、
  魔素ありの 450 K の木は 1 刻みで燃え尽き、置き直した刻みに異性体 7863954 µmol(置く操作は中身を置き換えるので、これが付け替えた転換の
  効き目)・その後は増えない、で同じ確かめが落ちた。確かめを「置き直した刻みの異性体 > 0」に直した(ビルドは通る。**GPU では未確認**)。
  別件: gpu_lab_box の「2 段細かくした箱」の辺り(224〜340 秒)で debug layer の D3D12 [527](ResourceBarrier の前の状態が
  UNORDERED_ACCESS でなく COPY_SOURCE)が 240 件出る(どちらの実行でも同じ数。付け替えの段は通らない所なので T-0377 の変更ではない
  見込み・main で出るかは未確認)。このままだと最後の PassesValidation で gpu_lab_box が落ちる。

## 引き継ぎメモ
- 替える先 0 の転換は列に残る(期間の終わりまで)。エディタのパッチの一覧(T-0325)で「替える先が消えた」と出すなら、効き方の語の
  物質 ID 0 を見ればよい。
- 仮の世界の GPU は「効かなくなった数」をハッシュの表に出していない(メモ・参考)。窓に出すなら、ハッシュの表の空き(語 15)に
  適用の単位(BeginTick の後)で書く形を後のチケットで(GPU の列は CPU から見えないので、CPU の側では数えられない)。
- 仮の世界の試験の「後も効き続ける」は差し替えの後の燃え残りが少なく、異性体の増えが 6 µmol と小さい(通るが余裕が無い)。
  表や火の形を変えて落ちたら、実験室と同じく差し替えの後に置き直す形にする。
