## 次の手(T-0972 へ)
1. 段の受け渡しを「袋 1 本」から「袋の中の光線を R 本(場所と向きを溜めから選ぶ)」にする(R を 4〜8)。費用は段 1 以上が R 倍。
2. 近くの区間だけ対の形で交換する(23 §3.3 の「超えるなら近くの区間だけ対の形」。ADR-0252 の対称な式)。坂を構造で 0 にする道。
3. 2 本で通らなければ退く道(決めた数の向きで掃く。ADR-0262)。段 0 の作り(面の上で散らす・ずらした向きの cos)は退く道でもそのまま使える(1 段 = 段なしで坂 4 %)。

- 読み: 熱いセルを 256 倍にしても光線は 1.5 倍。光線の数は「照り返す地面の面」で決まる(地面の石が返した光が次の刻みに全部の面から放つ)。
  **照り返しがあると、焚き火 1 つでも地面全体が光源になる**ので、費用は熱いセルの数ではなく照り返す面の数で決まる(GPU 版 T-0959 で 1 ms に入るかが要所)。

## 照り返しの持ち越し(刻みをまたぐ状態。一旦の決定〔司令塔〕: セーブとハッシュに入れる)
- 形: 0 でない (セル・面・帯) だけを、セル・面・帯の順に持つ(CascadeCarry)。ハッシュは HashCascadeCarry。
- セーブの形の案(CascadeCarrySaveBytes): セルごとに 番号 4 B + (面 × 帯)の 12bit の印 2 B + 0 でない値ごとに 4 B(1 刻みに 1 面へ返る量は 2^32 未満と見込む。未確認: 大火事の近く)。
- 測った値(試験の出力。48³ = 110,592 セル): 焚き火 1 つ: 持つセル 408(0.37 %)・値 878・**5,960 B(持つセルあたり 14.6 B・世界のセルあたり 0.054 B)**。
  熱い床 16 × 16: 持つセル 911(0.82 %)・値 2,194・**14,242 B(持つセルあたり 15.6 B・世界のセルあたり 0.129 B)**。
  熱い床 48 × 48(地面全部が熱い・照らされる石の面が無い): 0 B。照り返す物が無い所(空気・黒い物)は 0 B。
  密に持つと 1 セル 6 面 × 2 帯 × 8 B = 96 B なので、疎に持つ形で 1/700〜1/1800。
- 【エンジン】持ち越しをセーブに入れない案もある: 作り手から見て、読み込んだ直後の 1 刻みだけ照り返しの光が消える(1/60 秒。見えない)。
  入れる案(今の仮)は、読み込んでもハッシュが続けて一致する(D-608 と同じ考え)。重くなったら切れるように、欄は「導かれる値」ではなく別の小さな欄にする(T-0974)。

## 土台へ(作らない。要る口)
- **吸った光をセルのエネルギーへ足す段・熱で放った分をセルから引く段**: 出力は CascadeTickResult::absorbed・emitted(セルごと・帯ごと。2^−16 mJ)。
  セルのエネルギー(mJ)へ当てる時の端数(2^−16 mJ)の持ち越しも要る(1 刻みに 1 mJ 未満の受け手が多い)。
- **帳簿の理由の行**: 「放射で世界の外へ出た」(ledger.escaped)。放った・吸ったは世界の中の受け渡しなので帳簿の外。持ち越し(reflected → 次の carriedIn)は刻みをまたぐ量として帳簿の釣り合いに入る。
- **刻みの順(S42 の 7)**: 太陽の影の柱 → 距離ごとの段 → 吸った分をエネルギーへ。距離ごとの段は刻みの初めの温度(CascadeGrid の写し)を読む。
- **照り返しの持ち越しの欄**(T-0974): セルの欄として疎に持つ所(field の頁か、別の疎な表か)。セーブ・ハッシュ・多重解像度の粗くする/細かくする時の扱い(面の量を足す・分ける)。
- **多重解像度の木を読む道具**(T-0973): 今の MakeCascadeGrid はレベル 0 の根だけ。細かい葉・粗い根は sun_column の SunBlockView と同じ形で葉を引く。
