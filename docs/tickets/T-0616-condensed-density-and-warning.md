## 目的(1〜2 行)
標準パッケージ real_matter の凝縮相(炭〔黒鉛〕・セルロース・液体の水・氷)の全部に現実の密度を書き、セルの場所を取らせる。
凝縮相に密度を書き忘れたら、ベイクが警告を出す(T-0593 の判断待ち 1 のおすすめ。表は当たる)。

## 完了条件(チェックできる形で)

- [x] ベイクの警告「物質 X: 凝縮相に密度(density_kg_per_m3)が無い…」(sim/reaction_table.cpp の BakeAllSpecies。液体は今まで通り誤り)
- [ ] reaction_package_test: 標準パッケージの読み込みで OtherWarningCount == 0 のまま・書き忘れた固体で警告が 1 つ出る
- [ ] 数の動いた試験と理由(下の表)・燃える木箱の「同じく動く」幅(T-0491・Q63)を外れたかの記録
- [ ] release のビルド(警告 0)・CPU の試験・GPU の要る分・archmap --check

## 範囲の判断: 孔の通しやすさ(透水の係数)は入れない → T-0652 に分けた
- 理由: 密度と警告は「値を書く・知らせる」だけで、場面の数を少し動かす工学。透水は流れの式(気体の面の流れ・液体の面の力)を変える設計で、
  作り手が書く欄(物質ごとの透水の係数 / 空きの 3 乗の式)をユーザーに聞く要がある(Q94 ③)。混ぜると数の動いた理由が分けられない。

| 物質 | 密度 kg/m³ | 出典(どれも資料と一つずつは照合していない = 未確認) | 試験の世界で占める割合 |
|---|---|---|---|
| 炭(黒鉛) | 2260 | 理想的な黒鉛の結晶の X 線密度 2.266 g/cm³(CRC Handbook の黒鉛 2.2〜2.27) | 炭の材料 312 mol = 3.7 kg → 0.5 m のセル(125 L)の 1.3 % |
| セルロース | 1500 | 木の細胞壁の実質(木材の真密度 1.49〜1.54。結晶 Iβ 1.63・非晶 1.48 の間) | 木箱のセル 38.6 mol = 6.26 kg → 3.3 % |
| 液体の水・氷 | 1000・917 | T-0611(real_matter の頭) | — |
| 砂(場面 grass_fire_river の silica) | 2648 | α 石英 2.648 g/cm³ | 土のセル 3121 mol → 56.6 %(残りが孔) |

- 作り手から見た違い: 木と炭は孔の多い物(物質量が少ない)なので、木箱のセルの気体の空きは 96.7 %(圧力が 3.4 % 高く読まれ、少し押し出される)。
  岩・土のように物質量の多い固体は気体も水も止める。密度を書かない固体は今まで通り素通しで、読み込みのたびに警告が出る。

## 数の動いた試験と理由(E だけ。2026-10-17・release)
- CPU の試験(72 本 + gas_* 3 本): **数の期待値が動いて落ちた試験は無い**。セルの空きを読むのは気体の段(probe_gas)と液体の段(probe_liquid)だけで、
  木箱(セルロース 3.3 %)・炭(1.3 %)は孔が多く、probe_gas の燃える木箱の期待値(幅のある検査)の中に収まった。反応・伝導・GPU の表・状態のハッシュは
  密度を読まない(モル体積は GPU の表に入らない)ので、気体と液体の段の無い試験と GPU の試験は変わらない。
- **gpu_probe_gas**(GPU の気体と CPU の毎刻みビット一致): GPU の段は空きを読まない(T-0617)ので、試験の表だけ固体の密度を外した
  (tests/gpu_probe_gas_test.cpp の MakeTable。T-0617 でやめる)。外さないと燃える木箱のセルで CPU だけが空き 96.7 % を読んで食い違う。
  **作り手から見て: T-0617 までは、実行中の世界(GPU)の気体は木箱・炭・岩・水の場所を数えない**(CPU の区画とは違う。密度を書いた液体の水・氷も同じで、T-0611 からある食い違い)。
- **probe_phase**(main の時点で落ちていた。T-0611 × T-0593b のマージの組み合わせ): 試験の石(stone)に密度が無く場所を取らないので、
  氷の場面で溶けた水が 500 K の台の石の中へ流れ、20 秒で全部が湯気になり、エネルギーの保存も崩れた(+24 GJ。保存の崩れは別の不具合の疑い → 下)。
  石に密度 2650(セルを満たす)を書いた。
- image_probe_volume・image_probe_slice: main の 2026-10-16 18:45 の試験と同じ画素数で落ちていた(このチケットと関係なし。main は 19:43 に通っている)。
- 燃える木箱の「同じく動く」幅(T-0491・Q63): 木箱の測り(slope_check の --burn)は気体の段を持たないので、E では動かない(F の方で測る)。
