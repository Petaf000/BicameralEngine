## 目的(1〜2 行)
中身(反応表・魔素の値)を触って決めるために、実験室の箱に表の全物質から材料を組んで、量・温度・圧力を指定して置けるようにする。
大きい箱・細かい箱は T-0173。

## 完了条件(チェックできる形で)
- [x] 材料は表の全物質から 3 つまで(1 つのコマンドの上限 LAB_MAX_FILL_SPECIES)。ひな形(空気・木・木炭・二酸化炭素・窒素)を読み込んで直せる
- [x] 量の単位: mol・g(表の分子量)・kPa(1 セル 0.125 m³ を理想気体で満たした分圧。置く温度で換算)。換算は整数(sim::LabGasMicromoles・LabMassMicromoles)
- [x] 温度は数で入れる(1〜6000 K)。置く範囲は 1 セル・直方体・箱全体(範囲のコマンド LAB_COMMAND_TYPE_FILL_REGION・TEMPERATURE_REGION。
      GPU〔lab_box.hlsl〕と CPU〔ApplyLabCommands〕が同じ順で 1 セルずつ当てる)
- [x] lab_box: 範囲 = 1 セルのコマンドを並べたのと同じハッシュ・箱の外・逆の範囲・熱すぎるは当てない・換算(1 気圧 300 K の 1 セルが空気の材料と 0.1% 以内)
- [x] gpu_lab_box(HW・WARP): 箱全体を酸素の多い 200 kPa の空気にする範囲のコマンドと直方体の温度を入れても毎刻みビット一致
- [x] window_lab: `--auto-lab` が箱全体を 200 kPa の空気にしてから木を燃やし、隅のセルの窒素が置いた量のまま・記録から別の箱で再生しても同じ

## メモ・参考
- 箱は圧力を状態に持たない(気体の流れ〔07〕は箱に無い)。「圧力」は置く時の量の決め方(分圧 → µmol)。固体・液体の体積は引かない
  (表に相が無い。相ごとの値は M2 の後)。kPa を固体に使うと「その物質を気体として 0.125 m³ に詰めた量」になる。
- 1 つのコマンドに入る物質は 3 つまで(64 バイトのコマンド)。4 つ以上の混ぜ物は同じセルに 2 回置けない(FILL は置き換え)ので、
  要るなら「足す」コマンドを足す(BACKLOG 2026-10-10 に書いた。今は作らない)。
