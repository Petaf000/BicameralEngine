## 目的(1〜2 行)
活性(T-0100)の上で、しばらく変わっていない本物の葉のブロックを自動で親へ戻す(05 §4「静かなブロックは粗いレベルにまとめてよい」)。
要求は GPU が作り、順は枠の番号の順(決定的)。T-0018 の要求の処理にそのまま渡す。

## 完了条件(チェックできる形で)
- [x] 忙しさの印: 見出しに busyTick(最後に変わった刻みの印: 刻んでセルが変わった・木の変更でつつかれた)。CPU と GPU が同じ所で書く
      (はじめは「種だった・進める規則があった」にしたが、セルが変わらないのに種であり続けるブロックが粗くならなかったので変えた)
- [x] 静かな葉 = 世界の本物のブロックで、根でない・本物の子が無い・MR_QUIET_TICKS(N。定数)刻みを超えて忙しくない。
      同じ親の兄弟で静かなものは八分の一の番号の小さい 1 つだけ(1 刻みに 1 つの親は 1 つの要求しか通らないので枠を無駄にしない)
- [x] GPU の 1 グループの Compute(TreeQuiet)が、外から渡された要求の後ろに枠の順で足す(一覧が一杯なら後回しにして数える)
- [x] 状態の全部と次の刻みの種が CPU と GPU(HW・WARP)で毎刻み一致・2 回の実行で一致
- [x] 毎刻み「世界 + 帳簿」が最初とビット一致。忙しかったブロック(N 刻み以内に種か反応)を粗くしない。火が消えたら木が根まで畳まれる
- [x] T-0017 / T-0018 / T-0096 / T-0100 の場面がそのまま通る
- [x] build(debug / release)・tidy 警告なし・archmap OK・要求を作る段の GPU 時間を perf.md に

## メモ・参考
- N は定数(2026-10-04 ユーザー決定。後から測って調整)。
- 観察の影の親になっている本物のブロックを粗くすると影の親が消える(見出しは影を知らない)。今は影の親は根か写しだけ。観察の枠の管理(呼ぶ側)が親を付け替える約束にする(BACKLOG)。
- 場面・確かめ方・結果は 17 §5「静かなブロックを粗くする」と §6「結果(T-0101)」。

## 作業ログ(チャットごとに 3〜5 行、新しいものを下に)
- 2026-10-04: 見出しに busyTick を足し(88 B)、静かな葉(MrIsQuietLeaf・兄弟は小さい八分の一だけ MrWantsQuietCoarsen)の粗くする要求を、
  CPU は SubmitQuietCoarsenRequests、GPU は multires_tree.hlsl の TreeQuiet(1 グループ 512 スレッドの累積和で枠の順)で作る。
  忙しさを「種」で決めると、セルが変わらないのに毎刻み種になる燃え尽きかけの木箱が 4000 刻みでも粗くならなかったので、「セルが変わった・つつかれた」に変えた(BACKLOG に反応の核の件)。
  確認: multires_quiet(粗くしたのは N 刻み変わっていないものだけ・保存量・刻み 218 に根だけ・一杯で回す・兄弟に譲る・取り合い 0)・gpu_multires_quiet(HW・WARP 毎刻み一致・まとめて投げても一致)。
  TreeQuiet 0.0056 ms(枠 640、release)。
