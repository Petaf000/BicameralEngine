## 書き方の案(作り手が釣り合いを何で書くか)
| 案 | 作り手が書くもの | 作り手から見た違い |
|---|---|---|
| **1(仮・おすすめ)釣り合いの点 + 急さ** | `balance = { temperature_mk = 373124, concentration_mol_per_m3 = "32.66", enthalpy_j_per_mol = 40650 }`。その温度で、気体の濃さの比(Q)が `concentration^Δn` で釣り合い、温度で `enthalpy` の急さ(van 't Hoff・Clausius–Clapeyron)で動く | 融点・沸点を「温度」でそのまま書ける(水: 273.15 K・沸点 373.12 K で 1 気圧ぶんの濃さ)。曲線は 1 本の式なので点と急さの 2〜3 個で済む。現実の値は文献の融点・沸点・潜熱を写すだけ |
| 2 K(T) の表 | 温度ごとの釣り合いの点を何点か書き、間を補間 | 曲線の形を自由に書ける(現実の飽和水蒸気圧に細かく合う)。書く値が多い。表と補間の作りが要る |
| 3 釣り合いの濃さだけ(温度によらない) | `concentration` だけ | いちばん簡単。融点・沸点が書けない(温度で向きが変わらない)ので相変化に使えない |

- **どの物質の濃さが釣り合いに入るか**: 物質の相で決める(気体 = 濃さ〔mol/m³。セルの体積あたり〕・凝縮相〔固体・液体〕= 活量 1)。作り手は次数を書かない
  (釣り合いの規則に `orders` は書けない)。溶けた物質の濃さ(溶媒の量あたり)はまだ無い → 塩が溶ける釣り合いは T-0655(名前だけ)。
- **速さ**: `rate`(A・Ea)は「釣り合いへ近づく速さ」(1/s)。1 刻みの進み = 釣り合いまでの距離 × min(1, k(T)/60)。距離 0 なら進まない = 眠れる。
  代案(作り手から見た違い): 釣り合いから遠い所は今の質量作用の速さ(反応物の量に比例)で、釣り合いを越えないように止める形。遠い所の速さが量で変わるが、
  向きごとに速さを書く(書く値が 2 倍)・逆向きの速さの単位が次数で変わる。
- **1 本で両向き**: ベイクが逆向きの規則(名前 `<名前>~逆`)を作り、表に並べる。逆向きの規則は自分の反応物(元の生成物)の索引に入る。
  どちらも「自分の向きに釣り合いへ向かう時だけ」進むので、1 つのセルで同時に進むのは片方だけ。種なしで凍る・霧はこれで出る
  (水だけのセルで凝固の側が、湯気だけのセルで凝縮の側が引かれる)。パネル・坂の欄には逆向きの規則も 1 行として出る。
- **距離の求め方**: g(ξ) = log2 Q(ξ) − log2 K(T(ξ))(ξ だけ進めた後の成分と温度。温度は潜熱と比熱の変化を入れる)が負の間は進める。
  ξ の整数の二分法で g < 0 の最大の ξ を求める(凝縮相だけの規則は Q = 1 なので、温度がちょうど釣り合いの温度になる所 = 融点が mK でちょうど)。

## 判断待ち(仮で進めた。ユーザー未確認)
1. 書き方は案 1(上)。
2. 釣り合いに入る濃さを物質の相で決める(気体だけ。セルの体積あたり)。
3. 速さは「釣り合いまでの距離 × 割合」。
4. 逆向きの規則を表に 1 行として出す(`~逆`)。
5. 近づく速さ a = 1 /s(水の 2 本。下の「載せ直し」)。
6. probe_gas の投影の 6 種で流さない刻みを許す(試験の期待を直す。T-0667 で消える見込み)。
