## 熱の伝導(仮: 読まない。ADR-0429)
- 今の `face.blocked` は表面の細かい形から作る(`DeriveFaceBlocked`)。形の固い物はセル自身の固い物(D-615: 真実はセルの固い物の量)で、**固い物は熱を通す**。
  伝導に (1 − b) を掛けると、溝のセルと隣の固い地面のセルの間(面は石と石)の伝導がほぼ 0 になり、石の中を熱が伝わらなくなる(法則が嘘になる。D-428)。
- 伝導はセル全体の熱を運ぶ(相ごとではない)ので、「流体だけが通る面の割合」は伝導の通しやすさではない。気体・液体が運ぶ熱は流れと一緒に `FoFaceOpen` で絞られる(この試験の 2)。
- 伝導が絞られるべきなのは、**セルの物質でない物**が面を塞ぐ時(物の塞ぐ面 T-0977: 薄い扉・板。熱は物の中を通り、物の箱と両側のセルの受け渡しになる)。
  その時は伝導の面の係数に (1 − 物が塞ぐ割合) を掛ける(物の中の伝導は物の箱の側。20 §12)。
- **【エンジン】問い 1**: 面の開き具合の欄を「形(セル自身の固い物)」と「物(セルの外の物)」の 2 つの値に分けるか。
  - (a) 分ける【おすすめ】: `face.blocked` を面 × 3 の 2 成分(形・物)にし、運ぶ家族(気体・液体・粒・放射)は両方の大きい方を `FoFaceOpen` に、伝導は物の分だけを読む。
    作り手から見た違い: 薄い扉を閉めると部屋の熱の伝わり方が扉の材料で決まる(扉の箱が受け渡す)。溝・割れ目は熱を止めない(石は石のまま伝える)。
  - (b) 分けない: 伝導は欄を読まない(今の仮)。作り手から見た違い: 物の薄い板を閉めても、板の両側の空気どうしの伝導は板が無い時と同じに流れる(板の材料が効かない)。
  - (c) 分けず伝導も読む: 溝の横の石が熱を伝えなくなる(上の理由で採らない)。
  - 答えで変わるもの: 欄の値の数(3 → 6)・T-0977 の書き方・伝導の種類 `TxConduction` の面の係数。T-0977 の前に決めたい。今は (b) のまま(取り消しやすい: 伝導のコードは触っていない)。

## 放射(wt6)・案 B の箱(wt3)への申し送り(読む口の使い方)
- 口は `shaders/common/face_opening.hlsli` の `FoFaceOpen(cellsOpenQ16, blockedQ16)`(HLSL と C++ の 1 つの源)。欄は `sim/face_opening.h` の
  `FACE_BLOCKED_FIELD_NAME` を `FindNestField` で引き、`LoadFaceBlockedQ16(nest, field, slot, index, axis)`(セルの + 側の面。axis は世界の軸)で読む。
  − 側の面は − 側の隣のセルの + 側の面を読む(液体の `FaceOpenQ16`・気体の `FaceBlocked` と同じ)。欄が無い世界・無い頁は 0 = 塞がない(今とビット一致)。
  欄の値は `field.values` を直接読まない(`LoadNestField` か `FieldPageValues`。ADR-0403)。
- **放射**(23 §7「法則の光はセルの物質と面の開き具合で遮る」): 遮りの透過に `FoFaceOpen(Q16 の 1, b)`(= 1 − b)を掛ける(セルの物質の吸い込みは今のまま。
  セルの空きと min を取らない: 固い物の吸い込みは物質の行で数える)。太陽の影の柱は縦の面(上の面 axis = 世界の上)の b、横から来る光は横の面の b。
  形の b は「面のうち地面が届く割合」なので、溝の底へ届く光は溝の幅の分だけになる。
- **案 B の箱**(21 §2.7「各相の面の流れは開いた割合 ×(1 − 塞ぐ割合)」): 相ごとの面の開き = `FoFaceOpen(その相の両側の空きの小さい方, b)`。掛けずに小さい方
  (同じ固い物を 2 回数えない。ADR-0420)。塞いだ部分の速さは物の面に垂直な速さ(物の塞ぐ面 T-0977 が入ってから)。粒の相は `FoGrainFaceOpen` を重ねる。
  陰の圧力の面の係数は気体と同じく法則の側で `GfPressureFaceCoefficient(K, 開き)` の形(C-0 の部品の型は変えない)。
- 熱の伝導は上の問いが決まるまで読まない。

## 仮(ユーザー未確認。取り消しやすい形)
- 熱の伝導は欄を読まない(上)。
- 塞ぐ面がある世界の気体は空きを読む箱で流す(空きが全部 1 でも)。空きを読む式は、気体の無いセル(質量 0)の基準との差を 0 と数える(T-0593 の式)ので、
  塞ぐ面の有無で箱の式の数え方が 1 つ変わる(塞ぐ割合が全部 0 なら写さないので今とビット一致)。
- 気体の箱の欄の持ち主は面の − 側のセル(液体と同じ)。開いた境界・壁の外が − 側の面は塞がない。
