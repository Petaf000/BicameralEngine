## 目的
気体の既定は本物の音速のまま(D-519)。作り手が最速(投影)を選んだ世界で、小さい空きのセルの層(16³ の細孔の板の形)があれば、ベイクと実行時に作り手へ警告する
(ADR-0346: 層の全部が空き 1/256 の板を最速で流すと値が壊れる。孔の中を 1 刻みに中身の約 10 倍が通る)。

## 完了条件
- [x] どの空きの小ささ(と層の広さ)から警告するかを T-0722 の板の測り(gas_projection_test の --plate16)から決め、決め方をチケットに書く(下の「結果」。`--plates`)
- [x] ベイク(置いた世界)と実行時(最速の区画の 1 刻み目・セルの空きが変わった刻み)に警告(名前付き。値は変えない)
- [x] 警告の試験・release 警告 0・archmap --check

## 結果(2026-10-19・CPU・release。gas_projection_test --plates = ctest gas_projection_plates)
16³ の箱・z = 4 の板・板の下 4 層の気体を上の raise %・最速(音速 0)・40 刻み。「壊れた」= 気体の通れるセルの |x| が 2^59 µPa を超えた(速さも 10^6〜10^13 m/s)。
保存はどれもビット単位。塞がったセル(空き 0)の x は式の面を持たず値に効かないので数えない(数えると孔のある壁が全部「壊れた」に見えた)。

| 板の形(層の全部) | 102% | 120% | 150% | 200% | 500% |
|---|---|---|---|---|---|
| 空き 1/2 | 収まる | 収まる | 収まる | 収まる | 収まる |
| 1/4 | 収まる | 収まる | 収まる | 収まる | **壊れる** |
| 1/8 | 収まる | 収まる | **壊れる** | **壊れる** | **壊れる** |
| 1/16 | 収まる | **壊れる** | 収まる(外側が毎刻み上限・食い違い 68 g) | **壊れる** | **壊れる** |
| 1/32〜1/128 | 収まる(1/128 は外側が 23 刻み上限) | **壊れる** | | | |
| 1/256 | **壊れる** | **壊れる** | | | |

| 板の形(102%) | 結果 |
|---|---|
| 孔のある壁(層の 1/2・1/4・1/16 のセルが 1/256、残りは塞がる) | 壊れる |
| 同じく 1/64 のセル(4 つ)が 1/256 | 収まる(外側が 34 刻み上限・食い違い 64 g) |
| 孔のある壁(1/4 のセルが 1/16〜1/64) | 壊れる / 孔が 1/2 なら収まる |
| 多孔の板(1/256)に開いた孔(層の 1/2〜1/64 のセルが空き全部) | どれも収まる |
| 塞がった板(全部 0) | 収まる(外側が 30 刻み上限。分かれた区画の多重格子 = T-0688 の件) |

**決め方**: 壊れる根は「気体の 2 つの部分が小さい空きのセルだけでつながる」こと(開いた孔が 1 つでもあれば収まる・孔のある壁も多孔の板も同じ形で壊れる)。
層(平らな板)に限らず、殻・管も同じ根なので、**検査は層ではなく「小さい空きのセルを通らないと行き来できない気体の部分の組」**
(大きいセルの面のつながり + 開いた境界の外を部分とし、2 つ以上の部分に接する小さいセルのまとまり。同じ部分の組をつなぐまとまりは 1 つの組に)。
壊れ始めの空きは圧力の差で変わる(1.02 倍で 1/256・1.2 倍で 1/16・1.5 倍で 1/8・5 倍で 1/4)。爆発は 5 倍を超えうるので、**空き 1/2 未満を小さい**とした
(1/2 は測った全部で収まった)。警告の文には、その空きが測った板で何 % の差で壊れたかを入れる。ctest gas_projection_plates が「壊れた板は必ず警告する」を確かめる。

## 判断待ち(仮で進めた。ADR-0353)
1. **閾値 1/2 未満**(仮): 作り手から見ると、空き 1/2〜1/4 の砂や多孔の板の層でも最速なら警告が出る(弱い差では壊れないが、5 倍の差で 1/4 が壊れた)。
   代案: 1/16 未満(1.2 倍の差まで安全・警告は少ない。強い爆発では警告なしに壊れうる)。おすすめは 1/2(D-428。壊れる場面を黙って流さない)。
2. **ベイクの口**: 今は「最速」をパッケージで選ぶ欄が無い(最速の投影を選べるのは C++ の ProbeGasOptions だけ。GPU と多重解像度の世界は陽解法だけ)。
   そのため検査はエンジンの関数(CheckFastestOpenings)と刻みの中だけで、ベイク(表と世界の置き方)からは呼んでいない。
   作り手が最速をパッケージ(例: 環境か gas_regions の欄)で選べるようにするなら、その読み込みが同じ関数を呼ぶ(欄の名前と置き場所はユーザーが決める)。
