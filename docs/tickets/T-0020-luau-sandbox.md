## メモ・参考
- 殻: engine/src/script/luau_sandbox.{h,cpp}(`script::LuauSandbox`)。テスト: tests/luau_sandbox_test.cpp(ctest の `luau_sandbox`)。
- Luau の interrupt は「安全点(ループの折り返し・呼び出し・GC)」で呼ばれる。命令ごとの呼び戻しは無いので、上限は安全点の数で数える。
- `math.random` の既定の種は時計とアドレス(lmathlib.cpp)→ Run の始めに `math.randomseed(randomSeed)`。
- Luau 0.729 には実験中の `integer` ライブラリ(64 ビット整数。FFlag `LuauIntegerLibrary`、既定で無効)がある。ベイクを整数で書く助けになるかもしれない(T-0021 で検討。未確認)。
- vcpkg が port にパッチを当てるとき git が日本語のユーザー名のパスで落ちる → CMakePresets.json で git の設定の場所を `out/vcpkg/git-config` に向けた(ADR-0030 決定 1)。
  **パッチを当てるほかの port(ImGui など)も同じ問題に当たるはず**なので、この変更が main に入れば直る。
