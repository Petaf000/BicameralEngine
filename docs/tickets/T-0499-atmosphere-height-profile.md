## 目的(1〜2 行)
基準の大気(気体の層の基準になる、世界の静止した大気)を、海面からの高さの点ごとの温度と成分で書けるようにする。
圧力は一番低い点の値だけ書き、上はエンジンが重力と温度から静水圧の釣り合いで出す。

## 書き方(ユーザーの決定。Q61 = 案 1)
- 作り手は世界の絶対の高さ(海面からの高さ)の点ごとに温度と成分(ppm)を書く。点の間は直線でつなぐ。
- 圧力は地面の値だけ書き、上はエンジンが重力と温度から静水圧の釣り合いで出す(手で書いた圧力が重力と合わず風が吹き出すのを防ぐ。整数・決定的)。
- 標準パッケージ earth_environment に地球の高さの分布を現実の値(出典付き)で入れる。「重い物ほど下に溜まる」点を成分と温度から作る補助関数を
  標準パッケージに置く(Luau)。ゲームは標準を `require("@earth_environment")` で写し、変えたい所だけ点を書き足す/上書きする。
- 点を 1 つだけ書いた今の書き方(一様な大気)は今まで通り読める。書き間違い(高さが並んでいない・合計が 1000000 でない など)はベイクで止める。

## メモ・参考
- 書き方(Luau):
  ```lua
  local atmosphere = require("@earth_environment/atmosphere")
  local earth: any = require("@earth_environment")
  local profile = atmosphere.set_point(earth.environment.atmosphere_profile,
      { height_mm = 0, temperature_mk = 300000, composition = { nitrogen = 780780, oxygen = 209460, argon = 9340, carbon_dioxide = 420 } })
  return { environment = { atmosphere_profile = profile } }   -- 圧力は atmosphere_surface_pressure_pa(一番低い点)だけ
  ```
- 地球の分布の静水圧(release・2026-10-15): ISA の表と 11 km −0.013%・20 km −0.027%・32 km −0.045%(平均のモル質量が ISA の 28.9644 より
  わずかに重い 28.9667 g/mol〔CO2 を入れた分〕と、0.5 m の段の分)。
- 気体の層の基準と高さの静水圧の差は 0.36 Pa 以内(重力 0〜100 m/s²。気体の導く値の丸めの分。重力 0 でも同じ大きさ)。
- 補助 `settled` の例(地面で N2 50%・CO2 50%、地球の温度): CO2 は 5 km 41.4%・10 km 32.3%・15 km 23.6%。
- 作り心地の記録(D-486): 点の列を表の中に直接書くと、Luau の型検査が点ごとに別の型を作って `{ AtmospherePoint }` に合わない誤りを出した
  (`{ nitrogen: number }` は `{ [string]: number }` と「ちょうど同じ」でない)。型の定義の `atmosphere_profile` は `{ any }` で受け、
  欄の誤りは読み込み(environment_package.cpp)が場所付きで止める形にした。`local p: { AtmospherePoint } = {...}` と型を付ければ型検査も効く。
  同じ形の誤りは「表の列の中の成分の表」を持つほかの分類でも起きうる(BACKLOG の候補: 型の定義の書き方を直すか、Luau の新しい型検査器で直るか)。

## 判断待ち(仮で進めたもの。ユーザー未確認・取り消しやすい)
エンジンを使う人(作り手)から見た違いで:
1. **点の列を environment の 1 つの鍵にした**(案 A・仮)/ 案 B: 分類 `atmosphere_points` に点ごとの鍵(名前)で書く。
   - A: 上書きは列ごと(標準の点を消せる・並びが一目で分かる)。Mod が点を 1 つ足すにも列を写して書き直す。
   - B: Mod が点を鍵ごとに足せる。標準の点を消せない(地球の 8 点の上に自分の点が混ざる)・同じ高さの点の重なりは鍵の名前では防げない。
   - おすすめ A(ユーザーの「標準を読み込み、変えたい所だけ書き足す/上書きする」は require の写しで書ける)。
2. **圧力を書く高さ = 一番低い点の高さ**(仮)/ 代案: 常に海面(高さ 0)の圧力。作り手から見ると、仮の形は「一番下の点に地面の値を書く」で、
   海面より高い所にしか大気を書かない世界(高原の世界)でも、その一番下の点の圧力を書ける。地球は一番下の点が海面なので同じ。
3. **端の点の外は端の値**(仮): 一番高い点より上も温度と成分は一定(圧力は静水圧で下がり続ける)。一番低い点より下も一定(圧力は上がる)。
