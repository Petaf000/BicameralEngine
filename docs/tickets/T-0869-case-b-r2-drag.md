## 目的(1〜2 行)
相どうしの引きずり(流体 ↔ 粒・流体 ↔ 据わる固体の孔)を、陰の圧力と同じ解きの中で扱う(面ごとに粒を消去して圧力の式に入れる)。
強い引きずりでも刻みが割れず、保存 0・決定的・0.5 m と 2 m で同じかを、21 §5.2 の R2 の行で測る。

## 完了条件(21 §5.2 の R2。仮の目安は 21 のまま)
- [x] 砂が水中を落ちる速さ ±30 %(300 µm。終端 42.7 mm/s)
- [x] Darcy ±10 %(孔のある石の栓。k = 1000 µm²)
- [x] 染みる速さが刻み 1/60 と 1/120 で ±5 %
- [x] 1 mg で暴れない(水中・空気中)
- [x] 保存の誤差 0(全部の刻み・全部の場面)・2 回の実行でハッシュ一致・粒も孔も無ければ R1 とビット一致
- [ ] しずくの終端の速さ ±20 % → T-0963(気体 ↔ 液体は置き場 ① が要る)
- [ ] 水面で風が水を引きずりすぎない(10 m/s で水面 5 % 以下)→ T-0963
- [ ] 詰まった砂を染みる水(Kozeny–Carman。砂の堤)→ T-0963

## 研究の打ち切り条件(着手時に書いた)

## 作ったもの
- `case_b_flow`(`FlowOptions::drag`。既定 false = R1 のまま):
  - 面ごとに `PrepareCoupledFace`: 粒の重さと浮力(浮力は押しのけた流体の重さで、流体 → 粒の受け渡し)、引きずり K(下)、
    詰まった所・据わる固体・物のあるセルへ入る粒の面は止める(帳簿 Wall。押し合いは R3・仮)。止めた粒は流体から見て据わる孔(K を K_x へ)。
  - `EliminateGrain`・`CoupledSystemTerms`: 2 × 2 の面の連立 [m_f + K + K_x, −K; −K, m_s + K] から粒を消去し、
    a' = m_f + K_x + K m_s ÷ b・c' = A_f + A_s K ÷ b(b = m_s + K)で、圧力の係数 c'² ÷ a' + A_s² ÷ b と予測の流れを R1 と同じ形で組む。
  - `SolveCoupledFace`: 解いた y で、圧力の力積 → 相どうしの受け渡し(MoveMomentum。和 0)→ 孔の引きずりの残り(帳簿 FixedPhase)。保存は受け渡しの形で守る。
  - K: 散らばった粒 = 粒の体積 ×(18 μ/d² + 3 √(ρ μ |Δv| / d³) + ¾ C₂ ρ |Δv| / d)(C_d ≈ 24/Re + 4/√Re + C₂)と、
    詰まった粒 = Kozeny–Carman(180 μ φ_s ÷ (d² φ_f))の大きい方。孔 K_x = Darcy(μ φ_f² ÷ k)× セルの体積。K は mg の Q16(1 mg の粒で 0 に丸まらない)。
  - 粒の運び(`TransportGrains`): 粒の質量の流れ(mg の Q32 = 風上の粒の質量 × v Δt ÷ Δx)+ 面の持ち越し(`faceCarry` の粒の置き場。21 §2.10)で整数の mg を移す。
    面積を通さない(1 mg の粒の面積は 1 mm² 未満)。粒の運動量の MAC の運びも流体と同じ形で(`AdvectSlot`)。
- `tests/case_b_r2_test.cpp`(ctest `case_b_r2`。約 14 秒): 場面は試験の中で書いた(水中の砂・空気中の粉・孔のある石の栓・1 mg)。引数 0〜4 で 1 つに。
- `docs/architecture/map.yaml`: ノード casebdrag。

  - 粒の面積を Q16 の割合から → 0.001 % の粉が 0 に丸まった。粒の体積 ÷ 辺に。

  - 粉 1 % の場面は粉の雲が空気の 22 倍重く、1 粒の終端ではなく雲が崩れる流れ(0.5 m で 87 mm/s)。0.001 % に薄めて 1 粒の終端を測った(重い雲の崩れ方は記録・正しい向き)。
  - 薄めた時に熱を作り直さず、空気が 2800 K になって 2 m の箱が爆発した(試験の場面の誤り)。

## 仮・判断待ち
- 仮: 粒の抗力の形 C_d ≈ 24/Re + 4/√Re + C₂(C₂ = 1.0 = 自然の砂)・Kozeny–Carman 180。法則の定数で、作り手は書かない(21 §1.1「引きずりの係数は今の欄から導く」のとおり)。
  中の項 4/√Re は 24/Re と C₂ をつなぐために置いた(無いと 300 µm の砂が水中で 23 % 速い)。`FlowOptions::grainShapeDragPermille` で C₂ を選べる(既定 1000)。
- 仮: 粒が詰まった所・据わる固体・物のあるセルへ入る粒の面は止める(帳簿 Wall)。詰まった粒の押し合い・崩れる角度は R3。止めた面の粒は流体から見て据わる孔。
- 仮: 粒の浮力は流体の柱ではなく「押しのけた流体の重さ」(面の流体の密度 × 粒の体積)で、流体 → 粒の受け渡し。横の面だけ柱の差の力を粒の面積に。
- 仮: 粒の運び方は質量の流れ + 面の持ち越し(端数)。流体(R1)はまだ体積の流れ・持ち越し無し(21 §2.10 の残り。T-0868)。
- ゲームの中身へ: 無し。
