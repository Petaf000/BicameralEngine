## 直したこと(T-1368 の表の番号)
- L1 TestFire: 燃えた印を「セルロースが減る・箱の O2 が減る・炭素の酸化物(CO2 + CO)が出る」に。付けたセルの CO2 は炭が大過剰の 3000 K 超のセルで
  Boudouard により数刻みで CO になる(この表の熱分解は発熱)ので、どちらの酸化物かは温度で決まり、和で見る。
  測り: 300 刻みでセルロース 308.8 → 270.2 mol・O2 544.02 → 543.04 mol・CO2 0・CO 1.966 mol。
- L2・L3 TestTableMark: 替わり目(刻み 100)に燃えていない木 (4, 3, 3) を 600 K に(gpu_lab_box の SWAP_IGNITE_CELL と同じ。替えない側にも同じコマンド)。
  ハッシュとセルロースはどちらも替えた刻みの終わりで比べる。T-1368 の案の「+10 刻み」は、替えない側もちょうどその刻みで熱分解の暴走に入って
  使い切り、同じ 231.6 mol になった(測り)ので境目で不安定。替えた刻みの終わりは T-1368 の測りで 270.18 / 270.02 mol(速い表が少ない)。
- L4 TestGauge: 計器で見る物を CO に(速さの和 = 量の差の確かめはそのまま)。古い注「60 刻みではまだ CO2 が出ない」を消した(CO2 は刻み 4 に出て CO になる)。
- L5・L6 TestRefinedHeatSpeed: 解き方の試験なので MakeFastConductionTestTable() の表で回す(ADR-0505 の決定 2 に追記)。
  測り: 基準のレベル 薄い空気 0・空気 1・木 4・木炭 4。熱の広がり 理論 0.6863・陰解法 0.6654(−3.0 %)・小刻み 0.6741(−1.8 %)・陰解法なし 0.0469。
- gpu_lab_box_test の RunFire: 燃えた印に CO2 + CO > 0 を足した(CPU と同じ性質を GPU でも見る)。

## 確かめた前提(CPU と GPU)
- CPU: 上の測り。表を替えた箱は刻み 100 からハッシュが違い、その前は同じ。
- GPU: gpu_lab_box〔HW・WARP〕は T-1066 で前提を直したもの(燃えていない木を替わり目に 600 K・向かいの角 (4, 4, 4) を 600 K)。
  CPU の箱と毎刻みビット一致を見るので、CPU で確かめた振る舞いがそのまま GPU の前提にもなる。
