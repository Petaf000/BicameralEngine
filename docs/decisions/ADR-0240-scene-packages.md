# ADR-0240 ⑤ の場面はパッケージのフォルダ(data/scenes)に置き、遊びの指標で測る

- Status: Proposed
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
D-486: ⑤ の各場面(T-0414〜T-0416)の中身は、作り手と同じやり方(Luau のパッケージとエディタの道具)で作る。
場面をどこに置き、どう起動し、面白さ(延焼の速さ・川で止まるか)をどう測るかの形が無かった(T-0414)。

## 決定(仮。ユーザー未確認)
1. 場面は `data/scenes/<場面>/` の下のパッケージ(普通はゲーム本体 1 つ)。依存は標準パッケージ(data/standard)。
   `data/packages`(サンプルの世界の既定の読み込み)には置かない(置くとサンプルの世界が Mod として読み、試験の表が変わる)。
2. 起動は `--packages data/scenes/<場面>`。今はゲーム本体の名前が combustion_test に決め打ちなので `--world sample` と、フォルダの名前を
   combustion_test にする回避で読む(T-0557 で外す)。
3. 場面の面白さは、その場面のパッケージの遊びの指標(play_metrics。T-0432)で測る。前の版の値は `data/scenes/<場面>/metrics_baseline.txt`
   (`--measure-metrics --metrics-baseline ... --metrics-save`)。値を変えたら測り直して差を見る。
4. 場面のパッケージに書く値は見本の値(現実の値 + 試験の倍率)で、ゲームの中身ではない(D-006)。魔素・魔法は書かない。

## 検討した代案と、採らなかった理由
- data/packages に場面ごとの Mod を足す: サンプルの世界と試験の表が変わる。
- 場面を C++ の試験の場面として書く: D-486(中身はエンジンの C++ に書かない)に反する。
- ブランクの世界 + Mod として読む(`--world blank --packages`): Mod は標準パッケージの鍵を書き直せない(熱伝導率の倍率が書けない)。

## 影響(何がしやすく/しにくくなるか)
- 作り手と同じ形で場面を作り、指標で前の版と比べられる。場面ごとのフォルダなので並べて増やせる。
- フォルダの名前の回避(combustion_test)は T-0557 まで残る。指標は世界全体の量しか測れない(T-0559)。

## 追記(2026-10-15・T-0557)
- 2 の回避を外した: ゲーム本体はマニフェストの `game = true` で決まる(名前に依らない。ADR-0250。仮)。場面のパッケージに `game = true` を書き、
  フォルダを `data/scenes/grass_fire_river/grass_fire_river` に直した。起動は `bicameral --packages data/scenes/grass_fire_river`
  (ブランクの世界のまま。`--world sample` は要らない)。

- **2026-10-26 本体の棚卸し(QUESTIONS Q75)**: 草原の延焼の最小の版の仮 3 つ → もう要らない(A 場面の置き場は ADR-0250・B 試験の倍率は D-511・D-637 で外した・C 草の物質はゲームの中身 D-539)。
