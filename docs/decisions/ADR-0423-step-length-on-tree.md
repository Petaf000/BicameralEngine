# ADR-0423 刻みの長さの選び方を多重解像度の木の上で(研究 R-T2 の 2)

- Status: Proposed(研究の途中。形の細部は Claude の案・ユーザー未確認。ADR-0390 の「エンジンの形(仮)」・ADR-0410 の続き)
- 日付: 2026-10-22
- 決めた人: Claude(wt4 の作業役。T-0950)。芯は ADR-0390・D-600(ユーザー決定)
- 関係: ADR-0410(試し 1)・ADR-0397(C-0)・ADR-0399・ADR-0403・ADR-0417(C-1)・D-552(決まった乱数の丸め)・D-608(温めた始まりは状態)
- 試作: engine/src/sim/time_step_tree.{h,cpp}・tests/time_step_tree_test.cpp(捨てる試作。CPU。熱だけ)

## 決めたこと(仮)
1. **試し 1 の規則を木のブロックへそのまま**: ブロック(8³ セル)ごとの歩 2^e・上限 14・伸ばすのは 1 歩に 1 段まで・隣(面でつながる枠。
   レベルが違っても)の差 1 段・長すぎる隣は打ち切り・境は短い側が持ち主で長い側の歩の初めの値を読む。
2. **解きは C-0 の部品のまま**(SolveEquilibrium。口は変えない)。長さ N は法則が面の係数・地面の係数(値を固定した面)・源に入れる。
   **差の形で渡す**: 未知数は歩の初めの温度からの差 δ。右辺 = N Σ g (x0_j − x0_i) + N g地面 (T地面 − x0_i) + 反応の熱、外の隣は値 0 を固定した面。
   釣り合っている所は右辺が整数でちょうど 0 になり、δ も面の流れも 0(x そのものを解くと、V サイクルの丸めの揺れが長い歩の大きな係数に掛かって
   静かな所に流れが出る)。決まった回数の V で解けきらない分は、差の形でも面の流れを両側に足すので保存は厳密のまま。
3. **違うレベルの面の受け渡し**: 面は細かい側が 1 回だけ作り、粗い側へは 8^差 で割った値を決まった乱数で丸めて送る(D-552 の広がる家族の丸め)。
   細かい側は送った値 × 8^差 を失う。端数の枠(ADR-0017)を使わずに保存が厳密(試作の仮。本物は当てる段 transport_apply の形に合わせる)。
4. **予算(1 歩の変化の許す大きさ)は木の上で仮に 1/16 mK**(1 列の試作は 1 mK で足りた)。1 mK では違うレベルの境の近くで 8 mK ずれた。
   V の回数(4 → 16)・Galerkin の粗い段では直らず(7.2・6.7 mK)、予算を 1/16 にすると 0.18 mK。原因は選び方の側(境の向こうの
   変化を見ずに伸ばす)で、解きの側ではない。解きの回数は 0.022 → 0.147 回/セル/刻み(約 7 倍)。直し方の候補は T-0985。
5. **眠る・起こすは C-1 のまま**: 歩の変化が全部 0 の枠は歩の終わりに C-1 の FoldQuietPages で畳む(導かれる値は覆われていないセルの平均)。
   変化が来た枠は ExpandNestPage で起こし、導かれる値は次の歩の初めに解き直す。眠っている間は導かれる値を書かない(T-0854 の申し送り)。
6. **歩の途中のセーブ(Q146 の一旦の決定 (A))**: 歩の記録(枠の e・望みの e・始めた刻み・歩の途中か / セルの記録〔反応・地面〕/ 面の記録〔区間・受け渡した値〕)
   を木の状態と一緒に写せば、読み込んで続けたのとビット一致(試験で確かめた)。歩の変化(セルごと)は記録の和なので作り直せる。

## 結果(2026-10-22・開発機の CPU・release・1 スレッド。詳しくは T-0950)
- 早送り(1 刻みずつ・一気に・ばらばらの塊)と 2 回の実行でビット一致・どの塊の境目でも保存が厳密。
- 歩の途中のセーブ: 戻して続けたのとビット一致。歩の記録は最小 11.6 B/セル(歩の変化も持つと 27.6 B/セル)。
- 精度: 静かな夜は予算 1/16 mK で 0.18 mK(通過。1 mK では 8.2 mK)。**火事は前線で 5.7 mK(落ち)**。
- 細かさ(0.5 m と 1 m): **池 平均 0.71 段・97.7 %・火事 0.55 段・84.0 %(落ち)**。ブロックの長さが細かさで違う(4 m と 8 m)ことの効き目は T-0985 で分ける。
- 眠った所の導かれる値は眠った時の平均のまま(火事で 8 回見て違い 0)。
- 費用(CPU 1 スレッド): 夜 116 秒(毎刻み 743 秒)・火事 244 秒(毎刻み 381〜766 秒)。
- 打ち切り条件(T-0856): 選び方の段を 2 通り変えて直らなければ退く道。1 通り目(予算)で夜だけ直った。2 通り目は T-0985。

## 影響
- 作り手から見て: 1 列の試作と同じ(刻みの長さは書かない・早送り = 待った)。違うのは、木の上では予算を細かくしないと
  レベルの境で精度を超えたこと(費用が増える)。
- 土台へ要る口: T-0950 の「C-1 に要る口」。C-0 は今の口で足りる(運ぶ〔風上の流れ〕は対称でない面が要る = T-0984)。
