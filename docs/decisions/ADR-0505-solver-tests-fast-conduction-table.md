# ADR-0505 陰解法・近くの畳みの GPU 試験は、T-1066 の前の伝導率の倍率を掛けた試験の表で回す(T-1250)

- Status: Proposed(Claude の一旦の決定。試験の側だけの変更で、エンジンの式と既定の試験の表は変えない。作り手から見た違いは無い)
- 日付: 2026-10-29
- 決めた人: Claude(wt4 の作業役・T-1250)
- 親: D-637・ADR-0454(試験の倍率を外した)/ 関係: T-0117・T-0127・T-0129・T-0132・T-0112(落ちていた試験)

## 背景
main の HW で前から落ちていた gpu_multires_implicit(計測: 鎖を測れない)・_tree・_build(SegFault)・implicit_conduction の _chain・
gpu_multires_near_fold(畳んだ頁 0)は、どれも **T-1066(21ceb6e0・2026-10-24。D-637 で試験の伝導率の倍率 気体 5000・固体 20000 を外した)** から落ちる。
- 境目: 71930728^ と 71930728(T-0931)の上では gpu_multires_implicit_build_warp が合格。T-1066 の後の main では
  「熱い点: 陰解法の刻みが無い」。その間で陰解法・木の伝導の場面に触れたのは T-1066 だけ(d28bb4dc は途中の版でビルドが通らない)。
- 仕組み: 面の係数が熱容量の上限で頭打ちにならない最後のレベル(基準 MrSubcycleBaseLevel)は、T-1066 の前は 2、現実の値では **7**(今の式〔体積の平行の道・√T〕に前の倍率を掛けた表では 1)
  (multires_implicit_tree の物差しのログ「基準 7」)。陰解法の系に入るのは基準より細かいブロックだけ(InImplicitConduction)なので、
  レベル 6 までの場面(熱い点・鎖・たくさんの要求)には系ができない。
  - _tree・_build の SegFault は、空の刻みの列に計測(release の HW だけ)が `ticks.back()` を読んだため(CPU 側。確かめる側には空の確認があり、WARP は「刻みが無い」で落ちていた)。
  - gpu_multires_implicit の「鎖を測れない」は、基準 + 1 より細かいセルが無く系が空のため。
  - near_fold は、現実の伝導率では鎖が 4000 刻みで許容差(100 mK)まで均されず、頁が畳まれないため。
- CPU の multires_implicit_tree は通っていた(系が空でも「保存量が一致」は満たす。V サイクル 0 のまま)。試験になっていなかった。

## 決定
1. 試験の表 `MakeFastConductionTestTable()`(tests/reaction_test_table.h)を足す: 試験のパッケージの表の伝導率に T-1066 の前の倍率
   (気体 5000・凝縮相 20000。物質の相で分ける)を掛ける。試験のパッケージ(combustion_test)と既定の試験の表は変えない。
2. 解き方(陰解法の系・多重格子・GPU の段・許容差つきの畳み)を確かめる試験はこの表で回す: gpu_multires_implicit・_tree・_build・
   _conduction(全部)・multires_implicit_tree・gpu_multires_conduction の --near-fold。
3. 計測の側にも空の刻みの確かめを足す(SegFault ではなく理由を返す)。

## 理由
- これらの試験が確かめるのは「CPU と GPU がビット一致で解けること」と解き方の費用で、物質の値の現実さではない。基準のレベルを場面の中に
  置かないと解く物が無い。場面を基準より細かく(レベル 8 以上)作り直すと、T-0117〜T-0135 の計測(perf.md)と比べられなくなり、木も深くなる。
- 前の値と同じ表なので、前の計測・基準(V サイクル・系の大きさ)とそのまま比べられる。

## 退けた案
- 場面をレベル 8 以上に作り直す(費用の比べが途切れる・場面の作り直しが大きい)。
- 期待を「系が空でもよい」に緩める(試験が何も確かめなくなる)。

## 作り手から見た違い
無い(試験の側だけ)。現実の伝導率の世界(D-637)では、陰解法の系に入るのは 0.5 m × 2^-8 ≒ 2 mm より細かいセルだけになる
(基準 7)。陰解法(D-434)が働く所が、今の世界の細かさではほとんど無いことの記録として残す。

## 残る問い
- 現実の伝導率で基準が 7 なら、陰解法の段(D-434 の案 a)を既定の世界で持つ意味があるか(司令塔へ。土台の見直しの材料)。
