# ADR-0386 初めの状態は生成して落ち着かせてから・セーブは初めの状態 + 真実の差分

- Status: Accepted(2026-10-21。形はユーザーの決定。前提の「どの GPU でもビット単位で同じ」は未確認で、研究 R-G1 で確かめる)
- 日付: 2026-10-21
- 決めた人: ユーザー(claude/33 S34・S36。Claude が案を出した)
- 関係: D-312・D-585・D-586・D-207・設計 05 §6・§7・15 §1・claude/34 S41(真実と導かれる値)・claude/35 §3 列 6(R-G1・R-F1)

## 背景
- 生成したままの世界は法則と食い違う所があり、始まった途端に崩れる・流れる。
- 20 km の世界を全部書くセーブは大きく遅い。セーブ・ロードは自由(claude/31 S1)なので、気軽に何度もセーブできる形が要る。

## 決定
1. **初めの状態 = 生成 → 法則で落ち着かせた結果**。落ち着かせも決定的で、種・生成手順の版・法則の版から作り直せる。生成器は堆積・浸食を真似る作り(地層が読める)。
2. **セーブ = 初めの状態の決め方(種と版)+ 変えた所の差分**。差分に入るのは真実だけ(導かれる値は読み込んで解き直す)。
3. 前提の研究 **R-G1**: 同じ種から違う GPU(少なくとも 2 社)で同じ世界がビット単位で出るか(合格と打ち切りは設計 05 §6.1)。
4. **退く道**: R-G1 が落ちたら初めの状態も差分と一緒に持つ。セーブの形式は、初めの状態を「種から作る / ファイルに持つ」を見出しの値 1 つで選べる形にしておく(退いても形式を変えない)。

## 検討した代案と、採らなかった理由
- 生成したまま始める: 始まった途端に崩れる・流れる。
- 生成そのものを法則の早送りにする(堆積・浸食・川が谷を掘るを本当に走らせる): 地層と川筋が本物の歴史と一致するが、作る時間がとても長く、形を手で決めにくい(研究)。
- セーブに全部を書く: 単純だが、20 km の世界で 1 回のセーブが大きく遅い。

## 影響(何がしやすく/しにくくなるか)
- しやすく: 軽いセーブ。世界は最初から釣り合っている。差分は真実だけなので小さい。
- しにくく: 生成と落ち着かせのシミュは整数だけで書く必要がある(04 §4)。法則の版が変わると初めの状態も変わる(法則の版と古いセーブの扱いは claude/33 M5。A8 の枠)。
  落ち着かせの費用(何刻み・何分)は未確認。AMD の機械が無いうちは R-G1 を NVIDIA と WARP で先に進める(D-207)。
