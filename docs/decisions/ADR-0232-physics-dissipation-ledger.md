# ADR-0232 物理の散逸の帳簿(失った力学的エネルギーを物ごとに数える)

- Status: Accepted(数え方)/ Proposed(熱の返し先と負の散逸の扱い: 仮・ユーザー未確認。T-0519 の判断待ち 1・2)
- 日付: 2026-10-15
- 決めた人: Claude が提案(T-0519)。根拠は D-465(保存則: 出入りはすべて帳簿に載る)・D-466(坂を下る散逸の行き先)

## 背景
- 19 §2.2: 物の物理(AVBD)は衝突・摩擦・減衰で失った運動エネルギーの行き先が無く、帳簿にも載らなかった(G2)。気体は全エネルギーを運ぶので済んでいる。

## 決定
1. 物ごとに、小刻みの初め(PxInitializeBody)と終わり(PxFinishBody)に同じ整数の式で力学的エネルギー(½ m v² + m g y + ½ Σ I_k ω_k²。2^-10 µJ)を数え、
   差を PxBody::dissipatedEnergy に足す。接触・摩擦・陰的な積分・仕上げの位置の直し・丸めを行ごとに分けず、差でまとめて数える(帳簿の式がビット単位で成り立つ)。
2. CPU(sim::PhysicsWorld)と GPU(physics_step.hlsl の Finish)は同じ関数を呼び、物ごとの帳簿がビット単位で同じ(gpu_physics_test の CompareEnergy)。
3. 小刻みの外の出入り(押す力積・現れる/消える・重力の差し替え)は散逸に入れない。世界の合計は sim::SumPhysicsEnergy。
4. 動きの式とハッシュは変えない(数えるだけ。PxBody は 448 → 464 バイト)。
5. **(Proposed)** 世界の熱へ返すのは T-0542: 島(接して動く物の組)の合計を接触点の仕事の重みで分け、接触の両側へ半分ずつ(物が温度を持つまでは接触点のセルへ)。
   島の散逸が負の時は島の「借り」として帳簿に残し、次の正の散逸から差し引く(世界を冷やさない)。

## 影響
- 物ごとの値は運動量のやり取りを含むので、物ごとに熱へ返してはいけない(当てられた物が冷える)。返すのは島・接触点の単位(T-0542)。
- 物の温度(08 §1 の物の中身)ができたら、物の側の半分を物へ返すように替える(帳簿の式は変わらない)。

## 追記 1(2026-10-15・T-0542)
- 決定 5 の返し先は ADR-0242 で決めた: 島ごとではなく、返す元を世界で 1 つにし、接触点の仕事の重みで分ける(仮)。借りと端数は同じ帳簿の残り。

- **2026-10-26 本体の棚卸し(QUESTIONS Q71)**: 物理で失った運動エネルギーの熱の返し先 → ① もう要らない(物も温度を持つ。D-545)・② 閉じた(負の散逸は借りとして帳簿に残す。D-539)。
