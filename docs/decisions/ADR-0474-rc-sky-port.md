# ADR-0474 空との交換の口: 参照の温度との差だけを運ぶ RC の、上の境目の出入りを太陽の影の柱の掃きで入れる(案)

- Status: Proposed(T-1145 で CPU と GPU の掃きに入れた。RC の刻みの順へはまだつないでいない。決めるのはユーザー)
- 日付: 2026-10-25
- 決めた人: Claude(T-1145)
- 設計: docs/design/23-radiation.md §3.2・§3.3 / 前: ADR-0461(参照の温度との差だけを運ぶ)・ADR-0396(太陽の影の柱)・D-646

## 背景
ADR-0461 の RC は同じ温度の所で何も放たないので、坂を下るは構造で 0 になった。その代わり、世界の箱の外は「参照の温度の物」として扱われる
(差の光は外へ出るが、参照の分は出入りしない)。上の外(空)は参照の温度ではない(夜の空は冷たい・昼は散らばった光が来る)。

## 決定(案)
1. 世界の箱の外は、**空の向き(上の境目)= 天候の層の空の光、ほか(横・下)= 参照の温度の物**。横と下は箱の外へ続く地面として扱う。
2. 口の量 = 帯ごとの「空から水平な面へ来る強さ − 参照の黒体の強さ」。正の帯と負の帯を別の掃きにする(RC の正の側と負の側と同じ考え)。
3. 運び方は**太陽の影の柱の掃きをそのまま使う**(決めた向きの平行な光線の束。保存・決定性・CPU と GPU のビット一致は R-R0 のまま)。
   既定の向きは 4 つの斜め (±1, −1, ±1)(取り分 1/4 ずつ): 開けた水平な面で差の 1 倍、開けた縦の面で 1/2 倍がちょうど出る。
4. 吸った分はセルのエネルギーへ(負の掃きは引く)、返した分は RC の同じ符号の側の持ち越しへ(太陽の照り返しと同じ口)。

## 作り手から見た違い(仮)
- 【エンジン】空の温度と散らばった日の光を天候の層の値で選ぶと、開けた所ほど空と熱をやり取りする(夜に開けた地面が冷え、軒下は冷えにくい)。
  空 = 参照の温度(ブランクの世界の既定)なら口は何もしない。
- 箱の横の外が 0 K でなくなる(今の RC は箱の外を 0 K として全部の向きへ逃がしていた)。
- 空の見える割合は 4 向きの筋で出る(穴の底・軒下の細かい形は向きの数だけの粗さ)。向きの組は値で増やせる。

## 検討した代案
- RC の箱の外に「空のセルの殻」を置き、RC 自身で空の光を運ぶ → 運び方は RC と揃うが、殻の面が毎刻み放つ光源になり(64³ で地面と同じ数)、RC の段の作りを変える。
- 空の見える割合をセルごとに前もって作り(幾何が変わる時だけ)、差 × 割合を足す → 速いが、煙・物が動くたびに作り直す決まりが要る(D-428 の結果を変えない形にするには毎刻みの掃きと同じになる)。
- 今の形(外 = 0 K)のまま → 同じ温度の閉じた所で坂を下るが崩れる(ADR-0461 の前に戻る)。
