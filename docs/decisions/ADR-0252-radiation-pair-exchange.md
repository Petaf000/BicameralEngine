# ADR-0252 放射は「1 mol が遮る面積」を物質に書き、セルどうしの対の交換で運ぶ

- Status: Proposed(2026-10-15。T-0583 で仮に実装。ユーザー未確認)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- T-0414(⑤ 草原の延焼)で、伝導だけでは燃える物が途切れると必ず止まり、川が遊びとして意味を持たないと分かった。放射が要る(T-0028・R-TRANS-1)。
- D-443(放射の方式は光線)・D-454(中身を持たない: 放射の性質は物質の値でパッケージに書く)・D-465(保存・決定性)・D-466(坂を下る)。
- 物質の放射の性質をどう書くか、σ(Stefan–Boltzmann 定数)を誰が持つか、行き過ぎをどう防ぐかを決める必要があった。

## 決定(仮。ユーザー未確認)
1. **物質の任意の欄 `radiation_absorption_mm2_per_mol`(1 mol が放射を遮る面積)**。セルの吸収率 α = 1 − e^−τ、τ = Σ a·n ÷ セルの面。
   放射率も同じ値(灰色体。Kirchhoff)。書かない物質は 0(放射しない・吸わない)。ブランクの世界と今のパッケージは放射なしのまま。
2. **σ は器の換算の定数**(`shaders/common/radiation.hlsli` の RD_PAIR_SCALE_Q32 の 1 か所。SI の定義値。気体定数 R と同じ扱い。ADR-0171 §2)。
3. **α ≤ 1**(黒体より強く光る物は作らない)。
4. **交換はセルの対ごとに 1 つの整数**: Q = σAΔt·α_i·α_j·F·(T_i⁴ − T_j⁴)。係数 h = σAΔt·w·(T_i + T_j)(T_i² + T_j²)は伝導の面の係数と同じ単位で、
   i と j について対称(入れ替えると符号だけ反転 → 保存がビット単位)。h ≥ 0 なので坂を下る。温度は刻みの初め(順番によらない)。
5. **行き過ぎの上限**: 対の係数 ≤ min(熱容量) × 1/4 × 対の分け前。伝導は 6/8 のまま、放射は 1/4 を分け合う(合計 ≤ 1 で凸結合)。
   受け手の側で分け前の合計 ≤ 1 を保証する配り方は T-0584(研究)で決める(見つからなければ 2 回に分ける上限)。

## 検討した代案と、採らなかった理由(作り手から見た違い)
- **1. の代案 A: 物質ごとの放射率(0〜1)**
  - 作り手: 「この物質の表面は黒い / 白い」と直感的に書ける。ただしセルは混ざり物(草 + 空気・煙 + 空気)なので、セルの放射率の決め方
    (量の平均だと草が空気に埋もれて光らない・最大だと煙の薄さが出ない)をエンジンが選ぶことになり、作り手は「薄い煙は透ける・濃い煙は遮る」を書けない。
  - 採らない(仮)。案 B(採用)は 1 つの欄で草・煙・砂・ガラス(0)が書け、量で濃さが変わる。代わりに値の意味が少し間接的
    (道具で「このセルの量なら放射率 0.91」と見せる必要がある。T-0585 で表のパネルに出す)。
- **1. の代案 C: 両方(表面の放射率 + 体積の吸収)**: 欄が 2 つで、同じ現象を 2 か所で書けてしまう。今は採らない。
- **2. の代案: σ を世界の値(環境のパッケージ)にする**
  - 作り手: 「この宇宙では熱い物がもっと強く光る(遠くまで火が届く)」が書ける。案 1 の α ≤ 1 だと放射の強さの上限は黒体で決まる。
  - 費用: 環境の値が 1 つ増えるだけ(重力と同じ形)。ブランクの世界は 0(放射なし)にできる。
  - 仮に採らない理由: 放射と伝導・反応の熱の比が宇宙ごとに変わると、パッケージの作り手が温度の目盛りを読み替える必要がある(R を変えないのと同じ理由)。
    ただし R と違い、σ を変えると**プレイヤーが観察できる違いが出る**ので、ユーザーの判断が要る。後から欄を足すのは取り消しやすい(RD_PAIR_SCALE を表の値にするだけ)。
- **3. の代案: α > 1 を許す**: 対の形(α_i·α_j が対称)なので坂は下るまま(永久機関にはならない)。ただし「黒体より明るい物」は現実の直感から外れる(D-464 の向き)。
- **4. の代案: 07 §1 の第 1 段(半径 r の表面へ 1/r² で配る)**: 空へ抜ける分を数えず、相手が 1 つなら全部を送る。事前調査(T-0028)のとおり採らない。

## 影響(何がしやすく/しにくくなるか)
- しやすくなる: 物質に 1 行書けば放射が出る。煙が遮る(D-443 ④)は、すすの物質に a を書けば光線の途中の透過で出る(T-0584 の後)。
- しにくくなる: 物質の a は「物の細かさ」(草の葉の薄さ・すすの粒)込みの値で、純粋な物質の値ではない(同じセルロースでも木の塊と草の束で違う)。
  別の物質として書くか、相(M2)が入った時に形の欄を足すかは後で決める。
- GPU: 今は CPU のリファレンスだけ。GPU の表(RxSpecies)に a を入れるのは T-0586(表の大きさが 4 バイト増える)。
- 試験: `radiation_reference`(T-0583)。
