# ADR-0183 標準パッケージの棚(data/standard)と、環境ミキサーで世界に足す仕組み

- Status: Proposed(案 A を仮で実装。ユーザー未確認。T-0373)
- 日付: 2026-10-13
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- D-457: エディタに環境ミキサー。現実の元素・物理定数・反応と物質・地球の環境を、ボタンで世界に足す。中身は標準パッケージ(13 §2.6)。
- 世界の表は今、パッケージのフォルダ(既定 exe の横の data/packages)の直下を全部読む(ReadPackageRoot)。ここに標準パッケージを置くと、
  サンプルの世界(`--world sample`)にも全部読まれてしまう。

## 決定(仮)
1. **棚**: 標準パッケージは `data/standard/<名前>/` に置く(世界の既定の読み込みとは別。足さなければ読まれない。D-455)。
   1 つのフォルダ = 1 つのパッケージ(今の形のまま)。マニフェストに見せる名前 `title`(省ける)を足した。
   今の中身(D-471 ②: ⑤ の場面に要る分だけ): real_elements・real_matter・real_reactions・earth_environment・earth_air(data/standard/README.md)。
   「現実の物理定数」のパッケージは作らない: 世界ごとに変えられる物理の値は今は重力と音速の基準だけで、どちらも地球の環境(D-480)。
2. **足す仕組み**: 世界の読み方(`script::ReactionTableSource`)に、足すパッケージのフォルダの一覧 `addedPackages` と、
   元のフォルダを読むか `readPackageRoot` を足した。足したものはほかのパッケージと同じ読み込み・同じ合わせ方・同じ表の版になる
   (再生ファイルは表の中身だけから作り直すので、棚が無くても再生できる)。
3. **依存**: 足すと依存も足す・外すと依存するものも外す(`script::MixAdd`・`MixRemove`)。依存の足りない一覧は足す前に誤り(`MixFolders`)。
4. **起動の引数** `--mix a,b,...`(依存も書く)。ブランクの世界(既定)は足したものだけを読む。サンプルの世界に足すと、
   同じ鍵を書くパッケージは足すだけの合わせ方(ADR-0031)で読まれない(警告に出る)。
5. **サンプルの世界(combustion_test)との関係は案 A(並べる)**。標準パッケージから作り直さない。
6. **標準パッケージの値は現実の値**: 熱伝導率に試験の倍率を掛けない(サンプルは掛けている。units.luau)。反応の速さはサンプルと同じ
   (熱分解だけ文献の値。ほかの 4 本は仮の値と明記。⑤ の場面で文献の値に替える)。
7. 試験の場面の「標準の値」(地球の重力・音速の基準)は engine/src/sim/world_physics.h から tests/standard_world_physics.h へ移した
   (エンジンに地球の値を置かない。D-454。standard_packages_test がパッケージと同じか確かめる)。

## 検討した代案と、採らなかった理由(作り手から見た違い)
サンプルの世界と標準パッケージの関係:
- **案 A(おすすめ・仮で実装): 並べる**(サンプルはそのまま、標準パッケージは別の棚)。
  - 作り手から見た違い: サンプルを開くと今までどおりすぐ動く(試験の倍率で火が伝導だけでも広がる)。標準パッケージを足した
    ブランクの世界は現実の値なので、伝導だけでは火がほとんど広がらない(放射 T-0028・気体の流れ T-0210 が入るまで)。
    同じ物質(酸素・セルロースなど)の値が 2 か所に書いてある(サンプルを直しても標準は変わらない)。今の試験・ハッシュは何も変わらない。
- **案 B: サンプルを標準パッケージの上に作り直す**(combustion_test が real_* に依存し、試験の倍率・木箱・魔素だけを持つ)。
  - 作り手から見た違い: 値が 1 か所になる。ただし熱伝導率の倍率を上書きするので、サンプルは「改造された世界」の印付きになるか、
    上書きを許す合わせ方(QUESTIONS Q8)が要る。記録のハッシュ(表の版)は中身が同じなら同じだが、Ar・CO2 が増えると変わる。
  - 取り消し: 案 A から案 B へは後で移れる(パッケージのファイルを書き換えるだけ)。逆は難しくない。
- **案 C: サンプルを消して、試験は標準パッケージを読む** — 今の試験の多く(木箱の延焼の値)が変わる。⑤ の場面ができてから考える。

棚の場所:
- **案 A(仮): data/standard の別の棚** — サンプルに混ざらない。足すのはミキサーか --mix だけ。
- **案 B: data/packages に置き、世界ごとに読むパッケージの一覧を持つ** — 世界の「読む一覧」の保存先(世界のファイル)が先に要る。

## 影響
- しやすくなる: ブランクの世界から、足したものだけが動く世界を作れる(D-455・D-457)。⑤ の場面は標準パッケージ + 場面のパッケージで作る。
- しにくくなる: 足した一覧は、今は起動の引数(--mix)とエディタの間だけ(世界のファイルに保存しない。セーブの形 15 で決める)。
- 未対応: 足した環境の値(重力)と初めのセル(earth_air)は、動いている世界に差し替えても効かない(表の法則だけ替わる。
  ADR-0176 の未対応 T-0444 と同じ)。効かせるには世界を作り直す(T-0453)。

## 追記(2026-10-13・T-0453)
- 影響の「未対応」のうち初めのセル(earth_air)・物は、ミキサーの「世界を作り直す」(今の表で刻み 0 から = 足した一覧を --mix で起動したのと同じ世界)で効く(ADR-0192。仮)。
  環境の値(重力)を差し替えの刻みで当てるのは T-0444。
