# ADR-0436 案 B の R3: 動いている粒と止まりかけの粒で降伏の上限を分ける形は採らない(研究の打ち切りの記録)

- Status: Rejected(研究の打ち切り。作業役 T-1004。既定は分けない = ADR-0430 のまま)
- 日付: 2026-10-22
- 決めた人: Claude(作業役 T-1004。打ち切り条件どおり)。採るかの見直しは R3 の判定と一緒にユーザー
- 関係: ADR-0428・ADR-0430・docs/design/21 §2.5・§5.2・T-0997・T-1004・T-1019・D-556・D-620

## 背景
ADR-0430(降伏の上限 = 書いた値 + 6°)で砂山は書いた値で止まるようになったが、柱の崩れの走る長さが 0.25 m で 5.25 → 4.25 m に縮んだ。
本物の粒は止まった粒が崩れ始める角度(静)と動いている粒が止まる角度(動)が違うので、上限を動いている粒 = 書いた値・止まっている粒 = 書いた値 + 差に分けて、
走る長さを戻せるかを試した。

## 試したもの(2 本。`FlowOptions::grainMovingSpeedMmPerS`・`grainMovingByCell`。既定 0 / false)
1. 面ごと: 降伏の段の初めの面の粒の速さ(面の運動量 ÷ 面の粒の質量)が v_s 以上なら動いている。
2. セルごと: セルの横の面のどれかが v_s 以上ならそのセルの粒は動いている。両側のどちらかが動いているセルの面は動いている。
- どちらも状態(前の刻みから持ち越した面の運動量)だけで決まり、決定的。v_s は 50・150 mm/s。

## 結果(φ 34°・差 6°。詳しくは T-1004 の表)
- 砂山はどれも書いた値 ±4°(芯 30〜34°)・0.5 m と 0.25 m の差 ≤ 2°。
- 柱の崩れ 0.25 m は 4.25〜4.50 m で、差 0 の 5.25 m に戻らない(0.5 m は 4.50 m のまま)。
- 走る前の面(粒が来たばかり)は運動量 0 で静の上限になるので、1 本目は先頭がいつも静の上限で止まる。2 本目は先頭も動く側に入れて 0.25 m が 4.50 m に伸びたが、
  山は 30° に下がった。動の上限を使う範囲を広げるほど、走る長さと同じ割合で止まる角度も下がる。

## 決定
- 採らない(既定は分けない)。この降伏の形では走る長さと止まる角度が 1 つの摩擦で結ばれていて、上限の分け方では両立しない(ADR-0430 の代案の見込みどおり)。
- 試作は残す(`grainMovingSpeedMmPerS` 既定 0。`case_b_r3_test <場面> <v_s>` で測り直せる)。

## 作り手から見た違い
- 無い(既定は ADR-0430 のまま)。

## 未確認・次
- 走る長さの不足の根は摩擦の値ではなく、落ちる柱の縦の運動量が当たって消え、横へ向きを変えないことの見込み(差 0 でも 0.5 m 4.50 m・実験 約 7.3 m)。→ T-1019
- 面ごと 50 mm/s は 45° の斜面を 20 秒で止め切った(動く粒 0 / 1 ‰。分けない形は 88 / 41 ‰)。砂山は 31° / 33°。採るかは R3 の判定の後。
