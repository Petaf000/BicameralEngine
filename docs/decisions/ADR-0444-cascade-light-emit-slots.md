# ADR-0444 距離ごとの段(R-R1)を速くする: 放つ面を最上段のブロックごとの組に分け、刻みで回す

- Status: Proposed(T-1010 の研究の 1 本目。Claude の案。Q147 の (A)〔数秒の平均で見る〕の見込みの上)
- **D-636 の注(2026-10-24 ユーザー決定)**: 距離ごとの段(RC)は土台として main に残し(t-1010-rc-fast を 2026-10-24 にマージ)、別の光の運び方を同じ場面で並べて研究する。合格した方を残す(ROADMAP T-1062)。記録: 瞬間の筋は RC では光線を増やしても減らない(T-0959)。筋の合格の見方(瞬間 / 数秒の平均)は研究の結果で決める
- 日付: 2026-10-22
- 決めた人: Claude(T-1010)
- 設計: docs/design/23-radiation.md §3.3・§3.4・§4 / 前: ADR-0432(GPU 版)

## 背景
T-0959 の測りで、照り返す地面があると焚き火 1 つでも地面全体が次の刻みに光源になり(放つ面 700〜6000)、RTX 3070 Ti で 64³ が 4.1〜7.7 ms/刻み。
費用の芯は段の袋の数で、袋の数は「光源のある最上段のブロックの数 × 升目」でほぼ決まる(遠い段ほど、光源が 1 つでもブロックの升目が全部埋まる)。

## 決定
1. **放つ面を最上段のブロック(2^(段 − 1) セル)ごとに組に分け、刻み % 組の数 が自分の組の刻みにだけ放つ**(`emitSlots`。組 = (bx + 3 bz + 5 by) mod 組の数)。
   自分の組でない刻みの光は**照り返しの持ち越しの表で待ち**、組の刻みにまとめて放つ。待つ光は表にあるので保存はそのまま(帳簿に held・kept の欄を足した)。
2. **熱で放つ光も待たせるかは選べる**(`thermalInSlots`)。セルは毎刻み放った分を失う(温度の動きは今と同じ)。光が届くのが組の刻みまで遅れる(最大 組の数 − 1 刻み)。
3. 組の数は奇数(升目の中のずらしの巡り 159 × 組の数 が 256 と互いに素で、組の刻みだけでも 16 × 16 を一巡する)。
4. 既定は 1(毎刻み全部。T-0959 と同じ結果)。

## 検討した代案
- 受けた量の多い面だけを放つ(閾値・重要度で選ぶ)→ 閾値の下の面の光をどこで放つかが要る。待たせて量が閾値を超えたら放つ形にすると、組と同じく保存は守れるが、
  放つ刻みが場所ごとにばらばらになり、袋の数(最上段のブロックの数)は減らない。組をブロックで揃える方が袋が減る。
- 照り返しを粗い段から出す(段 0 を飛ばす)→ 近くの区間を飛ぶので、照り返しの光が近くの壁を抜ける(壁の陰が崩れる)。採らない。
- 段の数を減らす・升目を粗くする → 筋が悪くなる(T-0958)。

## 作り手から見た違い(仮)
- 【エンジン】照り返し(と熱で放つ光)が最大 組の数 − 1 刻み(7 組で 0.1 秒・15 組で 0.23 秒)遅れて、まとめて届く。熱容量で均される見込み(D-443 ②)。
  1 刻みで見ると光は組の刻みにだけ来るので、瞬間の筋は今より大きい(Q147 の (A) では合格に入れない)。
