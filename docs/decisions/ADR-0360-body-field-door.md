# ADR-0360 物と場の口: 物のボクセルは場から見て「占める体積」と「対の面」の 2 つだけ。受け渡しは帳簿の 1 つの理由を通る

## 背景
- 08 §4 は「物の表面のボクセルと重なる場のセルの間で、熱・物質・運動量を受け渡す」とだけ書き、形が無い。今の物は直方体で中身を持たず、
  場との間は物理の熱(PxHeatEntry → 帳簿の理由「物理の熱」)だけ。水は物を知らず(浮かない・押しのけない)、物は水を知らない。
- 物と場の間を現象ごと(浮力・抗力・燃える表面・接触の熱・扉を押す圧力)に別の式で書くと、物専用の法則と境目のバグが増える(D-520 ②)。

## 決定(仮)
### 一つの芯
**量の持ち主はいつも一人(セルか物のボクセル)。場と物の間の道は 2 つだけ**:
1. **占める体積**(場 ← 物の形): 物のボクセルがセルに占める体積を、見立ての固体の体積に足す。水・気体から見ると、物は砂・岩と同じ「詰まった所」。
2. **対の面**(場 ⇄ 物の中身と力): 物の表面のボクセルと、それが重なるセルを「対」(20 §2.3。離れた 2 セルの面の一般化)として面の帳簿に置く。
   熱・物質・力積はこの対を、セルどうしと同じ流れの種類・同じ当てる段・同じ上限で通る。**物専用の流れの式を作らない**。
- 帳簿: 対を通った量はすべて世界の帳簿の**理由 2 を広げた「物との受け渡し」**(今の「物理の熱」を含む)に出・入として載る。
  物の側は同じ量を物の帳簿に持ち、保存の検査は「Σ セル + Σ 物 − 帳簿(物との受け渡しを除く理由)= 一定」の 1 関数に広げる(ADR-0331 の 2)。

### 1. 物の中身(08 §1 を最初の版で形にする。T-0821)
- 物 = 物の局所の格子のボクセル(最初は 1 物 1 レベル。既定はセルと同じ 0.5 m・`voxel_level` で細かく)。各ボクセルはセルと同じ中身(物質の量・エネルギー)。
- **質量・慣性は中身から数える**(量の持ち主が一人。`mass_g` との二重を作らない。**判断待ち C**)。燃えて減れば数え直す(08 §4)。空になったボクセルは物から消える。
- 物のボクセルの中の反応・熱の伝導はセルと同じ共有 .hlsli を呼ぶ(物専用の法則 0。D-520)。物の中の面(ボクセルどうし)は物の中の伝導の面。

### 2. 占める体積(T-0820)
- **占める層**: 刻みごとに、物理の刻みの後、物の姿勢と形からセルごとの「物が占める体積」と「どの物がどれだけ」(上位 4 物まで・溢れは上限の計器)を作る。
  数え方はセルを 4³ = 64 点に分け、点が物のボクセルの中かを整数で判定して数える(体積の単位 = セルの 1/64。CPU と GPU で同じ関数・順によらない)。
- **永続しない**(見立てと同じ): 物の姿勢から毎回作るので保存点・ハッシュに入れない。占める体積が変わったセルを起こす(当てる段の 6 と同じ)。
- 見立ての入力を 1 つ足す: `MakeCellView(表, セル, レベル, 基準の圧力, 占める体積)`。空き(液体・気体)と液体の入れる体積は「固体 + 占める体積」から作る。
  熱容量・質量・物質量には足さない(中身は物の持ち物)。物の無い世界は占める体積 0 = 今とビット一致。
- 物が入ってきたセルの液体・気体は、入れる体積が減って満ち具合・圧力が上がり、今の流れで押し出される(押しのけ・水位が上がる。式を足さない)。

### 3. 対の面(T-0821・T-0798)
- 対 = (物のボクセル, 重なるセル, 重なりの点の数)。面の広さは重なりの点の数から(仮。T-0798 で測る)。違うレベルは細かい側が数え、粗い側は端数(ADR-0017)。
- 対を流す種類(最初の版): **熱の伝導**(面の式は HcFaceFlow のまま)・**気体**(物のボクセルの気体の空き〔孔〕を通って酸素が入り煙が出る。燃える木の表面)。
  液体の濡れ・染みは同じ形で後(吸い上げ・孔の欄がそのまま効く)。
- 世界の約束の `Add` は持ち主で分かれる(セル → 変化の表、物のボクセル → 物の変化の表)。当てる段の上限・帳簿・起こすは同じ。
- 物どうしの接触の熱(燃える物が触れた物を熱する)も、接触点の 2 つのボクセルの対で同じ伝導を流す(物理の摩擦の熱はそのボクセルへ。D-520)。

### 4. 力(T-0755・T-0798)
- **壁の力積の列を物へ**: 流体の面の流れが「占める体積」で塞がれて受けた力積(今は世界の帳簿の「壁の力積」へ消えている分)のうち、物の占めた分の割合を、
  その物の「受けた力積と回転の力積」(物ごと・刻みごと。重さの中心のまわり)に足し、帳簿は「物との受け渡し」の運動量の列へ。次の刻みの物理の入力(20 §2.5 の入力)。
- 浮く・沈む・水や風に押される・圧力が扉を押す・水車は、この 1 つの道から出る(浮力の式を書かない)。
- 物の動きが流体を押す向き: 占める体積の変化(押しのけ)と、対を通る運動量(物の速さとの差)。後者の形は T-0798 の研究。
- 物から見た場の固体: 据わる・ばらける固体のセル(固体の体積が半分以上のセル。しきい値は仮)は物の接触で**動かないボクセル**として当たる。反作用は世界の帳簿の「壁の力積」(ADR-0359 判断待ち B 案 1)。

### 5. 持ち主の約束と変換
- **セル ⇄ 物の変換は作らない**(D-520 ②)。物の中で燃えて出た気体は対を通ってセルへ出る(変換ではなく受け渡し)。灰など固体の生成物は物のボクセルに残る。
- 後で要るとわかった時の原則(BACKLOG・D-520): 変換は当てる段の中で一度に移す・帳簿に載せる・開発ビルドで保存の検査を毎刻み・往復の乱数の試験。
  セル → 物は支えを失った時の 1 回だけ(崖・洞窟の岩・流氷)、物 → セルはばらける物質の物が眠った時だけ(瓦礫 → 砂)。置き場は M5。
- 速くて細い物(矢)の掃く形・CCD は M6(D-520)。最初の版の占める層は刻みの終わりの姿勢だけを見る(1 刻みに数セル動く物はすり抜けうる。上限の計器で数える)。

### 6. 刻みの順(20 §2.5 に入れる所)
入力(コマンド・**前の刻みに物が受けた力積**・物理の熱)→ 物理の刻み → **占める層を作る** → 表の差し替え → [見立て → … 種類の小刻み(対も流す)] → 反応(セルと物のボクセル)→ 次の種。
力積は 1 刻み遅れて物に当たる(陽)。軽い物が重い水で暴れるなら T-0798 の 2 本目(陰・付加質量)。

## 判断待ち(ユーザー)
- **C 物の重さの書き方**(作り手が橋を書く時の違い):
  - 案 1(おすすめ)中身で書く: `world_bodies` に `fill_umol = { wood = ... }`(world_cells の `amounts_umol` と同じ書き方)。重さ・慣性・燃える・浮くは中身から決まる。
    `mass_g` だけの物(中身なし)は読み込みが警告し、燃えない・熱を持たない「法則の外の物」として動く(今のサンプルの積み木を残すため。後で消す)。
  - 案 2 `mass_g` と `fill_umol` を両方書ける: 重さと中身が食い違える(燃えても軽くならない・浮き方が中身と合わない)。量の持ち主が 2 つ。
- **D 地面は何で書くか**(作り手が地形を書く時の違い):
  - 案 1(おすすめ)地形はセル(据わる固体)だけ: 物は場の固体のセルに当たる。地面の物(今のサンプルの `ground`)は要らなくなる。水も物も同じ地面を見る。
  - 案 2 地面は今どおり動かない物でも書ける: 二重に書けて、水は通るのに物は止まる地面(か逆)ができる。

## 代案(採らない)
- 現象ごとの式(浮力 = ρ g V・抗力の係数・燃える表面の酸素の式): 物専用の法則になり、セルの燃え方と食い違う。値を作り手が 2 か所に書く。
- 物の体積を見立てに入れず、物のボクセルをセルへ一時的に書き込む: 量の持ち主が刻みの中で 2 つになり、写しの後始末(ADR-0333 で消した形)が戻る。
- 物どうしの熱を物理の側の別の式で: セルと物で伝導の式が 2 つになる。

## 影響
- 作り手: `world_bodies` に中身を書く(重さは書かない)。浮く・燃える・押されるは物質の値だけで決まる。
- エンジン: 見立ての入力 1 つ・占める層(永続しない)・対の面(面の帳簿にもう 1 つの面の出どころ)・物の変化の表・帳簿の理由 2 の意味を広げる・保存の検査に物の和。
  物理には「受けた力積」の入力と「場の固体のボクセル」の当たりが入る(今の地面の物は試験の都合で残す)。
- 試験: 物の無い世界で今とビット一致・水に木を浮かべる / 石を沈めて水位が上がる / 木の物が燃える(セル + 物 − 帳簿 が毎刻み一定)/ 扉を圧力が押す・CPU と GPU のビット一致。

## 未確認
- 占める層を毎刻み作る費用(物の数 × 重なるセル × 64 点)。動かない物・眠った物は作り直さない見込み。
- 4³ の点で浮き方がどれだけ段々になるか(1/64 の体積の段で水面の高さ 1/4 セル = 12.5 cm)。
- 対の面の広さを点の数から決めた時の熱の伝わり方(同じ物をセルで置いた時と比べる)。
- 1 刻み遅れの力積で、軽い物が重い水に入った時に暴れないか(T-0798 の研究の芯)。
