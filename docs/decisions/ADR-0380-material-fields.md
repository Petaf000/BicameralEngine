# ADR-0380 物質の欄の約束: 値は温度の表で変えてよい・混ざった所の値は値ごとにエンジンが物理の混ぜ方で出す・摩擦は物質ごとのすべりやすさを組み合わせる

## 決定
1. **温度の表**(S16): どの物質の値も、温度(K)と値の組の列で書ける。書かなければ一定。相の変化(反応)とは別。ベイクで整数の表にし、区分線形に引く(表の外は端の値)。
   表を引くのは値を読む所の 1 か所(CPU と GPU で同じ .hlsli)。眠った所では引かない。
2. **混ざった所の値**(S23): 1 つのセル・物のボクセルに物質が混ざる時の値は、**値ごとに物理の混ぜ方をエンジンが持つ**(作り手は書かない)。
   熱の容量 = 足し算 / 熱の通しやすさ = 混ざり方の式 / 粘り = 固い物が増えると急に上がる式 / くっつく強さ = 濡れの式 / 硬さ・強さ = 固い物の割合で弱める式。
   **混ざったら反応で別の物質にする書き方(土 + 水 → 泥)も使える**(作り手が自分で値を決めたい時)。粗くした箱の値も同じ決め方で出す(S43)。
3. **摩擦**(S18): 物質ごとのすべりやすさ 1 つ。接触の摩擦は 2 つを組み合わせる規則(組ごとの表は作らない)。間に挟まった物(液体・粒・溶けた水)の割合で、挟まった物のすべりやすさへ寄せる。
4. 何も書かない世界は今とビット一致(温度の表なし = 一定・混ざりの式は書いた値が 1 種なら元の値・摩擦の値が無ければ今の既定)。

## 案と見送った理由
- 混ざりを体積の割合の平均だけで: 泥が水と土の間くらいにしか粘らない・濡れた砂と乾いた砂の熱の差が小さい。
- 混ざりを反応だけで(c 案だけ): 物質の組の数だけ書くことになる(既定にはしない。使えるようには残す)。
- 摩擦を組ごとの表で: 物質の数の 2 乗の表を作り手が書くことになる。

## 未確認
- 各式を整数で決定的に・表の 1 行で書けるか・費用(値ごとに式が 1 つずつ増える)。
- 温度の表を引く費用。挟まった物を接触の点ごとに引く費用。
