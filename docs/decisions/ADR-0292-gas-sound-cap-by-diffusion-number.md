# ADR-0292 熱いセルの音速の頭打ちの温度を、圧力の拡散の数で決める(T-0631)

- Status: Proposed(数値の正しさの直し。作り手から見た違いは下の「影響」。D-461〔Q32 案 D: 頭打ちを安定の上限まで上げる〕の意図は変えない)
- 日付: 2026-10-17
- 決めた人: Claude(T-0631 の作業役)

## 背景
- 陽解法の気体(gas_reference・gas_tree・GPU の gas_step)は、熱いセルの p̃ を T_頭 ÷ T 倍して実効の音速を抑える(T-0226・T-0269・D-461)。
- T-0269 は T_頭 = T_基準 ×(上限 ÷ c̃)²(既定 約 473 K)にした。これは音の速さの数 c_e Δt ÷ Δx ≤ 0.6 だけを見ている。
- 面の質量の流れの圧力の拡散は Δp̃ × A Δt ÷ 4c̃ で、c̃ は世界の基準のまま。熱いセルの拡散の数は c_e² ÷ c̃ × Δt ÷ Δx(c_e = c̃ のとき ν_c̃)で、
  c_e > c̃ では音の速さの数より大きい。市松(奇偶)のモードには中心の流れも面の力積も応じない(面の平均で消える)ので、拡散の数が境を超えると
  1 小刻みごとに育ち、出ていく割合の上限で止まるまで抜けて真空のセルができる(T-0631。仮の世界の燃える木箱の断面の市松)。

## 決定
- T_頭 = T_基準 × 上限 ÷ c̃(`GasSoundCapTemperature`。切り捨て)。拡散の数が上限の ν(1 レベルの箱 0.6・木は細かいレベルの分だけ小さい)に届く温度。
  既定(340 m/s・小刻み 24・293.15 K)で約 372 K、実効の音速の上限は 約 383 m/s(T-0269 は 432 m/s)。
- 係数は CPU が作って GPU に渡す(GasGpuParameters::soundTemperature)ので、シェーダーは変えない。CPU と GPU の一致・保存は今まで通り。

## 影響
- 作り手から見て: 372 K より熱い気体の中で、圧力の波(音・爆風の芯の押し合い)が 432 → 383 m/s で伝わる(本物は 1500 K で約 770 m/s。どちらも遅い)。
  冷たい空気の中の音・衝撃波の速さは変わらない(管の試験は同じ数)。熱い所の市松(1 セルおきに 1000 K 超と 0 K)が消える(空気・CO2・湯気の等圧の塊)。
- 数が動いた試験: gas_reference の strong pressure(1500 K の 1 セル)の 2 秒後の最大の速さ 1.35 → 2.04 m/s・5 倍の衝撃波の幅がわずか。
  probe_gas の燃える木箱(2 秒): 熱の重心 11636 → 11781・CO2 の重心 10120 → 4595・CO2 1 mol 以上の最も高い層 22 → 3
  (見込み・未確認: 前は市松の抜けたセルを通って煙が上へ運ばれていた。T-0646 の直しの数とも並べて見る)。
- 残り(T-0658): まだ温度だけで比べる。拡散の数は p/ρ = RT/M に比例するので、空気より軽い気体(湯気 M 18)は同じ温度で 1.6 倍。
  比熱の比 γ の違い(単原子 1.67)も見ていない。p/ρ(と γ)で比べる形にすると CPU・木・GPU の 3 か所の導く値が変わる。

## 代案(採らなかった)
- 圧力の拡散を局所の音速で割る(素の Rusanov の λ = 局所の速さ): 頭打ちを 473 K のままにできるが、面ごとに平方根(整数)が要り、
  冷たい空気の数も全部変わる。今の形の係数 1 つの直しで足りるので採らない(T-0658 で p/ρ にする時に見直してよい)。
- 小刻みを増やす: 費用が増える(D-468)。
