# ADR-0220 引きずりの一般の形: 「運ぶ」と「交差(結合の強さ q)」

- Status: Accepted(2026-10-17 ユーザー決定。D-503。表の書き方は ADR-0238)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
D-487 ④: 「X の流れが Y をどれだけ引きずるか」を作り手が表に書ける一般の形を ③ で作る(書きすぎると永久機関になる値はベイクが落とす)。
D-466 は「魔素は物質の一つで、どんな坂を持ち何をどれだけ引きずるかをゲームが決める」。今のエンジンの引きずりは、気体が自分の中身(熱・成分・運動量)を運ぶもの(07 §2)だけで、
散逸の流れどうしの結合(熱の流れが成分を動かす など)を書く所が無い(19 §2.3 の G3)。

## 決定(案)
引きずりを 2 つの形に分ける(GENERIC の 2 つの部分。19 §2.1 の P3)。
1. **運ぶ**(可逆の部分): 流れる物(気体・水・物)は、自分の中にある量(熱・成分・運動量)を同じ割合で運ぶ。係数は 1 に決まっていて作り手は書かない
   (書けると「中身を作る・消す」になる)。作り手が決めるのは、何がどの流れる物の中にあるか(相・置き場所)だけ。今の気体の形(07 §2)がこれ。
2. **交差**(散逸の部分。Onsager の交差の係数): 坂 X で動く流れが、量 Y も動かす。作り手は**結合の強さ q(−1〜1)**を書く
   (Kedem–Caplan の結合度。+ は X の流れと同じ向きへ Y を動かす)。エンジンは交差の係数を **L_xy = q √(L_xx L_yy)** で作り、
   逆向きの引きずり(Y の坂が X を動かす)も同じ係数で自動で入れる(相反)。|q| ≤ 1 なら結合の行列は半正定で、どの状態でも坂を上らない。
   - 整数: K = |q| を切り捨て × √(…) を切り捨て で作るので、丸めた後も K² ≤ q² L_xx L_yy(半正定のまま)。セルごとの熱のキャッシュと同じく √ をキャッシュに置けば、
     面では両側の小さい方を使っても半正定のまま(√min = min √)。
   - **ベイク**: |q| > 1 は警告して ±1 に押さえる(D-487 ②「警告して動かす」)。
   - |q| = 1 は「結合しきった」理想の機械: ある組み合わせ(模型では温度と濃さの組)が坂を下らずに残り、閉じた系でも一様にならない。永久機関ではない(エントロピーは減らない)。
   - 坂を上らせる構造(T-0495)の効率の上限は q だけで決まる(η_max = q² ÷ (1 + √(1 − q²))²)。同じ q を使える見込み(未確認。T-0495 で確かめる)。
3. **表の書き方(仮のおすすめ)**: 反応表と並ぶ独立の分類 `drags`(1 行 = 流れ X・引きずられる量 Y・q・どこで〔物質・相〕)。値は q。
   案と作り手から見た違いは docs/tickets/T-0493-drag-general-form.md。

## 検討した代案と、採らなかった理由
- 物理の係数(Soret 係数など)を直接書く: 現実の値を写せるが、坂を上らない上限 √(L_xx L_yy) が温度・濃さで変わるので、ベイクで保証できず、実行時に面ごとに押さえることになる
  (書いた値と効く値が場所で違う)。q の形なら保証が式の形で、状態によらない。現実の係数から q への換算は道具(パネル)で出す。
- 交差の係数を両方向とも作り手が書く: 相反(L_xy = L_yx)が崩れると坂を上る組ができる。1 つの値から両方を作る。
- 運ぶの係数(割合)を作り手が書く: 1 以外は中身を作る・消す(保存が崩れる)か、選り分け(仕事なしで濃さの差を作る)になる。粉が気体に一部だけ乗る、のような滑りは「運ぶ + 交差(相対の流れ)」で書く(後で)。

## 影響(何がしやすく/しにくくなるか)
- 作り手は −1〜1 の 1 つの数で引きずりを書け、どんな値でも(押さえた後は)永久機関にならない。現実の係数をそのまま写すには換算が要る。
- エンジンは流れの種類ごとに「坂」と「直接の係数 L_xx」を持つ必要がある(熱・成分の拡散。成分の拡散は気体の中にまだ無い = 19 §2.2)。
- 模型: tests/drag_model_test.cpp(T-0493)。世界への組み込みは T-0186・T-0210 と、成分の拡散が入った後。
