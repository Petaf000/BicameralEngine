# ADR-0259 気体の比熱を定圧で書き、ベイクが定積の比熱 c_v = c_p − R を作る(表ごとの選択。T-0591)

- Status: Accepted(2026-10-17 ユーザー決定。D-506 = 案 A〔既定オン〕。QUESTIONS Q87 を閉じた)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- セル(RxCell)は体積が一定なので、反応・伝導・気体の段の温度は定積の比熱で読むのが正しい(気体の段の式は c_v を前提。T-0234)。
- 標準パッケージ real_matter の比熱は NIST-JANAF の定圧の比熱 c_p(N2 29.124 J/(mol·K))で、エンジンはそれを定積として読んでいた。
  気体は同じ熱で温まり方が約 3 割小さく、比熱比 γ・断熱の冷え方もずれる。

## 決定(仮)
- 表に選択 `ReactionTableDefinition::gasHeatCapacityAtConstantPressure` を足した(既定 false = 今まで: 書いた値をそのまま定積として読む)。
  true の表は、凝縮相でない物質(condensed = false)の比熱を c_v = c_p − R(R = 8314 mJ/(mol·K))にしてベイクする。凝縮相はそのまま。
  H0 は書いた c_p から作る(298.15 K の内部エネルギー = 生成エンタルピー − RT。閉じたセルの反応熱 ΔU = ΔH − Δn_気体 RT が出る)。
  気体の c_p が R 以下ならベイクが断る(凝縮相の書き忘れの多く)。
- 今は C++ の試験(probe_gas_test の地球の空気)だけが true にしている。パッケージから書く場所と既定は T-0597。

## 判断待ち(作り手から見た違い)
- 案 A(おすすめ): **既定を true にする**(作り手は資料の c_p をそのまま書く。凝縮相に condensed = true を書くことが要る)。
  違い: real_matter の世界の気体が今より熱くなる(同じ熱で N2 は 29.1 ÷ 20.8 ≒ 1.4 倍温まる)。場面の数値と GPU の試験の期待値が動くので、
  切り替えの時に測り直す。condensed を書き忘れた固体・液体は R だけ比熱が小さくなるか、断られる。
- 案 B: 今のまま(書く値を c_v とする。作り手が資料の値から R を引いて書く)。違い: 資料の値と書く値が食い違う。
- 案 C: 表(パッケージ)ごとに宣言する(この ADR の形のまま、パッケージに書く場所を足す)。
- 相(M2)が入ったら「凝縮相でない」を相で決める(ADR-0230・T-0590 の判断待ち 2 と同じ)。

## 追記 1(2026-10-17・ユーザー決定 D-506)
- 案 A に決めた: **既定を true にする**(作り手は資料の定圧の比熱 c_p をそのまま書き、ベイクが c_v = c_p − R を作る)。
  パッケージの書き場所・型・読み込み・既定の切り替えと、場面の数値・GPU の試験の期待値の測り直しは T-0597。
