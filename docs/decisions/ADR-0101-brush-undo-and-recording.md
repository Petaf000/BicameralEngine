# ADR-0101 筆の元に戻すは「保存点へ戻し、その運びを除いて今の刻みまで流し直す」。記録には最後の流れだけを残す

- Status: Accepted(方向は 14 §1「元に戻す・やり直しは CPU の文書の上で行い、GPU の世界は文書と『ここからの再生』で作り直す」と
  ADR-0089 §4。記録への残し方・戻せない場合の扱い・追いつき方は実装の細部として Claude が決めた。CLAUDE.md §5。
  ユーザー未確認の点はチケット T-0278 の「判断待ち」)
- 日付: 2026-10-11
- 決めた人: Claude(T-0278)

## 背景
- 筆(T-0222・T-0245)の置く操作は、どれも置くコマンドとして GPU のキューへ入り、再生ファイルに記録される(ADR-0067・ADR-0089)。
- 「元に戻す」で、その運び(1 回のクリック・1 回のドラッグ)が無かった世界にしたい。逆のコマンドでは戻らない
  (置く前のセルの中身は GPU にしか無く〔D-107〕、置いた後に進んだ反応も戻らない。ADR-0089 の代案)。
- 巻き戻し(T-0143・ADR-0036)は保存点 S(t) と「t 以降のコマンドの足し直し」で戻る。足し直す列から運びを除けば、
  決定性(ADR-0008)により「その運びが無かった世界」そのものになる。
- 今の巻き戻しは、記録中(`--record`)・`--check-physics`・トレースの間は使えなかった(ADR-0036)。

## 決定
1. **運び = 押してから、離して置き終えるまでに作った置くコマンドの番号(sequence)の列**。筆のパネル(editor/brush_panel)が
   運びごとに控える(最大 64。古いものから忘れる)。1 フレームに置ききれず次のフレームへ続いた分も同じ運び。
2. **元に戻す(パネルのボタン・Ctrl+Z)= 最後の運びを除く**(editor/brush_undo。CPU だけの計算。brush_undo_test):
   - まだ GPU へ足していない分(フレームのループで待っている)は、除くだけ。
   - GPU へ足した分があれば、その運びが最初に当たる刻み f 以前でいちばん新しい保存点 s(s ≤ f。S(s) に刻み s のコマンドは
     まだ入っていない)へ戻し、今の流れの控え・足し直しを待つ列からその運びを除いて、戻す前の刻みまで流し直す。
   - 流し直しは **現実の時間を待たずに追いつく**(SimScheduler::CatchUpTo。止めていても進む。1 フレームの予算はそのまま)。
     ふつうの巻き戻し(ビデオの巻き戻し。T-0143 の判断待ち A)は今まで通り、戻した刻みから現実の速さで進む。
   - 運びより後の操作(つつき・押す・ほかの運び)はそのまま残る(足し直す)。
3. **記録(再生ファイル)には、元に戻した後の最後の流れだけを残す。元に戻す操作の印は残さない**:
   巻き戻すと記録(save::ReplayRecorder::Rewind)も戻した刻みから先のコマンドと S(s + 1) から先のハッシュを捨て、流し直した分を
   書き直す。元に戻した運びは足し直されないので記録に入らない。再生は今まで通り「コマンドの列を流すだけ」で、
   元に戻した世界と同じハッシュ列になる(= その運びが無かった世界)。
   これに合わせて **記録中も巻き戻せるようにした**(ふつうの巻き戻しも同じ道で記録を書き直す。足し直す列は同じなので記録は変わらない)。
4. **戻せない時**(パネルに理由を出し、運びは控えに残す):
   - 運びが最初に当たった刻み以前の保存点が無い(古すぎる運び。`--editor` の既定は 120 刻みごとに 6 個 = 約 12 秒前まで。
     起動して最初の保存点〔刻み 120〕より前の運びも戻せない)。
   - `--check-physics`・トレースを集めている間(ADR-0036 と同じ。刻みが一度ずつ進む前提の道具)。
   - 塗っている途中(押している・置ききれない分が残っている)・別の巻き戻しを待っている間。
   - 戻す保存点の刻み以後に反応表を差し替えた(巻き戻しは差し替えの印を足し直さないので、記録からも世界からも落ちる)。
     記録中のふつうの巻き戻しも同じ理由で差し替えより前へは戻さない。
5. **確かめ方**: `--auto-place` を広げた(ctest window_place_record・window_place_play): 円柱(5 個)の運びの後につつき、
   円柱 → 直方体のドラッグ(13 個・2 フレームに分かれた 1 つの運び)の順に元に戻す。それぞれ、戻す前に読み戻した最後の
   刻みの状態と、流し直した同じ刻みの状態が違う(運びが世界を変えていて、本当に除けた)こと・残って当たった置くコマンドが
   はず通り(5 個)であることを確かめ、記録する。別の起動の `--replay` が同じハッシュ列 = 元に戻した世界と「置かなかった記録」が一致。

## 検討した代案と、採らなかった理由
- **記録に「元に戻した」の印(新しいコマンドの種類)を残し、再生も巻き戻して流し直す**: 「何をしたか」の履歴は残るが、
  再生が保存点を持たないと流し直せない(仮の世界は再生にも保存点が要る)。GPU には何もしない印のコマンドが増え、再生の突き合わせが
  巻き戻しの有無に依存する。操作の履歴が要るなら、世界の列とは別の欄(ADR-0035 の「見る側の操作の列」と同じ扱い)に後から足せる。
- **記録中は元に戻せない(今まで通り)**: 筆で作って記録して確かめる流れ(D-449)が切れる。記録の切り詰めは CPU の帳簿だけで済む。
- **元に戻した後、保存点の刻みから現実の速さで進める(ビデオの巻き戻しと同じ)**: 元に戻すたびに世界が数秒前へ飛び、
  止めて作業していると「戻した結果」が見えない。追いつく方が「その運びだけが消えた」に見える。
- **最初から流し直す(刻み 0 から)**: 保存点が無くても戻せるが、長く遊んだ後ほど遅い(ADR-0036 と同じ)。刻み 0 の保存点を作る
  (初期化の後に写す)のは別の話として残す(判断待ちに書いた)。

## 影響(何がしやすく/しにくくなるか)
- しやすい: 筆で置き間違えた運びだけを、後の操作を残したまま消せる。記録しながら作って直せる(記録は直した後の流れ)。
  止めている間でも、元に戻した結果がすぐ見える。
- しにくい: 保存点より古い運びは戻せない(保存点を増やすと VRAM が要る。1 つ約 33 MiB)。やり直し(Redo)は無い(取っておいた
  運びのコマンドを新しい刻みで足し直すことはできるが、元の刻みには戻らない。要るなら別のチケット)。
  元に戻す操作そのものは記録に残らない(操作の履歴を見返すことはできない)。流し直しの間(保存点の間隔ぶん)は重い。

## 追記 1(2026-10-13・T-0411・D-474 ②): 刻み 0 の保存点
- **決定(D-474 ② はユーザーの答え。下の数え方と古い運びの扱いは Claude の仮。ユーザー未確認。T-0411 の「判断待ち」)**:
  保存点を使う起動(`--editor` の既定・`--save-points n` が 1 以上)では、`--save-points` の数とは**別に 1 つ**、刻み 0 の保存点を作る
  (VRAM が 1 つ分〔仮の世界 + 積み木で約 33 MiB〕増える)。刻み 0 の保存点は回して上書きしない・捨てない
  (巻き戻しで先の保存点を捨てる時も残る)。捨てるのは反応表を差し替えた時だけ(ほかの保存点と同じ。ADR-0047 §6)。
  回す保存点は今まで通り `--save-interval` の倍数の刻み(120・240…)で、`--save-points` の数を古いものから上書きする。
- **写し方**: 保存点を使うなら、最初のリストは世界の初期化だけにする(単位もコマンドも足さない)。次のリストの先頭で S(0) を写す
  (写すのはリストの先頭で、バッファが COMMON の時だけ。初期化と同じリストでは写せない。frame_loop の SubmitSim・SaveSlotFor)。
  いつ投げるかが 1 フレーム遅れるだけで、世界のハッシュ列は変わらない(gpu_probe_rewind の刻み 0 の試験)。
- **元に戻す**: 選び方(PlanBrushUndo。運びが最初に当たった刻み以前でいちばん新しい保存点)は変えない。刻み 0〜119 の運びは刻み 0 へ戻して
  流し直す。回す保存点より古い運び(約 12 秒より前)も、刻み 0 の保存点があれば刻み 0 から流し直して戻せる
  (「古すぎて戻せない」は反応表を差し替えた後だけになる)。流し直しは今の刻みまでの全部(長く動かした後ほど時間がかかる。
  上の代案の「最初から流し直す」の重さ)。
- 記録は今まで通り元に戻した後の流れだけ(D-474 ①)。再生ファイルの形式は変えない。やり直し(Redo)は入れない。
- 時間のパネルの巻き戻しにも刻み 0 が出る(いつでも最初の状態へ戻れる)。`--auto-rewind`(「保存点が 2 つできたら古い方へ」)は刻み 0 へ戻す。
