# ADR-0509 支えの法則: 違う大きさの面の対の負の項に、粗いセルの隣から読む一様な歪みを目標に材料の硬さを残す(ADR-0485 ④ の直し・案)

- Status: Proposed(Claude 案・T-1278。CPU。**既定は今まで〔None〕のまま。既定にするかはユーザーの判断**)
- 日付: 2026-10-30
- 決めた人: Claude(wt3 の作業役)
- 関係: ADR-0485(対のずれ)・ADR-0501(対の曲げ)・ADR-0504・設計 22 §3.2・§3.5・T-1260・T-1261・T-1278

## 背景
ADR-0485 の対のずれの負の項 −½ K (d_U − d_L)² は、粗いセル C の面に並ぶ 2 つの細かいセル L・U の相対の動きを「C が剛体で表せない」として全部 C から外す。
根の角(壁と梁の根の線の両側だけを分けた場面)では、C の中で強く変わる伸びまで外し、たわみが全部 0.25 m の 1.056(T-1260)。
T-1261 は C の材料の硬さを直列で残したが(相対の動きの目標を 0 と置いた)、一様な縦の縮みを 2 度数えて洞窟の天井の細かい面が 3.42 → 10 %(つぎはぎの検査を壊す)。

## 決定(案)
- 対の相対の動き P(並ぶ向き p の面の点の差)の目標を、**C が表せる一様な歪み**にする。C の一様な歪みは新しい自由度を足さず、C の p の向きの隣(両側)の中心の差で読む:
  C の面の高さの繊維 f = t_p − σ ε φ の差 m = d (f_N − f_C) ÷ 2(固定した面の側は壁まで m = −d f_C)。足す項は側ごとに ½ (K_q ÷ 読める側の数) (P − 側 × m)²。
  K_q = 外した硬さ K と C の材料の硬さ 6 b_p の直列。負の項はそのまま(全部外す)なので、一様な歪み 3 つ・回り・一様な曲げでは P = m で今と同じ。
- 両側を 1 つの項にすると C の両隣(同じ色)が直接つながり C-0 の色の約束を壊すので、側ごとに分ける(節は L・U・C・隣の 4 つ。隣と L・U はレベルの差 1 の斜めの面)。
- 読めない側(隣が分けたセル・無い・面が割れた)は読まない。両側とも読めなければ足さない(今と同じ)。
- 比べ用の選択 `SupportOptions::mixedPairMaterial = MixedPairMaterial::NeighborStrain`(形 A)。曲げの負の項にも同じ形を当てる `NeighborStrainBend`(形 B)は外れ(記録用)。

## 残り・作り手から見た違い(既定にした場合)
- 作り手から見た違い: 書く値は無い。細かくする所の境で、細かい面の縁の力(割れの判定が読む)の偽の差が減り、周りを分けない設定(refineRing = 0)の
  根の角の柔らかさが約 5.6 % → 4.5 %(試験の線 6 % → 5 %)。代わりに対ごとに面が最大 12 増える(節の数は同じ)。
- ADR-0501 の残り 4.87 %(固定した面のすぐ横)はこの芯では消えない(形 A 4.83 %・形 B 5.25 %)。別の根(粗いセルの側の 2 次の離散化)。
- 根の角は 1.045 で、目標を 0 と置いた T-1261(1.031)までは届かない(隣から読む歪みが根の角の集中を平らに読む分と見ている・未確認)。
- 3 次元(T-0944)・GPU 版(gpu_equilibrium_block の支えの場面)への延ばしは未確認(同じ項を面のブロックに入れるだけの見込み)。→ T-1279 の追記を見る。

## 追記(T-1279・2026-10-30・wt3): 3 次元と GPU 版
- **GPU 版**: 支えの GPU は CPU が組んだ系(面の 3 × 3 のブロック)を写して解く(GpuEquilibriumBlock。段 0 を GPU で組むのは T-0981)ので、形 A は GPU の式を足さずに入る。
  gpu_equilibrium_block_test の違う大きさの 7 場面(壁と梁の根の線の両側の 2 場面を足した)を None と形 A の両方で、HW(RTX 3070 Ti)・WARP とも毎刻み CPU とビット一致(逆順も)。
  費用: 洞窟の天井と空洞の縁を 0.25 m(1288 節)の 1 回の解き 1.955 → 2.232 ms(+14 %。隣の数 +7 %・Dispatch は同じ)。
- **3 次元**: 支えの法則そのものがまだ 2 次元(3 次元は T-0960)。項の読み方は T-1279 §2: C の面の 2 × 2 の細かいセルの対 4 組それぞれに、面の中の向き(p・q)の
  C の隣から同じ (r_n, r_q) で読む繊維の歪み(3 次元ではねじれ ω_n r_q の分が増える)を目標に、同じ式。一様な歪み 6・回り 3・一様な曲げ・ねじれでは項が 0(机の上)。T-0960 で入れて測る。
- **既定にした時**: 既定を仮に形 A にして支えの CPU の試験 11 本(support_*・warm_start_save)が全部合格。割れの道で値が変わるのは違う大きさのセルを持つ場面だけ
  (片持ち梁の下りる道 93 → 94 kN/m〔全部 0.25 m の 94〕・周りなし 96 → 97・洞窟の下りる道の縦の割れ 7 → 5 面。T-1279 §4)。試験は既定に付いてくる形にした。
  既定を変えるのは support_law.h の 1 行(と ctest support_mixed_neighbor_strain の扱い)。既定にするかはユーザーの判断(Q182)のまま。
