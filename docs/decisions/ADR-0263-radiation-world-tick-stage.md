# ADR-0263 放射は世界の刻みの「気体の後・伝導と反応の前」の段。物質に a を書いた表でだけ動く

- Status: Proposed・保留(2026-10-17 ユーザー決定 D-501。CPU の段と測る道具は残す・GPU〔T-0586〕は保留)。**2026-10-21 ADR-0382 で読み替え**: 段の位置は S42 の刻みの 7(まっすぐ運ぶ。20 §2.5)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- T-0583(ADR-0252)で対の交換の式、T-0584(ADR-0262)で対の見つけ方ができた。世界の刻みのどこに入れるか、誰が入れるかを決める。
- 並走で刻みに段を足すチケットがある(T-0590/T-0591 気体・T-0027 水・T-0558 セルの量の上限)。順番の約束を書いておく。

## 決定(仮。ユーザー未確認)
1. **段の順**(仮の世界の CPU リファレンス `ProbeReference::Advance`): (1) コマンド → 物理の熱の入口 → (1b) 気体 → **(1c) 放射** → (2) 伝導と反応。
   放射は刻みの初めの温度(熱のキャッシュ)で対を交換し、その世代のエネルギーに足す(変わったセルは熱のキャッシュを作り直し、ブロックを予定の種にする。気体の段と同じ形)。
   伝導・反応とは段を分ける(演算子の分割)。どちらの段も 1 つで凸結合なので、続けても温度の順序は入れ替わらない。
2. **入れ方**: 今は CPU リファレンスだけで、呼ぶ側が `EnableRadiation` で入れる(GPU に無いので、GPU とビット一致を比べる試験の場面を変えないため)。
   GPU に入った後(T-0586)は、**表の物質のどれかが a を書いていれば動く**(世界ごとのスイッチを持たない)。ブランクの世界・今のパッケージは a を書いていないので放射なし。
3. 種(向きの組と線の格子)は世界の種(R6)。

## 検討した代案(作り手から見た違い)
- **2. の代案: 環境のパッケージに「放射を入れる」のスイッチを置く**: 作り手は物質に a を書いても、スイッチを入れ忘れると何も起きない
  (「書いたのに効かない」の迷いが 1 つ増える)。代わりに、重い段を世界ごとに明示的に切れる。→ 仮に採らない(重さは D-468 で器が持つ)。
- **1. の代案: 伝導と同じ段の中で足す(1 つの凸結合)**: 伝導 6/8 + 放射 1/4 の分け前で 1 つの段にでき、段が 1 つ減る。ただし伝導の核(GPU の
  ConductBlock)が放射の対の結果を待つことになり、段の間の受け渡しは同じだけ要る。分けた方が段ごとに試験できる。→ 採らない(仮)。

## 影響
- CPU リファレンスの重さ: 64³ の草原の場面で 1 刻み 22 ms → 約 110 ms(release・全部のセル・32 本。docs/perf.md)。
  T-0028 の打ち切り条件 (b) の「CPU リファレンスが 50 ms を超えたら場面の試験は 32³」に当たる(仮の世界の格子は 64 で決め打ちなので、試験は短い秒数で回す)。
- 並走の約束: Advance に段を足す時は (1b)(1c) の並びに足し、チケットに段の順を書く。
- 試験: `radiation_scene`(場面を 2 秒流す煙の試し)。測りは tests/radiation_scene_measure.cpp の先頭。

## 追記 1(2026-10-15・第 6 巡のマージ)
- 液体の段(T-0609・ADR-0266)と同じ巡目に入ったので、段の順は 適用 → 物理の熱 → 表の差し替え → (1b) 気体 → (1c) 液体 → **(1d) 放射** → 予定 → 伝導と反応 にした。
  放射は気体と液体が動かした後の温度と量で見通しと吸収率を決める(流れた煙が遮る)。

## 追記 2(2026-10-17・ユーザー決定 D-501。QUESTIONS Q86 を閉じた)
- 放射の段は保留(ADR-0262 の追記 1)。仮の世界の CPU リファレンスの段と場面の測る道具は残し、気体と草の現実の燃え方の後に同じ場面で測り直す。
