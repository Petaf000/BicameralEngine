# ADR-0543 占める層と対の面(重なり)を「物のボクセルの点が行き先の箱の並びのどの箱に入るか」を数える 1 つの関数で作る・止まりを眠りと置く判定に分ける

## 背景
ADR-0360 §2 は「セルを 4³ 点に分けて、点が物の中かを数える」、§3 は「対の広さは重なりの点の数から(仮)」としていた。ADR-0541 で行き先に地面の格子のボクセルが加わり、
物の熱の箱(ADR-0434)はセルより細かい物(7.8 mm)を持つ。行き先ごとに数え方を作ると、同じ物の体積が行き先の細かさで違って見える。占める層・対の面はまだ実装が無い(T-0820・T-0821 は Todo)。

## 決定(案)
1. 1 つの関数: 物のボクセル(姿勢つき)の点が、行き先の箱の並び(世界の木 / 地面の格子 / ほかの物の箱)のどの箱に入るかを整数で数える。行き先の違いは「点を持つ箱の引き」だけ。
2. 点のレベル = max(物のボクセル, 行き先の箱)+ 2。物の側から数え、写した 8 隅が同じ箱に入る塊は一度に足す。足し込みは整数の和(順に依らない)。
3. 占める量 = 物のボクセルの中身が使う体積(凝縮相 + 孔)。器の物は器の中の空間も占める。
4. 対の面(重なり)の広さ = 物のボクセルの表に出た面の広さを、点の割合で行き先の箱へ分ける。対の面(接触)は物の物理の接触の組から。
5. 止まりは 2 つ: 眠り(結果を変えない飛ばし。物の物理 T-0044)と、置く判定(層の置き場の法則。ADR-0541・T-1388)。占める層の作り直しは姿勢か形が変わった物だけ。

## 作り手から見た違い
- 浮き方・押しのけが物の中身の体積どおり(セルより小さい物・斜めの物でも。0.5 m のセルの 1/64 の段々が出ない)。燃えて減れば占める量も減る。
- 物がセルの境をまたいでも、熱・物質の出入りの広さは変わらない。
- 書く値は増えない。物の無い世界は今とビット一致。

## 退けた案
- B 行き先の箱ごとに 4³ 点(ADR-0360 §2 の書き方): 体積の段が 1/64 セル(水面で 12.5 cm)・小さい物が 0 か 1/64 に丸まる。
- C 物の箱の外接箱: 斜めの物・中空の物が大きく見える。
- b 対の広さを重なりの点の数から: 厚い物ほど広くなる・境をまたぐと変わる。
- 止まりを 1 つ(眠りで置く判定): 炎のふるまいが物の物理の飛ばし方に引きずられる。

## 追記 1(2026-11-13 wt5。決定 3 の前提の確かめ)
今の物の熱の箱は、骨格のボクセルに箱いっぱいの濃さの空気を持ち(紙は箱の 1.3 %・空気は 98.7 %)、囲むセルの気体は減らしていない(箱の体積を二重に数えている)。
決定 3 の「凝縮相 + 孔」は今の形と合わないので、**占める量 = 物の並びが持つ箱の体積の全部(骨格 + 運ぶ層)を仮のおすすめ**に改める(今の答えを変えない・1 点に 1 人の持ち主)。
比べと作り手から見た違いは docs/design/20 §7.4.10。T-1392 の関数はどちらでも同じ(ボクセルの重みだけ)。
