# ADR-0047 反応表のホットリロードは、刻みの境界の「印のコマンド + 表の写し + 熱のキャッシュの作り直し」で当てる

- Status: Accepted(実装の細部。CLAUDE.md §5。ユーザー未確認の点はチケット T-0139 の「判断待ち」)
- 日付: 2026-10-09
- 決めた人: Claude。T-0139

## 背景
- 13 §2・D-304: エディタがパッケージのファイルの変更を見て、読み直し → ベイク → 刻みの境界で表を当てる。記録をまたいでも再現できること(原則 3)。
- 表(法則のデータ)は CPU がベイクして渡す(原則 2・ADR-0033)。世界の状態(セル・熱のキャッシュ・ブロックの予定)は CPU が書き換えない(原則 1)。
- 待ちの丸め(ADR-0018)は「速さ f はセルと表だけで決まり、表を変えるものは範囲のブロックを『変わった』にしてから評価する」約束。
- セルは物質を ID で持つ(ADR-0032: 名前のバイト順)。物質の一覧が変わると ID の意味が変わる。

## 決定
1. **見る**: `--editor` のときだけ、数フレームごと(15 フレーム)にパッケージのフォルダと型の定義の中身の指紋(相対パス + 中身。時刻は使わない)を取る。
   変わった指紋を 2 回続けて見てから読む(保存の途中を読まない)。読み直しは LoadReactionTable(型検査・ベイクの検査。ADR-0046・0033)。
2. **当てられるか**: 物質の一覧(名前 = ID)・元素の一覧・物質の元素の組み立てが同じときだけ当てる。違えば当てずに理由を出す(足した・消した物質)。
   版(TableVersion)が同じならコメントだけの変更として何もしない。
3. **落ちたら**: 古い表のまま続け、誤り(ファイル:行:列)をエディタの「状態」パネルとログに出す。
4. **当て方**: CPU が、まだ記録していない最初の適用の単位の刻み t に
   (a) 印のコマンド PROBE_COMMAND_TYPE_TABLE(版)を足す(GPU の適用では何もしない。記録と再生のため)、
   (b) 刻み t の適用の単位の前に、新しい表を**新しい**既定のバッファに写してルートの SRV を結び直す(古い表はそのリストが終わるまで持つ)、
   (c) 適用の後に RefreshTable(GPU): 2 世代の熱のキャッシュを新しい表で作り直し、全部のブロックの tc を「刻み t の直前に変わった」、
       起こす刻みを t にして、刻み t の一覧を空にしてから WakeDueBlocks に全部を足させる。
   CPU リファレンスは ProbeReference::Advance(t, commands, newTable) で同じことをする(毎刻みビット一致を gpu_probe_sim_test で確かめる)。
5. **再生**: 印の版の表を、知っている表(起動時の表とその実行で読み直した表)から探して同じ刻みに当てる。持っていなければ止まる
   (表の中身を再生ファイルに残すのは T-0193)。
6. **保存点**: 表を差し替えたら全部捨てる(前の表の熱のキャッシュを持っているので、戻ると表と食い違う)。

## 検討した代案と、採らなかった理由
- **GPU のコマンドだけで表を写す**(表を GPU の置き場に先に上げ、適用の単位が印を見て写す): 1 スレッドの適用の単位で数百 KB を写すのは重く、
  置き場の数の上限も要る。CPU がリストに写しを記録しても、何をいつ当てるかは印(コマンド)で決まり、世界の状態は GPU が作るので原則 1 に触れない。
- **差し替えたブロックだけ起こす**: 表は全部のセルに効く(熱容量が変われば全部の温度が変わる)ので全部を起こす。費用は差し替えた 1 刻みだけ。
- **物質の一覧が変わっても当てる(名前で付け替え)**: 付け替えの段と、消えた物質の扱い(保存則)を決める必要がある。判断待ち(T-0139)。
- **時刻(更新日時)で変更を見る**: 写し・展開で時刻が戻る・同じ秒の 2 回の保存を見落とす。中身の指紋なら確実(数十ファイルなら軽い)。

## 影響(何がしやすく/しにくくなるか)
- しやすい: 反応表を書く人が、規則・速度・熱の値を書き換えて保存するだけで、動いている世界の反応の変わり方を見られる。誤りは場所つきで出る。
- しにくい: 物質を足す・消すときは起動し直す。読み直しの間はエディタのフレームが止まる(同期。重ければ別のスレッドへ)。
  ホットリロードをまたぐ記録の再生は、同じ実行の中か T-0193 の後。
