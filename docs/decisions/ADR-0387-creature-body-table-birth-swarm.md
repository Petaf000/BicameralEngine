# ADR-0387 生き物 = 体 + 表、口「生まれる」と「群れ」

- Status: Accepted(2026-10-21。ユーザーの決定)
- 日付: 2026-10-21
- 決めた人: ユーザー(claude/32 S24。口 2 つは Claude の洗い出しからユーザーが了承)
- 関係: D-584・D-408・D-451・D-469・設計 09 §0・§1.1・claude/27 K9(セル → 物の受け渡し)

## 背景
- 体は法則・心は行動表(D-469)で動物は書けたが、植物・カビ・酵母・群れ・「種が芽を出す」が同じ形に入るかが未確認だった。
- 洗い出し(claude/32 §3.3)で、「体(反応する物質)+ 表」で全部を覆えるが、口が 2 つ足りないと分かった。

## 決定
1. **生き物 = 体(反応する物質)+ 表**。動物は行動表、植物は育ち方の表。表の無い草・苔・カビ・酵母は反応する物質として広がる。
2. **死ぬ = 体を保てなくなった状態**(旗ではない)。
3. **口「生まれる」**: 条件(状態)を満たすと、物質の塊が表を持つ個体(物)に移る。セル → 物の受け渡しと同じで帳簿が合う。
   親の値を変異の表に従って受け継ぐ口も兼ねる(遺伝・進化は D-451 の研究のまま。変異の選び方は状態のハッシュで決定的)。
4. **口「群れ」**: D-408(群れは 1 つの物、近づけば一体ずつ)と体 + 表をつなぐ。一体ずつにする・戻すは同じ受け渡しで数と物質が保存される。

## 検討した代案と、採らなかった理由
- 植物・カビを別の仕組み(成長の札・広がりの規則)で書く: 体の法則と食い違い、燃える・腐る・食べられるを二重に書くことになる。
- 遺伝・進化を持たない(種の値は固定): 初めの版で Claude が書いたが、D-451(世代を重ねて進化する研究)と食い違う誤りだったので直した。

## 影響(何がしやすく/しにくくなるか)
- しやすく: 発酵・病気・カビ・草の広がり・木が切られて倒れる・種が芽を出す・卵が孵る・ある物質が濃い所から生き物が生まれる、が一つの形に入る。
- しにくく: 「生まれる」の条件の評価は全部のセルでなく、条件に関わる物質のある所だけで行う必要がある(費用は未確認。M8)。
