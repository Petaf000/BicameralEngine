# ADR-0461 RC の坂を下るを構造で 0 にする: 釣り合い(参照の温度)との差だけを RC で運び、参照どうしの交換は対の流れで(案)

- Status: Proposed(T-1102 の 2 本目で CPU と GPU に入れた。ビット一致・6 場面で構造で 0。**既定は 0**: 参照の分の空との交換の口〔23 §3.2〕が要る。2026-10-24 司令塔: 坂を下るはエンジンの約束なので聞かずに進める)
- 日付: 2026-10-24
- 決めた人: Claude(T-1102。決めるのはユーザー)
- 設計: docs/design/23-radiation.md §3.3 / 前: ADR-0424 の 2・ADR-0252(対の交換)・D-646(RC のまま・筋は数秒の平均で ±12 %)

## 背景
RC は、同じ温度の閉じた箱でもセルごとの正味の出入りが放った量の 15〜21 % 残る(段の受け渡しの向きの偏り)。温度に直すと 0.09 mK/刻み(5 mK/秒)で、数秒で計器(1 mK)に出る。
温度差のある箱では、この偏りが本物の信号より大きく、冷たい壁が熱を失う(T-1102: 塊 1010 K で最大 0.087 mK/刻み)。

## 根っこ
釣り合い(同じ温度どうしの放ち合い)は正しい物理では正味 0 なのに、RC はそれを毎刻み光線で運び、その誤差がそのまま正味になる。**運ぶのは釣り合いからのずれだけにすれば、釣り合いの誤差は形の上で 0**。

## 決定(案)
1. RC が熱で放つ量を σ(T⁴ − T_ref⁴) × 帯の割合 × α にする(T_ref = そのブロックの参照の温度)。同じ温度なら放たない → 正味は構造で 0(測り: ちょうど 0)。
2. 参照の温度は起きている所に 1 つ(環境の温度)。ブロックごとの参照 + 対の流れ(ADR-0424 の 2)はブロックの間の見える割合が要るので後(T-1102)。
3. 参照より冷たい物は負の側で放つ(参照の光を吸う)。RC の量は符号なしのまま、正の側と負の側を別の組で運び、差を取る(核の袋・溜め・持ち越しを変えない)。
4. 参照の分の世界の外(空)への出は、RC の外へ出た割合から当てる(形は未確認)。

## 作り手から見た違い(仮)
- 【エンジン】同じ温度の部屋で物が勝手に温まったり冷えたりしない(今は数秒で計器に出る)。温度差のある所の熱の行き先は今と同じ RC の筋(±12 % の平均)のまま。
- 費用: 同じ温度の物が光を放たなくなるので、照り返しの光源が減る(照り返す地面の費用が下がる見込み。未確認)。

## 検討した代案
- 今の形のまま、偏りが計器の精度の内かだけを見る → 0.09 mK/刻みで数秒で出る。
- 対のつながり(ADR-0452)で運ぶ → 研究で動く物と煙が通らなかった(T-1094・T-1095)。D-646 で RC のまま。
