# ADR-0258 気体の箱の成分の数に上限を置かない(CPU。成分ごとの並び GasPerSpecies・丸めの鍵は物質 ID。T-0591)

- Status: Accepted(エンジンの作りの細部。作り手から見た違いは「表の気体を何種書いても流れる」だけ)
- 日付: 2026-10-15
- 決めた人: Claude(T-0591 の作業役。D-401 に沿う実装の細部)

## 背景
- 1 レベルの気体の箱(gas_reference・gas_projection)の成分の欄は 4 つ(GAS_MAX_SPECIES。GPU の GasGpuCell と同じ形)で、
  仮の世界の気体の区画(T-0590)は区画の気体の物質が 5 つ目になった刻みを流さなかった。地球の空気(N2・O2・Ar・CO2)だけで 4 つ埋まる。
- D-401: エンジンに固定の上限を置かない(1 セルの成分の数も)。

## 決定
1. **成分ごとの値は `GasPerSpecies<T>`**(gas_reference.h): 4 つ(GAS_MAX_SPECIES)までは中に持ち、5 つ目の欄に書いた時に全部を外の配列へ移す
   (RxCell のインライン 8 + 溢れと同じ考え)。並びの外を読むと 0、比べる時は足りない方を 0 で埋める。
   GasCell の物質量・GasConfig の物質・係数の質量・帳簿・合計・基準の層の割合をこれにした。式と足し引きの順は変えていない
   → 4 種以下の箱は今までとビット単位で同じ(gas_reference・gas_tree・gas_projection の試験がそのまま通る)。確保もしない。
2. **丸めの乱数の鍵**: GasSpecies::roundingKey(既定 = 欄の番号 = 今まで)。世界のセルに載せる時(probe_gas)は物質 ID にする。
   区画に新しい気体が現れて欄の並びがずれても、他の成分の丸めが変わらない。
3. **GPU の段と多重解像度の木は 4 つのまま**(展開する決まった数の欄。T-0397)。GpuGas::Create は 5 つ以上と既定でない鍵を断り、MakeGasTree は assert。
   GPU の帳簿は GPU の形(GpuLedger)へ写して上げ下げする(GasLedger はもう 64bit の並びそのものではない)。
   GPU で上限を外すのは T-0592 の後(セルの成分の並びで回す形。ticket T-0591 の目的の GPU 側)。
4. 仮の世界の区画(probe_gas): 上限 4 の断りを外した。代わりに、流すと 1 セルの成分が RxCell のインライン 8 を超える刻みは
   **流さずに数える**(ProbeGasStepReport::skippedCellOverflow。セルにも気体の欄にも帳簿にも触れない。溢れのセルは R-MULTI-4)。

## 影響
- 作り手から見て: 表の気体の物質を何種類書いても、区画の中で流れる(CPU)。GPU で流すのは T-0592 と GPU 側の上限外し。
- 費用: 5 種以上の箱はセル・面ごとに外の配列を確保する(CPU リファレンスの費用。数値は docs/perf.md の 2026-10-15 T-0591)。
- 代案(採らなかった): 欄の数を大きな固定値にする(D-401 に反する)/ 箱を成分の構造体の配列に分けて並べ直す(変更が木と GPU と試験に広がる。速さが要るなら後で)。
