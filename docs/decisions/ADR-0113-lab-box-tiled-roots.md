# ADR-0113 実験室の大きい箱は「多重解像度の本物の根を x・y・z に並べる」で作り、箱の形は作る時に決める

- Status: Accepted(実装の細部。ユーザー未確認の点はチケット T-0173 の「判断待ち」)
- 日付: 2026-10-11
- 決めた人: Claude(CLAUDE.md §5。T-0173・D-449)

## 背景
- ADR-0037 の実験室の箱は多重解像度の木の本物の根 1 つ(8³ セル・4 m 角)。D-449 で、中身(反応表・魔素の値)を触って決めるために
  「大きい箱と細かい箱」を足すことにした(T-0173)。
- 多重解像度の木は根をいくつでも置け(PlaceRootBlock)、根どうしの面は伝導が索引で隣を引いて熱を通す(17 §5「面の隣」)。
- 置く操作のコマンド(common/lab_box.hlsli)は 64 バイトで、セルの番号は 1 語(根 1 つの MrCellIndex)、範囲は 1 語に角 2 つ(5 ビットずつ = 0〜31)。

## 決定
1. **大きい箱 = 根(8³)を x・y・z に並べる**(`lab::LabBoxShape`。どの軸も 1〜4 本、最大 4×4×4 = 64 根・32768 セル・16 m 角)。
   根の枠は x → y → z の順に 0 から(MakeLabBoxNest が空きのスタックから順に取る = `lab::LabRootSlot`)。根の原点 = 根の座標 × 8。
   どの根もいつも頁を持つ(ADR-0037 と同じ)。刻みは今の木の刻みそのもの(根の境は木の伝導が熱を通す。外とは熱も物も通さない)。
2. **箱の形は作る時に決め、後から変えない**(GPU の箱〔GpuMultires〕の容量が形で決まる)。パネルは「箱の大きさ」を選んで作る・作り直す。
3. **セルの番号**: 下位 9 ビット = 根の中のセル(MrCellIndex)、その上に根の x・y・z を 2 ビットずつ(`lab::LabCellIndex`)。
   根 1 つの箱では今までの MrCellIndex と同じなので、T-0142 からのコマンドと記録はそのまま読める。範囲の語は今の 5 ビットの座標のまま
   (4 根 = 32 セルがちょうど入る。軸あたり 4 根が上限なのはこのため)。形の外のセル・範囲は GPU と CPU の両方が当てない。
4. **つつくのは当てたセルを含む根だけ**(表を替えた印は全部の根)。GPU(lab_box.hlsl)は 64 ビットの印で数え、CPU(ApplyLabCommands)も同じ。
   GPU のルート定数 g_external1 は箱の枠から箱の形(`lab::LabPackShape`)に替えた。
5. **記録 BLAB 版 5** = 版 4 + 箱の形(種の後ろに u32 × 4)。版 1〜4 は根 1 つ。形の違う記録は LabSession::Replay が断り、
   パネルは記録の形の箱を作って再生する。計器(SampleLabGauge)・最初に違ったセル(FindLabMismatch)は箱の全部の根を数える。

## 検討した代案と、採らなかった理由
- **根を 1 つのまま、根のレベルを粗くして細かい子を並べる**(根を rootLevel 1 にして 8 つの子を作る): 木の要求で作るので一部を細かくする
  (T-0314)と同じ道になるが、粗い根のセルは覆われていて、置く操作が粗いセルと細かいセルのどちらに当たるかを決める必要がある。
  並べるだけなら根を並べる方が単純で、木の管理も要らない。
- **コマンドに新しい種類(大きい箱用の 1 セル)を足す**: セルの番号の上のビットに根の座標を入れれば今の種類のままで済み、古い記録の意味も変わらない。
- **範囲の語を広げる(座標を 6 ビット以上に)**: 角 2 つ × 3 軸で 1 語に入らなくなり、範囲のコマンドの形(T-0220)を変えることになる。
  4×4×4(16 m 角・32768 セル)は CPU リファレンスの 1 刻みも重くなる大きさで、今は足りる。
- **箱の形を後から変えられるようにする**: GPU の箱の作り直しが要る(debug で数十秒〜数分)。作り直すのと同じなので、ボタンで作り直す。

## 影響(何がしやすく/しにくくなるか)
- しやすい: 火が根の境を越えて隣へ移る・離れた所に置いた物どうしの反応を、毎刻み GPU と CPU のビット一致を見ながら試せる。
  根の境は木の伝導の道そのものなので、世界の木の根どうしの伝導の不具合も小さな場面で再現できる。
- しにくい: 一部を細かくした箱はまだ無い(T-0314。木の要求で子を作り、置く操作を細かいセルに当てる決め方が要る)。
  大きい箱ほど 1 刻みが重い(CPU リファレンスで全部のセルを刻み、毎刻み箱を読み戻して比べる)。比べる画面の流し直しも重くなる(ADR-0075 の
  「大きい箱の時に VRAM の保存点か裏のキューで流すか決め直す」は、今は決め直していない)。
