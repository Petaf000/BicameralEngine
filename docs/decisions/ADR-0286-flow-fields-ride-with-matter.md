# ADR-0286 流れの欄(運動量とエネルギー)は物質に付く: 出ていく割合の上限と、段の外で気体の質量が変わった時の運動量(T-0646)

- Status: Proposed(仮・ユーザー未確認。T-0646 の判断待ち 1)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- T-0611 の湯気の場面(熱い石の上の水たまりが蒸発し、冷たい池で凝縮する)で、気体の区画のエネルギーの合計が 960 刻み目に +54 kJ ずれた(元素は保存)。
- 見立ては「反応が気体の質量を変えても運動量が残り、運動のエネルギーが増える」だったが、測ると違った(T-0646 の作業ログ):
  気体の段そのものは毎刻みビット単位で保存していた。ずれは、**物質がほぼ無いのに −60 kJ のエネルギーを持つセル**(区画の天井の近く。
  空気 0.03 mol)で、試験の合計が物質の無いセルを数えていなかったので現れた。
- 根っこ: 気体の塊は、風上の熱の分け前(熱容量の比)に加えて**押し出す仕事 n R T**を持って出る(07 §2.4)。出ていく割合の合計は 1 までしか
  抑えていなかったので、強い流れが 1 小刻みでセルの中身を 7 割より多く押し出すと、引く側の熱が負になる(空気の c_v ÷ (c_v + R) ≒ 0.71)。
  中身が全部出ると、物質の無いセルに −n R T のエネルギーが残る。熱が負のセルは温度 0・圧力 0 の「冷たい穴」になり、まわりの気体を吸って冷やす。
- もう一つ(見立ての方): 反応・相変化・置く操作で気体の質量が減っても運動量はそのままだった(質量が減ると速さと運動のエネルギーが増え、
  その分を熱から取る)。湯気の場面の崩れの直接の原因ではなかったが、同じ「欄が物質から離れる」形。

## 決定(仮)
**流れの欄(運動量・運動のエネルギー・熱)は物質に付く。物質が無いところにそれらを残さない。**
1. **出ていく割合の上限**: 風上のセルごとに、出ていく割合の合計を (C + n R) ÷ C 倍してから 1 と比べ、超えたら比例して縮める
   (C = 熱容量・n = 物質量。断熱のときだけ。等温は押し出す仕事が無いのでそのまま)。引く側の熱は負にならず、セルは 1 小刻みで空にならない。
   CPU は gas_reference.cpp の EffectiveOutflow(陽解法と投影の両方)、GPU は gas_step.hlsl の GasOutflow。普段の流れ(割合が小さい)では結果は変わらない。
2. **段の外で気体の質量が変わった時の運動量**(仮の世界の区画。probe_gas・probe_gas_tick): 区画が前の段の終わりの気体の質量を持ち、段の入口で
   減っていたら速さを保つ(運動量 × 今の質量 ÷ 前の質量。減った気体は同じ速さで凝縮相へ移ったものとし、その運動量は帳簿へ。凝縮相は
   運動量を持たない)、増えていたら運動量を保つ(増えた気体は静止して現れる)。運動のエネルギーはどちらも前の値を超えず、差は熱になる。
   段の終わりに気体が残らないセルの運動量は帳簿へ(質量の無い運動量を持たない)。

## 影響
- 作り手から見て: 強い爆発・急な蒸発で、セルの気体が 1 刻みで抜けきらず、少し遅れて抜ける(空気なら 1 小刻みに 7 割まで)。
  雲(気体の中で凝縮した露)の運動量は凝縮した時に世界の外(帳簿)へ出る(液体の区画があっても、今は液体の勢いにならない。T-0648 → T-0673)。
- 保存の検査は「セルの合計 + 運動エネルギーのぶん − 帳簿」に加えて「どのセルも熱が負にならない・物質の無いセルはエネルギー 0」を確かめる(probe_gas_test)。
- 木(gas_tree・gas_tree_step。多重解像度)も T-0647 で同じ換算にした(追記 1)。木と箱が一致する試験は普段の流れなので変わらない。
- 代案(採らなかった): 物質の無いセルに残ったエネルギーを帳簿や隣へ移す(見せ方で直す継ぎはぎ。熱が負のセルは空になる前から生じる)/
  運動量の代わりに速さを持つ(増えた気体が動いて現れ、運動量が無から出る)/ 前の運動エネルギー(mJ に丸めた値)から質量の比を逆算する(遅い流れで丸めが効く)。

## 液体の区画(T-0656・2026-10-17 追記。同じ決まり)
- 液体の面の運動量(ADR-0266・ADR-0276)も物質に付く。区画が前の刻みの終わりのセルの液体の質量を持ち、段の入口で面の両側の質量の和が
  減っていたら速さを保つ(運動量 × 今 ÷ 前。0 の向きへ切り捨て。減った液体の運動量は帳簿へ)、増えていたら運動量を保つ。
  運動のエネルギーは前の値のまま運び、刻みの終わりに今の質量から計算し直した差が熱になる(増えないので熱を負にしない)。
  液体が残らない面の運動量は帳簿へ(前から)。CPU は probe_liquid.cpp の FollowMassChange、GPU は probe_liquid_tick.hlsl の LiquidForces の初め。
- 作り手から見て: 流れている水が蒸発・凍る・反応で減っても、残りの水の速さは変わらない(前は運動量が残り、減るほど速くなってその運動のエネルギーを熱から取った)。
  増えた水(溶けた氷・露)は静止して現れ、まわりの流れを少し遅くする。
- 雲(気体の中で凝縮した露)の運動量を液体の勢いにするか(気体の帳簿へ出る分を液体の面へ渡す)は T-0673 に分けた(気体と液体の区画をつなぐ)。

## 追記 1(2026-10-17。T-0647)
- **木(多重解像度。gas_tree・gas_tree_step)も同じ換算**: 出ていく割合の合計と、同じ小刻みの面がもう出した分(committedOutflow)の両方を
  (C + n R) ÷ C 倍してから 1 と比べる(換算の倍率は風上の物質だけで決まり、粗い小刻みの間は同じ)。GPU は gas_cell.hlsli の
  EffectiveOutflow を箱と木で共有。普段の流れ(割合が小さい)では結果は変わらない。
- **採らなかった: 上限を力積の後の熱 H で数える(合計 ≤ H ÷ (H + n R T₀))**。燃える木箱で熱が負のセルが 9 → 14(最も負 −628 kJ → −11.9 MJ)、
  H ≤ 0 の時だけ元の換算に戻しても 5 セル・−81 MJ で 0 にならなかった(元の換算でも露の木箱で −158 MJ)。力積が足す運動のエネルギーは同じ小刻みで流れ込む塊の押し出す仕事で返るので、
  返る前の熱で出口を塞ぐと運動量が溜まって暴走する。熱が負のセルの元は出ていく量ではなく力積の大きさ(T-0676)。
