# ADR-0266 液体を世界のセルに載せる形(セルが唯一の真実・面の運動量・列の静水圧・物質の相と密度。T-0609)

- Status: Proposed(仮・ユーザー未確認。T-0609 の判断待ち 1〜5)。**2026-10-17 ADR-0326 で一部置き換え**: 区画(流す直方体)は D-510 でやめ、相は `phase` 1 本(D-512)。セルが唯一の真実という芯は土台に引き継ぐ
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- 07 §3 は液体を「3D のパイプ模型」で流すと書き、T-0026 の事前調査は W1(3D パイプ + 列の静水圧)をすすめていた。D-442 は「水の勢い(運動量)も最初から厳密に保つ」。
- ⑤ の場面 T-0415(氷が溶けて流れる・池を抜く)と、草原の延焼(T-0414)の川(水が熱を吸う・湯気・岸の草が湿る)に液体が要る。
- 気体は ADR-0256 で「セルが唯一の真実・足す欄は運動量だけ・区画」の形で世界のセルに載った。液体も同じ形にそろえる。

## 決定(仮)
1. **セルが唯一の真実**。液体の成分 = セルの成分のうち表で液体の物質。液体の別の格子は持たない(反応・伝導・気体と同じセルを読む)。
2. **物質の書き方**: 物質に任意の欄 `phase = "gas" | "solid" | "liquid"` と `density_kg_per_m3` を足す。`phase` の solid と liquid は凝縮相(今の `condensed = true` と同じ。
   両方書いて食い違えば読み込みが断る)。液体には密度が要り(無ければベイクが断る)、ベイクがモル体積(mm³/mol = モル質量 ÷ 密度)を作る。
   セルに入る液体の量 = セルの体積 ÷ モル体積。固体の密度は、気体と体積を分け合う所(T-0612・T-0593)が読む予定。
3. **流れの形(3D のパイプ模型 + 列の静水圧)**: 面ごとに運動量を持つ(区画のセルの + 側の面 ×3。スタッガード)。
   圧力を質量の単位で P = 2 × 上に続く液体の質量 + 自分の質量 + 溢れの圧力 と書き、面の運動量に毎刻み P の差(縦の面はさらに − 両側の質量 = 重さ)を足す。
   静かな水では差と重さが整数で厳密に打ち消し合う。1 刻みに動く質量 = 面の運動量 × g × dt² ÷ (2 × 1 辺)。上流のセルから、液体の成分の比で物質量と
   液体のぶんのエネルギー(熱 × 動く熱容量 ÷ セルの熱容量 + 動く化学)を動かす。出る合計がセルの液体を超えれば比で縮める。前の刻みの値だけから決める(順番に依存しない)。
4. **運動量の保存(D-442)**: 各セルの圧力は自分の両側の面を同じ大きさで逆向きに押す(内側の力の和は整数で 0)。外から入る運動量
   (壁と床の押し返し・重さ・摩擦・行き場のない運動量)を軸ごとに帳簿に載せ、Σ 面の運動量 − 帳簿 が毎刻みビット単位で一定。
   運動量を液体と一緒に運ぶ(移流)のはまだ無く、上流が空になった面の運動量は「行き場なし」として帳簿へ出す(T-0610 で無くす)。
5. **壁**: 液体でない凝縮相を少しでも含むセルは液体を通さない(仮。固体の体積と分け合うのは T-0612)。区画の外の面も壁。
6. **段の順**: 適用 → 物理の熱 → 表の差し替え → 気体 → **液体** → 伝導と反応(ProbeReference::Advance の (1c))。区画は気体と同じく世界が書いた直方体(既定は無い。D-455)。
7. **相変化は反応表で書く**(T-0611 で確かめる): 氷・水・湯気は別の物質で、溶ける・凍る・蒸発・凝結は反応の規則。潜熱は生成エンタルピーの差から出る。

## 影響
- 作り手から見て: 物質に `phase = "liquid"` と密度を書くと、区画の中で低い方へ流れて溜まる。書かなければ今までどおり(液体の無い世界・ブランクの世界は何も変わらない)。
- 今の制限: 位置と運動のエネルギーを数えない(落ちる水が温まらない。T-0610)・液体が入っても空気は押し出されない(T-0612)・摩擦は区画の設定の仮の値(判断待ち 3)・CPU だけ。
- 追記 1(2026-10-15・T-0610): 運動量の移流と位置・運動のエネルギーを足した(ADR-0276 Proposed)。決定 4 の「行き場なし」はまわりが空になった面だけになり、
  摩擦の既定は 1/16 → 1/128。上の「位置と運動のエネルギーを数えない」は解消。
- 代案(採らなかった): 浅水方程式の高さの場(W2。洞窟の張り出しを扱えない。遠くの粗い層の川には後で使う)・VOF + 射影(W3。整数で決定的な PLIC が重い)・
  粒子(W4。並べ替えが要り、セルの化学と合いにくい)・Noita 型のセルオートマトン(順番に依存する・運動量が無い)。

## 追記 1(2026-10-15・第 6 巡のマージ)
- 放射の段(T-0585・ADR-0263)と同じ巡目に入ったので、段の順は 適用 → 物理の熱 → 表の差し替え → (1b) 気体 → **(1c) 液体** → (1d) 放射 → 予定 → 伝導と反応 にした。

- **2026-10-26 本体の棚卸し(QUESTIONS Q89)**: 液体を仮の世界に載せた時の仮 → ⑤ もう要らない(D-522)。①〜④ は前に土台で閉じていた。
