# ADR-0316 セルの気体の器を反応の取り合いの資源にする(気体を増やす規則は器の残りまでに縮める。T-0622)

- Status: Proposed(仮・ユーザー未確認。T-0622 の判断待ち A = QUESTIONS Q113。2026-10-17 main へ〔T-0709〕。ADR-0326 の土台でも反応の側の器はセルの中のまま残る)
- 日付: 2026-10-17
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- 1 セルの気体のぶん(condensed でも liquid でもない物質の合計)は 2^31 µmol(2147 mol)未満(ADR-0260)。気体の式が移す量を Q32 の 64bit で計算する器。
  入口(world_cells・材料のひな形)は確かめていたが、**走っている間に反応が気体を増やす**のは確かめていなかった(T-0601)。
- 水の蒸発は釣り合いの規則(ADR-0290)で、湯気は釣り合いの濃さ × セルの体積で止まる。見本の値では約 726 K より熱い水の釣り合いが器を超える
  (1200 K で約 2.9 万 mol / セル)。溶岩・焚き火・熱い石の近くの水(⑤ の場面)で起きる。燃えて気体が増える規則(セルロースの熱分解など)も同じ。
- 超えると、debug は気体の式の assert、release は Q32 の溢れ(気体の移す量・圧力が壊れる。保存の帳簿が崩れる)。

## 決定(仮)
1. **気体の器を、反応の取り合い(02 §3 の 3)の資源にする**。吸熱の規則が熱(の 1/8)で縮められるのと同じ形:
   - 規則ごとに `gasGrowth` = 進行度 1 µmol で増える気体のぶん(Σ 気体の生成物の係数 − Σ 気体の反応物の係数。減るか同じなら 0)をベイクが出す(RxRule)。
   - 刻みの初めの「器の残り」= 2^31 − 1 − 今の気体のぶん(RxGasRoom)。気体を増やす候補の要求の合計(Σ 進行度 × gasGrowth)が残りを超えたら、
     その規則を同じ比で縮める(確率的な丸め・丸め上げの戻しも同じ。並び順に依らない)。
   - 気体を減らす規則の分は同じ刻みに差し引かない(熱で発熱の規則を足さないのと同じ。保守的で順番に依らない)。
2. **GPU の表に物質の気体の印を入れる**(`RxSpecies::flags` の RX_SPECIES_GAS = condensed でも liquid でもない。気体の区画が流す物質と同じ。ADR-0256)。
   RxSpecies は 24 → 32 バイト・RxRule は 112 → 120 バイト(gasGrowth と空き)。
3. 置くコマンドも気体のぶんを確かめる(置いた後の気体のぶんが器に入らないセルは飛ばす。合計の器と同じ扱い)。
4. 多重解像度のレベル k のセルは 8^-k µmol で数えるので、器の数はレベルによらない(ADR-0260)。

## 影響(作り手から見た違い)
- 作り手は何も書かない。気体を増やす規則(蒸発・熱分解・燃焼で気体が増えるもの)は、セルの気体のぶんが約 2147 mol(0.5 m 角。726 K で約 1000 気圧)に
  近づくと遅くなり、器に届くと止まる。気体の区画の流れ(圧力)が隣へ運んだ分だけ、次の刻みにまた進む。
  → 熱い水は「湯気が逃げる速さ」で沸く(閉じた器では釣り合いまで行かない)。現実の高圧の沸騰も圧力で抑えられるので向きは合う。
- 器に張り付いたセルは、規則が進もうとし続けるので眠らない(湯気が逃げない閉じた場所。費用は起きているセル 1 つ分)。
- 1 セルの反応の評価に、気体を増やす候補がある刻みだけ、セルの成分の気体の印を読む分の費用が足される。
- 上限の印(RX_LIMIT_*)はまだ足していない(器で縮めた刻みは数えない)。

## 代案(採らなかった)
- B. **器を広げる**(気体の式を 128bit に・移す量の Q 形式を変える): 作り手から見て壁が 2^36 まで遠のくが、気体の段(gas_step・gas_tree_step・
  仮の世界の GPU の気体の段)のすべての式が重くなる。300 K で 1 万気圧を超える気体は気体の式(理想気体)の外で、遊びに意味が無い。
- C. **器を超えた分をその刻みに隣へ溢れさせる**(反応の段が隣のセルへ書く): 作り手から見て湯気が壁・水・石を無視して隣に湧く。
  反応の段がセルごとに独立でなくなり(書く順・同じ隣への取り合い)、圧力で運ぶ気体の区画の仕事と重なる。A + 流れで「押し出される」は物理として起きる。
- D. **法則で止める**(圧力の上限を規則の速さに効かせる・臨界点を書く): 中身(パッケージ)の側の書き方で、作り手は書いてよい。
  ただしエンジンはどんな規則が書かれても器を守る必要があるので、A は D の有無によらず要る。
