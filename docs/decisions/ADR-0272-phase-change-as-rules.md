# ADR-0272 相変化を反応表の規則で書く(全部次数 0 の規則を足す。T-0611)

- Status: Accepted・改訂(2026-10-17 ユーザー決定 D-504: 向きごとの規則の対は今の形。釣り合いを書ける規則の形を T-0623・T-0624 で足す。QUESTIONS Q96 を閉じた)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- ADR-0266 の 7: 氷・水・湯気は別の物質で、溶ける・凍る・蒸発・凝結は反応の規則(T-0611 で確かめる)。D-466(坂の原理)・D-487 ①(向きは作り手が書く・案 A)。
- エンジンは中身を持たない(D-454)。相に固有の段(沸点・融点の欄)を足すと、物質ごとに「相の表」を持つ M2 の形になる。

## 決定(仮)
1. 相変化は**向きごとの規則の対**で書く。潜熱は書かない(生成エンタルピーと比熱の差から出る。エネルギーは構造的に保存)。
2. **凝縮相の反応物は次数 0 で書く**(活量 1。量によらない)。そのため、ベイクは**反応物が全部次数 0 の規則**を通す(次数 1 の反応物は 0〜2 個)。
   全部次数 0 の規則の進みは「反応物がある限り、セルの体積あたり一定」で、A は mol/(m³·s)(1 刻みの進み = A e^(−Ea/RT) × セルの体積)。
   評価のコードと GPU の表の形は変えない(前から積が 1 で扱えた)。
3. 見本(標準パッケージ real_matter・real_reactions):
   - 蒸発 = 水(次数 0)→ 湯気・凝縮 = 湯気(次数 1)+ 水(次数 0。触媒)→ 水 2。釣り合いの湯気の濃さ = A_蒸発 e^(−Ea/RT) ÷ k_凝縮 を飽和水蒸気の濃さ
     (IAPWS-95 の 298.15 K と 373.15 K)に合わせた(Ea 40 kJ/mol・k_凝縮 1 /s)。
   - 融解 = 氷(次数 1)→ 水(Ea 600 kJ/mol の急な Arrhenius)・凝固 = 水(次数 0)+ 氷(次数 1)→ 氷 2(1 /s)。273.15 K で等しい。
     正味 = 氷 ×(k_融解 − k_凝固)なので、向きは量によらず温度だけで決まり、熱が足りなければ融点に張り付く。
4. 凝縮・凝固は相手の相があるセルでだけ起きる(水・氷を触媒)。霧・凍り始めは書かない(仮。T-0624)。

## 注(作り手の注意)
- 触媒の形の規則は同じ刻みのうちに自分の触媒を作り直す(取り合いは同じ刻みの始めの量で決まる)。触媒の量に比例しない規則(次数 0)だと、
  熱いセルにも氷が残り続けた。触媒の相について次数 1 で書く。
- 釣り合った対は眠らない(毎刻み行き来する)。静かな池が計算され続ける(費用。T-0623)。
- 坂の検査(T-0492)は規則ごとに見るので、対の片方ずつ(4 本)が「坂を上る温度がある」と警告した(表は当たる。D-487 ②)→ 追記 1。
- 速さの表は 1 K ごと(下へ切り捨て)なので、融点の切り替わりは 273/274 K の境になる。
- 湯気は飽和の濃さ × セルの体積で止まるので、気体のぶんの器(ADR-0260)を超えるのは約 726 K より熱い水だけ(T-0622)。

## 影響
- 作り手から見て: `orders` で全部の反応物を 0 にした規則が書ける(前はベイクが断った)。標準パッケージを足すと水の 3 相と相変化が入る。
- 表の形・GPU のシェーダー・ハッシュの作り方は変わらない。標準パッケージに依存する世界(サンプルの世界・場面)は物質と規則が増える(物質 ID がずれる)。
- 代案(T-0623 の案 B): 規則に釣り合い(K(T)・融点)を書き、1 本で両向きを正味で進める。融点がちょうど・釣り合えば眠る・坂の検査が 1 本で済む。書き方が 1 つ増える。

## 追記 1(2026-10-15・T-0611 の続き。仮・ユーザー未確認)
- 坂の検査は**逆向きの対**(正味の係数がちょうど符号違いの 2 本。触媒・次数・速さは問わない)を見つけ(`RuleSlope::reverseRule`)、
  対の規則には「一方向の規則が坂を上る」警告を出さない。警告の文の前提(一方向なので坂の上へ運び続ける・直すなら逆向きを足す)が対には当たらないため。
  坂の欄(上る温度の範囲)は 1 本ずつのまま残し、パネルは対を黄の「対・上る」で出す。GPU の表とハッシュは変わらない。
- 見ないもの: 対の速さの比(k_正 / k_逆)が釣り合い K(T) = e^(−ΔG°/RT) と合うか。合わない対は対でも坂の上へ運び続けうるが、今は警告しない → T-0623。
- 作り手から見て: 標準パッケージ(水の 3 相)を使う世界で起動のたびに出ていた 4 本の警告が消える。一方向の規則(boudouard など)の警告は今まで通り。

## 追記 2(2026-10-17・ユーザー決定 D-504。この ADR の改訂)
- 規則に「釣り合い」を書ける形を足す(相変化専用ではなく反応の規則の一般の形。釣り合いの温度・濃さは作り手が書く = D-487 の案 A のまま)。
  1 本で両向き・釣り合えば眠る・融点がちょうど・種が無くても冷えれば凍り始める・霧が書ける・化学の釣り合いにも使う。
- 向きごとの規則の対(この ADR の決定 1〜4・追記 1)は今の形として残し、標準パッケージの水の 3 相は釣り合いの形ができたら書き換える(T-0623・T-0624)。
- 背景(ユーザーの問い「反応だけでは書けなかったのか」): 書けたが、新しい相が生まれ始める所(種なしの凍り始め・霧)と、釣り合って止まる所(眠り・融点ちょうど)が
  書けなかった。根っこは「速さが温度だけで決まる形」。
