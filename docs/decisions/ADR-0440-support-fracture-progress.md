# ADR-0440 支えの割れ: 面ごとの割れの進みを真実として持ち、係数を下げる(2 通りの判定の比べ)

- Status: Proposed(Claude 案・ユーザー未確認。研究 R-B2 の 1 チャット目 T-0872 の結果から。判定の形は打ち切り条件に当たったので未決)
- 日付: 2026-10-22
- 決めた人: Claude(wt2 の作業役。T-0872)
- 関係: ADR-0379(支えの法則)・ADR-0407(格子の梁)・ADR-0415(段の斜めの棒)・ADR-0418(成分を持つ節)・D-609・D-612・設計 22 §3.3〜§3.5・§5・§6

## 背景
22 §3.3 は割れを反応の家族で起こし、強さ(押し・引きの 2 つ)で割れ始めの所と向きを、エネルギー(割れ面のエネルギー G)で割れが進むかを決めるとした。
R-B2 は ① 強さだけ ② 強さで割れ始め + エネルギーで進む、の 2 本を試す。C-0(釣り合う家族の共通部品)の型は変えない約束。

## 決定(仮)
1. **割れの進み**(真実): 格子の梁の面ごとに 0〜1(割れた面積の割合。Q16)。面の係数(伸び・ずれ・曲げ)を (1 − 進み) 倍し、割れ切った面は係数 0 = 面を外す
   (法則の側で係数を変える。C-0 の型はそのまま。支えの場面の欄 `intactX` / `intactUp`、空なら今までとビット一致)。
2. 進みは物質の割れの速さ(m/s)で 1 刻みに速さ × Δt ÷ Δx まで(D-612 の既定 = この宇宙の速さとして遅く。仮 5 m/s)。全部の面を同じ解から決めてから当てる(順によらない)。
3. 地面・壁(固定した面)へ割れていない面でたどれないセルに「分かれた」印を付けて釣り合いから外す(物の物理へ渡すのは R-O1)。
4. 帳簿: 進みの分だけ面から解放されるたわみのエネルギー(変位を止めて)= 払う割れ面のエネルギー + 熱(整数で厳密)。割れ切った面の割れ面のエネルギーは G × 面積。
5. 判定の 2 本(`FractureRule`): ① 縁の応力が強さの形を超えた面は割れ切る ② 強さを超えた面だけ割れ始め、面のエネルギーの比 κ で線形に軟化する(払うエネルギーが G × 面積になる傾き = crack band)。
   **② は式の上で「解放 = 払う割れ面のエネルギー」になり熱 ≥ 0(坂の原理)。① は熱が負になる(払えないのに割れる)**。

## 結果と未決(T-0872)
- 薄い物(棚の下を掘る)と洞窟の天井は 0.5 m と 0.25 m で ±1 セルの内(② は洞窟も同じ幅)。**厚い片持ち梁(2 / 4 セル)の根の角で ① −42 %・② −45 %**(打ち切り条件に当たった)。
- 原因はどちらも「セルの大きさの面で判定する」こと。3 本目の候補 = 判定を材料の長さ(破片の大きさ)で平均する(T-1042)。退く道(22 §5)も面の平均で判定するので同じ所で落ちる見込み(未確認)。

## 検討した代案
- 強さだけ(①): 熱が負(坂を上る)・角の集中を細かいほど拾う。採らない見込み。
- 面ごとのエネルギーの判定だけ(強さを見ない): 滑らかな所では割れ始めの応力が 1/√Δx で変わる(長さ 0 の割れは解放するエネルギーが 0)。22 §3.3 のとおり割れ始めは強さ。
- 割れた面に押し合いと摩擦を残す(瓦礫どうし): 一方向の触れ合いは非線形で、釣り合いの家族(直線の式だけ)に入らない。瓦礫は R-B4・R-O1。

## 影響
- 作り手: 書く値は変わらない(硬さ・強さ 2 つ・割れ面のエネルギー〔書かなければ導く〕・割れの速さ)。
- エンジン: 支えの法則に面ごとの真実 1 つ(割れの進み)と、割れて分かれたセルの印。割れが進んだ刻みは釣り合いの系を作り直す(費用は R-B3 で測る)。

## 追記(2026-10-24・T-1042): 3 本目「材料の長さ ℓ で平均する」の結果
- 形(`FractureRule::Window`): 割れの面を長さ ℓ の区間に分け、区間ごとに引きの側・押しの側の応力の平均・ずれ・エネルギーを平均して 2 本目と同じ判定をし、区間の面を一緒に進める。熱 ≥ 0 は区間ごとに成り立つ(全部の場面で 1 面 1 刻みの最小 0.000 J)。決定的。
- 結果(弱い岩。A 片持ち梁の折れる荷 kN/m・0.5 / 0.25 / 0.125 m): ℓ 0.5 m で 106 / 94 / 86(見込み 77.1。段の差 −11 % / −9 %)、ℓ 1 m で 245 / 237 / 221(見込み 188.2。−3 % / −7 %)。
  1・2 本目の −42〜−45 % から ±10 % 前後まで直った。B(棚を掘る)・C(洞窟)は細かさによらず同じ荷・同じ場所(ℓ 0.5・1・2 m のどれでも)。
- **判定の細かさ**: セル ≤ ℓ/2 で段の差が ±10 % の内、セル = ℓ で外。ただし ℓ/2 以下でも見込みの方へ 7〜9 % ずつ寄り続ける(根の角)。
- ℓ ≥ 物の厚さでは ℓ が効かない(倍率 4 で頭打ち)。区間を世界の原点からそろえる今の形は、置く場所で強さが変わる(厚さ 2 m の梁が ℓ 2 m で 550 ↔ 210 kN/m)→ 物の表面からそろえる(T-1069)。
- すぐ折れる棚(8 m)は 3 本目で 2.1 / 3.7 秒かかる。割れではなく、壁につながる棚の釣り合いが遅いため(T-1041 → T-1068。C-0 の粗い段)。
- **判定の形は 3 本目(Window)を一旦の形とする**(Claude 案。打ち切り条件の「別の道」として A が ±10 % 前後に入った)。ℓ の持ち方は ADR-0448(Proposed)。
