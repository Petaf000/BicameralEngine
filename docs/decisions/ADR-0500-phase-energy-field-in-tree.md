# ADR-0500 世界の木での層のエネルギー Ec の持ち方: 真実の SAME の欄 + セルの配りが部分ごとに書く(T-1211)

- Status: Proposed(Claude の一旦の決定。**土台の登録と当てる段に触るので司令塔へ**。作り手から見た違いは無い)
- 日付: 2026-10-29
- 決めた人: Claude(wt4 の作業役・T-1211)
- 親: ADR-0486 の 1・7(持ち方・細かく/粗くする)・ADR-0497(セルの段の形)・D-674(熱容量の重み)/ 使い手: T-1230・T-1231

## 背景
ADR-0486 の Ec を世界の木の欄(shaders/common/state_field.hlsli の登録)に載せようとすると、今の 2 つの規則のどれにも合わない(2026-10-29 に登録の検査を読んだ):
- **VOLUME**: 登録の検査で「保存量の印 ⇔ VOLUME」(SfDescValid)。Ec を VOLUME にすると世界の帳簿に列が立ち、
  セルのエネルギー(和)と二重に数える。Ec は層の上の面・反応で変わるので保存量でもない。T-1160 のおすすめ(「凝縮相のエネルギー」として VOLUME)はこの検査で通らない。
- **内訳(BREAKDOWN。T-1177)**: 親が保存量の欄で 0 ≤ 内訳 ≤ 親。セルのエネルギーは欄ではなく(セルの頁が持つ)、Ec は化学のエネルギー(H0 < 0 の水など)で負になる。
- **SAME**: 細かく = 子は親と同じ数、粗く = 平均。ADR-0486 の 7(細かく = 層の熱を子の凝縮相の熱容量の重みで・粗く = Σ 子の凝縮相のエネルギー)はどちらもセルの中身(熱容量・相)を読む。
- 細かく/粗くする時のセルのエネルギーの配り(T-1176 の PlaceRefineCell・MultiresNest::refineCells)は、すでにセルの中身を読む「セルの配り」の中にある。

## 決定(一旦)
1. **Ec は真実の欄**: SF_PLACE_CELL・SF_TYPE_I64・SAME・ハッシュに入る(SF_FLAG_HASHED)・保存量ではない・置かれ方の印なし。頁は混ざったセルのある所だけ(疎・無い頁は 0 = ADR-0497 の 2)。
2. **細かく/粗くする時の値はセルの配りが書く**: 欄の一般の段(SAME の写し・平均)の後に、セルの配り(T-1176 の refineCells と同じ口)が
   部分ごとに 2 回の重み(層の熱 → 子の凝縮相の熱容量・気体の熱 → 子の気体の熱容量)で子の Ec を、粗くする時は Σ 子の凝縮相のエネルギー
   (混ざった子は Ec・凝縮相だけの子はエネルギー全部・気体だけの子は 0)÷ 8 の切り捨てで親の Ec を上書きする(和の端数はセルのエネルギーの側の帳簿のまま)。
   その後に PlRemixCondensedEnergy(親や子が混ざらなければ 0)。
3. 欄の一般の段の値は必ず上書きされるので、上書きする側を持たない作り(セルの配りが既定で空 = T-1188 より前)では **Ec の欄を登録しない**(2 つのエネルギーは切る)。

## 土台に足りないもの(司令塔へ。この作業役は足さない)
- (a) 欄の登録: 「セルの配りが書く欄」の印(例 SF_FLAG_CELL_OWNED。一般の段は写さず 0 のまま渡す)を足すか、印なしで一般の段の後に上書きする順を約束にするか。
  おすすめは印を足す(順に頼らない・平均の無駄な計算が無い)。
- (b) 当てる段: 粗くする時のセルの配りの口(今は細かくする refineCells だけ)。Ec の粗くするは子のセルの中身を読む。
- どちらも wt2(multires_tree・gpu_multires。T-1188)の持ち物に重なる。

## 作り手から見た違い
- 無い(Ec はエンジンの中の値で、パッケージの作り手は書かない・読まない。セーブとハッシュに 8 B/混ざったセルが増える)。

## 検討した代案
- 新しい規則 SF_SCALE_PART(細かく = 部分の熱容量の重み・粗く = Σ 部分のエネルギー)を登録に足す: 規則がセルの中身(物質の表)を読むことになり、
  欄の一般の段が物質の表に依存する。退けた(セルの中身を読むのはセルの配りだけ、の形を保つ)。
- 「凝縮相のエネルギー」をすべての凝縮相のセルに持つ(VOLUME の和で粗くできる): 岩のセル全部に頁が要る(疎でない)うえ、保存量の印の検査で通らない。退けた。
- 「凝縮相の熱」(Ec × 1000 − Σ 凝縮相の量 × H0。0 以上)を持つ: 負にならないので内訳に近いが、親(セルのエネルギー)が欄でないので内訳の形にならない。
  単位が µJ になるだけで配りの難しさは同じ。退けた。
