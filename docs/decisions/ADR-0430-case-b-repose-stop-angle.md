# ADR-0430 案 B の R3: 書いた崩れる角度は「山が止まる角度」、降伏の上限は書いた値 + 6°(崩れ始める角度。一旦)

- Status: Proposed(一旦の決定。作業役 T-0997。読み方はユーザーの決定 D-620、差の 6° は Claude の一旦の値)
- 日付: 2026-10-22
- 決めた人: 読み方 = ユーザー(D-620・Q149)。差の値と形 = Claude(作業役 T-0997)
- 関係: ADR-0428・docs/design/21 §1.1・§2.5・§5.2・T-0996・T-0997・D-556・D-620

## 背景
ADR-0428(R3 の 2 本目・面ごとの降伏)は、書いた φ で崩れ始め、勢いで行き過ぎて φ より約 6° 低く止まった(打ち切りの条件 φ ±4° に当たった)。
ユーザーは `repose_angle_deg` を「山が止まる角度」と読むと決めた(D-620。崩れ始めはそれより数度急)。

## 決定(一旦)
1. 降伏の上限(tan φ × 有効な重さ + c_eff)の角度は「書いた値 + 差」。差は法則の定数 `FlowOptions::reposeStartOffsetDegrees`(既定 6°)。作り手が書く値は増えない。
2. 6° は、差 0 で測った行き過ぎ(φ 25°・34°・40° の砂山で 5.5〜7°。0.5 m と 0.25 m で同じ)から置いた。
   差 6° で砂山は 26°・33°・39° に止まり(書いた値 ±1°・2 つの細かさで同じ)、斜面は 31°・38°・44° で崩れ始める(書いた値 + 4〜6°)。
3. 止まり方の式(降伏の後の運動量を持ち越す・上限だけ減らす)は変えない。崩れ始めと止まりの差は、この式の行き過ぎが作る(実験の θ_start − θ_stop の 2〜5° の桁。未確認)。

## 作り手から見た違い
- 砂山を作ると、書いた `repose_angle_deg` の角度で止まる(前は約 6° 低かった)。
- 書いた値より 4〜6° 急な斜面までは崩れずに立つ(掘った直後の壁・積んだ直後の山)。それより急なら崩れて書いた値に戻る。

## 検討した代案と、採らなかった理由
- 書いた値で崩れ始める(差 0。ADR-0428 のまま): 山が書いた値より 6° 低く止まる。D-620 と合わない。
- 動いている面と止まった面で上限を分ける(静の上限 = 書いた値 + 差・動の上限 = 書いた値): 動の上限が書いた値なら行き過ぎが残り、山は書いた値より低く止まる(差 0 と同じ)。
  止まる角度を書いた値にするには動の上限も上げる必要があり、1 つの差と同じになる。
- 速さで摩擦を上げる(μ(I)): 0.5 m のセルでは慣性数 I が 10^-4 の桁で、摩擦がほぼ上がらない(流れる層の厚さが粒 10〜20 個ぶんで、セルで解けない)。

## 未確認
- 差が角度によって少し違う(行き過ぎ 5.5〜7°)。6° の 1 つの値で 25°〜40° は ±1° に入った。もっと緩い(15°)・急な(50°)角度は測っていない。
- 勢いで走る長さが短くなった(柱の崩れ 0.25 m 5.25 → 4.25 m。角度だけの 4.22 m + 0.5 m に届かない)。走る間の摩擦まで上げたため。
  動いている面と止まりかけの面で上限を分ける形は T-1004(記録だけ)。掘った後の角度・ほかの値は T-0997 の表。
  → T-1004(ADR-0442)で分けてみたが走る長さは戻らなかった(打ち切り。既定は分けない)。
