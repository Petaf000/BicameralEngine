# ADR-0385 電気は坂を下る保存量・磁気も法則として持つ(どちらも「釣り合う」家族で解く)

- Status: Accepted(2026-10-21。形はユーザーの決定。作るのは 2 周目で、研究 R-E1〜R-E4・R-M1・R-M2 の結果で退く道に下がることがある)
- 日付: 2026-10-21
- 決めた人: ユーザー(claude/32 S22・claude/33 S29・S30。Claude が案と退く道を出した)
- 関係: D-580・D-581・D-588・設計 24・20(運ぶ計算の共通の土台)・claude/34 S38(釣り合う家族)・S41(真実と導かれる値)・S42(刻みの順)

## 背景
- 電気と金属は ⑦ の後ろの段にあった(ROADMAP)。体験版の作戦は電気を使わないが、電気・磁気の形を後から変えると、欄の持ち方・刻みの順・解き方の家族に手戻りが出る。
- 土台の洗い出し(claude/34)で、陰の圧力・支えの法則・電位・磁場が「領域全体の釣り合いを解く」同じ数学の型だと分かり、「釣り合う」家族を 1 回だけ作る方針になった(S38)。

## 決定
1. **電荷は保存量**(真実)。電位は導かれる値で、釣り合う家族で解く。流れ = 坂 × 通しやすさ、損は熱。速さはほぼ一瞬(刻みの中で坂を下りきる)。
2. **溜まる電気も持つ**(静電気・コンデンサ・雲の電気)。違いは物質の通しやすさ 1 つで、別の仕組みを作らない。
3. **破れ**は反応の家族: 坂が物質の「絶縁の強さ」を超えた面が破れる。熱は 4095 K で頭打ち(D-588)。
4. **電池 = 押す家族**(反応の蓄えで電荷を坂の上へ)。**電気分解 = 電気の仕事を使う反応**。
5. 細い電線は物で持ち、触れた面で電荷を渡す(物の中で全部の家族を走らせる口。S45)。
6. **磁気は法則**: 電流 → 磁場 → 力(物の物理と場へ)、変わる磁場 → 電流(誘導)。帳簿が厳密に合う。
7. 雷は、天候の層が雲に入れた電荷が世界の中で破れて起きる。
8. エンジンは特定の物質を電気・磁気で特別扱いしない。物質の値(電気の通しやすさ・絶縁の強さ・誘電・磁気の通しやすさ・磁石の強さ)を書かなければ、電気も磁気も無い(費用 0)。

## 検討した代案と、採らなかった理由
- 電気: **流れだけ持つ**(回路の電流だけ。溜まる電気なし)。軽いが、雷・静電気を別に用意することになる。→ R-E1 の退く道として残す(雷は天候の層から外から入れる)。
- 磁気: **持たない**(一番軽い。モーター・発電機・方位磁針が作れない)。研究して発明する柱に合わない。
- 磁気: **部品として書く**(モーター・発電機を決まった効率の押す構造の値に)。作り手は扱いやすいが、仕組みは法則から出ない。→ R-M1・R-M2 の退く道として残す。
- 電位・磁場を専用の解き方で作る: 陰の圧力・支えと同じ型を 2 回余計に書くことになる(claude/25 の「同じ仕組みを法則ごとに書き直す」問題)。

## 影響(何がしやすく/しにくくなるか)
- しやすく: 電池・電熱・電球・ショート・静電気・火花・雷・コンデンサ・電気分解・感電・電磁石・モーター・発電機・方位磁針が、物質の値と形だけで出る。
- しにくく: 釣り合う家族(試作の列 1 の C-0)ができるまで作れない。通しやすさが何十桁も違う物が並ぶ所の多重格子の収まり・整数の幅・費用は未確認(R-E1)。
- 欄: 電荷は真実(ある所にだけ)。電位・電流・磁場は導かれる値(起きている所で計算)。1 セルの大きさの見積もり(M-0)に電荷を入れる。
