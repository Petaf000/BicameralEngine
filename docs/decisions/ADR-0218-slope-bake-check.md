# ADR-0218 坂を上る規則のベイクの検査(案 A。警告して動かす)

- Status: Accepted(D-487 ①② の実装。エントロピーの無い物質の扱いだけ Proposed: 仮の案 2・ユーザー未確認)
- 日付: 2026-10-15
- 決めた人: ユーザー(D-487)。検査の定義と仮の扱いは Claude が提案(T-0492)

## 背景
- D-487 ① 反応の向きは作り手が規則ごとに書き、エンジンは坂を上る規則を警告するだけ(案 A)。② 坂を上る書き間違いは警告して動かす(表は当たる)。
- T-0491 で物質に任意の欄 standard_entropy_mj_per_mol_k を足し、試験(倍精度)で boudouard の組が 949 K 以下で坂を上ることを確かめた。

## 決定
1. ベイク(BakeReactionTable の最後)が規則ごと・1 K ごとに ΔG°(T) = Σ ν (h0 + Cp T − T S° − Cp T ln(T / 298.15)) を**整数で**数える
   (engine/src/sim/reaction_slope。fixed.hlsli の ln。どの機械でも同じ判定)。速さの表が 0 でない温度で ΔG° > 0 なら「坂を上る」として警告する。
   警告の文は BakedReactionTable::warnings(頭「坂: 」)、規則ごとの結果は ruleSlopes(パネルの「坂」の欄)。
2. GPU の表とハッシュは変えない(エントロピーは CPU だけ)。表はいつも当たる(起動・ホットリロード・再生)。
3. 「成分しだい」(下るが |ΔG°| < RT ln 10^6)はパネルの注意だけ。成分で決まる行き過ぎの量は開発ビルドの計器(T-0518)で数える。
4. **(Proposed)** 正味の係数が 0 でない物質に標準エントロピーが無い規則は「未評価」とし、まとめて 1 行の警告にする(T-0492 の判断待ち 1。案 1〜5)。
   触媒(両辺で消える物質)はエントロピーが無くてよい。

## 影響
- 標準パッケージ real_reactions の boudouard(一方向)は警告が出る(中身を直すかはユーザー。T-0492 の判断待ち 2)。
- 警告が空であることを確かめていた試験は、坂の警告を除いて数える。

- **2026-10-26 本体の棚卸し(QUESTIONS Q67)**: 坂の警告の仮 → ①〜③ 閉じた(まとめて 1 行の警告・boudouard は一方向のまま警告・成分しだいのしきい値 10^6。D-539)。④ は Q73 ① へ移していた。
