# ADR-0370 1 周目の進め方はウォーターフォール(設計を先に固め、調査は設計の段の中で)

- Status: Accepted
- 日付: 2026-10-21(決定は 2026-10-19〜20 の設計チャット。claude/29 の進め方・Q8c、claude/30 N6・N10a・N10b)
- 決めた人: ユーザー
- 決定の番号: D-533(ほかに D-532・D-535・D-537)

## 背景
- 手戻りの原因は「土台の芯を決めずに現象を先に作った」こと(claude/26 §4。10/17 の土台の直しも今あるコードから逆算していた)。
- ユーザー(2026-10-19 夜): 「最初はアジャイルではなくウォーターフォールでやっていきたい」。
- 壁(claude/30 の洗い出し): 結果が読めない賭け(研究)は紙の上では決まらない。賭けが生きたまま設計を「固めた」ことにすると、固めた後に落ちて大きく戻る。

## 決定
1. **段と関門**(V 字。1 周 = 体験版まで):

   | 段 | 決めること | 中の調査(捨てる試作・測り) | この段で書く試験 | 関門 |
   |---|---|---|---|---|
   | 0 棚卸し | 正の置き場を一つにする(決定の反映・ブランチの仕分け) | なし | — | G0 |
   | 1 要求 | 作戦の一覧(中身は非公開)・体験版の範囲・要る現象の印・法則の約束 | 紙の遊び試験 | 受け入れ試験の台本 | G1 |
   | 2 基本設計 | 案 B の形と予備・圧力の解き方の組み込み・支えの法則・予算と最低機 | 案 B の試作・細かさの比べ・費用の測り | 結合試験(現象の場面と合格値) | G2 |
   | 3 詳細設計 | 欄の配置・GPU の段・口・作り手の道具・試験の回路の仕様 | 作り手の試し書き・VRAM の実数 | 単体試験 | G3 |
   | 4 実装 | 何も決めない(決めることが出たら変更要求) | 禁止 | 単体 → 結合 | G4 |
   | 5 試験 | 体験版が要求を満たすか | — | 受け入れ試験(友人テスト) | G5 |

2. **調査と実装を分ける**: 調査 = 捨てる箱・試作・測り(main の土台の共通部分に足さない = D-532)。設計の段で並走させてよいのは調査と反論役だけ。設計書を書くのは 1 本の流れ。
3. **研究の打ち切り**は「諦める」ではなく「別の道に移る合図」。研究ごとに打ち切り条件と退く道を書き、退く道が尽きた時だけユーザーに出す。**全体の期間は見積もらない**(D-411)。
4. **1 周 = 体験版まで**(N10a)。体験版の外は 2 周目の要求に回し、1 周目では「入る口がある」ことだけ基本設計で確かめる。
5. **段 0 の棚卸しで、案に依らない仕上がりのブランチは入れる**(実装に数えない。N10b)。測りのブランチは結果を記録して閉じる。
6. **遊びの確かめ**(N6): 要求の段に紙の遊び試験。縦切りは案 B の判定(G2)の直後、実装の最初の成果物。
7. 凍結の後の変更は変更要求 1 枚(何を・なぜ・どの段に戻るか・影響する現象 #)。関門で聞くのは 5 問まで。

## 検討した代案と、採らなかった理由
- 今までの並走(チケットを回して試作で直す): 土台の芯が無いまま現象を作り、作業役ごとに共通部分を足して重複が増えた(claude/26 §4)。
- 全体を一度に設計しきる: 賭けが落ちた時の手戻りが大きい。決定の一部(圧力の波・粗さ・見た目)が既に「体験版で確かめて見直す」を含む。
- 研究に時間の打ち切りを付けて全体の期間を見積もる: ユーザーが「できるだけ諦めたくない」で採らなかった(Q8c)。

## 影響
- 作り手(エンジンを使う人)から見て: しばらく main のコードはほとんど増えない。増えるのは設計書・決定・測りの記録と、調査の試作(捨てる前提のブランチ)。
- 司令塔: 並走の作業役には調査(試作・測り)だけを配る。土台の共通部分に足りない物が出たら、作業役は印を付けて返し、設計で直す。
- 今の順(ROADMAP)は「試作の列」(D-538・claude/35)に組み直した。前の ③' の段 5 以降は「列 7(今の縦切り)」として残す。
