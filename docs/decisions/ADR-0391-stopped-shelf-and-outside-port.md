# ADR-0391 世界の外の「止まった棚」と、世界の外との出入りの口(袋・体を置き直す)

- Status: Accepted(2026-10-21。棚の形はユーザーの決定 claude/36 S46。体を置き直す口は一旦の決定 S52 (1)。§「エンジンの形(仮)」は Claude の案でユーザー未確認)
- 日付: 2026-10-21
- 決めた人: ユーザー(claude/36 S46・S52。Claude が案を出した)
- 関係: D-602・D-606・claude/34 S41(真実と導かれる値)・D-586(セーブは真実の差分)・D-419(明示的な出入り)・設計 15 §1.1・§1.2・08(物)・09 §7

## 背景
- 持ち物を全部世界の中に置くと、持ち物の管理・重さ・袋の中の反応がサバイバルの手間になる。ユーザー: 「やりたいのは世界を研究し実験することで、サバイバルではない」。
- 一方、袋の中の物を「札(アイテムの名前と数)」に作り直すと、物 ⇄ 札の変換規則が要り、熱い物・生の物・途中まで反応した物の状態が落ちる(バグの元)。
- 死んだ時・ノートの中身はゲームの中身で、エンジン設計では決めない(claude/36 S53)。エンジンはどちらに決まっても使える口だけを持つ。

## 決定
1. **手に持つ物・身に着けた物は世界の中**(法則がそのまま効く。松明を持ったまま水に入れば消える)。
2. **袋の中は世界の外の「止まった棚」**: 袋に入れた物は真実(S41)をそのまま止めて持ち、出すと入れた時の続きから動く。札に作り直さない(物 ⇄ 札の変換規則を持たない)。
3. **出し入れは世界の出入りとして帳簿に載る**(保存則の検査で差し引く。天候の境目・魔素の湧き出しと同じ「外との出入り」)。
4. **袋の中の費用は 0**(止まっているので刻みで計算しない)。
5. **体を置き直す出来事の口**(S52 (1)): 体(や物)を世界の外から世界のある場所へ入れる出来事。袋の出し入れと同じ口(世界の外 ⇄ 世界)を使う。いつ・どこへ置き直すかはゲームが決める。
6. ゲームの中身(エンジンは値・データで受けるだけ。D-006): 何を袋に入れられるか(燃えている物・器に入っていない液体を入れられるか等)・持ち物の重さを体に効かせるか(既定は効かせない)・死んだ時どうなるか。

## エンジンの形(仮。ユーザー未確認)
- 棚 = 世界の外の物の置き場。物の真実(ボクセルの木の成分・エネルギー・割れの進み・変わった形・勢い)を、入れた刻みのまま凍らせて持つ。
  導かれる値は持たない(出した時に解き直す。セーブと同じ)。袋の中の勢いは入れた時のまま持つか 0 にするかは【ゲーム】の値(既定は 0 = 静かに出る。仮)。
- 出し入れはコマンド(06 §3)で、刻みの境界で起きる。出す場所が塞がっていた時の扱い(押し出す・断る)は、ゲームが決める値(既定は断る。仮)。
- 帳簿: 「外への出入り」の列に、出し入れした物質の量とエネルギーを刻みと一緒に記録する(保存則の検査は外への出入りを差し引いて 0)。
- セーブ: 棚の中身もセーブに入る(真実だけ。15 §1.1)。棚はプレイヤーごと(マルチは無い。D-422 は設計データだけ)。
- 体を置き直す: 同じ口で「世界から外へ出す(体)」→「外から世界のある場所へ入れる」を 1 つの出来事として並べる。体の中の真実(蓄え・温度・成分)は持ったまま運ぶ(変えるかはゲームの値)。

## 検討した代案と、採らなかった理由
- 全部世界の中(袋の中も法則が効く): 一度選んだが、サバイバルの手間になるので変えた(ユーザー)。
- 袋の中を札にする(普通のゲームの持ち物): 変換規則が要り、状態が落ちる。研究ゲームで「入れた物が変わって出る」は偽の法則になる。
- 袋の中も時間が進む(世界の外の簡単な法則で進める): 世界の法則と食い違う第 2 の法則になる。

## 影響(何がしやすく/しにくくなるか)
- しやすく: 持ち物の管理をしなくてよい(実験したい物だけ手に出す)。持ち物の仕組みは「止める・続ける」だけで、法則の書き換えではない。死んだ時の形がどちらに決まっても同じ口で書ける。
- しにくく: 熱いまま・生のまま運べるので、「火を遠くへ運ぶ」ような謎は入れられる物の決め方(ゲームの値)で守る必要がある(ゲーム側の調整)。
- 未確認: 棚の大きさの上限(VRAM か主メモリか)・出す時に解き直す費用。
