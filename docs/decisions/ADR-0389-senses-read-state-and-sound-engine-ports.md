# ADR-0389 感覚は状態を読む・サウンドエンジンが体の状態と地域を読む口・匂いは本物の物質

- Status: Accepted(2026-10-21。ユーザーの決定 claude/32 S20・S27・claude/33 S35。口の中身の形〔設計 11 §3.2 の表・目鼻耳の場所〕は Claude の案でユーザー未確認)
- 日付: 2026-10-21
- 決めた人: ユーザー(claude/32 S20・S27・claude/33 S35。Claude が案を出した)
- 決定の番号: D-593・D-594・D-595・D-596
- 関係: D-006(ゲームの中身は非公開)・D-454・D-469(体は法則、心は行動表)・D-542(真実だけ持つ)・D-584・D-590・D-603(プレイヤーの体)・ADR-0388・設計 11 §3〜§5・09 §3・23

## 背景
- 生き物は匂い・光・熱・音で気付く必要がある(風下から近づく・煙を嫌う・足音に気付く・血の匂いで呼ぶ・匂いの強い物で隠す)。
- ゲームには、聞き手の体の中の状態と今いる地域で、音の聞こえ方を変える遊びがある(中身は非公開の控え)。エンジンに要るのは読む口だけ。

## 決定
1. **感覚は状態を読む**(D-593): 見る = 放射の場の見える帯 × 視線、嗅ぐ = 気体の物質の量と坂の向き、熱い = 温度と当たる熱の流れ、聞く = 法則の音の場(ADR-0388)。
   感覚専用の札・場・欄を作らない。読んでも世界は変わらない。しきい・鋭さは行動表(ゲーム)。
2. **サウンドエンジンの読む口**(D-594): 出来事・続く音のまとめ・聞き手の所の法則の音・**聞き手の体の状態**(物質ごとの量〔読む物質はゲームが登録〕・体温・蓄え・息の成分)・
   **今いる地域**(世界のデータの地域の印・天候の予定の今の値)・周りの広さ。スナップショットと抽出を読むだけ(D-308)。どう聞こえ方に変えるかは全部ゲーム(Luau)。
3. **匂いは本物の物質**(D-595): 匂いを出す反応・風と混ざるで動く・時間で分解する反応で消える。種類の上限を決めない。新しい仕組みは足さない。
4. **R-S1(2 周目)**(D-596): 費用が線の内で種類の数が頭打ちになるかを測り、2 本で合わなければ数種類の匂いの軸に下げる(物質の数を減らすだけ。エンジンの作りは変わらない)。

## 検討した代案と、採らなかった理由
- 感覚専用の場(匂いの場・音の札): 法則と食い違う(世界の物質は消えたのに匂いの札が残る、など)。新しい仕組みが増える。
- 体の状態を読む代わりに「食べた時刻と料理の札」を口に渡す: 体の中の反応(消化)と食い違う。札が法則の外に出る。
- 匂いを最初から数種類の軸に: 匂いの強い物で隠す・混ざった匂いの区別が値だけで書けない。ユーザーの条件は「できるなら本物」。

## 影響
- しやすく: 感覚・匂い・聞こえ方の口は、どれも今ある状態を読むだけ。ゲームの中身がどう決まっても同じ口で書ける。
- しにくく: 匂いの物質の数と薄い所の端数(気体の量子 1 µmol)が費用と届く距離に効く(未確認。R-S1)。

## 仮・ユーザー未確認
- 目・鼻・耳の場所を体の中の点として種類ごとの表に書く形。読む口の表の中身(設計 11 §3.2)。取り消しやすい。
