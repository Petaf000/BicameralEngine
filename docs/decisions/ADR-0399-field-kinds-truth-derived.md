# ADR-0399 欄の登録に種類を持たせる: 真実 / 導かれる値 / 温めた始まり(試作 C-1 の 1 チャット目)

- Status: Accepted(形の細部は Claude。T-0854)。「温めた始まりを状態に入れる」は 2026-10-21 ユーザー決定 D-608 で (A)(前は D-549 の仮)。〔注: 重くなったら (B) に切り替えてよい。切り替えは §3 の 1 行。測るのは T-0922〕
- 日付: 2026-10-21
- 決めた人: ユーザー(D-542 欄の持ち方・眠った所は (b) 粗くして残す)/ Claude(T-0854 の作業役。形の細部)
- 関係: ADR-0373 §3(欄の持ち方)・ADR-0329(登録)・ADR-0361(観察の影の欄)・ADR-0386(セーブ = 初めの状態 + 真実の差分)
- 設計書: docs/design/20-transport-substrate.md §10・§13.2

## 背景
- 20 §10 は欄を「真実(状態そのもの)」と「導かれる値(真実から計算できる)」に分け、眠った所の導かれる値は粗くして残す(D-542 (b))と決めた。
  決まった回数で解く法則の解き始め(温めた始まり)は導かれる値だが答えを変えるので、状態に入れるかは D-608(ユーザー決定 (A) = 入れる。前は D-549 の仮)。
- 今の登録(state_field.hlsli の SfFieldDesc)は保存量か・ハッシュに入るかの 2 つの印しか持たず、眠る(頁を畳む)時は欄が全部ビット単位で一様な時だけ畳む。
  導かれる値(圧力・力など)はセルごとに違うのが普通なので、このままでは導かれる値を持つブロックが眠れない。

## 決定
1. **種類は印 2 つで書く**: `SF_FLAG_DERIVED`(導かれる値)・`SF_FLAG_WARM_START`(温めた始まり。DERIVED と一緒に)。印の無い欄は真実(今の欄は全部真実のまま)。
   種類は `SfFieldKind` で読む(`SF_KIND_TRUTH / DERIVED / WARM_START`)。登録の補助 `SfMakeDerivedDesc`。
2. **種類から決まること**(作業役が欄ごとに考えない):
   | | 真実 | 導かれる値 | 温めた始まり |
   |---|---|---|---|
   | 置き場・規則 | 今どおり | セル・面だけ・SAME・保存量でない | 同左 |
   | ハッシュ(`SfHashed`) | HASHED の印 | 入らない | `SF_WARM_START_IN_STATE`(今 true) |
   | 保存点・写し(`SfSaved`) | 入る | 入らない(戻すと 0。次に解き直す) | `SF_WARM_START_IN_STATE` |
   | 真実の要約(`HashTruthLeaves`) | HASHED の印 | 入らない | 入らない |
   | 眠る(頁を畳む) | ビット単位で一様な時だけ(今どおり) | 畳むのを止めない。覆われていないセルの平均(−∞ 向きの切り捨て)を一様の値の枠へ | 同左 |
   | 起きる(頁に広げる) | 子は親と同じ数(今どおり) | 同左(眠った値を配って解き始める) | 同左 |
   | 木の粗く(一様な親) | 値が違えば親を頁に広げる | 親の値のまま(木の形を変えない) | 同左 |
3. **取り消せる形**: D-549 を (B) にするなら `SF_WARM_START_IN_STATE = false` の 1 行。R-F1 で (b) が使えず (a) 捨てるに下げるなら
   `SF_DERIVED_SLEEP_KEEP_COARSE = false` の 1 行(眠る時に 0)。どちらも state_field.hlsli(CPU と GPU の 1 つの源)。
4. 平均は 128bit で足して割る(`SfMeanSum`・`SfMeanValue`。512 個の 64bit の端の値でも溢れない)。余りは捨てる(保存量でない)。

## 採らなかった案
- 種類を 1 つの値(enum の欄)で持つ: SfFieldDesc の並び(GPU の定数バッファ)が変わる。印 2 つなら並びは今のまま。
- 導かれる値も「一様な時だけ畳む」: 圧力・力はセルごとに違うのが普通で、導かれる値を持つ所が眠れなくなる(20 §10 の芯に反する)。
- 起きた時に粗い値を「比で配る」(観察の影の引き戻し SfPullBackChild): 導かれる値は保存量でなく和を保つ理由が無い。子は親と同じ数(SAME)が単純で、解き始めとして十分(R-F1 で測る)。

## 結果
- しやすく: 新しい法則の欄は「真実か導かれる値か(解き始めか)」を登録に書くだけで、ハッシュ・保存点・眠り方が決まる。
- 確かめ(tests/field_storage_test.cpp): 眠る世界と眠らない世界で真実の要約と Σ 保存量 − 帳簿が毎刻みビット一致・眠っている途中の保存点から戻すと毎刻み同じ要約。
- 残り: ある所にだけ持つ(疎な頁。20 §10.2)は T-0921・GPU は T-0920。今の気体・液体の欄は全部真実のまま(付け替えは使い手が来た時)。
