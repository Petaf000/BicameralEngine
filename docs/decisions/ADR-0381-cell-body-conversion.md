# ADR-0381 セル ⇄ 物の変換を前倒しで作る・抽象化したコマンドも細かい版と同じ物質の値で判定する・骨格 ⇄ 粒は相変化の道で両方向

- Status: Accepted(ユーザーの決定: claude/29 Q4a・C5・C6、2026-10-19。D-520 ② と ADR-0360 §5 を置き換える)。
  変換のきっかけの細部(姿勢が格子に合っている時だけ戻す・行き来の幅)・刃の縁の面積は Proposed(Claude 案。claude/29 W14・W15)
- 日付: 2026-10-21
- 決めた人: ユーザー(設計チャット)/ Claude(反映の作業役 wt4。細部)
- 関係: D-567・D-568・08 §7〜§10・設計 22 §3.5・ADR-0359・ADR-0360・ADR-0379・D-520

## 背景
- D-520 ② は「セル ⇄ 物の変換は最初は作らない(要るとわかったら、セル → 物の一方向だけ)」、ADR-0360 §5 も同じ。
  設計チャット(claude/29 Q4a)で、崩れ落ちる・凍った湖・氷の橋のために前倒しすると決まった。支えの法則(ADR-0379)の欠片(S19)もこの道を通る。

## 決定
1. **セル ⇄ 物の変換を前倒しで作る**。どちらの向きも量の持ち主は一人のまま、刻みの 10(受け渡しと締め)で一度に移し、帳簿の理由「物との受け渡し」に載せる。
   - セル → 物: 支えの法則でセルの据わる固体が割れて、どこにもつながらない塊ができた時。セル以上の塊は物へ、セル未満は同じ物質の粒へ。
   - 物 → 粒: 物が割れてセル未満の欠片ができた時。
   - 物 → セル(Proposed): 物が眠り、姿勢が格子に合っている時だけ(寄せない)。合わない物は眠った物のまま残す。行き来の幅は状態として持つ。
   - 保存はビット単位・開発ビルドで毎刻み保存の検査・往復の乱数の試験。
2. **コマンドの判定**(C5): 抽象化したコマンド(切る・砕く・割る)も細かい版と同じ物質の値(押しの強さ・引きの強さ・割れ面のエネルギー)で、世界の法則と同じ関数で判定する。
   力 ÷ 面積の面積は道具の刃の縁の面積から出し、相手の箱の大きさは使わない(Proposed)。割る仕事 = 割れ面のエネルギー × 新しい面積を出した者から払う(坂の原理)。
3. **骨格 ⇄ 粒**(C6): 骨格 → 粒は応力で起きる相変化(支えの法則で強さを超えた所)、粒 → 骨格は反応(焼き固まる・凍る・押し固める)。
   両方向とも相変化の道(反応の家族・帳簿の同じ理由)に載せ、こねる段(R8)で一緒に作る。粒の大きさは物質の値から出す。

## 影響
- D-520 ② と ADR-0360 §5「変換は作らない」は、この ADR で置き換え(古い行には触らない。本体がマージ後に注を付ける)。
- ROADMAP: 変換の置き場(M5)を前へ。試作の列 3(支え)の R-O1 と同じ道で作る(行の案はチケット T-0870)。
- 08 §8(変換)・§9(コマンド)・§10(骨格 ⇄ 粒)。
