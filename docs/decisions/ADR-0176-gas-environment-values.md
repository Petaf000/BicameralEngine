# ADR-0176 気体の環境の値(音速の基準・基準の温度)の置き場所と、パッケージの分類 environment

- Status: Accepted(2026-10-14 ユーザー決定)
- 日付: 2026-10-13
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- ADR-0151 の 5・ADR-0171(D-480)は「世界ごとに違ってよい値は世界のデータ(パッケージ)、単位の選び方から決まる換算の数は器」とし、
  重力を世界のデータ(`sim::WorldPhysics`。ブランクは 0)にした。続きの「環境の値」(音速の基準・基準の温度)はこの ADR で決める。
- 洗い出し(T-0400 のチケットの表): 気体の値で、エンジンのソースに中身として埋まっていたのは **音速の基準 c̃ = 340 m/s**
  (`GasConfig::soundSpeedMmPerS` の既定)だけ。「地面の層の基準の温度」は定数ではなく、呼び手が渡す基準の大気
  (成分・温度・地面の圧力。`MakeHydrostaticReference`・`MakeGasTree` の引数)から導く値だった。
- 新しい分類の読み込みは T-0398 の「共有の決め事」(反応表と同じ読み込み・分類ごとに別のファイル)に従う。

## 決定(案 A。仮)
1. **音速の基準 c̃ は世界のデータ(環境の値)**: `sim::WorldPhysics::soundSpeedMillimetersPerSecond`(mm/s・uint32)。
   ブランクの世界は 0 = 無い(気体の箱は作れない。気体を使う世界は環境で渡す)。器の `GasConfig::soundSpeedMmPerS` の既定も 0 にし、
   `ApplyWorldPhysics` が重力と一緒に入れる。標準の値 340 m/s(D-440)は重力と同じく `StandardWorldPhysics()` に置く
   (標準パッケージ T-0373 が渡すまでの置き場所。ADR-0171 の 4 と同じ扱い)。
2. **器に残すもの**: 音速の基準の単位(mm/s)・上限(安定の条件 ν ≤ 0.6 → `GasSoundSpeedLimitMmPerS(小刻み)` = 小刻み × 18 m/s。
   既定の小刻み 24 で 432 m/s)・係数への換算(圧力の拡散・α。`MakeGasCoefficients`・`MakeGasBox`)・小刻みの数・
   熱いセルの頭打ちの決まり(`soundCapTemperature`。0 = 地面の層の温度。QUESTIONS Q32 の仮の案 A)・気体定数 R(ADR-0171)。
3. **基準の温度は新しい値にしない**: 地面の層の基準の温度は、世界の基準の大気(成分・温度・地面の圧力)から導く値で、エンジンの定数は無い。
   基準の大気そのものは環境の値だが、成分が物質の名前を指すので、大気の成分と一緒に環境ミキサー(T-0373)で分類 environment に足す
   (気体をサンプルの世界に載せる段 T-0210 まで、呼び手は試験だけ)。
4. **パッケージの分類 `environment`**: 1 つの鍵 = 1 つの値(整数・単位は鍵の名前)。
   `gravity_um_per_s2`(0〜100 m/s²)・`sound_speed_mm_per_s`(0〜安定の上限)。書かない値は 0 = 無い。知らない鍵・整数でない数・
   範囲の外は読み込みの誤り(どの鍵か・どのパッケージが書いたか付き)。Mod・環境ミキサーは鍵ごとに足す(合わせ方は反応表と同じ)。
   読む所は `script/environment_package.{h,cpp}` の `ReadWorldEnvironment`、型は `data/types/bicameral.d.luau` の `Environment`。
   合わせた表に入るので、表の版と再生ファイルの表の中身に入る(環境を変えた世界は版が変わり、再生は記録の表の中身から同じ環境を作り直す。14 §2)。
5. **サンプルの世界**は `data/packages/combustion_test/environment.luau` に地球の値(重力 9806650・音速の基準 340000)を書き、
   窓の `--world sample` はベイクした表の環境の値で物理の重力を作る(今までの `StandardWorldPhysics()` と同じ値。environment_package_test が確かめる)。

## 検討した代案と、採らなかった理由(作り手から見た違い)
- **案 A(おすすめ・仮で実装)**: 作り手は環境に音速の基準を数で書く。
  - 作り手から見た違い: 気体を使う世界は `sound_speed_mm_per_s` を書く(書かないと気体の箱が作れない)。書いた速さで圧力の波・衝撃波が進む。
    大気の成分・温度と食い違う値(例: 二酸化炭素だけの大気に 340 m/s)を書いても黙って通る(実際の速さは書いた値になる)。
    安定の上限を超える値は読み込みで誤りになる。
  - 試験: 標準の値でビット一致(値の置き場所が変わっただけ)。
- **案 B: 器が地面の基準の大気から本物の音速を導く**(作り手は書かない。書けば上書き = 案 A との合わせ技も可)。
  - 作り手から見た違い: 大気を変えると音速が自動で追従する(二酸化炭素の大気で約 270 m/s・熱い大気で速い)。書き間違いの余地が無い。
    ただし軽い・熱い大気(水素の大気で約 1300 m/s)では小刻み 24 の上限を超えるので、小刻みを自動で増やす(気体の費用が比例して増える)か
    誤りにするかの決まりが要る。
  - 費用: 今の 340 m/s(試験の空気の本物は 343.7 m/s)から α = 1 に変わり、気体の試験の結果(ハッシュ)が少し変わる。整数の平方根と、
    係数を基準の大気の後に作り直す順番の変更が要る。→ 選ぶなら別のチケット(T-0443)。
- **案 C: 器の定数のまま** — D-454(エンジンは中身を持たない)に反する。採らない。

## 影響
- しやすくなる: 環境ミキサー(T-0373)で重力と音速の基準を鍵ごとに足す・外す。`StandardWorldPhysics()` は試験の場面だけが使う形になり、
  標準パッケージができたら消せる。
- しにくくなる: 古い再生ファイル(環境の分類が無い表)のサンプルの世界は、再生すると重力 0 になる(今は保存した再生ファイルは無い)。
- 未対応: 環境の値のホットリロード(表は差し替わるが、物理の重力は世界を作った時の値のまま。T-0444)。

## 追記(2026-10-13・T-0373)
- 決定 1 の「標準の値 340 m/s は `StandardWorldPhysics()` に置く」は、標準パッケージ earth_environment に移した(エンジンから消した。ADR-0171 追記 3)。
- 決定 3 の基準の大気は ADR-0182(分類 atmosphere + environment の atmosphere_temperature_mk・atmosphere_surface_pressure_pa)。

## ユーザーの決定(2026-10-14)
- D-489 ①: 案 A(作り手が環境の値に書く)。T-0443 は作らない。
