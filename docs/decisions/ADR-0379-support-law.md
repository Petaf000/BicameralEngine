# ADR-0379 支えの法則: 固い物は硬さでたわんで釣り合い(「釣り合う」家族)、割れ・曲がりは反応の家族で坂を下る時に起こす。強さは押しと引きの 2 つ

## 背景
- 経緯(上書きの鎖の最終形だけを残す): 支えは「つながりだけ」→ 物質に強さ 1 つ(claude/29 Q4b)→ 曲げも持つ = 硬さを足す(claude/30 N7)→ 強さは押しと引きの 2 つ(claude/32 S10)。
- 強さ 1 つと比べるだけでは、支え方が一つに決まらない形(両端と中ほどで支えた梁)で力の分かれ方が決まらず、エンジンが勝手に分けると偽の法則になる(格子の向きで強さが変わる・アーチが梁より強くならない)。

## 決定
1. **法則**: 固い物は力が掛かると硬さでたわんで釣り合う。たわみと中の力は導かれる値。テコ・アーチ・両端で支えた梁が法則から出る。
2. **解き方は「釣り合う」家族**(陰の圧力・電位・磁場と同じ型。claude/34 S37・S38): 世界の多重解像度の木を多重格子の段に・決まった回数・前の答えから温めて始める・
   力は面の形で保存が解の精度によらず厳密・変わった所から物理の長さ(変わった所の大きさの倍数)で閉じる・整数・決定的。釣り合いの家族は直線の式だけを持つ。
   解けきらない場面は決まった回数のまま進み、釣り合いに着くまでの刻みの数と見た目を試作で記録してユーザーに見せる(S38)。
3. **割れ・曲がり・破れは反応の家族**(刻みの 9): 強さの形「押し合い × 摩擦 + くっつく強さ」(押しの強さと引きの強さから c と φ が一つに決まる)で割れ始めの所と向きを決め、
   **割れた方がエネルギーの坂を下る時**(解放されるたわみのエネルギー ≥ 割れ面のエネルギー × 面積)に割れが進む。出るのは熱と割れ面で帳簿に載る。割れは物質の値の速さで進む(N8)。
4. **物質の値**: 硬さ・押しの強さ・引きの強さ・ねばさ(もろい/ねばい。S15)。割れ面のエネルギー・破片の大きさは書かなければ導く。温度の表で変えてよい(ADR-0380)。
   押し = 引き → 強さ 1 つの物、無限 → 割れない物(特別な仕組みは作らない)。硬さを書かない固体は支えの法則に入らない(ブランクの世界は今とビット一致)。
5. **粒と一つの形**: 粒の「崩れる角度 + くっつく強さ」は、くっつく強さ ≈ 0 の同じ形。割れた岩は、くっつく強さを失った同じ物質の瓦礫(粒)になる(R-B2 で確かめる)。
6. **揺れの分け目**(S11): 一番遅い揺れの周期が分け目の時間(秒。世界の定数。仮 0.1 秒)より短い物は釣り合いだけ解き、長い物は物の物理(柔らかい関節の列)で揺らす。
   作る時に形と物質から決め、作り手は置き方(セル / 物)で選び直せる。同じ物はどちらでも同じ強さで壊れる。
7. **欠片**(S19): セル以上は物、セル未満は同じ物質の粒。表現が変わる出来事は破片の大きさ(物質の値)で決まる細かさで起こす(箱の大きさから出さない)。
8. **退く道(一旦の決定。N7)**: R-B1〜R-B3 が打ち切りに当たったら「重さの流れ(曲げ無し)」= 各つながり面が強さ × 面積まで重さを運び、運びきれない最小の切り口で割れる。
9. 欄: 割れの進み・ねばい物の変わった形は真実(ある所にだけ)。たわみと力は導かれる値(claude/34 S41)。刻みの順は claude/34 S42 の 5(釣り合う: 電位 → 磁場 → 支え)・9・10。
10. **(Proposed)割れ方の旗は作らない**: 08 §3 の前の版にあった「決まった割れ方」「きれいに切れる」の上書きは作らない。上書きは値と形だけ(D-465)。T-0870 でユーザーに確かめる。

## 案と見送った理由
- 強さ 1 つ(Q4b): 押しに強く引きに弱い石・鉄筋・下から割れる天井が出ない。
- 重さの流れを本命に: テコ・たわみの前触れ・アーチの得を失う(退く道としては残す)。
- 揺れも全部解く(固い物の波を毎刻み): 岩・地面の速く小さい揺れは刻みより速く見えず、費用だけ大きい。
- 強さだけで割れを決める: 点の力が細かいほど大きく見えるので、割れが細かさで変わる(D-465 細かさによらない一貫性)。

## 研究(合格と打ち切りは 22 §6。どれも 2 本でだめなら退く道)
R-B1 釣り合い / R-B2 細かさによらない割れ・粒と一つの形 / R-B3 費用 / R-B4 連鎖と破片 / R-B5 揺れの分け目 / R-B6 ねばい物 / R-O1 物の物理への受け渡し(落ちたら司令塔とユーザー)。

## 影響
- 作り手: 固い物に硬さ・強さ 2 つ・ねばさを書く(書かなければ今と同じ)。割れ方は形と値で書く。
- エンジン: 釣り合う家族の使い手が 1 つ(C-0 の上)・反応の家族に割れ・曲がりの規則・刻みの 10 で物を分ける・セル ⇄ 物の変換(ADR-0381)。
- 試験: 22 §6 の場面(片持ち梁・両端で支えた梁・アーチ・洞窟の天井・1 セルの張り出し・45° の梁・曲げた鉄)・0.5 m と 0.25 m・CPU と GPU のビット一致・帳簿。
