# ADR-0037 実験室の箱は「多重解像度の本物の根 1 つ + コマンドを当てる Compute」で作り、GPU と CPU を刻みごとに比べる

- Status: Accepted(実装の細部。ユーザー未確認の点はチケット T-0142 の「判断待ち」)
- 日付: 2026-10-09
- 決めた人: Claude(CLAUDE.md §5。T-0142)

## 背景
- 14 §2 の「実験室」: 小さな箱の世界で反応を試し、CPU リファレンスと並べて比べる。反応表を書く人(ユーザー)が、書いた規則が
  思った通りに燃える・分解するか、GPU が CPU リファレンスとビットで同じか、をその場で見る道具。
- 原則 1(D-107): CPU は世界の状態を書き換えない。物を置く操作もコマンド(sim/command.h)として渡す。
- 仮の世界(ProbeSim の 64³)は大きく、物理と一緒に動いていて、実験の箱としては重い(保存点 1 つ 33 MiB・パイプラインの作成も重い)。

## 決定
- **箱 = 多重解像度の木(sim/gpu_multires・sim/multires_nest)の本物の根 1 つ**(8³ セル、レベル 0 = 0.5 m 角 → 4 m 角。初めは 300 K の空気。
  外とは熱も物も通さない)。刻みは今の木と同じ `RecordStep` / `StepNest`(反応は待ちの丸め + 熱の伝導)。仮の世界とは別の世界。
- **置く操作はコマンド**(`LAB_COMMAND_TYPE_FILL` = セルの中身を物質 3 つまでと温度で置き換える、`LAB_COMMAND_TYPE_TEMPERATURE` = 温度を決める)。
  当てる関数は `shaders/common/lab_box.hlsli`(HLSL と C++ で共通)。GPU は刻みの前に `shaders/sim/lab_box.hlsl`(1 スレッドで列の順に当てる)、
  CPU リファレンスは `sim::ApplyLabCommands`。当てたブロックは「つつかれた」にして、次の刻みで全部のセルを評価し直す。
  当てられないコマンド(箱の外・物質の誤り・温度が範囲外)は両方とも飛ばす。
- 箱の根は**いつも頁を持つ**(GPU のコマンドは頁のセルに書く。一様のブロックに 1 セルだけ書く道は木の管理になるので作らない)。
  頁を畳む(FoldQuietPages)は箱では呼ばない。
- **比べ方**: 1 刻みずつ GPU のリストを投げて待ち、箱を読み戻して CPU の箱と状態の全部(HashWholeNest)を比べる。違えば最初に違ったセル
  (番号の順)、セルが同じなら違う欄(見出し・端数・帳簿など)を出して止まる(sim::FindLabMismatch・sim::LabSession)。
- **記録と再生**: 実験の記録 = コマンドの列 + 刻みごとのハッシュの列(初めの箱は決まっている)。読み直して初めの箱から流し直すと、
  ハッシュの列が記録と同じかも確かめる。ファイルの形は `sim::SerializeLabRecording`(`BLAB`・版 1)。
- 箱は自分の compute キュー(ImmediateQueue)で 1 刻みずつ待つ(エディタの道具。ゲームのフレームの歩調〔ADR-0011〕の外)。

## 検討した代案と、採らなかった理由
- **仮の世界(ProbeSim)をもう 1 つ小さく作る**: 64³ が固定で、物理・抽出・保存点まで付いてくる。箱の大きさを変える道が無い。
- **1 セルだけの反応(reaction_cells.hlsl・AdvanceLoneReactionCell)を並べる**: 一番簡単だが、セルの間の熱の伝導が無く、
  「火が隣へ移る」を試せない。
- **CPU で箱を作り直して毎回写す(置く操作をコマンドにしない)**: 簡単だが原則 1 に反し、記録と再生の形がゲームの世界と違ってしまう。
- **コマンドを並べて当てる(1 スレッド 1 コマンド)**: 同じセルに当たるコマンドの順が結果を決めるので、並べると順番が決まらない。
  数が小さい(1 刻み 64 まで)ので 1 スレッドで足りる。

## 影響(何がしやすく/しにくくなるか)
- しやすい: 反応表(T-0021 のパッケージ)を変えたら、その場で箱で燃やして GPU と CPU を比べられる。食い違いは最初の刻みとセルで分かる。
  箱の刻みは本物の木の刻みそのものなので、木の反応・伝導の不具合も小さな場面で再現できる。
- しにくい: 箱は 1 レベル・閉じた 8³ だけ(細かくする・流れ・気体の移動は無い)。大きな箱・細かくした箱は木の要求で作れるが、まだ作っていない。
  今の表は試験の表(燃焼・熱分解)に固定(パッケージの表を読むのは T-0157 の後)。
