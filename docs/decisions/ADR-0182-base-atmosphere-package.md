# ADR-0182 基準の大気(成分・温度・地面の圧力)をパッケージに書く形

- Status: Accepted(改訂あり)(2026-10-14 ユーザー決定)
- 日付: 2026-10-13
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- ADR-0176 の 3: 地面の層の基準の温度はエンジンの定数ではなく、世界の基準の大気(成分・温度・地面の圧力)から導く値。
  基準の大気そのものは環境の値だが、成分が物質の名前を指すので、環境ミキサー(T-0373)で足すことにしていた。
- 気体の層の基準(`sim::MakeHydrostaticReference`・`MakeGasTree`)は、成分の割合(Q32)・温度(mK)・地面の圧力(µPa)を引数に取る。
  今は試験だけが呼び、気体を世界に載せる段(T-0210)が世界の値から呼ぶ。

## 決定(案 A。仮)
1. 成分は新しい分類 **`atmosphere`**(1 つの鍵 = 1 つの物質。値は物質量の割合の ppm。足して 1000000)。
   温度と地面の圧力は分類 `environment` の 2 つの鍵 **`atmosphere_temperature_mk`**・**`atmosphere_surface_pressure_pa`**。
2. 検査はベイク(`sim::BakeWorldAtmosphere`。engine/src/sim/world_atmosphere.*): 知らない物質・割合 0・合計が 1000000 でない・
   成分があるのに温度か圧力が無い(か、その逆)は読み込みの誤り。全部書かなければ空(ブランクの世界。D-455)。
   ベイクした表の `atmosphere`(物質 ID の順)に入り、表の版・再生ファイルの表の中身に入る。
3. 読む所は `script::ReadWorldAtmosphere`(environment_package.cpp)、型は data/types/bicameral.d.luau。
4. 地球の値は標準パッケージ `earth_environment`(ISA の海面 15 ℃・101325 Pa・乾いた空気 N2 780780・O2 209460・Ar 9340・CO2 420 ppm)。
5. 基準の大気は「セルを満たす」ことはしない(層の基準の値だけ)。セルを空気で満たすのは別の標準パッケージ `earth_air`(分類 world_cells)。

## 検討した代案と、採らなかった理由(作り手から見た違い)
- **案 A(おすすめ・仮で実装)**: 成分は分類 atmosphere に物質ごとの鍵で、温度と圧力は environment の鍵。
  - 作り手から見た違い: Mod が成分を 1 つずつ足す・上書きできる(例: 魔素の気体を 1 つ足す時は、ほかの成分を減らす鍵の上書きも要る。
    合計が合わなければ読み込みで止まり、どのパッケージの何が違うかが出る)。
- **案 B: environment の中に成分の表を入れ子で書く**(`environment = { atmosphere = { nitrogen = ... } }`)。
  - 作り手から見た違い: 大気がひとまとまりに見えるが、Mod は大気を丸ごと置き換えるしかない(鍵ごとに足せない。ADR-0031 の合わせ方は 1 段)。
- **案 C: 割合ではなく 1 m³ あたりの物質量で書く**(温度と圧力は量から導く)。
  - 作り手から見た違い: 圧力を直接書けず、温度を変えると圧力も変わる。理想気体の計算を作り手がする。

## 影響
- しやすくなる: 気体を世界に載せる段(T-0210)が、表の基準の大気から層の基準を作れる。環境ミキサーで地球の大気を足す・外す。
- しにくくなる: 合計をちょうど 1000000 にする必要がある(端数を作り手が合わせる)。
- 未対応: 基準の大気から音速を導く(ADR-0176 の案 B・T-0443)。環境の値のホットリロード(T-0444)。

## ユーザーの決定(2026-10-14)
- D-490 ②: 基準の大気は高さごとに書けるようにする(高さで成分・温度が変わる)。書き方は T-0499 で決め直す。
