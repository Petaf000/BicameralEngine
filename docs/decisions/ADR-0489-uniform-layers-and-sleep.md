# ADR-0489 成分ごとの層の 2 段目: 一様の枠の層・眠る判定の「残り」・層を使う世界(案)

- Status: Proposed(仮。T-1220 の作業役が司令塔の仮の決め〔2026-10-26〕どおりに入れた。ユーザー未確認)
- 日付: 2026-10-27
- 決めた人: Claude(T-1220)
- 設計: docs/design/20-transport-substrate.md §10.5 / 前: ADR-0481 の 5(D-678)/ 関係: T-1210・T-1220・T-1221

## 背景
ADR-0481 の 5 は、セルの成分(物質)ごとに「そのうち積もった層の量」を持つ形に決まった(D-678)。1 段目(T-1210)は頁のセルだけに入れ、
一様の枠・細かくする / 粗くする・溢れの成分・眠る判定は 0 に戻すか畳まないで逃げていた。2 段目(T-1220)でこれらを埋める時に、ADR-0481 の 5 の
文面どおりでは書けない所が 2 つ出た(T-1210 の「土台に足りないもの」1・2)。

## 決定
1. **一様の枠は成分ごとの層を持つ**(ADR-0481 の 5 の 1「一様の値の枠は層 = 0 か全部が層の 2 つだけ」を改める)。
   「全部が層」では、隙間の空気(層にならない成分)が混ざった一様の砂の床が書けないため。持ち方は「0 でない層の物質と層の量の組」(層のある枠だけ。疎)で、
   読む時は今の一様の値(溢れまで)と物質で結んで `層 = min(層, 量)`。2 つの値はこの特別な場合。
   - 畳む(頁 → 一様): セルに加えて層まで一様な時だけ。ほぼ同じ頁を平均で畳む道(許容差つき)は、層のある頁では使わない。
   - 広げる(一様 → 頁): 覆われていないセルに一様の値の層を写す。細かくする時の一様な子は親と同じ層。
   - 粗くする時、一様な親のまま残れるのは、一様の値に加えて層も同じ時だけ(違えば頁に広げる)。
2. **眠る判定の「残り」は粒の物質だけで数える**(ADR-0481 の 3 の「残りのある頁は畳まない」の読み方)。気体・液体の成分は層にならないので、
   その残りまで数えると空気のある頁が眠れない。粒の物質 = 物質の表の相の印 `RX_SPECIES_GRAIN`。
3. **層を使う世界(`EnableCellLayers`)を作り手が選ぶ**。使う世界では、粒の物質の層でない分(残り)は舞う粒:
   細かくする時は空きに同じ濃さで配り(層は沈む側)、舞う粒のある頁は畳まない(2)。使わない世界(既定)は今と同じ(粒は全部沈む側として配り、
   眠る判定も今のまま)。層の持ち方・付け替え・細かくする / 粗くする時の配りは、どちらの世界でも同じ。
   - 理由: 1 段目のまま「層の並びが無い = 層 0 = 全部が舞う粒」と読むと、層を書く法則がまだ無い世界の砂が全部舞って眠らなくなり、
     層の無い世界がビット単位で今と同じでなくなる(T-1220 の完了条件)。
4. **細かくする**: 層を持つ成分(と層を使う世界の粒)は「層 = 沈む側(凝縮相)」と「残り = 物質の置かれ方」の 2 つの物質に分けて置かれ方で配り、
   子の層 = 子へ配った層の分。子の量の和 = 親 × 8・子の層の和 = 親の層 × 8(ビット単位)。層の無い成分は前と同じ 1 つの物質。
   置かれ方で配らない(SAME)セル・世界は、子は親と同じ量と同じ層。
5. **粗くする**: 成分ごとに子 8 つの層の和 ÷ 8 の切り捨て(粗いセルの量で抑える)。切り捨ての余りは層から残りへ移る(量の保存は今のまま)。
6. **溢れの成分**(溢れを使う世界。T-0187): 溢れの領域に成分と同じ並びの層を持つ(層のある領域だけ)。書く時は書く前のセル(インライン + 溢れ)と
   物質で結ぶので、インライン ↔ 溢れの間で物質が動いても層は物質についていく。

## 【エンジン】作り手から見た違い(3 の問い。ユーザーに確かめる)
- 問い: 層を使う世界で、層を書かずに置いた粒(根を置く・パッケージの初めの場面)を「舞う粒」と読むか、「全部が層」と読むか。
  | | (a) 舞う粒と読む(入れた形) | (b) 全部が層と読む |
  |---|---|---|
  | 作り手から見た違い | 砂の床は層として置く(層つきの置き口で)。置き忘れると、その砂は細かくすると空中に同じ濃さで広がり、頁は眠らない(重くなる) | 何も書かなくても砂は積もる。舞わせる時だけ層から残りへ移す法則を書く |
  | 費用 | 置く時に層を書く分だけ | 「層の並びが無い」と「層 0」を分けて持つ印が要る(付け替えの規則が 2 つになる) |
  | おすすめ | (a)。規則が 1 つのまま(層 = min(前の層, 量)・増えた分は残り)で、無い = 0 が保たれる | |
- 今の根の置き口(`PlaceRootBlock`)は層 0 で置く。(a) のままなら、層つきの根の置き口(と環境のパッケージからの置き方)が要る(分けたもの: T-1220 のチケット)。
- 2026-10-29 T-1236: 置き口は (a)(b) 共通にした。層つきの根の置き口 `PlaceRootBlock(…, layers)`・パッケージの `world_cells` の `settled_umol`(層 > 量・中身に無い物質はベイクの誤り)。
  書かなかった粒の読み方は `UnwrittenGrainLayers` の値 1 つ(world_layout.h の `UNWRITTEN_GRAIN_LAYERS`。仮 = Floating: 層 0 + ベイクの知らせ / Settled: 層 = 量)。
  (b) に決まった時に残るのは「層の並びが無い ≠ 層 0」の印(刻みの付け替え・層なしの置き方)だけ。
- 2026-10-29 T-1241: 層を使う世界はパッケージの環境 `environment.cell_layers = true`(書かない = 使わない。名前は仮)で選ぶ(`WorldPhysics::cellLayers`)。
  多重解像度の木には `ApplyCellLayersChoice` が当てる。層を書かなかった粒の知らせ(`unsettledGrainNotes`)は、使う世界だけ表の警告(`BakedReactionTable::warnings`)に出る。
  (b) なら知らせが作られないので警告も出ず、選ぶ口も警告の道もそのまま(作り直さない)。

## 限り(T-1221 で直す)
- GPU は層を知らない: GPU から読んだ列はインラインの層を付け替えで保ち(`層 ≤ 量`)、溢れの成分の層は消す。溢れを使う世界の一様の値の層は読み戻しで結び直さない(読む時に結ぶので `層 ≤ 量` は保たれる)。
- 観察の枠(影)の引き戻しは付け替え(`層 = min`)だけ。
- 2026-10-29 T-1221 の 1 段目: 頁の層は GPU に置いた(層の頁・刻みの後に層を合わせる段。層の頁を持つ GPU では読み戻しが CPU の頁の層を GPU の層で置き換える)。GPU の木の段・一様の枠の層・溢れの成分の層は T-1240(それまで層の頁を持つ GPU は、一様の枠の層・溢れの世界の層を写さずに断る)。影は T-1239。

## 取り消し方
- 1: 一様の枠の層を持たなければ(`MultiresCellStore::uniformLayers` を空のまま)1 段目と同じ(層のある頁は畳まない)。
- 2・3: `EnableCellLayers` を呼ばなければ今と同じ。全部の残り(気体も)を数えるなら `HasFloatingGrain` の粒の印を外す。
- 4・5: 層の無い世界はビット単位で今と同じ(multires 系・placement_refine・tree_refine_placement の試験)。
