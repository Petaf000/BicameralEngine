# ADR-0268 1 セルの体積を相で分け合う(固体 + 液体 + 残りが気体。空きが流れを決める。T-0593・T-0612)

- Status: Accepted(2026-10-17 ユーザー決定。D-505。QUESTIONS Q94 を閉じた)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- 気体(ADR-0256)は固体を素通しにし(木箱・岩・壁が煙を通す)、液体(ADR-0266)は「液体でない凝縮相を少しでも含むセルは壁」だった
  (砂 1 µmol でも水を止める)。同じセルを読む 2 つの流れが、固体について逆の決まりを持っていた。
- 液体が入っても空気は押し出されず、孔のある物(砂・土・木)に水が染みることも、孔を空気が通ることも書けなかった。
- T-0609 で物質に密度(density_kg_per_m3)が入り、ベイクがモル体積(mm³/mol)を作っていた(液体だけが使っていた)。

## 決定(仮)
1. **一つの芯: セルの体積 = 固体が占める分 + 液体が占める分 + 残り(気体)**。占める分 = Σ 物質量 × モル体積(密度から)。
   `sim/cell_volume`(ShareCellVolume・LiquidOpenQ16・GasOpenQ16)が 1 か所で数え、気体と液体の段の両方がそれを読む。
   - 液体の空き = (セル − 固体)÷ セル、気体の空き = (セル − 固体 − 液体)÷ セル(Q16。0 で頭打ち)
   - 面の開き = 両側の空きの小さい方(孔の形〔透水の係数〕は読まない。T-0616)
2. **密度を書かない物質は場所を取らない**(体積 0。今までの気体と同じ)。気体の物質は書いた密度があっても場所を取らない(圧力で決まる)。
3. **気体**(gas_reference の GasBox::openQ16。空 = 全部 = 今までとビット単位で同じ):
   本物の圧力 = n R T ÷(セル × 空き)・基準との質量の差は「基準 × 空き」と比べる(固体の多いセルの静かな大気に浮力を作らない)・
   一部だけ開いた面は、開いた所を両側の平均の圧力、塞がった所を各側自身の圧力(壁の鏡)で押し、差は塞いだ物が受けて帳簿へ・
   面の質量の流れは各側の運動量を「面の開き ÷ その側の空き」倍、圧力の拡散を開きの倍(どちらも 1 以下で安定の条件は緩くなる)・
   気体の無いセルは押さない。空きが 0 のセルは気体を通さない(中に気体ができても閉じ込める)。陽解法だけ(投影・木・GPU は T-0617)。
4. **液体**(probe_liquid): 「固体を少しでも含めば壁」をやめ、空き(セル − 固体)で満ち具合・溢れ・下の支えを数える。
   圧力は「質量 ÷ 空き」(孔の中の水も開けた水と同じ高さで同じ圧力)。面の力と重さは開きの割合だけ効き、残りは固体が受けて帳簿の壁へ。
   空きが 0 のセルは壁。孔が液体で満ちるまで上の液体を支えない(上の水は孔に染み込む)。
5. **液体が空気を押し出す**のは 1 の芯からそのまま出る: 液体が入ると気体の空きが減り、圧力が上がって気体の段で押し出される。
   逆向き(閉じた所の空気の圧力が液体を押す・水の下に閉じ込められた空気の泡)は T-0618。
6. **燃えて固体が減る・溶けて液体になる**などで成分が変わると、次の刻みの空きがそのまま変わる(空きは毎刻みセルから作る。持つ欄は増えない)。

## 影響
- 作り手から見て: 固体の物質に `density_kg_per_m3` を書くと、その量に応じてセルの場所を取る。セルを満たす量の岩・壁は気体も水も通さず、
  半分を占める砂は気体と水を通しにくくし(孔に水が染みる)、少しの砂は通す。書かなければ今どおり気体は通る(液体は今までと違い、
  密度の無い固体も通す — 判断待ち 1)。液体は密度が要る(T-0609 と同じ)。
- 状態・ハッシュ・保存点の形は変わらない(空きは毎刻み作る)。密度を書いた固体の無い世界・空きが全部のセルだけの刻みは今までとビット単位で同じ。
- 試験(CPU・cell_volume_test): 満ちた砂の壁は気体も水も 0 µmol 通す、1 µmol の砂・密度の無い砂は砂なしの 95% 以上、半分の砂は間、
  満ちた壁を途中で半分にすると渡り始める、砂の床に水が染み込む、水が落ちると下のセルの空気が上へ移る。毎刻み保存はビット単位。

## 代案(採らなかった)
- A. 固体ごとに「気体を塞ぐ / 液体を塞ぐ」の印を書く: 量に依らず、燃えて減っても塞いだまま。孔を通る・染みるが書けない。
- B. 固体が少しでもあれば壁(液体の今の形)を気体にも: 砂 1 µmol が煙も止める。木箱の孔の空気(燃える酸素)が閉じ込められる。
- C. 透水の係数(Kozeny–Carman の φ³ ÷ (1 − φ)²)まで最初から入れる: 孔の形が物質の性質になり、作り手が書く欄が増える。
  まず空きだけで形を作り、遅すぎる / 速すぎるが場面で見えたら T-0616 で足す。

## 追記 1(2026-10-17・ユーザー決定 D-505)
