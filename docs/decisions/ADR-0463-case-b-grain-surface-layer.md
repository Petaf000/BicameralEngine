# ADR-0463 案 B の R3: 粒の表面のセルを層として数える形(① と同じ芯)は採らない。空気ありの止まる角度は案 B の判定で落ちる所(研究の打ち切りの記録)

- 関係: ADR-0441・ADR-0449・ADR-0457・docs/design/21 §2.3〜§2.5・§5.1・§5.2・T-1043・T-1070・T-1071・T-1091・D-556・D-620・D-641

## 背景
ADR-0441 の後、空気のある所で砂山が平らになる(芯 0° / 10°。真空 36° / 28°)。T-1070 で平らさは粒と空気の引きずりの強さだけで決まると分かった。

## 試したもの(`FlowOptions::grainSurfaceLayer`・`grainSurfaceLayerMoving`。既定 false。T-1070 の摩擦を解きの中へと一緒に)
1. 支えられた詰まり切らないセルの横の面は空気とつながない(止まった粒は孔でもない障害物・動く粒は引きずり 0)。支えられていない詰まり切らないセルは 1 粒の抗力 × 粒の数だけ。
2. 1 のうち動く粒の面はつなぐ。

## 結果
- 1: 砂山 15° / 13°・粒が 46〜199 m/s で暴れて止まらない・柱の崩れ 7.0 / 16.0 m。2: 0° / 0°・斜面 45° → 4° / 11°。
- 詰まり切らないセルが沈み固まるのに 1.5〜3.5 秒(真空の 3〜4 倍。T-1091)。

## 決定
- どちらも採らない(既定は ADR-0449 のまま)。① の芯(相ごとの柱 + 境の剪断)は、摩擦で止まる・動く粒の層には閉じない(粒を圧力の系に残すと圧力に押される重い相になる)。
- 空気ありの止まる角度は、案 B の判定(21 §5.1)で R3 が落ちる所としてユーザーに上げる。案 A へは戻さない(D-556)。代案の表は T-1071。

## 作り手から見た違い
- 無い(既定は変えていない)。今の案 B の形では、空気のある所の砂山は書いた `repose_angle_deg` より大きく低く止まる。
