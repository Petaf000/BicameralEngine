# ADR-0310 流れる区画(気体・液体)を世界のデータに書く(T-0671)

- Status: Proposed(仮・ユーザー未確認。T-0620 の判断待ち 2・T-0671 の判断待ち)
- 日付: 2026-10-17
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- 気体(T-0592・ADR-0256)と液体(T-0613・ADR-0266)の区画は ProbeSimOptions::gas・liquid で作るが、それを書く道が試験の C++ にしか無かった。
  アプリ(--world・--packages・エディタ)の世界では区画を作れず、⑤ の場面(草原の延焼が川で止まる・氷が溶けて流れる)で水も湯気も流れなかった。
- エンジンは中身を持たない(D-454)・書かなければ何も起きない(D-455)・中身はパッケージに書く(D-486)。区画は「どこで流すか」という場所なので、
  初めのセルの中身(world_cells)・置く物(world_bodies)と同じく世界の組み立てに属する。

## 決定(仮)
1. **世界の組み立てに分類 `gas_regions`・`liquid_regions` を足す**(world_cells・world_bodies の隣。1 つの鍵 = 1 つの区画):
   - `gas_regions.<名前> = { min_cell = { x, y, z }, size_cells = { x, y, z }, boundary = { "wall" | "open" | "periodic" × 3 }? }`(既定は全部 "wall")
   - `liquid_regions.<名前> = { min_cell, size_cells, advection = true? }`
   - 書き方は script/world_layout_package(型は data/types/bicameral.d.luau の GasRegion・LiquidRegion)。T-0620 の案 A
     「world_cells の中に gas_regions・liquid_regions」は、world_cells の鍵がセルの領域の名前なので、同じ分類の中に別の種類の鍵を混ぜずに隣の分類にした。
2. **読む時の誤り(区画の名前の付いた理由)**: 2 つ目の区画(今は 1 つずつまで。ProbeSim の区画が 1 つ)・格子(64 セル角)からはみ出す箱・
   基準の大気が無い世界の気体の区画・重力 0 の世界の液体の区画(T-0590 の判断待ち 5 の仮 = 真空を基準にせず断る)。ベイク(BakeWorldLayout)が
   環境の値と基準の大気の後で確かめる。
3. **アプリの世界・写しの世界・指標の写しは全部 `sim::SetLayoutRegions(layout, options)` を通して同じ区画で作る**
   (frame_loop の CreateSimulation・WorldCopyFactory・PlayMetricFactory、--measure-metrics、PlayMetricMeasurer)。
   気体の乱数の丸めの種は 0(アプリにまだ世界のシードが無い)。陽解法の小刻み・模型の値(摩擦など)はデータに出さない(既定のまま)。
4. 区画は表の中身(TableBytes)に入るので、記録の再生は表だけから同じ区画を作り直す。区画の書き換えは表の版を変える。
   区画の付け替え(ホットリロードで区画の場所が変わる)は今の世界に当てず、世界を作り直すと効く(world_cells と同じ)。

## 影響(作り手から見た違い)
- 場面のパッケージに数行で「ここで気体・液体を流す」と書ける。書かない世界(サンプルの世界・ブランク)は今まで通り流れない。
- 書き間違い(はみ出す・2 つ目・大気が無い)はパッケージを読む時に名前付きで止まる(窓を開く前・ホットリロードなら古い表のまま)。
- 区画は箱 1 つずつなので、川と離れた池など複数の場所はまだ書けない(足すなら ProbeSim の区画を複数にする。費用は区画ごとの作業場)。
- 気体の区画の重さ(1 刻み 1〜2 ms/3456 セル。D-468)は作り手が箱の大きさで決める(読む時の警告はまだ無い = 判断待ち)。

## 代案
- 案 B: environment(環境の値)に「気体を流す範囲」。重力・音速と同じ所だが、環境の値は場所によらない値なので場所が混ざる。
- 案 C: 起動の引数(--gas-region)。データに残らず、同じ世界を開き直すと区画が消える(採らない)。
