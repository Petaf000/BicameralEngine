# ADR-0466 案 B の R3: 粒の層を「速さの決まった相」として圧力の系に入れる形は採らない(研究の打ち切りの記録)

- Status: Rejected(研究の打ち切り。作業役 T-1092。代案 (a) は司令塔の一旦の決定で着手・ユーザー未確認)
- 日付: 2026-10-24
- 決めた人: Claude(作業役 T-1092。打ち切り条件どおり)
- 関係: ADR-0449・ADR-0457・ADR-0463・docs/design/21 §2.3・§2.5・§5.1・T-1071・T-1092・T-1093・T-1105・D-556

## 背景
空気ありの砂山が平らになる根を、部分セルの砂がセル平均で空気の中に散らばった砂に見えることと見立てた(ADR-0463)。代案 (a) は表面のセルの粒を層として状態に持つ形。

## 試したもの(`FlowOptions::grainLayerPrescribed`・`grainLayerPoreDrag`。既定 false)
1. 表面のセルの層の横の面: 止まった粒は障害物(孔でもない)、動く粒は「速さの決まった相」(圧力の式の右辺だけ・係数なし・圧力の力積なし・空気とつながない)。
   速さは解く前に押す力と摩擦で決める(T-1070 の形)。圧力の系の口は変えない(21 §2.3 の物と同じ口。C-0 / C-1 に足す口は無い)。
2. 1 に加え、層の中の空気だけに孔の引きずり(セルの引きずり × 層の詰まり)。

## 結果
- 1: 砂山 13° / 0°・25° の斜面(0.25 m)が 0° に崩れた。2: 砂山 0° / 0°。どちらも空気が数十 m/s で暴れ、舞った粉が乗る。

## 決定
- どちらも採らない(既定は ADR-0449 のまま)。層の数え方を変えて表面のセルのつなぎを弱めると空気が暴れる(T-1043・T-1071 と同じ)。暴れの元の測りは T-1105。
- 代案 (b) は D-556 の決め直しに当たるので、見立てだけにした(T-1093)。
