# ADR-0449 案 B の R3: 桁を直した後の測り直し。粒の無いセルから支えられた粒へ向かう面は解く前に止める。積もった層の扱いを変える 2 本は採らない(研究の打ち切りの記録)

- Status: Proposed(作業役 T-1043。解く前に止めるのは誤りの直しとして既定。2 本の試しは打ち切り。R3 の判定の順はユーザー)
- 日付: 2026-10-24
- 決めた人: Claude(作業役 T-1043。打ち切り条件どおり)
- 関係: ADR-0428・ADR-0430・ADR-0441・ADR-0442・ADR-0438・docs/design/21 §2.3・§2.5・§5.2・T-1003・T-1043・T-1070・T-1071・D-620・D-641

## 背景
ADR-0441(粒が流体から受け取る運動量の桁の直し)の後、空気のある所で砂山・斜面が平らになった(砂山の芯 0.5 m 0°・0.25 m 10°・書いた 34°)。
D-641 は、崩れ始めと止まる角度の差(法則の定数。ADR-0430 の 6°)を桁の直しの後に測り直して決め直すとした。

## 分かったこと
- 差を 12° にしても止まる角度は 0〜16°(φ 25°・34°・40°)。差の値は根ではない。真空では 36° / 28°(差 6°)。
- 見立て: 崩れた粒は支えの無い雲として落ち、一緒に落ちた空気が床に沿って横へ出て、積もった層(表面のセル)を押し流す。
  層のセルを「セルで平均した詰まり」の Kozeny–Carman で空気とつなぐので、層の上を流れる空気が層の中を通るように数えられる。
  さらに降伏(摩擦)は陰の圧力の後の段で粒の運動量だけを見るので、(a) 解きの中で空気に引かれた分のうち摩擦を超えた分が動き、
  (b) 降伏で動かした粒の体積が圧力の体積の釣り合いに入らない。

## 決定
1. **粒の無いセルから支えられた粒へ向かう粒の面は、陰の圧力を解く前に止めて孔にする**(`FlowOptions::grainRestLock`。既定 true。grainYield の時だけ)。
   前(ADR-0428)は同じ面を解いた後で止めており、解きの中では面の粒(両側の平均で半分)の重さが空気を下へ押していた。止める所を前へ動かしただけで、
   値は斜面 25° 0.25 m の動く粒(88 → 43 ‰)のほかは変わらない。R2 の行は同じ値。
2. 積もった層を空気とつながない(引きずり 0)形は採らない: 粒が圧力に押される別の相になり 22〜107 m/s で暴れた。
3. 積もった層を解く間は動かない障害物にし、降伏だけで動かす形(`FlowOptions::grainRestLayer`。既定 false)は採らない:
   斜面 25° 0.25 m が 9° まで崩れた(降伏で動かした粒の体積が圧力の釣り合いに入らない)。
4. 差は 6° のまま。決め直しは、降伏を解きの中へ入れた後(T-1070)。

## 作り手から見た違い
- 無い(誤りの直しだけ。R3 の空気ありの値は ADR-0441 の後のまま: 砂山が書いた値より大きく低い)。

## 検討した代案と、採らなかった理由
- 差を大きくして合わせる: 差 12° でも止まる角度は書いた値に届かず、崩れ始めが書いた値 + 10° を超えて実験(2〜5° の桁。未確認)から外れる。
- 桁の直し(ADR-0441)を戻す: 帳簿で運動量が消える誤りの上に合わせることになる(ADR-0441 のとおり採らない)。

## 未確認・次
