# ADR-0300 区画(気体・液体)のある世界の保存点・状態のハッシュ・表の差し替え(T-0620)

- Status: Proposed(仮・ユーザー未確認。T-0620 の判断待ち 1・3)
- 日付: 2026-10-17
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- T-0592(気体)・T-0613(液体)で仮の世界の GPU の刻みに区画が載った。区画はセルの外に持ち越す欄を持つ(気体: セルごとの運動量・
  運動エネルギーのぶん・帳簿。液体: 面の運動量・面の運動のエネルギー・位置のエネルギー・帳簿)。
- 保存点(ADR-0036)・写しの早送り(ADR-0198)・状態のハッシュはセルと物理だけを見ていたので、区画のある世界では断っていた。
  ⑤ の場面(川が熱を吸う・氷が溶けて流れる)をエディタの窓で 置く → Undo → プレイ → やめる、写しの早送りで遊びの指標を測る、の下支えが要る。
- 決定性(ADR-0008)・保存則(D-465): 戻した世界・写しの世界は、最初から流した世界と区画の欄まで同じでなければならない。

## 決定(仮)
1. **保存点と写しの早送りは区画の持ち越す欄を写す**: 気体は欄(gasState)と作業場(gasWork)の全部、液体は作業場のうち刻みの中だけの作業の値より前
   (制御・帳簿・見出し・物質ごとの値・面の運動量・運動と位置のエネルギー)。区画の欄は世代を持たない(1 組)ので、刻み t の境界の値 = S(t) の値。
   気体の箱(GpuGas)のセルと 1 刻みの帳簿は毎刻み区画から作り直すので写さない。写しの世界(WorldCopy)は写す元と同じ区画を作り、見出しが違えば写さない。
2. **状態のハッシュに区画の寄与を足す**: 世界のハッシュ = Σ セルの寄与 + Σ 区画のセルの寄与 + 区画の帳簿の寄与(mod 2^64 の和。04 R2)。
   1 つの寄与は種(区画の種類と欄)と番号から FxHashCombine で値を混ぜて仕上げる(common/probe_region_hash.hlsli)。GPU はハッシュの単位で
   HashCells の後に GasHash・LiquidHash が同じ欄へ 64bit の atomic で足し、CPU は ProbeReference::StateHash が HashTerm を足す。
   区画の無い世界のハッシュは今までと同じ値。
3. **表の差し替えは区画の欄の作りが変わらない表だけ**(ProbeSim::CheckRegionTableSwap): 物質の一覧が同じ・区画が読む物質ごとの値が同じ・
   環境の値と基準の大気が同じ。反応の規則と速さだけのホットリロードは通る。ほかは理由付きで断る(RecordFrame も同じ検査で断る)。
   区画の作業場は作る時に表から物質ごとの値・設定の型・層の基準・開いた境界の外を作り、CPU リファレンスの区画も作る時の値を持つので、
   作り直さずに通すと GPU と CPU のどちらも黙って古い値で流れる。作り直し(帳簿の付け替えを含む)は T-0670。

## 影響
- 作り手から見て: 区画のある世界でも保存点へ戻す・写しで早送りする・記録と再生のハッシュで比べる、が区画の流れまで含めて正しく働く。
  区画のある世界で物質を足す・物質の値や重力を変えるホットリロードは、T-0670 まで断られる(理由がログに出る。世界を作り直すと新しい値で流れる)。
- 保存点 1 つが区画の作業場の分だけ大きくなる(気体の作業場は刻みの中だけの値も含む。並べ直すと小さくできる = T-0620 の判断待ち 3)。
- 区画の欄を足す時の約束: 気体は gasWork か gasState のどこでもよい(全部写す)。液体は snapshotOffset より前に置く。ハッシュに入れる欄は
  GasHash/LiquidHash と HashTerm の両方に足す。

## 試験
- gpu_probe_rewind_regions(gpu_probe_rewind_test --regions): 気体の区画 16 × 14 × 16(木箱を囲む)と液体の区画 12 × 8 × 3(ダムの水)のある世界で、
  保存点へ戻す・表の差し替えをまたいで戻す・刻み 0 へ戻す・写しの早送りが、最初から流した世界とハッシュ列で全部一致。差し替えの約束(速さだけ違う表は通る・
  液体の密度が違う表は断る)。
- gpu_probe_gas・gpu_probe_liquid: 毎刻みの GPU のハッシュ(区画の寄与を含む)が CPU と一致。
