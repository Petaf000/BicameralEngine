# ADR-0497 2 つのエネルギーのセルの段の形: 混ざっているかはセルの中身から・混ざらないセルの Ec は 0(T-1211)

- Status: Accepted(Claude の一旦の決定。作り手から見た違いは無い = 書く値も見える振る舞いも ADR-0486 のまま)
- 日付: 2026-10-27
- 決めた人: Claude(wt4 の作業役・T-1211)
- 親: ADR-0486(持ち方と受け渡し)・D-665・D-682 / 共通の核: shaders/common/phase_layer.hlsli の「セルの段」

## 背景
ADR-0486 の Ec を世界の段(伝導・反応・運ぶ・細かく/粗くする)から呼ぶには、セルごとに「混ざったセルか」を知る必要がある。
1 列の試験(T-1160)は印(mixed)を別に持っていたが、世界の欄に印を足すと疎の約束(混ざったセルにだけ頁)と二重になる。

## 決定
1. **混ざっているかはセルの中身から決める**(PlLayerOf の mixed)。印は持たない。面の流れは量を変えないので刻みの中で変わらない。
2. **混ざらないセルの Ec は 0**(欄の頁が無いのと同じ = 疎の約束と同じ形)。混ざったセルの Ec だけが意味を持つ。
3. 量が変わる段(反応・運ぶ・細かく/粗くする)は、**前のセルと後のセルを PlRemixCondensedEnergy に渡して**変わり目を直す
   (混ざった → 温度が揃う配り PlEvenCondensedEnergy・混ざらなくなった → 0)。前が混ざっていたかは前のセルの中身から出る。
4. セルの段の呼び方は 1 つ: 面の流れと層の上の面(PlInnerFlowOf。刻みの初めの値から)→ PlBeginReact → 反応の核(世界の待ちの丸め)→ PlEndReact →
   PlRemixCondensedEnergy。1 列の試験・1 セルだけの GPU の試験(PlStepLoneCell)・世界の段(T-1230〜T-1232)が同じ関数を呼ぶ。

## 作り手から見た違い
- 無い(書く値・見える振る舞いは ADR-0486 のまま)。tests/phase_layer_test.cpp の測りは前の形(印を持つ)とビット単位で同じ(2026-10-27)。

## 検討した代案
- 印を欄に持つ(混ざったセルの印 + Ec): 疎の約束と二重で、印と中身が食い違う状態を作れてしまう。退けた。
- 混ざらないセルにも「凝縮相のエネルギー」を持たせる(凝縮相だけ = E・気体だけ = 0): 粗くする規則(ADR-0486 の 7 の和)はそのまま書けるが、
  岩などの凝縮相だけのセル全部に頁が要る(疎でなくなる)。読む時にその値を導く形(保存は疎のまま)は粗くする段(T-1231)で使う。
