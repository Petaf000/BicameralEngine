# ADR-0228 坂を上らせる構造(押す)の一般の形: 交差を構造が持つ

- Status: Proposed(T-0495 の模型で確かめた案。表の書き方はユーザー未確認。仮のおすすめで進める)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
D-487 ⑤: 坂を上らせる構造(蓄えたエネルギーで向きを持って押す形)は、機械・体・魔法に共通の一般の形を ③ で作る(ゲームの中で機械も作れるようにする)。
D-481 の「押す」(体に蓄えたエネルギーで集める・運ぶ・押し出す)は ⑦ でこの形を使う。19 §2.1 の P4「ある流れが坂を上るのは、同じ所で別の流れが坂を下り、
合計のエントロピーの生成が ≥ 0 の時だけ」の受け皿が今のエンジンに無い(19 §2.3 の G4)。T-0493(ADR-0220)は散逸の流れどうしの交差を結合の強さ q で書く形を作った。

## 決定(案)
1. **一つの芯**: 押す構造は、**蓄え X が自分の坂を下る流れと、押される物 Y の流れの交差**(ADR-0220 の交差と同じ 2 × 2 の形)を、構造が自分の係数で持つもの。
   引きずり(ADR-0220)との違いは係数の出どころだけ: 引きずりは物質の係数(伝導率・拡散)、押す構造は構造が持つ係数(速さ P・1 単位を押す費用 w)。
   - 坂はエネルギーの単位にそろえる: f_X = 蓄え 1 単位が下る時の自由エネルギー(仕事の蓄えなら 1、熱の流れなら 1 − T_低 ÷ T_高、物質・反応なら Δμ・−ΔG)、
     f_Y = Y を 1 単位動かす時の自由エネルギーの下がり(負 = 坂の上へ)。y = f_Y ÷ w。
   - **J_X = P (f_X + q y)、J_Y = (P ÷ w)(q f_X + y)**(L_XX = P・L_YY = P ÷ w²・L_XY = q √(L_XX L_YY))。
   - 生成 T σ = P (f_X² + 2 q f_X y + y²) は **|q| ≤ 1 ならどの状態でも ≥ 0**。効率 −J_Y f_Y ÷ J_X f_X の最大は **q だけで決まる**
     (Kedem–Caplan: η_max = q² ÷ (1 + √(1 − q²))²)。X が熱の流れなら、熱から得る効率は Carnot × η_max(q) を超えない(Carnot を形が自分で守る)。
   - q = 1 は「きっちり結合」: 1 単位押すたびに w を使う比の機械。坂が費用に追いつくと(y = −f_X)止まり、蓄えも使わない。押し返されると逆に回る(発電機)。
     費用 w(歯車の比)と速さ P はどんな正の値でも法則を破らない。法則を破れるのは q だけ。
2. **刻みの規則**(エンジンが持つ。作り手は書かない):
   - 蓄えが足りない時は、蓄えの流れを残りに固定して Y の流れを同じ行列で解き直す(シューアの補: J_Y = q s₀ ÷ w + P (1 − q²) y ÷ w)。
     蓄えが尽きると q = 1 は押した差を保ち、q < 1 は滑り(1 − q²)の分だけ押し返される。
   - 1 刻みの行き過ぎの歯止め(模型では少ない側の 1/64)に当たったら、流れの組を同じ割合で縮める(生成は同じ割合になるので ≥ 0 のまま)。
   - 整数の丸め: 蓄えの流れは +∞ 方向(熱を多めに出す)、Y の流れは 0 方向(坂の上へ押す量を少なめに)。
3. **ベイクの検査**: |q| > 1 は効率 > 1 の状態がある(永久機関)ので、警告して ±1 に押さえる(D-487 ②。ADR-0220 の引きずりと同じ検査を 1 つの関数で)。
   w ≤ 0・P < 0 は警告して止めた構造にする。パネルには η_max(q) と止まる坂(q f_X w)を出す。
4. **表の書き方(仮のおすすめ)**: 反応表・`drags` と並ぶ独立の表 `machines`(1 行 = 構造の種類: 蓄え X・押す Y と 2 つの口・結合の強さ q・費用 w・速さ P)。
   案と作り手から見た違いは docs/tickets/T-0495-push-structure-general-form.md。

## 検討した代案と、採らなかった理由
- **一方向の押す規則**(反応と同じく作り手が向きを書き、坂を上る時はエンジンが警告。D-487 ① の形): 機械は坂に負けると止まる・逆に回るのが性質の中心で
  (何倍まで押せるか・押し返されたらどうなるか)、一方向だと機械を限界まで使うたびに坂を上る警告が出る。結合の形なら止まる所と逆回りは形から出て書かなくてよい。
- **効率そのものを書く**: 機械を作る人には分かりやすい。q と 1 対 1(q = 2√η ÷ (1 + η))なので、表の見せ方の案として残す(チケットの問い 2)。
- **押す構造だけの特別な形・魔素だけの形**: 引きずりと同じ芯で書けたので要らない。D-466「魔素に固有の形は足さない」。
- **生成の符号を実行時に検査して押さえる**: |q| ≤ 1 の範囲の検査で形として保証できるので、実行時は計器(T-0518)で数えるだけでよい。

## 影響(何がしやすく/しにくくなるか)
- 作り手は、蓄え X・押す物 Y と 3 つの数(q・w・P)で機械を書ける。どんな値でも(押さえた後は)永久機関にならない。止まる圧力・空回りの損・逆回り(発電機)・
  蓄えが尽きた後の押し戻しは形から出る(書かない)。熱の流れを X にすれば熱機関になり、Carnot を超えない。
- エンジンには、構造の置き場所(2 つの口・蓄えの置き場)と、流れの種類ごとの坂 f の計算が要る(未設計。T-0536)。気体・成分の坂は ln が要る(GPU では FxLnU64。
  構造の数はセルの数より少ない見込みで、費用は未確認)。
- 体(筋肉。Y = 物理の仕事)は物理の散逸 → 熱(T-0519)の後に同じ形で確かめる(T-0537)。魔法の「押す」(⑦)もこの形を使う。
- 模型: tests/push_model_test.cpp(T-0495)。
