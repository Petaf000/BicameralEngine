# ADR-0007 ゴールから全部決めてから作る

- Status: Accepted
- 日付: 2026-09-30
- 決めた人: ユーザー

## 背景
チケットが「道具を先に作る → 指摘が来たら新しいチケット」で積み上がり、ゴールから逆算した道筋が無かった(ユーザーの指摘)。

## 決定
- 何かを作る前に、ゴールから一番下(データ構造・マイルストーン・チケット)まで決める。
  決定は docs/plan/DECISIONS.md(層ごと・ID つき)、詳細設計は docs/design/、道筋は docs/plan/ROADMAP.md。
- 測らないと分からないものは、「どう測り、結果がどうならどちらへ進むか」(研究の打ち切り条件)を先に決める。
- 作業中に出た思いつき・提案は、すぐ着手せず docs/plan/BACKLOG.md に入れ、ロードマップと照らして優先度を決めてから着手する(CLAUDE.md の運用)。
- 上の層の決定が変わったら、依存する下の層の決定と文書を見直す。

## 影響
- 旧チケット T-0002〜T-0008 はロードマップに合わせて組み直す。
