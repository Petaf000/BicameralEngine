# ADR-0172 世界の組み立て(初めのセル・物)をパッケージの分類 world_cells・world_bodies に書き、反応表と同じ読み込みに入れる

- Status: Accepted(2026-10-14 ユーザー決定)
- 日付: 2026-10-13
- 決めた人: Claude(作りの細部。作り手から見て違いが出る点はユーザーに聞く。CLAUDE.md §5・D-476)

## 背景
- サンプルの世界の初めのセル(空気の中の木箱)と物(積み木)は C++ の sim::MakeProbeInitialWorld・sim::MakeProbeStackScene に、
  物質の名前(oxygen・cellulose)と量で書いてあった。エンジンは中身を持たない(D-454・ADR-0151 の 2)・中身は作り手と同じやり方で書く(D-486)。
- 並走の T-0399(材料のひな形)・T-0400(環境の値)も「パッケージから読む新しい分類」を足すので、読み込み方を揃える必要があった。

## 決定
1. **新しい分類は反応表と同じ読み込みに入れる**(LoadPackages の合わせた表)。表の版 TableVersion・中身 TableBytes に入る。
   再生ファイルは表の中身だけから同じ初めの世界を作り直せる(T-0193)。型検査・Mod の合わせ方(鍵ごとの AddOnly)・誤りの出し方・
   ホットリロードもそのまま使う。分類ごとに読む所(script/<分類>_package)・型(sim/<分類>)を分け、ReadReactionTableDefinition・
   BakeReactionTable の印の節に 1 行ずつつなぐ(T-0398 のチケットの「共有の決め事」)。
2. **世界の組み立ての書き方**(engine/src/script/world_layout_package.h・data/types/bicameral.d.luau の WorldCellRegion・WorldBody):
   - `world_cells`: 鍵 = 領域。`amounts_umol`(物質 → µmol)・`temperature_mk`・場所(`min_cell`・`size_cells`。省けば格子の全部)・
     `shell_cells`(箱の外側の殻だけ)・`layer`(重ね書きの順。同じなら鍵の順)。
   - `world_bodies`: 鍵 = 物(直方体)。`size_mm`・`position_mm`(物理の座標)・`mass_g`(0 = 動かない)・`order`(番号の順。同じなら鍵の順。
     物理の結果は番号の順に依るので、並びを書き手が決められるようにした)。
   - 物質の名前はベイクで ID に直し、知らない物質・1 セルの成分の上限(8 種)を超える中身は誤り。領域のセルはベイクで作っておく。
3. **分類が無ければ空**: ブランクの世界(D-455)はセルが全部空・物なし。窓の初めの世界と物は、`--world` に依らず読んだ表の組み立てから作る
   (`--world blank --packages X` なら X の組み立て)。
4. サンプルの値は試験のパッケージ combustion_test の world_cells.luau・world_bodies.luau(サンプルの世界のゲーム本体。標準パッケージへの
   分け方は T-0373)。前の C++ の組み立てとビット一致(world_layout_test)。

## 検討した代案
- **別の読み込み(版に入れない)**: 組み立てだけを直しても表の版が変わらない。代わりに、再生ファイルがディスクのパッケージ(か別の欄)に頼る。
  型検査・Mod の合わせ方・誤りの出し方を作り直す手間がある。採らない。
- **組み立てを LoadedReactionTable(script の層)だけに持つ**: 試験(BakeReactionTable を直接使う 60 か所余り)と ProbeSim の既定の初めの世界
  (表から作る)に、組み立てを別に渡す口が要る。BakedReactionTable の CPU だけの欄にした。

## 影響
- 作り手: 世界の初めの中身と物を Luau で書ける(ループで並べてよい)。Mod が鍵で領域・物を足せる。
- 世界の組み立てだけを直しても表の版が変わる(ホットリロードは表の差し替えの印を記録に入れる。法則は同じなので世界は変わらない)。
- 摩擦(物の組の摩擦係数 0.5)・回転・現れる刻みはまだ書けない(要る場面が出たら足す)。格子の外の領域は黙って切る。
- 試験の表から物質を消す道具は、組み立てを空にする(消した物質を指すため)。
