# ADR-0382 光と熱の放射は一つの道: 2 つの帯・まっすぐ運ぶ家族(太陽の影の柱・距離ごとの段)

- Status: Accepted(ユーザーの決定 S12・S32・S39。2026-10-19〜21 の設計チャット)。ただし「仮」の 2 つ(下)は Proposed(ユーザー未確認)
- 日付: 2026-10-21
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)
- 置き換える: ADR-0252 の「書かなければ 0」と欄 1 つ(→ 帯ごとの欄)・ADR-0262 は退く道として残す・ADR-0263 は S42 の刻みの 7 に読み替える。D-501・D-443 ③⑤ を置き換える(D-570・D-572・D-573)
- 設計: docs/design/23-radiation.md §0〜§4・§9・§10

## 背景
- 放射は T-0028(ADR-0252・0262・0263)で CPU の対の交換まで作ったが、草原の場面で川の意味が出ず、GPU の版を保留にした(D-501)。
- 2026-10-19〜21 の設計チャットで、法則を 6 つの家族に分け(S37)、放射は「まっすぐ運ぶ」家族になった。光と熱の放射を一つの道にし(S12)、帯を 2 つにし(S32)、運び方を決めた(S39)。
- 描画は ReSTIR・GI を持つ(10)。法則と描画が別々の光源と値を持つと、見える明るさと温まり方が食い違う。

## 決定
1. **一つの道**(S12): 光源・物質の光の値・遮る物は法則と描画で同じ物を使う。法則は 0.5 m の粗さでエネルギーを運び、描画は同じ光源と値から細かく描く。描画は状態を変えない。描画の質を下げる前提の設計にしない。
2. **2 つの帯**(S32): 見える光と赤外。物質は帯ごとに吸い込み(1 mol が遮る面積)と照り返しを書き、表面の滑らかさ・屈折の値を持つ。波長で変わる屈折(分光)は描画だけが使う。全部、温度の表で変えてよい(S16)。
3. **まっすぐ運ぶ家族**(S39): 太陽は向き 1 つの影の柱、青空は上の境目(天候の層 S25)、世界の中の光は距離ごとの段(Radiance Cascades の型)。研究が落ちたら決めた数の向きで掃く。にじむ近似は採らない。
4. **保存は精度によらず厳密**: 放った整数を通り道に沿って配り切る(吸った所に足し、残りは先へ、世界の外へ出た分は帳簿)。
5. 届く距離に上限を置かない(遠くは粗い段)。炎の χr・揺れの許し・煙が遮るは D-443 のまま。
6. 刻みの順は S42 の 7(運ぶの後・広がるの前)。

### 仮(Proposed・ユーザー未確認)
- **仮 1【エンジン】光の値を書かない物質**: 固体・液体は「灰色で通さない」(両帯で同じ吸い込み・照り返し 0.5・滑らか 0)、気体は「透明」。片方の帯だけ書いたらもう片方は同じ値。書き忘れはベイクで警告。
  作り手から見た違い: 仮の案は、書き忘れた岩も灰色に見えて日なたで温まり、空気は透明。代案(ADR-0252 のまま「書かなければ 0」)は、書き忘れた岩が見えず日に当たっても温まらない。
  おすすめは仮の案(書き忘れが「見えない・温まらない」という分かりにくい形で出ない)。
- **仮 2【エンジン】照り返しを 1 刻み遅らせて返す**: 返す光は次の刻みにそのセルが放つ光に足す。代案は同じ刻みの中で数回回す(重さが回数倍)。作り手から見た違いは無い(1/60 秒の遅れは見えない)。

## 検討した代案と、採らなかった理由(作り手から見た違い)
- **世界の中の光を、決めた数の向きで掃く(ADR-0262 の形)だけにする**: 決定的・保存が厳密・作りが単純。ただし遠くの小さな火の熱が向きの数だけの筋になる(遠くの焚き火の暖かさが立つ場所でまだらに変わる)。向きを増やすと重い。→ 退く道として残す。
- **にじむ量として近似する(P1・FLD)**: 一番軽いが、影がぼやけ壁の向こうへ熱が回り込む。壁の陰で火の熱を避けられない(一つの道にした目的に反する)。→ 採らない(ユーザー)。
- **帯を 1 つ(灰色)**: 安いが、温室・窓・雪の照り返し・赤外の計器が出ない。→ 採らない(ユーザー)。
- **法則と描画で別の光源・別の値**: 描画が自由になるが、見える明るさと温まり方が食い違う。→ 採らない(S12)。

## 影響
- 物質の光の値の欄が増える(帯ごとの吸い込み 2・照り返し 2・滑らかさ・屈折・分光。名前は仮)。ADR-0252 の欄は帯ごとの 2 つに読み替える(移し方は R-R0 のチケットで)。
- T-0586(対の交換の GPU 版)は再開しない。CPU の参照(radiation_reference)は黒い板の解析解の参照と、近くの区間の予備として残す。
- 描画(10)は法則の光の場と物質の光の値を読む。描画の研究 R-V1(分光・コースティクス)が R-R1 と組む。
- 費用は未確認(R-R0・R-R1)。日の当たる地面が昼夜で起き続けることの費用も未確認(M-0・R-T2)。
