# ADR-0453 筋の測り方: 8 m の円の受け手を、面の積分で出した正しい値と比べる

- Status: Proposed(T-1062。Claude の案。Q147〔筋の合格を瞬間で見るか数秒の平均で見るか〕の材料)
- 日付: 2026-10-24
- 決めた人: Claude(T-1062。決めるのはユーザー)
- 設計: docs/design/23-radiation.md §10 R-R1(筋が出ない ±10 %)

## 背景
RC の試験(cascade_light_test の MeasureRing)は、受け手の量を「立方体の中心どうしの距離²÷ 見かけの面²」で割って並べる。
T-1062 の試作で、正しい値(焚き火の面から受け手の面への遮る物の無い G の細かい積分)と比べると、**軸の向きの受け手(16, 0)は面どうしの隙間が 15 セルなので、その割り方では +6.83 % に見える**
(斜めは −0.7 〜 −2.0 %)。運び方が正しくても、その割り方では最大 6.83 % の床がある。RC の 500 刻みの平均 9.2 %(T-0959)の多くはこの床の見込み(未確認)。

## 決定(案)
1. 筋の合格は、受け手ごとに**正しい値(面の積分)からのずれ**で見る(RC の割り方の値も並べて残す)。
2. 合格の線 ±10 %(23 §10)はそのまま。瞬間(1 刻み)と 60・250・500 刻みの平均を並べる。
3. RC の試験も同じ測り方に直して測り直す(T-1081)。

## 作り手から見た違い
- 無い(試験の測り方だけ)。合格かどうかの判断が、運び方の誤差だけを見るようになる。
