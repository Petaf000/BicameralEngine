# ADR-0270 仮の世界の GPU の刻みに気体の区画を載せる形(欄の物質を GPU が刻みごとに決める・適用の単位の中・丸めの鍵は設定に。T-0592)

- Status: Accepted(エンジンの作りの細部。作り手から見た違いは ADR-0256 の範囲)。ただし「GPU の気体は今の gas_step を共有し、別の作りにしない」は
  T-0598 の進め方に関わるので、ユーザーが違う方向を選べば見直す
- 日付: 2026-10-15
- 決めた人: Claude(T-0592 の作業役)

## 背景
- ADR-0256(仮): セルが唯一の真実・足す欄は運動量と運動エネルギーのぶん・区画・段の順(適用 → 物理の熱 → 表の差し替え → 気体 → 伝導と反応)。
  CPU リファレンスは probe_gas(T-0590・T-0591。成分は何種でも・丸めの鍵は物質 ID)。
- GPU の気体の段(gas_step.hlsl)と木は成分の欄 4 つ(T-0598)。丸めの鍵は欄の番号だけだった。
- 区画にどの気体があるかは刻みごとに変わる(燃えると CO2・H2O が現れる)。CPU は世界の状態を知らない(D-107)。

## 決定
1. **欄の物質は GPU が刻みごとに決める**: 区画のセルの凝縮相でない物質の印(GasCollect)+ 基準の大気 → ID の順に欄へ(GasPrepare)。
   設定(GasGpuParameters の物質ごとの欄)と開いた境界の外も同じ段で作る。層の基準の導く値(t1)は欄の並びによらない(和だけ)ので作る時に 1 回。
   物質量 0 の欄・欄の並びは結果を変えない(整数の和・丸めの鍵が物質 ID)ので、CPU の「区画にある物質」と同じ結果になる。
2. **丸めの鍵を設定に持つ**(GasGpuParameters::roundingKey。既定は欄の番号 = 今までの GPU の試験はビット単位で同じ。区画は物質 ID)。
3. **段の場所は適用の単位の中**(物理の熱・表の作り直しの後、起こす刻みの来たブロックを一覧へ足す前)。気体が変えたセルのブロックは物理の熱と同じく
   「刻みの直前に変わった」にして起こす刻みを今にする(後ろの WakeDueBlocks が一覧へ 1 回だけ足す)。単位の番号(PROBE_UNIT_*)を変えない。
   費用は適用の単位の時間に入る(別の単位にするかは T-0621 で段ごとに測ってから)。
4. **GPU は今の gas_step を共有する**(仮の世界の気体を別の作りにしない)。成分の上限 4 は gas_step と木で一緒に外す(T-0598)。それまでは
   区画の気体の物質が 5 つ以上の刻みは流さずに数える(GPU の作業場の SKIPPED_TOO_MANY。CPU とは食い違う)。基準の大気の物質 5 つ以上は作る時に断る。
5. ルート署名: u15 気体の欄・u16 作業場・u17 気体の箱のセル・u18 箱の帳簿(多重解像度でない ProbeSim のルート署名は 59/64 語)。
   設定と開いた境界の外は作業場の中を t0・t2 として gas_step に結ぶ(その間だけ読む状態へ遷移)。

## 影響
- 作り手から見て: ProbeSimOptions::gas(CPU の EnableGas と同じ値)で、実行中の世界でも煙が流れる。陽解法だけ(投影は T-0621)。
  区画のある世界は表の差し替え・保存点・写しの早送りをまだ断る(T-0620)。
- 代案(採らなかった): CPU が欄の物質を決める(世界を読み戻すことになる。D-107)/ 表の気体の物質を全部欄にする(試験の表でも 5 つを超え、GPU の上限 4 に当たる)/
  気体の段を新しい単位にする(PROBE_UNIT_* の番号が全部ずれる。費用の切り分けは T-0621 のタイムスタンプで足りる)。
