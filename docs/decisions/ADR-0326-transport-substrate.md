## 背景
- 気体・液体・熱の伝導・(保留中の)放射・結合(drags / machines)は、それぞれが自分の「区画」「器」「上限」「帳簿」「欄の付け方」「CPU と GPU の二重書き」を持って育った。
  同じ決まり(相の判定・体積の空き・出ていく割合の上限・帳簿・状態のハッシュ・段の外で変えたセルの後始末…)が 4〜11 か所に重なり(docs/design/20 §5)、
  1 つ直すと 2〜3 か所を直す形になっていた(T-0646・T-0656・T-0667・T-0676・T-0689 など)。
- 作り手から見ても、遊びのために書くもの以外(区画の箱・熱の通しやすさの試験の倍率・`condensed` と `phase` の二重・器の数・インライン 8)を書いたり覚えたりする必要があった。
  T-0697(草原の延焼の場面の 2 版)で「区画の箱が火の越え方を決めていた」= 場所で法則が変わっていた(D-465 に反する)ことが見えた。
- 2026-10-17 13:55 にユーザーの指示で実装を区切りで止め、作り手が遊びを作るために法則を書くことを念頭に、運ぶ計算の共通の土台を設計し直した。

## 決定

### 一つの芯
1. **世界の真実はセルの物質とエネルギーだけ**。作り手は物質ごとに「どの相で動くか」と「どれだけ通すか(熱・粘り・混ざる速さ・孔・吸い上げ)」を資料か遊びの値で書く。場所の箱・倍率・器は書かない。
2. **動きはすべて「面を通る流れ = 坂 × 通しやすさ」**。坂と通しやすさは、刻みごとに 1 か所で作る**セルの見立て**(相・空き・熱容量・温度・圧力…)から読む。
3. **流れの種類が固有に持つのは「坂の値・面の式・安定の条件」の 3 つだけ**。出ていく/入る上限・欄が物質に付く・帳簿・起こす・溢れは、1 つの**面の帳簿**と 1 つの**当てる段**が全種類に同じく行う。
4. **持ち越す状態は登録制**(保存点・写し・ハッシュ・表の差し替え・細かく/粗くするは登録を回るだけ)。式は共有 .hlsli の 1 つの源を CPU と GPU が呼ぶ(二重書き 0)。
5. **土台は多重解像度の世界(MR)の上に作り、区画の箱をやめる**。費用は活性(眠る/起こす)と粗くすることで収める。仮の世界(PS。64³)は「1 段の MR」として答え合わせの基準に使い、縦切りの後に退かせる。

### ユーザーの 6 つの答え(D-510〜D-515)
1. **区画の箱をやめる**(D-510)。気体・液体は世界のどこでも流れる。外との境は世界の端だけ。費用は活性と粗くすることで収め、計器で見る。gas_regions・liquid_regions・ADR-0310・Q109 は取り下げ。
   代案(箱を「計算する範囲」として残す = 箱の外は流れない = 場所で法則が変わる)は採らない。
2. **熱の通しやすさの試験の倍率(固体 ×20000・気体 ×5000)を外し、資料の値だけにする**(D-511)。最初の縦切り(段 5)で無風の平地の燃え広がりを測り、
   広がらなければ (a) 放射を戻す(D-501 の見直し)か (b) この宇宙の草の値を決める(倍率ではなく値そのもの)かをその時に選ぶ。
3. **物質に書く動き方の欄は 5 つ**(D-512): 相 `phase` 1 本(gas / liquid / solid。既定 gas。`condensed` は廃止)+ 任意で 液体の粘り・気体の混ざる速さ・固体の孔の通しやすさ・固体の吸い上げ。
   名前と単位は仮(`viscosity_upa_s`・`diffusivity_mm2_per_s`・`permeability_um2`・`suction_pa`。型は T-0710)。書かなければ今と同じ動き。
4. **土台は MR の上だけに作る**(D-513)。PS は答え合わせ(ビット一致)の基準に使ってから退かせる。代案(PS の上で作ってから MR へ = 作りが 2 回)は採らない。
   作り手から見て: 64³ の枠が消え、場面の大きさ・細かさを選べる。代わりに移し替えの間(段 6〜8)は新しい世界を窓とエディタで触れるのが遅れる(縦切りは CPU で測る)。
5. **世界の端は環境に書く**(D-514): `world_edges = { top, bottom, sides }`(各 "open" / "wall"。書かなければ全部 wall)。面ごとに変えたい所(洞窟の口)は端ではなく世界のセル(岩)で作る。
   **風は今は入れない**(天候の段で入れる。設計の案にあった `wind_mm_per_s` は外した)。
6. **気体の圧力の伝わりの既定は「最速(投影)」を目標にし、投影の外側の発散(T-0689)が土台の上で直るまでは本物の音速(陽解法)**(D-515)。
   最速では爆風の先端が見えず結果がその刻みに出る(D-487 ⑥)。遅い爆風を見せたい場面だけ音速を書く。

### 作り手から見た姿(詳しくは 20 §1)
- **書くもの**: 物質に `phase`・密度・比熱・熱の通しやすさ(資料の値。倍率なし)・任意の 4 つ / 反応・結合(今のまま。machines の push は相を問わない)・置いた機械(T-0555 の案 i)/
  環境に重力・圧力の伝わる速さ(音速 or `"instant"`)・基準の大気・世界の端 / 世界のセル・物(今のまま)。
- **書かなくてよくなるもの**: 区画の箱と、それに付いた制限(1 つまで・64³ の中・大気が要る・重力が要る・面が軸ごと・川が流れ続けない)/ 熱の倍率 / `condensed` と `phase` の二重 /
  器とインライン 8 の数 / 液体の摩擦の区画の設定 / 区画のある世界のホットリロードの断り。閉じた空気が水を押さない(T-0618)も、液体の坂に同じセルの気体の圧力が入るので消える。
- **残る制限**: 反応の形の上限・4095 K・釣り合いの書き方・物の材料・1 刻みの費用(計器で見える)。
- **知らせ**: ベイク(誤りは名前付きで止める・あやしいのは警告して動かす。D-487 ②)/ 上限の計器 1 つ(流れの種類 × 理由 × 場所)/ 費用の計器(活性のブロック数 × 小刻み・D-468 の予算)/
  遊びの指標の量(面を通った量・最大圧力・液面・濡れたセルの数)/ 影響の見える化の元(各流れの種類が読む物質の欄を宣言する。D-482 ①)。

### 土台の芯(詳しくは 20 §2)
- **状態は登録制**: 持ち越す状態 = セル(成分 + エネルギー。溢れのセル込み)+ 登録した欄 + 物(物理)+ 世界の帳簿。欄の登録は 1 行
  (名前・置き場〔セル / 面 / ブロック / 世界〕・型・付く相・保存量か・細かく/粗くする時の規則・ハッシュに入るか)。区画の欄・熱のキャッシュは無くす。
- **セルの見立て**: 共有 .hlsli の `MakeCellView(セル, レベル, 表)` が活性のブロック(+ 隣の 1 セル)について刻みごとに作る(永続しない)。熱のキャッシュの後始末が 0 になる。
- **流れの一般の形**: 何を動かすか × 坂(見立ての値の差)× 通しやすさ(両側の物質の値 × 面の開き × レベルの係数)× 安定の条件。
  熱の伝導(陽・陰)・気体の塊・液体の塊・混ざる・結合 drags・機械 machines・放射(保留)が同じ形の表に並ぶ。「染みる」は種類を足さず、摩擦に孔の詰まりを足すと孔の中で Darcy の流れになる。
  離れた 2 セル(機械の口・放射の対)は面の一般化(対)として同じ帳簿に書く。新しい種類 = 3 つ(坂・面の式・安定の条件)と読む欄の宣言。
- **面の帳簿と当てる段**: ① 流す(面の持ち主が 1 回計算し両側が同じ値を足し引き)② 上限(順に依存しない。出る側 = min(1, 中身 ÷ 出る合計)・入る側 = min(1, 器の残り ÷ 入る合計)。今の 4 種の式が 1 つに)
  ③ 当てる(溢れのセルも。違うレベルの面は細かい側が計算し粗い側は端数)④ 欄が物質に付く(ADR-0286 の形を 1 か所に)⑤ 世界の帳簿 1 つ(列 = 量 × 理由。保存の検査は 1 関数)⑥ 起こす。
- **1 刻みの順**: 入力 → 表の差し替え → [見立て → 欄の合わせ直し → 種類の小刻み(流す → 上限 → 当てる → 起こす)] を 気体 → 液体 → 伝導 → 反応(セルの中。D-504)→ 次の刻みの種。物理は別(熱と力積の入口・出口)。
- **費用は活性で収める**: 流すのは活性のブロックだけ。一様なブロックは欄が 0 の間は一様のまま。大きな現象は状態による粗くすること(17 §3 A・D-428)で下げ、それでも予算を超える所は D-468 の計器で警告(結果は変えない)。
  場所で変わる場合分けは**世界の端**と**レベル**だけ(D-465)。
- **CPU と GPU は 1 つの源**: 見立て・包み・面の式・上限・当てる・欄の合わせ直しを shaders/common/*.hlsli に書き、C++ が include する(heat_conduction.hlsli と同じ形)。違うのは回し方だけ。
  CPU と GPU のビット一致の試験は残す(回し方・atomic・活性の取りこぼしを確かめる)。

### 二つの世界に同じ土台(詳しくは 20 §3)
- 土台が世界に求めるもの 4 つ: 活性のブロックの一覧 / セルの読み書き / 面の隣(同じ・粗い・細かいレベル)/ 端数の置き場。MR はどれも伝導で実績がある。
- PS は「1 段の MR」(64³・0.5 m = レベル 0 のブロック 8 × 8 × 8 で子の無い MR)。今の PS(区画を世界いっぱいに置いた版)を答え合わせの基準にする。
- レベルの単位を 1 つに(量・エネルギー・運動量は 8^-k)・種類は「冪 e」を宣言するだけ(拡散型 e = 2・波の型 e = 1)・小刻みと粗い側の受け直しは土台の 1 つの実装。

### 今の仕組みと止めたブランチの扱い(詳しくは 20 §4)
- 熱の伝導・気体(陽解法・投影)・液体・放射・結合・物の物理・相変化・セルの器は、それぞれ「種類が固有に持つもの」だけが残り、ほかは土台へ移る(20 §4 の表)。
- **t-0622**(器を反応の取り合いの資源に。ADR-0316): 形は土台と合う(セルの中)。**CPU の全部の試験と gpu_reaction・gpu_probe_place を main の上で通してマージした**(T-0709)。
- **t-0414b**(T-0697。草原の場面を測る道具の鍵と記録): エンジンは変えていないので **マージした**。段 5 で同じ場面・同じ指標で測り直す基準。
- **t-0689**(投影の外側の発散): 見立て(LimitOutflow が通り抜けを切る)を段 3 ④ の投影の入力に残し、**コードは捨てる**(マージしない。ブランチは残す)。
- **t-0668**(気体の木が空きを読む): **捨てる**(気体の木は凍結して段 7 の答え合わせの基準。空きは見立てが全種類に与える)。
- **t-0686**(水と湯気の見え方): 案はチケットに残し、表示は「セルの物質と相を読む」一般の形で段 8 に(区画の欄を読まない)。**ブランチは捨てる**(マージしない・残す)。

### 残る研究(打ち切り条件)
- **段 3 ④ 投影 + D-508**(T-0722): 投影の外側の反復が小さい空きのセルで発散しない形を、当てる段の上限の上で作る。打ち切り: 16³ の最速の細孔の板(T-0689 の再現)で外側の反復が上限の中で収まる形が 2 本で作れなければ、
  D-515 のまま既定を陽解法に固定し、投影は選んだ場面だけ(収まらない刻みは D-502 の上限で持ち越す)にしてユーザーに問う。
- **段 4 ① 活性で眠るか**(T-0723): 静かな大気に 1 秒の火を置き、火が消えて 60 秒で活性のブロックが 10 % 以下に戻らなければ「静止の丸め」(速さが 1 単位未満の欄を 0 にして運動のエネルギーを熱へ・帳簿の列)を足す 1 本。
  それでも戻らなければ費用の上限の案を並べてユーザーに問う。
  → 2026-10-17 気体は 2 本目に当たり、ユーザーが答えた(D-516。下の「未確認: 活性」)。
- **段 7 研究**(T-0736・T-0737): 気体のレベル境の反射(今 2.26 %)・液体の面の欄の細分。打ち切り: 静かな水・止まった気体が細かくする/粗くするでビット単位で動かない形が 2 本で作れなければ、
  液体の境のレベル差を 0 に固定する(液体のある所は同じレベル)。
- 状態による粗くすること(R-MULTI。17 §3 A)は M4 の研究のまま。

### 未確認(測っていない・読んでいない所)
- 費用: 見立てを毎回作る費用(伝導の係数の割り算をキャッシュしない)・面の帳簿の上限の 2 回目の段・GPU の気体の 1 セルあたりの限界の費用(T-0592 の 1.64 ms/3456 セルは段の数の固定費が大きい)。
- 活性: 乱れた気体が整数でちょうど静止に戻るか・煙の柱の活性のブロック数・粗くする基準。
  **→ 答え(2026-10-17。T-0723 の研究 → D-516)**: 乱した気体は 60 秒で眠らず、静止の丸め(1 µm/s・1 mm/s)も効かない(残るのは運動量。粘りが無い)。液体は積んだ水が 1 mm/s の丸めで 32 秒で全部眠った(浅い池は運動が育つ不具合の疑い = T-0757)。
  ユーザーの決定(D-516): 気体にも静まる性質(粘りの欄を気体にも・格子で解けない乱れが静まる分は世界の値の 1 つの欄)+ 静まりきらない所は状態で粗くし予算の計器で見る + 静止の丸めも土台に。作るのは T-0758。煙の柱の活性のブロック数と粗くする基準は未確認のまま(R-MULTI)。
- 答え合わせ: MR のレベル 0 の伝導が PS の伝導とビット単位で同じか・上限を 1 つにした時に気体(EffectiveOutflow)と液体(MoveMass)の結果がビット単位で今と同じか。
- 気体の器 2^31 を見立ての式を広げて無くせるか(128bit の掛け算の数・GPU の費用)。
- Darcy の摩擦を陰的に入れた時の安定と、吸い上げの曲線の形(満ち具合の 1 次で足りるか)。粘りを書かない液体の既定(今の摩擦 1/128 との換算)。
- 倍率なしで火が広がるか(無風・平地・放射なし。D-511)。湯気が見えるか。
- 液体の面の運動量の細分の規則・気体の MUSCL の 2 セル先の隣をレベル境でどう取るか。
- 段 8 の規模(PS を参照する engine 32 ファイル・試験 24 本。窓・エディタ・指標が PS のバッファを直接読む所の数)。
- 気体のセルの運動量(セル)と液体の面の運動量(面)を 1 つの置き場にそろえるか(今は登録で両方持つ)。
- セルの伝導率の数え方(mol の平均・面は min)を体積の重み・調和平均に変えるか(燃える木箱の基準が変わる。別の問い)。
