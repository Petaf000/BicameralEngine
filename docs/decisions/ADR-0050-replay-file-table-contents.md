# ADR-0050 再生ファイルは、使った反応表の「合わせた表の中身」と読んだパッケージの一覧を持つ(形式の版 2)

- Status: Accepted(実装の細部。CLAUDE.md §5)
- 日付: 2026-10-09
- 決めた人: Claude。T-0170・T-0193

## 背景
- 15 §2・§4: 再生ファイルには表の版(パッケージの一覧とハッシュ)を残す。発見の共有(D-110)は、受け取った側が自分の機械で同じ結果を見る。
- T-0157 までの再生ファイル(形式の版 1)は表の版の欄が常に 0 で、再生は「今のパッケージの表」を使っていた。
  T-0139 のホットリロードで、記録の途中で表が変わる(印のコマンド PROBE_COMMAND_TYPE_TABLE)ようになり、持っていない版の表は再生で止まっていた。
- 表の版は合わせた表の正準なバイト列(script::TableBytes)の FNV-1a(ADR-0031 の 6)。同じ中身なら、パッケージの組が違っても同じ版。

## 決定
1. **何を残すか**: 記録に使った表の全部(初期状態の表と、記録したコマンドの差し替えの印の版の表)を、版の昇順に 1 つずつ。
   1 つの表 = 版・読んだパッケージ(読んだ順)・「改造された世界」の印・**合わせた表の中身(TableBytes)**。
   見出しの表の版の欄 = 初期状態の表の版(今までの 0 をやめる)。
2. **中身は TableBytes(Luau のソースでもベイクした GPU 用の表でもない)**:
   - 再生はそれを読み戻し(script::ParseTableBytes)→ 定義 → ベイク(script::RebuildReactionTable)。Luau は走らせず、型の定義もパッケージのフォルダも要らない。
   - 版 = 中身のハッシュなので、中身が壊れていれば必ず分かる(ハッシュと、読み戻した表の版の 2 回確かめる)。
   - 反応表の GPU 用の形(RxSpecies・RxRule など)をファイルの形に固定しない(GPU 用の形が変わっても、再生ファイルの形は変わらない)。
3. **ファイルの形**: 見出しの [12](版 1 では予約)を表の数にし、ハッシュの後ろに表を並べる(詳しくは save/replay_file.h の先頭)。
   save は中身をバイト列のまま持つ(GPU も Luau も知らない)。読むときに版の昇順・初期状態の表があること・大きさを確かめる。
4. **再生の表の選び方**(frame_loop の LoadWorldReactionTables):
   - 再生ファイルに表の中身がある → それだけを使う(パッケージのフォルダは読まない。ログ「再生ファイルの表を使う」)。
   - 表の中身が無い(版 1 の古いファイル)→ 今のパッケージの表で再生し、警告を出す(記録した時と表が違えばハッシュが合わない)。
     版 1 のファイルの途中の差し替えの印は「その表の中身が再生ファイルに無い」で止まる(今まで通り)。
   - 表の版が書いてあるのに中身が無く、今のパッケージの表と版が違う → 窓を開く前に止める(違う法則の世界で再生しない)。
5. **古い形式**: 版 1 は読める(表の無い形への変換。15 §1)。版 1 で予約の欄が 0 でないもの・知らない版は読まない(理由を返す)。

## 検討した代案と、採らなかった理由
- **パッケージのソース(.luau)を残す**: 再生のたびに殻で走らせ型検査が要る(型の定義の版にも縛られる)。Mod を除いた理由など、表の外の事情も再現が要る。
  合わせた結果が同じなら版も同じなので、中身だけで足りる。
- **ベイクした表(GPU 用のバイナリ)を残す**: 再生ファイルが反応表の GPU 用の形に縛られ、形を変えるたびに再生ファイルの変換が要る。
  ベイクは決定的(ADR-0032)なので、中身から作り直せば同じバイトになる。
- **版だけ残して、合わなければ断る**: 発見の共有・Mod を外した後のバグの再現ができない(15 §3)。

## 影響(何がしやすく/しにくくなるか)
- しやすい: 再生ファイル 1 つで、パッケージの無い機械・Mod を入れ替えた後でも同じ表で再生できる(発見の共有の下地)。ホットリロードをまたぐ記録も再生できる。
- しにくい: 再生ファイルが表の数 × 数 KB〜大きくなる(今の試験の表で 1 つ 2781 バイト。表が大きくなったら、同じ版を共有する仕組みを考える)。
  ベイクの仕方(sim/reaction_table)を変えると、古い再生ファイルの結果も変わる(これは表の中身の形式とは別の問題で、今までと同じ)。
- 実績・共有で「改造された世界」をどう扱うかは決めていない(印を残すだけ。QUESTIONS Q8)。
