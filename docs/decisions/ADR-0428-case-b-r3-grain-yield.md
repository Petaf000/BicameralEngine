# ADR-0428 案 B の R3: 粒は「支えられて詰まった時だけ」押し合い、横の面ごとに tan φ × 重さ + c_eff で降伏する(一旦)

- Status: Proposed(一旦の決定。作業役 T-0996。ユーザー未確認。21 §5.1 の判定で ADR-0376 と一緒に確かめる)
- 日付: 2026-10-22
- 決めた人: Claude(作業役 T-0996)
- 関係: ADR-0376・ADR-0409・ADR-0421・docs/design/21 §2.3(B-b)・§2.5・§2.7(S8)・§5.2・22 §3.3・T-0869・T-0963・T-0996・D-556・D-613

## 背景
R3(21 §5.2)は、粒が詰まった時だけ押し返し、崩れる角度 φ とくっつく強さ c で止まる形を、R1・R2 の陰の圧力の箱に入れて確かめる研究。
R2(T-0869)は詰まった所へ入る粒の面を止めるだけで、押し合い・崩れる角度は R3 に残していた。

## 決定
1. **粒の降伏は陰の圧力の後の段(`grainYield`)**。圧力の系の形・係数は変えない(粒は今のまま粒そのものの体積で入る)。C-0 の口は足さない。
2. **支えられた粒だけが押し合う**: 列を下から見て、下が支えられた詰まった粒・据わる固体・物・床の時だけ支えられる。支えられた粒は上の粒の浮力を引いた重さを柱で持つ(有効応力)。
   舞う粒・落ちる粒は押し合わず、引きずりと重さだけで動く(21 §0.4)。
3. **降伏は横の面ごと**(2 本目): 押す力 = 両側の有効応力 × 詰まりの割合の差 × 面積、上限 = (tan φ × 両側の重さの平均 + c_eff × 詰まりの平均)× 面積。
   面の運動量に押す力を足し、上限以下なら 0(ちょうど止まる)・超えたら上限だけ減らして持ち越す(21 §2.5)。向かう側が詰まった面は 0。
   面の柱の和で決める形(1 本目)は、深さ ÷ Δx 倍の運動量が表面に集まり、山が平らになりすぎたので採らない(`yieldPerFace = false` で残す)。
4. **詰まりを超えて入らない**: 運ぶ段で、向かうセルの詰まりの残りを超える粒の流れを同じ割合で縮め、入れなかった分の運動量は押し返しで消す(帳簿 Wall)。
5. c_eff = cohesion + suction × 4S(1−S)。混ざった粒の φ・c・吸い上げは体積の平均(S9)。tan φ は整数の CORDIC。
6. **穴を通る口(S8)は口だけ**: 箱の面の開き具合(`Box::faceBlockedQ16`・`faceHoleSizeUm`。欄 `face.blocked` と同じ形)を読み、
   面の開き = `FoFaceOpen`・粒の開き = `FoGrainFaceOpen`(T-0937 の 1 つの源)が 0 の面を止める(T-0998 で `FlowOptions::faceHoleSizeUm` から差し替え)。
   `grain_pass_ratio_pct` を書かない時の既定は 100 %(仮)。穴の大きさの置き場は T-0977。

## 作り手から見た違い
- 書く欄は増えない(粒の 3 つ・`repose_angle_deg`・`suction_pa` は 21 §1.1 のまま)。
- 今の形では、砂山は書いた `repose_angle_deg`(34°)より約 6° 低い角度で止まる(0.5 m でも 0.25 m でも同じ)。φ より緩い斜面は動かない。
  【エンジン】`repose_angle_deg` を「止まる角度」と読むか「崩れ始める角度」と読むか(T-0996・T-0997)。
- 粒を詰める(`packed_fraction_pct` を上げる)と積もった重さが詰まりの比で増える(D-613 のとおり。60 % ÷ 50 % で 1.199)。

## 検討した代案と、採らなかった理由
- 面の柱の和(1 本目): 角度が細かさで変わった(0.5 m 29°・0.25 m 23°)。
- 粒の押し返しを共有の陰の圧力の状態式に入れる(詰まりを超えた分の体積で圧力が立つ): 運ぶ段で詰まりを超えないので要らなかった。
  粒の山の中の押し合いは有効応力(柱)で持ち、圧力の系は流体と粒の体積の分け合いだけを見る。

## 未確認
- 止まる角度が φ より低い根(勢いの行き過ぎか、表面のセルの割合か)。T-0997。
- 砂時計の流量が Beverloo の形に合うか → T-0998: 細かさ・降伏の有無によらず口の幅の比は約 2(口の速さが 1 粒の終端の速さ近くで一定)。空気を抜くと 2.4〜2.8・C ≈ 1。根は粒と空気の引きずりの見込み(T-1003)。
- 濡れた砂の急な面(R4)。吸い上げ 3 kPa では乾いた砂と区別がつかなかった。
