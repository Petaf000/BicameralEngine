# ADR-0457 案 B の R3: 降伏(摩擦)を陰の圧力の解きの中へ入れる形と、触れ合う詰まりを下げる形は採らない(研究の打ち切りの記録)

- Status: Rejected(研究の打ち切り。作業役 T-1070。既定は入れない = ADR-0449 のまま)
- 日付: 2026-10-24
- 決めた人: Claude(作業役 T-1070。打ち切り条件どおり)。R3 の判定の順はユーザー
- 関係: ADR-0428・ADR-0430・ADR-0441・ADR-0449・docs/design/21 §2.3・§2.5・§5.2・T-1043・T-1070・T-1071・T-1091・D-620・D-641

## 背景
ADR-0441 の後、空気のある所で砂山が平らになる(芯 0.5 m 0°・0.25 m 10°。真空 36° / 28°)。T-1043 は根を「降伏が解きの外にある」と見込んだ。

## 試したもの(`FlowOptions::grainFrictionInSolve`・`grainContactPermille`。既定 false / 0)
1. 支えられた粒の横の面の押す力 D と摩擦の上限 F を解く前に決め、|P + D| ≤ F なら解く間は据わる孔(空気の力積 J を足して超えたら次の刻みへ)、超えたら F を引いて一緒に解く。
2. 1 に加え、下のセルの詰まりが 50 % / 80 % 以上なら上の粒を支えられた粒にする。

## 結果(T-1070 の表)
- 1: 砂山 0° / 10°(変わらない)。2: 空気あり 0° / 0〜11°・真空が 11° / 14° に下がった。
- 引きずりの倍率だけを下げると戻る(×0.1 で 21° / 27°・×0.01 で 33° / 29°)。

## 決定
- どちらも採らない。平らになるのは摩擦の置き場ではなく、粒と空気のつなぎの強さで決まる。
- 見込み: 部分セルの粒をセルに一様に散らばった粒として空気とつなぐため、崩れた砂と空気が空気の圧力で支えられた重い流体として広がる。次は T-1071(部分セルを層として数える)。

## 作り手から見た違い
- 無い(既定は ADR-0449 のまま)。

## 未確認
- 部分セルの砂と空気が沈み固まるまでの時間(T-1091)。T-1071 の結果で、R3 の空気ありの止まる角度が案 B の判定で落ちるかが決まる。
