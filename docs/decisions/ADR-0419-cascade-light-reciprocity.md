# ADR-0419 距離ごとの段(R-R1)の直し: 面の上で散らして放ち、ずらした向きで重みを付け、袋は溜めから 1 本選んで出す

- Status: Proposed(研究 R-R1 の 1 本目の直し。Claude の案。坂を下る・筋の合格はまだ通らない〔T-0972〕)
- 日付: 2026-10-21
- 決めた人: Claude(T-0958。ADR-0413 の 1・3 を直す)
- 設計: docs/design/23-radiation.md §3.3。核 shaders/common/cascade_light.hlsli・CPU リファレンス engine/src/sim/cascade_light.cpp

## 背景
ADR-0413 の形(面の真ん中から放つ・升目の真ん中の Lambert の重み・袋の量の重心から出し直す)を CPU リファレンスで測ると、
同じ温度(1000 K)の閉じた石の箱で、セルごとの正味の出入り ÷ 放った量が最大 **+510 %**(5 段)・17 %(1 段)。
重心 1 点から出る袋の光線が向かいの壁の真ん中に集まり(焦点)、また面の真ん中の 1 点から放つと向き合う 2 面の見え方が揃わない。
23 §3.3「坂を下る」(冷たい側から熱い側へ正味で流れない)を壊すので直す。

## 決定
1. **段 0 の出どころは面の上で一様に散らす**(光線ごとに (種・刻み・光線) のハッシュ。R6)。期待値で「点から見た面」と「面から見た点」が対称になる。
2. **段 0 の升目の重みは、ずらした後の向きの cos と立体角の密度**(`RcAimedFaceWeight` = |D_A| × max(0, D·n) ÷ |D|⁴)。
   升目の真ん中の重みのままだと、粗い升目(n0 = 4)で斜めの面どうしの受け渡しが偏った。1 と 2 で、段なし(1 段)の閉じた箱は 4 %(160 刻み)まで下がった。
3. **袋の出どころは、袋に入った光線から量に比例した確率で 1 本選んだその出どころ**(重み付きの溜め。鍵 = −ln(u) ÷ 量の最小。min の畳み込みなので順によらない。
   GPU は 64bit の atomic min で同じ。T-0959)。1 つの焚き火なら焚き火から(前の重心の形と同じ)、広い壁なら壁のどこかの 1 点から出る。焦点は消えた。
4. **子の升目へ分ける重みは、子の袋の光線が向く(ずらした後の)向きの立体角の密度**(`RcAimedSolidAngleWeight`)。
5. ADR-0413 の 2(段の場所 = 木の段・区間)・4(DDA)・5(ずらし)はそのまま。

## 残ったこと(T-0972)
- 段の受け渡し(1 袋 = 1 本)で、閉じた箱の正味の出入りが 17〜19 % 残る(段 1 つでも)。温度に直すと 1 セル(石 2 万 mol)で約 0.25 mK/刻み。
- 8 m の円の筋: n0 = 4・5 段で ±14〜33 %(種で揺れる。60 刻みの平均)。合格の ±10 % に入らない。
- 次の手: 袋から R 本出す・近くの区間だけ対の形で交換する(23 §3.3)・駄目なら退く道(決めた数の向きで掃く。1・2 はそのまま使える)。

## 検討した代案
- 袋の出どころを重心 ± 広がり(量で重み付けた 2 次のモーメント)で散らす → 遮る物の中から出る光線ができ、56 %(5 段)。
- 区間を 2 ブロックにする → 筋が ±36〜40 % に悪くなる。

## 仮(作り手から見た違い)
- 【エンジン】3 の袋の出どころ: 広い熱い壁の遠くの光は、刻みごとに壁のどこか 1 点から出る(熱容量で均されて見えない見込み。D-443 ②)。
