# ADR-0486 凝縮相と気体が混ざるセルの 2 つのエネルギーの持ち方と受け渡し(D-665 の形。T-1160)

- 設計: docs/design/20-transport-substrate.md §10.5・§10.6・§12.4 / 決定: D-664・D-665・D-666・D-674・ADR-0469 の 3-1〜3-3・ADR-0434(物の膜)
- 共通の核: shaders/common/phase_layer.hlsli(CPU と GPU の 1 つの源)・試験 tests/phase_layer_test.cpp

## 背景
D-665 で「凝縮相と気体が混ざるセルでだけ、2 つのエネルギーを持つ」と決まった。持ち方(何を真実にするか)・面の分け方・反応の温度・
細かく/粗くする時の配り方は、作り手が書く値を変えないので、この ADR で一旦決めて進める。

## 決定(一旦)
1. **真実は層のエネルギー Ec(mJ・64bit)1 つ**。気体のエネルギー = セルのエネルギー − Ec。セルのエネルギー(和)は今の保存の列のまま。
   Ec は混ざったセルにだけ持つ(欄の頁は混ざったセルのある所だけ = 疎。ハッシュ・セーブに入る真実。SF_PLACE_CELL)。
2. **混ざったセル** = 気体でない物質の量 > 0 かつ気体の量 > 0 かつ凝縮相の体積 < セル(満ちたセルの孔の気体は 1 つのまま)。
3. **層の形**(ADR-0469 の 3-1 (a)・D-664 と同じ見立て): 凝縮相はすべて重さの向きに積もる層。高さ = 凝縮相の体積 ÷ セルの体積(Q16)。
   場所を取らない物質(モル体積 0)だけの層は下限の厚さ(Q16 の 1 = 7.6 µm)。**据わる固体も熱の形では底の層として数える**(細かくする規則 D-664 では寄せない。判断待ち 1)。
4. **面**: 下の面 = 層、上の面 = 気体、横の面 = 下から層の高さまでが層(隣と高さの重なりで 4 つに分ける)。係数は今と同じ「両側の小さい方」
   (片側 = 伝導率 × 2^15 ÷ 道の高さ。満ちたセルでは今の 伝導率 × 0.5)。上限は部分の熱容量の 1/8 × 受け持つ面の割合(和は 7/8 以下 = 行き過ぎない)。
   **層の上の面**(層 ⇄ 気体)は 2 つの半分の道の直列。
5. **反応**: 凝縮相の項を 1 つでも持つ規則(溶ける・沸く・露・炭が燃える = 接する面の反応)は層の温度で回す。見るセル = すべての物質 + Ec + 気体の物質を層の温度にしたエネルギー。
   反応の後、生まれた気体は層の温度(後)の h を、消えた気体は気体の温度の h を気体の側へ出し入れする(和はビット単位)。気体だけの規則は気体の部分(E − Ec・気体の物質)で回す
   (規則の振り分けの印はベイクが付ける。T-1211)。
6. **混ざり方が変わる時**: 混ざったら 2 つの温度が揃う配り(熱容量の重み。D-674 と同じ考え)。混ざらなくなったら Ec を捨てる(エネルギーは 1 つへ。和は変わらない)。
7. **細かくする**: 層の熱は凝縮相の置かれ方に沿って子の凝縮相の熱容量の重みで、気体の熱は子の気体の熱容量の重みで配る(D-674 を部分ごとに 2 回。子の部分の温度は親の部分の温度)。
   混ざらない子は 1 つの値へ。**粗くする**: 親の Ec = Σ 子の凝縮相のエネルギー(混ざった子は Ec・凝縮相だけの子はエネルギー全部・気体だけの子は 0)。
8. **運ぶ**: 気体の区画が混ざったセルから運び出す気体は気体の部分の温度の h を、液体の区画が運び出す液体は層の温度の h を持ち出す(どちらも Ec の側を合わせて動かす)。
9. **固体の側の境界の層(3-3・D-666)**: まず接する面の温度の差で状態で細かくする形を世界の木で測り(T-1219)、線を超える所だけ面の皮(ADR-0469 の 3-5 と 1 つの形)。

## 作り手から見た違い
- 書く値: 増えない(今の伝導率・比熱・潜熱・モル体積から)。
- 見えること: 層と気体の温度が分かれる(氷の上の空気は暖かいまま・露のセルの空気は石に冷やされない・蒸発の潜熱は層から出る)。
  **相が変わる速さは、層の側の道(判断待ち 2・T-1218)と固体の側の層(3-3・T-1219)が決まるまで現実に届かない**(下の測り)。
- エンジンが数える状態: 混ざったセルに Ec(8 B + 欄の頁の見出し)。セーブ・ハッシュに入る。

## 判断待ち
1. 据わる固体を熱の形で底の層として数える(仮)。比べた案: 据わる固体は一様に散らす(層を作らない。地形の表のセルの石と空気の温度が分かれない)。
2. **層の側の道の長さ**(研究 T-1218): 層の高さ(温まるだけの層には合う)では相が変わる層が約 30 倍遅いまま(上の表)。相が変わる層は温度が一様で熱は接する面で吸われるので、
   道は溶けた液の膜(状態から導く長さ)か 0 に近い。
- → 閉じた(2026-10-26 D-682): 1 は確定・2 は層の高さを既定に確定(相が変わる層の道は研究 T-1218 で続ける)・probe_phase は世界の木へ移して現実の値の線で決め直す。

## 検討した代案
- 気体のエネルギーを真実にする: 作り手から見て同じ。相変化(層の側の反応)が直接読み書きする値を真実にした。
- 部分ごとの温度を真実にする: 保存がビット単位で書けない(エネルギーの和から温度を割り戻す丸め)。
