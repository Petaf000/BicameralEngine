# ADR-0117 気体のレベルをまたぐ面は細かい側が計算し、粗い側は物質・運動量・全エネルギーを端数つきで受ける

- Status: Accepted
- 日付: 2026-10-11
- 決めた人: Claude(実装の細部。CLAUDE.md §5。T-0208)

## 背景
- 気体(07 §2・ADR-0043・ADR-0083)を多重解像度の木(17 §1・ADR-0015)に載せる。レベル k の量の単位は 8^-k で、細かいセルが粗いセルへ渡すと粗い側に 8^-d の端数が出る。
- 熱の伝導は ADR-0017 で「細かい側が計算・粗い側は整数部 + 2^-64 の端数」にした。気体は物質(成分ごと)・運動量 ×3・全エネルギーを運び、面の力(圧力の力積・重さ)もある。

## 決定
1. **レベルをまたぐ面は細かい側だけが計算する**(面の単位 = 細かい側のレベル。面の係数もそのレベル)。同じレベルの面は gas_reference と同じ(全部レベル 0 なら毎刻みビット一致)。
2. **粗い側の値の読み方**: 密度のような値(流れを出す運動量・基準との質量の差・圧力)は数のまま、中身(移す割合の分母の質量・移す物質量・塊のエネルギーと運動量)は × 8^d。
   静水圧の差の半分は粗い側の高さの分 × 2^d、重さの力積は粗い側へ × 2^d(細かい単位。粗いセルの面は細かい面 4^d 枚に分かれるので、全部で同じレベルの面と同じ 1/4)。
3. **粗い側への増減は整数部をセルへ、2^-64 単位の端数をセルの端数(GasTreeFraction: 成分ごと・エネルギー・運動量 ×3)へ**。符号つきの値も whole + fraction の 128bit の足し算で、
   順に依存しない。導く値は整数部だけから(ADR-0015 と同じ)。帳簿と合計もレベル 0 の whole + 2^-64。
4. **レベルをまたぐ面の成分は 1 次の風上**(MUSCL は同じレベルの 3 つ並びだけ)。乱数の丸めの面の番号はそのレベルの座標から、用途に + レベル(レベル 0 は今までと同じ)。
5. **T-0208 の範囲**: 隣のレベルの差は 1 まで(2:1)・全部のレベルが同じ小刻み(いちばん細かいレベルで ν ≤ 0.6)。レベルごとの 2^σ は T-0320、d ≥ 2 と細かくし方は T-0321。

## 理由
- 1・3: ADR-0017 と同じ形で、成分・エネルギー・運動量が端数を含めてビット単位で保存される(gas_tree_test の閉じた 2 レベルの箱で毎刻み確かめた)。粗い側の単位へ丸める案は、
  粗い 1 単位が細かい塊より大きい時に細かいセルの中身が跳ねる(ADR-0017 の代案と同じ理由)。
- 2: 同じ濃度・速度ならどのレベルも同じ数なので、流れ(質量の流束 = 運動量の密度 × 面積)は数のまま足すのが正しく、塊は中身なので単位をそろえる。
- 4: レベルの境の外側の隣はレベルの違うセルで、勾配の幅がそろわない。境は細い帯なので 1 次でも煙のにじみの増え方は小さい(未測定 → T-0209 か T-0210 で必要なら)。

## 検討した代案
- 木を 2:1 に保つ(AMR でよくある): 今は気体だけ 2:1 を前提にした(d = 1 なら粗い中身 × 8 が 2^31 の上限の下に収まる)。熱は差を制限していないので、d ≥ 2 を気体でも受けるか
  (128bit で中身を読む)、気体のある所だけ 2:1 にそろえるかは T-0321 で決める。
- 粗い側が細かい面 4^d 枚をまとめて計算する: d が大きいと重い(ADR-0017 と同じ)。採らない。

## 影響
- 05 のセルに気体の端数の欄(成分ごと・エネルギー・運動量 ×3 の 64bit)が要る(T-0210)。熱の端数のブロック(ADR-0015)と同じ置き場所にまとめるかは T-0210。
- 細かいセルを親の数の写しで作ると、親の中の静水圧の傾きが無く 2.9 cm/s ほど動く(07 §2.5)。細かくする時は傾きを子へ配る(T-0321。17 §3B「見るだけなら変わらない」)。

## 追記(2026-10-11、T-0320。決めた人: Claude〔実装の細部。CLAUDE.md §5〕): レベルごとの小刻み 2^σ
- **レベル k を 1 刻みに substeps × 2^σ(k) 回の小刻みに分ける**。σ(k) = clamp(k − 基準, 0, Δσmax)(`GasTreeOptions` の `subcycleBaseLevel`・`maxSubcycleGap`。
  熱の `MultiresStepOptions` と同じ名前・同じ形。既定 Δσmax = 0 = 分けない = T-0208)。気体は音の CFL(Δt ∝ Δx)なので熱の 4^σ ではなく 2^σ で、
  ν はどのレベルも同じ(基準 0・小刻み 24 なら全部 0.47)。係数は MakeGasCoefficients の式に小刻みの数 substeps × 2^σ を入れたもの(流れ・拡散・力積・重さの力積が × 2^-σ)。
  安定の条件は全部のレベルで ν × 2^(k − σ) ≤ 0.6 を `MakeGasTree` が assert。
- **時間線**: 1 刻み = いちばん細かい小刻み substeps × 2^σmax 回(通し番号 micro)。レベル k の小刻みは micro が 2^(σmax − σ) の倍数の時に始まり、その終わりにだけ
  セルの値が変わる。セルは「小刻みの初めの値(導く値はここから)・力を当てた値 forced・次の値 next」を持ち、粗いセルの forced と next は粗い小刻みの間ずっと持つ。
- **違う小刻みの面(Berger–Colella の refluxing。熱の ADR-0017 追記〔T-0108〕と同じ)**: 細かい側が細かい小刻みごとに計算する。粗い側の値は粗い小刻みの初めのまま
  (時間補間しない)。粗い側への力積・移した塊は next に足し、粗い小刻みの終わりに受ける(同じ小刻みの面の力積だけが forced に入り、その小刻みの流れに効く)。
  受け渡しは整数部 + 2^-64 の端数のままなので、保存はビット単位(閉じた 2 レベルの箱で毎刻み確かめた)。
- **粗い風上から細かい面が 2^g 回引く時の正の値**: 出ていく割合を × 2^g で数え、使える分は「1 − 粗い小刻みの初めに同じ小刻みの面が出した割合」
  (`committedOutflow`)。各細かい小刻みの合計 ≤ (1 − 初めの分) ÷ 2^g なので、粗い小刻み 1 回の合計は 1 以下(熱の C/8 ÷ 引く回数と同じ考え)。
  移す物質量(乱数の丸め上げ・MUSCL の分)は、粗い小刻みの間に出した分(`taken`)を中身から引いて抑える(早い者勝ち。割合を抑えた後なので丸めの端数だけ)。
- **乱数の小刻みの通し番号はレベルごと**(tick × substeps × 2^σ + その中の番号)。σ = 0 なら T-0208 と同じ。
- 理由: 細かいレベルが 1 つ増えるたびに全部のセルの小刻みが 2 倍になる T-0208 の形を、細かいセルだけが 2 倍になる形にする(17 §4・T-0030 の推奨の気体の部分)。
  σ = 0 の時の値が T-0208 と同じなので(状態のハッシュの鎖で 12 刻み確かめた)、GPU(T-0209)は同じ規則を段の列で組めばよい。
- 測った値(gas_tree_test・debug): 圧力の波がレベル 0 → 1 → 0 を通る時の反射は、同じ小刻み(48)の 1.05% に対し、分けた形(レベル 0 は 24・レベル 1 は 48)で 2.26%
  (通った波の誤差 3.25% → 3.89%。どちらも同じ小刻みの一様な管と比べ、初めの山に対して)。時間補間が無い分で約 2 倍。減らすなら粗い側の値を
  小刻みの初めと仮の終わりの間で補間する(GAMER・Berger–Oliger の形。保存は refluxing のまま)→ T-0338(必要になったら)。
- 検討した代案: 細かい面の力積を粗い側の forced に入れる(T-0208 と同じ見た目): 粗い小刻みの 2 回目以降の細かい面が使う値と食い違い、粗い側の値が小刻みの途中で変わる。
  採らない。粗い側から引く割合を早い者勝ちで抑える: 1 回目の細かい小刻みが全部を持っていける(物理の流れの形ではない)。採らない。

## 追記(2026-10-11、T-0209。決めた人: Claude〔実装の細部。CLAUDE.md §5〕): GPU に載せる形(σ = 0 の木)
- **面の一覧は木を作った時に CPU が一度だけ作って GPU へ写す**(`ListGasTreeFaces` = StepGasTree が使う EnumerateFaces と同じ一覧・同じ順。木は作った後に変えない
  という T-0208 の前提の間だけ。木が変わる時に GPU で作り直すのは T-0357)。セルは自分の面の並び(面の番号 × 2 + 自分が右側か)を持ち、
  セルの段はその並びを集める(CPU は面ごとに両側へ散らす。どちらも整数の足し算なので同じ値)。1 レベルの箱の GPU(T-0185)の「面の番号から両側を計算する」形は
  レベルをまたぐと面の数がセルごとに変わる(粗いセルの 1 面に細かい面 4 枚)ので採らない。
- **粗い側への増減は GPU でも整数部 + 2^-64 の端数の 128bit の足し算**(セルの段で、自分の単位へのずらし 3 × (面のレベル − 自分のレベル) で)。
  帳簿(レベル 0 の whole + 2^-64。`GasTreeTotals` と同じ並び)は、下位へ 64bit の原子的な足し算 → 返った前の値から繰り上がりを出して上位へもう 1 回の原子的な足し算
  (全部の足し込みの後の 128bit の値は順によらない)。繰り上がりは比べずにビットで出す(`((a >> 1) + (b >> 1) + (a & b & 1)) >> 63`。T-0124・T-0185 の
  NVIDIA のドライバの 64bit の誤りを避ける形)。
- 1 セルの熱力学の部品(導く値・移す塊のエネルギー・勾配の制限・丸め)は `shaders/common/gas_cell.hlsli` に移して 1 レベルの箱と共有した(式は変えていない)。
- 結果: HW(RTX 3070 Ti)・WARP、debug で 5 場面(閉じた 2 レベルの箱・静止大気・開いた境界と風・minmod と切り捨て・全部レベル 0)とも
  セル・端数・帳簿が毎刻み CPU とビット一致(tests/gpu_gas_tree_test.cpp)。初めのビルドで一致した。

## 追記(2026-10-11、T-0356。決めた人: Claude〔実装の細部。CLAUDE.md §5〕): GPU に載せる形(2^σ の小刻み)
- **GPU の 1 刻みは「いちばん細かい小刻み substeps × 2^σmax 回 × 9 段」**(T-0320 の時間線をそのまま段の列に)。どのレベルの小刻みが始まる・終わるかは、
  ルート定数の小刻みの番号(micro)とレベルごとの σ(`GasTreeGpuLevel::subcycleExponent`)から段の中で決める。始めないレベルの面・セルは段の中で飛ばす
  (面の一覧をレベルで分けて Dispatch を小さくするのは費用を測ってから。T-0358)。σ = 0 なら毎回 全部が始まって終わるので T-0209 と同じ段・同じ値。
- **粗い小刻みの間持つもの**: セルごとに forced(u2・u3)・next(u8・u9。粗い側への力積と塊はここへ)・`GasTreeGpuCarry`(u10。committedOutflow と成分ごとの taken)。
  始めるセルは段 1 で forced と carry を作り直し、段 3 で同じ小刻みの面の力積を forced へ・next = forced。細かい小刻みの面の力積は段 3 で next へ足す。
  段 9 で塊を next へ足し、carry を足し(同じ小刻みの面の割合 → committedOutflow・出した物質量 → taken)、終えるレベルのセルだけ next を状態へ写す。
  足し込みは全部 128bit の整数の足し算なので、集める順(セルの面の並び)によらず CPU と同じ値。
- **乱数の小刻みの通し番号はレベルごとに段の中で作る**(tick × (substeps << σ) + (micro >> (σmax − σ)))。ルート定数は tick・micro・substeps・σmax を渡す。
- **抑えの判定も同じ式**: 使える分 = 1 − committedOutflow(抑えた後なので 1 以下。「0 で止める引き算」は書かない)・中身 = (forced × 8) − taken。
  試験の場面(粗いセルの列が 1500 m/s で細かい範囲へ流れ込む箱)で、CPU の `GasTreeStepStats` で両方の道(× 2^g で数えて縮めた・使える分 < 1・中身から taken を引いて縮めた)を
  通ったことを確かめ、その場面も HW・WARP で毎刻みビット一致。
- 結果: HW(RTX 3070 Ti)・WARP、debug で 9 場面(T-0209 の 5 + 分けた形の閉じた箱・静止大気・開いた境界と風・速く流れ込む箱)とも、セル・端数・帳簿が
  毎刻み CPU とビット一致(tests/gpu_gas_tree_test.cpp)。初めのビルドで一致した。
