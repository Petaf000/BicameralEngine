# ADR-0117 気体のレベルをまたぐ面は細かい側が計算し、粗い側は物質・運動量・全エネルギーを端数つきで受ける

- Status: Accepted
- 日付: 2026-10-11
- 決めた人: Claude(実装の細部。CLAUDE.md §5。T-0208)

## 背景
- 気体(07 §2・ADR-0043・ADR-0083)を多重解像度の木(17 §1・ADR-0015)に載せる。レベル k の量の単位は 8^-k で、細かいセルが粗いセルへ渡すと粗い側に 8^-d の端数が出る。
- 熱の伝導は ADR-0017 で「細かい側が計算・粗い側は整数部 + 2^-64 の端数」にした。気体は物質(成分ごと)・運動量 ×3・全エネルギーを運び、面の力(圧力の力積・重さ)もある。

## 決定
1. **レベルをまたぐ面は細かい側だけが計算する**(面の単位 = 細かい側のレベル。面の係数もそのレベル)。同じレベルの面は gas_reference と同じ(全部レベル 0 なら毎刻みビット一致)。
2. **粗い側の値の読み方**: 密度のような値(流れを出す運動量・基準との質量の差・圧力)は数のまま、中身(移す割合の分母の質量・移す物質量・塊のエネルギーと運動量)は × 8^d。
   静水圧の差の半分は粗い側の高さの分 × 2^d、重さの力積は粗い側へ × 2^d(細かい単位。粗いセルの面は細かい面 4^d 枚に分かれるので、全部で同じレベルの面と同じ 1/4)。
3. **粗い側への増減は整数部をセルへ、2^-64 単位の端数をセルの端数(GasTreeFraction: 成分ごと・エネルギー・運動量 ×3)へ**。符号つきの値も whole + fraction の 128bit の足し算で、
   順に依存しない。導く値は整数部だけから(ADR-0015 と同じ)。帳簿と合計もレベル 0 の whole + 2^-64。
4. **レベルをまたぐ面の成分は 1 次の風上**(MUSCL は同じレベルの 3 つ並びだけ)。乱数の丸めの面の番号はそのレベルの座標から、用途に + レベル(レベル 0 は今までと同じ)。
5. **T-0208 の範囲**: 隣のレベルの差は 1 まで(2:1)・全部のレベルが同じ小刻み(いちばん細かいレベルで ν ≤ 0.6)。レベルごとの 2^σ は T-0320、d ≥ 2 と細かくし方は T-0321。

## 理由
- 1・3: ADR-0017 と同じ形で、成分・エネルギー・運動量が端数を含めてビット単位で保存される(gas_tree_test の閉じた 2 レベルの箱で毎刻み確かめた)。粗い側の単位へ丸める案は、
  粗い 1 単位が細かい塊より大きい時に細かいセルの中身が跳ねる(ADR-0017 の代案と同じ理由)。
- 2: 同じ濃度・速度ならどのレベルも同じ数なので、流れ(質量の流束 = 運動量の密度 × 面積)は数のまま足すのが正しく、塊は中身なので単位をそろえる。
- 4: レベルの境の外側の隣はレベルの違うセルで、勾配の幅がそろわない。境は細い帯なので 1 次でも煙のにじみの増え方は小さい(未測定 → T-0209 か T-0210 で必要なら)。

## 検討した代案
- 木を 2:1 に保つ(AMR でよくある): 今は気体だけ 2:1 を前提にした(d = 1 なら粗い中身 × 8 が 2^31 の上限の下に収まる)。熱は差を制限していないので、d ≥ 2 を気体でも受けるか
  (128bit で中身を読む)、気体のある所だけ 2:1 にそろえるかは T-0321 で決める。
- 粗い側が細かい面 4^d 枚をまとめて計算する: d が大きいと重い(ADR-0017 と同じ)。採らない。

## 影響
- 05 のセルに気体の端数の欄(成分ごと・エネルギー・運動量 ×3 の 64bit)が要る(T-0210)。熱の端数のブロック(ADR-0015)と同じ置き場所にまとめるかは T-0210。
- 細かいセルを親の数の写しで作ると、親の中の静水圧の傾きが無く 2.9 cm/s ほど動く(07 §2.5)。細かくする時は傾きを子へ配る(T-0321。17 §3B「見るだけなら変わらない」)。
