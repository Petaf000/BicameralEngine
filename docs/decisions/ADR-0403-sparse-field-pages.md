# ADR-0403 欄をある所にだけ持つ: 疎な欄の頁(試作 C-1 の続き)

- Status: Accepted(形の細部は Claude。T-0921。D-542・claude/34 S41 の「真実はある所にだけ」の CPU の形)
- 日付: 2026-10-21
- 決めた人: ユーザー(D-542 欄の持ち方)/ Claude(T-0921 の作業役。形の細部)
- 関係: ADR-0399(欄の種類)・ADR-0329(登録)・ADR-0373 §3・T-0102(一様なブロック)
- 設計書: docs/design/20-transport-substrate.md §10.2・§13.2 の 1

## 背景
- 欄(セル・面の登録した値)は、セルの頁と同じ番号の「欄の頁」に全部の頁の分を先に取っていた(密)。
  気体の運動量のように、静かな所では 0 の値が多い。20 §10.2 は「頁があるかの印を足し、無い頁は 0 と読む」と決めた。
- 疎にしても、ハッシュ・保存の検査・刻みの結果は変えない(§13.2 の 1)。

## 決定
1. **置き場 `MultiresFieldStore`**: 一様の値(枠ごと)+ 欄の頁 + 疎なら「セルの頁 → 欄の頁」の表 `pageOf`(無い = `MULTIRES_NO_FIELD_PAGE` = 全部 0)と返された頁の一覧。
   疎か密かは世界ごとの `MultiresNest::sparseFields`(欄を登録する前に決める。既定は疎)。
2. **頁の出入り**: 0 でない値を最初に書く時に作る(0 を書いても作らない)。眠る判定(静かな頁を畳む前)で全部 0 なら返す。
   セルの頁を返す・置き直す所(畳む・粗くする・影の鎖を捨てる・根を置く)では欄の頁も返す。頁全体を書き直す所(広げる・細かくする・影を作る)は先に返してから書く。
3. **使っていないセルの頁の欄は 0**(密でも)。そのため状態の要約・保存点は「密の並び」(一様の値 → セルの頁ごとの値。無い頁は 0)で取り、疎と密で同じ値。
   保存点・写しは置き場ごと(頁の表も)写す。疎の保存点は密の世界には戻せない(形が違う)。
4. 単位は頁(512 セル)。頁の中のどれか 1 セルに値があれば頁 1 つ分を持つ。

## 採らなかった案
- セルごとの疎(値のあるセルだけ): 隣を読む面の回し・GPU の読みが「表を引く」に変わり、1 刻みの費用が増える。頁の単位で始め、要るなら T-0932 で測る。
- 頁があるかの印だけを持ち、欄の頁の番号はセルの頁と同じにする(メモリは減らない)。印だけでは S41 の目的(持たない)にならない。
- 返した頁の欄の古い値を残す(前の作り): 疎では「無い = 0」なので、要約が疎と密で違ってしまう。密も 0 にした(要約の並びは同じ・値は返した頁の分だけ変わる)。

## 結果
- 確かめ: tests/multires_sparse_test.cpp(ctest `multires_sparse`)で木・気体・液体の場面の疎と密が毎刻みビット一致(要約・Σ 保存量 − 帳簿・報告)・保存点。
- 測り(docs/perf.md 2026-10-21): 欄は静かな空気で 40 → 8 B/セル。燃えている所・流れている水は同じ。セルの状態(RxCell 112 B/頁のセル)が支配。
- 残り: GPU(T-0930。T-0920 の中で)・セルそのものの疎(T-0931)・頁の中の疎(T-0932 研究の候補)。
