# ADR-0003 反応の伝播は世代同期で決定的にする

- Status: Accepted(2026-09-30、D-205・D-305)
- 日付: 2026-09-29
- 決めた人: ユーザー

## 背景
Work Graphs で即時に伝播させると、起動順によって結果が変わる(非決定的)。

## 提案
前世代の状態を読み、次世代に書くダブルバッファ。1 フレーム 1 段の伝播。

## 理由
- 「同じ条件なら同じ結果」は、プレイヤーが法則を発見するための前提(ゲームの根幹)
- リプレイ・デバッグ・CPU リファレンスとの突き合わせが可能になる

## 代償
連鎖が 1 フレームに 1 段しか進まない(60 段/秒)。演出上足りない場面が出たら、1 フレーム内で複数世代を回す。

## 決定(2026-09-30)で広がったこと
- 決定性は「同じ機械で同じ結果」ではなく**機種が違っても完全に同じ結果**(D-205)。シミュは物理も含めて整数で計算する(ADR-0008)。
- 伝播は世代同期のまま。ただし「1 フレーム 1 段」ではなく「1 刻み(世界時間 1/60 秒)1 段」で、描画のフレームとは切り離す(D-201・D-305)。
  速い現象は刻みを細分する(06-simulation-loop.md)。
