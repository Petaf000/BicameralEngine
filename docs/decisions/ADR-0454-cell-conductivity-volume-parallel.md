# ADR-0454 セルの伝導率を体積で重み付けた平行の道に・気体の伝導率と混ざる速さを温度で変える

- Status: Accepted(D-637・D-639 の実装の形。2026-10-24 ユーザー決定の式を Claude が整数に下ろした。細部の仮は T-1066。実装はブランチ t-1066-conductance で、試験の取り直しの後に main へ)
- 日付: 2026-10-24
- 決めた人: ユーザー(D-637・D-639)・Claude(整数の形。T-1066)
- 設計: docs/design/07-transport.md §1 / 前: ADR-0434(物の箱の熱。体積の平行は物の箱で先に入った)

## 背景
セルの伝導率(HcCellConductance)は物質量で重み付けた平均だった。固体は気体より体積あたりの物質量が 200 倍ほど多いので、
少しの固体がセル全体の伝導率を決めていた(T-1016 の調べ。紙の箱 約 95 mW/(m·K)、体積の平行なら 約 27)。
燃え広がりは試験の表の倍率(固体 ×20000・気体 ×5000。units.luau)が支えていた。

## 決定
1. **セルの伝導率 k = (Σ 凝縮相の体積 × 伝導率 + 残りの体積 × 残りの伝導率)÷ セルの体積**(shaders/common/heat_conduction.hlsli。CPU と GPU が同じ関数)。
   - 凝縮相の体積 = 量 × モル体積(RxSpecies::molarVolume。mm³/mol。T-0609 の密度から)。セルの体積はレベル 0 の 0.125 m³(量の数は 濃さ × 0.125 m³)。
   - 残り = 気体 + 密度を書いていない凝縮相(場所を取らない。cell_volume.h と同じ)。残りの伝導率は物質量の平均。
   - 詰め過ぎ(凝縮相の体積 > セル)は凝縮相の体積で割る。
2. **気体の伝導率 ∝ √(T ÷ 室温)、混ざる速さ ∝ (T ÷ 室温)^1.5**(HcGasScaleAt。室温 298.15 K。整数の平方根)。物質の値は室温の値として書く。
   固体・液体の伝導率は温度で変えない(仮)。
3. **試験の倍率を外す**(units.luau の倍率を 1 に。T-1082 で書き直しの形を片付ける)。
4. 伝導率は温度で変わるので、仮の世界のキャッシュは本道で毎回作り直す(割り算は 1 セル 1〜2 回)。

## 作り手から見た違い
- 物の箱・砂の混ざった空気のセルの熱の伝わり方が体積の割合で決まり、箱の細かさによらない。
- 現実の伝導率なので、伝導だけでは火はセルからセルへほとんど広がらない(T-1018 の 3 行目)。燃え広がりは放射と気体の流れで起きる。
- 熱い気体ほど熱を伝え、速く混ざる。

## 残る問い
- 固体・液体の伝導率の温度の形(物質ごとの表にするか)。今は一定。
- 向きによる直列の道(層になった物)。今は平行の道だけ。
