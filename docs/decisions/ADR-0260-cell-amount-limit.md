# ADR-0260 1 セルに書ける量はセルの器 1 つで決める(合計 2^36 µmol・気体のぶん 2^31 µmol。T-0558)

- Status: Proposed(仮・ユーザー未確認。T-0558 の判断待ち A・B)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- 草原の延焼の場面(T-0414)で、0.5 m 角の水 6917 mol・砂 3121 mol が world_cells に書けなかった(1 物質 2,147,483,647 µmol まで)。水を 3 割にして回避した。
- 上限はばらばらだった: world_cells は 1 物質 2^31 − 1(気体の式の器に合わせた)・材料のひな形は 2^53(倍精度の整数の上限で、実質なし)・
  置くコマンドは 1 物質 2^36・セル(RxCell)の型は uint64。
- 2^31 の根っこは気体の式(07 §2)で、移す量を Q32 の 64bit で計算するため。気体はセル(T-0590・ADR-0256)の **condensed でない物質だけ**なので、
  凝縮相まで 2^31 に縛る理由は無かった。

## 決定(仮)
1. **1 セルの量の上限は「セルの器」1 つで、量の型・単位・ハッシュは変えない**(uint64 µmol のまま。レベル k は 8^-k µmol)。
   - 合計(全部の相)≤ `CELL_AMOUNT_LIMIT_MICROMOLES` = 2^36 µmol(68,719 mol / 0.125 m³ = 550 mol/L。いちばん詰まった固体〔ダイヤモンド 293 mol/L〕の約 1.9 倍)
   - 気体のぶん(condensed でない物質の合計)< `CELL_GAS_AMOUNT_LIMIT_MICROMOLES` = 2^31 µmol(今までの気体の式の器。300 K で約 400 気圧)
   - 定数は `shaders/common/units.hlsli`(HLSL と C++ の共通)に置き、気体(gas_internal.h の MAX_CELL_AMOUNT)・置くコマンド(PROBE_PLACE_MAX_AMOUNT)はその別名。
2. **1 物質ごとではなく合計で数える**。物理の意味(詰め込める密度)が合計にあり、熱容量・化学のエネルギーの和(04「セルの器」)の最悪も合計で決まるため。
3. **入口が同じ判定を使う**: 世界の組み立て(world_cells)と材料のひな形はベイクで `sim::CheckCellAmounts`(合計と気体のぶん)。
   置くコマンドは合計だけ(GPU の表に相が無い。足した後の合計が器を超えるセルは飛ばす。GPU と CPU が同じ ProbePlaceCell)。
4. 走っている間(反応・流れ)は確かめない。反応で気体のぶんが器を超える場合の扱いは T-0601。
   → **追記 1(2026-10-17・T-0622)**: 反応は気体の器を取り合いの資源にした(ADR-0316)。置くコマンドも気体のぶんを確かめる(GPU の表に気体の印が入った)。

## 影響
- 作り手から見て: 凝縮相(condensed = true の物質)は 1 セルに約 68,719 mol まで書ける(水 6917・砂 3121・鉄 17,600・ダイヤモンド 36,600 mol)。
  気体は今まで通り約 2147 mol まで。誤りは「world_cells.<鍵>.amounts_umol: 1 セルの量の合計は … まで」「気体のぶん … 未満」で出る。
- 置くコマンドは「1 物質 2^36」から「合計 2^36」に厳しくなる。前の再生ファイルで、合計が 2^36 を超える足しがあれば飛ぶようになる(実際の記録にあるかは未確認。ほぼ無い見込み)。
- 型・VRAM・ハッシュ・GPU のセルの形は変わらない。気体の式の値は同じ(別名にしただけ)。
- 物質の表の上限(比熱 2^32 mJ/(mol·K)・H0 2^53 J/mol)は和の器(比熱 2^27・|H0| 2^26 で 2^36 の合計が 64bit に入る)より広い → T-0600。

## 代案(採らなかった)
- B. 相で分けて 1 物質ごと(凝縮相は 1 物質 2^36・気体は 1 物質 2^31): 気体の式が見るのは気体の合計なので 1 物質ごとでは守れない。
  成分 8 つを全部上限にすると合計 2^39 になり、和の器の見積もりが成分の数で変わる。
- C. 上限を外して和を 128bit にする: 物理的に意味の無い密度まで許すために、反応・伝導・GPU の熱の和の型を全部変えることになる。
- D. 凝縮相だけ単位を mmol にする: 反応の進行度と保存の帳簿の単位が相で変わる(元素の数を整数のまま保存する ADR-0012 の形が崩れる)。

- **2026-10-26 本体の棚卸し(QUESTIONS Q88)**: 1 セルに書ける量の器 → 閉じた(A 合計で数える器 1 つ・2^36 µmol。D-539)。
