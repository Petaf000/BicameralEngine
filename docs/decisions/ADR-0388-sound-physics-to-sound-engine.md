# ADR-0388 音は「物理エンジン → サウンドエンジン」の一方向・法則の音は「広がる」家族

- Status: Accepted(2026-10-21。一方向の流れはユーザーの決定 claude/32 S21。広がる家族は一旦の決定 claude/34 S40。法則の音の場を真実で持つ形〔D-592〕は Proposed = 仮・ユーザー未確認)
- 日付: 2026-10-21
- 決めた人: ユーザー(claude/32 S21・claude/34 S40。Claude が案を出した)
- 決定の番号: D-590・D-591・D-592
- 関係: D-452(置き換える)・D-317(再生は自作)・D-308(GPU → CPU は待たないリング)・D-403・D-465・D-467・D-540(6 つの家族)・D-606 (2)・ADR-0373・ADR-0392・設計 11・20 §8・06 §3

## 背景
- 前の形(D-452): 音はできるだけ物理から作る(物の固有の振動・燃焼や破断の出来事からの合成。研究)。設計 11 は鳴らす側だけだった。
- 2026-10-21 のユーザー: 「出来事が音を出すのは出す。BotW みたいに。でもこっち側でもいろいろできるようにしたい。物理エンジン → サウンドエンジンって感じでデータの流れ・発火する流れは決まるイメージ」。
- 生き物が音で気付く(S20)には、決定的で、壁・扉・距離で正確に変わる音が世界の中に要る。

## 決定
1. **二つの層・一方向**: 法則の音(GPU・Model・決定的。生き物が聞く)→ 鳴らす音(CPU・View・サウンドエンジン。作り手が自由に強める・変える・足す)。
   鳴らす側から世界へは戻らない(D-403)。
2. **音の出来事は法則の行の出来事(ADR-0392)の一種**。中身は刻み・場所・法則の行の鍵・物質(最大 2)・出来事のエネルギー・音のエネルギー(× 物質の鳴りやすさ)。
   一回の出来事はリングへ、続く音は場の源とブロックごとのまとめ(セルごとに出さない)。
3. **法則の音の届き方は「広がる」家族**(坂に沿ってにじむ・通り道の吸いやすさで減る)。角を回る・閉じた壁で止まる・開いた扉は開き具合だけ通る・距離で弱まる、が一つの式から出る。
   通り道は物質の値「音の通しやすさ」(相ごとの既定。仮)と物の塞ぐ面・面の開き具合(物と場の口)で決める。新しい家族・部品・当たりを作らない。
4. **仮(D-592)**: 法則の音の場は真実(ある所にだけ持つ)。帳簿の列「出来事 → 音」「音 → 熱」で保存は厳密。伝わる速さの既定は刻みのうちに届く。

## 検討した代案と、採らなかった理由
- 物理から音を合成する(前の D-452): 作り手が鳴らし方を自由に変えにくい。研究が重く、結果が読めない。ユーザーが言い直した。
- 法則の音を「まっすぐ運ぶ」家族に: 角の向こうで聞こえなくなる(回折が出ない)。
- 法則の音を持たず、生き物は出来事を距離だけで聞く(前の 09 §3): 壁・扉で遮られない。「扉を閉めて隠れる」が法則から出ない。
- 法則の音を導かれる値に(その刻みの源だけから解き、残さない): 軽い。残響が法則から出ず、帳簿は出来事の場所で熱にする形になる。R-A1 の 2 本目として測る。

## 影響
- しやすく: 作り手は鳴らす側を好きに作れ、世界の結果は変わらない。獣が聞く音は壁・扉・距離で正確に変わり、作戦になる。音のための新しい仕組みは無い(広がる家族と法則の行の出来事を使う)。
- しにくく: 鳴らす側と法則の側が食い違うことがある(鳴らす側だけ強めても獣は気付かない)。作り手の責任で、計器(聞き手の所の法則の音)で見える。
- 未確認: 法則の音の場の費用(R-A1)。

## 仮・ユーザー未確認
- 【エンジン】法則の音の場を真実で持つか導かれる値にするか(D-592)。作り手から見た違いは決定 4 と代案の最後。取り消しやすい。
