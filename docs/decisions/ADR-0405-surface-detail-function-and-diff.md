# ADR-0405 表面の細かい形の関数と差分の持ち方(研究 R-T1 の 1 本目)

- Status: Proposed(形は Claude の仮。真実の決め方は【エンジン】の問いとして T-0879 に)
- 日付: 2026-10-21
- 決めた人: Claude(T-0879 の作業役)。前の決定: ユーザー D-575・ADR-0384(表面の細かい形の 3 段)
- 設計書: docs/design/23-radiation.md §7・§10 R-T1

## 背景
ADR-0384 は約 2 cm〜0.5 m の形を「物質と場所の種から決まる関数 + 変えた所だけの差分」で持ち、法則は整数の版・描画は小数の版の同じ関数を読むと決めた。
差分の持ち方(高さの差の格子か、彫った形の一覧か)は R-T1 で決めることになっていた。

## 決定(仮)
1. 関数は `shaders/common/surface_detail.hlsli` の 1 つの源(CPU と GPU)。地面の高さ = 下地(柱の高さ)+ 肌理(値の雑音。最も細かい波 2^15 µm ≒ 3.3 cm)− 彫った深さ。
   乱数は (場所の種, 用途, 波, 世界の格子の座標) のカウンタ型(04 R6)。描画の版 `shaders/render/surface_detail_float.hlsli` は同じ乱数で float の補間(ずれ 0.22 mm)。
2. 法則へは柱ごとのセルの「固い物の割合・+x/+z の面の開き・上の面の開き」(Q16)で効く(21 §2.7 の塞ぐ面と同じ量)。形が変わった柱だけ計算し直す。
3. 差分は **彫った形の一覧(線分 + 半径 + 深さ)を仮の採用**。柱ごとの登録は導かれる値。格子(17 × 17 点)は同じ費用で差分が約 120 倍・形が最大 29 mm ずれた。
4. 下地は柱の中で平ら(既定)。滑らかな補間は設定で選べる。

## 取り消し方
- 格子に替える: 区画の mode を SD_MODE_GRID にするだけ(両方の候補の作り方・セーブ・試験を残してある)。
- 関数の形(雑音の種類・段の数)は肌理の値と関数の中だけで閉じている。

## 未確認
