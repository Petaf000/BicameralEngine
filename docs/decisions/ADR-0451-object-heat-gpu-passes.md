# ADR-0451 物の熱の GPU の段: 全部の物のボクセルを 1 本の並びにし、5 つの段(Compute)で 1 刻みを回す

- Status: Proposed(司令塔の仮。ユーザー未確認。T-1064・T-1065)
- 日付: 2026-10-24
- 決めた人: 司令塔の仮(T-1064 の依頼「多くの物を 1 回の Dispatch でまとめて回す形」)。形は Claude(wt5 の作業役)
- 設計: docs/design/20 §12.4・ADR-0434(物の熱は物の箱が持つ)・D-637・D-639
- 実装: shaders/common/object_heat.hlsli(共有の式)・shaders/sim/object_heat.hlsl(段)・tests/object_heat_cpu.h(CPU リファレンス)・tests/gpu_object_heat_test.cpp

## 決定(仮)
1. **共有の式**: 物のボクセルの口(対の面の伝導・気体の混ざり・放射・光)・物の中の伝導(体積の平行)・対の端数・セルへ当てるは shaders/common/object_heat.hlsli に置き、
   CPU と GPU が同じ関数を呼ぶ。T-0991 の試作と毎刻みビット一致(object_heat の 7)。
2. **物の形**: 箱の中の並び(sizeX × sizeY × sizeZ)と、ボクセルごとの形の語(隣のある方向 6 ビット + 囲むセルに面する面の数)。
   薄い紙は「両面だけが外」。外に面する面の数で膜の広さと放射の広さを掛ける(試作の「両面 = 2」を一般にした形)。
3. **段**(小刻みごとに ①〜④、刻みの終わりに ⑤。物ごとに投げない):
   ① 下ごしらえ(1 スレッド = 1 ボクセル)→ ② 流れ(1 スレッド = 1 ボクセル。囲むセルは読むだけ。自分のボクセルにだけ書く)
   → ③ 物ごとの和と対の端数(1 グループ = 1 物。groupshared で足す)→ ④ セルへ当てる(1 スレッド = 物の入っているセル 1 つ。物は囲むセルの順に並べる)
   → ⑤ 反応(1 スレッド = 1 ボクセル。RxStepCellWait)。64bit の atomic は使わない(R4 の可換な足し算だけでも足りるが、セルの成分の並びは atomic で足せない)。
4. **対の面の気体は表の気体 8 つまで**(OH_MAX_GASES)。気体の番号ごとに記録を持つ(物質 ID の写像は表から作る)。
5. **眠らせ方**(T-1065・まだ作らない): 起きている物の一覧で Dispatch する。眠る = 1 刻み回してボクセル・対の端数・セルへの受け渡しが全部 0
   (流れは 0 の向きに切るので、温度と気体の濃さが囲むセルと揃えば厳密に 0)かつ反応が待ちの丸めで起きない。
   起こす = 囲むセルが変わった・光が当たった。冷えた紙は 2 刻み目から何も変わらない(object_heat の 8)。

## 検討した代案(作り手から見た違い)
- 物ごとに Dispatch: 物が 1000 個で 5000 回の投げ(1 回 数 µs の固定費)。作り手から見た違いは無く、遅いだけ。
- 物とセルの受け渡しを 64bit の atomic で直接セルへ: セルの成分の並び(物質 ID の昇順に詰める)が atomic で足せない。セルごとの範囲で足す形にした。

## 影響
- エンジン: 物のボクセル(T-0821)の真実の置き場と、世界の刻みの中の段の位置(当てる段の後・反応の前)は T-1077 で決める。セルの口は MultiresCellStore(T-1077)。
- 作り手: 燃える小さい物は物として置く(ADR-0434 問い 2 は Q153 のまま)。

## 費用(T-1065・RTX 3070 Ti・CPU とビット一致の版)
- 1 ボクセル 8〜10 ns・1 刻みの固定費 約 0.1 ms。燃える紙 1000 枚 10〜18 ms・小枝 1000 本 1.5 ms・薪 100 本 4.3〜4.8 ms。燃え進んでも重くならない(反応 55 %・流れ 35 %)。
