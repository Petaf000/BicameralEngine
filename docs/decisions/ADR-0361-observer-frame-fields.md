# ADR-0361 観察の枠(影・写し)にも登録した欄を付いて行かせる(影の欄の引き戻しは「子の和 = 親 × 8」)

- Status: Accepted(2026-10-19。工学の形。引き戻しの配り方は仮〔ユーザー未確認〕。T-0761)
- 日付: 2026-10-19
- 決めた人: Claude(T-0761 の作業役)。土台の登録制はユーザー(ADR-0329)
- 関係: ADR-0329(状態の登録)・D-403(見るだけなら世界は変わらない)・D-444 ②(覗いている所の影)・設計 20 §2.1・multires.hlsli の MrPullBackShadow(セルの引き戻し)

## 背景
- ADR-0329 で欄(気体の運動量・液体の面の運動量など)は世界の木の細かく/粗くに付いて行くようにしたが、観察の枠(影・世界の写し)は欄を持たなかった
  (影を細かくしても欄の頁は前の値のまま・引き戻しもしない)。段 7(影の中で運ぶ計算を解く)の前に、影の欄の扱いを決める必要があった。
- 影は親を覆わず、世界に返さない(D-403)。セルの引き戻しは「影の子 2³ の和を親 × 8 に合わせる」(物質は子の今の量の比で配る)。

## 決定
1. **影を細かくする**: 欄も子は親と同じ数(世界の木と同じ SfRefineValue)・ブロックの欄は親の値。**親の欄は変えない**(覆わない。世界の木の Refine との違い)。
2. **影を引き戻す = 子の和を親 × 8 に**(子のレベルの単位。影を粗くすると親と同じ値・余り 0)。SAME / VOLUME・型によらない 1 つの規則
   (state_field.hlsli の SfPullBackChild。CPU と GPU で同じ関数):
   - 親と子 8 つが全部 0 以上(2^60 未満): 親 × 8 を子の今の値の比で配る(切り捨て。余りは 0 でない子に番号の順に 1 ずつ。全部 0 なら親と同じ数)。
     セルの物質と同じ配り方 = 負にならない量(運動のエネルギー・前の質量)が負にならず、影の中の偏りの形を保つ。
   - 負の値がある(運動量など): 足りない分を 8 つに等しく足す(余りは番号の順に 1 ずつ)。影の中の違い(覗いて見たい細かい流れ)はそのまま。
   - ブロックの欄は親の値に戻す。世界の欄・親・世界の帳簿には触れない(影の欄は帳簿に入らない = 保存量の合計は本物のブロックだけ)。
3. **写しを置く**: 欄は 0 から(前の影・写しの値を残さない)。写す元の世界が欄を持つ時は、呼ぶ側が置いた後に StoreNestField・StoreNestBlockField で書く
   (今の写す元 = 仮の世界は欄を持たない。仮の世界が登録に載るのは設計 20 §3)。
4. 欄の無い世界は前とビット単位で同じ(欄の一覧が空なら何もしない)。

## 案と見送った理由(引き戻しの配り方)
- A(採用): 上の 2 の規則。負にならない量は負にならず、運動量は影の細部を残す。どの欄も粗くすると親と同じ。
- B: 子を全部親と同じ数に戻す(和 ÷ 8 の逆)。簡単だが、影が刻みごとに細部を失う(覗く意味がなくなる)。
- C: 全部の欄を比で配る。符号の混じる運動量では比が決まらない(和が 0 の時など)。
- D: 型(U32 だけ比で配る)で分ける。運ぶ計算の欄は全部 I64 で、運動のエネルギーが影で負になりうる。

## 作り手から見た違い(仮の確かめどころ)
- 欄を登録すれば、覗いた所(影)にも欄が付いて行き、覗いても世界の値・保存量は 1 ビットも変わらない。
- 影の中の値は毎刻み「粗く見れば親と同じ」に戻される。負にならない欄は比で、負になりうる欄は等しくずらして合わせる
  (負になりうる欄で 0 以上の値ばかりの所は比で配られる。値で配り方が変わるのは、負にならない量を負にしないため)。

## 影響
- 段 6(GPU。T-0760)は同じ SfPullBackChild を影の引き戻しのノードから呼ぶ(子の値は読むだけ・決まった数の回しで書いてある。T-0397)。
- 段 7(影の中で運ぶ計算を解く)は、影の欄をこの引き戻しの後の値から始める。
