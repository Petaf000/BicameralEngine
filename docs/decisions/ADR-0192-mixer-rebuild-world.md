# ADR-0192 環境ミキサーで足した初めのセル・物を効かせる「世界を作り直す」

- Status: Proposed(案 A・記録 R1 を仮で実装。ユーザー未確認。T-0453)
- 日付: 2026-10-13
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- 環境ミキサー(T-0452・ADR-0183)で標準パッケージを足すと、表の法則(元素・物質・反応)は次の刻みの境界で今の世界に当たる
  (ホットリロードと同じ道。記録に印のコマンドと表の中身が残る。ADR-0047・ADR-0065)。
- パッケージには刻み 0 にしか意味の無いものもある: **初めのセル**(分類 world_cells。例: earth_air が全部のセルを地球の空気で満たす)と
  **物**(world_bodies。積み木など。物理の場面は世界を作る時に作る)。これらは足しても今の世界には現れない。
- **環境の値**(重力・音速の基準・基準の大気)を差し替えの刻みで当てる道は T-0444(wt3)が作る。この ADR は初めのセル・物だけを扱う。

## 決定(仮)
1. **案 A: 足すと法則と環境の値が今の世界に当たり、初めのセル・物は「世界を作り直す」で効く**。
   作り直す = 世界が今使っている表で刻み 0 から作り直す。**足した一覧を `--mix` で起動したのと同じ世界**(同じ表の版・同じ初めのセル・同じ物)。
   窓と GPU・表示とカメラは続ける。今のセル・置いた物・燃えている火・保存点・元に戻す履歴は消える。
   ミキサーのパネルに「世界を作り直す」ボタンと、今の表が世界を作った表と違うか(作り直すと初めのセル・物も替わるか)を出す。
2. **記録は作り直した所から(R1)**: `--record` のファイルは最後の世界(作り直した後)の記録になる。
   再生ファイルの形は変えない(初めの表 = 作り直した時の表。再生は「その一覧を --mix で起動した世界」の再生と同じ)。
3. 仕組み: `frame::RunFrameLoop` が世界ごとに FrameLoop を作り、作り直す依頼で終わったら窓と GPU(LoopDevice)と今の表を受け取って
   次の FrameLoop を作る(表は読み直さない。ミキサーで当たった表そのもの)。再生中は作り直さない。
4. 人がいない確かめ `--auto-rebuild`: ブランクの世界に空気で満たす(と依存)を足す → 当たる → 作り直す → 作り直した世界の初めの表が
   `--mix` で読んだ表と同じ版・初めのセルの領域がある・60 刻み進む。記録を別の起動で再生してハッシュ列が同じ(window_rebuild_record/play)。

## 検討した代案と、採らなかった理由(作り手から見た違い)
初めのセル(大気)を足した時、今の世界にどう効かせるか:
- **案 A(おすすめ・仮で実装): 作り直すボタン**(上)。
  - 作り手から見た違い: 法則だけ試したい時は世界が続く(足すだけ)。空気・物も欲しい時は 1 回押す。作り直した世界は `--mix` の起動と
    同じなので、起動の引数・セーブ(15)に足した一覧を書けば同じ世界が作れる。今の世界の状態は残らない。
  - 取り消し: 案 B・C は後から「作り直す」の横に別のボタンとして足せる(この案を壊さない)。
- **案 B: 足した刻みで、セルを初めのセルの値に置き換える**(世界は続き、刻みと記録も続く)。
  - 作り手から見た違い: 物理の物・時刻は続くが、セルの中身(燃えている火・置いた物質)は上書きで消えるので、案 A とほぼ同じ結果を
    違う道で作ることになる。置き換えで消えた物質・熱は保存則の帳簿に「改造による出入り」として載せる必要がある(D-484 と同じ扱い)。
    記録には「セルを書き換えるコマンド」が要る(再生ファイルの形が変わる)。
- **案 C: 足した刻みで、今のセルに足し合わせる**(今ある空気の上に空気を足す)。
  - 作り手から見た違い: 既に空気がある所は 2 倍の量・2 気圧になる。足す量を作り手が予想しにくい。帳簿は案 B と同じく改造の出入り。
- **案 D: 足すと自動で作り直す** — 法則だけ試したい時にも世界が消える。採らない(案 A のボタンを押せば同じ)。

記録の扱い:
- **R1(仮): 作り直した所から** — 再生ファイルの形が変わらない。作り直す前の操作は記録に残らない。
- **R2: 作り直しを記録のコマンドにする**(1 つの記録に複数の世界)— 作り直す前後を通して再生できるが、再生ファイルに世界の区切りと
  区切りごとの初めの表が要る(形の版が上がる)。要るようになったら R1 の上に足せる。

## 影響
- しやすくなる: ブランクの世界から、ミキサーで足して作り直すだけで「空気で満たした世界」が作れる(起動し直さなくてよい)。
- しにくくなる: 作り直す前の世界の記録は残らない(R1)。作り直すと保存点・元に戻す履歴も消える。
- 未対応: 足した一覧の保存(世界のファイル。セーブの形 15)。
- 追記(2026-10-13・司令塔): T-0444 がマージされ、環境の値(重力など)は差し替えの刻みで今の世界に効く(ADR-0194)。作り直しが要るのは初めのセル・物だけ。
