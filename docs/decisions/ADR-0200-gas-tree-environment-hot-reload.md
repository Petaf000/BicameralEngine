# ADR-0200 気体の多重解像度の木の環境の値のホットリロード(小刻みの数は替えず、木の上限の外は断る)

- Status: Proposed(下の 1 を仮で実装。ユーザー未確認。T-0470)
- 日付: 2026-10-14
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)
- 関係: ADR-0194(環境の値のホットリロード。1 レベルの気体の箱と物理)・ADR-0117(気体の木・レベルごとの小刻み T-0320)・T-0269(頭打ちの温度)

## 背景
- ADR-0194 で 1 レベルの気体の箱(CPU `SetGasEnvironment`・GPU `GpuGas::RecordEnvironment`)と物理の重力は、表の差し替えの刻みから
  新しい環境の値で刻むようになった。多重解像度の木(`gas_tree`・`GpuGasTree`)は木を作った時の値のままだった(T-0444 から分けた)。
- 木は 1 レベルの箱と違い、環境の値(音速の基準)が木の形とつながっている:
  - 安定の条件はどのレベルも ν × 2^(k − σ) ≤ 0.6(σ はレベルごとの小刻みの指数。`GasTreeOptions` から木を作る時に決まる)。
    音速の基準の上限は 1 レベルの箱の上限(`GasSoundSpeedLimitMmPerS(substeps)`)の 2^(k − σ の最大) 分の 1。
  - 熱いセルの頭打ちの温度(T-0269)は ν がいちばん大きいレベルで安定の上限に届く温度で、c̃ と基準の大気の温度から決まる。

## 決定
1. **小刻みの数(substeps と σ)は木の作りとして替えない(仮)**。音速の基準を上げて木の上限
   (`GasTreeSoundSpeedLimitMmPerS` = `GasSoundSpeedLimitMmPerS(substeps) >> GasTreeFinestShift`)を超えるなら、ホットリロードは断る
   (古い表のまま + 理由)。1 レベルの箱で小刻みの数を替えない(`CheckGasEnvironment`)のと同じ扱い。
   - 案 B(採らない・未確認): 差し替えで c̃ が上がったら、エンジンが σ(やレベル 0 の小刻み)を増やして受ける。1 刻みの境目ではどのレベルも
     小刻みがそろっているので作り直せるが、1 刻みの重さが値の書き換えで黙って倍になり(D-468: 負荷で遅れるのは不具合)、刻み方(離散化)が
     法則の値で変わるので、同じ c̃ でも「作った時の値」か「途中で変えた値」かで結果が変わる(D-465 の「法則は状態だけで決まる」に近い所で
     場合分けが増える)。小刻みを増やしたいなら、木を作る時の `GasTreeOptions`・小刻みの数を替えて作り直す。
2. **頭打ちの温度は作り直す**: `soundCapTemperature` が 0(既定 = 安定の上限から求める)なら、新しい c̃・新しい基準の大気の地面の温度・木の上限で
   求め直す(MakeGasTree と同じ式)。値を書いた頭打ち(試験・Q32 の案 A の形)は世界の作りとしてそのまま。
3. **作り直しは MakeGasTree と同じ道**: 環境から決まる値(全部のレベルの係数・層の基準〔新しい重力と基準の大気: 成分の割合・温度・地面の圧力〕・
   導く値・開いた境界の外・α・頭打ちの温度)を作る関数を 1 つにし(`BuildLevelEnvironments`)、`MakeGasTree` と `SetGasTreeEnvironment` が
   どちらもそこを通る。木の形(範囲・σ・セルの表)と状態(セル・端数・帳簿・刻み)には触れない(ADR-0194 の 1 の「状態はそのまま、法則だけ替える」)。
   → 替えた木は、新しい環境で作った木に今の状態を写したものと同じ係数で、毎刻み同じに進む(gas_tree_test)。
4. **GPU**: `GpuGasTree::RecordEnvironment` が環境から決まる表 t0〜t3(設定・レベルごとの係数・層の基準の導く値・層の外)を作り直して写す
   (`GpuGas::RecordEnvironment` と同じ形。前の表は呼ぶ側がリストの終わりまで持つ)。木の形の表 t4〜t6(面・セルの場所・セルの面の並び)はそのまま。
5. **断る理由の形を 1 つに**: `sim::CheckWorldPhysics` に木の `gasFinestShift`(k − σ の最大)を渡せるようにし、`CheckGasEnvironment`
   (1 レベルの箱)と `CheckGasTreeEnvironment`(木)の範囲の検査(重力の上限・音速の基準の安定の上限)はどちらもここを通す
   (パッケージの読み込み・反応表のホットリロードと同じ決まりと理由の文)。

## 影響(作り手から見た違い)
- 気体の木を世界に載せた後(T-0210)、パッケージの重力・音速の基準・基準の大気を書き換えて保存すると、木の気体も差し替えの刻みから新しい法則で刻む
  (空気は並べ直さず、新しい重力・基準と釣り合っていない分が流れて落ち着く)。
- **細かくした木ほど音速の基準の上限が低い**(小刻みを分けない 2 レベルの木で小刻み 48 なら 432 m/s。1 レベルなら 864 m/s)。上限を超える値を
  書くと「古い表のまま + 理由」(「音速の基準 … は気体の小刻み 48(木のいちばん細かい ν のレベルで 2^1 分の 1)の安定の上限 432000 mm/s を超える」)。
  上げたい時は、木の作り(小刻みの数・レベルごとの小刻み)を替えて世界を作り直す。
- 世界に気体の木を載せる時(T-0210)は、ProbeSim の表の差し替え(`ApplyEnvironment`)で `CheckGasTreeEnvironment` → `SetGasTreeEnvironment`
  → `GpuGasTree::RecordEnvironment` を同じ刻みで呼ぶ。今の `script::CheckHotReloadCompatible` は既定の小刻みの 1 レベルの上限で見ているので、
  その時に木の上限で見るようにする。

## 試験
- `gas_tree`(CPU): 途中の刻みで環境(月の重力・c̃・冷たく薄い基準の大気)を替えても閉じた 2 レベルの箱の保存が 30 刻みの毎刻みビット一致
  (分けない・分けた形)・2 回の実行で同じ・替えた木は新しい環境で作った木と同じ係数・層の基準・頭打ちの温度で毎刻み同じ・同じ値の当て直しは
  結果を変えない・木の上限の外(1 レベルなら受けられる 432 001 mm/s)・0・重力の上限の外・小刻みの数の書き換えは断る。
- `gpu_gas_tree`・`gpu_gas_tree_warp`: `closed_environment_change`・`subcycled_environment_change`(閉じた箱。毎刻み保存も)・
  `open_environment_change`(開いた境界と風)が刻み 3 で替えて 8 刻み、毎刻み CPU とビット一致。
