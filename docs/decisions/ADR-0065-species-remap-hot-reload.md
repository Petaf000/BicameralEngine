# ADR-0065 物質を足す・消す反応表の差し替えは、名前で ID を付け替え、消えた物質を元素の単体に分けて戻し、熱を保つ

- Status: Accepted(実装の細部。CLAUDE.md §5。ユーザー未確認の点はチケット T-0223 の「判断待ち」)
- 日付: 2026-10-10
- 決めた人: Claude。T-0223(D-438)

## 背景
- D-438: 物質を足す・消す変更も、名前で ID を付け替えてその場で当てる。消した物質が世界に残っていたら元素に分けて戻し、保存則を守る。
- 物質 ID は名前のバイト順(ADR-0032)。物質を 1 つ足す・消すだけで後ろの物質の ID がずれ、セルの中身の意味が変わる。
- これまでのホットリロード(ADR-0047)は物質の一覧が同じ表しか当てなかった(T-0139 の判断待ち 1 の案 A)。
- セルの成分は物質 ID の昇順・物質量 0 の成分は持たない(reaction.hlsli)。セルのエネルギーは「熱 + 化学(Σ 物質量 × h0)」。
- 安定な化合物を元素に戻すのは強い吸熱(セルロース C6H10O5 は約 +963 kJ/mol)。エネルギーをそのまま保つと、木の壁のセルは熱が
  大きく負になる(温度が作れない)。

## 決定
1. **同じ物質**: 名前と元素の組み立て(元素の名前ごとの原子の数)が同じなら同じ物質。ID だけ付け替える。残る物質どうしの順は
   名前のバイト順のままなので、セルの成分は昇順のまま。名前が同じで組み立てが変わった物質は「消して足した」とみなす(原子を保つため)。
2. **消えた物質は元素の単体へ**: 元素ごとに、新しい表の「単体」(その元素だけでできた物質のうち、原子 1 つあたりの h0 が一番低い
   = 一番安定な形。同じなら原子の数が少ない方・ID が小さい方)へ、原子の数を保って移す。セルの中の消えた物質の原子を単体ごとに集め、
   単体の原子の数で割る。単体は新しい表の ID の昇順に足す。
3. **失うもの(報告する)**: 単体の原子の数で割り切れない端数(O2 に奇数個の O。1 セル 1 元素あたり単体の原子の数 − 1 µmol 未満)と、
   セルの成分の上限(RX_MAX_CELL_SPECIES)に入らない単体。どちらも量を報告する(SpeciesRemapReport)。上限は D-448 で無くす予定。
4. **熱を保つ**: 分けた分の化学のエネルギーの差(µJ)を mJ に切り上げてセルのエネルギーに足す(熱は減らず、増えても 1 mJ 未満)。
   足したエネルギーは改造による出入り(D-419 の明示的な出入りと同じ扱い)として報告する。残る物質の値(生成エンタルピーなど)が
   変わった分は、これまでどおりエネルギーを保つ(ADR-0047)。
5. **当てない表**: 消す物質の元素に単体が無い表は当てない(理由: どの物質のどの元素か)。世界の中身を見ずに表だけで決める
   (GPU の世界を読み戻さずに済み、記録と再生で同じ判断になる)。元素を消す表は、その元素を含む物質が消えるので同じ規則で当てない。
6. **いつ・どこで**: 表を差し替える刻みの始め、コマンドの適用の前に、2 世代のセルを付け替える(その後は ADR-0047 のまま:
   新しい表でコマンドを当て、熱のキャッシュを作り直し、全部のブロックを起こす)。
7. **記録と再生**: 付け替えは今の表と新しい表の 2 つだけから決まる。再生ファイルは差し替えの印と表の中身を持つ(ADR-0050)ので、
   再生は同じ付け替えを作り直す。新しいコマンドの種類は要らない。
8. **同じ関数**: セル 1 つの付け替えは shaders/common/species_remap.hlsli の RxRemapCell(HLSL と C++ の両方でコンパイル)。
   CPU リファレンス(sim::RemapReactionCell・ProbeReference::Advance)と GPU の付け替えの段(probe_tick.hlsl の RemapSpecies。
   付け替えの表は sim::PackSpeciesRemap の語の列をルートの SRV t5 で読む)が同じ関数を呼ぶ。
9. **段階**: 世界の側が付け替えられるまで、ホットリロードは物質の一覧が変わる表を当てない(script::SpeciesChangePolicy::Reject)。
   付け替えられる世界は Remap を渡す。世界(CPU リファレンスと GPU の ProbeSim)は T-0223 で付け替える。覗き窓・実験室とエディタで当てる所は T-0242。

## 検討した代案と、採らなかった理由
- **エネルギーをそのまま保つ**(熱を保たない): 保存則としては厳密だが、セルロースを消すと木の壁の熱が負になり温度が作れない
  (化学のエネルギーの差は 1 mol で約 960 kJ。壁のセルの熱の何十倍)。改造は世界の反応ではない(D-428 の「嘘」ではない)ので、
  差を明示的な出入りとして記録・表示する方を採った。
- **端数をセルの間で持ち越す**(セルの番号の順に足して、世界全体で原子を厳密に保つ): GPU で前置和が要る。失うのは 1 セル 1 元素あたり
  1 µmol 未満(O で 16 µg)なので、報告に留めた。判断待ち(T-0223)。
- **単体が無ければ、元素の単体を表に自動で足す**: 読み込んだ表とファイルの中身が食い違い、版・再生の表の中身(ADR-0050)の扱いが
  複雑になる。単体を足すのは表を書く人に任せる(当てない理由に「単体を足すか、物質を残す」と書く)。
- **世界に残っていなければ当てる**(中身を見て判断): GPU の世界の読み戻しが要り、判断が世界の状態に依存する。表だけで決める方が単純で決定的。
- **付け替えをコマンドの payload に入れる**: 付け替えは表 2 つから決まるので、記録は表の中身で足りる。

## 影響(何がしやすく/しにくくなるか)
- しやすい: 反応表を書く人が、新しい物質を足す・要らない物質を消す変更を、動いている世界のまま試せる(エディタで当てるのは T-0242 の後)。
  消した物質の原子は単体として世界に残るので、元素の数は(報告した端数を除いて)保たれる。
- しにくい: 単体の無い元素を持つ物質は消せない(先に単体を足す)。消した物質の吸熱・発熱は温度に出ず、エネルギーの出入りになる。
- 差し替えの刻みは全部のセルを 1 回なめる(GPU は 1 スレッド 1 セルの段が 1 つ増えるだけ。差し替えた刻みだけ)。

## 追記(2026-10-10・T-0242): 覗き窓・実験室・エディタ
- エディタのホットリロードは `--species-remap` の時 `SpeciesChangePolicy::Remap`(frame/table_hot_reload。世界・覗き窓・実験室が付け替えられる)。
  既定にするのは、窓の世界で物質の数が変わる差し替えの後に出る GPU の assert を直してから(T-0254)。
- 覗き窓: 作りは ADR-0054 の 2 のまま(付け替えた後の世界の写しから影の鎖を作り直す。影の鎖そのものは付け替えない)。
- 実験室: 表を替えた印の刻みに、コマンドの前に箱の全部のセル(一様の値と頁)を付け替える(GPU と CPU が同じ RxRemapCell)。
  箱は 1 レベルなので端数の枠と帳簿は付け替えない。記録(BLAB)は今までどおり印と表の中身だけ。再生は流す前に表から表へ付け替えられるか確かめ、
  流し終えて最新の表へ戻す印は付け替えられる時だけ置く。
- まだ当てていない操作の物質 ID: 物質 ID は表ごとに違うので、前の表で作って新しい表の刻みに当たる置く操作(実験室の材料・同じフレームの筆)は、
  記録する前に名前で付け替える(消えた物質の材料は落とす)。記録には付け替えた後のコマンドが残るので、再生では付け替えない。
