# ADR-0284 GPU の気体の段と木の成分の数に上限を置かない(件 = 頭 + 欄 × 欄の数・欄の数はルート定数。T-0598)

- Status: Accepted(エンジンの作りの細部。作り手から見た違いは「GPU でも表の気体を何種書いても流れる」だけ)
- 日付: 2026-10-15
- 決めた人: Claude(T-0598 の作業役。D-401・ADR-0258・ADR-0270 に沿う実装の細部)

## 背景
- CPU の 1 レベルの箱は T-0591(ADR-0258)で成分の数の上限を外した(GasPerSpecies)。GPU の gas_step・gas_tree_step と CPU の木は
  欄 4 つ(GAS_GPU_MAX_SPECIES。GasGpuCell 64 バイト)のままで、仮の世界の GPU の刻み(T-0592・ADR-0270)は区画の気体の物質が 5 つ以上の刻みを
  流さずに数えていた(CPU と食い違う)。地球の空気(N2・O2・Ar・CO2)だけで 4 つ埋まり、燃えると H2O・CO が加わる。
- 気体の段は Compute(Work Graph ではない)。ルート署名は 1 レベルの箱 24 語・木 46 語・仮の世界 59/64 語で、成分ごとに別のバッファを足す余地は木と仮の世界に無い。

## 決定
1. **成分ごとの欄は ByteAddressBuffer に置き、バッファの本数とルート署名は変えない**(gas_gpu.hlsli・gas_tree_gpu.hlsli)。
   - 状態と作業(セル・面・セルごとの合計・木の端数と出した量。毎段たくさんのスレッドが読む): **決まった形の頭 × 件の数の後ろに、成分ごとの面
     (uint64 × 件の数)を欄の数だけ**(GasGpuPlaneAddress)。隣のスレッドの同じ成分が隣り合うので読みがまとまり、欄の数より少ない成分しか回さない時
     (仮の世界)は使わない欄の面に触れない。
   - 設定(頭 112 バイト + GasGpuSpecies 24 バイト × 欄)・開いた境界の外(頭 32 + 物質量 8 × 欄)・帳簿(エネルギー・運動量の後に物質量): 件ごと。
   - 先に件ごと(頭 + 欄)の形を試した: 4 種以下の箱は今と同じ速さだったが、仮の世界(欄の数 8 に使う欄 4)の気体の段が 1.64 → 2.82 ms に重くなった
     (D-468)。成分ごとの面にして 1.57 ms・一様な箱 32³ の 3 種も 10.0 → 8.4 ms(docs/perf.md)。
2. **欄の数(1 件の大きさ)は作る時に決まり、ルート定数で渡す**(gas_step・gas_tree_step の b0 の 4 語目。GetDimensions は使わない)。
   **回す成分の数は設定の speciesCount**(≤ 欄の数)。仮の世界は欄の数 = 表の気体の物質の数(区画に現れうる気体の物質の数)、回す数 = 刻みごとの欄の物質の数
   (GPU が決める。ADR-0270 の 1)。成分のループは件の欄を直に読み書きし、成分の数の大きさのローカルの配列を作らない(T-0397 の形に当たらない)。
3. **成分の和は 1 つずつ足す**(GasGpuTotals: 物質量・熱容量・化学のエネルギー・質量)。整数の足し算なので足す順に依らず、
   4 種以下の結果は今までとビット単位で同じ。木の粗い風上の × 8^d は和を 2^shift 倍する(2^64 を法として成分ごとにずらしてから足すのと同じ)。
4. **丸めの鍵は設定の欄ごとの値**(既定は欄の番号 = 今まで)。木(CPU・GPU)も設定の鍵を使う(ADR-0258 の 3 の「木は欄の番号だけ」を外す)。
5. CPU の木(gas_tree)の端数・帳簿・面の移す量・出した量も GasPerSpecies にし、MakeGasTree の 4 つまでの assert を外した。
6. 仮の世界: 欄の物質・物質 → 欄・基準の大気の物質・設定は作業場の見出しの場所(probe_gas_gpu.hlsli)。基準の大気の物質の数の上限(4)も外した。
   区画の気体の物質が欄の数を超えた刻み(SKIPPED_TOO_MANY)は欄の数の決め方から起きない(守りとして残す)。

## 影響
- 作り手から見て: 表の気体の物質を何種書いても、GPU の気体の段・木・仮の世界の GPU の刻みで流れ、CPU と毎刻みビット一致する。
- 費用: 成分の数に比例するのは面の移す量・セルの和・移す段の欄だけ(力・流れの段は成分に依らない)。一様な箱 32³ で 3 種 8.4 ms・6 種 10.6 ms/刻み
  (RTX 3070 Ti。docs/perf.md の 2026-10-15 T-0598)。
  仮の世界は欄の数(表の気体の物質の数)ぶんの件の大きさを確保し、回すのはその刻みに区画にある気体の物質だけ。
- 代案(採らなかった):
  - 成分ごとの欄を別のバッファにする: 木は 9 本・仮の世界は 1 本以上のルート引数が要り、64 語に収まらない(同じバッファの後ろに面を置けば足りる)。
  - 件ごと(頭 + 欄)に並べる: 上の 1 の通り、使わない欄がある時に重い。
  - RxCell のようにインライン 4 + 溢れ: GPU では件の大きさが揃わず、溢れの置き場の管理が要る。
  - 表の気体の物質を全部回す(仮の世界で刻みごとに欄を決めない): 区画にない物質のぶんも毎刻み回すことになる。
