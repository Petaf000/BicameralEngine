# ADR-0424 世界の中の光(R-R1): 距離ごとの段の研究を閉じ、退く道(決めた数の向きで掃く)へ移る

- Status: Proposed(研究の打ち切りの約束〔23 §3.3・§10 R-R1〕どおりの移り。Claude の案。退く道の形の細部は T-0987)
- **D-636 の注(2026-10-24 ユーザー決定)**: 距離ごとの段(RC)は土台として main に残し(t-1010-rc-fast を 2026-10-24 にマージ)、別の光の運び方を同じ場面で並べて研究する。合格した方を残す(ROADMAP T-1062)。記録: 瞬間の筋は RC では光線を増やしても減らない(T-0959)。筋の合格の見方(瞬間 / 数秒の平均)は研究の結果で決める
- 日付: 2026-10-21
- 決めた人: Claude(T-0972。司令塔の判断「これが最後の 1 回」に従う)
- 設計: docs/design/23-radiation.md §3.3(退く道)・§10 R-R1 / 前: ADR-0413・ADR-0419 / 基: ADR-0262・ADR-0252(T-0584 の CPU の作り)

## 背景
距離ごとの段(Radiance Cascades の型)は、ADR-0413 の形・ADR-0419 の直しの 2 本で、合格 6 項目のうち筋(8 m の円 ±10 %・60 刻みの平均)と
坂を下る(同じ温度の閉じた箱で正味の出入りが計器の精度の内)が通らなかった。T-0972 で知られた直し方を試した:
1. 段の受け渡し(bilinear fix に当たる形): 区間の終わりの点から続ける → 筋 ±93 %(悪い)。升目の中のずらしを刻みで層に分ける → 60 刻みで −18 〜 +20 %、256 刻みで ±9 %。
   本来の 3D の形(下の段の各プローブから上の段の 8 つへ結ぶ)は段 1 以上の光線が 8 倍(照り返しのある地面で約 300〜450 万本/刻み)で、費用の線(1 ms)に入る見込みが無い。
2. 向きの前平均 + 相互の重み(量が出た面の Lambert の重みで子へ分ける): 閉じた箱の偏りは 2 段で消えた見込み(19 % → 200 刻みで 4.7 %、刻みで減る)。5 段は 75 刻みで 11.7 %(未確認)。
筋の合格に入る形が無いので、研究の打ち切りの約束に従って退く道へ移る(数字は T-0972)。

## 決定
1. 世界の中の光の運び方は、**決めた数の向きで掃く**(ADR-0262 の平行な線の束)を基にする。距離ごとの段のコード(sim/cascade_light・common/cascade_light.hlsli)は
   研究の記録として残し、段 0 の面から放つ量(RcFaceEmission)・帯と物質の光の値・照り返しの持ち越しの形は退く道でも使う。
2. 坂を下るは、対ごとに 1 つの整数の流れ(温度の差に比例。ADR-0252)で**構造で 0** にする(段の形で残った正味の出入りの芯を形で消す)。
3. 筋は受け入れる(23 §3.3)。ただし向きの組を刻みごとに R6 のハッシュで回し(16 組に決めない)、時間の平均で均す。向きの数は費用の線で決める(T-0987)。
4. 届く距離に上限を置かない(D-572。T-0584 の 16 m の切りは外す)。

## 検討した代案
- 距離ごとの段に 3D の bilinear fix を入れて続ける → 光線 8 倍。GPU の 1 ms(T-0959)に入る見込みが無い。研究の打ち切りの約束(2 本)も越える。
- 段の形のまま 60 刻みの合格を 250〜500 刻みの平均に緩める → 合格の線を変えるのはユーザーの判断(D-443 ② の「熱容量で均される」の読み方)。下の問い。

## 問い
- 【エンジン】筋の合格の線を「60 刻みの平均で ±10 %」から「数秒(250〜500 刻み)の平均で ±10 %」に緩めれば、距離ごとの段(1b + 2 の形)が通る見込みがある。
  作り手から見た違い: 遠くの小さな火から受ける熱が、1 秒ほどの間は場所で ±20 % 揺れる(数秒で均される)。退く道は筋が向きの数だけ残る代わりに、坂は構造で 0。
  今は約束どおり退く道へ移る(仮)。緩めるならユーザーが決める。

## 仮(作り手から見た違い)
- 【エンジン】退く道へ移る: 遠くの小さな火の熱が向きの数だけの筋になる(刻みで向きを回して均す)。近くの光・壁の陰・照り返し・保存は同じ。
