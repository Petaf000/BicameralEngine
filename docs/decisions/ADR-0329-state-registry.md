# ADR-0329 持ち越す状態は登録制にする(区画の一覧を回る・欄は頁と同じ番号の「欄の頁」)

- Status: Accepted(2026-10-17。土台の決定〔ユーザー 2026-10-17〕の段 1 ①。細部の 3 つは仮〔ユーザー未確認〕。T-0711)
- 日付: 2026-10-17
- 決めた人: ユーザー(土台・登録制)/ Claude(T-0711 の作業役。形の細部)
- 関係: runner/design/substrate-decided.md §2.1・§3・§6 段 1 ①・ADR-0015(多重解像度の木)・ADR-0017(端数)・ADR-0331(世界の帳簿 1 型。T-0712)

## 背景
- 状態のハッシュは約 11 か所・保存点と写しは 3 つあり、区画(気体・液体)を足すたびに 2〜3 か所を直していた(survey-engine §3)。
- 土台では気体の運動量・液体の面の運動量・前の相の質量・機械の蓄えなど「セルの外の欄」が増える。MR には置き場が無かった。

## 決定
1. **欄の登録の形は共有 .hlsli(shaders/common/state_field.hlsli の SfFieldDesc)**: 置き場(セル / 面〔+ 側の 3 面〕/ ブロック / 世界)・型・付く相・
   細かく/粗くの規則・保存量か・ハッシュに入るか・値の数。名前は C++ の側。CPU と GPU が同じ関数(SfRefineValue・SfAddCoarsenChild・SfCoarsenValue)を呼ぶ。
2. **置き場**: セル・面の欄は頁と同じ番号の「欄の頁」(並びは nest.cells と同じ。一様なブロックは値 1 つ)。ブロックの欄は枠ごと、世界の欄は 1 つ。
3. **細かく/粗く**: 細かく = 子は親と同じ数(量の単位はレベル k で 8^-k)。粗く = 和 ÷ 8(−∞ 向きの切り捨て)。VOLUME の欄は余りを世界の帳簿(ADR-0331)の「粗くした端数・出」のその欄の列へ、SAME の欄は捨てる。
   **VOLUME の欄 = 保存量の欄(SF_FLAG_CONSERVED)**: 登録すると帳簿に値の数だけ列が足され、ComputeConservedTotals が欄の和を数える(T-0762)。
   和は各値を 8(v >> 3) + (v & 7) に分けて足す(64bit を越えない)。
4. **状態の区画の一覧(VisitNestState)を 1 つ持ち、ハッシュ・保存点・写しはそれを回るだけ**。一覧の前の部分の並びと要約の仕方は前の HashWholeNest と同じ
   (欄の無い世界の要約はビット単位で同じ。試験で確かめた)。種と索引はハッシュに入らないが保存点・写しには入る。
5. 木の操作は欄の関数(nest_fields の 7 つ)を呼ぶ: 根を置く・頁に広げる・畳めるか・畳む・細かく・粗くしても一様か・粗く。

## 仮(ユーザー未確認。T-0711 の判断待ち)
- 値はどれも 64bit の符号付きで持つ(型は範囲の約束)。
- 欄が一様でない頁は畳まない(許容差つきでも欄はビット単位の時だけ)。
- 面の欄の細かく/粗くはセルと同じ(内側の新しい面の値は段 7 の研究)。

## 影響
- 欄を足す = 登録 1 行。ハッシュ・保存点・写し・細かく/粗くは直さない。
- 残り: GPU(段 6。T-0760)。観察の枠の欄は T-0761 で済み(ADR-0361。影の欄の引き戻しは子の和 = 親 × 8)。余りを世界の帳簿の 1 型の列へは T-0762 で済み(欄ごとの帳簿 MultiresField::ledger は無くなった)。

- **2026-10-26 本体の棚卸し(QUESTIONS Q114)**: 状態の登録の仮 3 つ → ①② 閉じた(D-539)・③ もう要らない(細かくする時は置かれ方で配る。D-664)。
