# ADR-0337 世界の端は「外のセルとの同じレベルの面」(open / wall・外の柱・帳簿の「世界の端」)

- Status: Proposed(2026-10-17。T-0721。土台の決定 D-509・D-514〔外との境は世界の端だけ・風は入れない〕の作り。細部は仮〔ユーザー未確認〕)
- 日付: 2026-10-17
- 決めた人: Claude(T-0721 の作業役)
- 関係: docs/design/20 §1・§2.4・§2.6・T-0710(world_edges の欄)・ADR-0331 / T-0762(帳簿)・T-0714 / ADR-0334(面の帳簿と当てる段)

## 背景
- 区画の箱をやめたので、外との境は世界の端(上・下・横)だけ。作り手は環境の world_edges に open / wall を書く(T-0710)。
- 今まで MR の面の隣が世界の外なら断熱(MR_NEIGHBOR_NONE)で、開いた端の形が無かった。PS の気体は箱ごとに「開いた境界の外」を別に持っていた。

## 決定(仮)
1. **開いた端の面 = 外のセルとの同じレベルの面**。外のセルは値を変えない(無限の溜め)。流れの種類は外のセルの見立てを読むだけで、
   端の場合分けを持たない(熱は外の温度へ・気体は外の大気と出入り・液体は外に液体が無いので出るだけ、が各種類の式から出る)。
   流れた分は世界の帳簿の理由「世界の端」(WL_REASON_WORLD_EDGE)の出 / 入へ、包みの列ごとに。保存の検査は ComputeConservedTotals のまま合う。
2. **wall = 面の隣が無い**(MR_NEIGHBOR_NONE。今の既定と同じ)。既定は全部 wall なので、端を書かない世界は前とビット一致。
3. **世界の箱**は根のレベルのセルの座標(WeWorld。low を含み high を含まない)。面の先が箱の外かは面の軸だけを比べる。縦は z(上 = +z)。
4. **外の柱**: 外のセルはレベル 0 の z ごとの 1 列(基準の大気をその高さで読んだもの)。レベルの単位が 8^-k なので、同じ密度・温度ならどのレベルでも同じ数。
   レベル k のセルは中心を含むレベル 0 の z の行を読む。上下の外は端の行のまま。柱が空(基準の大気が無い)なら外は真空。
5. **影のブロックの外は断熱のまま**(影は自分の中だけ)。
6. 当てる段(T-0714)に載せる: 面の隣の種類 MR_NEIGHBOR_EDGE(index = 外の柱の行)・World の約束に Outside(行, レベル)〔外の見立て〕と
   AddEdge〔5 帳簿〕を足し、TxFlowCell は EDGE の面を同じレベルの式で流して相手に足さず帳簿へ(分岐 1 つ)。上限の段では外の倍率は 1。

## 代案
- 端ごとに種類が境界条件を持つ(熱は外の温度を固定・気体は外の圧力を固定…): 種類ごとに場合分けが増え、PS の気体の開いた境界と同じ二重書きになる。採らない。
- 外のセルを根のレベル 1 つにする: 細かくした所の端で面の大きさが合わない(粗い隣として扱うと細かい側が送る形になり、外に端数の置き場が要る)。採らない。

## 影響
- 作り手: world_edges の open が動く(今は陽の伝導だけ。気体・液体は T-0720・T-0717 で同じ口)。
- 費用: 端に接するセルの面ごとに外の見立て 1 つ(柱の行。刻みで変わらない)。
- 後で: 外の柱を基準の大気から作る・環境につなぐ(T-0772)、GPU と陰解法(T-0773)。
