# ADR-0214 エディタの編集の状態とプレイ(UE と同じ形。D-491・T-0497)

- Status: Accepted(形は 2026-10-14 ユーザー決定 D-491。下の「仮」はユーザー未確認)
- 日付: 2026-10-15
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- D-491 ①: 起動は止まった編集の状態 → プレイで動かす → 動かしたままも編集できる → プレイをやめると編集の状態(プレイ前の世界)に戻る。
  ②: 止まっている間の置く・消すは普通の Undo/Redo で何回でも。プレイ中の Undo は最近約 12 秒。T-0411 の刻み 0 の保存点はプレイ中の Undo に使わない。
- 置く・つつく・押すは刻みのコマンドで、刻みの最初の単位(適用)で当たる(06 §3)。保存点は刻みの境界の状態(ADR-0036)。
  筆の元に戻すは「保存点へ戻し、その運びを除いて流し直す」(ADR-0101)。

## 決定
1. **状態**: `editor::TimeControl` が Edit / Play を持つ。`--editor` の生の起動(再生でない)は Edit から。再生・エディタなしはいつも Play。
   一時停止と 1 刻みはプレイの中(編集の状態では時間を進めない)。
2. **編集の状態で置く(仮)**: 待っているコマンドは、それを当てる刻みだけ進めて当てる(frame_loop の ApplyEditCommands。
   1 回 = 1 刻み = 1/60 秒、世界が進む)。編集の状態の刻みは置いた回数ぶんだけなので、元に戻す・やり直しは刻み 0 の保存点から何回でも流し直せる。
3. **プレイ**: 押した後の最初の刻みの境界 P の状態を、プレイを始めた保存点(保存点の最後の番号。--editor の生の起動だけ 1 つ足す)へ写す。
4. **やめる**: プレイを押した後に作ったコマンド(番号で見分ける)とその運びを捨て、P の保存点へ戻す(残っていなければ P 以前の保存点から
   P まで流し直す。反応表を差し替えて保存点が無ければ戻さず、今の世界のまま編集の状態へ)。記録も P まで切り詰める(ADR-0101 と同じ)。
5. **元に戻す・やり直しの範囲**: 戻ってよいいちばん古い刻み `UndoFloorTick` = 編集の状態は 0、プレイ中は max(P, 今 − 720 刻み)(仮: 12 秒で固定)。
   運びも戻る保存点もこれより後。やり直しは元に戻した運びのコマンドを元の刻みのまま今の流れの控えへ戻し、元に戻すと同じ道で流し直す。
   新しい運びを始めるとやり直しの列は空になる。
6. **キー(仮)**: F5 / Space = プレイ・Esc = やめる・プレイ中の Space = 一時停止 / 再開・N = 一時停止中に 1 刻み・Ctrl+Z / Ctrl+Y。
7. **CLI**: `--play`(起動してすぐプレイを押す。窓の試験で世界を動かす時)・`--auto-play`(確かめ)。

## 理由
- やめて戻る・Undo/Redo を、新しい仕組みを足さずに保存点と流し直し(ADR-0036・ADR-0101)だけで作れる。世界の結果はコマンドと刻みだけで決まるので、
  戻った世界と 2 回目のプレイは決定的に同じ(--auto-play が 2 回のプレイのハッシュ列で確かめる)。
- 編集の状態で時間を全く進めずに当てる案(適用の単位だけを走らせる)は、刻みの途中の状態を見せ・保存する仕組みが要る。今は 1 刻み進める形で
  一旦決め、気になれば T-0509 で替える(T-0497 の判断待ち ①)。

## 影響
- `--editor` の窓の試験で世界を動かすものは `--play` を付ける。保存点の VRAM は --editor の既定で 1 つ(約 33 MiB)増える。
- T-0411 の判断待ち(古い運びを刻み 0 から戻す)は、編集の状態では案 A のまま・プレイ中は 12 秒の範囲に置き換わった。

## 追記 1(2026-10-15・T-0509): 決定 §2 を置き換えた
- 編集の状態で置いたものは、1 刻み進めずに刻み E の適用の単位だけで当てる(カーソルは (E, 0) か (E, 1)。ADR-0236)。
  (E, 1) からプレイを押すとプレイを始めた刻みは E。やめると E へ戻してプレイ前に置いた分を当て直す。
