# ADR-0171 物理定数のうち、世界のデータにするもの・器に残すもの

- Status: Accepted(2026-10-13 ユーザー決定。D-480。ブランクの世界の重力は 0・上限 100 m/s² のまま)
- 日付: 2026-10-12
- 決めた人: ユーザー(Claude が提案した場合も、決めるのはユーザー)

## 背景
- ADR-0151 の 5 は「重力のように世界ごとに違ってよい値はパッケージの値に、気体定数 R のような換算の値を器に残すかは T-0372 で確かめる」とした。
- T-0372 で洗い出した物理定数(表はチケット T-0372): 重力 g(物理・気体の浮力・層の重さの圧力・重さの仕事の 4 か所に、別の単位で)、
  気体定数 R(気体・反応のベイク・実験室・転換の評価の 4 か所に、同じ整数 8314462618 で)、音速の基準(T-0400)、単位と刻み(units.hlsli)。

## 決定(案 A。仮)
1. **世界のデータにするもの = 遊びが変わる値**: 重力の強さ(今回通した)。続いて環境の値(音速の基準・基準の温度。T-0400)、
   将来の放射の強さ(太陽光。T-0028・T-0373)。値は世界のパッケージが渡し、エンジンは**単位・上限・換算**だけを持つ
   (`shaders/common/world_physics.hlsli`。重力は µm/s² の uint32、上限 100 m/s²)。CPU リファレンスと GPU は同じ換算の関数を通り、
   換算した値を係数・パラメータ(構造化バッファ)で GPU に渡す。シェーダーに世界の値の定数を書かない。
2. **器に残すもの = 単位の選び方から決まる換算の定数**: 気体定数 R(= k_B × N_A。SI の定義値)は `units.hlsli` の
   `GAS_CONSTANT_NANOJOULES_PER_MOLE_KELVIN` の 1 か所に置き、ほかはそこから読む(R ÷ V の Q32 は static_assert で R と結ぶ)。
   世界ごとには変えない。
3. 重力の向き(物理は -y・気体は -z)は器が決める。
4. 標準の値(9.80665 m/s²)は、標準パッケージ(T-0373)が渡すまで `world_physics.hlsli` の 1 か所に置く(仮の置き場所。ADR-0151 の 2 の例外として明記)。

## 検討した代案と、採らなかった理由
- **案 A(おすすめ・仮で実装)**: 上の通り。
  - プレイヤーと遊び: 重力の違う世界(月のような低重力で物が高く跳ぶ・重い気体が溜まりにくい・炎の上昇気流が弱い、強い重力で煙が地を這う)が作れる。
    R を変えた世界は作れないが、R を変えることは「温度とエネルギーの目盛りを変える」ことと同じで、プレイヤーが観察できる新しい法則は生まれない
    (反応の速さを変えたいなら反応則の活性化エネルギー、気体のふるまいなら比熱・モル質量という、パッケージが既に持つ値で表せる)。
  - 費用: 重力は構造化バッファの 8〜16 バイト。ルート定数は増えない。割り算の数も変わらない。
- **案 B: R も世界のデータにする**
  - プレイヤーと遊び: 案 A と見える違いは無い(上の理由)。パッケージの作者が R を書き間違えると、気体の圧力・反応の速さ・実験室の量の換算が
    同時にずれ、「嘘の物理」が混ざりやすくなる(D-428 に反する向き)。
  - 費用: R ÷ V の Q32・1 セルの物質量の上限(MAX_CELL_AMOUNT)・圧力の桁の約束(04 §2)が R の値に依存するので、上限を R から作り直す仕組みが要る。
    反応のベイク・転換の評価(magic_patch)にも R を渡す欄が要り、HW の Work Graph のルート署名(64/64 語)に余地が少ない。採らない。
- **案 C: 物理定数を全部エンジンの定数のまま(重力も)**
  - プレイヤーと遊び: 重力の違う世界が作れない。ブランクの世界(D-455)で「重力が無い」状態が作れない。D-454 に反する。採らない。

## 影響(何がしやすく/しにくくなるか)
- しやすくなる: 環境ミキサー(T-0373)で重力をボタンで足す・外す。無重力の実験室。T-0400 の環境の値も同じ形で足せる。
- しにくくなる: 重力の上限(100 m/s²)を超える世界は、気体の重さの力積の係数の桁の見直しが要る。
- 試験: 標準の重力ではビット一致(換算は今までの定数と同じ値になる)。別の重力の試験は T-0423。
- ADR-0151 の 5 は、この ADR が Accepted になったら「T-0372 の結論は ADR-0171」と追記する。
