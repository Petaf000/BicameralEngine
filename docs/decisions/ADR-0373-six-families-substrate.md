## 背景
- 前の土台(ADR-0326・20 の前の版)は「勢いを持つ流れ・広がる流れ・反応・押す」の 4 つの家族と共有の配管だった。
- 2026-10-19〜21 の設計で足した法則のうち、支えの法則(釣り合いを解く)・電位・磁場・陰の圧力(Q1)・放射(まっすぐ運ぶ)は、この 4 つのどれにも入らない。
  別々に作ると、前に土台を止めた原因(同じ仕組みを法則ごとに 4〜11 回書き直した。claude/25・20 §5)が戻る。
- 欄も大きく増えた(濡れ・電荷・電位・磁場・力とたわみ・割れの進み・2 つの帯・匂い・魔素)。全部のセルに全部の欄を持つと 20 km の世界は入らない(D-312)。
- 刻みの順(claude/28 §2.14)は電気・磁気・支え・放射・音の出来事・割れを含まず、粗くした時の振る舞い(N1)は力・電荷・磁場・放射を含まなかった。
- 経緯(1 行): 設計チャットで Claude が「土台の形はほぼ出そろった」と言い、ユーザーの「本当に?」で見直して穴 F1〜F9 を洗い出し、F1〜F8 を閉じた(F9 = 案 B は試作で閉じる)。

## 決定
### 1. 6 つの家族(D-540)
法則を数学の型で分ける: **運ぶ**(勢いが進む)・**広がる**(坂に沿ってにじむ)・**釣り合う**(領域全体の釣り合いを解く)・**まっすぐ運ぶ**(向きを持って進み遮られる)・**反応**(その場で変わる)・**押す**(蓄えで坂を上らせる)。
- 新しい法則は必ずどれかに入れる。家族ごとに、解き方・眠り方・粗くし方・細かさの約束・費用の読み方を 1 回だけ作る(20 §8.2)。
- 配管(登録・見立て・面の帳簿と当てる段・眠る/起こす・欄の持ち方・刻みの順)は全家族で共有。家族どうしの受け渡しは面の帳簿か刻みの順だけ(相手の欄を直接書かない)。
- どの家族にも入らない法則は、作業役が足さずに司令塔とユーザーへ上げる。
- 家族は「型」、解く部品は「道具」: 広がる家族の陰解法は釣り合う家族の多重格子の部品を呼ぶ。

### 2. 釣り合う家族(D-541)
- 世界の多重解像度の木をそのまま多重格子の段にする(今の熱の陰解法の段の作り = ADR-0019 の形を部品に上げる)。物の箱でも同じ。
- 決まった回数(V サイクルの回数は法則ごとに固定)・温めた始まり・整数・赤黒の平滑化で決定的。
- 保存は面の形で厳密(解けきらなくても帳簿は合う)。残差は計器へ。
- 割れる/曲がる/破れるは解の外で、反応の家族が物質の値の速さで起こす。釣り合いの家族は直線の式だけを持つ。
- 領域は変わった所から物理の長さ(法則ごとの式。状態から決まる)で閉じ、外は前の答えで固定する。
- 解けきらない場面は決まった回数(ユーザー「とりあえず (a) で見て、酷かったらどうにかする」)。釣り合いに着くまでの刻みの数と見た目を試作で記録して見せる。

### 3. 欄の持ち方(D-542)
- 真実(物質の量・エネルギー・勢い・電荷・割れの進み・ねばい物の変わった形)だけを、ある所にだけ持つ。導かれる値は起きている所で計算する。
- 眠った所の導かれる値は粗くして残す(使えなければ捨てる。研究 R-F1)。
- 登録の 1 行に「真実 / 導かれる値 / 温めた始まり」の印と、ある所にだけ持つ(疎な頁)を足す。頁があるかは結果に効かない(無い = 0 とビット一致)。

### 4. 刻みの順(D-543)
入力 → 物の物理 → 占める層と塞ぐ面 → 押す → 釣り合う(電位 → 磁場 → 支え)→ 運ぶ → まっすぐ運ぶ → 広がる → 反応 → 受け渡しと締め(20 §2.5)。

### 5. 粗さ(D-544・D-547・D-548)
- 粗さは局所の状態だけで、いつも同じ規則で選ぶ(N1)。予算を超えた時の最後の手段は「世界全体を一様にゆっくり」(結果を変えない。不具合として警告)。
- 粗くすること = 混ぜること: 真実は和、物質の値は混ざった所の値の決め方(S23)。家族ごとの別の規則を作らない。
- 縦にだけ粗い列(Q12)は特許を確かめてから Irving 2006 の形で。列にするかも局所の状態で選ぶ。
- 作り手が粗く書いた物は見分けられる別の種類(Q5)。同じ名前・見た目で振る舞いが違うのはベイクの誤り。
- 粗くしても同じ結果になるかは賭け 2 で測る。通らない所は粗くせず、費用か広さで払う。法則は変えない(claude/30 N8)。

### 6. 物の中(D-545)
地面の並びと物の並びのどちらにも骨格と流れる箱がある(C1。MPM は作らない)。物の箱で 6 つの家族を同じ関数で走らせ、世界とは家族ごとに対の面で受け渡す(ADR-0360 を全家族に広げる)。AVBD と支えの釣り合いの受け渡しは 20 §12.3。

### 7. GPU と連鎖(D-546)
GPU は Compute を既定、Work Graphs は測って速い所だけ(D-302 を置き換える)。連鎖は法則が持つ速さ(m/s)で刻みをまたいで伝わり、1 刻みの中で最後まで回さない。
法則の速さが 1 刻みに進める距離(Δx/Δt)を超える連鎖(岩の割れ・爆轟など)は、(a) 速さから決まる固定の小刻みで進める か (b) この宇宙の速さとして遅く定める のどちらか。**2026-10-21 ユーザー決定 D-612**: エンジンは両方できる形にする(速さは物質の値。Δx/Δt を超える値を書いたら速さから決まる固定の小刻みで進める)。既定は (b)。(a) を選んだ時の小刻みの費用は予算として前もって決める(負荷で遅れない。D-468)(claude/30 N8 の補い・20 §2.7。前は未決・Q141)。

### 温めた始まりをセーブに入れる(2026-10-21 Accepted・ユーザー決定 D-608。前は仮 D-549)
- 決まった回数で解くので、解き始め(前の刻みの答え・眠った所の粗い値)が答えを変える。真実だけからは作り直せないので、**解き始めに使う導かれる値もハッシュとセーブに入れる**(案 A)。
  案 B(真実だけ)は、読み込んだ直後の数刻みのたわみ・圧力が続けて遊んだ場合とビット単位で一致しない(D-465「再生できる」とぶつかる)。おすすめ A。取り消しやすい(登録の印 1 つ)。
- **決定(D-608)**: (A)。ただし重くなったら切れるもの: セーブの大きさ・費用を測り(T-0922)、重ければ (B) に切り替えてよい(`SF_WARM_START_IN_STATE` の 1 行。ADR-0399 §3)。

## 検討した代案と、採らなかった理由
- **法則ごとに解き方を作る**: 前に土台を止めた原因そのもの(4〜11 回の書き直し)。
- **釣り合いを決めた精度まで解く**(回数が場面で変わる): いつも正確だが、重い場面で回数が増えて予算を超えうる(D-468 とぶつかる)。ユーザーは決まった回数を選んだ。
- **釣り合い用に別の格子を作る**: 世界の木にもともと粗い段がある。別の格子は二重の持ち物と受け渡しを生む。
- **全部の欄を全部のセルに持つ**: 20 km の世界が入らない。眠った所の導かれる値を全部残す案も同じ理由で採らない。捨てる案は起きた時に橋が少したわんで戻るように見える恐れがあり、退く道にした。
- **予算を超えたら遠くを粗く計算する**(claude/29 Q9): 粗さが予算で変わると、同じ実験の答えが場面の重さで変わる(D-465)。N1 で置き換えた。
- **形の変わる物に MPM**: 縮む・反るまで出るが、別の書き方の家族が増え、整数で決定的にできるかが研究。C1 で採らない(骨格 → 粒と、くっつく粒で形を変える)。
- **できる限り Work Graphs**(D-302): 実測で伝導は Compute が少し速く(0.72 対 0.82 ns/セル)、対応する GPU も狭い。結果は同じなので費用だけで選ぶ。

## 影響(何がしやすく/しにくくなるか)
- しやすく: 新しい法則は「どの家族か」の 1 問で載る。眠り方・粗くし方・計器・CPU と GPU の 1 つの源が最初から付く。真実だけなのでセーブの差分(S36)も小さい。
- しやすく: 試作の列 1(C-0 釣り合う家族の共通部品・C-1 欄の持ち方)が、支え(R-B1)・案 B の陰の圧力(R1)・電位・磁場の全部の土台になる。
- しにくく: 決まった回数なので、大きな塊を動かした直後は釣り合いに着くまで数刻みかかる(見せて判断する)。解き始めが状態の一部になる(D-608 の節)。
- しにくく: 刻みの順が 10 段に増え、段ごとの読み書きの約束(前の段の結果だけ読む)を守る検査が要る。
- 未確認: 閉じた領域の境目のずれが溜まらないか・眠った所の粗い値から起きた時の動き(R-F1)・1 セルの大きさ(M-0)・縦にだけ粗い列の費用と特許。
- 試作の列への効き: C-0 は気体の陰の圧力の GPU 版(T-0842〜T-0845)を土台にするが、それは**ブランチ t-0845 にあり main に入っていない**(2026-10-21 の確かめ)。C-0 はその取り込みから始まる。
