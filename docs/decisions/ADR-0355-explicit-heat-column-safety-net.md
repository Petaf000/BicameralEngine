# ADR-0355 陽解法の安全網は「当てる段の上限の熱の列」(風上は自分の熱より多くの熱を持ち出さない)。0 K に着くのは受け入れる

- Status: Accepted(2026-10-19。D-524 でユーザーが「案 2 を 2 本試し、だめなら案 1 で閉じる」と決めた。案 2 は打ち切り条件に当たり、案 1 の形を決めた。
  CPU の箱の既定に入れた〔GasBox::limitMovedHeat = true。T-0787 の 3 チャット目〕。燃える木箱の試験で縮むのは、その場面が約 440 気圧の爆発で、
  列なしでは小刻みの終わりに熱が負のセルが出ていたため〔下の 4〕。余裕の形は変えない)
- 日付: 2026-10-19
- 決めた人: ユーザー(D-524)。式と余裕は Claude(T-0787)
- 置き換え: ADR-0346 の 3(D-508 の面の力積の上限は入れない)の続き。D-508 の「先端の頭打ち」は要らなくなった

## 背景
陽解法の気体の小刻みで、強い爆発(1 セルを 40 倍・2600 K)のとき熱が 0 以下のセルが出た(T-0691)。T-0787 の調べ(gas_reference_test の
--heat-probe・GasBox::heatProbe):
- 力積の側(力を当てた後に熱が負)は 1806 あったが、全部が小刻みの終わりまでに正に戻る(入ってくる塊の押し出す仕事が埋める)。
- 小刻みの終わりに負のまま残るのは**運ぶ側**: 風上が、押し出す仕事 n R T を小刻みの初めの温度で数えて、力の後の自分の熱より多くの熱を持ち出す
  (1059 + 力で一時負になったセルが負の熱を持ち出した 12)。

## 決定
1. **当てる段の上限に「熱の列」を足す**(設計 20 §2.4 ②「量・エネルギー〔押し出す仕事込み〕の列ごとの最小」):
   風上のセルごとに、出ていく面の「塊の熱のぶん」(= 塊のエネルギー − 化学 − 運動の分け前 = 熱の分け前 + 押し出す仕事。0 以下は 1)の和が
   「持ち出せる熱」(= 力の後の熱 − 余裕 6 mJ〔面ごとの丸め 1 mJ × 6 面〕)を超えたら、出ていく面の割合と成分を同じ倍率で縮める
   (TxMakeLimit・TxFaceScale・TxScaleAmount。入る側は縮めない)。物質の量の上限の後に掛ける。断熱のときだけ。
   式は gas_flow.hlsli の `GfMovedHeatPart`・`GfHeatRoom`(CPU と GPU で共有)。
2. **残す熱は余裕だけ**(1 小刻みに熱の一部を残す形は、5 倍・1500 K でも縮めて値を変えるので採らない。下の表)。
   熱は負にならないことを式の形で保証し、**0 K に着くことは受け入れる**(1 小刻みの強い膨張の離散の冷え過ぎ。熱は負でなく、次の刻みに入ってくる塊が戻す)。
3. **縮めた面の数**(GasBox::energyLimitedFaces)を気体の刻みの報告(ProbeGasStepReport::energyLimitedFaces)と開発の計器の警告(Sim の Warning)へ。
   D-508 の「先端の頭打ち(約 650 m/s)と頭打ちの回数」は、力積の側が一時だけと分かったので入れない。この数がその代わりの目安。

4. **燃える木箱の試験(probe_gas・gpu_probe_gas)は強い爆発として縮める**(T-0787 の 3 チャット目の測り): セルロース 50 mol が刻み 1 で
   約 250 mol・約 2600 K の湯気になり約 440 気圧。隣の空気のセルは力積で力の後の熱が約 −923 kJ になり、列が出ていく面を 0 に縮める
   (刻み 1 に 6000〜12000 面)。列なしでは小刻みの終わりに熱が負のセルが 1 小刻みに最大 209(最も負 −219 kJ)出ていた。
   列ありでも最大 24 セル・最も負 −9.6 J が残る(列は風上の自分の熱だけを見る十分条件。残りは T-0814)。
   GPU の区画に列が入るまで(T-0813)、gpu_probe_gas_test の CPU の比べの側だけ列を切る(ProbeGasOptions::limitMovedHeat = false。仮)。

## 試したこと(12³ の閉じた箱の 1 セル・陽解法・30 刻み)
| 形 | 5 倍 1500 K(縮めた面・最も冷たい・最速) | 40 倍 2600 K(縮めた面・最も冷たい) |
|---|---|---|
| 前(熱の列なし) | 0・283.5 K・4.58 m/s | 0・**0 mK**(小刻みの終わりに熱が負のセルあり) |
| **熱の列・余裕だけ(決定)** | 0・283.5 K・4.58 m/s(前とビット単位で同じ) | 7021・**0 mK**(熱が負のセル 0) |
| 熱の列・1/8 を残す | 42・282.3 K | 1291・202 K |
| 案 2a: 押し出す仕事を初めと終わりの平均の温度で | 0・**282.3 K・5.47 m/s** | 0・229.7 K(熱の列なしでも負のセル 12) |
| 案 2b: 押し出す仕事を終わりの温度で | 0・**281.4 K・5.46 m/s** | 0・231.4 K(同上) |

案 2(D-524 で先に試した。終わり = 出ていく側だけ引いた後の風上の温度。閉じた形で解いた: 平均は x = 2A ÷ (2A + W)、終わりは x = A ÷ (A + W)。
A = 熱 − 熱の分け前の和・W = 初めの温度の押し出す仕事の和)は 40 倍の 0 K を消すが、5 倍の値も変える(最も冷たいセル −1.2〜−2.1 K・最速 +19%)ので、
打ち切り条件(2 本で 0 K が消え、かつ 5 倍が変わらない形が無ければ案 1)に当たった。調べの口(GasHeatProbe::pushForm)は残してある。

## 検討した代案と、採らなかった理由
- 面の力積の上限(D-508 の初めの形・T-0722): 効きすぎる(衝撃波の管の速さが外れ、5 倍でも 132 面)。ADR-0346 の 3。
- 1 小刻みに残す熱を決める: 5 倍でも 1 小刻みに熱の 31/32 以上を持ち出すセルがある(刻みの終わりには戻る)ので、「強い時だけ効く」閾値を熱の割合で作れない。
- 案 2(押し出す仕事の温度): 上の表。物理としては終わりの温度の形が断熱膨張の厳密な解((1−F)^γ)に近いが、ふつうの強い流れの値を変える。
  0 K を嫌う場面が出たら、これを既定にする案として見直せる(ユーザーの判断)。

## 影響(作り手から見て)
- ふつうの煙・風・衝撃波・5 倍の爆発の値は変わらない(縮めない)。強い爆発(燃える木箱の試験・40 倍の試験)では縮めて値が変わる。
  強い爆発の中心では 1 刻みだけ 0 K のセルが出ることがある(熱は負にならない。保存はビット単位)。
- 「熱の列で縮めた」は警告として見える(どの刻みで強い膨張が起きたか)。
- GPU の段(箱と木)と CPU の木(gas_tree.cpp)に同じ列を入れるのは T-0813(この ADR の式を使う)。それまで GPU と CPU の箱は、熱の列が縮めた刻みだけ
  一致しない(ふつうの場面では縮めないので一致)。
