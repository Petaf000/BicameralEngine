# ADR-0067 世界に物を置く筆は「置くコマンド」1 つ(球・置き換えか足す・明示的な湧き出し)

- Status: Accepted(方向は D-449〔ユーザー決定: エディタで触って中身を決める・筆で木・岩・水・魔素などを置く〕と D-439〔実験室の「置く」は
  中身の置き換え〕。形は実装の細部で Claude が決めた。CLAUDE.md §5)
- 日付: 2026-10-10
- 決めた人: ユーザー(方向)・Claude(形)。T-0222

## 背景
- D-449: 反応表・魔素の値などは、エディタで触って決める。そのために、普通の世界に筆で物を置く道具が要る。
- 世界の状態は VRAM にあり CPU は書き換えない(D-107)。世界を変える操作はコマンド(sim/command.h)として GPU のキューと再生ファイルへ。
  再生で同じ結果になり、GPU と CPU リファレンスがビット一致すること(ADR-0008・CLAUDE.md §1-4)。
- 今の普通の世界は仮の世界(64³・0.5 m のセル・sim/probe_sim)。コマンドは 64 バイト(payload 48 バイト = 12 語)。
- 実験室(ADR-0037)の FILL は 1 セル・物質 3 つまで + 温度で置き換え。待ちの丸め(ADR-0018)の約束: セルを変えたブロックは
  「刻みの直前に変わった」にしてから評価する。

## 決定
1. **置くコマンド `PROBE_COMMAND_TYPE_PLACE`**(common/probe_place.hlsli): 中心のセル・半径(0〜8 セル。0 は 1 セル)・置き方
   (置き換え / 足す)・温度・物質 3 つまでと 1 セルあたりの量。1 回の筆の運び(クリック 1 回)= 1 コマンド。形は球
   (中心からの距離の 2 乗 ≤ 半径の 2 乗。格子の外は切る)。
2. **置き換え**は実験室の「置く」と同じ(D-439): セルの中身を材料にし、その温度のエネルギー(化学 + 熱容量 × 温度。mJ に切り上げ)にする。
   **足す**は、今の中身に材料を足し、材料がその温度で持ち込むエネルギーを足す(混ざった温度になる)。成分が入りきらない・量の上限
   (1 物質 2^36 µmol)を超えるセルは飛ばす(GPU と CPU が同じ関数 ProbePlaceCell)。
3. **保存則の外**(エディタの明示的な湧き出し。つつきと同じ扱い。D-206): 変わったエネルギーの和を刻みの湧き出しの欄に数える
   (元素は数えない。置いた分だけ増える・減る)。
4. **起こし方**: 球の範囲の箱が重なるブロック全部を「刻みの直前に変わった」にし、起こす刻みの印を今にする。一覧へ足すのは
   その後の WakeDueBlocks(1 ブロック 1 回)。前の刻みに一覧へ足したブロックと重なりうるので、活性の一覧の容量をブロックの数だけ増やした
   (1 + 2 × ブロックの数 + キューの容量)。
5. **適用は 1 スレッドで番号の順**(今の適用の単位のまま)。表の物質の数は適用の単位の引数(ルート定数の 3 語目)で渡す
   (表を刻みの途中で差し替えても、その刻みの表で検査する)。当てられない値(格子の外・半径・置き方・温度・表に無い物質・重なる物質・
   量 0・物質の数 0 か 4 以上)は GPU も CPU も何もしない。当たったら `PROBE_EVENT_PLACE_APPLIED`(場所 = 中心)を出す。

## 検討した代案と、採らなかった理由
- **セルごとに 1 コマンド(実験室の FILL を世界に)**: 半径 8 の球は約 2,100 セルで、キューの容量(1024)と 1 フレームの上限(256)を超える。
  再生ファイルも大きくなる。筆の運び 1 回 = 1 コマンドの方が、記録が「何をしたか」のまま読める。
- **形をコマンドに持たず、CPU が触るセルを列挙して送る**: 同じく大きい。形は整数の式で GPU と CPU が同じに決められる。
- **足すとき温度を変えない(今の温度のまま量だけ増やす)**: 熱容量が増えるのにエネルギーを足さないと温度が下がる。足すエネルギーを
  何かに決める必要があり、「材料がその温度で持ち込む」が物理として素直(冷たい水を足すと冷える)。
- **触ったブロックを適用の中で直接一覧へ足す(つつきと同じ)**: 1 コマンドで最大 125 ブロック・同じブロックを何度も足し、容量の見積もりが
  コマンドの数 × 125 になる。起こす刻みの印を今にすれば WakeDueBlocks が 1 回だけ足す(容量はブロックの数だけ増やせば足りる)。
- **球のほかに箱・円柱・面を塗る形**: 後のチケット(筆の UI の作り込み)。形の種類は語 [1] の空きビットで足せる。

## 影響(何がしやすく/しにくくなるか)
- しやすい: エディタで普通の世界に木・炭・空気などを置き、そのまま燃やして確かめられる。置いた操作は再生ファイルに残り、再生で同じ世界になる。
- しにくい: 適用は 1 スレッドなので、1 刻みにたくさんの大きな筆を当てると適用の単位が重くなる(半径 8 で約 2,100 セル。測っていない)。
  ドラッグで塗り続ける筆(1 フレームに何回も当てる)を作る時は、適用を種類ごとに分けるか測ってから決める。
- 連鎖のトレース(T-0087)は置くコマンドを根として記録しない(つつきだけ)。トレース中に置くと予想と食い違う(後で足す)。
- 魔素は今の試験の表に無い(T-0225)。表に物質が入れば、材料の一覧(sim::MakeLabMaterials)に足すだけで筆で置ける。
