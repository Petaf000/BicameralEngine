# ADR-0420 セルの面の開き具合を法則が直接読む欄(21 §2.7 の塞ぐ面・T-0937)

- Status: Proposed(形は Claude の仮。T-0937 の 1 チャット目。CPU だけ)
- 日付: 2026-10-22
- 決めた人: Claude(T-0937 の作業役)。前の決定: ユーザー D-615(真実はセルの固い物の量・溝に沿って流れる要望)・D-575・ADR-0384・ADR-0399(欄の種類)・ADR-0403(疎な頁)
- 設計書: docs/design/21-motion-case-b.md §2.7・docs/design/23-radiation.md §7・docs/design/20-transport-substrate.md §2.3・§10

## 背景
- R-T1(T-0879)は 10 cm の溝に水を流すのに、形の固い物の割合をセルの石の量に変えて、今の液体(面の開き = 両側のセルの空きの小さい方)に流した。
  0.5 m のセルより細い溝が 2 本並ぶと、どちらのセルも少し空いているので、間の固い地面を抜けて水が隣の溝へ漏れる(この試験で 0.5 m のセルで確かめた)。
- 21 §2.7 は「面を塞ぐ割合」を入力に持ち、表面の細かい形も同じ「面の開き具合」で法則に効かせると決めている。その欄と、運ぶ家族が読む口が無かった。

## 決定(仮)
1. **欄**: 面の塞ぐ割合 b(Q16)を登録した欄 1 つで持つ(名前 `face.blocked`。置き場 = 面〔+ 側の 3 面〕・U32・付く相なし・
   **導かれる値**〔`SfMakeDerivedDesc`。欄の持ち方 C-1 の型のまま〕)。無い頁は 0 = 塞がない。真実はセルの固い物の量と表面の形の差分(D-615)で、
   b はそこから作る(`sim/face_opening` の `DeriveFaceBlocked`。形の関数 `SdCellOpennessAt`)。導かれる値なのでハッシュ・保存点に入らず、
   読み込んだ後・形が変わった時(刻みの段 3「占める層と塞ぐ面」)に作り直す。
   - 「開き」でなく「塞ぐ割合」を持つのは、無い頁 = 0 = 今までどおり(疎な頁と、欄を登録しない世界と同じ意味になる)にするため。
2. **読む口**: `common/face_opening.hlsli` の `FoFaceOpen(両側のセルの空きの小さい方, b) = min(…, 1 − b)`。運ぶ家族は面を通る量に掛ける開きをこれで作る。
   今の使い手は多重解像度の 1 段の液体(`MultiresLiquid`。欄を名前で引き、あれば読む)。b = 0 なら今とビット単位で同じ(試験で確かめた)。
   - 掛けずに小さい方を取る: 形とセルの固い物の量は同じ固い物の 2 つの見え方なので、掛けると同じ固い物を 2 回数える。
3. **形からの作り方**: セル 1 つ(1 辺はレベルから)ごとに、中 16 × 16 点・+ x と + z の面の上 16 点ずつ(R-T1 と同じ数え方)。
   面の上の点の地面の高さは面の両側の高い方(面はどちらかの側の固い物が触れていれば塞がる)。上の面は「地面がセルの上に届かない点の割合」。
4. **粒が穴を通る口(S8)**: `FoGrainFaceOpen(面の開き, 穴の大きさ, 粒の大きさ, 比)`。粒 ÷ 穴 が 比 ÷ 100 より大きければ 0。穴 0・比 0 は制限しない。
   1 周目は口だけ(案 B の粒の流れが呼ぶのは 2 周目)。穴の大きさを欄に持つかは物の塞ぐ面と一緒に決める(T-0977)。

## 採らなかった案
- 開き(1 = 開いている)を欄に持つ: 無い頁 = 0 = 閉じた面になり、欄を登録した世界ではどこでも頁が要る(疎の意味が逆になる)。
- 開き = セルの空き × (1 − b): 同じ固い物を 2 回数え、溝のセルの面がセルの空きの 2 乗ほどまで狭くなる。
- 欄を真実にする: D-615 で真実はセルの固い物の量。形の差分(ある所にだけ)と量から作れるので導かれる値。

## 結果

  保存 0・2 回で同じ要約・保存点から戻して作り直すと同じ要約 / 0.5 m と 0.25 m で同じ向き。数値はチケット T-0937。
