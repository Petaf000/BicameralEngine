# ADR-0501 支えの法則: 違う大きさのセルの間の面の曲げも「対の平均」で粗いセルにつなぐ(ADR-0485 ④ の延ばし)

- Status: Proposed(Claude 案・T-1207。CPU。仮で既定)
- 日付: 2026-10-29
- 決めた人: Claude(wt4 の作業役)
- 関係: ADR-0485(対のずれ)・ADR-0491(固定した面の面の点の形)・ADR-0470・設計 22 §3.2・§3.5・T-1191・T-1206・T-1207

## 背景
片持ち梁 8 × 1 m の上の段だけを 0.25 m にした場面(違う大きさの上の面 = 移り目が梁の中立軸に沿う)で、移り目の上の面の縁の力が
全部 0.25 m の答え(0)と大きく違った: 根から 1 m 6.95 %・根の柱(固定した面の近く)10.08 %(縁の力の最大で割る。T-1206 の後の残り)。
③・②・③' でも 7〜16 % = ④ の対のずれ(一様な歪みの直し)の外。

## 根
**回りの勾配(曲率)を粗いセルが持てない。** 曲げの梁では回りが面に沿って変わる(上の面なら ∂角/∂x = 曲率 κ)。粗いセル C の上に並ぶ
細かいセル L・U の回りは C の回りから ±κ s/2 ずれる。違う大きさの面の曲げの項は面ごと ½ (b/3) p_k²(p_k = 2φ_k − φ_C = s (角_k − 角_C))なので、
L・U に逆向きの偽の回りの力が出る(縁の力で ±b κ s²)。全部細かい塊では面の両側のセルの回り(上下に並ぶセル)は同じなので 0。
浮動小数点の捨てる模型(作業場だけ。C++ の 6.95 % / 2.06 % / 10.08 % と全部の場面の値を 3 桁で再現)で確かめた。

仮説 2(曲率で L・U の面の点の縦の変位が C の剛体の面から κ s²/8 ずれる = 弦の差)は退けた: セルの値をセルの平均と読むと、
粗いセルの平均と細かい 2 つの平均の弦は放物線でも一致し(κ s²/6)、直しの項を足すと x の面の場面が 3〜20 % 悪くなった。

## 決定(案)
違う大きさの面の対(④ FacePair・β の分)は、**曲げも対の平均だけで C につなぐ**:
½ (b/3) p_L² + ½ (b/3) p_U² − ½ K_曲げ (p_L − p_U)²(K_曲げ = 直列の硬さ。等しければ b/6 → 対で ½ (2b/3) p̄²・p̄ = (p_L + p_U)/2)。
- ずれの −½ K (d_U − d_L)² と同じ形・同じ芯(対の中の形の違い = 粗いセルが表せない歪みは C に掛けない)。どの向きの面にも同じ式(x の面の対は上に並ぶ)。
- 系の全体は正(対の 2 つの曲げの項の和は平均の 2 乗)。面のブロックは対の面(L と U の面)に負の項として入れる(ずれの負の項と同じ所)。
- 面の縁の力の曲げは、負の項の力を曲げの項と同じ両端の勾配(C −1・F +2 の割合)で足して読む(面の点の回りの内挿は同じ形)。
- 比べ用に ④' 対のずれだけ(`MixedBeam::FacePairShear`。T-1191〜T-1206 の既定)を残す(前の値にビット一致)。違う大きさのセルが無い場面は今とビット一致。

## 根拠(T-1207・2026-10-29・wt4・release・CPU。support_mixed。縁の力の差 ÷ 全部 0.25 m の縁の力の最大。違う大きさの面 / 細かい面 / 固定した面の近く)
| 場面 | ④'(前) | ④(今) |
|---|---|---|
| 張り出しの根 1 m | 0 / 0 / 2.82 % | 0 / 0 / 2.82 % |
| 片持ち梁の根の半分 | 1.22 / 1.40 / 0 % | 0.76 / 1.62 / 0 % |
| 片持ち梁の先の半分 | 1.14 / 1.81 / 0 % | 0.92 / 2.07 / 0 % |
| 片持ち梁の真ん中 4 m | 2.06 / 2.86 / 0 % | 1.96 / 3.27 / 0 % |
| **片持ち梁の上の段だけ** | **6.95** / 2.06 / **10.08 %** | **1.32** / 0.29 / **4.87 %** |
| 両端を固定した梁の真ん中 3 m | 1.82 / 3.91 / 0 % | 0.63 / 4.47 / 0 % |
| 洞窟の天井 | 1.67 / 2.87 / 0 % | 0.96 / 3.42 / 0 % |
- たわみの比(全部 0.25 m との比)は上の段だけ 0.998 → 1.000・ほかは同じ(4 桁)。
- 模型で厚い梁 8 × 2 m(0.5 m のセル 4 段)も: 上半分・上 1 段・真ん中 2 段・区画で違う大きさの面 3.3〜3.9 % → 0.7〜1.5 %・細かい面 1.2〜2.5 % → 0.3〜1.9 %。
  固定した面の近く 5.4〜6.1 % → 2.4〜3.6 %(根の柱だけを細かく: 3.84 → 4.43 %)。
- 細かい面が少し上がる場面がある(x の面の対で 0.2〜0.6 点。全部 5 % の中)。x の面の対では対の回りの差(∂角/∂y)はずれの歪みの変わり方から来る分があり、
  粗いセルが表せない点は同じなので同じ式にした(向きで式を分けない)。

## 残り・作り手から見た違い
- 作り手から見た違い: 書く値は無い。梁の厚さの途中(特に中立軸)で細かさが変わる所の縁の力の偽の曲げが 7〜10 % → 1〜5 % になり、移り目で割れの判定が早まる・遅れる量が減る。
- 残りの 4.87 %(上の段だけの根の柱)は、固定した面のすぐ横で縦の変位が強く曲がる所(壁から 0.25 m で −21・0.75 m で −95 の形)の縦の伸び(縁の力の平均)と、
  中立軸を挟んだ回りの放物線(ずれの歪みの分布)を粗いセルの片側の差で読む分(2 次の離散化の誤差)。直すには粗いセルの側の精度を上げる(研究)か、移り目を固定した面から離す(細かさの規則)。
- 3 次元(T-0944)の対は 2 × 2 の 4 つ。曲げ(回り 3 成分)の差も対の平均で同じ芯に延ばせる見込み(未確認)。

## 追記(2026-10-29・T-1261・wt3)
- 違う大きさの面の対の負の項に粗いセルの材料の硬さを直列で残す形(T-1261 の比べ用 `MixedPairMaterial`)では、上の段だけの根の柱は 4.87 → 4.86 % で動かない。
  残りの 4.87 % は対の負の項(T-1260 の根)とは別の根(この ADR の見立て = 固定した面のすぐ横の 2 次の離散化)。
