# ADR-0331 世界の帳簿を 1 つの型にする(理由 × 向き × レベル × 量。保存の検査は「Σ 保存量 − 帳簿」の 1 関数)

- Status: Proposed(2026-10-17。T-0712。土台の決定〔2026-10-17 ユーザー〕の §2.4 ⑤ の作り。細部は仮〔ユーザー未確認〕で進めた)
- 日付: 2026-10-17
- 決めた人: Claude(T-0712 の作業役)
- 関係: 運ぶ計算の共通の土台(決定 4: MR の上だけ)・ADR-0015 / ADR-0016(MR の帳簿)・T-0104(畳んだ余り)・T-0711(状態の登録)

## 背景
- 帳簿と保存の検査が仕組みごとにばらばら(型 7・和 9・GPU 5。survey-engine §3)。MR の帳簿は「粗くした端数」専用で、外との出入り(改造・物理の熱・世界の端…)の列が無く、
  実験室の箱の試験は「コマンドの無い刻みだけ合計が同じ」としか確かめられなかった。

## 決定(仮)
1. **型**: shaders/common/world_ledger.hlsli(CPU と GPU が同じ番地・同じ繰り上げ)。番地 = [欄 = 理由 × 2 + 向き][レベル − MR_LEDGER_LEVEL_MIN][列]。
   - 理由 8: 粗くした端数・改造・物理の熱・世界の端・壁の力積・重さの仕事・速さの上限・静止の丸め(足すのは定数 1 つと WL_REASON_COUNT)。
   - 向き 2: 出(セルから減った)・入(セルに増えた)。**符号を持たず、両方を足すだけの数にする**(GPU は 64bit の atomic の足し算だけで順によらない。
     符号つきを段の繰り上げで持つと借りが粗い段へ無限に続く)。
   - 列(量): 0 = エネルギー、1 + 物質 ID(元素は組成から数える)、その後ろに状態の登録(T-0711)が「保存量」とした欄(運動量 ×3・位置/運動のエネルギー)。
     列の数は作る時 1 + 物質の数で、RegisterNestField が保存量の欄の値の数だけ足す。欄の列 = NestFieldLedgerBase + NestConservedIndex + 値の番号(T-0762)。
   - 値はそのレベルの単位 × 2^-64(MR の端数と同じ)。桁あふれは 1 段粗い段の 2^61 へ。丸ごとの量 u は 21 段粗い段に 2u・22 段粗い段に最上位の bit × 2^61。
     このため段の下限を -16 → -24(レベル 0 の改造が帳簿に入る)。
   - 欄 0(粗くした端数・出)は前の MR の帳簿と同じ番地なので、GPU の畳む・粗くする段はそのまま。
2. **検査の 1 関数**: ComputeConservedTotals = Σ 本物の葉のセル(元素・エネルギー・登録した保存量の欄〔ConservedTotals::fields。T-0762〕)− Σ 帳簿(入 − 出)。外との出入りを全部載せれば、刻んでも改造しても変わらない。
3. **改造の載せ方**: 当てたセルの「前の中身を全部 出」+「後の中身を全部 入」(差を取らない。順・物質の並びによらず、CPU と GPU で同じ。負のエネルギーは逆の向き)。
4. **大きさ**: 欄はいつも 16 本(使わない理由も 0 で持つ)〔**注 2026-10-18: ADR-0335〔T-0770・T-0769〕で理由を 3 つ足し WL_REASON_COUNT = 11 になったので、欄は 22 本。帳簿の語の数は 1.375 倍**〕。語の数 = 16 × 88 × 列。実験室の箱(列 20 程度)で約 230 KB。読み戻し・ハッシュの費用は
   未計測(多ければ「登録した理由の欄だけ持つ」に変える。番地の関数 1 つで済む)。
5. **表の差し替え(物質の付け替え)では帳簿を付け替えない**(今の欄 0 と同じ)。表を替えたら保存の基準を取り直す(元素の定義が変わるので比べられない)。
   名前で付け替えるのは段 8(表の差し替えが登録を回る)。

## 代案
- 符号つき 128bit を欄ごとに 1 つ(段なし): 最も細かいレベルが動くので単位が決まらない。GPU の atomic にならない。
- 理由ごとに別の配列: 「1 型」にならず、ハッシュ・保存点・写しが欄の数だけ増える。

## 結果
- 実験室の箱の試験が「置く・温度を決める・細かくする・燃やすを通して 保存量 − 帳簿 が刻み 0 と同じ」を確かめる(lab_box_test)。
- 今の MR の保存の試験(multires_*・lab_box)は、改造の無い場面では前と同じ値で通る(欄 0 のみ)。

- **2026-10-26 本体の棚卸し(QUESTIONS Q115)**: 世界の帳簿 1 型の仮 3 つ → 閉じた(D-539)。
