# ADR-0345 気体を当てる段へ載せ、帳簿を理由ごとに世界の帳簿へ移し、係数をセルのレベルの関数にする

- Status: Proposed(2026-10-18。T-0763・T-0765。細部は仮〔ユーザー未確認〕で進めた)
- 日付: 2026-10-18
- 決めた人: Claude(wt4 の作業役)
- 関係: ADR-0326(運ぶ計算の共通の土台)・ADR-0334(当てる段)・ADR-0335(包み・液体の帳簿)・ADR-0331(世界の帳簿の 1 型)・ADR-0332(粘りと静止の丸め)・
  T-0720(MR の 1 段の気体)・T-0762(帳簿の書き方の約束)・設計 20 §2.3〜§2.4・§3

## 背景
- T-0720 の MR の 1 段の気体は、仮の世界(区画 = 世界いっぱい)と同じ気体の箱の小刻み(gas_reference の Substep)を面の一覧で回す。
  上限(出ていく側の割合の換算・成分ごとの中身)と移す(Transfer)は小刻みの中に自前で持ち、当てる段(T-0714・T-0770)を通っていなかった。
- 帳簿のエネルギーと運動量は世界の欄 `gas.ledger_energy`・`gas.ledger_momentum` に仮置きで、理由の区別が無く、ComputeConservedTotals で気体の欄の列が合わなかった。
- 係数(0.125 m³・Δx = 0.5 m の centralFlow・pressureFlow・pressureImpulse・層の重さ・重さの仕事)と粘り・音速の上限はレベル 0 の数で、根のレベル 0 の世界しか作れなかった。

## 決定(仮)
1. **気体の小刻みの上限と当てるを当てる段に**(箱・仮の世界・MR が使う 1 つの CPU の小刻み。T-0765)。
   - 出る側の倍率 = `TxMakeLimit(1〔Q32〕, 換算した出ていく割合の合計, TX_ROOM_UNLIMITED, 0)`、面の割合は `TxLimitAmount`。
     成分ごとの上限は列ごとの倍率 `TxLimitColumn(TxMakeLimit(中身, 出る合計, 無限, 0), TxNoLimit(), 量)`(transport_apply.hlsli に足した列の版)。
   - 移す塊は包み `TxPacket`(成分の物質量・引く側のエネルギー・運ぶ欄 0〜2 = 運動量)を `TxApplyPacket` で当てる。箱の世界 `GasApplyWorld` が
     セル(次の値)と開いた境界の外(帳簿の「世界の端」)へ書く。**重さの仕事は気体の種類の当て方**(`AddGravityWork`: 下流で引いて帳簿の「重さの仕事」へ。
     位置のエネルギーを数えない気体の模型なので、包みの列にはしない)。包みの物質の数(8)を超える成分は包みを分ける(箱は物質の数に上限なし。D-401)。
   - **入る側は縮めない**(気体は圧縮できる = 器で切らない。液体と同じ TX_ROOM_UNLIMITED)。式はどれも前と同じ切り捨て 1 回
     (GfLimitFraction・GfLimitMovedAmount と同じ数)なので、**仮の世界・GPU の段・箱の試験とビット単位で同じ**(基準の取り直しは要らない。D-487 ③)。
2. **帳簿を理由ごとに**(T-0763)。`GasLedger`・`GasCellsLedger` に内訳(和 = 前の合計)を持ち、MR は世界の帳簿の列へ載せる(世界の欄 `gas.ledger_*` は消した):
   - 物質の列 = 世界の端。
   - エネルギーの列 = 世界の端(開いた境界を出入りした塊)・重さの仕事。
   - 運動のエネルギーの欄(gas.kinetic_energy)から熱になった分(刻みの初めの欄の和 − 終わりの和。衝撃・混ざり・粘り・欄が物質に付く・静止の丸め)は
     欄の列の出 + エネルギーの列の入(静止の丸めの分は「静止の丸め」、残りは「物理の熱」。液体の ADR-0335 4 と同じ形)。
   - 運動量の列 = 世界の端(出入りした塊・外の大気の圧力の力積)・壁の力積(壁・一部だけ開いた面の塞いだ物・気体の無い側)・重さの仕事(重さの力積)・
     欄が物質に付く(段の外で気体の質量が減った・無くなった分と、段の中で気体が残らなかったセルの運動量)・静止の丸め。正 → 入。
   - これで ComputeConservedTotals(Σ 保存量 − 帳簿)が気体の刻みで列ごとに一定(閉じた端・開いた端・燃える木箱・静止の丸めの全部の場面で毎刻み)。
3. **係数をセルのレベルの関数に**(`GasConfig::cellLevel`。T-0765・設計 20 §3)。量・エネルギー・運動量はレベルの単位(8^-k = 0.125 m³ あたり)なので
   圧力・密度・α・物質の粘りの密度の式はレベル 0 のまま。面の式(中心の流れ・圧力の拡散・面の力積)は × 2^k、層の重さの圧力・重さの仕事は × 2^-k
   (細かいレベルは切り捨て)、重さの力積はそのまま、粘りの面の係数 κ = ν Δt ÷ Δx² は × 4^k(gas_flow.hlsli の式の引数は変えず、ν を 4^k 倍して渡す)、
   音速の上限は × 2^-k、基準の大気の層の厚さは 0.5 m × 2^-k。
   **小刻みは substeps × 2^σ、σ = max(0, k)**(波の型 e = 1。細かいレベルでも音の数 ν をレベル 0 と同じに保つ → 係数はレベル 0 とビット単位で同じ数)。
   MR の気体は根のレベル −8〜8 を受ける(前は 0 だけ)。
4. **静止の丸めの置き場 = 当てる段と粘りの後・書き戻しの前**(`RestGasCells`。前は書き戻しの中)。箱のエネルギーは全エネルギーなので運動量を 0 にすれば
   運動エネルギーのぶんはそのままセルの熱(値は前とビット単位で同じ)。順は「小刻み(1 流す → 2 上限 → 3 当てる)× 2^σ → 粘り → 静止の丸め → 書き戻し・帳簿」。
   液体(T-0777)も同じ置き場(当てる段の後の仕上げ)にそろえる。式は common/rest_rounding.hlsli の RrShouldRest の 1 つ。

## 作り手から見た違い
- 今の場面(レベル 0)は値がビット単位で同じ(仮の世界・GPU の段と同じ)。
- 根のレベルが 0 でない世界(0.25 m・1 m のセル)でも気体が流れ、レベル 0 と同じ物理(音の速さ・浮力)になる(試験: 音の波の先の位置・熱い泡の昇り方)。
- 帳簿を読む道具(計器・保存の検査)は、気体の出入りを「世界の端・壁・重さ・欄が物質に付く・静止の丸め・物理の熱」で分けて見られる。

## 代案
- 重さの仕事を包みの運ぶ欄(carried[3])にして AddPacket の中で引く: 包みの意味(上流 → 下流へ同じものが動く)が崩れる。種類の当て方として分けた。
- 粗いレベル(k < 0)の小刻みも減らす(σ < 0。substeps ÷ 2^|k|): 速いが小刻みの数が割り切れない時の決まりが要る。今は粗いレベルは同じ小刻み(ν が小さく安定)。
  多重レベルの気体(粗い側の受け直し)で小刻みを入れ子にする時に決める(判断待ち 1)。
- 層の重さ・重さの仕事を係数ではなく割る数で 2^-k(gas_tree の MakeLevelReference の形): gas_flow.hlsli の式(GPU と共有)を変えることになる。係数を縮めた。

## 判断待ち(仮で進めた。取り消しやすい)
1. **粗い世界の小刻みの数**: 仮 = 粗いレベル(1 m・2 m のセル)もレベル 0 と同じ小刻み 24。作り手から見た違い: 粗い世界の気体の費用が小刻みの分だけ高い
   (結果は同じ物理)。案 B = 粗いほど半分(1 m で 12)。おすすめ: 多重レベルの気体で入れ子の小刻みを決める時まで仮のまま。

- **2026-10-26 本体の棚卸し(QUESTIONS Q126)**: 粗い世界の気体の小刻みの数 → もう要らない(D-554・D-544・D-600)。
