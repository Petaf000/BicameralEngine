# ADR-0151 エンジンと中身の境界: エンジンは仕組みと器だけを持ち、名前と値はすべてパッケージに置く

- Status: Accepted(方向はユーザー決定 D-454〜D-457。物理定数をデータにする範囲は T-0372 で詰めて追記する)
- 日付: 2026-10-12
- 決めた人: ユーザー(D-454〜D-457)・Claude(境界の書き分け。CLAUDE.md §5)

## 背景
- 元素・物質・反応は Luau のパッケージで書き、整数の表にベイクして GPU へ送る形になっている(13 §1・§2.2・ADR-0031)。
  一方で、今のエンジンには中身の値が C++・HLSL の定数として埋まっている所が残っている: 試験の世界(木箱の世界)の組み立て・
  空気の成分の既定・気体の音速の基準・実験室と筆の材料の既定・気体定数 R(gas_internal.h・reaction_table.cpp・lab_box.cpp・
  magic_patch.hlsli に別々に)・重力(gas_internal.h・gas_cell.hlsli・physics_step.hlsli の PX_GRAVITY)など。
- ユーザーは「エンジンは中身を持たない」「ブランクの世界が既定で本当に空」「サンプルの世界は別パッケージ」「環境ミキサーで標準パッケージを
  ボタンで足す」と決めた(D-454〜D-457)。これを実装するために、どこまでがエンジンでどこからがパッケージかを決めておく。

## 決定
1. **エンジン(C++・HLSL)が持つもの = 仕組みと器**: 表を読む・型検査・ベイク・GPU の段・保存則の検査・記録と再生・エディタの UI。
   器の決まり = 単位と整数の表し方(µmol・mJ・mK・8^-k の単位〔17 §1〕)・上限(1 セルの種の数・頁の大きさなど)・決定性の規則(04)。
2. **パッケージ(Luau)が持つもの = 名前と値**: 元素・物質・反応則・材料・環境(大気の成分・重力・周囲の温度・太陽光)・試験の世界の組み立て。
   エンジンのソースに中身の名前(「空気」「木」など)や、現実の物性の値を新しく書かない。
3. **ブランクの世界**: パッケージを 1 つも足さない世界は、表が空・環境の値が「無い」状態で、刻みは何も変えない(保存則の検査は自明に通る)。
   表が空でもベイク・GPU の段・記録が壊れないことを試験で確かめる(T-0371)。
4. **標準パッケージとサンプルの世界**: 現実の元素・物理定数・反応と物質・地球の環境は、独立に足せる標準パッケージとしてリポジトリに置く
   (エンジン本体のビルドには入れない)。サンプルの世界はそれらと試験の地形・物を全部入りにした別パッケージ。今の C++ の既定はここへ移す(T-0371)。
   試験はどのパッケージを読むかを明示する。
5. **物理定数(T-0372 で詰める)**: 重力のように「世界ごとに違ってよい値」はパッケージの値にし、ベイクで整数の表(ルート定数か表の語)へ入れる。
   気体定数 R のように単位の選び方から決まる換算の値をエンジンの器に残すか、値として世界ごとに持つかは、整数の計算(定数が掛け算の
   シフト・割り算の除数に入っている所)と GPU の費用を確かめてから決める(研究の要素あり。打ち切り条件は T-0372 に書く)。
   それまでは今の定数のまま、置き場所(gas_internal.h など)を 1 か所に寄せる準備だけしてよい。

## 捨てた案
- 「現実の化学をエンジンの既定として持ち、パッケージは上書きだけ」 — D-454・D-455(ブランクが本当に空)に反する。
- 「サンプルの世界をエンジンのビルドに同梱」 — D-456 に反する(UE のサンプルマップのように別に配る)。

## 影響
- T-0371(サンプルの世界をパッケージへ・ブランクから起動するのを既定に)・T-0372(物理定数を世界のデータに)・T-0373(環境ミキサーの中身)。
- 今の試験の多くはサンプルの世界を前提にしているので、T-0371 で「パッケージを明示して読む」形に直す。値が同じならハッシュは変わらないことを確かめる。
- 設計: 13 §2.6・14 §2「環境ミキサー」。

## 追記 1(2026-10-12・T-0371): ブランクの世界の起動と、世界の種類の選び方
- 起動の世界は `--world blank|sample`(既定 blank。**今は仮で sample**: GPU のブランクの刻みが止まる疑いを T-0371 の続きで直すまで)。ブランクの世界 = セルは全部空・物理の物なし・表はパッケージ無しなら空の表
  (物質は使わない 0 番だけ・規則 0。版と中身は空の合わせた表のもの)。`--packages` を渡したブランクの世界は、ゲーム本体なしで全部を Mod として読む。
- サンプルの世界は、今は C++ の組み立て(木箱・空気・積み木)+ ゲーム本体のパッケージ combustion_test。組み立てをパッケージへ移すのは T-0398〜T-0400。
- 再生ファイルの「世界の種類」(ヘッダの world の欄。既にあった)に Blank = 2 を足し、今までの Probe = 1 をサンプルの世界と読む(形式の版は変えない。
  古いファイルはサンプルの世界として今まで通り再生できる)。再生は引数の --world でなくファイルの世界で起動する。
- 空の表でも GPU の段が壊れないよう、表のバッファは空の列を 0 の要素 1 つ分で作る(数はルート定数で渡すので読まれない)。
- 試験は使う世界を明示する(窓の試験は `--world sample`)。ブランクの世界で何も起きないことは blank_world・gpu_probe_blank・window_blank で確かめる。
