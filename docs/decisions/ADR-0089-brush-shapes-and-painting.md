# ADR-0089 筆の形(直方体・円柱)・ドラッグで塗る・材料を全物質から組む(置くコマンドは 1 つのまま)

- Status: Accepted(方向は D-449〔エディタで触って中身を決める・筆で物を置く〕・D-439・ADR-0067。形・間隔・上限・元に戻すの道は
  実装の細部として Claude が決めた。CLAUDE.md §5)
- 日付: 2026-10-11
- 決めた人: Claude(T-0245)

## 背景
- T-0222(ADR-0067)の筆は、クリック 1 回 = 置くコマンド 1 つ(球)。材料はひな形(空気・木・木炭・二酸化炭素・窒素・魔素〔試験〕)だけ。
- 筆で地形や壁を作る・燃料を撒くには、ドラッグで塗る・箱や柱の形・好きな物質を混ぜた材料が要る(ROADMAP T-0245)。
- 置く操作はどれもコマンドとして記録され、再生で同じ結果になり、GPU と CPU リファレンスがビット一致すること(ADR-0008)。
- 置くコマンドの payload は 12 語で埋まっている(中心・形・温度 + 物質 3 つ × 3 語)。空いているのは語 [0] と [1] の上の 8 ビットだけ。
- 仮の世界の GPU のキューは 1024、1 フレームに足せるのは 256。適用は 1 スレッドで、1 コマンドの上限は 17³ セル(ADR-0067)。

## 決定
1. **形は同じ置くコマンド `PROBE_COMMAND_TYPE_PLACE` の空きビットに入れる**(common/probe_place.hlsli):
   語 [1] の上の 8 ビット = 形(0 = 球・1 = 直方体・2 = 円柱)、語 [0] の上の 8 ビット = 大きさ 2・3(4 ビットずつ)。
   直方体は x・y・z の半幅(0〜8)、円柱は半径・軸の向きの半幅・軸(0 = x・1 = y〔縦〕・2 = z)。範囲は形を囲む箱
   (ProbePlace の extentX・Y・Z)で、GPU の ApplyPlace と CPU リファレンスが同じ箱を同じ順に回し、同じ ProbePlaceCovers で選ぶ。
   触ったブロックも形を囲む箱で起こす(ADR-0067 §4 と同じ)。1 コマンドの上限は 17³ セルのまま(直方体の最大)。
   **T-0222 の記録はそのまま読める**: 形の欄は 0(= 球)で、語 [0] の上の 8 ビットは 0 だった(0 でなければ当てない値だった。
   MakePlaceCommand の「格子の外」の印 0xFF000000 は今も当てない値)。種類の番号は替えない。
2. **ドラッグで塗る = 筆の運びを置くコマンドの列にする**(editor/brush_stroke。CPU の Controller。再生の時は動かない):
   押したセルに 1 つ、押したまま動いた道を「いちばん大きく動く軸」で間隔ごとに区切って 1 つずつ。
   間隔は **足す = 2 × 半幅 + 1**(形を囲む箱がその軸で重ならない = 同じセルに 2 度足さない)・**置き換え = max(1, 半幅)**
   (同じ材料で置き換え直すだけなので重なってよく、隙間が出ない)。**1 フレームに 8 個まで**・**GPU のキューとフレームのループで
   待っているコマンドが 64 個以上なら置かない**(止めている間にドラッグしても 1 刻みに溜まるのは 64 個程度。実験室の 1 刻み 63 個と同じ桁)。
   置ききれない分は目標のセルを覚えておき、次のフレームに続きから置く(離した後も目標まで置いて終わる)。
3. **材料は表の全物質から 3 つまで組む**(editor/material_rows。実験室〔T-0220〕と同じ行・同じ換算〔mol・g・kPa → 整数の µmol〕を
   共通にした)。ひな形は読み込んで直せる。表が替わったら行の物質を名前で付け替える(T-0242)。量の % は行で決めるので無くした。
4. **元に戻すは「保存点への巻き戻し + 取り消した運びを除いた再生」にする**(14 §1「元に戻す・やり直しは CPU の文書の上で行い、
   GPU の世界は文書と『ここからの再生』で作り直す」の通り。実装は T-0278)。

## 検討した代案と、採らなかった理由
- **形ごとに新しい種類の番号(PLACE_BOX など)**: 適用の単位と CPU の分岐が増える。空きビットで足りて、古い記録の意味も変わらない。
- **直方体を角 2 つで持つ(実験室の範囲のコマンドと同じ)**: 中心 + 半幅の方が球・円柱と同じ形の欄で書け、ドラッグの間隔も半幅から決まる。
  中心からの半幅なので幅は奇数のセルだけ(偶数の幅は 2 つ置く)。
- **ドラッグをセルの集まり 1 つのコマンドにする(通ったセルの印の列)**: payload に入らない。1 筆 = 1 コマンドの列なら、記録も
  「何をしたか」のまま読め、再生・巻き戻し・GPU と CPU の一致は今の道のまま。
- **足すで重なりを許す(間隔 = 半幅)**: 重なったセルだけ 2 倍足され、塗り斑ができる(量を決める実験に使えない)。
- **元に戻すを「逆のコマンド」にする**: 置く前のセルの中身は GPU にしか無く(D-107)、最大 17³ セルを CPU は知らない。GPU に置く前の
  中身を残すバッファとそれを戻すコマンドを作ることはできるが、戻すまでに進んだ反応(燃え広がった先)は戻らず「取り消し」にならない。
  巻き戻し + 再生なら、その運びが無かった世界そのものになる(決定性があるので正確)。

## 影響(何がしやすく/しにくくなるか)
- しやすい: ドラッグで壁・燃料の帯・魔素の筋を塗れる。好きな物質を混ぜた材料を置ける(実験室と同じ組み方)。記録・再生・
  GPU と CPU の一致はコマンドの列のまま(gpu_probe_place に形とドラッグの場面、window_place に `--auto-place` のドラッグ)。
- しにくい: 1 フレーム 8 個 × 最大 17³ セル(約 3.9 万セル)を 1 スレッドで当てる重さは測っていない(T-0280)。
  → 2026-10-11 T-0280: 測ると 8 個で 177 ms・64 個で 1.3 s だったので、ADR-0125 で 1 グループに分けた(2.0 ms・15 ms)。止めている間に塗ると
  1 刻みに約 64 個が溜まる(再び進めた最初の刻みが重い)。球や円柱の足すドラッグは、間隔を囲む箱で決めるので角に隙間が出る。
  面に沿って塗る(地面の表面だけ)は無い(T-0280)。カーソルの下の筆の大きさの表示は無い(T-0279)。

## 追記(2026-10-11・T-0332): 面に沿って置く・塗る
- **決定**: 筆の当て方に「面に沿って」を足す。カーソルの光線が最初に当たる「物」(物質量の合計がしきい値以上のセル)の手前の空いたセルを中心にする。
  物かどうかは GPU が抽出の後ろで作る印(64³ ビット)を CPU へ読み戻して CPU で光線を通す(View。シミュに入れない。置く位置だけがコマンドとして記録される)。
  しきい値は仮 20 mol(表に相が無いため物質量の濃さで見分ける)。ドラッグの間は押した時の印で塗る。
- **代案**: (a) GPU で光線を通して当たったセルを返す — 画素ごとに 1 フレーム遅れて返り、ドラッグの通ったセルの列を GPU に渡す道が要る。印の方が
  カーソルの表示・ドラッグ・自動の確認を CPU の同じ関数で書ける。(b) 抽出(描画用)を読み戻す — 見る物質 3 つの量しか無く「空気でない」が分からない。
  (c) 物の手前でなく物のセルそのものを中心にする — 置き換えだと面を削る形になる(塗るより彫る)。手前なら置き換えでも面の上に足される。
- **影響**: 断面を動かさずに 3D の物の上に燃料・苔・魔素を塗れる。気体の材料(1 気圧の窒素・二酸化炭素)は面にならない。読み戻しは 1 フレーム 32 KiB と
  1 回の Dispatch(面に沿っての筆を持つ間だけ)。印は数フレーム前の世界なので、速く動く物の面は少しずれる。
