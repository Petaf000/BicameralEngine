## 背景
CPU の nest_detail::GrowGrainLayers は刻む前のセル(上限の無い形)と比べて増えた粒を層に足す。GPU は刻む前のセルを u5 に写して
刻みの後に比べる(T-1323)が、溢れを使う世界ではインラインに無い成分の刻む前の量が要る。刻みの段は面を入れ替えるが、同じ刻みの中で
同じ頁を 2 回書く段(WideDeferred の ②・WideRetry・WideBig)があるので、刻みの後の「もう片方の面」は刻む前の溢れとは限らない。

## 決定
1. 刻む前の写し(u5)を溢れの変種では生のバッファにし、セル(u1 と同じ並び)の後ろに溢れの領域(u6 の g_overflowBase から
   MrWideAreaWords 語)を同じ並びのまま写す。写しの溢れは今の溢れと同じ道(見出しの面 → 塊の表 → 塊)で、語の番地を写しへ
   ずらして読む。見出し・置き場の番地は塊の数だけで決まる。新しいバッファの口は足さない(ルート署名 64/64 語のまま)。
2. 写す段は枠の後ろのグループ(64 × 16 語ずつ)。写しの溢れの始まり・語の数は外の定数 g_external2・g_external3(層の段は欄の区画を読まない)。
   費用は要る世界(層を使う・粒を生む表・溢れを使う)だけで、刻みごとに溢れの領域の大きさ(既定 170 塊で約 0.7 MiB)。
3. 比べる段は粒が増えたか・生まれた粒を足した層を、インライン + 溢れの成分ごとに求め、0 でない層を成分の順に 8 組へ前から詰める
   (層は物質で結ぶ。CPU の像〔MakeGpuLayerImage〕と同じ詰め方)。粒の増えないセルは溢れの成分の量まで min。
4. 0 でない層を持つ物質が 1 セルで 9 種以上になる時は、断って数え(層の足りない数)、そのセルは舞う粒のまま(仮【エンジン】。D-689 と同じ形)。

## 退けた案
- 写さずに頁のもう片方の面を読む: 上の 2 回書く段で刻む前の溢れが消える。
- CopyBufferRegion で u6 の区間を写す: 同じリストの UAV と写しの状態の遷移が要る。段で写せば障壁は今の UAV の障壁だけ。
