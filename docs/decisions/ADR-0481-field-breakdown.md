# ADR-0481 欄の内訳(1 つの保存量の 2 つ目の状態)の登録の形と、物質ごとの量の内訳の置き場(案)

- 日付: 2026-10-26
- 決めた人: Claude(T-1177)
- 設計: docs/design/20-transport-substrate.md §10.1・§10.5 / 前: ADR-0469 の 2-2・2-6・D-659・D-664・D-668 / 関係: T-1136・T-1138・T-1167

## 背景
D-659 で、セルの粒を「積もった層」と「舞う粒」の 2 つの状態で持つことが決まり、ADR-0469 の 2-2 は「登録の印『内訳』(親の保存量の欄を指す)」を一旦の決定にした。
形は案 B の試作(T-1136 の 2 本目・T-1138 の ②)の結果を待った。T-1138 の ② + 見直し 2 が合格したので、内訳 1 つ + 運動量の置き場 2 つの形で土台の登録に入れる。

## 決定
1. **登録の印 `SF_FLAG_BREAKDOWN` と `SfFieldDesc::parent`**: 内訳は親(先に登録した保存量の欄・置き場と値の数が同じ・内訳でない)の値のうち「止まれる側の状態」の量。
   真実・SAME・ハッシュに入る(保存点にも)。保存の列は親だけ。0 ≤ 内訳 ≤ 親(`SfBreakdownFits`・`CountBreakdownMisfits`)。親 1 つに内訳は 1 つ。
2. **細かくする**: 内訳は内訳の置かれ方の印で、残り(親 − 内訳)は親の置かれ方の印で配り、子の親 = 子の内訳 + 子の残り(D-664 の「置かれ方で配る」1 つのまま)。
   砂なら「粒の量 = PLACE_OPEN・層 = PLACE_CONDENSED」で、層は沈めて下の子から・舞う粒は空きに同じ濃さ。**粗くする**は今の規則のまま(切り捨ては単調なので 0 ≤ 内訳 ≤ 親 が保たれる)。
3. **眠る(頁を畳む)判定**: 残りのある頁は畳まない(舞う粒は濃さ 0 まで起きている)。止まれる側だけなら今の規則で畳める。
4. **運動量の置き場(2-6)は内訳にしない**: 層の運動量・舞う粒の運動量はそれぞれ独立の保存量の面の欄(PLACE_CONDENSED / PLACE_OPEN)。和を親にする意味が無い(符号を持つ)。

## 5. 物質ごとの量の内訳の置き場((a) に決定・D-678。2026-10-26 T-1209 の作業役の案をユーザーが確定)
今の内訳は「登録した保存量の欄」の内訳だけを書ける。ところが粒の量はセルの成分(物質ごとの量。セルの頁の species / amounts)で、登録の欄ではない。
- 【エンジン】問い: 砂と灰のように粒の物質が混ざったセルで、「積もった層」と「舞う粒」の物質の割合を別々に持てるようにするか。

| | (a) 成分ごとの層の量 | (b) 粒の量の和に内訳 |
|---|---|---|
| 持つもの | セルの成分(物質・量)ごとに「そのうち層の量」(0 ≤ 層 ≤ 量) | セルに「層の質量の和」1 つ(0 ≤ 層 ≤ 粒の物質の量の和)。層の物質の割合はセルの粒の割合と同じと読む |
| 作り手から見た違い | 計器・セルの見え方に層の成分と舞う成分が別に出る。書く値は増えない(層になるかは物質の相と粒の値から) | 層と舞う粒の物質の割合はいつも同じ(灰と砂が同じ割合で舞う)。読む値は和 1 つ |
| 費用(見込み・未測定) | 粒のある頁だけ成分ごとに 8 B(幅 2 の頁で 1 セル 33 → 49 B)。セルを書く全部の道で、成分の並びが変わる時に付け替える | 粒のある頁だけ 1 セル 8 B。付け替えは和の頭打ちだけ |
| 遊びを作る上のメリット | 混ざった粉で舞いやすい物だけが舞う(#37 粉じん・#38 すすが落ちる)。「風に当てると分かれる」こと自体が研究で見つかる法則になり、物を見分け・分ける作戦(ふるい・風選)が立てられる | 単純で、計器に出る値が少ない。費用が小さい |
| デメリット | 費用と付け替えの道の数。反応が層と舞う粒のどちらから取るかの規則が要る(下の 3) | 混ざった粉の現象が出ない(現実と違う割合が研究で見つかってしまう。D-428・D-463)。後で (a) に変えるとセーブの形が変わる |

- **一旦の決定: (a)**(D-659 の「物質は 1 つのまま・書く値は増えない」を保ち、混ざった粉の現象に要る)。ユーザー未確認。
- **(a) の形(土台に入れる時。T-1210)**:
  1. 置き場: 反応の核のセル(RxCell)の形は変えず、セルの頁に並ぶ「成分の内訳の頁」(粒のある頁だけ。疎。欄の頁と同じ作り)に層の量を持つ。
     成分の並びの位置ではなく**物質で結ぶ**(書く時に新しい並びへ物質で付け替える。無くなった物質の層は 0)。一様の値の枠は層 = 0 か「全部が層」の 2 つだけを持つ(一様の砂の床)。
  2. 規則(1 つ): 内訳は止まれる側の量。層を動かす法則(積もる・舞い上がる・崩れる・層の流れ)だけが層を書き、ほかの法則が成分の量を変える時は残り(舞う側)が先に変わる:
     書く時に `層 = min(前の層, 新しい量)`、増えた分は残りへ(層は変わらない)。0 ≤ 層 ≤ 量 は書く時に必ず保たれ、検査は 1 の `SfBreakdownFits` と同じ形。
  3. 反応は成分の量の全部に当たる(物質は 1 つ)。減る時は 2 のとおり残りから先に減る。層と舞う粒で反応の速さを変えるか(舞う粉は表面が広く速く燃える)は別の問い(21 の現象の一覧と照らしてから。今は問いにしない)。
  4. 細かくする: 成分ごとに 2 の配り(層は内訳の印 = 凝縮相・残りは親の印 = 空きに同じ濃さ)。粗くする: 成分ごとに和 ÷ 8 の切り捨て(単調なので 0 ≤ 層 ≤ 量 のまま)。
     眠る: 残りのある頁は畳まない(1〜3 と同じ)。保存の列: 物質ごとの量のまま(内訳は列を持たない)。ハッシュ・保存点: 真実として入る。
  5. 1〜4 の登録の内訳(`SF_FLAG_BREAKDOWN`)は、登録した保存量の欄の内訳としてそのまま残す(2 つは同じ規則で、置き場だけが違う)。
- **追記(2026-10-27・T-1220)**: 1 の「一様の値の枠は層 = 0 か全部が層の 2 つだけ」は、隙間の空気が混ざった一様の砂の床を書けないので、
  一様の枠も成分ごとの層を持つ形に改めた。3 の「残り」は粒の物質だけで数え、粒の残りを舞う粒と読むのは層を使う世界(`EnableCellLayers`)だけにした。
  どちらも ADR-0489(Proposed・仮)。
- **土台に足りないもの(入れなかった理由)**: セルの成分の並びは反応の核(RxCell)・セルの頁(ADR-0417)・溢れの領域(T-0187)・GPU のセルを書く全部のカーネルが書く。
  成分の内訳を保つには、セルを書く全部の道に 2 の付け替えが要る。T-1177 で認められた範囲(ADR-0469 の 2-2・2-6 = 登録の欄の型と運動量の置き場)を超えるので、
  今の土台には入れていない(司令塔へ。T-1210)。案 B の箱(case_b)は 1 物質なので、箱の中の研究はこれを待たない。

## 取り消し方
- 1〜3: 内訳の欄を登録しなければ今まで通り(内訳の無い欄はビット単位で同じ。placement_refine_test の 1〜4)。
- 5: まだ何も入っていない。(b) に替えるなら T-1210 の置き場をセルに 1 値にし、2 の規則を「和の頭打ち」にする。
