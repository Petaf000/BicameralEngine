# ADR-0481 欄の内訳(1 つの保存量の 2 つ目の状態)の登録の形と、物質ごとの量の内訳の置き場(案)

- Status: 1〜4 は Accepted(ADR-0469 の 2-2 の一旦の決定 (a) の形。T-1177)/ 5 は Proposed(判断待ち。司令塔へ)
- 日付: 2026-10-26
- 決めた人: Claude(T-1177)
- 設計: docs/design/20-transport-substrate.md §10.1・§10.5 / 前: ADR-0469 の 2-2・2-6・D-659・D-664・D-668 / 関係: T-1136・T-1138・T-1167

## 背景
D-659 で、セルの粒を「積もった層」と「舞う粒」の 2 つの状態で持つことが決まり、ADR-0469 の 2-2 は「登録の印『内訳』(親の保存量の欄を指す)」を一旦の決定にした。
形は案 B の試作(T-1136 の 2 本目・T-1138 の ②)の結果を待った。T-1138 の ② + 見直し 2 が合格したので、内訳 1 つ + 運動量の置き場 2 つの形で土台の登録に入れる。

## 決定
1. **登録の印 `SF_FLAG_BREAKDOWN` と `SfFieldDesc::parent`**: 内訳は親(先に登録した保存量の欄・置き場と値の数が同じ・内訳でない)の値のうち「止まれる側の状態」の量。
   真実・SAME・ハッシュに入る(保存点にも)。保存の列は親だけ。0 ≤ 内訳 ≤ 親(`SfBreakdownFits`・`CountBreakdownMisfits`)。親 1 つに内訳は 1 つ。
2. **細かくする**: 内訳は内訳の置かれ方の印で、残り(親 − 内訳)は親の置かれ方の印で配り、子の親 = 子の内訳 + 子の残り(D-664 の「置かれ方で配る」1 つのまま)。
   砂なら「粒の量 = PLACE_OPEN・層 = PLACE_CONDENSED」で、層は沈めて下の子から・舞う粒は空きに同じ濃さ。**粗くする**は今の規則のまま(切り捨ては単調なので 0 ≤ 内訳 ≤ 親 が保たれる)。
3. **眠る(頁を畳む)判定**: 残りのある頁は畳まない(舞う粒は濃さ 0 まで起きている)。止まれる側だけなら今の規則で畳める。
4. **運動量の置き場(2-6)は内訳にしない**: 層の運動量・舞う粒の運動量はそれぞれ独立の保存量の面の欄(PLACE_CONDENSED / PLACE_OPEN)。和を親にする意味が無い(符号を持つ)。

## 5. 物質ごとの量の内訳の置き場(Proposed。判断待ち)
今の内訳は「登録した保存量の欄」の内訳だけを書ける。ところが粒の量はセルの成分(物質ごとの量。セルの頁の species / amounts)で、登録の欄ではない。
- 【エンジン】問い: 砂と灰が混ざったセルで、層と舞う粒の物質の割合を別々に持てるようにするか。
  - (a) **成分の量の内訳**(物質ごとに層の量。セルの頁の成分の並びに 1 つ足す): 混ざったセルで舞いやすい粉だけが舞う(#37 粉じん・#38 すす)。セルの頁が成分ごとに 8 B 増える(粒のある所だけ)。
  - (b) **セルの粒の量の和を保存量の欄にして内訳を付ける**(1 の形のまま): 層と舞う粒の物質の割合はいつも同じ(灰と砂が同じ割合で舞う)。成分の並びは変えない。
  - おすすめ (a)(D-659 の「物質は 1 つのまま」を保ち、混ざった粉の現象に要る)。成分の並び(RxCell・セルの頁)に当たるので、粒が土台に来るチケットで入れる。

## 取り消し方
- 1〜3: 内訳の欄を登録しなければ今まで通り(内訳の無い欄はビット単位で同じ。placement_refine_test の 1〜4)。
