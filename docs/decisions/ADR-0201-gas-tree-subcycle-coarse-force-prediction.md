# ADR-0201 気体の木の分けた小刻み: 粗い側も境の面の力を見込んで流れを出す(T-0479)

- Status: Accepted(不具合の直し。作り手から見て変わるのは偽の流れが消えることだけ)
- 日付: 2026-10-14
- 決めた人: Claude(不具合の直し。ユーザーの判断が要る違いは無い)
- 関係: ADR-0117(気体の木・レベルごとの小刻み T-0320・GPU T-0356)・ADR-0200(T-0470。見つけたきっかけ)

## 背景
- レベルごとの小刻み(T-0320)では、粗いセルが細かい面から受ける力(圧力の力積・重さ)は、粗い小刻みの終わりに合計で受けていた(refluxing)。
  気体の小刻みは「力を先に当て、その運動量で流れを出す」順なので、粗い小刻みの間に流れを出す運動量(forced)は、粗い面の側の力だけを受け、
  細かい範囲の側の力を受けていなかった。
- 圧力が基準と一様にずれると(p̃ = α(p − p_基準) が一様に 0 でない。閉じた部屋の火・基準と違う大気・環境の差し替え)、境の粗いセルは片側だけから
  押され、偽の運動量で毎小刻み質量を流す。11% の一様な加圧で約 11 m/s の偽の流れ(分けない形は 0)。合計の運動量は釣り合うので保存の試験では
  見えず、今までの静止大気の試験は p = p_基準 ちょうどなので見えなかった(T-0479 に測った値)。

## 決定
- **粗い側(小刻みの差 g > 0)は、粗い小刻みの初めに、その面の初めの力 × 2^g を見込みとして forced に足し、同じ分を next から引く**。
  細かい面の本当の力は今まで通り毎回 next に足す。next の合計(= 状態に入る値)は見込みの有無で同じなので、保存(成分・エネルギー・運動量・帳簿)は
  そのまま。Berger–Colella の「粗い側は自分の見積もりで進め、終わりに細かい側の合計との差を受け直す」形に揃えた。
- 見込みは細かい面の初めの値(粗い側の値は粗い小刻みの間変わらず、細かい側は初めの値)。時間補間はしない(T-0320 と同じ)。
- 分けない形(g = 0 だけ)は何も変わらない(T-0208 の状態のハッシュの鎖と一致のまま)。
- CPU: `gas_tree.cpp` の `ApplySideForce`(倍率 2^g・1 − 2^g)。GPU: `gas_tree_step.hlsl` の `AddFaceForces`(同じ倍率。足し算は 64.64 の固定小数点で
  順によらない)。

## 影響
- 分けた形の木で、一様な加圧の静止大気が止まったまま(重さなし 1 mm/s 未満・重さあり 0.02 m/s。分けない形と同じ程度)。
- 分けた形の圧力の波の反射 2.31% → 1.37%・通った波の誤差 3.83% → 3.37%(分けない形の 1.35%・3.19% とほぼ同じ。07 §2.5 の
  「粗い側の時間補間が無い分の約 2 倍」は、実はこの見込みが無かった分だった)。
- 分けた形の結果は変わる(GPU と CPU は同じ式で毎刻みビット一致のまま)。
