# ADR-0535 熱の放射の段(RC)の「向こうが通さない面は放たない」の崖(T-1156。Proposed)

- Status: Proposed(2026-11-12 wt4 作業役。ユーザーの判断待ち。仮 = (a) 今のまま〔エンジンは変えない〕で進める)
- 日付: 2026-11-12
- 決めた人: まだ(案は Claude〔wt4 の作業役〕)
- 親: T-0877(段の共通の核。面の向こうがその帯を通さなければその面から放たない = 触れている物どうしは伝導の仕事)・T-1161(RcMaskAcross)・T-1113(既定の RC)・D-428
- 実装(今): shaders/common/cascade_light.hlsli の RcMaskAcross(向こうのセルの τ ≥ 32〔RD_DEPTH_SATURATED_Q32〕の帯を 0)

## 背景(測った数。T-1156・radiation_scene_measure watch=1・release・CPU リファレンス・既定の RC)
- 草原の場面の草のセル: セルロース 1.2 mol × 長い帯の a 11,000,000 mm²/mol ÷ 面 0.25 m² = **τ 52.8(32 以上 = 飽和)**・短い帯 a 320,000 で τ 1.54。
- 付けたセル(つつき 970 kJ)は 3 秒で 1.17 MJ を放つが、**隣の草のセルの面は長い帯が隠れる**ので、長い帯はほぼ上の面(空気 → 空)からだけ出る。
  隣(x+1)が受けたのは短い帯の 30 kJ だけで 384 K で止まる(表の熱分解の速さ〔a 2.8e19・Ea 242.4 kJ/mol〕が 1/秒 ほどになるのは 650 K 付近〔計算〕。2 つ先 x+2 は 2.9 kJ・308 K)。伝導は 0.06 kJ/秒(草のセルは空気がほとんど)。
- 草の長い帯の a を 6,000,000(τ 28.8。飽和の手前)にすると面が隠れず、x+1 は 0.5 秒前に・x+2 は 2 秒前に燃える。
- **τ が 31.9 なら面ごとに σ(T₁⁴ − T₂⁴)A を全部渡し、32.0 なら 0**。表の値の連続な変化で法則の結果が飛ぶ崖(作り手は a を少し変えただけで燃え広がりが消える・現れる)。
- 物理: 「触れている物どうしは伝導」は詰まった固体(石・木の中)では正しい(中の放射は µm で吸われる)。まばらな物(草・藁・枝の山。セルの体積の 0.1 % が固体)は
  0.5 m では不透明でも中は隙間で、放射が中を拡散で運ぶ(Rosseland: k = 16σT³ ÷ 3β。β = τ ÷ 0.5 m)。今の面の扱いは τ の大きさで「全部渡す / 0」の 2 つしかない。

## 案(作り手〔エンジンを使う人〕から見た違い)
| 案 | 作り手から見た違い | 費用・ハッシュ |
|---|---|---|
| (a) 今のまま(仮) | 不透明(τ ≥ 32)な物どうしの面は放射で受け渡さない。まばらな燃える物を燃え広がらせたいなら、その物の光の a を 1 セルで τ < 32 になる値にする(崖の手前は面ごとに全部渡す)。崖は残る | 変えない |
| (b) 面の受け渡しを τ で連続に(拡散の係数。τ が大きいほど細く、詰まった固体で 0 に近づく) | a を変えると燃え広がりの速さが連続に変わる。草は a の値(=どれだけまばらか)で速さが決まる。今の表の草(τ 52.8)は (a) より広がりやすいが、拡散の係数では今の値のままだと広がらない見込み(未確認) | 段の核(CPU・GPU)を変える。熱い不透明な物の中の面が放つ所の費用が増える。不透明な物が熱い場面のハッシュが変わる。研究(形を決める) |
| (c) 「触れている」をセルの固体の体積の割合(cell_volume の空き。気体・液体の面の開きと同じ芯)で決める | 密度を書いた物は詰まり具合で放射の面が開く。まばらな草は全部渡す。砂・土(固体 6 割)の中の面も 4 割開き、熱い地面の中を放射が強く運ぶ(実の砂の数十倍。未確認) | 段の核を変える・ハッシュが変わる |

## おすすめ
(b)(一つの芯 = 放射の運び方を光学の厚さで連続にする。崖が無くなり、中身は a の値だけで選べる)。ただし形が研究なので、決まるまでは (a) のまま(取り消しやすい = 何も変えていない)。

## 結果(仮の (a) で)
- エンジンは変えない。既定の RC で燃え広がる場面の試験(radiation_scene_spread: 草の τ 28.8 で広がる・表の値 τ 52.8 で広がらない)を足した。
- 草の a をいくつにするか(草がどれだけまばらか)はゲームの中身(D-539)。

## 追記(2026-11-12 wt4 の作業役・T-1365 の研究。既定は変えていない・Status は Proposed のまま)
CPU リファレンスで (b) の形 2 つ(面から放つ量に係数 g を掛ける。τ = 面の両側の小さい方。① g = min(1, 4/3τ)・② g = 1/(1 + 3τ/4))を、
既定 0 の口 `CascadeParams::faceCoupling` で試した(数は T-1365 の表)。
- **今の形は崖の下でも外れていた**: 厚い一様な物の中で、τ < 32 では Rosseland の拡散の 3τ/4 倍(τ 31 で 19 倍)を運び、τ ≥ 32 で 0。
  T-1156 の「τ 28.8 なら燃え広がる」はこの過大な受け渡しによる。(b) の形は τ ≥ 16 で解析解の ±21 %・τ ≥ 32 で ±3 %。
- **今の形は片側だけ通さない面で同じ温度の釣り合いを崩す**(通さない側だけが放つ。石の殻 + τ 2 の物の箱で放った量の +5.9 % が殻から中へ)→ T-1367。(b) の形は両側で同じ係数なので崩れない。
- 詰まった物(既定の灰色の固体: 木 τ 8e6・砂 τ 1.7e7)は係数が 0 で、伝導と二重に数えない。保存はビット単位で成り立つ。
- 費用: 向こうが通さない帯(τ ≥ 32)は光線を歩かずに向こうのセルへ直に当てる(光線は向こうで全部止まるので量は同じ)と、厚い一様な板の費用は今と同じ。草原の場面はまだ 2.2 倍(照り返しの持ち越しの見込み。T-1365 の引き継ぎ)。
- **作り手から見た違い((b) にしたら)**: 今の表の草(τ 52.8)も τ 28.8 も放射だけでは燃え広がらない(τ 8 で隣 1 セル)。放射で燃え広がる草は τ がおよそ 2〜8 未満の a になる(未確認の幅)。a を変えると燃え広がりは連続に変わる。
- おすすめは (b) の形 ②(二流束。折れ目の無い 1 つの式)。(a) のままにする場合も T-1367(両側の小さい方の τ で崖を決める)は直す方がよい。

## 追記(2026-11-13 wt4 の作業役・T-1367。Status は Proposed のまま)
- (a) のままでも直す所を直した: 崖の条件を「向こうが τ ≥ 32」から「**両側とも τ ≥ 32**」(両側の小さい方の τ。RcBandSealed)にした。
  透ける物と通さない物の面は両方が全部放つ(触れている固体どうしは今まで通り伝導の仕事)。同じ温度の箱(石の殻 + τ 2 の物)の正味は +5.9 % → −2.4 %(向きの粗さの残り。形 1・2 と同じ向き)。
- 作り手から見た違い: 透ける物(薄い煙・草・浅い水など)が、触れている固体へも放射で熱を渡す(前は固体から透ける物への片道だけ)。(b) の形 1・2 は元から両側で同じ係数(両側の小さい方の τ)なので、この直しと同じ考え方で矛盾しない。
