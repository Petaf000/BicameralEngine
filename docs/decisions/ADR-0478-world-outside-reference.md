# ADR-0478 世界の外の扱い: 熱の放射(RC)の箱の外を「参照の温度の物 + 上は空との交換の口」にする(案)

- Status: Accepted(2026-10-26 ユーザー決定 D-671。既定を「周りの環境の温度の物 + 上は空との交換の口」にする。T-1164 の値で選べる形のまま、既定を切り替えるのは wt6 の作業)
- 日付: 2026-10-26
- 決めた人: Claude(T-1155・T-1164)
- 設計: docs/design/23-radiation.md §3.2・§3.3・§4 / 前: ADR-0461(参照の温度との差だけを運ぶ)・ADR-0474(空との交換の口)・D-468・D-646

## 背景
T-1113・T-1154 で放射の段(RC)を仮の世界の既定にしたが、世界の箱の外は 0 K の空のまま。室温の物の外向きの面は毎刻み少しずつ冷え、
そのブロックは眠らない(何もしない 300 K の世界で毎刻み 32 ブロック・296 セルが変わる)。D-468(負荷で遅れるのは不具合)の費用に効く。

## 決定(案)
1. 放射の段の外は**参照の温度の物**(ADR-0461 の差だけを運ぶ形: CascadeParams::referenceMk)。参照の温度は世界の値(環境の温度)。
   同じ温度の所は何も放たないので、参照の温度で釣り合った世界は放射で何も変わらず眠る。
2. 上の外(空)は**空との交換の口**(ADR-0474。空の光 − 参照の黒体の差だけ)。空 = 参照なら口は何もしない(ブランクの世界の既定)。
3. 参照の温度の既定は、世界を作った時の値(作り手が書く。書かなければ 0 = 今の 0 K の空。仮)。

## 作り手から見た違い(比べた案。何もしない 300 K の世界・火の世界は仮の世界の CPU の測り。T-1164)
| 案 | 何もしない 300 K の世界 | 火の世界 | 作り手が書くもの |
|---|---|---|---|
| (a) 今: 外は 0 K の空 | 面のブロックが毎刻み起きる(32 ブロック・296 セル/刻み)。室温の物が勝手に冷える | 外の面も冷える(296 セル/刻み変わる) | 何も無い |
| (b) **外 = 参照の温度 + 空の口(おすすめ)** | 何も放たず全部眠る(0 ブロック・0 光線) | 熱い所と、参照と違う所だけが放つ(217 セル/刻み) | 環境の温度・空の温度と散らばった光(天候の層の値) |
| (c) 外 = 環境の温度の黒体(差ではなく全部を運ぶ) | 外との出入りは釣り合うが、箱の中の面どうしが毎刻み σT⁴ を運び合い、向きの升目の筋で正味が 0 にならない(ADR-0461 の前と同じ)→ 眠らない | (a) と同じ費用 | 環境の温度 |
- (b) で夜の地面(空が参照より冷たい)は、開けた所が口で冷え続ける(釣り合いではないので眠らないのが正しい)。軒下は冷えにくい。測りは T-1164 の残り(木の世界で口とつなぐ時)。
- 閉じた実験の箱(lab_box。外とは熱を通さない)では、外 = 鏡(返す)の形も要るかもしれない(未確認。世界の端の種類 WE_WALL で選ぶ形が自然)。

## 入れた形(2026-10-26 wt6・T-1164)
- 仮の世界(CPU の ProbeReference・GPU の ProbeSim)の既定: 参照の温度 = **作った時の表の基準の大気の高さ 0 の温度**(ProbeCascadeReferenceMk)。
  基準の大気を書かない表は 0(外は 0 K の空。決定 3)。決めた値にするのは ProbeCascadeOptions::environmentReference = false + params.referenceMk(試験・測り用)。
  表の差し替えでは参照の温度を変えない(CPU と GPU で同じ)。
- GPU は段を正の側と負の側の 2 つ(GpuCascadeLight × 2。作業と状態の並びは同じ)。当てる段が 正 − 負 を 32bit の上下に分けて引いて丸める。
- 空との交換の口は仮の世界にはつないでいない: 空の値を書く口(天候の層)がまだ無く、空 = 参照の温度なので口は何もしない(決定 2 のブランクの既定)。
  口の向きは毎刻み 4 方向すべて(D-676。SkyPortParams::rotateDirections の既定は切のまま)。
- 試験の表(combustion_test。earth_environment の ISA)は環境 288.15 K・初めの世界 300 K なので、何もしない世界も環境へ冷え続けて眠らない(正しい振る舞い)。
  300 K の環境の表では全部眠る(probe_radiation の 7)。
  → 2026-10-26(wt6 第 3 回): combustion_test の基準の大気の地面の点を 300 K にした(仮・ユーザー未確認。T-1164)。サンプルの世界の何もしない所は眠る。
- GPU の持ち越しは鍵で引く密な表 2 つ(ADR-0484。前の疎な表が溢れて窓の再生が非決定になった)。

## 結果
- 釣り合った世界の放射の費用が 0 になる(眠りが効く)。参照の温度を書かない世界は今と同じ。
- RC は正の側と負の側の 2 回になる(参照と違う所だけが光源なので、光線の数は今以下。CPU リファレンスは参照と同じ温度の面を先に抜く:
  仮の世界の CPU で 1 刻み 何もしない世界 187 → 52 ms・火の世界 177 → 87 ms。T-1164)。
