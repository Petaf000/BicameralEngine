# チャットを始めるときの定型文

## PC チャット(いつもこれ。先にランナーを起動しておく)
```
続き
```
特定のチケットをやりたいとき:
```
T-0003 をやる
```
最初にフォルダ 2 つ(リポジトリと鍵フォルダ)の接続許可が出るので承認する。

## 設計チャット(PC に触れないとき)
```
設計チャット。T-0002 の反応表を詰めたい。今日は「中間生成物」の系統を考える
```
終わりに Claude が「反映用まとめ」を出す。次の PC チャットで:
```
続き。前の設計チャット(反応表・中間生成物)の反映用まとめをリポジトリに反映して
```

## 途中で区切らせたいとき
```
引き継いで
```

## 方針を変えたとき
```
方針変更: <何を、なぜ>。ADR を書いて、影響するチケットと設計書を直して
```

## Claude が迷走しているとき
```
いったん止まって。今の仮説と、試したことと、次に試すことを 5 行で
```
