# まとめてレビュー(T-0009)— 決めてほしい点

L4(docs/design/02・04〜16)と L5(ROADMAP.md)を書き終えた。設計の中で、ユーザーに決めてほしい点・確認してほしい点をここに集めた。
番号で答えてもらえれば、DECISIONS.md に足して反映する。推しは (推) と書いた。

## A. ゲームの手触りに効く設計の選択
1. **草は 1 本ずつではなく、セルの成分(バイオマス)として持つ**(05 §2)。草を 1 本抜く・1 本だけ燃やす、はできない。見た目は GPU で生やす。
   → (推) これで良い / 1 本ずつ扱いたい物(薬草など)は「物」として別に置く
2. **物は、あらかじめ分けた部品の範囲でしか壊れない**(08 §1)。任意の形には割れない。細かく壊したい物は細かい部品で作る。
   → (推) これで良い / 任意に割れる必要がある物がある(何か)
3. **物理の形は球の集まり**(08 §1)。見た目はメッシュ。角ばった物どうしがぴったり積み重なる、は苦手。
   → (推) まず球の集まり。積み木や石積みで困ったら凸形を足す
4. **世界の高さの範囲 -512m 〜 +1536m**(05 §1)。一番高い山・一番深い洞窟はこの中。
   → (推) これで良い / 変える(中身の都合)
5. **近くで個体として動く生き物は同時 256 体**(09 §1)。大群(虫の群れ・魚の群れ)は別の仕組み(群れを 1 個体として扱う)が要る。
   → (推) 256 で始め、大群は C3 の中身を見て決める
6. **1 刻み = 世界時間 1/60 秒**(06 §1)。昼夜・季節の速さ(現実の何分で 1 日か)は中身なので C2 で決める。
   → (推) これで良い
