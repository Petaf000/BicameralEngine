## Q62 最速の伝わりを広い範囲で選んだ時、1 刻みで下りきらない分をどう扱うか(T-0494。エンジンの仕組み。仮 = 案 1 + 案 3・ユーザー未確認)〔**2026-10-15 ユーザーに聞いた**。答えはまだ〕
- 背景: 刻みより速い伝わり(D-467 の最速。熱の陰解法・後で気体の圧力)を 1 刻みで坂を下りきるまで解くと、64³(26 万セル)の鋭く変わる刻みで
  ×10³ 10.4 ms・×10⁶ 76 ms 以上(RTX 3070 Ti)。予算 4 ms(仮)で下りきるのは、鋭い刻みで約 3〜5 万セル(32³〜40³)まで。落ち着いた後は 64³ まで 4 ms に入る。
- 案 1(おすすめ): **粗い段で先に下りきり、細かい模様は 1〜数刻み後に追いつく**(V サイクルの回数を刻みの予算で切る)。
  作り手から見て: 最速を選んだ広い範囲では、遠くまでの平均の温度はその刻みに届くが、細かい温度の模様が揃うのは 1〜数刻み後。エネルギーはビット単位で保存される。
- 案 2: 下りきるまで回す。作り手から見て: 最速の範囲を広くするとその刻みが予算を超え、世界の時間が遅れる(D-468 では不具合)。
- 案 3: 「同じ刻みに下りきる」を約束する範囲の大きさを決めて文書に示し(例: 3 万セル)、超えたら開発ビルドの計器に出して案 1 の形で遅れる。
  作り手から見て: どこまでの広さなら最速が 1 刻みで揃うかが分かる。案 1 と一緒に使える。
- 気体の圧力(T-0503)も同じ形になる見込み。詳しくは docs/tickets/T-0494-wide-propagation-cost.md・docs/perf.md。

## Q66 引きずりの表の書き方(T-0493。ADR-0220 Proposed。作り手から見た違い。仮で進めた・ユーザー未確認)〔**2026-10-15 ユーザーに聞いた**。答えはまだ〕
「X の流れが Y をどれだけ引きずるか」(熱の流れが塩を運ぶ など)を作り手が表に書く形。運ぶ引きずり(流れる物が中の熱・成分を同じ割合で運ぶ)は係数 1 で書かない。問うのは交差の引きずり。
1. **どこに書くか**: **A 独立の表 `drags`(おすすめ・仮)** `{ flow = "heat", drags = "species:salt", coupling = 0.3, within = "phase:liquid" }` = 法則の表として一か所で一覧でき、
   ノード表示(D-482 ②)にそのまま出る / B 物質の欄 = 物質ごとに見えるが、違う物質の境の面でどちらの値かの決まりが要る / C 流れの側 = 短いが、どの物質・相の中でかを書く所が無い。
2. **値を何で書くか**: **a 結合の強さ q(−1〜1)(おすすめ・仮)** = どんな値でも坂を上らない保証が式の形で付き、温度・濃さによらない。坂を上らせる構造(T-0495)の効率と同じ 1 つの数。
   現実の係数は直接写せない(パネルで換算を出す)/ b 物理の係数(Soret 係数など)= 現実の値を写せるが、上限が温度・濃さで変わり、書いた値と効く値が場所で違う。
3. **範囲の外(|q| > 1)**: **警告して ±1 に押さえて動かす(おすすめ・仮。D-487 ② と同じ)** / 読み込みを止める。押さえないと模型で 26 刻みで 57 K の温度差が仕事なしで育った(永久機関)。
4. **|q| = 1 を許すか**: **許す(おすすめ・仮)** = 結合しきった理想の機械を作れる(閉じた系で 1 つの組が一様にならない。エントロピーは減らない)/ 1 未満に押さえる。

## Q70 押す構造(機械・体・魔法の「押す」)の表の書き方(T-0495。ADR-0228 Proposed。作り手から見た違い。仮で進めた・ユーザー未確認。**Q66 と一緒に**)〔**2026-10-15 ユーザーに聞いた**。答えはまだ〕
「構造が蓄えた物 X を使って物 Y を坂の上へ押す」(ポンプが蓄えたエネルギーで気体を高圧側へ押す・熱機関・筋肉)を作り手が表に書く形。
押す構造は Q66 の引きずりと同じ 1 つの形(結合の強さ q。違いは係数を物質でなく構造が持つことだけ)なので、Q66 と同じ答え方にそろえるのがおすすめ。
例(仮): `machines = { { name = "pump", store = "energy", push = { what = "gas", from = "port:in", to = "port:out" }, coupling = 0.9, cost = 3000, speed = 3000 } }`
1. **どこに書くか**: **A 独立の表 `machines`(おすすめ・仮)** = 置いた所だけで効く「物」として法則の表(反応・`drags`)と分かれて見える。検査は `drags` と同じ /
   B `drags` の行に `through = 構造` = 表は 1 つで済むが、どこでも効く法則と置いた所だけの機械が混ざり、費用・速さ・口の欄が多くの行で空 /
   C 物の型(物理の物・生き物の体)の欄 = 体の筋肉は書きやすいが、セルで作る機械(壁に埋めたポンプ)を書く所が無い。
2. **数を何で書くか**: **a q・費用 w(1 単位押すのに使う蓄え)・速さ P(おすすめ・仮)** = q は `drags` と同じ 1 つの数。パネルに「最大の効率」と「止まる坂」(何倍の圧力まで押せるか)を出す /
   b 最大の効率 η(0〜1)・w・P = 機械を作る人には分かりやすい(「効率 25% の筋肉」)が、`drags` の q とは別の数に見える /
   c 止まる坂(例: 最大の圧力の比)・q・P = 止まる所を直接決められるが、気体の坂は温度で変わるので書いた値は決めた温度での値になる。
3. **坂に負けた時**: **結合の形のまま(止まる・押し返されると逆に回って蓄えを作る = 発電機。おすすめ・仮)** /
   一方向の規則(反応と同じく向きは作り手が書き、坂を上る時は警告して動かす。限界まで使うたびに警告が出る。止まる所・逆回りは作り手が別に書く)。
4. **範囲の外(|q| > 1。効率が 1 を超えうる)**: **警告して ±1 に押さえて動かす(おすすめ・仮。D-487 ②)** / 読み込みを止める。押さえないと模型で熱から蓄えを作り続けた(+86 kJ。保存は守るので帳簿では見つからない)。
5. **q = 1 を許すか**: **許す(おすすめ・仮)** = 止まった所で蓄えを使わず押し返されない理想の機械 / 1 未満に押さえる(止まった後も空回りで蓄えを少しずつ使う)。
答えの後: T-0536(表の読み手・型・ベイクを `drags` と 1 つに・構造の置き場所)。

## Q67 坂の警告の仮 4 つ(T-0492・T-0518。ADR-0218。作り手から見た違い)〔**2026-10-15 ユーザーに聞いた**。答えはまだ〕
1. **標準エントロピーの無い物質を含む規則**: **まとめて 1 行の警告(仮)**「坂を調べられない規則 N 本: …(標準エントロピーの無い物質: …)」がログとパネルに出る。エントロピーを書けば消える /
   黙って通す(書き間違いに気づけない)/ 規則ごとに 1 行(多い表で並ぶ)/ エントロピーを必須にする(既存のパッケージを全部直す)/ 無ければ 0(誤った判定が出る)。
2. **標準パッケージ real_reactions の boudouard(C + CO2 → 2CO)**: 一方向の規則なので 949 K 未満で坂を上る警告が出たまま(今は直していない・仮)。

4. (**Q73 ① へ移した**。T-0518 で案〔任意の欄 `condensed`〕を仮に作った)**計器(T-0518)の固体の活量**: エンジンの物質は相を持たないので、活量を全部「気体の分圧」にすると固体(炭・セルロース)で誤る。
   物質に任意の欄(例 `condensed = true`。活量 1)を足す = 書くものが 1 つ増えるが計器がすぐ正しくなる(おすすめ・仮)/ 相の仕組み(M2)を待つ = 書くものは増えないが、それまで計器の固体を含む規則の量は誤る。

## Q68 基準の大気を高さごとに書く形の仮 3 つ(T-0499。ADR-0182 の改訂。作り手から見た違い)〔**2026-10-15 ユーザーに聞いた**。答えはまだ〕
1. **点の列は environment の 1 つの鍵 `atmosphere_profile`、上書きは列ごと(仮・おすすめ)**: 標準の点を消せる・並びが一目で分かる。Mod が点を 1 つ足すにも列を写して書き直す(補助 `set_point` を使う)。

- 背景: 仮の世界(64³)の CPU リファレンスで、区画を書いた所だけ気体が流れるようにした(燃やすと煙と熱が上へ流れ、閉じた部屋の O2 は流れで補われる)。GPU の刻みは T-0592。
1. **世界の上下の向き(格子の y)**: 場面の world_cells は「y が上」、物理の対応は「格子 y = 64 − 物理 y」(下向き)で食い違っている。気体の重さはどちらかに決めないと向きが逆になる。
   **仮(案 A・おすすめ)= 格子の y が上**にそろえ、物理の対応を直す(今書いた場面がそのまま上下正しい)。案 B = 格子の y を下向きにし、world_cells の約束と既存の場面の y を全部ひっくり返す。直すのは T-0592。
2. **凝縮相の欄(condensed)が刻みに効く**: 坂の計器だけが読んでいた仮の欄(ADR-0230)が、気体として流れるかを決めるようになった。
   作り手から見て: 固体・液体に `condensed = true` を書き忘れると、その物質が気体として流れて広がる。**仮 = このまま使い、相(M2)が入ったら相で決める**。
3. **比熱**: 表の気体の比熱は定圧の値で、気体の段は定積の比熱として読んでいる。**仮 = そのまま**(セルの温度の決まりを 1 つに保つ。比熱比 γ と断熱の冷え方が少しずれる)。
   おすすめは T-0591 で「ベイクが定積の比熱 = 定圧 − R を作り、セルの温度もそれで読む」(作り手が書く値は今どおり定圧の比熱。密閉したセルの温まり方が変わり、今の場面の数値が少し変わる)。
4. **区画(気体を流す範囲)をどこに書くか**: **仮 = 試験の C++(ProbeReference::EnableGas)**。おすすめは T-0592 で世界の環境(environment)か world の分類に「気体を流す範囲」を書く形
   (書かなければ気体は流れない = ブランクの世界は何も読まずに動く。D-455)。
5. **基準の大気が無い世界**: **仮 = 区画を断る**。真空を基準にして気体を流すか(宇宙・真空の部屋)は T-0592 で決める。
