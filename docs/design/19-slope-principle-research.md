## 0. 結論(先に)
- 今のエンジンは**保存(受け渡しと帳簿)はほぼ全部できている**が、**「坂を下る向き」を構造で守っているのは熱の伝導だけ**。
  - 反応は向きを作り手が規則ごとに書く。物質にエントロピーの値が無いので、エンジンは化学の坂(ΔG)を知らず、坂を上る規則も黙って走る(§2.3 の例)。
  - 物理は衝突・摩擦で失った運動エネルギーが熱にならず消える(帳簿にも載らない)。
  - 引きずり(煙が熱を運ぶ)は気体の中にあるが、燃える木箱の世界(伝導 + 反応)とつながっていない(T-0186・T-0210)。
  - 坂を上らせる構造(ポンプ・筋肉。D-481 の「押す」)の形は無い。
- 代案は 3 つ(§3): **A 流れの勘定にそろえて坂の検査を足す** / **B 坂の値(化学ポテンシャル)から流れを決める(反応を可逆に)** / **C GENERIC の括弧を整数で直接書く**。
- **おすすめ**: A を土台に(木箱がビット単位で今のまま・費用ほぼ 0)、反応だけ B を小さく試す(物質のエントロピーから逆向きの速さを自動で作る)。
  C は実装せず、A の「坂の検査」の定義(理論の物差し)にだけ使う。D-467 の重さは既にある陰解法の熱の計測から始める。

## 2. 今のエンジンを坂の原理で見る

### 2.1 坂の原理をエンジンの約束に言い直す(GENERIC から)
GENERIC(Grmela & Öttinger 1997)は状態 z の時間変化を dz/dt = L(z)∇E + M(z)∇S と書く。L は反対称(エネルギーを保つ運動)、
M は対称で半正定(坂を下る散逸)、退化の条件 L∇S = 0・M∇E = 0 から dE/dt = 0・dS/dt ≥ 0 が出る。エンジンの言葉にすると次の 5 つ。

| # | 約束 | エンジンでの意味 |
|---|---|---|
| P1 | 保存 | 量は受け渡しでしか変わらない(04 R2)。外との出入りは帳簿(D-465) |
| P2 | 坂を下る | 散逸の流れ(熱・濃さの拡散・反応・摩擦)は、それぞれの坂の値の差の向きにだけ進む(エントロピーの生成 ≥ 0)。坂の値: 熱 = 1/T、物質 = μ/T(化学ポテンシャル)、体積 = p/T、運動 = 速度 |
| P3 | 引きずり | 可逆の運動(L)は流れる物が持つ量(熱・成分・運動量)を一緒に運ぶ。散逸の流れどうしの結合(Onsager の交差の係数)も引きずりで、結合の行列は半正定(L_xy² ≤ L_xx・L_yy) |
| P4 | 坂を上る | ある流れが坂を上るのは、同じ所で別の流れが坂を下り、合計のエントロピーの生成が ≥ 0 の時だけ(それを決めるのが「向きを持つ構造」) |
| P5 | 外からの入力 | コマンド・筆・境界は明示的な入力として帳簿に載る(D-419 の枠もここ) |

### 2.3 欠けているもの(研究で埋めるもの)
- **G1 反応の坂**: 物質のエントロピー・逆反応・平衡が無い。**例**(値は現実の文献値。試験の表で計算はしていない = 未確認):
  Boudouard(C + CO2 → 2CO)は ΔH ≈ +172.5 kJ/mol・ΔS ≈ +176 J/(mol·K) で、ΔG = 0 になるのは約 980 K。これより冷たい所では逆向き(2CO → C + CO2)が坂を下る向き。
  試験の表の `boudouard` は一方向なので、冷えても C + CO2 → 2CO に進み続ける(T-0014 の記録で 2000 K → 777 K まで進んだ)。
  `mana_test_catalyzed_boudouard` はさらに低い温度で進む = 触媒が向きを変えている(D-481「解くは壁を下げるだけで向きと量は変えない」に反する)。
  今の形では、作り手が値だけで「仕事なしで周りから熱を奪い続ける物質」(第二種の永久機関)を作れる。D-466 の「永久機関は作れないので架空の値でも暴れない」は、今は反応では成り立っていない。
- **G2 散逸の行き先**: 物理で失った運動エネルギーが熱にならない(気体は全エネルギーで済んでいる)。
- **G3 引きずりの一般の形と、木箱と気体の結合**: 今の引きずりは「流れる物が自分の量を運ぶ」だけ。D-466 の「何をどれだけ引きずるかをゲームが決める」には交差の係数の形と半正定の検査が要る。
  基準「煙が熱を運ぶ」は、燃える木箱の世界に気体をつなぐこと(T-0186・T-0210 の工学)が前提。
- **G4 坂を上る構造の形**: ポンプ・筋肉(P4)。
- **G5 坂の検査の道具**: 流れごと・刻みごとのエントロピーの生成の符号を測る道具が無い(P2 を「確かめる」手段)。
- **G6 刻みの中で下りきる(D-467)**: 熱は陰解法がある。気体の圧力・速い反応(R-REACT-1)には無い。

## 3. 離散化の代案
どの案も変えないもの: 整数・受け渡しの形(R2)・前の世代から計算する(Jacobi 型)・帳簿・CPU リファレンスとのビット一致。

### 案 A 流れの勘定にそろえる(今の式を残し、坂の検査を足す)
- **何をするか**: 各現象の式はそのまま。変化を「面の流れ(量 q を坂 s が動かす)」か「セルの中の変換(反応・散逸)」のどちらかとして書き直し、
  それぞれに「どの坂で動いたか」の札を付ける。札から刻みごとのエントロピーの生成を数える**坂の検査**(CPU リファレンスと開発ビルド)を足す。
  G2(物理の散逸を接するセルの熱へ。帳簿に載せる)と G3 の結合も同じ形で書く。反応は物質に**エントロピーの欄を任意で**足し、ベイクが
  「この規則は X K より冷たい(熱い)と坂を上る」を警告し、反応表のパネルに出す。
- **作り手から見た違い**: 書くものはほぼ今のまま(+ 物質のエントロピー。任意)。書き間違いは、ベイクの警告と開発ビルドの計器
  (「坂を上った流れ N 回・量」)に出る。**値で永久機関を作れてしまうが、必ず見える**。
- **基準**: 木箱 = **ビット単位で今と同じ**(式を変えない)/ 引きずり = 気体と結合すれば出る(T-0186 が要る)/ ビット一致 = 保つ / 保存 = 保つ + 物理の散逸を帳簿へ。
- **重さ**: リリースの世界はほぼ 0(検査は試験と開発ビルド)。物理の散逸 → 熱の受け渡しが少し。
- **危うさ**: 低い。読めないのは、気体の数値の散逸(MUSCL の反拡散)が面ごとに坂を上る所があるか。原理を「保証」ではなく「検出」にする分、美しさで劣る(D-462 の二番)。
- **打ち切り条件**: 坂の検査が「離散化を直しても消えない坂を上る流れ」を見つけたら(刻みの合計でも生成が負)、その現象だけ案 B の形へ移る。
  面ごとに負でも刻みの合計が ≥ 0 なら可とする(数値の反拡散)。
- **見積もり**: 2〜3 チャット(坂の検査の道具 1・反応のエントロピーとベイクの警告 1・物理の散逸の行き先 1)。気体との結合は T-0186 で別。

### 案 B 坂の値から流れを決める(化学ポテンシャル・可逆の反応)
- **何をするか**: 散逸の流れの向きと大きさを、状態から導く坂の値の差で決める。熱 = 温度(今と同じ)、物質の移動(拡散・蒸発・溶ける)= μ、
  反応 = 親和力 A = −ΔG = RT ln(K/Q)。反応は可逆になる。形は 2 つ:
  - **B1 逆向きの速さを自動で作る**: k_r(T) = k_f(T) ÷ K(T)。K(T) は物質の ΔH°・S°・比熱からベイクで温度ごとの表に(今の k(T) の表と同じ作り方)。
    逆向きは生成物の物質量で評価する。詳細釣り合いと整合するのは次数が係数どおりの規則(素反応)だけで、今の「次数 0 か 1・次数 1 は 2 個まで」の規則
    (木の燃焼は O2 × 6 で次数 1)には当てはまらない → 当てはまらない規則は B2 か一方向(案 A の検査)。
  - **B2 正味の速さ**: r = r_f × (1 − Q/K)(de Donder の形)。Q/K はセルの物質量の整数の ln の和で比べる(ln は 1 回 fmul の 550〜1200 回分。04 §6)。
- **作り手から見た違い**: 物質に**エンタルピーとエントロピー(と比熱)が必須**。規則に書くのは「何が何になるか」と反応の壁(A・Ea)だけで、
  **逆に戻るか・どの温度で釣り合うかはエンジンが出す**。書き間違いは「釣り合う温度がおかしい」として反応表のパネルに出る。
  **値では永久機関を作れない**(触媒は壁だけを下げるので向きは変わらず、D-481 がそのまま成り立つ)。架空の物質にもエントロピーを決める手間が増える
  (D-485 ② の下書きの道具で減らせる見込み)。
- **基準**: 木箱 = 同じく燃えるがビット単位では変わる(高温での CO2 ⇄ CO の釣り合いが入る。燃焼の K は非常に大きいので燃え方はほぼ同じ見込み。未確認)/
  ビット一致 = 保てる(整数の表)/ 保存 = 保てる / 引きずり = 案 A と同じく気体の結合が要る。
- **重さ**: B1 は規則ごとに表が 1 枚(4096 × 8 B)と逆向きの評価で、反応の段が最大で約 2 倍の見込み(未確認)。B2 はセルごとの ln が重い。
- **危うさ**: 中〜高。① 平衡の近くの硬さ: 前向きと逆向きがどちらも速く差が小さいと、1 刻みに 1 回の評価で行き過ぎ・振動する
  → 刻みの中で平衡まで解く形が要る(R-REACT-1・D-467 と同じ問題)。② 待ちの丸め(D-429)との相性: B1 は前と逆を別々に丸めるので、
  平衡のセルが毎刻み揺れて眠れず、活性の費用が増える恐れ。B2 は平衡で正味 0 なので眠れる。③ 次数の制限(上)。
- **打ち切り条件**: B1 を木箱 + Boudouard で試し、(i) 平衡のセルが眠れず活性のブロックが今の 2 倍を超える、か (ii) 反応の段の時間が 2 倍を超えるなら B2 へ。
  B2 の ln の費用が反応の段の 3 倍を超え、表と多項式(04 研究の代案の順)でも下がらなければ、反応は案 A(一方向 + 検査)に戻す。
- **見積もり**: 4〜6 チャット(CPU の試作 2・GPU と待ちの丸め 2・パネルと警告 1〜2)。

### 案 C GENERIC の括弧を整数で直接書く
- **何をするか**: セルの状態 z に、物質ごとのエネルギー E(z) とエントロピー S(z) の関数を持たせ、すべての相互作用を (L, M) の対という 1 つの形で書く。
  時間の進め方は離散勾配(Gonzalez・McLachlan–Quispel–Robidoux)で、毎刻み ΔE = 0 と ΔS ≥ 0 を式の形で保つ。熱・気体・反応・物理・押す構造が全部同じ形。
- **作り手から見た違い**: 物質ごとに「エネルギーとエントロピーの式」と、つながりの行列(何が何をどれだけ引きずるか)を書く。1 つの形で全部(美しさは最大)。
  書き間違いは、行列が対称・半正定・退化の条件を満たさない時にベイクで落ちる。値で永久機関は作れない。
- **基準**: 木箱 = 作り直し(式が全部変わる。ビット単位では違う)/ 引きずり = 形として出る / ビット一致 = 原理的には可能(反復の回数を固定)/
  保存 = E は受け渡しの形で保てる。**S の単調性は整数の丸めで崩れうる**(S は log を含み整数で正確に表せない。丸めの向きを決める工夫が要る)。
- **重さ**: 離散勾配は一般に陰的(非線形の反復)で、毎刻み世界全体を解く → 今の陽解法の数倍〜数十倍の見込み(未確認)。
- **危うさ**: 最も高い。既存の研究は浮動小数点で、エネルギーは近似か機械精度まで(§7)。整数・ビット単位の例は見つからなかった。
- **打ち切り条件**: 熱 + 1 つの反応の 2 セルの模型で、整数の離散勾配で毎刻み ΔE = 0 かつ ΔS ≥ 0 を満たす式が 2 チャットで作れなければ、
  案 C は理論の物差し(案 A の坂の検査の定義)に留める。
- **見積もり**: 模型 2 チャット。世界へ広げるのは 8〜15 チャット(読めない)。

## 4. D-467 の研究: 刻みの中で広い範囲に伝える重さ
- **今ある数**(RTX 3070 Ti。17 §6・07 §2.3・docs/perf.md):

  | 形 | 場面 | 1 刻み |
  |---|---|---|
  | 熱・陽解法の小刻み(Δkmax 3 = 64 回) | 鎖(T-0111) | 8.4 ms |
  | 熱・陰解法(GPU の段から。T-0132) | 熱い点 / 鎖 / たくさんの要求(約 2 万セル) | 1.5 / 4.2〜4.3 / 23.5 ms(多重格子の空の回の固定費 0.8〜3 ms。T-0179) |
  | 気体・本物の音速(小刻み 24。T-0226) | 32³ / 64³ | 9.6 / 73.9 ms(約 290 ns/セル) |

- **分かること**:
  - 拡散の形の坂(熱・濃さ)は、後退 Euler + 多重格子で「刻みの中で下りきる」形が既にある。費用は伝わる速さにほぼ依らず、系の大きさと多重格子の段の数で決まる見込み(未確認)。
  - 波の形の坂(圧力。慣性がある)を刻みの中で下りきらせると、圧力の投影(ポアソン方程式)か陰的な音になり、**音の前線・衝撃波が消える・ぼやける**。
    作り手から見ると「速さを最速にすると、爆風の前線は見えなくなり、圧力が一瞬で釣り合う」。小刻み(陽解法)なら前線は残るが、費用が速さに比例する。
  - 速い反応の平衡(R-REACT-1・案 B の硬さ)も同じ「刻みの中で下りきる」問題で、セルの中の小さい陰解法になる。
- **最初の計測**: 1 レベルの一様な箱で、陰解法の熱を 16³・32³・64³・128³ の系で解き、伝わる速さ(伝導率 × 1・× 10³・× 10⁶)ごとに 1 刻みの時間と
  V サイクルの回数を測る。気体の圧力は、陰解法の熱の多重格子を流用した圧力の投影の CPU 模型で、静止大気と熱い泡が今と同じに動くかを見る。
- **打ち切り条件**: 64³ の系を下りきるのが 1 刻みの予算(D-468 の数値は ⑥ で決める。仮に 4 ms)を超え、多重格子の固定費(T-0179)を削っても下がらなければ、
  「最速 = 粗いレベルで先に下りきり、細かいレベルは次の刻みで追いつく(1 刻み遅れ)」の形を作り手に見せて決めてもらう。
- **見積もり**: 2〜3 チャット(GPU の計測あり。GPU の順番待ちに入る)。

## 8. 段 0 の結果(T-0491・2026-10-15。詳しくは docs/tickets/T-0491-slope-check-gauge.md)
- 物差し: 試験 `slope_check`(tests/slope_check_test.cpp。CPU・倍精度)。物質の標準エントロピーは任意の欄 `standard_entropy_mj_per_mol_k`(ベイクは読まない)。
  反応は刻みの核をなぞって規則ごとの進行度を取り出し、S(t + 1) とビット一致を確かめてから σ = ξ · A / T を数える(気体は分圧で活量を入れる)。
- **次へ進む条件は満たした**: 燃える木箱 18000 刻みで、伝導で坂を上る面 **0**(面の σ の最小 0・流れは反対称)。坂を上る規則の一覧:
  - boudouard と mana_test_catalyzed_boudouard: 標準で 949 K 以下で坂を上る(§2.3 の見込み 980 K と符号は同じ。差は比熱一定の近似)。
  - 木箱で実際に坂を上ったのは、boudouard が **CO の多いセルで釣り合いを越えて進んだ 1645〜1738 K の 179 回**(量は小さい)。949 K 以下の 122 回は CO が少なく活量込みでは下った。
  - ほかの 5 本はどの温度でも下る。
- 段 1(T-0492)への申し送り: ΔG° のベイクの警告は boudouard の組を捕まえるが、成分しだいの行き過ぎ(一方向の規則が釣り合いの近くで生成物を作り続ける)は
  ベイクでは捕まえられないので、開発ビルドの計器(刻みごとの数え上げ)が要る。ベイクで出せるのは「|ΔG°| が小さく、成分しだいで坂を上りうる」の注意まで。
- 「燃える木箱が同じく動く」の幅(D-487 ③。仮・ユーザー未確認): 火が消える刻み 16,657 ±10 %・セルロースが 1 % 以下になる刻み 3,123 ±10 %・
  1000 K 以上のセルの最大 787(刻み 3,829)±10 %・最後の炭 67,972 mol ±5 %・最後の CO 582 mol ±25 %・最高温度 4,030.5 K ±5 %。
  気体とつなぐ(T-0493・T-0186・T-0210)と大きく外れる見込みで、その時に基準を取り直すかはユーザーが決める。
