# 24 電気と磁気(L4 詳細設計)

対応する決定: D-580(電気 = 坂を下る保存量。claude/32 S22・claude/33 S29)/ D-581(磁気は法則として持つ。S30)/ ADR-0385。
関係: 「釣り合う」家族(20・claude/34 S38)/ 刻みの順(claude/34 S42)/ 欄の持ち方(真実と導かれる値。S41)/ 温度の上限 4095 K(D-588)/ 天候の層(05 §5)/ 坂の原理(02 §5・D-466)。

**状態**: 法則の形は決定(2026-10-21 ユーザー)。**作るのは 2 周目**(体験版の作戦は電気を使わない)。形だけ先に決めたのは、後から変えると手戻りが大きいため。
研究 R-E1〜R-E4・R-M1・R-M2 の合格と打ち切り(§6)はこの文書が持ち主。費用はすべて**未確認**。

## 0. 結論(一つの芯)
1. **電気(電荷)は熱と同じ「坂を下る保存量」**。溜まると電位の坂ができ、通しやすい物を伝って坂を下る。流れる時の損は熱になる。
2. **溜まる電気も同じ形から出る**。通しにくい物の上では電荷がなかなか逃げない(静電気・コンデンサ・雲の電気)。違いは物質の「電気の通しやすさ」1 つ。
3. **破れは割れと同じ考え**: 坂(電場)が物質の「絶縁の強さ」を超えると破れて通り道ができる(火花・雷)。破れた所は熱になり、4095 K で頭打ち(D-588)。光は熱から出る。
4. **電池と電気分解は坂の原理そのもの**: 電池 = 反応の蓄えで電荷を坂の上へ押す(押す構造と同じ形)。電気分解 = 電気の仕事で反応を坂の上へ上らせる。
5. **磁気は法則として持つ**: 電流が磁場を作る・磁場が電流や磁石や鉄を押す・動く磁石や変わる磁場が電流を生む。
6. 電位と磁場は**導かれる値**(真実は電荷と、物質の磁化の値だけ。S41)。解き方は**「釣り合う」家族**(陰の圧力・支えの法則と同じ部品。20)。電気や磁気の無い所は眠る(タダ)。
7. エンジンは特定の物質(魔素を含む)を特別扱いしない。電気と結びつく物質・反応は、作り手が物質の値と反応表で書く。

## 1. 作り手から見た姿(いちばん大事)
- 書くのは**物質の値だけ**(§3)。回路の部品・電線の種類・モーターの型は書かない。電池は「電荷を押す反応」、電線は「通しやすい物」、コンデンサは「通しにくい物を挟んだ通しやすい物」として、形と素材から働く。
- 書かなければ「電気を通さない・磁気は空気と同じ」なので、電気を使わないゲームは何も書かずに今のまま動く(ブランクの世界 D-455 でも費用 0)。
- 計器: 電荷・電位・電流・磁場は、熱や圧力と同じく測れる・描ける・記録できる(D-465)。
- 出るもの: 電池・電熱・電球(熱で光る)・ショートで燃える・静電気・火花・雷・コンデンサ・電気分解(水から水素・鉱石から金属)・感電(体の中の電流が熱とダメージに)・電磁石・モーター・発電機・方位磁針・磁石どうしの引き合い。発電機を回すと、作った電気の分だけ動きが減る(帳簿で合う)。

## 2. 電気(claude/33 S29)
### 2.1 電荷と電位
- **真実は電荷**(セル・物の箱ごとの保存量。ある所にだけ持つ。S41)。電荷はどこでも厳密に保存される(面の形で、片方から出た分がもう片方に入る)。
- **電位は導かれる値**: 電荷と物質の「電気の溜めやすさ(誘電)」から、釣り合いの式(ポアソン型)を解いて出す。
- **流れ = 坂 × 通しやすさ**(20 の「面を通る流れ」と同じ形)。電位の差を面の電気の通しやすさで掛けた分が流れ、損(抵抗の熱)はその面の両側のエネルギーに入る(帳簿に載る)。
- **速さはほぼ一瞬**: 金属の中では、刻みの中で坂を下りきるまで解く(釣り合う家族の決まった回数で)。通しにくい物の上では刻みをまたいでゆっくり逃げる。どちらも同じ式で、違いは通しやすさだけ。

### 2.2 破れ(火花・雷)
- 物質ごとに「絶縁の強さ」(電場の上限)を持つ。坂がそれを超えた面は破れて通しやすくなり、電荷が一気に流れる。
- 破れは**反応の家族**で扱う(釣り合いを解く → 強さを超えた所が破れる → 次の刻みで解き直す。支えの法則の割れと同じ流れ。S38)。破れの進む速さは物質の値の速さ(claude/30 N8)。
- 枝分かれは状態だけから決まる(乱数を使うなら状態のハッシュ。決定的)。
- 破れた通り道は熱になる。熱は 4095 K で頭打ち(D-588)。強い見た目(閃光・稲妻の形)は描画が同じ状態から出してよい。

### 2.3 電池・電気分解・電熱
- **電池**: 反応の蓄え(化学のエネルギー)を使って電荷を坂の上へ押す。押す家族(筋肉・魔法の押す・機械と同じ形。02 §5)の一つで、押した仕事 = 反応で減った蓄え(帳簿が厳密に合う)。
- **電気分解**: 電流の仕事で、反応を坂の上へ上らせる(水 → 水素 + 酸素、鉱石 → 金属)。反応表の「電気の仕事を使う反応」として書く(どの反応がそうなるかは作り手の値)。
- **電熱**: 電流の損は熱。電熱線・ショートで燃える・感電(体の中の電流が体の熱とダメージに。体は普通の物質。09 §0)が同じ式から出る。

### 2.4 細い電線と触れた面
- セルより細い電線は**物**(関節の列や細かい物。08)で持ち、物の中で電荷と電位を解く(物の中で全部の家族を走らせる口。claude/34 S45)。
- 物どうし・物とセルは**触れた面**で電気を渡す。接触の通しやすさは触れ方(触れている面積・押し付け)から出る。

### 2.5 雷
- 天候の層(05 §5)が雲に電荷を入れる(世界の外から入る出入りとして帳簿に載る)。雷そのものは**世界の中で破れとして起きる**(2.2)。

## 3. 物質に書く値(足すもの。名前は仮)
| 値 | 書かなければ | 効く所 |
|---|---|---|
| 電気の通しやすさ | 通さない | 金属・水(溶けた物で変わる。混ざった所の値はエンジンの混ぜ方。claude/32 S23)・体 |
| 絶縁の強さ | 空気の値 | 火花・雷・どこで破れるか |
| 電気の溜めやすさ(誘電) | 空気の値 | コンデンサ |
| 磁気の通しやすさ | 空気の値 | 鉄が磁石に引かれる・電磁石の芯 |
| 磁石の強さ(元から持つ磁化) | 0 | 磁石・方位磁針 |
- 全部、温度の表で変えられる(claude/32 S16。熱すると磁石が弱まる、など)。
- どの値も**どの物質にも同じ意味で書ける**(エンジンは特定の物質を特別扱いしない)。

## 4. 磁気(claude/33 S30)
- **磁場は導かれる値**: 電流と、物質の磁化(磁石の強さ)・磁気の通しやすさから、釣り合う家族で解く。
- 力: 磁場が電流の流れている物・磁石・磁気を通しやすい物(鉄)を押す。力は物の物理(08。AVBD)と場へ、次の刻みの力として渡す(刻みの順 §5)。
- 誘導: 動く磁石・変わる磁場が電流を生む(発電機)。動きのエネルギーが電気のエネルギーになった分だけ動きが減る(動く磁石にブレーキがかかる)。**帳簿が厳密に合う**ことを研究の合格に入れる(R-M2)。
- **研究が落ちた時の退く道は「部品として書く」**: モーター・発電機を、電気と動きを決まった効率で変える押す構造の値として書く(作り手が扱えるが、仕組みはプレイヤーが発見する物ではなくなる)。

## 5. 刻みの中の置き場所と費用
### 5.1 刻みの順(claude/34 S42 の順の中で)
| 段 | 電気・磁気がすること |
|---|---|
| 4 押す | 電池の起電(反応の蓄えで電荷を押す)・発電機の押す側 |
| 5 釣り合う | **電位**(電荷 → 電位・電流)→ **磁場**(電流・磁石 → 磁場・力)→ 支え |
| 2 物の物理(次の刻み) | 前の刻みの磁気の力を使う |
| 9 反応 | 破れ・電気分解・電流の損を熱へ |
| 10 受け渡し | 触れた面の電荷の受け渡し・帳簿の締め |

### 5.2 どこまで解くか(眠る/起こす。claude/34 S38 の「物理の長さで閉じる」)
| 法則 | 閉じる長さ |
|---|---|
| 電位 | つながった導体の全部(回路は 1 か所のスイッチで全体が変わる)+ 電荷の多さから決まる距離(遠くでは弱まる) |
| 磁場 | 磁石・電流の強さから決まる距離(遠くでは急に弱まる) |
- 外側は前の答えのまま固定する。長さは状態だけから決まり、細かさによらない・重くても結果を変えない(D-468)。
- 電荷も磁化も無い所は眠る(電気・磁気の費用 0)。**電気のある所の費用は未確認**(R-E1 で測る)。

## 6. 研究(2 周目。どれも「2 本試してだめなら退く道」で打ち切る)

## テスト(作る時)
- 小さい回路の場面(電池・抵抗・コンデンサ・スイッチ)で CPU リファレンスとビット一致・電荷の和が刻みごとに一致。
- 0.5 m と 0.25 m の同じ回路で電流が ±1 % の内。
- 帳簿: 電池の反応で減った蓄え = 押した仕事 = 損の熱 + 溜まった電気のエネルギー(厳密)。
