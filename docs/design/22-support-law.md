## 0. 結論(一つの芯)
1. **固い物は、力が掛かると硬さでたわんで釣り合う**。たわみと中の力は「釣り合う」家族(claude/34 の 6 つの家族の一つ。陰の圧力・電位・磁場と同じ型)で解く導かれる値。
   テコが効く(曲げを持つ)・両端で支えた梁の力の分かれ方が硬さから決まる・アーチが同じ石の梁より強い、が法則から出る。
2. **割れる・曲がったまま残る・破れるは、釣り合いの解の外で「反応」の家族として起こす**(釣り合いの家族は直線の式だけを持つ)。
   割れるのは**割れた方がエネルギーの坂を下る時**(たわみに蓄えたエネルギーが、新しい割れ面を作るエネルギーを払える時。坂の原理 D-466)。割れは物質の値の速さ(m/s)で進む(刻みの中で最後まで割り切らない)。
3. **作り手が書く値は「硬さ」「押しの強さ」「引きの強さ」「ねばさ」**(+ 書かなければ導く「割れ面のエネルギー」「破片の大きさ」)。
   押しと引きに同じ値 = 強さ 1 つの物・無限 = 割れない物。**特別な仕組み(壊れない旗)は作らない**。
4. **強さ 2 つは、粒の「崩れる角度 + くっつく強さ」と同じ一つの形**(押し合い × 摩擦 + くっつく強さを超えたらずれる・割れる)。割れた岩は、くっつく強さを失った同じ物質の瓦礫(粒)になる。
5. **解き方は揺れの速さで物理的に選ぶ**: 速く小さく揺れる硬くて重い物(岩・壁・地面)は、力が変わった時だけ釣り合いを解く。遅く大きく揺れる細く柔らかい物(吊り橋・枝・板・弓)は物の物理で揺らす。分け目は秒(物理の単位)で、細かさによらない。
6. **欠片はセル以上なら物、セル未満なら粒**。セル ⇄ 物の変換は前倒しで作る(08 §8。D-567)。
7. 物質の値は**温度の表**で変えてよく、**混ざった所の値は値ごとにエンジンが物理の混ぜ方で出す**(§2。全部の値に効く約束)。

## 1. 作り手から見た姿(いちばん大事)
### 1.1 書く値(Luau。名前・単位は仮)
| 欄 | 意味 | 書かなければ |
|---|---|---|
| `stiffness_mpa` | 硬さ(力でどれだけたわむか。ヤング率) | 支えの法則に入らない(固体でも、たわまず割れない = 今と同じ。ブランクの世界は何も変わらない。D-455) |
| `compressive_strength_kpa` | 押しの強さ(押しつぶされずに耐える限界) | 引きの強さと同じ値(強さ 1 つの物)。両方無ければ無限(割れない) |
| `tensile_strength_kpa` | 引きの強さ(引っ張られて裂けずに耐える限界) | 押しの強さと同じ値 |
| `ductility` | ねばさ: 割れるまでに形が変わってよい量(0 = もろい。0〜1 の割合。仮) | 0(もろい) |
| `fracture_energy_j_per_m2` | 割れ面のエネルギー(新しい割れ面 1 m² を作る仕事) | 強さ・硬さ・破片の大きさから導く(§3.4) |
| `fragment_size_mm` | 割れた時の破片の大きさの目安 | 粒の大きさ(`grain_size` を書いた物質)。無ければベイクが警告して仮の既定(未確認。R-B4 で決める) |
- 温度で変わる物は、どの値も温度の表で書ける(§2.1)。混ざった所の値は書かない(§2.2)。
- 物か世界のセルかは**置き方で選ぶ**(ADR-0359 の塊と同じ。`world_bodies` に書けば物、`world_cells` なら据わる固体)。遅く大きく揺れる物をセルで置くと、ベイクが知らせる(§4)。

### 1.2 例(どれも作り手は値だけ書く)
```lua
species = {
  stone = { ..., phase = "solid", stiffness_mpa = 50000, compressive_strength_kpa = 100000, tensile_strength_kpa = 5000 },  -- 押しに強く引きに弱い
  iron  = { ..., phase = "solid", stiffness_mpa = 200000, compressive_strength_kpa = 250000, tensile_strength_kpa = 250000,
            ductility = 0.3,
            temperature_table = { tensile_strength_kpa = { { 300, 250000 }, { 1000, 30000 } } } },  -- 熱いと柔らかい(S16)
  ice   = { ..., phase = "solid", stiffness_mpa = 9000, compressive_strength_kpa = 5000, tensile_strength_kpa = 1000 },
}
```
- **洞窟の天井は下(引かれる側)から割れる**: 石は引きに弱いので、天井の下の面の引きの力が先に引きの強さを超える。
- **石積みのアーチと柱は長く持つ**: アーチは重さを押しの力で運ぶので、押しに強い石が効く。同じ石の真っすぐな梁は下の面が引かれて割れる。
- **鉄筋で引きを補う**: 石の下側に鉄を置くと、引きの力を鉄が持つ(つながった固い物の中の釣り合いなので、作り手は何も足さない)。
- **曲げた鉄が曲がったまま残る**: ねばい鉄は、強さを超えても割れずに形が変わったまま残り、変わった分の仕事は熱になる(帳簿に載る)。
- **割れた岩は同じ物質の瓦礫になる**: セル以上の塊は物として落ち、セル未満は同じ物質の粒になって崩れる角度で止まる(§3.5)。
- **たわみが前触れになる**: 割れる前にたわみが育つ(状態。描ける・計器で測れる)。波や揺れに頼らない。

### 1.3 書き間違い・書き忘れの知らせ(ベイク。D-487 ②)
- 気体・液体に支えの欄(誤り: 固体の欄)/ 強さを書いて硬さが無い(警告: たわまないので割れの判定ができない。硬さを書くか、強さを消す)/
  `ductility` が 0〜1 の外(誤り)/ 押しの強さ < 引きの強さ(警告: 現実の物ではまれ。意図なら消せる)/ 温度の表が温度の順でない(誤り)。
- 遅く大きく揺れる形をセルで置いた(知らせ。§4。物で置くかを選び直せる)。

## 2. 物質の欄(全部の値に効く約束)
### 2.1 温度の表(D-563・S16)
- **どの物質の値も温度で変わってよい**。温度の表(温度 K と値の組の列)で書く。書かなければ一定。相の変化(反応)とは別。
- エンジン: ベイクで物質ごと・値ごとの整数の表にし、セルの温度で区分線形に引く(表の外は端の値で止める)。CPU と GPU で同じ関数(.hlsli)。
- 熱した鉄が柔らかい・冷えた物がもろい・熱で溶ける前に弱る、が値だけで出る。対象の値は §1.1 の支えの値・摩擦のすべりやすさ・熱の通しやすさ・粘りなど全部(表を引く場所は値を読む所 1 か所)。
- 未確認: 表を引く費用(セルごと・刻みごと)。眠った所では引かない(温度が変わらないので)。

### 2.2 混ざった所の値(D-564・S23)
1 つのセル・物のボクセルに物質が混ざって入る時(土 + 水 + 空気・小麦粉 + 水・瓦礫 + 水)、その所の値は**値ごとに物理の混ぜ方をエンジンが持つ**。作り手は書かない。
| 値 | 混ぜ方(形。式の細部は未確認・試作で決める) |
|---|---|
| 熱の容量 | 足し算(量 × 比熱の和。今と同じ) |
| 熱の通しやすさ | 混ざり方の式(候補: 体積の割合の幾何平均。並べ方の上限と下限の間に入る式) |
| 粘り | 固い物の割合が増えると急に上がる式(詰まった割合に近づくと発散する形。泥がどろっとする) |
| 強さ(くっつく強さ) | 濡れの式(粒の間の水が少しあると強く、満ちるとだれる山形。湿った砂・雪が固まる) |
| 硬さ・押しの強さ・引きの強さ | 固い物の体積の割合で弱める式(孔の多い物は弱い) |
| 光の値 | 量の割合で混ぜる(描画と放射。持ち主は別の文書) |
- **混ざったら反応で別の物質にする書き方も使える**(土 + 水 → 泥)。作り手が自分で値を決めたい時。エンジンは両方を同じ物質の表で扱う。
- 粗くした箱の値も同じ決め方で出す(粗い箱 = 細かい箱が混ざった箱。claude/34 S43。20 の持ち主へ渡す)。
- 未確認: 各式を整数で決定的に、表の 1 行で書けるか。式の数が値ごとに 1 つずつ増えることの費用。

### 2.3 摩擦の値(D-565・S18。使うのは 08 §2.1)
- 物質ごとの**すべりやすさ**を 1 つ書く(`friction`。0〜。仮)。組ごとの表は作らず、**組み合わせる規則**で 2 つの物質から接触の摩擦を出す(規則は仮: 2 つの幾何平均)。
- **間に挟まった物で変わる**: 接触の所に液体・粒・溶けた水があれば、その割合で、挟まった物のすべりやすさへ寄せる(氷は、溶けた水が挟まると滑る。状態から出る)。

## 3. エンジンの側: 支えの法則
### 3.1 「釣り合う」家族の上に乗る(claude/34 S38)
- 支えの法則は「釣り合う」家族の使い手の一つ(ほかは陰の圧力・電位・磁場)。解き方・眠り方・粗くし方・細かさの約束・費用の読み方は家族で 1 回だけ作る(作るのは試作の列 1 の C-0)。
  - **世界の多重解像度の木を、そのまま多重格子の段にする**(解き方のために別の格子を作らない)。物の座標の箱でも同じ(§3.6)。
  - **決まった回数だけ解く**(回数は法則ごとに固定・場面によらない)。前の刻みの答えから始める(温めた始まり)。解けきらない場面は (a) 決まった回数のまま進み、釣り合いに数刻みかかることがある。
    **釣り合いに着くまでの刻みの数と見た目を試作で記録し、ユーザーに見せる**(S38。「酷かったらどうにかする」の判断材料)。
  - **保存は解の精度によらず厳密**: 力は面の形(片方から出た分がもう片方に入る)で出すので、解けきっていなくても運動量の帳簿は合う。残りの差は上限の計器に出す。
  - **領域は変わった所から物理の長さで閉じる**(外は前の答えのまま固定)。支えの長さは「変わった所の大きさの何倍か」(力の乱れは変わった所の大きさくらいの距離で消える)。倍率は試作で測る(未確認)。
  - 整数・決まった順・Jacobi 型の平滑化で決定的(陰の圧力 T-0845 と同じ作り)。
- 刻みの順(claude/34 S42): 5. **釣り合う**(電位 → 磁場 → **支え**: 重さ・荷重 → たわみ・力。物の中も)→ … → 9. **反応**(割れる・曲がる・破れる)→
  10. **受け渡しと締め**(物の割れ = 物を分ける・セル → 物の欠片)。割れ・曲がりが起きた所は、次の刻みの 5 で解き直す。
- 欄(claude/34 S41): **真実** = 割れの進み・ねばい物の変わった形(ある所にだけ持つ)。**導かれる値** = たわみと力(起きている所でだけ計算して持つ。眠った所は粗くして残す。使えなければ捨てる = 研究 R-F1)。

### 3.2 釣り合いの式(研究 R-B1)
- 未知数は固い物の各点のたわみ(3 成分)。荷重 = 重さ + 触れた力(物・流体の圧力の力積・荷が乗る)+ 加速の見かけの力(物の中)。
- 形の候補(R-B1 で 2 本試す。**未確認**):
  ① セルの中心を点とし、面ごとに伸び縮みとずれのばねを置く(格子のばね。横の縮み方〔ポアソン比〕は固定 = この宇宙の法則として宣言)。
  ② 六面体の要素(セル = 要素)の線形の弾性。横の縮み方は固定か値。
- **1 セルの厚さの梁・張り出しで曲げが出るか**を合格に入れる(洞窟の 1 セルの張り出しは体験版の「掘る」で一番よく出る形。① の形ではずれのばねが無いと曲げに抵抗しない。§6)。
- 据わる固体どうしのつながりは「固い物どうしが面で触れている」こと。違う物質の面は弱い方の強さ(仮)。世界の端・掘れない地面は動かない境。

### 3.3 割れる・ずれる・曲がったまま残る(反応の家族。研究 R-B2・R-B4・R-B6)
- **形は一つ**: ある面について「押し合い × 摩擦 + くっつく強さ」を超えたら、ずれる・割れる(モール・クーロンの形 + 引きの切り口)。
  - 押しの強さ σc と引きの強さ σt から、くっつく強さ c と内部の摩擦の角 φ が一つに決まる: **c = √(σc·σt) / 2、sin φ = (σc − σt) / (σc + σt)**。
    押しと引きが同じなら φ = 0(強さ 1 つの物)。粒はくっつく強さ ≈ 0・φ = 崩れる角度の同じ形(S10 の「粒と同じ一つの形」。R-B2 で確かめる)。
  - 引きの向きが引きの強さを超える = 裂ける(開く割れ)。押し合いでずれの向きが超える = 砕ける・ずれる。
- **割れるかの判定は坂の原理**(エネルギー): 割れ目を 1 面広げると解放されるたわみのエネルギー ≥ 割れ面のエネルギー × 面積 なら割れる。出るのは熱と割れ面で、帳簿に載る。
  強さ(上の形)は「どこで・どの向きに割れ始めるか」、エネルギーは「割れが進むか」を決める(細かさによらない割れのため。点の力は細かいほど大きく見えるので、強さだけで決めると細かさで変わる)。
  R-B2 は ① エネルギーの判定 ② 強さの判定 + 面のエネルギーで進み、の 2 本を試す(**未確認**)。
- **ねばい物**: 強さを超えても、ねばさの分までは割れずに形が変わったまま残る(真実「変わった形」を持つ。元の長さが変わる)。変わった分の仕事は熱になる。ねばさを使い切ったら割れる。
- **割れの速さ**: 割れは物質の値の速さ(m/s)で進み、刻みの中で最後まで割り切らない(N8)。法則の速さが 1 刻みに進める距離(Δx/Δt)を超える連鎖(岩の割れ・爆轟など)は、(a) 速さから決まる固定の小刻みで進める か (b) この宇宙の速さとして遅く定める のどちらか。**2026-10-21 ユーザー決定 D-612**: エンジンは両方できる形(割れの速さは物質の値。Δx/Δt を超える値を書いたら速さから決まる固定の小刻みで進める)。既定は (b) この宇宙の速さとして遅く定める。(a) の小刻みの費用は予算として前もって決める(D-468。ROADMAP T-0943)。
  (前の版の「どのレベルの Δx/Δt よりも遅い・既定は音の速さの割合」は食い違っていた: 岩の音速は数 km/s、0.5 m・1/60 秒の Δx/Δt は約 30 m/s。)
- **割れた面**: くっつく強さを失う(押し合いと摩擦だけが残る = 瓦礫どうし・粒と同じ)。くっつき直すのは反応で書く(焼き固まる・凍る。08 §10)。

### 3.4 既定で導く値(書けば上書き)
- **割れ面のエネルギー** G = σt² × L ÷ E(L = 破片の大きさ、E = 硬さ。仮・Claude 案)。物質の長さ L を使うので、細かさによらない大きさの効き方(大きい物ほど割れやすい)が出る。R-B2 で確かめる(**未確認**)。
- **破片の大きさ**: 書いた値 → 粒の大きさ → 仮の既定。破片の数は「割れた量 ÷ 破片の大きさ」で決まる(破片の上限の数は置かない。偽の法則になるので)。
- **瓦礫の崩れる角度**: 強さ 2 つから出る φ(書けば上書き。仮)。

### 3.5 欠片(D-566・S19)と表現が変わる時
- 割れて分かれた塊が**セル以上なら物、セル未満なら粒**(同じ物質のばらける固体。ADR-0359)。粒と物の境目は案 B の境目(粒の大きさ)と同じ線。
- **表現が変わる出来事(割れて物になる・粒になる)は、破片の大きさで決まる細かさで起こす**(粗い所で割れても、破片の大きさは箱の大きさから出さない。仮・Claude 案 claude/29 W9)。
  粗くした時も割れの進みは割れ面のエネルギーで数えるので、和で保てる見込み(claude/34 S43。R-B2)。
- 受け渡しは刻みの 10 で一度に(当てる段)・帳簿に載せる・量の持ち主は常に一人(08 §8)。

### 3.6 物の中の支え(claude/34 S45)
- 物も自分の座標の箱で同じ釣り合いを解く(座標が違うだけ。荷重 = 触れた力 + 重さ + 加速の見かけの力)。強さを超えたら割れ(刻みの 9)、物を分ける(刻みの 10)。分かれた物は次の刻みから物の物理(AVBD)に入る(08 §7)。

## 4. 揺れの分け目(D-561・S11)
- 固い物の揺れも本物の法則のまま、**解き方を揺れの速さで物理的に選ぶ**:
  | 側 | 物 | 解き方 |
  |---|---|---|
  | 硬い側 | 岩・壁・地面・太い柱(速く小さい揺れ。刻みより速く、見えない) | 釣り合いだけ解く(力が変わった時だけ。眠っている岩はタダ。前の答えから続けて解く) |
  | 柔らかい側 | 吊り橋・枝・板・弓・縄・布(遅く大きい揺れ) | 物の物理で揺らす(物の小片を柔らかい関節でつないだ列。08 §7) |
- **分け目は秒で書く**: その物の一番遅い揺れの周期(形と物質から出す。細長い物は曲げの周期)が分け目の時間より短ければ硬い側。分け目の時間は世界の定数(仮 0.1 秒・未確認。R-B5 で決める)。
  セルの大きさによらない(N4 の空気の「弱い差は揺れずに戻る」と同じ考え)。
- 決めるのは**作る時**(置き方を読む時)。作り手はセルで置くか物で置くかを選び直せる。柔らかい側の形をセルで置いた時はベイクが知らせる(その物は揺れずに釣り合うだけになる)。
- **同じ物は、どちらの側で置いても同じ強さで壊れる**(柔らかい側の関節が切れる強さは、物質の強さ × 断面から出す。R-O1)。

## 5. 退く道「重さの流れ(曲げ無し)」(一旦の決定。N7)
- 研究(R-B1〜R-B3)が打ち切りに当たったら、支えはこの形に下がる: 各つながり面が「強さ × 面積」まで重さを運び、運びきれない最小の切り口で割れる。
- 残るもの: 張り出しが重さで落ちる・大きい物ほど落ちやすい・割れが細かさによらない(面積は Δx²・重さは Δx³ で効く)。
- 失うもの: テコの効き・たわみの前触れ・アーチの得(一部)・強さ 2 つの向きの違い(押しの強さだけで運ぶ。仮)。
- 体験版の作戦は曲げを使わないので、退く道でも体験版は止まらない(claude/32 §1)。
