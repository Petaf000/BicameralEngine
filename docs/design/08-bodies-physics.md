# 08 物(Body)と物理(L4 詳細設計)

対応する決定: D-113(部品は物理として存在し、燃える・壊れる・倒れる)/ D-205(物理も含めて整数で完全一致。新しいアルゴリズムを作ってもよい)/ D-301(物は部品の集まり)/ D-302 / ADR-0002

## 目的
木・岩・建物の部品・道具・生き物の体を、反応と一緒に、機種が違っても同じ崩れ方をするように動かす。
**物理の整数化は研究**(R-PHYS)。この文書は、研究の段取りと、研究の結果に関わらず決まっている部分を書く。

## 1. データ
### 部品(Part)
| 項目 | 型 | 意味 |
|---|---|---|
| 位置 | int64 ×3 | 重心(04 の単位) |
| 回転 | int32 四元数 Q1.30 | |
| 速度・角速度 | int32 ×6 | |
| 質量・慣性 | uint64 + int32 ×6 | 成分から計算(燃えると変わる) |
| 形 | 形の ID | 下の「形」 |
| 成分 ×4・エネルギー | 05 のセルと同じ | 反応(02)で変わる |
| 物の ID | uint32 | どの物に属するか |

### 物(Body)
- 部品の集まりと、部品どうしの関節(固定・蝶番・玉)。関節には「強さ」があり、強さは両側の部品の物質と状態(焦げ・凍り・湿り)から決まる。強さを超えた力がかかると外れる(= 壊れる・倒れる)。
- 壊れ方は、ベイク時に部品に分けておいた範囲で起きる(実行中に任意の形に割らない)。細かく壊れてほしい物は、細かい部品で作る。

### 形
- 第 1 段: **球の集まり**(部品の形を半径の違う球で近似)。整数で接触判定しやすく、決定的。
- 地形との接触: 地形のセル(05)の占有から符号付き距離を整数で作り、球と当てる。
- 描画の見た目はメッシュ(10)。物理の形と見た目の形は別物。

## 2. 1 刻みの流れ(06 の段 5)
1. **広域の選別**: 部品を空間ハッシュ(整数のセル座標)に入れ、近くの組を作る。組は (小さい ID, 大きい ID) をキーに並べる(決定性)。— Work Graphs
2. **接触生成**: 組ごとに球どうし・球と地形の接触点を作る。— Work Graphs
3. **彩色**: 拘束でつながる部品を色分けする。色は ID から作る優先度(ハッシュ)で決める(Jones-Plassmann 型。実行順に依存しない)。
4. **ソルバー**: 色の順に、同じ色の部品を並列に解く。反復回数は固定。— 測って安い方(D-302)
5. **関節の破断**: 強さを超えた関節を外す。外れたら物を分ける(新しい物の ID は親の ID + 番号)。
6. **部品の眠り**: 動きが止まった部品は眠らせ、ブロックの活性(05)と同じく計算しない。

## 3. 研究 R-PHYS: 整数で決定的な剛体ソルバー
### 候補
| 段 | 方法 | 良い点 | 心配 |
|---|---|---|---|
| R-PHYS-1 | **AVBD を 64bit の固定小数点で**(拘束の硬さを反復ごとに上げる拡張ラグランジュ法を、そのまま整数に) | 論文の性質(大きな質量比・積み上げに強い)をそのまま使える | 硬さを上げていくと値の幅が 64bit を超えるおそれ。局所の 6×6 の連立方程式を整数で解く精度 |
| R-PHYS-2 | **AVBD を自前の決定的な浮動小数点(整数で実装)で** | 値の幅の問題が消える | 遅い(何倍か、未測定) |
| R-PHYS-3 | **整数に向いた新しい解き方を作る**(例: 硬さを上げる代わりに、拘束を直接満たすよう位置を投影する方式を、AVBD の頂点ブロックの形で) | 整数に最初から合わせられる。論文になり得る | 設計からやる。安定性が未知 |

### 判定の場面と基準
- 場面 A: 10 段の積み木が崩れずに立つ(60 秒)。
- 場面 B: 根元が燃えて関節が弱った木が倒れる(倒れ方が自然か)。
- 場面 C: 岩を 200 個積み上げて崩す(質量比 1:100 を含む)。
- 基準: (1) 3 場面とも発散・貫通・振動がない (2) 同じ入力で機種間ビット一致 (3) 部品 2000 個が予算内(D-209 の生き物と物理の枠。初期値 4ms / 3070 Ti)。

### 打ち切り条件
- R-PHYS-1 で基準を満たせばそれで確定。場面 A か C で発散し、原因が値の幅なら R-PHYS-2 へ。
- R-PHYS-2 で基準 (1)(2) を満たし (3) だけ満たさない場合、R-PHYS-3 を研究しつつ、R-PHYS-2 で先に進む(部品数の予算を下げる)。
- R-PHYS-3 はチャット 6 回分を上限とする。超えたら R-PHYS-2 で確定し、R-PHYS-3 は発売後の研究に回す。

## 4. 反応・場との結合(06 の段 7)
- 部品が重なるセルと、熱を伝導で受け渡す(接触面積は球の数で近似)。
- 部品の表面と空気のセルの間で、反応に使う物質(酸素など)と生成物(煙など)を受け渡す。
- 燃えて部品の質量が減ったら、慣性を計算し直す。質量が 0 になった部品は消える(物の分割と同じ ID 規則)。
- 部品が水のセルに入ったら浮力と抵抗を受ける(水の量はセルから引かない。押しのけは第 2 段)。

## 5. 生き物の体(09 とつなぐ)
- 生き物・プレイヤーの体も部品と関節(ラグドール)。アニメーション(09)が関節の目標角度を出し、ソルバーがそこへ近づける。
- 体の部品も燃える・凍る・壊れる(D-113)。

## テスト
- 3 場面(A・B・C)をテストにする: CPU リファレンスとのビット一致、2 回走らせての一致、保存量(運動量は外力を除いて)の確認。
