## 0. 結論(一つの芯)
1. **動くものはすべて「相ごとの面の運動量 + 共有の圧力 + 相どうしの引きずり + 物質ごとの押し返し方」の一つの式で動く**(6 つの家族の「運ぶ(勢いを持つ流れ)」)。
   動く相は気体・液体・粒の 3 つで、式の形は同じ。違うのは押し返し方だけ(気体は縮めると押し返す・液体は硬く粘る・粒は詰まった時だけ押し返し、崩れる角度とくっつく強さで止まる)。
2. **速さの決まった相も同じ式に入る**: 据わる固体(速さ 0)と物(物理が決める速さ)。染みる・押しのける/押される・扉が部屋を閉じる・浮く・流される、は
   「決まった相との引きずり」と「塞ぐ面」から出る。物専用の流れの式は作らない。
3. **圧力はセルに 1 つで、全部の相が共有する**。解き方は**床**: 本物の音速のまま 1 刻み 1 回の陰の解き方(釣り合う家族)。強い差の所(衝撃の区)だけ陽。
   弱い差は揺れずに、世界のデータで決まった時間で釣り合いに戻る(法則の宣言)。**引きずりは圧力と一緒に解く**。
4. **粒は詰まった時だけ圧力に入る**(詰まりを超えた分だけ押し返す)。舞う粉・落ちる砂は引きずりと重さだけで動く。
5. **熱の伝導・混ざる・濡れの染み込みは「広がる」家族、燃える・相変化は「反応」家族のまま**。配管は全家族で共有。
6. **端数は家族で分ける**(運ぶ = 面の持ち越し + 順番 / 広がる = 決まった乱数の丸め)。合格は「ほぼ止まる」で、眠らせるのは止まりかけの粗視化(T-0833。B の合格に必須)。
7. **作り手が新しく覚える値は粒の 3 つ(大きさ・くっつく強さ・詰まり)だけ**。引きずりの係数・浸食のしきい値・孔の通しやすさ・終端の速さ・表面積は今ある欄から導く。

### 1.2 書き方の例(専用の法則は 0 本。物質の値だけで起きる)
**例 1 砂山が崩れる・掘ると崩れる・勢いで走る**
```lua
species = {
  sand  = { ..., phase = "solid", grain_size_um = 300, repose_angle_deg = 34, density_kg_per_m3 = 2650 },
  stone = { ..., phase = "solid", density_kg_per_m3 = 2600 },          -- 粒の大きさが無い = 据わる
}
```
- 粒の密度は粒そのもの(砂 2650)を書く。**積もった密度は導かれる値**(粒の密度 × 詰まり `packed_fraction_pct`。詰まり 60 % の砂は 1590。D-613)。
- 横の面の押し合いが tan 34° を超えた分だけ運動量になる。止まる所では摩擦が面の運動量をちょうど 0 にする。山は「ほぼ止まり」、T-0833 で眠る。
- 下を消すと勢いで少し行き過ぎて、また 34° に戻る。

**例 2 砂の堤に水を流して決壊(浸食は 2 周目。§2.6)**
- 水は砂の孔へ染みる(粒の大きさから出る Darcy)。半分濡れた砂は吸い上げでくっつき、満ちた所は崩れやすい(§2.5)。
- 越えた水が面の剪断で粒を削り、溝が広がって決壊する。運ばれた砂は遅い所に積もる。

**例 3 泥流**
```lua
species = { soil = { ..., phase = "solid", grain_size_um = 20, repose_angle_deg = 30, density_kg_per_m3 = 2650,
                     cohesion_pa = 5000, suction_pa = 30000 } }
```
- 細かい土は水との引きずりがとても強い。満ちると、水と土が一緒に「重くて粘る流れ」になる。水が抜けると止まる。

**例 4 雪崩**
```lua
species = { snow = { ..., phase = "solid", grain_size_um = 1000, repose_angle_deg = 40, density_kg_per_m3 = 917, cohesion_pa = 1500 } }  -- 粒(氷)そのもの。積もった雪は詰まりから導く
```
- くっつく強さで少し急でも保ち、爆発や掘削で超えると流れ出し、勢いで平地まで走る。板のように割れて滑る雪は 0.5 m では出ない(物にした時だけ)。

**例 5 鍋の水をこぼす・汲む・沸かす(A4・D-553)**
```lua
world_bodies = { pot = { size_mm = { 300, 200, 300 }, fill_umol = { iron = ... }, held_umol = { water = ... } } }
```
- 器の中の水は物の中身として一緒に動き、器の中でセルと同じ反応で沸く。
- 傾けると、縁を超えた分だけ縁の低い所のセルへ、物の速さを持った液体として出る(こぼす口)。
- 口が水面の下にある時だけ、器の残りの体積まで入る(汲む口。こぼす口の逆向き)。どちらも帳簿の「物との受け渡し」。

**例 6 サイフォン**
- 逆 U の石の管を水で満たす。頂上の圧力は大気より低くなれる(共有の圧力は大気との差なので負になれる)。出口の側の柱が重いので流れ続け、頂上が約 10 m を超えると真空になって切れる。

**例 7 衝撃の区と弱い差(S7)**
```lua
environment = { shock_zone_pa = 10000, pressure_relax_ms_per_m = 3 }   -- 既定と同じ。書かなくてよい
```
- 爆発の圧力の差は区に入り、衝撃の輪が音速で走る(手前の木から順に倒れる)。扉を閉める程度の差は区に入らず、揺れずに戻る(扉は 1 回戻って止まる)。

## 2. エンジンの芯

### 2.1 相と持ち主
| 相 | 中身 | 速さ | 押し返し方 |
|---|---|---|---|
| 気体 | phase = gas | 面の運動量 ×3 | 状態式・粘り |
| 液体 | phase = liquid | 面の運動量 ×3 | 硬さ(縮みにくさ)・粘り |
| 粒 | solid + 粒の大きさ | 面の運動量 ×3 | 詰まった時だけの押し合い・崩れる角度・くっつく強さ |
| 据わる固体 | solid(粒の大きさ無し) | 0 と決まっている | 引きずりの相手 |
| 物 | 物のボクセル(T-0820) | 物理が決める | 力積を物へ返す |
- 相変化 = 物質が、相の間を運動量ごと移ること(反応の家族が量を移し、運動量は運ぶ家族の欄で付いて行く)。

### 2.2 運動量の置き場
| 案 | 置き場 | 良い | 悪い |
|---|---|---|---|
| **① 相ごとの面 ×3【採る】** | 面の欄 9(+ 端数 9・前の質量 3) | 今の液体の形のまま。市松が出ない。降伏・浸食・塞ぐ面が「面の量」で書ける | 欄が多い |
| ② 相ごとのセル ×3 | セル 9 | 今の気体の形 | 市松の補正が要る。降伏を面で切れない |
| ③ 混ざった運動量 ×3 | 3 | 最少 | 水の下で止まった砂を表せない |
| **④ 粒だけ別 + 気体と液体は混ざった運動量【費用の退く道】** | 6 | ① の 2/3 | 水面の風と静かな水が引きずり合う |
- 単位は、全相の面の運動量を今の気体の単位(mg·2^-20 m/s・int64)に揃える。
- **持つのは真実だけ**(claude/34 S41): 面の運動量は真実で、**起きている所にだけ**持つ(眠った所は持たない = 0 として扱う)。圧力・温度は導かれる値。
- 欄の見積もり: 1 セル約 120 B(未確認。測りの M-0 で「真実だけ」の形で見積もり直す)。

### 2.3 共有の圧力
**床(案 A でも B でも共通。Q1・Q1b・N4・S7。D-559)**
- 圧力はセルに 1 つ。**本物の音速のまま、1 刻み 1 回の陰の解き方**(後退 Euler)。押し出す仕事は**刻みの終わりの温度**で数える(Q1b。今の陽の解き方〔GPU も〕にも入れる。基準の値は取り直す)。
  解くのは釣り合う家族の共通部品(C-0。世界の多重解像度の木をそのまま多重格子の段にする・決まった回数・整数・面の形で保存が厳密)。
- **強い差の所(衝撃の区)だけ陽**(今の陽解法の小刻み)。区の条件は物理の量と長さ(Pa・m/s・m)で書き、世界のデータ(S7・§1.1)。
  熱の出は「音の時間で圧力が立ち上がる速さ」で切り、ふつうの炎は区に入らない形にする(炎が入らないかは測る。未確認)。**液体は衝撃の区でも陰**。
- **弱い差は揺れずに、決まった時間で釣り合いに戻る**(N4。この宇宙の法則の宣言)。戻る時間は m・秒の値で世界のデータ(S7)。どのレベルでも過減衰の側にそろえる
  (要るなら物理の減衰の項を足す)。だから、閉じた空気で扉は 1 回戻って止まる・こだまは弱い(Q1c)。圧力の波を保つ研究(T-0846・T-0847)は打ち切り済みで、
  遊びで要ると分かったら再開する。
- **陰の圧力は物理の長さで閉じる**: 起こす余白を c·Δt(約 6 m)の倍数で決め、区画を縮めるのは完全に閉じた区画だけ。眠らせても結果が変わらないための形。
- **物は系に係数と右辺だけで入れる**。系の形(つながり)は完全に塞がった/開いた時だけ変える。軽い物(扉・板)は物の速さを圧力と一緒に解く。
- 陽(区)と陰の釣り合いの差(数 %)は、区の境目をまたぐ煙の柱の速さで測る(床の試験。案 B の判定の外)。
- 測り済み(気体だけ): 小さい空きで発散しない(T-0842)・64³ で 20〜23 ns/セル・CPU とビット一致(T-0845)。陽の小刻みは約 285 ns/セル。
- 経緯: claude/28 は共有の圧力を音速の小刻み(陽)で解き、予備(R1b)を「気体は今の陽解法」としていたが、Q1 で陰が床になり、予備の方が 10 倍重い逆さまの木になった。
  §5 の判定の木はこれを直した形(S6)。前の一旦の決定「液体の人工の音速は気体と同じ頭打ち」も取り下げ(液体の硬さは R1 の賭けと液体の段で決める)。

**案 B の圧力の中身**
**圧力 = 柱の重さ + 縮みの分**
- **柱の重さ**: 混ざった密度の柱を 1 回の走査で作る。各相の重さとちょうど打ち消し合う形で書くので、静かな池・空・砂は整数で力が 0 になる(ADR-0341・0339 の教訓)。
- **縮みの分**: 1 つの関数 `CellPressure`(仮名)で、セルごとの局所の状態式から出す。
  - 気体は理想気体(体積 = セル − 液体 − 詰まった粒 − 物)。
  - 液体は硬さで押し返す(本物の硬さ。空気と 4 桁違う。**R1 の一番の賭け**。落ちたら液体の段 §5.1)。
  - **粒は詰まり(`packed_fraction_pct`)を超えた分だけ押し返す**(B-b)。詰まっていない粒(舞う粉・落ちる砂)は圧力を持たず、引きずりと重さだけで動く。
  - 真空は p = 0。圧力は大気との差として負になれる(サイフォン)。
- **引きずりは圧力と一緒に解く**(B-a。D-556): 面ごとに相どうしの引きずりの小さな連立を先に消去し、各相が圧力の坂にどう応えるかを出してから、それで圧力の式を組む
  (多流体でふつうの形。IMF・部分消去の型)。分けて解く(圧力 → 引きずり)と、強い引きずり(泥・砂の中の水)で染みる速さが刻みの長さで変わるので採らない。
  費用は面ごとの小さな連立が増えるだけの見込み(未確認。M1 で測る)。
- 衝撃の区の中は陽の小刻みで、区の中の相の扱いは気体だけ(液体は区でも陰・粒は区に入らない)。

- 硬い所は「一緒に動く」に収まる。1 滴・1 粒は自然に終端の速さで動く(相が消える所の芯)。

### 2.5 粒の降伏・くっつく強さ・濡れ
- 詰まった粒だけが、上の粒の「浮力を引いた重さ」を柱で支える(有効応力の形。満ちると押し合いが減る = 液状化・泥流の芯)。
- 摩擦の上限: τ_max = tan θ × 押し合い × A + c_eff × A。力の和が上限以下なら面の運動量をちょうど 0 にする。超えた分だけ動く。
  しきい値が Δx に比例するので、細かさによらない見込み(R3)。降伏の後の運動量は持ち越す(雪崩が走る)。
- くっつく強さ: c_eff = cohesion + suction × 4S(1−S)(S = 孔の満ち具合。半分濡れた時に最大)。
- **濡れは新しい欄ではなく、孔の中の水の量**(S17・claude/34 S41)。孔の満ち具合 S は粒だけでなく、**孔のある全部の物**(据わる固体のセル・物のボクセル)で同じ関数で数える。
  染み込みは「流体 ↔ 孔」の引きずり(§2.4。動く水)と、広がる家族の染み込み(吸い上げ・`suction_pa`)の 2 つの道で、どちらも同じ S を読む。
  濡れた物が燃えにくい・冷える・強さが変わるは、孔の水の熱容量・蒸発(反応)・混ざった所の値の決め方(claude/32 S23)から出る(濡れ専用の規則は書かない)。
- 粒は、固い物の「押しの強さ + 引きの強さ」(支えの法則)と同じ一つの形(押し合い × 摩擦 + くっつく強さを超えたら動く・割れる)に収める見込み(支えの法則の研究 R-B2 で確かめる)。
- **混ざった粒**(S9): 1 セルの粒の詰まり・崩れる角度・くっつく強さは体積の割合で平均(エンジンの混ぜ方)。締まる形に替えられる口(混ぜ方の関数を 1 か所に置く)を残す。
- (2026-10-21 本体のマージで T-0870 の渡し物を当てた)粒の「崩れる角度 + くっつく強さ」は、固い物の強さ 2 つと一つの形(c = √(σc·σt)/2・sin φ = (σc − σt)/(σc + σt)。22 §3.3)。
  粒と物の境目(粒の大きさ)と欠片の線(D-566)は同じこと。濡れの式(くっつく強さの山形)は混ざった所の値(ADR-0380・22 §2.2)と同じもの。混ぜ方の関数の置き場は 22 §2.2 に一つ。

### 2.6 浸食の面の剪断(A9。**2 周目**)
- 横の面の流体が、下の詰まった粒の面を引きずる項を 1 本足す。剪断 τ_b = C_f ρ |u| u(C_f ≈ 0.003)、しきい値は Shields の形(θ_c ≈ 0.05)+ くっつく強さ。
- 超えた分の運動量を粒へ移す(和は保存)。削られた粒は散らばって運ばれ、遅い所に積もる。風が砂を巻き上げるのも同じ項。
- **案 B の判定から外す**(S6・一旦。体験版に要らない)。2 周目の入る口で確かめる(R5)。D-525 B「最初の版は押さない」は A9 で読み替え済み。

### 2.7 物を速さの決まった相に・塞ぐ面(A5)・穴の大きさ(S8)
- 入力は、占める体積(T-0820)と ★面を塞ぐ割合(+ 側 3 面ごとに 4×4 点を数える)。表面の細かい形(約 2 cm〜0.5 m。claude/34 S44)も、法則へは同じ「面の開き具合」で効く。
- 各相の面の流れは、開いた割合 ×(1 − 塞ぐ割合)だけ通る。塞いだ部分の速さは、物の面に垂直な速さになる。
- 力は壁の力積の列(ADR-0360 §4)から物へ返す。浮く・沈む・流される・扉・水車・泳ぐが、この 1 つの道から出る。据わる固体も「速さ 0 の決まった相」として同じ道を通る。
- 1 刻み遅れの陽の力積で始め、暴れたら付加質量を足す(軽い物は §2.3 のとおり圧力と一緒に解く)。
- **穴の大きさ**(S8): 塞ぐ面に `hole_size_um` を 1 つ持たせる(既定は形から導く)。粒の相の面の流れは、粒の大きさ ÷ 穴の大きさが `grain_pass_ratio_pct` より大きいと通らない。
  気体・液体は今の開いた割合のまま通る。**1 周目は欄・読み込み・既定・計器だけ**(通る/詰まるの計算は 2 周目)。

### 2.8 器の中身・こぼす口・汲む口(A4・D-553)
- 器 1 つの中身(物質の量・エネルギー)を、物の帳簿で持つ。反応と熱は、セルと同じ関数を呼ぶ。
- こぼす口: 縁を超えた分を、縁の低い点のセルへ出す(物 → セル)。汲む口: 口が水面の下にある時だけ、器の残りの体積まで入る(セル → 物)。どちらも帳簿の「物との受け渡し」。
- 器の形(口の位置・高さ)の書き方は 08 で未定(08 §11)。器の中を細かい場にするのは料理の芯の R7(§2.15)。

### 2.9 押す 2 形(A6)
- (a) 物質を押す: 今の machines。運動量ごと運ぶ。
- (b) 勢いに力を足す: `push = "momentum:<相>"`。費用は仕事(力 × 速さ)を蓄えから払う。反作用は押した体・道具へ返る(反動)。押した後も勢いで進む。

### 2.10 端数(A7。D-528 の決め直し)
- **運ぶ家族**: 面ごとの持ち越し + 順番(ADR-0357 を全相へ)。今の気体の質量の乱数の丸めは、これに置き換わる(気体の値は端数の大きさで変わる。R1 で測る)。
- **広がる家族**: 決まった乱数(場所・刻み・家族のハッシュ)で丸める。平均で正しい・欄が要らない・差のある所だけわずかにまだら。B と独立に今すぐ作れる。

### 2.11 眠る/起こす(A8)
- 合格は「ほぼ止まる」。目安(仮): 60 秒後に動く面が 1 % 未満・最大の速さが 1 mm/s 未満。
- 静止の丸め(D-516)を全相に。柱の釣り合いと降伏の「ちょうど 0」が、止まりやすさの芯。
- 残るわずかな揺れは、**止まりかけの粗視化(T-0833)で眠らせる。B の合格に必須**。液体の離散の坂(ADR-0341)を残すかは R1 で測る。
- D-527 (a) はそのまま(眠った所の静水の壁の力積を控えて足す)。眠った所の導かれる値(圧力)は「粗くして残す」(claude/34 S41。使えなければ捨てる)。

### 2.12 粗くする = 混ぜること(claude/34 S43)
- 粗い箱の真実(相ごとの質量・面の運動量)は細かい箱の真実の和。粗い面 = 細かい面 4 つの和。消えた運動のエネルギーは熱へ。
- 導かれる値(詰まり・崩れる角度・孔の通しやすさ)は、混ざった所の値の決め方(§2.5・claude/32 S23)で出す。粗くするための別の規則を作らない。
- 降伏のしきい値は Δx に比例、引きずりは単位体積あたり、浸食は 2 乗の形なので、レベルの係数なしで細かさによらない見込み(R3)。細かくした時の内側の新しい面は研究のまま。

### 2.15 料理と細かい物の芯(claude/27 §6・C1〜C6。D-557)
**芯**(C1): 世界にあるのは「物質と熱が入った小さな箱」だけ。箱は**地面に固定された座標**か**物と一緒に動く座標**の木に載り、どちらの木にも**固まった箱(骨格)**と**流れる箱**がある。
- 骨格は座標と一緒に動く(地面は速さ 0、物は剛体 AVBD)。流れる箱(気体・液体・粒)は、その座標の骨格に対してこの文書の同じ式で流れる。座標の加速・回転は見かけの力として一様に足す。
- 座標をまたぐ箱どうしは「対の面」で受け渡す(セル ⇄ 物・物 ⇄ 物・器 ⇄ 世界)。**物の中でも 6 つの家族を同じ関数で走らせる**(claude/34 S45)。
- 形が変わる = 結びつきの強さを超えて骨格の箱が粒になる(割れる・すりつぶす・煮崩れ)。くっつく粒は形を保ったまま押されて形を変える(生地・粘土)。3 つ目の動き方(MPM)は作らない。
- 細かくもできる・粗く組むこともできる(作り手が物ごとに箱の大きさを選ぶ)。法則は箱の大きさを知らない・帳簿は同じ・粗く書いた物も同じ向きに進む。
  粗く書いた物は見分けられる別の種類として書く(Q5。土台の側)。

**液体の段**(R1 が落ちた時の順。S6):
- (2) **液体の音の速さを下げる**(この宇宙の水の硬さとして宣言。どの細かさでも同じ値)。見た目はほぼ変わらない見込み(水は 10 m で 0.1 % ほど縮むだけ)。水中の衝撃・水撃の伝わりが遅くなる。
- (1) **解く回数を増やす**(V サイクル 2 → 4 など)。法則は変わらない。費用だけ増える。**(2) と (1) は同じ研究(R1 の 2 本目)の中で両方測る**。
- (3) **液体の縮まない分を別に解き、境目で受け渡す**(圧力が 2 つ)。閉じた空気の下の水位・水の中の閉じた空気の縮み方がずれる。粒は液体側に乗る。気体と粒の共有は残る(案 B の半分)。
- (3) でも液体が合格の範囲に入らなければ、液体は案 A(司令塔とユーザーに上げる)。

**全体の打ち切り(案 A に戻す)**: R3 が 2 本で不成立 / R2 が 2 本で不成立 / R1 が液体の段 (3) まで落ちても液体が範囲に入らない。
