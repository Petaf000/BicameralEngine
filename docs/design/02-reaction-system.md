# 02 反応システム(Chemical Circuit)

## 位置づけ
BotW の化学エンジン(属性の伝播ルール)を GPU に置き、規模と深さの制約を外したもの。
「ゲームロジック全般の DSL」ではなく**「化学反応則の DSL」**。会話や逐次的な処理を同じ仕組みで書こうとしない。

## モデル
- 世界はノードの集合。ノードは素材トークン(木・金属・水…)と状態量(温度・湿り気…)を持つ。
- 反応則 = Circuit Table(Read-Only StructuredBuffer)。「入力トークン × 条件 → 出力トークン・状態変化・シグナル」の表。
- 反応則は Luau で書き、エディタがベイクしてテーブルにする(Luau はロード時にテーブルを手続き的に作るために使う)。
- 魔法 = テーブルへのパッチ:
  - 触媒: 反応の閾値を下げる / 阻害: 反応を止める / 転換: トークンの種類を変える / 増幅: 出力量を増やす

## 伝播
- 世代同期: 前世代の状態を読み、次世代に書く。60fps なら 1 秒で 60 段。粉塵爆発の演出にも足りる見込み。
- 活性ノードだけが次世代の処理を起動する(Work Graphs)。燃えている分だけ計算する。
- 同じ入力・同じシードで同じ結果(ADR-0003 提案中)。これが無いとプレイヤーが実験を信頼できず、デバッグもできない。

## 反応表の設計基準(= ゲームの面白さ)
1. 予測可能性: 同じ条件で同じ結果
2. 部分的な規則性: 系統ごとの振る舞い(法則を見つけられる)
3. 例外: 意図して置く「なぜかこれだけ違う」
4. 合成可能性: 単純な規則の組み合わせで想定外の結果が出る

## 検証
- すべての反応カーネルに CPU リファレンス実装(エディタ側の評価器と共用)を付け、小さい盤面で一致を確かめる。
- 保存則(トークンが勝手に増えない)のチェックをデバッグビルドに入れる。
