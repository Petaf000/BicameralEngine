## 0. 結論(一つの芯)
1. **世界の真実は「真実の欄」だけ**: 物質の量(濡れの水・匂い・魔素も物質)・エネルギー・勢い(起きている所だけ)・電荷・割れの進み・ねばい物の変わった形(どれも、ある所にだけ持つ)。
   圧力・たわみと力・電位と電流・磁場・放射の場・温度は**導かれる値**で、起きている所でだけ計算して持ち、眠った所は粗くして残す(§10。D-542)。
2. **法則は数学の型で 6 つの家族に分ける**(運ぶ・広がる・釣り合う・まっすぐ運ぶ・反応・押す。§8。D-540)。新しい法則は必ずどれかに入れる。
   家族ごとに、解き方・眠り方・粗くし方・細かさの約束・費用の読み方を **1 回だけ**作る。どの家族にも入らない法則が出たら、それが本当の新しい形として司令塔とユーザーへ上げる。
3. **配管は全家族で共有**: 登録(§2.1)・見立て(§2.2)・面の帳簿と当てる段(§2.4)・刻みの順(§2.5)・活性(眠る/起こす。§2.6)・欄の持ち方(§10)。
4. **保存は面の形で厳密**: 流れも力も「片方から出た分がもう片方に入る」面の値で出す。解き方の精度(残差)は保存に効かず、計器に出るだけ(§9)。
5. **粗さは局所の状態だけで、いつも同じ規則で選ぶ**(N1。予算は理由にならない)。**粗くすること = 混ぜること**(粗い箱は細かい箱が混ざった箱。§11。D-544)。
6. **地面の並びと物の並び**: どちらにも固まった箱(骨格)と流れる箱があり、6 つの家族は同じ関数をどちらでも走らせる(§12。D-545)。
7. **連鎖は法則が持つ速さ(m/s)で伝わり、1 刻みの中で最後まで回さない**(N8)。GPU は **Compute を既定**、Work Graphs は測って速い所だけ(§2.7。D-546)。
8. 式は共有 .hlsli の 1 つの源を CPU と GPU が呼ぶ(二重書き 0)。CPU と GPU のビット一致は試験で確かめる。

### 1.2 書かなくてよくなるもの
- **区画の箱**(gas_regions・liquid_regions。ADR-0310 と Q109 は取り下げ。D-510): 「1 つまで・64³ の中・大気が要る・重力が要る・面が軸ごと・川が流れ続けない」が全部消える。
  流れは「その相の物質と坂がある所」ならどこでも起きる。外との境は**世界の端**だけ(物理として書く: 空は開く・地の底は閉じる)。T-0697 の「区画の箱が火の越え方を決めていた」が根から消える。
- **熱の倍率**(D-511): 気体がどこでも流れるので、熱い気体の上昇(対流)が倍率の代わりをする。物質ごとに掛ける・掛けないを決める手間・二重の数えが消える。
  無風の平地で倍率なしに火が広がるかは未確認(段 5 で測る。放射は D-570 で法則〔まっすぐ運ぶ家族〕に入ったので、広がらなければ草の値を決める。D-511 (a) の読み替え)。
- **相の二重**(D-512): `condensed` は読み込みで `phase` に読み替えて警告(後で消す)。坂の計器も相の表 1 つを読む。
- **器とインライン 8**: 当てる段が溢れのセル(R-MULTI-4。MR は既にある)へ書き、気体の器 2^31 は見立ての式を広げて無くす見込み(未確認)。作り手は数を覚えず、当たれば計器に出る。
- **液体の摩擦の区画の設定・孔は空きだけ**: 物質の値(粘り・孔)になる。**閉じた空気が水を押さない**(T-0618): 液体の坂に同じセルの気体の圧力が入る(見立てに両方ある)ので消える。
- **区画のある世界のホットリロードの断り**(T-0670): 状態はセルと登録の欄だけなので、物質・環境の値を変えても見立てを作り直すだけで当たる。
- 残る制限(作り手に見える): 反応の形の上限・4095 K・釣り合いの書き方・物の材料・1 刻みの費用(計器で見える。§2.6)。

### 1.3 遊びの例 5 つ(作り手が書く Luau。`...` は今と同じ欄)
**例 1 草原の延焼と川(水が熱を吸う・湯気・岸が湿る)**
```lua
species = {
  grass = { ..., phase = "solid", density_kg_per_m3 = 300, thermal_conductivity_mw_per_m_k = 120,
            permeability_um2 = 1000, suction_pa = 2000 },          -- 隙間だらけで、水を少し吸う
  sand  = { ..., phase = "solid", density_kg_per_m3 = 1600, permeability_um2 = 10, suction_pa = 5000 },
  water = { ..., phase = "liquid", density_kg_per_m3 = 1000, viscosity_upa_s = 890 },
  water_vapor = { ..., diffusivity_mm2_per_s = 25 },             -- phase なし = 気体
}
reactions = { boil = { reactants = { water = 1 }, products = { water_vapor = 1 }, rate = { a = 60, activation_energy_j_per_mol = 0 },
                       balance = { temperature_mk = 373150, enthalpy_j_per_mol = 40660, concentration_mol_per_m3 = "32.6" } } }
environment = { ..., world_edges = { top = "open", sides = "open", bottom = "wall" } }
world_cells = { river = { layer = 2, min_cell = { 40, 1, 0 }, size_cells = { 4, 4, 64 }, amounts_umol = { water = 6917000000 } } }
```
- 動く道(エンジンを書き換えない): 燃えた所の熱い気体が上がり、まわりの冷たい空気が流れ込む(気体の流れ。区画なし)→ 川の水面は資料の伝導率なので水面が先に熱くなり沸く(釣り合いの規則。D-504)
  → 湯気は気体として上がって混ざる。川の水は砂と草の孔へ吸い上げで染み(液体の流れの坂に吸い上げ・摩擦に孔)→ 湿った岸の草は水を沸かしきるまで燃えない。
  「川が土の帯より強く止める」は、川と草と砂の値だけで決まる(作戦専用の法則 0)。
- 土台の外で要るもの: 無風で平らな草原で倍率なしに火が広がるかは未確認(放射は D-570 でまっすぐ運ぶ家族に入った〔23〕。D-511 で段 5 に測る)。風で越えるかは天候の段の後。

**例 2 密室の火とバックドラフト**
```lua
reactions = { co_burn = { reactants = { carbon_monoxide = 2, oxygen = 1 }, products = { carbon_dioxide = 2 },
                          rate = { a = "1e10", activation_energy_j_per_mol = 125000 } } }   -- 足すのはこの 1 本
world_cells = { walls = { layer = 1, min_cell = { 20, 1, 20 }, size_cells = { 10, 6, 10 }, shell_cells = 1, amounts_umol = { stone = ... } },
                door  = { layer = 2, min_cell = { 24, 1, 20 }, size_cells = { 2, 4, 1 }, amounts_umol = { wood = ... } } }
```
- 動く道: 酸素切れ・CO の溜まりは今も書けて動く。扉のセルを消す(コマンド)と、外の冷たく重い空気と中の熱く軽い気体が密度と圧力の坂で入れ替わり(区画なし・世界のどこでも)、CO と O2 が出会って燃える。
- 土台の外: 扉を物として書き、圧力が扉を押す(物 ↔ 場の力積。§4 の物理)・速い反応の細分(D-502)・4095 K の頭打ち。

**例 3 湖を凍らせる・氷が溶けて流れる・池を抜く**
```lua
environment = { ..., atmosphere_temperature_mk = 253150, world_edges = { top = "open", sides = "open", bottom = "wall" } }
reactions = { freeze = { reactants = { water = 1 }, products = { ice = 1 }, rate = { a = 60, activation_energy_j_per_mol = 0 },
                         balance = { temperature_mk = 273150, enthalpy_j_per_mol = -6010 } } }
```
- 動く道: 冷たい大気が水面を冷やし(気体の流れ + 伝導。水面で温まった空気は上がり、冷たい空気が入れ替わる)、水面から凍る。溶けた水は液体の流れでどこでも流れる(区画なし)。
  堤のセルを消すと水は低い方へ流れ、開いた横の端から世界の外へ出る(帳簿の「世界の端」の列)。
- 土台の外: 氷の塊が浮く・砂が崩れる(固体のセルは動かない。→ §7: ばらける固体の流れ〔T-0797〕と物〔ADR-0360〕)。風が水面を冷やす速さは天候の段の後。

**例 4 ポンプ・水車**
```lua
machines = { hand_pump = { store = "work", push = "species:water", coupling = "0.9", cost_j_per_mol = 20, speed_w = 200 } }
machine_sites = { well = { machine = "hand_pump", from_cell = { 10, 2, 10 }, to_cell = { 10, 8, 10 }, store_j = 50000 } }  -- 仮(T-0555)
```
- 動く道: 置いた機械は「離れた 2 つのセルをつなぐ面(対)」として面の帳簿に流れを書く(出ていく上限・器・帳簿は当てる段が同じく)。押すのが液体でも気体でも同じ(相を知らない)。
- 土台の外: 水車 = 液体の面の運動量 → 物の回転(物 ↔ 場の力積の列を物へ回す。§4)。

**例 5 新しい架空の物質(霧が岩からゆっくり染み出す・押される)**
```lua
elements = { Xa = { atomic_mass_mg_per_mol = 7000 } }
species = {
  drift_mist = { composition = { Xa = 1 }, formation_enthalpy_j_per_mol = 50000, heat_capacity_mj_per_mol_k = 30000,
                 thermal_conductivity_mw_per_m_k = 20, diffusivity_mm2_per_s = 5 },                 -- 漂って混ざる気体
```

  **エンジンを書き換えずに、データだけで「気体のように流れる・染み出す・押される」**(試金石)。必要なものは全部、相 1 本と 4 つの任意の値。

### 1.4 書き間違い・書き忘れの知らせ
- **ベイク**(誤りは名前付きで止める・あやしいのは警告して動かす。D-487 ②): 液体に密度が無い(誤り)・液体に粘りが無い / 固体に密度が無い(警告)・
  気体に孔や吸い上げ(誤り: 固体の欄)・`condensed` と `phase` の食い違い(誤り)・液体があるのに重力 0(警告「溜まらない」)・世界の端が全部 wall で大気が無い(注意)。
- **上限の計器 1 つ**(開発ビルド・エディタのパネル): 流れの種類 × 理由(出ていく上限・入る上限〔器〕・溢れのセル・D-502 の解く回数・音速/速さの頭打ち・静止の丸め)× 場所(ブロック)の回数と量。
  今は仕組みごとにばらばらの数・ログ。当てる段が 1 つなので、計器も 1 つで全種類を数える。
- **費用の計器**: 流れの種類ごとの活性のブロック数 × 小刻み・1 刻みの時間。D-468 の予算を超えたら警告(作り手は箱の大きさではなく現象の大きさで見る)。
- **遊びの指標の量を増やす**(面の帳簿があるので一般に測れる): 面を通った量(川を渡った水・扉を抜けた CO)・最大圧力・液面・濡れたセルの数。
- **影響の見える化(D-482 ①)の元**: 各流れの種類は「読む物質の欄」を宣言するので、「この値はどの流れに効くか」をエディタが自動で出せる。
- **釣り合いの残差**(2026-10-21 追加。§9): 釣り合う家族は決まった回数で解くので、解けきらなかった量(残差)を法則 × 場所で上限の計器に出す。釣り合いに着くまでの刻みの数も数える。
- **粗く書いた物の見分け**(Q5。§11.4): 同じ名前・同じ見た目で、法則に効く値か細かさが違う物の種類はベイクの誤り(名前付きで止める)。
- 作り手は家族を選ばない: 家族はエンジンの作り(§8)。作り手が書くのは今までどおり物質・反応・結合・環境・世界の値だけ。

### 1.5 6 つの家族と欄の持ち方で、作り手から見て変わること(2026-10-21)
- **書くものは増えない**: 家族はエンジンの作り。作り手は今までどおり物質・反応・結合・環境・世界の値を書き、新しい法則の値(強さ・硬さ・電気の通しやすさ・光の値など)は各家族の設計書の物質の欄に足される。
- **混ざった所・粗い所の値を書かない**: 混ざった箱の通しやすさ・強さは値ごとの混ぜ方をエンジンが持つ(S23)。粗い箱も同じ扱い(§11.2)。混ざったら別の物質にしたい時は反応で書ける(土 + 水 → 泥)。
- **釣り合いは決まった回数**: 大きな岩の塊を掘った直後などは、釣り合いに着くまで数刻み(数十分の 1 秒)かかることがある(§9.2)。重さはいつも読める。
- **眠った所も壊れない**: 眠った所のたわみ・圧力は粗くして残すので、起きた時に橋が少したわんで戻るように見えることは少ない見込み(R-F1 で測る。§10.3)。
- **粗く書いた物は別の種類**: 細かく書いた肉と粗く書いた肉の振る舞いが違うなら、名前か見た目を変える(§11.4)。
- **物の中も世界と同じ法則**: 物の中の熱・濡れ・電気・力・割れは、世界のセルと同じ値・同じ関数で動く(§12)。物専用の法則は書かない。

## 2. 土台の芯(エンジンの側)

共有の配管。§2.3 の表は「面の流れ」で解く家族(運ぶ・広がる・押す)の種類の表で、釣り合う・まっすぐ運ぶ・反応の家族の解き方は §8〜§9 と各家族の設計書。

### 2.1 状態は登録制
- 持ち越す状態 = **セル**(成分 + エネルギー。溢れのセル込み)+ **登録した欄** + 物(物理)+ 世界の帳簿。区画の欄・熱のキャッシュは無くす。
- 欄の登録(1 行で足す): 名前・置き場(セル / 面〔+ 側の 3 面〕/ ブロック / 世界)・型・**付く相**(gas / liquid / なし)・保存量か(帳簿の列)・
  細かくする/粗くする時の規則(同じ数 / 和 ÷ 8 + 端数)・ハッシュに入るか。例: 気体の運動量 ×3(セル・gas)・液体の面の運動量 ×3(面・liquid)・位置と運動のエネルギー・前の相の質量・機械の蓄え。
- 保存点・写しの早送り・ハッシュ・表の差し替え(物質の付け替えは名前で)・MR の細かく/粗く・端数は**登録を回るだけ**。欄を足しても 2〜3 か所を直さない。
- 2026-10-21: 登録の 1 行に「真実 / 導かれる値 / 温めた始まり」の印と、ある所にだけ持つ(疎な頁)を足す(§10・§13.2)。

### 2.2 セルの見立て(刻みごと・1 か所・永続しない)
- 共有 .hlsli の 1 つの関数 `MakeCellView(セル, レベル, 表)` が、活性のブロック(+ 隣の 1 セル)について作る:
  相ごとの物質量・質量・体積・熱容量(相の表 1 つから)/ 体積の分け合い(固体 + 液体 + 残り = 気体。空き・開き)/ 全体の熱容量・温度 / 気体の圧力 p と基準の大気との差 p̃ /
  液体の満ち具合・下の支え / 伝導の係数 / 孔の詰まり(固体の体積と孔の通しやすさから)/ 吸い上げ(満ち具合から)/ 欄から速さ。
- **熱のキャッシュの作り直し(後始末)が要らなくなる**: 見立ては永続しないので「段の外でセルを変えたら作り直す」写しが 11 か所から 0 になる(代わりに毎回作る費用。未確認 = ADR-0326)。

### 2.3 流れの一般の形
**流れ = 何を動かすか × 坂(見立ての値の差)× 通しやすさ(両側の物質の値の組み合わせ × 面の開き × レベルの係数)× 安定の条件**。

| 種類 | 動かすもの | 坂 | 通しやすさ(物質の値) | 安定の条件(種類が持つ) | 慣性の欄 |
|---|---|---|---|---|---|
| 熱の伝導(陽) | 熱だけ | T | 熱の通しやすさ(今の式のまま)| 係数 ≤ C/8・小刻み 4^σ | 無し |
| 熱の伝導(陰) | 熱だけ | T | 同じ | 刻みの中で解く(多重格子・上限 D-502) | 無し |
| 気体の塊 | 気体の相の中身(成分・熱の分け前・欄)を風上から | p̃ + 重さ | 開き × 孔の詰まり | 陽: 音の CFL・小刻み 2^σ・力積の上限(D-508)/ 最速: 投影 | セルの運動量・運動のエネルギー |
| 液体の塊 | 液体の相の中身を風上から | 柱の圧力 + 重さ + 気体の圧力 − 吸い上げ | 開き × 粘り × 孔の詰まり | 出る合計 ≤ 中身・速さの上限・摩擦は陰的(減衰の割り算 1 回) | 面の運動量・位置/運動のエネルギー |
| 混ざる(T-0186) | 気体の中の 1 物質 | 濃さ(モル分率) | 混ざる速さ | 係数の上限・小刻み 4^σ | 無し |
| 結合 drags | Y(熱・物質) | X の坂 | q √(L_XX L_YY)(ADR-0220) | \|q\| ≤ 1(ベイク) | 無し |
| 機械 machines | 押す物 Y(相を問わない) | 蓄え + Y の坂 | P・w・q(ADR-0228) | 蓄えの固定・組で縮める | 蓄え(登録の欄) |
| 放射(まっすぐ運ぶ家族。D-570・D-572。23 §3) | 熱(2 つの帯の光) | (面の流れではない。放った整数を配り切る) | 帯ごとの吸い込み・照り返し(23 §2) | 23 §3・§4 | 無し |
| 固体の流れ(段 9 研究 T-0797。§7) | ばらける固体の相の中身 | 重さ × 密度の差 + 積もった高さの差 − tan θ Δx | 相手の固体の入れる体積 × 開き | 出る合計 ≤ 中身・1 刻み 1 セル | 無し(最初の版) |

- 「染みる」は種類を足さない: 液体・気体の摩擦に孔の詰まり(粘り ÷ 孔の通しやすさ × 固体の割合)を足すと、孔の中では Darcy の流れ(終端の速さ)、空いた所では今の流れになる。
  吸い上げは液体の坂の項 1 つ。→ 例 1 の「岸が湿る」・例 5 の「ゆっくり染み出す」が同じ式。
- 離れた 2 セル(機械の口・放射の対)は「面」の一般化(**対**)として同じ帳簿に書く。
- 新しい種類を足す = 3 つ(坂・面の式・安定の条件)と読む欄の宣言を書くだけ。どの家族の種類かを先に決める(§8.2)。
- 表の行と家族: 熱の伝導・混ざる = 広がる / 気体・液体・固体の流れ = 運ぶ(案 B で 1 つにまとめる。21)/ drags・machines = 押す / 放射 = まっすぐ運ぶ(保留の対の式は退き、S39 の形へ。23)。
  気体の圧力の「最速(投影)」と陰の圧力は釣り合う家族の部品で解く(§9。D-515 の「最速を目標」は Q1 の陰の圧力〔本物の音速・1 刻み 1 回〕に置き換わった。21)。

- **運ぶ欄は移した質量に乗る(D-663・2026-10-26 ユーザー。ADR-0469 の 1-1)**: 運ぶ家族の面の流れでは、運動量・運動のエネルギー・熱(相の中身に付く欄の全部)を、
  移した物質量 μ(MUSCL)に比例して運ぶ(割合 F を別に持たない)。残る運動のエネルギーが (1 − μ) K に一致し、熱が負にならないことが式の形で保証される。
  入れるのは案 B の運動量の式(21 §2.2)を作る時に 1 か所で。旧気体(箱・木・GPU の箱・GPU の木)は案 B に置き換わるまで今の差の項(RestKineticExcess。ADR-0355 追記)のまま。

### 2.4 面の帳簿と当てる段(1 か所)
1. **流す**: 各種類が面(と対)ごとに「生の包み」を作る(熱 / 成分ごとの量 + エネルギー + 運ぶ欄)。面の持ち主が 1 回計算し両側が同じ値を足し引き(07 の共通の形)。
2. **上限**(順に依存しない・Jacobi): セルごとに生の出ていく合計と入る合計を数え、**出る側の倍率 = min(1, 中身 ÷ 出る合計)**(量・エネルギー〔押し出す仕事込み〕の列ごとの最小)、
   **入る側の倍率 = min(1, 器の残り ÷ 入る合計)**。包みは min(出る側, 入る側)で同じ割合に縮める。今の 4 種の式(気体 2・液体 1・木 1)が 1 つになる(伝導・放射の C/8・C/4 は安定の条件として種類に残る)。
   気体の陽解法の**熱の列**(T-0787・ADR-0355): 中身 = 力を当てた後の熱 − 余裕 6 mJ、出る合計 = 塊の熱のぶん(熱の分け前 + 押し出す仕事)の和。
   風上が自分の熱より多くの熱を持ち出さない = 熱が負にならないことを式の形で保証(D-508 の安全網。0 K に着くことはある。余裕の形を直してから既定に)。式は gas_flow.hlsli の GfMovedHeatPart・GfHeatRoom。
3. **当てる**: 変化をセルへ(溢れのセルへの書き足しもここ)。違うレベルの面は細かい側が計算し粗い側は端数(ADR-0017。欄の端数も)。
4. **欄が物質に付く**: 前の相の質量(登録の欄)と比べ、減れば速さを保つ・増えれば運動量を保つ(ADR-0286)。差の運動量は帳簿、運動のエネルギーの差は熱。気体・液体の CPU/GPU の 4 か所 → 1 か所。
5. **帳簿**: 世界の帳簿 1 つ(列 = 量〔エネルギー・元素・物質・運動量・位置/運動のエネルギー〕× 理由〔世界の端・壁の力積・重さの仕事・速さの上限・粗くした端数・物理の熱・改造・静止の丸め〕)。
   外との出入り(天候の境目・止まった棚との出し入れ・体を置き直す・地の底の熱)は理由「外への出入り」の 1 列にまとめる(§14.2・D-602・D-606 (1))。
   保存の検査は「Σ 登録した保存量 − 帳簿 = 一定」の 1 関数。
6. **起こす**: 変わったセルのブロック・流れが 0 でない面の両側を次の刻みの種に(MR の WakeAround)。
- 包みが「何を運ぶか」は相の表と見立ての分け前から 1 つの関数で作る(今の GasEnergyPart・MovedEnergy・MoveMass の 8 か所 → 1)。

### 2.5 1 刻みの順(全部の家族。S42・D-543)
段の列は登録(段を足す時は列に 1 行)。各段は前の段の結果を読む(決まった順で決定的)。
1. **入力**: プレイヤー・コマンド・天候の層の出入り・湧き出し。表の差し替え(登録を回る)
2. **物の物理**(AVBD: 体・道具・柔らかく揺れる物)。前の刻みの場からの力(圧力の力積・磁気の力・引きずり)を使う。軽い物(扉・板)は陰の圧力と一緒に解く(根 H)
3. **占める層と塞ぐ面**(物 → セル。表面の細かい形の面の開き具合もここ。S44)。見立て(§2.2)をここで作る
4. **押す**(魔法・筋肉・機械・電池の起電)
5. **釣り合う**: 電位(電荷 → 電位・電流)→ 磁場(電流・磁石 → 磁場・力)→ 支え(重さ・荷重 → たわみ・力。物の中も。§12)
6. **運ぶ**(陰の圧力 → 力 → 粒の降伏 → 引きずり → 運ぶ。衝撃の区は陽の小刻み。案 B の中の順は 21)
7. **まっすぐ運ぶ**(太陽の影の柱・距離ごとの段 → 吸い込んだ分をエネルギーへ)
8. **広がる**(熱の伝導・混ざる・匂い・染み込み・音)
9. **反応**(燃える・相変化・割れ・曲がる・破れ・生まれる・消化・電気分解・電流の損を熱へ。セルの中。D-504)
10. **受け渡しと締め**: セル → 物(欠片・生まれる・器)・物の割れ(物を分ける)・帳簿の締め・音の出来事を出す(→ サウンドエンジン)・眠る/起こすの判定・描画へ渡す
- 面の流れの家族(4・6・8)の中は、今までどおり [欄の合わせ直し → 種類の小刻み(流す → 上限 → 当てる → 起こす)]。
- 割れ・破れが起きた所は、次の刻みの 5 で解き直す。作り手から見た違いは 1/60 秒の中の順だけで見えない。連鎖の速さは物質の値の速さ(N8)で決まり、順のせいで変わらない。
- 前の版の順(気体 → 液体 → 伝導 → 反応)と claude/28 §2.14 の順は、これで置き換わる(6 の中の気体・液体は案 B で 1 つになる)。

### 2.6 区画の箱の代わり: 費用は活性で収める
- **流すのは活性のブロックだけ**。種 = 変わったブロック + 慣性の欄が 0 でないブロック + 起こす刻みの来たブロック(D-429)+ 流れのある面の隣。
  一様なブロック(静かな空・岩の中)は欄が 0 の間は一様のまま(値 1 つ)。
- 静かな大気は今も 20 刻みビット単位で変わらない(07 §2.7)ので眠れる見込み。乱れた気体が**ちょうど静止**に戻るかは研究(③' 段 4 T-0723。戻らなければ「静止の丸め」= 速さが 1 単位未満の欄を 0 にして運動のエネルギーを熱へ・帳簿の列)。
- 広がる煙の柱など大きな現象は、状態による粗くする(17 §3 A。§11.1。粗さは局所の状態だけで選ぶ = N1)で費用を下げる(研究 R-MULTI)。それでも予算を超える所は D-468 の計器で警告し、世界全体を一様にゆっくりにする(結果は変えない。D-202 の安全網)。
- 釣り合う家族は、変わった所から物理の長さで閉じた領域だけを解き、外は前の答えで固定する(§9.3)。眠った所の導かれる値は粗くして残す(§10.3)。
- これで「法則は状態だけで決まる」(D-465)を満たす: 場所で変わる場合分けは**世界の端**と**レベル**だけで、レベルの差は研究で測る(細かさによらない一貫性)。

### 2.7 CPU と GPU は 1 つの源・GPU は Compute を既定(WG・N8。D-546)
- 見立て・包み・面の式・上限・当てる・欄の合わせ直し・釣り合いの部品を全部 shaders/common/*.hlsli に書き、C++ が include して同じ関数を呼ぶ(heat_conduction.hlsli と同じ形)。
- 違うのは回し方だけ: CPU = ブロックの一覧を順に、GPU = 段ごとの **Compute の Dispatch** が既定。64bit の atomic の足し算は順に依存しない(今の伝導と同じ)。
- **Work Graphs は、測って Compute より速い所だけ**(連鎖の実行時の分岐・活性の起こし方など)。WG か Compute かは費用だけの問題で、結果は同じでなければならない(ビット一致の試験で確かめる)。
  実測では伝導は Compute の方が少し速かった(0.72 対 0.82 ns/セル。claude/29)。D-302(「できる限り Work Graphs」)はこれで置き換わる。
- **連鎖は法則が持つ速さ(m/s)で伝わる**(N8): 割れ・崩れ・燃え移りの速さは物質・法則の値で、1 刻みの中で最後まで回さない(刻みをまたいで進む)。
  「実行時に決まる深さまで走らせる」は、刻みをまたぐ活性の広がりとして Compute でも続ける。
- **速い連鎖**(claude/30 N8 の補い): 法則の速さが 1 刻みに進める距離(Δx/Δt)を超える連鎖(岩の割れ・爆轟など)は、(a) 速さから決まる固定の小刻みで進める か (b) この宇宙の速さとして遅く定める のどちらか。**2026-10-21 ユーザー決定 D-612**: エンジンは両方できる形にする(速さは物質の値。Δx/Δt を超える値を書いたら速さから決まる固定の小刻みで進める)。既定は (b)。(a) を選んだ時の小刻みの費用は予算として前もって決める(負荷で遅れない。D-468)。小刻みの道は ROADMAP T-0943。どちらでも法則は状態だけで決まる。
- 二重書き 4 組(gas_reference ⇔ gas_step・gas_tree ⇔ gas_tree_step・probe_gas ⇔ probe_gas_tick・probe_liquid ⇔ probe_liquid_tick。HLSL 約 3,200 行)が 0 組になる見込み。
  CPU と GPU のビット一致の試験は残す(式ではなく、回し方・atomic・活性の取りこぼしを確かめる)。

## 3. 仮の世界と多重解像度の世界に同じ土台

- **土台が世界に求めるもの 4 つ**: 活性のブロックの一覧 / セルの読み書き / **面の隣**(同じレベル・粗い〔差 d〕・細かい)/ 端数の置き場。MR はどれも伝導で実績がある(MrFindFaceNeighbor・WakeAround・MrFraction)。
- **PS は「1 段の MR」**: 64³・0.5 m は、レベル 0 のブロック 8 × 8 × 8 で子の無い MR と同じ。土台は MR の上だけに作り、
  **今の PS(区画を世界いっぱいに置いた版)を答え合わせの基準**にする(同じ場面・同じ式ならビット単位で同じはず。違えば活性の取りこぼしか式の差が見つかる)。縦切りの後、PS 専用のコード(区画・glue・二重書き)を退かせる。
- **レベルの単位を 1 つに**: 量・エネルギー・運動量(セル・面とも)は 8^-k(体積と同じ比。細かくすると子は親と同じ数 = 運動量もビット単位で保存)。
  体積の定数(0.125 m³ 固定の PROBE_CELL_VOLUME・液体の柱・g dt²/2Δx)は見立てでレベルの関数にする。
- **レベルの係数と小刻みを 1 つに**: 種類は「冪 e」を宣言するだけ(拡散型〔熱・混ざる〕e = 2: 係数 × 4^k・小刻み 4^σ / 波の型〔気体・液体〕e = 1: × 2^k・2^σ)。
  小刻みと粗い側の受け直し(Berger–Colella)は土台の 1 つの実装(今は伝導 4^σ と気体の木 2^σ で別々)。
- **セルの外の欄の置き場**: セルの欄は頁と同じ番号の「欄の頁」(登録した欄ごと)。面の欄はセルの + 側 3 面(05 §3 の「面の流れ ×3」の持ち方)・違うレベルの面は細かい側。
  端数(MrFraction)は登録した保存量の列に広げる(運動量の端数 = 気体の木の 2^-64 と同じ)。
- **細かくする / 粗くする時の配り方**: 細かく = 子は親と同じ数(物質・エネルギー・セルの運動量)。粗く = 和 ÷ 8 + 端数(今と同じ)、速さを平均して消えた運動のエネルギーは熱へ(帳簿で合う)。
  **液体の面の運動量を細かくした時の内側の新しい面**の値は研究(平均で置くと運動量の和が変わる)。
- 観察の枠(影。D-403)は土台の上でも「自分の中だけ・外は親から」(今の伝導と同じ)。

## 7. 固体の三つの形と物との口(T-0796・D-520。ADR-0359・ADR-0360 Accepted = D-525)

2026-10-21: この節の物との口(占める体積・対の面)は、§12 で 6 つの家族の全部に広げた。固体の流れ(ばらける固体)は案 B の粒(21)へ移る見込み(wt3 の判断)。

**一つの芯**: 固体の中身は持ち主がいつも一人(セルか物のボクセル)。三つの形(据わる / ばらける / 塊)の違いは「誰が固体を動かすか」だけ。
場から見ると三つとも「見立ての固体の体積」、場と物の間の道は「占める体積」と「対の面」の 2 つだけで、受け渡しは帳簿の 1 つの理由「物との受け渡し」を通る。
法則(反応・伝導・孔・吸い上げ)はセルでも物のボクセルでも同じ関数。欄の名前・単位は仮(ADR-0359 判断待ち A)。

### 7.1 作り手から見た姿(Luau。`...` は今と同じ欄)
**例 A 砂山が崩れる・掘ると崩れる**
```lua
species = {
  sand  = { ..., phase = "solid", solid_motion = "loose", repose_angle_deg = 34, density_kg_per_m3 = 1600, permeability_um2 = 10 },
  stone = { ..., phase = "solid", density_kg_per_m3 = 2600 },   -- solid_motion を書かない = "fixed"(据わる。今と同じ)
}
world_cells = {
  bedrock = { layer = 1, min_cell = { 0, 0, 0 }, size_cells = { 64, 1, 64 }, amounts_umol = { stone = ... } },
  pile    = { layer = 2, min_cell = { 28, 1, 28 }, size_cells = { 8, 8, 8 }, amounts_umol = { sand = ... } },
}
```
- 動く道: 砂の立方体は、横の坂(積もった高さの差 − tan 34° × Δx)が正の所だけ流れ、34° の段々の山で止まって眠る。下の砂を消す(コマンド)と支えの無くなった所が落ち、
  また安息角まで崩れる。山に水をかけると、今の孔と吸い上げで染みる(固体の流れとは別の種類。同じ見立てを読む)。
- 土台の外: 0.5 m の段々の見え方は細かいレベルと描画(D-520)。川が砂の岸を削るのは最初の版では起きない(ADR-0359 判断待ち B)。

**例 B 湖が凍って氷が水面に張る**
```lua
species = { ice = { ..., phase = "solid", solid_motion = "loose", repose_angle_deg = 90, density_kg_per_m3 = 917 } }  -- 90 = 横には崩れず、浮く・落ちるだけ
reactions = { freeze = { ... } }   -- 20 §1.3 例 3 と同じ。反応表に形を書かない
```
- 動く道: 水面の冷えたセルで凍った氷は、下向きの坂 = 重さ × (917 − 水の 1000) が負なので上に留まる。水の中で凍った氷は上がり、押しのけた水が下がる(入れ替わりの包み)。
  湖を抜くと、支えの無い氷は落ちる(セルの氷はつながりを持たない。橋のように架かる氷は物で書く)。

**例 C 木の橋が燃えて落ちて浮く**
```lua
world_cells  = { banks = { layer = 1, ..., amounts_umol = { stone = ... } },          -- 両岸(据わる)
                 river = { layer = 2, ..., amounts_umol = { water = ... } } }
world_bodies = { bridge = { size_mm = { 6000, 250, 1500 }, position_mm = { 20000, 4250, 16000 },
                            fill_umol = { wood = ... } } }   -- 中身で書く。重さは書かない(ADR-0360 判断待ち C)
```
- 動く道: 橋は岸のセルに当たって載る(地面は物ではなくセル。判断待ち D)。火は橋のボクセルの中でセルと同じ燃える反応で進み、酸素は対の面から入り煙は対の面から出る。
  燃えて軽くなり・つながりが弱くなって(08 §3・§4)落ちると、占める体積が水を押しのけ、水の圧力が塞がれた分の力積(壁の力積の列)が橋を押し上げて浮く。
  水に沈んだボクセルの火は、まわりのセルが水で酸素が来ず熱が水へ逃げるので消える(物専用の消える規則は書かない)。
- 土台の外: 割れ方は 08 §3 の研究。流れに押されて下流へ運ばれる形(対を通る運動量)は T-0798。

**例 D 石を池に落とすと水位が上がる・沈む**
```lua
world_bodies = { rock = { size_mm = { 1000, 1000, 1000 }, position_mm = { 16000, 8000, 16000 }, fill_umol = { stone = ... } } }
```
- 動く道: 石が入ったセルは液体の入れる体積が減り、水は今の流れで押し出されて水位が上がる(帳簿で量が合う)。石は 2600 > 1000 なので受けた力積が重さに負けて沈み、底のセルに当たって止まる。

**例 E 密室の圧力が扉を押す(20 §1.3 例 2 の続き)**
```lua
world_bodies = { door = { size_mm = { 1000, 2000, 100 }, position_mm = { ... }, fill_umol = { wood = ... } } }   -- 蝶番(関節)は物の関節の書き方で(後)
```
- 動く道: 中の圧力が上がると、扉の占める体積で塞がれた面の力積が中から外へ扉を押す。扉が動けば占める体積が動き、気体が入れ替わって燃える(バックドラフト)。水車も同じ道(羽根に当たる水の力積)。

### 7.3 段 9 の研究へ渡す打ち切り条件(案)
- **T-0797 固体の流れ**: 場面 3 つ(砂の 8³ の立方体を平らな岩に置く / その山の下の 2 列を消す / 水の 16³ の中ほどに氷を 2³)。成功 = 60 秒以内に全部眠る・
  山の斜面がどの向きでも tan 34° × Δx の段差 ± 1 セルに収まる・氷が水面に上がって留まる・保存の検査(物質・エネルギー)が毎刻み 0・CPU と GPU でビット一致。
  試す順: ① 横の坂を面ごとのしきい値で流す(当てる段の Jacobi の上限)/ ② 列の高さで流す(高さの場)。入れ替わりは ① 液体の流れに任せる / ② 固体の包みに入れる。
  **打ち切り**: 2 本で「60 秒で眠る」か「安息角 ± 1 セル」が満たせなければ、横に崩れるのをやめ(縦に落ちる・浮くだけ)、安息角は細かいレベルと描画に任せる案と、
  慣性の欄(地滑りの勢い)を足す案を並べてユーザーに問う。氷が上がらない・水が暴れる(16³ で 10 秒たっても液体の運動のエネルギーが入れる前の 2 倍を超える)なら、
  入れ替わりを 1 列 1 刻み 1 セルに絞った版で止めて問う。
- **T-0798 物と場**: 場面 4 つ(0.6 の木の 1 m 箱を静かな池へ落とす / 2.6 の石の箱を落とす / 木の箱が空気の中で燃える / 密室の圧力で蝶番のない板が押される)。成功 =
  木の喫水が中身から出る値(体積の 60 %)± 1/4 セル・上下の揺れが 10 秒以内に 1 cm/s 未満・石が沈み水位の上がりが押しのけた体積と帳簿で合う・
  セル + 物 − 帳簿 が毎刻み一定・CPU と GPU でビット一致。いちばん難しい場面として 0.1 の軽い箱を水に落とす(整数で暴れない)。
  試す順: ① 1 刻み遅れの陽の力積(今の形)/ ② 物の重さに押しのけた流体の重さを足す(付加質量。AVBD の質量の項)。
  **打ち切り**: 2 本で 0.1 の箱の揺れが 10 秒で収まらない(か運動のエネルギーが増える)なら、1 刻みに物が受ける力積を「押しのけた流体の運動量」で頭打ちにする版(帳簿の理由「速さの上限」で数える)で止め、
  浮き方の精度との取り引きをユーザーに問う。対の面の熱が、同じ形をセルで置いた時の燃え方(燃え尽きる時間)と 2 倍以上違えば、面の広さの数え方を 1 回変えて、それでも違えば問う。

### 7.4 占める層と対の面の形: 行き先を「箱の並び」1 つの関数で(**案(仮・ユーザー未確認)**。T-0820・T-0821・ADR-0543 Proposed)
(2026-11-13 wt5 の設計役。コードは書いていない。§12.6(ADR-0541)の土台の印 ②③④ を、要る現象の一覧(21 §3)と照らして詰めたもの。今のコード: 占める層・対の面は無い〔T-0820・T-0821 は Todo〕。
近いものは 面の開きの欄(face_opening.h・T-0937。世界の固体と表面の細かい形から)・物の熱の箱の「囲むセル 1 つ」との受け渡し(object_heat.hlsli・ADR-0434))

#### 7.4.1 要点
- **一つの関数**: 「物のボクセル(姿勢つき)の中の点が、行き先の**箱の並び**(レベルと姿勢を持つ格子)のどの箱に入るか」を整数で数える。
  行き先の並びは 3 つあるが関数は 1 つ: 世界の木(姿勢 = 地面・箱 = 葉のセル)/ 地面の格子(姿勢 = 地面・箱 = 格子のボクセル。§12.6)/ ほかの物の箱(姿勢 = その物)。
  「この点を持つ箱はどれか」の引きだけが行き先ごとに違う(格子の頁があればそのボクセル、無ければ世界の葉)。
- **数えるのは物の側から・細かい側の点で**: 点のレベル = max(物のボクセルのレベル, 行き先の箱のレベル) + 2(どちらの箱にも 4³ 点以上)。中に収まった塊は一度に足す(下の 7.4.3)。
  占める体積の和は物の中身の体積とビット単位で同じ(行き先の細かさに依らない。浮き方が行き先の箱の 1/64 の段々にならない)。
- **占める量 = 物のボクセルの中身が使う体積**(凝縮相 + その孔。物のボクセルの見立てから)。燃えて減る・焦げて孔が増えると占める量が自動で減る(式を足さない)。
- 対の面は 2 つの出どころ: **重なり**(上の数えで、物の表面のボクセル ⇄ 流体を持つ箱 = 世界の葉か格子のボクセル)と **接触**(物の物理の接触点で、物のボクセル ⇄ ほかの物のボクセル・場の固体のセル)。
- 止まりは 2 つに分ける: **眠り**(計算を飛ばす・結果を変えない。物の物理 T-0044)と **置く判定**(空気の層をどこに置くかの法則。層の側 §12.6.4)。

#### 7.4.3 数え方(決定性・ビット一致)
1. 物のボクセルごとに、ボクセルを姿勢で写した 8 隅が全部同じ行き先の箱に入れば、そのボクセルの全部の点(4³ × 8^k)を一度に足す(写した形は凸なので、隅が全部入れば中も全部入る = 点を全部数えたのと同じ数)。
2. 入らなければ 8 つに割って 1 に戻る。点のレベルまで割ったら点 1 つずつ(点の中心を写して箱を引く)。費用は表面の点の数に比例(中は塊で足す)。
3. 足し込みは整数の和(GPU は InterlockedAdd)なので順に依らない。上位 4 物は (量の大きい順, 同じなら物の番号の小さい順)で選ぶ。溢れは計器(結果は 4 物までの力の割り振りだけが変わる。ADR-0360 §4)。
4. 作り直すのは姿勢か形(中身の占める量)が変わった物だけ(変わったかは状態の比べ = 飛ばしても結果は同じ)。眠った物・止まった物は 0。
- 1 刻みの順(ADR-0360 §6): 物理の刻み → **占める層を作る(この関数)** → 表の差し替え → 見立て → 種類の小刻み(対も流す)→ 反応 → 次の種。

#### 7.4.4 止まりを 2 つに分ける(土台の印 ④)

### 8.2 家族が 1 回だけ作るもの(家族の約束)
新しい法則は、入る家族を選び、下の 6 つのうち**家族が決めていない所だけ**を書く。
1. **読む欄と書く欄**(真実か導かれる値か。§10。読む物質の値の宣言は影響の見える化の元 = 1.4)
2. **解き方の型**: 面の流れ(運ぶ・広がる・押す)/ 釣り合いの系(釣り合う)/ 掃く(まっすぐ運ぶ)/ セルの中(反応)
3. **安定か回数**: 陽なら安定の条件(C/8・音の CFL など)、釣り合いなら決まった回数(§9.2)
4. **眠り方**: いつ眠れるか(§2.6)と、眠った所の導かれる値の扱い(§10.3)
5. **粗い時の値**: 粗い箱の物質の値は混ぜる規則(S23)で出す(§11.2)。家族ごとの別の規則は作らない
6. **費用の読み方**: 活性のブロック数 × 小刻み(面の流れ)/ × 回数 × 段(釣り合い)/ × 段 × 向き(まっすぐ運ぶ)を費用の計器に出す
- どの家族にも入らない法則が出たら、作業役は足さずに印を付けて司令塔へ上げる(本当の新しい形。claude/26 決定 4 と同じ扱い)。

### 8.3 家族どうしの受け渡し
- 受け渡しは**面の帳簿と当てる段**(§2.4)か、**刻みの順で前の段の結果を読む**(§2.5)のどちらかだけ。家族どうしが直接相手の欄を書き換えない。
- 例: 電流の損 → 熱(反応の段でエネルギーへ)・吸い込んだ放射 → エネルギー(まっすぐ運ぶの段の終わりに当てる段で)・磁気の力 → 物(次の刻みの物の物理の入力)・割れ → 粒/物(受け渡しと締め)。

## 9. 釣り合う家族(S38・F1・F3。D-541)

### 9.1 芯
- 入る法則: 陰の圧力(Q1)・支えの法則(S10・S11)・電位と電荷(S29)・磁場(S30)。どれも「つながった領域の中で、釣り合いの式を解く」同じ型(直線の式だけを持つ)。
- **世界の多重解像度の木を、そのまま多重格子の段にする**: 段 ℓ + 1 = 段 ℓ の最も細かいレベルの節を親のセルへ縮約したもの(= 木にもともとある粗い段)。解くために別の格子を作らない。物の箱(§12)でも同じ。
  今の熱の陰解法の段の作り(implicit_conduction の BuildImplicitGrid・GPU の GpuImplicitLevels)がこの形で、これを家族の部品に上げる(§13.1)。
- **決まった回数だけ解く**: V サイクルの回数は法則ごとに固定し、場面によらない。前の刻みの答えから始める(温めた始まり。§10.4)。
- **保存は解の精度によらず厳密**: 流れ・力は面の形(片方から出た分がもう片方に入る)で出し、当てる段(§2.4)が両側に足す。解けきっていなくても帳簿は合う。
  精度は残差として測り、上限の計器(1.4)に法則 × 場所で出す。
- **曲がり(割れ・ねばい・破れ)は解の外で、反応の家族**: 釣り合いを解く(刻みの 5)→ 強さを超えた所が物質の値の速さで割れる・曲がる・破れる(刻みの 9。N8)→ 次の刻みでまた解く。
- 整数・決まった順・Jacobi 型(赤黒)の平滑化で決定的(気体の陰の圧力 T-0842〜T-0845 と同じ作り)。

### 9.2 解けきらない場面の約束(ユーザー決定 (a))
- **決まった回数**: 重さがいつも読める(D-468 の「負荷で遅れない」と合う)。大きな岩の塊を掘った直後などは、釣り合いに着くまで数刻みかかることがある(見た目は「少したわんでから落ち着く」)。
- ユーザー「とりあえず (a) で見て、酷かったらどうにかする」: 試作(C-0・R-B1)で**釣り合いに着くまでの刻みの数とその間の見た目**を記録し、ユーザーに見せる(**研究の合格の項目に入る**〔記録して見せる。S38〕。22 §6 の R-B1・R-B3 と同じ)。

### 9.3 遠くに効く解き方と眠る/起こす(F3)
**釣り合いの領域は、変わった所から「物理の長さ」で閉じる。外側は前の答えのまま固定する**(外のセルは系の未知数にせず、値を固定した境。今の陰解法の開いた端 ImplicitEdge と同じ形)。
長さは法則ごとの式で、状態から決まる(重さ・予算では決めない)。
| 法則 | 閉じる長さ |
|---|---|
| 陰の圧力 | 音の速さ × 刻みの倍数(根 H。約 6 m の倍数)。完全に閉じた区画は区画ごと |
| 支えの法則 | 変わった所の大きさの何倍か(力の乱れは変わった所の大きさくらいの距離で消える) |
| 電位 | つながった導体の全部(1 か所のスイッチで回路全体が変わる)+ 電荷の多さから決まる距離 |
| 磁場 | 磁石・電流の強さから決まる距離 |
- 細かさによらない(長さは物理の単位。レベルごとのセルの数へは部品が換算する)・決定的(状態だけで決まる)・重くても結果を変えない。
- 「変わった所」= 系の右辺か係数が丸めの幅を超えて変わったセル(活性の種と同じく状態だけで決まる)。
- 未確認: 閉じた境目の小さなずれが溜まらないか(C-0 で 600 刻み測って記録する。§13.1)。
- 注(2026-10-26・T-1171・ADR-0480 Proposed): 支えの「変わった所の大きさの何倍」は、掘る・積むなど正味の力が変わる出来事には当たらない(乱れが 1/r でしか消えず、値で固定した境目の誤差が細かいほど大きい)。その時は値で固定せず、遠くを粗いセルのまま一緒に解く(粗さで閉じる。変わった所の周り × 4 の内を細かく)。

| **真実**(状態そのもの。法則は状態だけで決まる約束〔D-465〕の「状態」) | 物質の量(匂い・魔素・**濡れの水**もここ。濡れは新しい欄ではなく孔の中の水の量)・エネルギー・勢い(起きている所だけ。眠っている所は止まっているので 0)・電荷(ある所だけ)・割れの進み・ねばい物の変わった形(ある所だけ)・変えた表面の形の差分(ある所だけ。D-575・23 §7) | いつも持つ。**ある所にだけ持つ**(無い所は 0 を持たない) |
| **導かれる値**(真実から計算できる) | 圧力・たわみと力・電位と電流・磁場・放射の場・温度 | **起きている所でだけ計算して持つ**。眠った所は粗くして残す(§10.3) |
- 温度・圧力のうち状態方程式だけで出る分は見立て(§2.2)がその場で作り、欄にしない。解く必要のある導かれる値(釣り合いの解・放射の場)だけを欄として持つ。
- 眠っている土・岩・空気の 1 セルは、物質の量とエネルギーだけ。1 セルの大きさの見積もりは、この形で測り直す(試作の前の M-0。未確認)。
- 登録(§2.1)の 1 行に「真実 / 導かれる値」の印を足す。保存量の列・ハッシュ・保存点・粗くする規則は印から決まる(作業役が欄ごとに考えない)。

### 10.2 ある所にだけ持つ(疎な欄)
- セル・面の欄は今「欄の頁」(セルの頁と同じ番号。一様なブロックは値 1 つ)に置く。これに**頁があるか**の印を足し、無い頁は全部 0 として読む。
  頁は当てる段で 0 でない値を最初に書く時に作り、眠る判定で全部 0 なら返す。
- **頁があるかないかは結果に効かない**: ハッシュ・保存の検査・面の流れは「無い = 0」と同じ値を出す(試験でビット一致を確かめる。§13.2)。
- **「無い頁は 0」は変えない(D-667・ADR-0469 の 2-4)**: 物の箱が囲む空気の層(§12.5)のように「無い所を囲むセルと同じ中身と読みたい」所は、層を作る時に囲むセルの中身を体積の分だけ帳簿でセル → 層へ移す(返す時は逆)。差だけを持つ読み方はとらない(層を読む関数が世界と同じでなくなる)。

### 10.3 眠った所の導かれる値(ユーザー決定: (b) 粗くして残す。使えなかったら (a) 捨てる)
- 眠る時、導かれる値はブロックに 1 つ(一様の値の枠)へ平均して残す。起きた時は、それを細かいセルへ配って解き始める。
- 研究 R-F1: 粗くして残した答えから起きた時、たわみ・圧力が見て分かるほど動かないか。動くなら (a) 捨てる(起きた時に解き直す)へ下げて、同じものを測る。
- **欄ごとに捨てる(ADR-0469 の 2-3・T-1159)**: 起きた時に使わない導かれる値(支えの刻みをまたぐ共役勾配の向き・残差。D-649)は、登録の印 `SF_FLAG_SLEEP_DISCARD` で眠る時に 0 を残す(保存点の無駄を省く)。導かれる値だけに付けられる。

### 10.4 温めた始まりは状態の一部(この文書で見つけた点。D-608 で決定)
- 決まった回数で解く(§9.2)ので、**解き始めの値が答えを変える**。起きている所の解き始め = 前の刻みの答え、眠った所 = 粗くして残した値。どちらも決定的だが、真実だけからは作り直せない。
- そのため、真実だけをセーブすると、読み込んだ後の数刻みの導かれる値(→ 力 → 割れ)が、続けて遊んだ場合とビット単位で一致しなくなる(D-465「何でも再生できる」とぶつかる)。
- **決定(2026-10-21 ユーザー D-608。前は仮 D-549)**: 解き始めに使う導かれる値(登録に「温めた始まり」の印)は、ハッシュとセーブに入れる。起きている所だけ・眠った所は粗い 1 値なので、増える量は小さい見込み(未確認。M-0 で測る)。
  【エンジン】問い(チケット T-0860 に案と影響): (A) 解き始めもセーブに入れる(読み込んでも続けて遊んだのとビット単位で同じ。セーブが少し大きい)/ (B) 真実だけ(読み込んだ直後の数刻み、たわみ・圧力が少し動くことがある。再生のビット一致は保存点からでなく最初からだけ)。おすすめ (A)。**QUESTIONS Q137**(2026-10-21 本体が上げた)。15 §1 のセーブの「差分は真実だけ」は (A) を前提に読む。**→ (A) に決定(D-608)。ただし重くなったら切れるもの**: セーブの大きさ・費用を T-0922 で測り、重ければ (B)(`SF_WARM_START_IN_STATE` = false)に切り替えてよい。

## 11. 粗さ(N1・S43・Q12・Q5。D-544・D-547・D-548)

### 11.1 粗さは局所の状態だけで、いつも同じ規則で選ぶ(N1)
- 粗くする・細かくするは、**局所の状態の関数**(勾配・活性・反応の前線・割れの先端)だけで決める(17 §3 A。D-208)。予算・視点・処理の重さでは決めない。
  粗くした所は、その大きさでの法則として振る舞う(粗い箱の法則が §11.2 で決まる)。
- 見るだけの細かさ(観察の影。17 §3 B・D-403)は世界に返さないので、視点で細かくしてもよい(粗さの規則とは別)。
- **予算を超えた時の最後の手段は、結果を変えない「世界全体を一様にゆっくり」**(D-202 の安全網。超えたら不具合としてエディタと開発ビルドで警告。D-468)。遠くを粗くして予算に収める(Q9)はしない。
- 時間の粗さ(刻みの長さ)も同じ芯で選ぶ(S50。§14.2)。
- **細かい所の半径と移り目は世界のデータの長さ(T-0954・ADR-0431)**: 環境の `fine_region = { radius_mm, far_leaf_mm, levels_per_doubling }`(名前は仮)。種(上の局所の状態で細かくした所)からの
  距離 ≤ 半径はいちばん細かいまま、外は距離 2 倍ごとに段の数ずつ粗く、遠くの葉で頭打ち(`sim::GradedCoarseness`)。距離は視点からではない(D-544・D-623)。
  木の要求へつないだ(T-1008・ADR-0436。CPU: 規則より粗い八分の一を細かくする要求を足す・規則より粗くなる静かな葉の要求を外す。GPU は T-1028)。
- **法則が守られる保証の残り**(claude/30 N8): 粗くしても同じ結果になるかは賭け 2 で測る。通らない所は粗くせず、費用か広さで払う。法則は変えない。

### 11.2 粗くすること = 混ぜること(S43)
- 粗い箱の**真実は細かい箱の真実の和**(物質・エネルギー・電荷・勢いは足すだけで保存される。今の登録の VOLUME の規則 = 和 ÷ 8 + 端数を帳簿へ)。
- 粗い箱の**導かれる値に使う物質の値(通しやすさ・強さ・硬さ・光の値)は、混ざった所の値の決め方(S23。値ごとに物理の混ぜ方をエンジンが持つ)で出す**。粗い箱は「細かい箱が混ざった箱」と同じ扱い。
  粗くするための別の規則を家族ごとに作らない。
- 割れの進みは割れ面のエネルギー(坂の原理)で数えるので、粗くしても和で保てる見込み(研究 R-B2 で確かめる)。
- まっすぐ運ぶ家族の距離ごとの段(S39)は、もともと粗さを段として持つ。
- 勢いを粗くして消えた運動のエネルギーは熱へ(帳簿で合う。§3)。
- **基準の層(重さで決まる静水圧の部分)も粗さをまたいで和で合わせる(T-0953・ADR-0431)**: 段ごとの柱 1 つ(`sim/gas_base_layers`)で、2 × 粗い層 = 細かい 2 層の和(量・エネルギー。整数で一致)。
  粗くする = 和 ÷ 8(静かな所は端数 0 で粗い段の基準そのもの)・起こす = 基準からのずれを同じ数で配る(Σ 子 = 8 × 親)。10 km の柱で 600 刻み速さ 0・揺れ 0。

### 11.3 縦にだけ粗い列(Q12)
- 縦に一様な所(深い湖・川の水面より下)は、**縦にだけ粗い列**(下の段は背の高いセル 1 つ、水面の近くはふつうのセル。先行例 Irving 2006 の形)で持てる。広い川・湖の費用が 50〜100 倍下がる見込み(claude/29。未確認)。
- 列にするかは §11.1 と同じく局所の状態だけで選ぶ。列の中の縦の流れ(温度の層・底の流れ)は粗くなる。§11.2 の「粗くすること = 混ぜること」がそのまま効く。
- **前提: 似た形の特許を確かめてから採る**(T-0862。Claude は先行例と公開された特許の範囲を調べて並べるまで。法律の判断と採るかはユーザー)。

### 11.4 作り手が粗く書いた物は、見分けられる別の種類(Q5)
- 作り手が物を粗く書く(例: 肉を細かい組織なしで書く)のはよい。ただし細かく書いた物と振る舞いが違うなら、**名前か見た目で見分けられる別の種類**として書く。
- **同じ名前・同じ見た目で振る舞いが違うのはベイクの誤り**(1.4)。エンジンは物の種類に「見え方の鍵」を持ち、鍵が同じ種類どうしで、法則に効く値か細かさが違えば名前付きで止める(仮。鍵の形は T-0854 の後で決める)。
- 抽象化したコマンド(切る・こねる)の判定は細かい版と同じ結びつきの強さで行う(C5。式は 02)。

## 12. 物の中で全部の法則を走らせる(S45・27-C1。D-545)

### 12.1 芯(27-C1)
> 世界にあるのは「物質と熱が入った小さな箱」だけ。箱は**地面に固定された並び**か、**物と一緒に動く並び**に入る。
> どちらの並びの中にも、**固まった箱(骨格)**と**流れる箱**がある。法則はどの箱でも同じで、箱の大きさは物ごと・場所ごとに選べる。
- 骨格は座標と一緒に動く(地面は速さ 0、物は剛体 = AVBD)。流れる箱は、その座標の骨格に対して同じ式で流れ、座標の加速・回転は見かけの力として一様に足す。
- 形が変わる = 結びつきの強さを超えて骨格の箱が粒になる(割れる・すりつぶす・煮崩れ)/ くっつく粒が押されて形を変える(生地・粘土)。**形の変わる物のための 3 つ目の動き方(MPM など)は作らない**。
- 分ける = 骨格のつながりが切れて別の物になる(08 §3)。

### 12.2 物の箱で 6 つの家族を同じ関数で走らせる
- 物は自分の座標の箱(細かさは型ごとに 1 つ)を持ち、**真実の欄は世界のセルと同じ**(§10)。6 つの家族は世界と同じ関数を物の箱でも走らせる(違うのは座標だけ)。
  釣り合う家族の多重格子の段も、物の箱の中で同じ作り(§9.1)。
- 世界とは**「対の面」で家族ごとに受け渡す**: 熱(触れた面の伝導)・物質(こぼれる・染みる・濡れが移る)・電気(触れた面の通り)・放射(物の表面が遮る・放つ)・圧力(塞ぐ面。ADR-0360 の占める体積)・力(触れた力)。
  帳簿は 1 つ(理由「物との受け渡し」。ADR-0360)。§7 の物との口をそのまま全家族に広げた形。

### 12.3 物の物理(AVBD)と支えの法則の受け渡し
- **AVBD が物の動きを解き、触れた所・関節の力を出す**(刻みの 2)。
- **硬い物**: 物の箱の中で釣り合いを解く(刻みの 5)。荷重 = 触れた力 + 重さ + 加速の見かけの力。強さを超えたら割れ(反応、刻みの 9)、物を分ける(刻みの 10)。
  欠片はセル以上なら物、未満なら粒(S19)。分かれた物は次の刻みから AVBD に入る。
- **柔らかく揺れる物**(吊り橋・枝・布・縄・弓): 小片を柔らかい関節でつないだ列として AVBD で揺らす。関節が切れる強さは物質の強さ × 断面から出す(硬い物と同じ法則で壊れる)。
- 硬い・柔らかいの分け目は物理の単位で、作る時に形と物質から決める(式と研究 R-O1 は 08・22 = wt4)。

### 12.4 小さい物の熱は物の箱が持つ(T-0991・ADR-0434。司令塔の仮)
**問題**(T-0878): 虫眼鏡の焦点の 7.9 W は 0.5 m の紙のセルの平均を 0.00003 K/s しか上げず、焦点で燃え始めた紙が燃え続けない。焚き火のそばの小枝・鍋の中身の焼き加減も同じ
(セルより小さい物の熱が、セルの平均に均されて消える)。
**芯**: セルより小さく、自分の熱で振る舞いが変わる物は**物**として置き、**物の箱のボクセルが自分の熱を真実として持つ**(§12.2・ADR-0360 §1。新しい欄は作らない)。
セルの平均とは**対の面**でだけ受け渡す。物の箱の細かさは**物の形と局所の状態**で決まり、世界のセルの細かさによらない。

**1. 真実の置き場**
- 物のボクセルの中身 = セルと同じ RxCell(物質の量・エネルギー)。単位はそのレベルの単位(8^−L µmol・8^−L mJ)なので、量の数は濃さ × 0.125 m³ で、
  反応の速さ(量の積 × k(T))も温度もセルと同じ関数がそのまま正しい(物専用の式 0)。
- 紙のように箱より薄い物は、箱を満たさない量として持つ(0.1 mm の紙を 7.8 mm の箱に: 紙で満たした箱の 1.3 %)。熱容量は中身から出るので、厚さを書かせない。
- 保存: **Σ セル + Σ 物のボクセル + Σ 対の端数 − 帳簿 = 一定**(エネルギー・元素。ADR-0360 冒頭の検査に対の端数を足す)。

**2. 物とセルのやり取りの口(対の面。どれも当てる段・Jacobi・両側に同じ値)**
| 家族 | 口 | 式(今ある関数) | 長さ・広さ |
|---|---|---|---|
| 広がる | 伝導 | 囲むセルの気体の伝導率 × ΔT(HcCellConductance) | 面の広さ ÷ **境の膜の厚さ**(物の形と流れで決まる物理の長さ。セルの半分でも箱の半分でもない。T-1016) |
| 広がる | 気体の混ざり | 物質ごとに 濃さの差 × 混ざる速さ(diffusivity)。運ぶ気体は出ていく側の h0 + 比熱 × 温度を持っていく | 同じ(O2 が入り、煙・水蒸気が出る) |
| まっすぐ運ぶ | 放射 | RdPairCoefficient を面の広さで縮める。吸い込みは物の長い帯の値(RdAbsorptanceQ16) | 物の表面の広さ。行き先は 23 の家族(試作は囲むセル) |
| まっすぐ運ぶ | 日の光・集めた光 | 物の表面が遮って吸う(照り返しの値を引く)。レンズの升(ADR-0425)のうち物の表面に入った分 | 物の表面 |
| 運ぶ | 対流 | **別の口を作らない**。セルより大きい流れは運ぶ家族がセルで解き、セルより小さい流れは膜の長さに入る | — |
- 膜の気体の値(混ざる速さ・伝導率)は**膜の温度**(両側の平均)で決める(剛体球の気体の運動論: ∝ T^1.5・∝ T^0.5。物質の値は室温の値)。
  これが無いと、熱い炭のまわりの O2 の入りが遅すぎて炭が 1 s で消える(試作の 1 本目)。混ざる・広がる家族の法則の形なので、入れるかは【エンジン】問い(ADR-0434 問い 1)。
- 細かい箱の対の面は 4^(L − L0) 回の小刻みで流す(1 小刻みに入れ替わる割合は ∝ 4^L。広がる家族の陽の小刻み 4^σ と同じ形。T-1016)。
- 物どうし(鍋と中身・焼き網と肉)は、触れた 2 つのボクセルの対で同じ伝導(ADR-0360 §3)。鍋の中身は器の物の中身(08 §11)で、同じく自分の熱を持つ。
- **対の端数**: 細かい側の単位で計算し、粗い側の 1 単位に満たない分は対(物ごと・量ごと)に持ち越す(真実・ある所だけ・ハッシュとセーブに入る)。
  帳簿の「粗くした端数」へは流さない(O2 の 0.08 µmol/刻みのような小さい流れが帳簿から湧く・消えるのを避ける)。違うレベルの面の端数(ADR-0017)と同じ考えを、量が帳簿へ漏れない形にしたもの。

**3. 燃え始め(ADR-0426 との関係)**
- 物のボクセルでは、**溜めた熱 = ボクセルのエネルギーそのもの**。燃え始めは反応のふつうの速さの式(アレニウス)で起き、燃え始める強さ q_c・溜める時間 τ の 2 つの値は要らない。
  当たる光が箱を温め、熱は対の面から漏れる — ADR-0426 の「溜めて漏らす」が、物の量と熱容量から出る。
- ADR-0426 の D(面ごとの溜めた熱)は、**当たる面より箱が粗い所**(地面のセルの中身の草・物の粗い箱の表面)の近似としてだけ残る(残すかは【エンジン】問い。T-0991)。

**4. 粗くした時(§11.1 N1・§11.2 S43)**
- 物の箱の細かさは、物の形(一番薄い寸法)と局所の状態(反応の前線・温度の差・当たる熱の流れの差)だけで選ぶ。予算・視点で粗くしない。
- 粗くすること = 混ぜること: 紙を 0.5 m の箱に混ぜると、同じ光で燃え始めない(試作の 2)。だから**前線・焦点・温度の差がある所は粗くしない**。
  眠った紙(温度も中身も一様)はまとめてよい(一様なので結果は同じ。起きる時に同じ値で分ける)。
- 世界のセルの細かさ(0.5 m / 0.25 m)は、物の箱には効かない(物の座標の箱。§12.2)。違うのは囲むセルの熱容量だけで、紙の燃え方は同じ向き(試作の 5)。
- 物の箱が焦点より粗いと、焦点の熱が箱に均される(箱 15.6 mm は燃え始めが 5 倍遅く、燃え続けない)。焦点の細かさに合わせて箱を細かくするのは、N1 の「当たる熱の流れの差」で選ぶ。
  箱 7.8 mm と 3.9 mm で、燃え始めて燃え続け、焦点のボクセルが燃え切る向きは同じ(燃え続けた時間 9.78 s と 8.73 s。T-1016 で膜の厚さ・小刻み・物の中の伝導率を直した後)。
  燃え始めの時刻は箱が焦点を分けて持てるかで変わる(1.0 s と 0.37 s)ので、焦点の所は当たる熱の流れの差で細かくする。

**5. 刻みの順(§2.5)**: 対の面は 6〜8(運ぶ・まっすぐ運ぶ・広がる)の当てる段で、物のボクセルの反応は 9(セルと同じ関数)。

**試作(T-0991・tests/object_heat_test.cpp。CPU だけ・試験の中の仮の口)**: 虫眼鏡の焦点の紙(0.1 mm・箱 7.8 mm)が 1.0 s で燃え始め、
レンズを外してから 9.8 s 燃え続けて焦点のボクセルの炭が燃え切る(2 本目)。0.5 m と 0.25 m の世界で燃え始め 0 %・燃え続けた時間 0.34 % の差・保存 0・決定的。
箱 3.9 mm でも同じ向き(8.7 s。T-1016)。
同じ紙をセルに混ぜると燃え始めない。詳しくは ADR-0434「試作の結果」。

**未確認**: 燃え広がり(物の中の隣のボクセルへ。紙の面に沿った火は炎の放射で広がる。炎 = 物の外の気体の反応で、囲むセルの細かさに依る)・セルより小さい自然の対流が混ざりを何倍にするか・
物の表面の放射の行き先(23)・占める体積(T-0820)と物のボクセルの中の気体の体積の分け方・費用(物の数 × ボクセル数。眠った物はまとめる)。

### 12.5 物のまわりの空気の層(D-667・2026-10-26 ユーザー。ADR-0469 の 3-4・D-660。T-1158)
- 物の箱の並びを骨格の外へ k 層広げ、流れる空気の箱(§12.1 の「物の座標の木にも骨格と流れる箱がある」)として持つ。熱分解で出た燃える気体は、この層で O2 と混ざって燃える(物にくっついた炎)。
  層 ⇄ 世界のセルが今の膜の口。燃えている物だけ層を持つ(冷えた物は頁を持たない)。
- 順: 層 1 段・流れなし(面ごとの膜の気体と同じ形)で燃え広がり(T-1097 の場面)を確かめる → 数層と流れ。層を超える大きい炎は世界を細かくする規則(§11.1)で受ける。
- 層を作る時は囲むセルの中身を体積の分だけ帳簿でセル → 層へ移す(返す時は逆。帳簿の「物との受け渡し」)。無い頁 = 0 の約束は変えない(§10.2)。
- 膜の厚さは物の大きさと囲むセルの勢いから導く(書く値なし。ADR-0469 の 3-5 の一旦の決定)。物の中のボクセルどうしの放射は放射の家族の対の式を当てる(3-6 の一旦の決定)。
- 未確認: 物どうしの層が重なる所(薪の山・積んだ紙)は、物 ⇄ 物の対の面で層どうしを受け渡すか片方だけが持つか(数層の段で決める)。
- **燃える物が多い時(D-693・2026-11-12 ユーザー。Q174)**: 層の流れは燃える物の数が増えても強い形を目指す。費用は「燃える物の数」ではなく「燃えている空気の体積」で増える形にし、
  結果を変える手抜き(D-428)はしない。今(T-1223。RTX 3070 Ti)は 1 物あたり紙 層 2 段 0.075 ms・層 4 段 0.194 ms で、燃える物 1000 で 75〜190 ms/刻み(物の数に比例)。
  道(研究 T-1320): 結果を変えない削り(圧力の欄 32bit・面ごとの流れ 1 回・汚れたボクセルだけの赤黒)→ **重なる層を 1 つの共有の空気の格子にまとめる(芯。上の「重なる所」の問いも同じ芯で解く)**
  → 大きい火は世界を細かくする規則へ(§11.1・帳簿で受け渡し・無い所 = 0)→ 層ごとの刻みの長さを状態で(R-T2 の枠・0.1 K の内)。
  段 2 で予算を超えて答えが違えば「重なる所だけ」共有に → ダメなら細かくする規則を早める。この節の形(D-667)を変える時は【エンジン】の問いで作り手から見た違いを出す。
  多重格子の規則を変えて速くする道は研究 T-1321(D-688)。
  **段 2 の詰め(2026-11-12 T-1331。案・未決)**: 物の箱は位置・向きを持たないので、共有の格子には物の箱を世界の格子に結ぶ共通の座標が要る(土台の印。司令塔へ)。
  仮のおすすめ = 止まった燃える物の層だけを地面に固定した格子(§11.1 の細かくする頁と同じ置き場の見込み)へ帳簿で移し、動いている物は今の物ごとの層のまま。
  段 1 の後の 1 ボクセルの費用から、段 2 だけでは 1000 個の密な山で約 15〜18 ms(予算 10 ms の 1.5〜1.8 倍)の見込み(未確認)。詳しくは T-1331。
  **2026-11-12 ユーザーの答え**: 止まっている燃える物の層は地面に固定した空気の格子へ帳簿で移し、動いている物は物ごとの層のまま(D-697。この節の「層 ⇄ 世界のセルが今の膜の口」を止まった物で改訂)。層の流れの圧力の答えは多重格子を残差の線 7 まで回して決まった規則で丸めた値(D-696。D-677 の改訂・GPU は T-1355)。物の箱を世界の格子に結ぶ形の案は T-1331(司令塔の一旦の決定の案・ユーザー未確認)。詰めた形は §12.6(案・仮)。

### 12.6 止まった燃える物の層を地面の格子へ: 物の箱を世界の格子に結ぶ形(**案(仮・ユーザー未確認)**。T-1331・ADR-0541 Proposed・D-697)
(2026-11-13 wt5 T-1331 の設計役。コードは書いていない。司令塔の一旦の決定の案 = 案 1 を詰めたもの。比べた案 2 は §12.6.7。土台の共通部分に触れる所は §12.6.9 の印 = 司令塔が決める)

#### 12.6.1 要点
- **案 1(おすすめ)**: 物の箱に「物の物理の物の番号」を 1 つ足し、姿勢は物の物理(AVBD)からだけ読む。止まった燃える物は、骨格を物の箱に残したまま、空気の層だけを地面に固定した格子(場所に 1 つ)へ帳簿で移す。
  格子のボクセルが骨格とどれだけ重なるかは、ADR-0360 §2 の占める数え(4³ 点を整数で数える)を格子のボクセルの細かさで回して作り、骨格 ⇄ 格子は ADR-0360 §3 の対の面で受け渡す。
- 流れの核は今の層の流れ(§12.5・D-696 の答え)のまま。違いは壁が 0/1 の印ではなく「開いた体積の割合・面の開きの割合」(21 §2.7 と同じ入力)になることだけ。向きの揃った物 1 つでは割合が 0/1 になり、今の物ごとの層とビット一致する。
- 費用は「燃えている空気の体積」で増える形になる(D-693 の形は満たす)。ただし段 2 だけでは 1000 個の密な山で 10 ms の予算に届かない見込み(§12.6.6。1.6〜3.7 倍・未確認)。

#### 12.6.3 流れ(止まっている間)
- 格子の上で今の層の流れの関数をそのまま回す(§12.2 の「違うのは座標だけ」)。壁は θ_v・θ_f(開いた割合 ×(1 − 塞ぐ割合)だけ通る。21 §2.7)。圧力の容量は θ_v に比例、面の係数は θ_f に比例。
  向きの揃った物(回り 0・位置が格子に揃う)では θ が 0 か 1 だけになり、式が今の 0/1 の壁と同じ数を作る → **物 1 つの場面で今の物ごとの層とビット一致**(T-1331 の完了条件 2 をこの形で確かめる)。
- 格子の端のボクセル ⇄ それを囲む世界の葉 = 今の膜の口(層 ⇄ セル)。格子が葉をまたいで広がるので、端のボクセルはそれぞれ自分を囲む葉と受け渡す
  (物ごとの層は 1 つの囲むセルとだけ受け渡すので、葉の間の圧力の差が山の中を通らない。格子では通る = 風が薪の山を抜ける #7)。
- 骨格のボクセル ⇄ 格子のボクセル = 対の面(ADR-0360 §3。熱の伝導・孔を通る気体)。今の「骨格の表面 ⇄ 層の 1 段目」の面は、向きの揃った物ではこの対の面と同じ組になる。
- セル(葉)への受け渡しは集めて書く段(T-1332・ADR-0500 の 3)のまま。行き先を「セル」から「セル または 格子のボクセル」に広げる(土台の印 ③)。
- 1 つの格子の箱は大きい(山 1 つで 46〜54 万ボクセル)ので、今の「物 1 つ = 1 グループ」では回せない(T-1355: 12 万ボクセル 1 グループで 213 ms)。
  **1 つの箱を複数のグループで回す多重格子(V 字の段ごとに Dispatch)**が要る。赤黒の色ごとの更新は順に依らないので、1 グループで回した答えとビット一致にできる(T-1350 の段ごとの Dispatch を D-696 の答えへ)。

#### 12.6.4 動く ⇄ 止まるの切り替わり
**判定(状態だけ。D-465)**: 物の物理には眠りがまだ無い(T-0044 は Todo・PxBody に眠りの欄が無い)ので、PxBody の状態と数え 1 つで決める(仮)。
- 置く ⇐ 物の表面の点の最大の速さ × 刻みの長さ < 格子のボクセル 1 つ(7.8 mm)が K 刻み続いた(K は法則の定数。仮 8)。
- 運ぶ ⇐ `anchorPose` から物の表面のどれかの点が格子のボクセル 1 つ以上動いた、または最大の速さ × 刻み ≥ 1 ボクセル。
- 置いたまま 1 ボクセル未満だけ動いた時は、その物の導かれる値(θ・対の面)を作り直す(押しのけは世界と同じく占める体積の変化で出る。式を足さない)。
- 作り手から見て: ゆっくりの物(転がり始め・沈む)も空気は地面に残り、物が空気の中を押し進む。1 刻みに 1 ボクセル以上動く物だけ炎がくっついて運ばれる(D-667 の形)。
  境の値はボクセルの大きさと刻みから導くので書く値は無い(K だけ定数)。

**止まる時(運ぶ → 置く)** — 1 刻みの当てる段の中で一度に(D-567 の「一度に移し帳簿に載せる」と同じ形):
1. 物の層のボクセル s(物の座標)と格子のボクセル g の重なりの点の数 c(s, g) を数える(細かい側で 4³ 点。整数)。
2. s の中身 X_s(欄ごと)を g へ ⌊X_s · c(s, g) / Σ_g c(s, g)⌋ ずつ配り、余りは c の一番大きい g へ(同じなら g の地面の座標の小さい方。状態だけで決まる)。
3. 頁が無かった g は頁を作る。頁の 64 ボクセルのうち、層から受けなかった点の分(64 − Σ_s c 点)は、囲む葉の気体を体積の分だけ移す(今の「層を作る」と同じ セル → 層 の規則)。
4. 既に格子があった所(ほかの止まった物の空気)は足すだけ。重なっていた分の空気は一時的に濃くなり、圧力の解きで外へ押し出される(二重に数えていた空気が、ここで保存のまま 1 つの空間に戻る)。
5. 物の箱を骨格だけに畳む。
**動き出す時(置く → 運ぶ)**:
1. 物の層の箱(骨格 + k 層・物の座標)を作り直し、層のボクセル s の各点が入る格子のボクセル g から、g の中身 × 点の重み ÷ 64 を取る(切り捨て。余りは g に残る)。
2. 同じ刻みに動き出す物が m 個同じ点を取る時は 1/m ずつ(点の重み = 12 / m。12 = 1〜4 の最小公倍数。5 個以上は上位 4 物の溢れと同じ計器)。物の登録の順に依らない。
3. 格子の頁の無い所の点は、囲む葉から体積の分だけ取る(今の「層を作る」)。
4. どの置いた燃える物の「骨格 + k 層」にも触れなくなった頁は、今の「層を返す」と同じ規則で葉へ返す(層に気体でない物があれば返さない)。
**保存・決定性・ビット一致**
- 配りは全部整数の切り捨て + 余りの決まった行き先なので、Σ 葉 + Σ 格子 + Σ 物 + Σ 対の端数 − 帳簿 = 一定がビット単位で保たれる。物の層 ⇄ 格子の移しは帳簿の理由「物との受け渡し」(ADR-0360)。
- GPU は「行き先の 1 ボクセル = 1 スレッドが(物, s)の一覧を集めて足す」= T-1332 の集めて書く段と同じ形。整数の和なので順に依らず、CPU と同じ関数(shaders/common の 1 つの源)でビット一致。
- 往復(止まる → すぐ動き出す): 向きの揃った物では c が 0 か 64 だけなので中身がビット単位で元に戻る(試験にする)。斜めの物は点の数えで配り直すので元には戻らないが保存は 0・決定的(D-520 の往復の試験)。

#### 12.6.5 世界の頁との重なり(D-428・§11.1)
- **持ち主は 1 点に 1 人**: 格子のボクセルは自分の体積の中身を持ち、囲む世界の葉は「葉の体積 − 格子の頁の体積 − 格子の外の物の占める体積」の中身を持つ。葉の見立ての空きはこの残りから作る(ADR-0360 §2 の MakeCellView に格子の体積を足す形)。

- 世界の木を格子のレベル Lg まで細かくしようとする所で格子の頁がある時は、格子が細かい側を持つ(木は Lg − 1 で止まる。頁があるかは状態なので D-465 の場合分けにならない)。
