## 0. 結論(一つの芯)
1. **音は二つの層で、データと発火は「物理エンジン → サウンドエンジン」の一方向に流れる**(D-590)。
   - **法則の音**(GPU・Model・決定的): 出来事が音のエネルギーを出し、距離で弱まり、壁で遮られて届く。**生き物が聞くのはこちら**。
   - **鳴らす音**(CPU・View・サウンドエンジン): 法則の出来事で発火して鳴らす。**作り手が主に触るのはこちら**で、強める・変える・足すなど好きにできる。
     世界へは戻らない(聞くだけなら変わらない。D-403)。
2. **法則の音の届き方は「広がる」家族**(D-591・20 §8)。新しい家族も新しい解き方も作らない。
3. **感覚は状態を読むだけ**(D-593)。見る = 光・嗅ぐ = 気体の濃さ・熱い = 温度・聞く = 法則の音。感覚専用の札・場は作らない。
4. **サウンドエンジンには、世界の状態を読む口を厚く作る**(聞き手の体の状態・今いる地域を含む。D-594)。読むだけで、使い方は全部ゲーム。
5. **匂いは本物の物質**(D-595)。新しい仕組みは作らない。費用は 2 周目の研究 R-S1 で確かめ、合わなければ数種類の匂いの軸に下げる(D-596)。

## 1. 作り手から見た姿(いちばん大事)

### 1.1 書くもの
| どこに | 書くもの(名前は仮) | 書かなければ |
|---|---|---|
| 物質の値(法則の音) | **鳴りやすさ**(出来事のエネルギーのうち音になる割合)・**音の通しやすさ**(m²/s)・**音の吸いやすさ**(1/s) | 鳴らない・吸わない。通しやすさは相ごとの既定(§2.3。仮) |
| 法則の行の出来事の登録 | どの法則の行が音の出来事を出すか(ぶつかる・割れる・燃える・流れる・吹く…)と間引き方 | 出さない(ブランクの世界は 0。D-455) |
| サウンドエンジン(Luau・D-318) | 出来事 → 鳴らし方の表・ミックス・EQ・BGM の規則・読む口(§3.2)から何を使うか | 何も鳴らない |
| 生き物の行動表(09) | どの感覚の値をどのしきいで読むか(気付く匂いの物質・聞こえる強さ・見える明るさ)・目・鼻・耳の場所 | 感じない |
| 物質と反応(匂い) | 匂いの物質・それを出す反応・時間で分解する反応 | 匂いは無い |

### 1.2 書かなくてよいもの
- 音の伝わり方の規則(角を回る・扉を通る・壁で止まる・距離で弱まる)。通り道の物質の値と物の塞ぐ面から出る。場面ごとの「聞こえる範囲」は書かない。
- 感覚のための別の欄・札(匂いの札・音の札・視界の札)。感覚は状態を読むだけ。
- 体の状態で聞こえ方を変えるための「時間」の欄。体の中の物の量は体の中の反応で状態として変わり、口はそれをそのまま読む。

### 1.3 作り手から見て変わること
- 生き物が聞く音(法則)と、プレイヤーが聞く音(鳴らす)は別物。鳴らす側はいくら盛っても世界の結果は変わらない。法則の側は壁・扉・距離で正確に変わる(作戦になる)。
- 同じ出来事で両方が発火するので、鳴らす側だけ強めても獣は気付かない。食い違いは作り手の責任で、計器(§3.2 の「聞き手の所の法則の音」)で見える。
- 「BotW のように出来事が音を出す」は、鳴らし方の表を書けば出る。物理から音を合成する研究(前の D-452)は持たない。

## 2. 法則の音(GPU・Model・決定的)

### 2.1 出来事
- 音の出来事は、**法則の行の出来事**(S52 (2)・ADR-0392〔reflect-a8〕)のうち「音のエネルギーを出した」もの。口を別に作らない。
- 中身(全部整数): 刻み・場所(セル)・法則の行の鍵(ぶつかる・割れる…)・物質(当たった側と当てた側。最大 2)・**出来事のエネルギー**・**音のエネルギー**(= 出来事のエネルギー × 鳴りやすさ)。
- **一回の出来事**(はじける・割れる・倒れる)と**続く音**(燃えている・流れている・吹いている)を分ける。
  - 一回の出来事: 1 つずつ出す(リングへ。06 §3)。
  - 続く音: 1 つずつ出さない。毎刻み、源(セルに入る音のエネルギー)だけを法則の音の場に入れ、鳴らす側へはブロックごとのまとめ(法則の行 × 物質ごとの強さの和)を出す(数万の炎のセルを 1 つずつ鳴らさない)。
- 出来事は刻みの終わりにキー(刻み・種類・場所)で並べてリングへ(06 §3)。**リングの溢れは鳴らす側だけに効き、法則の音の場には効かない**(源は刻みの中で場に直接入る)。

### 2.2 届き方: 「広がる」家族(D-591)
- 型: **坂に沿ってにじむ**。音のエネルギーの密度の坂を下ってにじみ、通り道の吸いやすさで減る。
  → **角の向こうへ回り込む・閉じた壁で止まる・開いた扉は通る・距離で弱まる**が、同じ一つの式から出る(角の向こうの足音・扉越しの声)。
  まっすぐ運ぶ家族に入れない理由: 音は角を回り込む(回折)ので、まっすぐ運ぶと角の向こうで聞こえなくなる(claude/34 §6.3)。
- 解き方: 広がる家族の陰(後退 Euler。決まった回数)。解く部品は釣り合う家族と同じ多重格子(20 §8.1・§9.1)。音のための部品は書かない。
- 伝わる速さ: **既定は「刻みのうちに届く」**(D-467 の最速の側。仮)。本物の音速なら 1 刻みに約 5.7 m なので、遅れが目に見えるのは数十 m から。
  鳴らす側は距離から遅れを付けてよい(View)。法則の側で音速の遅れが要る場面が出たら、広がる家族の「伝わる速さ」の値で選べる形にする(20 §8.2 の 3)。
- **真実として持つ**(D-592。仮・ユーザー未確認【エンジン】§7):
  - 音のエネルギーは出来事のエネルギーから分けて出し(帳簿の列「出来事 → 音」)、吸い込みで熱に戻す(「音 → 熱」)。**保存は厳密**(D-465)。
  - 閉じた洞窟・部屋では少し残る(**残響が法則から出る**)。外では速く消える。
  - **ある所にだけ持つ**(疎な欄。20 §10.2)。全部 0 になれば頁を返して眠る。静かな世界の費用は 0。
  - セーブ(差分。S36)に入るが、静かな所は 0 なので大きくならない見込み(未確認)。
- 細かさによらない: 通しやすさ・吸いやすさは物理の単位(m²/s・1/s)で書き、粗い箱の値は混ぜる規則(S23・20 §11.2)。0.5 m と 0.25 m で同じ届き方(R-A1 の合格)。

### 2.3 通り道
- 物質の値「音の通しやすさ」で決める。S40 の「空気の中だけを通る」は**相ごとの既定の値**で出す: 気体は通す・液体と固体は通さない(仮)。
  作り手が値を書けば、水中・薄い板越しも通る(値だけで変わる。エンジンの作りは変わらない)。
- **物と場の口をそのまま使う**: 物の塞ぐ面・面の開き具合(20・21 §2.7)で、閉じた扉は塞ぎ、開いた扉は開き具合だけ通す。音のための別の当たりは作らない。
- 表面の細かい形(23 §7)の溝・割れ目も、面の開き具合として同じに効く。

### 2.4 刻みの順(20 §2.5)
- 法則の音の場は **8 広がる** の中で解く(熱の伝導・混ざる・匂い・染み込みと同じ段)。
- 源: 2(物の物理)の出来事はその刻みの 8 で、9(反応)の出来事は次の刻みの 8 で場に入る(順で決まる 1 刻みの遅れ。決定的)。続く音の源も同じ。
- 10(受け渡しと締め)で、出来事をリングへ・続く音のまとめと読む口のスナップショットを抽出へ出す(→ サウンドエンジン)。

### 2.5 費用と眠り
- 音の場がある所だけ起きる。費用の読み方は広がる家族のまま(活性のブロック × 回数)。費用は未確認(R-A1)。
- 粗さは局所の状態だけで選ぶ(N1・20 §11.1)。音の場のために粗さの規則を別に作らない。

### 2.6 ほかの文書から来る要求(2026-10-21 本体のマージで当てた。runner/handoff-to-a5.md)
- **出来事の出どころ**: 割れの音の出来事は 22 §3.3 の割れから、破れ(火花・雷)の音は 24 §2.2 から出す(T-0870・T-0880)。どちらも反応の家族(刻みの 9。02 §9.5)の出来事なので、法則の音の場へは次の刻みの 8 で入る(§2.4)。
- **口は登録制**: 法則の行の出来事の口(ADR-0392・15 §3.1)は登録制で、登録が無ければ出さない。音の源はこの口の音の分(§2.1)。音のための別の口は作らない。
- **帳簿**: 外への出入り(天候・止まった棚)は帳簿の 1 列(20 §2.4・§14.2)。音のエネルギーを真実で持つ間(D-592 仮)は、帳簿の列「出来事 → 音」「音 → 熱」もここに並ぶ。
- **刻みの長さが場所ごとに変わる**(D-600・20 §14.2): 法則の音の場は広がる家族なので、長い刻みのブロックとの境の受け渡しは面の帳簿の形(20 §14.2)に従う。音のための別の規則は作らない。

## 3. 鳴らす音(CPU・View・サウンドエンジン)

### 3.1 流れ
```
GPU 段 10: 音の出来事(並べてリング)・続く音のまとめ(ブロックごと)・読む口のスナップショット
CPU: リングを読む(1〜3 フレーム遅れ)→ 鳴らし方の表(Luau)で音素材と鳴らし方を選ぶ → 自作ミキサー → XAudio2(D-317)
```
- 鳴らし方の表: (法則の行, 物質) → 音素材の組(ランダムに選ぶ候補)・音量と高さの幅・出来事のエネルギーから音量と高さを決める曲線。
  **作り手は強める・変える・足す・消すを自由に書ける**(D-590)。ゲームの中身なので Luau(D-318)。
- 鳴らす側は浮動小数点でよく、決定性は要らない(View)。ただしデバッグのため、同じ出来事の列で同じ選び方になる(乱数は出来事の鍵から)。
- 体験版(D-534)に要るのは、この節(出来事で発火して鳴らす)まで。法則の音(§2・R-A1)を体験版に入れるかは D-534 ③ の「物理の音」の読み(本体)。

- 雷の熱は 4095 K で頭打ち(D-588)。見た目と同じく、**雷の音の強さは鳴らす側(サウンドエンジン)が状態(破れの出来事のエネルギー・電荷)から決めてよい**(法則の音の場の値は頭打ちのまま)。

### 3.2 読む口(読むだけ。D-594)
| 口 | 中身 | 来る道 |
|---|---|---|
| 出来事 | §2.1 | リング(06 §3) |
| 続く音のまとめ | ブロック × 法則の行 × 物質の強さ | 抽出(06 §4) |
| 聞き手の所の法則の音 | 聞き手のセルの音の場の値と坂の向き(どちらから来たか) | スナップショット |
| **聞き手の体の状態** | 体の中の物質ごとの量(読む物質はゲームが登録)・体温・蓄え・息の成分 | スナップショット(06 §3「プレイヤーの状態」) |
| **今いる地域** | 世界のデータの地域の印・天候の予定の今の値(05 §5) | 世界のデータ(CPU が持つ)+ 聞き手の場所 |
| 周りの広さ | 残響を選ぶための占有のまとめ(粗い層と細かい層) | 抽出 |
- **どの値をどう聞こえ方(ミックス・EQ・BGM)に変えるかは、全部ゲーム**(Luau)。エンジンは口だけを持つ(D-594)。
- 体の状態は、体の中の反応で変わる量をそのまま読む(取り込んだ物が反応で減る・時間が経つと変わる、は状態から出る)。口は時間や旗を別に持たない。
- 聞き手は普通はプレイヤーの体。エディタでは任意の場所に置ける(神の目。D-470)。
- 読む口は抽出とスナップショットを読むだけで、世界のハッシュは変わらない(D-403。試験)。

### 3.3 ミキサー
- 声の数の上限(例 128)。優先度 = 大きさ × 距離の減衰。上限を超えたら優先度の低いものから止める。
- 空間化: 第 1 段は距離の減衰 + 左右のパン + 前後の低域カット。HRTF は研究(後回し)。

### 3.4 遮りと残響
- 遮り: 描画の DXR で、聞き手から主な音源へ光線を飛ばして遮りの量を出す(View 同士なので決定性は要らない。10 §5)。
  **もう一つの道(案)**: 聞き手の所の法則の音の場(§3.2)から遮りを読む(獣が聞くのと同じ届き方で、プレイヤーにも聞こえる)。どちらを使うかはサウンドエンジン(ゲーム)が選ぶ。
- 残響: 場所の広さ(洞窟・屋外)を占有のまとめから見積もり、残響の設定を切り替える。

### 3.5 入力への即時の反応
- 足音・道具を振る音は、入力を受けた瞬間に CPU が見込みで鳴らす。GPU の結果(実際に何を踏んだか)が届いたら、次からそれに合わせる(01-architecture)。

## 5. 匂い(D-595・D-596)
- **匂いは本物の物質**: 匂いを出す物(獣・血・焼いた物・煙)が反応で匂いの物質を出し、風(運ぶ)と混ざる(広がる)で動き、**時間で分解する反応**で消える。
  新しい仕組み・欄は足さない(20 §10.1: 匂いは真実の「物質の量」)。
- **種類の上限を決めない**(物質の数の上限は反応表の上限のまま)。数を保つのは分解の反応(作り手が書く)。
- 「匂いの強い物で隠す」は匂いの物質の量の比で、しきいは行動表。法則の外の「隠す」札は無い。
- 気になる所(未確認。R-S1 で測る):
  - **微量の端数**: 匂いは薄い。0.5 m のセルの空気は約 5 mol なので、百万分の 1 で約 5 µmol、十億分の 1 は気体の量子(1 µmol)未満になる。
    広がる家族の端数の扱い(決まった乱数で丸める)で、薄い所がどう消えるか・どこまで届くか。作り手が匂いの物質の量の単位を大きく取る(この宇宙の匂いの物質の性質として)と避けられるか。
  - **1 セルの物質の種類の数**: 獣の多い所・血・焼いた物が重なる所で、1 セルに入る物質の種類がいくつになるか。混ざるの費用は種類の数に比例する見込み。

### 5.1 R-S1 匂いの費用(研究・2 周目。claude/35 §5)
- 合格: 獣・焼いた物・血の匂いを本物の物質で持って、場面の費用が費用の線の内 / 分解の反応で種類の数が増え続けない(時間で頭打ち) /
  風下と風上で気付かれる距離が細かさによらない(0.5 m と 0.25 m で同じ) / 決定的・帳簿が合う。場面(例: 群れ 1・焚き火 1・倒した獣 1)は着手時に決める。
- 打ち切り(2 本): 1 本目 = そのまま本物の物質。2 本目 = 薄い匂いの量の単位と端数の丸めを直す。2 本で費用の線を超えたら退く道へ。
- **退く道: 数種類の匂いの軸にまとめる**(軸ごとに 1 つの物質。匂いを出す物は軸の物質を出す)。物質の数を減らすだけなので、エンジンの作りは変わらない(ゲームの中身へ)。
