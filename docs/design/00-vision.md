# 00 ビジョン — 魔法研究 × オープンワールドアドベンチャー

## 一言で
プレイヤーは世界の現象を**科学する**。燃焼・相変化・反応の連鎖を観察し、仮説を立て、実験し、
隠された自然法則を発見する。魔法はその法則への介入であり、魔法の研究と化学の研究は同じ行為になる。

## BotW との関係
- BotW の化学エンジンは「属性の伝播ルール」。規模(同時に燃えるオブジェクト数)と深さ(連鎖は 1〜2 段)を
  ハードの都合と設計判断で抑えていた。
- このゲームは BotW の進化系を名乗らない。BotW の強さは手で配置した膨大なコンテンツで、それは個人では作れないし、
  このエンジンの思想(真実は VRAM)とも逆向き。
- 代わりに、BotW が原理的にできなかったことを遊びの中心にする:
  - **規模**: 草原全体が風向き・傾斜・湿り気に従って同時に燃え広がる
  - **深さ**: 木 → 炭 → 風で舞う → 粉塵 → 引火 → 粉塵爆発 → 水が飛ぶ → 火が消える
  - **副産物**: 灰・炭・蒸気・煤・溶けた金属が残り、次の反応の材料になる
  - **法則への介入**: 魔法 = 反応表へのパッチ(触媒・阻害・転換・増幅)

## コンテンツの考え方
- **コンテンツ = 反応則そのもの。** 手で置くものを最小にする。
- 世界は決定的な生成 + 手直し(D-312)。一つのシームレスな世界の中に、性質の違う地域(硫黄の多い地域・低温地帯など)を置き、同じ法則を違う環境で検証できるようにする。
- 進行は BotW 型: 大きな目標に向かいつつ、寄り道は自由(D-103)。発見の蓄積(ノート・図鑑)と、少数の NPC の依頼(D-106)が進行を支える。
- 観測手段(温度計・組成分析・記録・自動実験装置など)がプレイヤーの装備であり、最重要の手作りコンテンツ(中身はユーザー)。

## ゴール(2026-09-30 決定。docs/plan/DECISIONS.md の L0)
- **ゲームを完成させて販売する**(D-001)。エンジンはその手段。期限なし・品質優先(D-002)。
- 出し方: 友人と自分で遊んで確かめる → 体験版(1 地域)→ 早期アクセス → 正式版(D-007)。
- ゲームの形(L1): 三人称(道具作り・観察で一人称にも)/ 8km 四方のシームレスな世界 / BotW 型の大きな目標と自由な寄り道 /
  実在する生態系としてのファンタジーの生き物・敵・ダンジョン / 少数の NPC / 天候・季節・流れる水 / 洞窟も地形。
- ゲームの中身(面白さ・設定・生態系・言語・文化・背景・反応表・魔法)は**すべてユーザーが決める**。
- エンジンの約束: 世界の状態と因果はすべて GPU で完結し、**機種が違っても完全に同じ結果**になる。SI 単位と保存則を守る
  「化学が作れるエンジン」(D-205・D-206)。

## 既知のリスク
- 化学サンドボックスは「作者には無限に面白く、プレイヤーには何をすればいいか分からない」になりやすい。
  最初の発見は確実に起きるように仕込む(中身はユーザー)。反応表を増やすより、発見の導線を作る側に回る判断がいつか要る。
- BotW の化学が浅いのは設計判断でもある(連鎖が深いと因果が追えない)。深い連鎖が面白いかは触って確かめる。
