# 00 ビジョン — 魔法研究 × オープンワールドアドベンチャー

## 一言で
プレイヤーは世界の現象を**科学する**。燃焼・相変化・反応の連鎖を観察し、仮説を立て、実験し、
隠された自然法則を発見する。魔法はその法則への介入であり、魔法の研究と化学の研究は同じ行為になる。

## BotW との関係
- BotW の化学エンジンは「属性の伝播ルール」。規模(同時に燃えるオブジェクト数)と深さ(連鎖は 1〜2 段)を
  ハードの都合と設計判断で抑えていた。
- このゲームは BotW の進化系を名乗らない。BotW の強さは手で配置した膨大なコンテンツで、それは個人では作れないし、
  このエンジンの思想(真実は VRAM)とも逆向き。
- 代わりに、BotW が原理的にできなかったことを遊びの中心にする:
  - **規模**: 草原全体が風向き・傾斜・湿り気に従って同時に燃え広がる
  - **深さ**: 木 → 炭 → 風で舞う → 粉塵 → 引火 → 粉塵爆発 → 水が飛ぶ → 火が消える
  - **副産物**: 灰・炭・蒸気・煤・溶けた金属が残り、次の反応の材料になる
  - **法則への介入**: 魔法 = 反応表へのパッチ(触媒・阻害・転換・増幅)

## コンテンツの考え方
- **コンテンツ = 反応則そのもの。** 手で置くものを最小にする。
- 世界はプロシージャル生成。「毎回違う自然環境で、同じ法則を検証する」ことに意味を持たせる(硫黄の多い地域、低温地帯)。
- 進行はクエストではなく**発見の蓄積**(ノート・図鑑)。
- 観測手段(温度計・組成分析・記録・自動実験装置)がプレイヤーの装備であり、最重要の手作りコンテンツ。

## 成功条件を 2 つに分ける
- **エンジンの成功**: テスト環境で「火を 1 点に落とす → 風下・斜面に広がる → 湿った帯で止まる → 木が炭化して倒れる → 煙 →
  素材別の音」が動き、デモ映像が撮れ、公開されている。
- **ゲームの成功**: 別の山として後で定義する。エンジンの完成を待たずに、反応表(T-0002)は並行して磨く。

## 既知のリスク
- 化学サンドボックスは「作者には無限に面白く、プレイヤーには何をすればいいか分からない」になりやすい。
  最初の 3 つの発見は確実に起きるように仕込む。反応表を増やすより、発見の導線を作る側に回る判断がいつか要る。
- BotW の化学が浅いのは設計判断でもある(連鎖が深いと因果が追えない)。深い連鎖が面白いかは触って確かめる。
