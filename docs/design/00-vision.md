# 00 ビジョン — 魔法研究 × オープンワールドアドベンチャー

## 一言で
プレイヤーは世界の現象を**科学する**。ゲームの世界は、遊びのために作った独自の法則を持つ**一つの宇宙**で、その中では論文が書けるほど正確に、
いつ・どこで・誰が起こしても同じに働く(D-463)。燃焼・相変化・反応の連鎖を観察し、仮説を立て、実験して法則を見つけ、
見つけた法則で「これが作れる・こういう作戦が立てられる」を広げる(遊ぶために研究する)。
法則は一つの表だけで、現実と嘘の二層に分けない。調整は法則そのものを書き換えることで行い、影響は一貫して全体に及ぶ。現実の化学は出発点のサンプルの一つ。
魔法もこの法則の中にある: 体に蓄えたエネルギーで魔素(物質の一つ)を押す、筋肉と同じ法則(坂の原理。D-466)。

## 優先順位(D-462)
1. **面白さ**が一番。
2. **美しさ**(エンジン設計とゲーム設計の美しさ)が二番。
3. それ以外(手作りか自動か・現実どおりか など)はこの 2 つに従って決める。手で作ること自体に価値は置かない(町も、自動の方が良ければ自動)。

## BotW との関係
- BotW の化学エンジンは「属性の伝播ルール」。規模(同時に燃えるオブジェクト数)と深さ(連鎖は 1〜2 段)を
  ハードの都合と設計判断で抑えていた。
- このゲームは BotW の進化系を名乗らない。BotW の強さは手で配置した膨大なコンテンツで、それは個人では作れないし、
  このエンジンの思想(真実は VRAM)とも逆向き。
- 代わりに、BotW が原理的にできなかったことを遊びの中心にする:
  - **規模**: 草原全体が風向き・傾斜・湿り気に従って同時に燃え広がる
  - **深さ**: 木 → 炭 → 風で舞う → 粉塵 → 引火 → 粉塵爆発 → 水が飛ぶ → 火が消える
  - **副産物**: 灰・炭・蒸気・煤・溶けた金属が残り、次の反応の材料になる
  - **法則の中での魔法**: 魔素を出す・集める・流す・反応させて現象を操る(体に蓄えたエネルギーで魔素を押す。D-466)。起きることは反応表と
    流れ・熱・力の法則で決まり、法則は書き換えない。反応表へのパッチ(倍率・止める・触媒・転換)はエディタの実験の道具としてだけ残す
  - **作戦が一般の法則から生まれる**: 作戦専用の法則は 0(例: 密室の火で酸素が尽きて CO が溜まり、扉を開けると一気に燃えるバックドラフト。D-464)

## コンテンツの考え方
- **コンテンツ = 反応則そのもの。** 手で置くものを最小にする。
- 世界は決定的な生成 + 手直し(D-312)。一つのシームレスな世界の中に、性質の違う地域(硫黄の多い地域・低温地帯など)を置き、同じ法則を違う環境で検証できるようにする。
- 進行は BotW 型: 大きな目標に向かいつつ、寄り道は自由(D-103)。発見の蓄積(ノート・図鑑)と、少数の NPC の依頼(D-106)が進行を支える。
- 観測手段(温度計・組成分析・記録・自動実験装置など)がプレイヤーの装備であり、最重要の手作りコンテンツ(中身はユーザー)。

## ゴール(2026-09-30 決定。docs/plan/DECISIONS.md の L0)
- **ゲームを完成させて販売する**(D-001)。エンジンはその手段。期限なし・品質優先(D-002)。
- 出し方: 友人と自分で遊んで確かめる → 体験版(1 地域)→ 早期アクセス → 正式版(D-007)。
- ゲームの形(L1): 三人称(道具作り・観察で一人称にも)/ TotK くらいの広さ(上空・地下を含む)のシームレスな世界 / BotW 型の大きな目標と自由な寄り道 /
  実在する生態系としてのファンタジーの生き物・敵・ダンジョン / 少数の NPC / 天候・季節・流れる水 / 洞窟も地形。
- ゲームの中身(面白さ・設定・生態系・言語・文化・背景・反応表・魔法)は**すべてユーザーが決める**。
- エンジンの約束: 世界の状態と因果はすべて GPU で完結し、**機種が違っても完全に同じ結果**になる。SI 単位と保存則を守る
  「化学が作れるエンジン」(D-205・D-206。約束の全部は 01「エンジンの約束」D-465)。どんな細かさ(分子まで)でもシームレスに調べられる(D-402)。エンジンに固定の上限を置かない(D-401)。
- 目指す体験: 遊びは BotW、世界の広さは TotK、描画は Death Stranding 2 のように遠くまでくっきり細かい(D-407)。
- 体験したいこと: 杖から魔法を出した時の反動や熱にどう対処するかまで考えて魔法を作る / 魔法 × 化学 × 物理を掛け合わせて大きな効果を狙う
  (閉じた空間で炎を出して酸素を減らす、など)/ 魔法具を形から考えて作り、魔石をはめ、最高効率の形を探す / 作った魔法具が商人を通して他のプレイヤーの店に並ぶ(D-418〜D-422)。
- **理想を下げない**(D-414): 完全 GPU 駆動のエンジンと、構想しているゲーム。見積もりが伸びても、理想を削る案は採らない。

## 既知のリスク
- 化学サンドボックスは「作者には無限に面白く、プレイヤーには何をすればいいか分からない」になりやすい。
  最初の発見は確実に起きるように仕込む(中身はユーザー)。反応表を増やすより、発見の導線を作る側に回る判断がいつか要る。
- BotW の化学が浅いのは設計判断でもある(連鎖が深いと因果が追えない)。深い連鎖が面白いかは触って確かめる。
